## 网络管理

根据国际标准化组织（ISO）定义，网络管理有**五大功能：故障管理、配置管理、性能管理、安全管理、计费管理**。

- **故障管理**：包括**故障检测、隔离和纠正**三方面——维护并检查错误日志、接受错误检测报告并作出响应、跟踪和辨认错误、执行诊断测试、纠正错误。
- **计费管理**：记录网络资源的使用，目的是控制和监测网络操作的费用和代价。
- **配置管理**：初始化网络并配置网络，以使其提供网络服务，目的是实现某个特定功能或使网络性能达到最优。
- **性能管理**：估价系统资源的运行状况及通信效率等系统性能。
- **安全管理**：安全性是网络的薄弱环节之一，而用户对网络安全的要求又相当高，因此网络安全管理非常重要。

> 按管理软件产品功能，又可细分为：网络故障管理软件、网络配置管理软件、网络性能管理软件、网络服务/安全管理软件、网络计费管理软件。目前主要的发展方向有：网管系统（NMS）、应用性能管理（APM）、桌面管理（DMI）、员工行为管理（EAM）、安全管理。
>
> **网络入侵检测系统（IDS）**的主要实现手段是监视和分析网络流量及异常行为，包括对网络协议的监视、对数据包结构的分析以及对网络行为的监控。通过实时监测和分析，IDS 能发现异常行为模式并发出警报，以便管理员采取适当措施。

### 常用网络命令（含跨平台对照）

- **ping**
  - **用法示例**：`ping [hostname/IP]`
  - **作用**：测试主机与目标 IP 的连通性，发送 ICMP 回显请求
  - **Windows**：`ping`
  - **macOS / Linux**：`ping`（macOS 需加 `-c` 限制次数，如 `ping -c 4 baidu.com`）
- **ssh**
  - **用法示例**：`ssh 用户名@主机`
  - **作用**：加密远程登录，管理远程主机（替代不安全的 telnet）
  - **Windows**：Windows 10+ 自带
  - **macOS / Linux**：系统自带
- **telnet**
  - **用法示例**：`telnet [hostname] [port]`
  - **作用**：与远程主机建立 TCP 连接，常用于**测试某个端口是否开放**（如 `telnet 192.168.1.1 443`）
  - **Windows**：需在"启用或关闭 Windows 功能"中开启
  - **macOS / Linux**：需安装（`brew install telnet`）
- **ipconfig / ifconfig**
  - **用法示例**：`ipconfig`（全部配置）、`ipconfig /all`（详细）
  - **作用**：查看网络配置（IP 地址、子网掩码、网关）
  - **Windows**：`ipconfig`
  - **macOS / Linux**：`ifconfig`、`ip addr`（Linux）
- **tracert / traceroute**
  - **用法示例**：`tracert [hostname/IP]`
  - **作用**：跟踪数据包到达目标主机的路径，显示经过的路由器（利用 ICMP TTL 超时）
  - **Windows**：`tracert`
  - **macOS / Linux**：`traceroute`（macOS 需 `sudo` 才能看到完整路径）
- **arp**
  - **用法示例**：`arp -a`
  - **作用**：显示 ARP 缓存，查看 IP 与 MAC 的映射关系
  - **Windows**：`arp -a`
  - **macOS / Linux**：`arp -a`
- **route**
  - **用法示例**：`route print`、`route add`
  - **作用**：查看和修改路由表，管理数据包转发
  - **Windows**：`route print`
  - **macOS / Linux**：`route -n`、`ip route`
- **nslookup**
  - **用法示例**：`nslookup [hostname]`
  - **作用**：查询 DNS 记录，获取域名与 IP 的映射（也可指定 DNS 服务器：`nslookup baidu.com 8.8.8.8`）
  - **Windows**：支持
  - **macOS / Linux**：支持
- **netstat**
  - **用法示例**：`netstat -a`（所有连接）、`netstat -r`（路由表）
  - **作用**：显示网络连接、路由表和接口状态，监控网络活动
  - **Windows**：`netstat -ano` 可显示 PID
  - **macOS / Linux**：`netstat -an`、`lsof -i`、`ss`
- **net**
  - **用法示例**：`net [command]`
  - **作用**：管理网络共享、用户和网络服务等
  - **Windows**：支持（`net use` 映射网络驱动器）
  - **macOS / Linux**：—

> **排障思路**：先 `ping` 网关（判断本机与局域网是否连通）→ `ping` 公网 IP（判断外网连通性）→ `nslookup`（判断 DNS 是否正常）→ `tracert`（定位故障在哪一跳）→ `netstat`（查看端口监听与连接状态）。
