## ES6 新特性

### let 与 const

#### 基本使用

**`let`** 与 **`const`** 是 ES6 引入的**变量声明**方式，取代了有缺陷的 `var`。

- **`let`**：声明**可变**变量。
- **`const`**：声明**不可重新赋值**的常量（声明时必须初始化）。

```js
let count = 1;
count = 2;        // 可修改
console.log(count); // 2

const name = "why";
// name = "tom";  // 报错：const 不能重新赋值

const obj = { a: 1 };
obj.a = 2;        // 可以修改对象属性（const 限制的是"重新赋值"）
console.log(obj.a); // 2
```

> `const` 的"不可变"指**变量不能重新赋值**，而非值本身不可变：`const` 对象仍可改属性。这与 Java 的 `final`、C 的 `const` 有细微差别，是理解 `const` 的关键。



#### 作用域提升

`let`/`const` 与 `var` 在**变量提升**上表现不同。

- **`var`**：提升声明，提前访问为 `undefined`。
- **`let`/`const`**：提升但进入**暂时性死区（TDZ）**，提前访问报错。

```js
console.log(a); // undefined（var 提升）
var a = 1;

// console.log(b); // ReferenceError（TDZ）
let b = 2;
```

> **暂时性死区**：从作用域开始到 `let`/`const` 声明之间的区域，访问变量会报错。它避免了 `var` 那种"提前访问拿到 `undefined`"的隐患，让错误更早暴露。



#### 与 window 的关系

`let`/`const` 与 `var` 在**是否挂到全局对象**上不同。

- **`var`**：声明的全局变量会挂到 `window`。
- **`let`/`const`**：全局声明**不会**挂到 `window`（存在于独立的全局词法环境）。

```js
var a = 1;
let b = 2;
const c = 3;

console.log(window.a); // 1
console.log(window.b); // undefined（不挂到 window）
console.log(window.c); // undefined
```

> `let`/`const` 的全局变量不挂 `window`，但仍可全局访问（`b` 可直接用）。这减少了全局命名空间污染，是 ES6 设计上的一项改进。



#### 块级作用域

`let`/`const` 拥有**块级作用域**，这是它们与 `var` 最大的区别。

- `var` 只有**函数作用域**，会漏出 `if`/`for` 的块。
- `let`/`const` 遵循**块级作用域**，`{}` 内声明只在块内有效。

```js
{
  var a = 1;
  let b = 2;
}
console.log(a); // 1（var 漏出块）
// console.log(b); // 报错（let 块级作用域）

for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i)); // 0 1 2（每次循环独立的 i）
}
```

> 块级作用域解决了 `var` 的两个经典问题：变量泄漏、以及循环中的**闭包陷阱**（`for` 里用 `var` 配合异步会全输出最后一个值，用 `let` 则每次迭代独立）。



#### 其他补充

`let`/`const` 的几个补充细节。

- `let` 可以**先声明后赋值**，`const` 必须**声明即赋值**。
- 同一作用域内 `let`/`const` **不能重复声明**（`var` 可以）。

```js
let x;
x = 10;       // let 可先声明后赋值

// const y;   // 报错：const 必须初始化
const y = 10;

// let z = 1;
// let z = 2; // 报错：不能重复声明
```

> 这些细节体现了 `let`/`const` 的**严谨性**：相比 `var` 的"宽松"（可重复声明、可漏出块、隐式提升），`let`/`const` 强制更规范的用法，是现代 JavaScript 的推荐选择。



### 对象字面量的增强

#### 属性的简写

ES6 允许对象字面量**属性简写**——当属性名与变量名相同时，可省略冒号和值。

```js
const name = "why";
const age = 18;

// 传统写法
const obj1 = { name: name, age: age };

// 属性简写
const obj2 = { name, age };
console.log(obj2); // { name: "why", age: 18 }
```

> 属性简写让"**用变量构造对象**"更简洁。它最常用于函数返回对象、组件传参等场景，是现代代码中随处可见的写法。



#### 方法的简写

对象字面量的**方法简写**——省略 `function` 关键字和冒号。

```js
// 传统写法
const obj1 = {
  sayHi: function () {
    console.log("Hi");
  }
};

// 方法简写
const obj2 = {
  sayHi() {
    console.log("Hi");
  }
};
```

> 方法简写不仅是语法更简洁，还意味着它是真正的"方法"（可用 `super`、不能作构造函数），与 `function` 属性有细微差别。



#### 计算属性名

**计算属性名**：允许用**表达式**动态计算属性名，用方括号 `[]` 包裹。

```js
const key = "name";
const prefix = "user";

const obj = {
  [key]: "why",              // 属性名为变量 key 的值 "name"
  [prefix + "Id"]: 123       // 属性名为 "userId"
};

console.log(obj.name);   // "why"
console.log(obj.userId); // 123
```

> 计算属性名让属性名可以**动态生成**（拼接、变量、表达式），解决了传统对象字面量属性名必须是字面量的限制。



#### Object.is 与严格相等

**`Object.is(a, b)`**：判断两个值是否**相等**，比 `===` 更精确地处理几个特殊值。

```js
console.log(Object.is(NaN, NaN));      // true（=== 为 false）
console.log(Object.is(0, -0));         // false（=== 为 true）
console.log(Object.is(1, 1));          // true
console.log(Object.is("a", "a"));      // true
```

> `Object.is` 与 `===` 仅有两个区别：**`NaN` 视为相等**、**`+0` 与 `-0` 视为不等**。其余行为完全一致。它在需要"精确判断"（如区分 `0` 和 `-0`）时使用。



#### Object.assign

**`Object.assign(target, ...sources)`**：把源对象的**可枚举属性**复制到目标对象，是**浅拷贝**的实现方式之一。

```js
const target = { a: 1 };
const source = { b: 2, c: 3 };

Object.assign(target, source);
console.log(target); // { a: 1, b: 2, c: 3 }

// 常用于合并配置、浅拷贝
const copy = Object.assign({}, target);
```

> `Object.assign` 是**浅拷贝**（嵌套对象仍共享引用），常用于**合并对象**、**复制对象**。注意它会**修改目标对象**并返回它，同名属性后者覆盖前者。



### 解构赋值

#### 对象解构

**对象解构**：把对象的属性**解包**到独立变量中。

```js
const user = { name: "why", age: 18 };

const { name, age } = user;
console.log(name, age); // "why" 18

// 嵌套解构
const person = { info: { city: "深圳" } };
const { info: { city } } = person;
console.log(city); // "深圳"
```

> 对象解构的核心是"**按属性名提取**"：`const { name } = user` 等价于 `const name = user.name`。它让"从对象取多个字段"变得简洁，是函数参数、导入导出等场景的常用技巧。



#### 数组解构

**数组解构**：把数组元素**解包**到变量中，**按位置**对应。

```js
const arr = [1, 2, 3];

const [a, b, c] = arr;
console.log(a, b, c); // 1 2 3

// 跳过元素
const [first, , third] = arr;
console.log(first, third); // 1 3

// 配合剩余参数
const [head, ...rest] = arr;
console.log(head, rest); // 1 [2, 3]
```

> 数组解构**按位置**（区别于对象解构按属性名），常用于交换变量（`[a, b] = [b, a]`）、提取返回值等。它让数组操作更简洁、更语义化。



#### 解构的默认值与重命名

解构支持**默认值**与**重命名**。

- **默认值**：属性不存在时使用默认值。
- **重命名**：`属性名: 新变量名`。

```js
const user = { name: "why" };

// 默认值
const { name, age = 20 } = user;
console.log(age); // 20（未定义，用默认值）

// 重命名
const { name: userName } = user;
console.log(userName); // "why"

// 组合：重命名 + 默认值
const { name: nickName = "匿名" } = {};
console.log(nickName); // "匿名"
```

> 解构的默认值只在**属性值为 `undefined`** 时生效（`null` 不会触发默认值）。重命名用于"属性名与变量名冲突或想改名"的场景，二者可组合使用。



### 模板字符串

#### 模板字符串的基本使用

**模板字符串**：用反引号 `` ` `` 包裹，支持**变量插值**（`${}`）和**多行**。

```js
const name = "why";
const age = 18;

// 变量插值
const str = `我叫 ${name}，今年 ${age} 岁`;
console.log(str); // "我叫 why，今年 18 岁"

// 多行
const multi = `第一行
第二行`;
console.log(multi);
```

> 模板字符串的 `${}` 里可以放**任意表达式**（变量、运算、函数调用），且**天然支持多行**，彻底告别了 `+` 拼接字符串和 `\n` 换行的繁琐。



#### 标签模板字符串

**标签模板字符串**：用一个**函数**处理模板字符串，函数接收被拆分的字符串与插值。

```js
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) => {
    return result + str + (values[i] ? `<b>${values[i]}</b>` : "");
  }, "");
}

const name = "why";
const html = highlight`你好 ${name}，欢迎你`;
console.log(html); // "你好 <b>why</b>，欢迎你"
```

> 标签模板让模板字符串**经过自定义函数处理**。第一个参数是被插值分割的字符串数组，其余参数是各插值。它可用于**国际化、样式处理（styled-components）、HTML 转义**等高级场景。



### 字符串的扩展

#### Unicode 与 codePoint

ES6 增强了字符串的 Unicode 处理，解决代理对（emoji、生僻字）的问题。

- **`codePointAt()`**：正确获取码点（处理代理对）。
- **`fromCodePoint()`**：从码点生成字符。
- **`for-of`**：正确遍历（按码点而非码元）。

```js
const emoji = "😀";
console.log(emoji.length);       // 2（两个码元）
console.log(emoji.codePointAt(0)); // 128512（完整码点）

console.log(String.fromCodePoint(128512)); // "😀"
```

> ES5 的 `charCodeAt` 按**码元**处理，遇到 emoji 等代理对字符会拆成两半；ES6 的 `codePointAt`、`for-of` 按**码点**处理，能正确处理这些字符。



#### 字符串的遍历

ES6 的 `for-of` 可以**正确遍历**字符串（按码点）。

```js
const str = "a😀b";

// for-of 按码点遍历，正确处理 emoji
for (const char of str) {
  console.log(char);
}
// "a" "😀" "b"
```

> 传统 `for (let i = 0; i < str.length; i++)` 按**码元**遍历，emoji 会被拆成两个"半个字符"；`for-of` 按**码点**遍历，一次一个完整字符。



#### includes、startsWith 与 endsWith

ES6 新增了三个**判断子串**的方法，比 `indexOf` 更语义化。

- **`includes(sub)`**：是否包含。
- **`startsWith(sub)`**：是否以某串开头。
- **`endsWith(sub)`**：是否以某串结尾。

```js
const str = "Hello World";

console.log(str.includes("World"));   // true
console.log(str.startsWith("Hello")); // true
console.log(str.endsWith("World"));   // true
console.log(str.includes("xyz"));     // false
```

> 三者都返回**布尔值**，语义比 `indexOf(...) !== -1` 清晰得多。判断"是否存在"用 `includes`，判断"前后缀"用 `startsWith`/`endsWith`。



#### repeat 方法

**`str.repeat(count)`**：把字符串**重复**指定次数。

```js
console.log("ab".repeat(3));  // "ababab"
console.log("*".repeat(5));   // "*****"
console.log("hi".repeat(0));  // ""
```

> `repeat` 常用于生成分隔线、占位符、填充等。注意 `count` 需是**非负整数**，负数或 `Infinity` 会报错。



### 函数的扩展

#### 函数的默认值

ES6 允许给函数参数设置**默认值**，在参数为 `undefined` 时生效。

```js
function greet(name = "匿名", age = 18) {
  console.log(`我叫 ${name}，${age} 岁`);
}

greet();              // 我叫 匿名，18 岁
greet("why");         // 我叫 why，18 岁
greet("why", 20);     // 我叫 why，20 岁
```

> 默认值在参数为 `undefined` 时生效（`null` 不触发）。它替代了旧式的 `name = name || "默认"`（后者会把 `0`、`""` 等假值也替换掉）。



#### 剩余参数

**剩余参数 `...args`**：把**多余的参数**收集到一个数组中，替代 `arguments`。

```js
function sum(...nums) {
  return nums.reduce((acc, cur) => acc + cur, 0);
}

console.log(sum(1, 2, 3, 4)); // 10

// 收集剩余
function greet(first, ...rest) {
  console.log(first); // "why"
  console.log(rest);  // ["18", "深圳"]
}
greet("why", 18, "深圳");
```

> 剩余参数 `...nums` 是**真正的数组**（不像 `arguments` 是类数组），可直接用数组方法。它必须写在**参数列表最后**，是现代处理"可变参数"的首选。



#### 箭头函数的补充

箭头函数（第 19 章已详述 `this`）的几个补充特性。

- **没有 `arguments`**：要用剩余参数代替。
- **不能作构造函数**：不能用 `new`。
- **没有 `prototype`** 属性。
- **不能作生成器**：不能有 `yield`。

```js
// 箭头函数没有 arguments、prototype
const fn = (...args) => args.length;
console.log(fn(1, 2, 3)); // 3

// 不能 new
// const F = () => {};
// new F(); // TypeError
```

> 箭头函数的这些限制源于它"**不是完整函数**"的设计定位——它专注于"简洁的表达式函数"，牺牲了 `arguments`、`prototype`、`this` 等能力。需要这些能力时，仍应使用普通函数。



### 数组的扩展

#### Array.from 与 Array.of

- **`Array.from(iterable)`**：把**类数组或可迭代对象**转为真数组。
- **`Array.of(...items)`**：用**参数**创建数组（无 `new Array` 的单参歧义）。

```js
// Array.from：类数组转数组
const arrLike = { 0: "a", 1: "b", length: 2 };
console.log(Array.from(arrLike)); // ["a", "b"]

// 从字符串
console.log(Array.from("hello")); // ["h", "e", "l", "l", "o"]

// Array.of：无歧义创建
console.log(Array.of(3));        // [3]（而非长度为 3 的空数组）
console.log(Array.of(1, 2, 3));  // [1, 2, 3]
```

> `Array.from` 解决"**类数组/可迭代转数组**"；`Array.of` 解决 `new Array(3)` 的**单参歧义**（`Array.of(3)` 是 `[3]` 而非空数组）。



#### fill 与 copyWithin

- **`fill(value, start, end)`**：用值**填充**数组。
- **`copyWithin(target, start, end)`**：**复制**数组内部一段到指定位置。

```js
// fill
const arr1 = [1, 2, 3, 4];
arr1.fill(0, 1, 3);
console.log(arr1); // [1, 0, 0, 4]

// copyWithin
const arr2 = [1, 2, 3, 4, 5];
arr2.copyWithin(0, 3);
console.log(arr2); // [4, 5, 3, 4, 5]
```

> `fill` 用指定值填充（常用于初始化数组）；`copyWithin` 把数组**内部某段**复制到另一位置。二者都**原地修改**数组，返回原数组。



#### entries、keys 与 values

ES6 为数组提供了三个**迭代器**方法。

- **`keys()`**：键（索引）的迭代器。
- **`values()`**：值的迭代器。
- **`entries()`**：键值对的迭代器。

```js
const arr = ["a", "b", "c"];

for (const key of arr.keys()) {
  console.log(key); // 0 1 2
}
for (const value of arr.values()) {
  console.log(value); // "a" "b" "c"
}
for (const [key, value] of arr.entries()) {
  console.log(key, value); // 0 "a" / 1 "b" / 2 "c"
}
```

> 三者返回**迭代器**，配合 `for-of` 使用。`entries()` 同时拿到键值，常用于需要索引和值都要的场景。



### 展开语法

**展开语法 `...`**：把**数组或对象"展开"**成独立的元素或属性。

- **数组展开**：把数组元素展开成独立参数或元素。
- **对象展开**：把对象属性展开（浅拷贝、合并）。

```js
// 数组展开
const arr = [1, 2, 3];
console.log(Math.max(...arr));     // 3（展开成参数）
const arr2 = [...arr, 4, 5];       // [1, 2, 3, 4, 5]
const copy = [...arr];             // 浅拷贝

// 对象展开
const obj = { a: 1 };
const merged = { ...obj, b: 2 };   // { a: 1, b: 2 }
const objCopy = { ...obj };        // 浅拷贝
```

> 展开语法 `...` 是**最常用的 ES6 特性之一**：替代 `apply` 传参、数组/对象合并与浅拷贝、类数组转数组。它与"剩余参数"是同一个符号的两种用法——**展开**是"拆开"，**剩余**是"收集"。



### Symbol

#### Symbol 的使用

**`Symbol`**：是 ES6 引入的**原始类型**，表示**独一无二**的值，用作对象的属性键可避免冲突。

```js
const sym1 = Symbol("desc");
const sym2 = Symbol("desc");

console.log(sym1 === sym2); // false（即使描述相同，Symbol 也唯一）

// 用作对象属性键
const obj = {
  [sym1]: "value"
};
console.log(obj[sym1]); // "value"

// Symbol 属性不出现在普通遍历中
console.log(Object.keys(obj)); // []（Symbol 键被隐藏）
```

> `Symbol` 的核心特性是**唯一性**：每个 `Symbol()` 都是独一无二的，即使描述相同。用作属性键时**不会被普通遍历枚举**，适合做"半私有"属性、避免命名冲突。



### 新增数据结构

#### Set

##### Set 的基本使用

**`Set`**：是 ES6 引入的**集合**数据结构，存储**唯一值**（自动去重）。

```js
const set = new Set([1, 2, 2, 3, 3]);
console.log(set);          // Set { 1, 2, 3 }（自动去重）
console.log(set.size);     // 3

// 数组去重
const arr = [1, 2, 2, 3];
const unique = [...new Set(arr)];
console.log(unique); // [1, 2, 3]
```

> `Set` 用 `===`（加 `NaN` 特判）判断相等，**自动去重**。它最常用的场景就是**数组去重**：`[...new Set(arr)]`。



##### Set 的常见方法

`Set` 的增删查方法。

- **`add(value)`**：添加。
- **`delete(value)`**：删除。
- **`has(value)`**：判断是否存在。
- **`clear()`**：清空。

```js
const set = new Set();
set.add(1);
set.add(2);
console.log(set.has(1));  // true
set.delete(1);
console.log(set.size);    // 1
set.clear();
console.log(set.size);    // 0
```

> `Set` 的方法语义清晰：`add` 加、`delete` 删、`has` 查、`clear` 清空。它与数组的区别是**无索引、元素唯一**，适合"去重、成员判断"场景。



#### WeakSet

##### WeakSet 的基本使用

**`WeakSet`**：是 `Set` 的"弱引用"版本，**只能存对象**，且不阻止垃圾回收。

```js
const weakSet = new WeakSet();
const obj = { a: 1 };

weakSet.add(obj);
console.log(weakSet.has(obj)); // true
// weakSet.add(1); // 报错：只能存对象
```

> `WeakSet` 与 `Set` 的区别：**只能存对象**、**弱引用**（对象可被回收）、**不可遍历**、**无 `size`/`clear`**。它不阻止 GC，适合"标记对象"而不影响其回收。



##### WeakSet 的应用场景

`WeakSet` 的典型应用是**标记对象**，且不造成内存泄漏。

```js
// 记录已处理过的对象，避免重复处理
const processed = new WeakSet();

function process(obj) {
  if (processed.has(obj)) {
    console.log("已处理过，跳过");
    return;
  }
  processed.add(obj);
  console.log("处理中");
}

const data = { name: "why" };
process(data); // 处理中
process(data); // 已处理过，跳过
```

> `WeakSet` 适合"**给对象打标记**"：标记存对象（弱引用），对象被回收时标记自动消失，不占内存。相比用 `Set` 存对象（强引用、阻止回收），`WeakSet` 更安全。



#### Map

##### Map 的基本使用

**`Map`**：是 ES6 引入的**键值对**结构，与对象的区别是**键可以是任意类型**（含对象、函数）。

```js
const map = new Map();

// 键可以是任意类型
map.set("name", "why");
map.set(1, "数字键");
map.set({ id: 1 }, "对象键");

console.log(map.get("name")); // "why"
console.log(map.get(1));      // "数字键"
console.log(map.size);        // 3
```

> `Map` 相比普通对象：**键可为任意类型**（对象键只有 `Map` 能做）、**保持插入顺序**、**有 `size`**、**更适合频繁增删**。需要"对象作键"或"有序键值"时用 `Map`。



##### Map 的常见方法

`Map` 的增删查方法。

- **`set(key, value)`**：设置。
- **`get(key)`**：获取。
- **`has(key)`**：判断。
- **`delete(key)`**：删除。
- **`clear()`**：清空。

```js
const map = new Map();
map.set("a", 1);
map.set("b", 2);

console.log(map.get("a"));  // 1
console.log(map.has("b"));  // true
map.delete("a");
console.log(map.size);      // 1
```

> `Map` 的方法与 `Set` 对称，多一个 `get`。`set` 返回 `Map` 本身，因此可**链式调用**：`map.set("a", 1).set("b", 2)`。



#### WeakMap

##### WeakMap 的基本使用

**`WeakMap`**：是 `Map` 的弱引用版本，**键只能是对象**，不阻止垃圾回收。

```js
const weakMap = new WeakMap();
const key = { id: 1 };

weakMap.set(key, "value");
console.log(weakMap.get(key)); // "value"
// weakMap.set("str", 1); // 报错：键只能是对象
```

> `WeakMap` 与 `Map` 的区别：**键只能是对象**、**弱引用**、**不可遍历**、**无 `size`**。它的键被回收时，对应的值也自动消失。



##### WeakMap 的应用场景

`WeakMap` 常用于**给对象关联私有数据**，且不阻止回收。

```js
// 给 DOM 元素关联数据，元素移除后自动释放
const elementData = new WeakMap();

function bindData(element, data) {
  elementData.set(element, data);
}
function getData(element) {
  return elementData.get(element);
}

const el = document.querySelector("div");
bindData(el, { name: "关联数据" });
console.log(getData(el).name); // "关联数据"
```

> `WeakMap` 的典型应用：**为对象/ DOM 元素关联额外数据**，用对象作键、弱引用，对象被销毁时关联数据自动回收，避免内存泄漏。它也是 Vue3 响应式等框架内部使用的数据结构。



### 数值的表示

#### 八进制与二进制

ES6 允许用**前缀**表示不同进制的数字。

- **`0b`**：二进制。
- **`0o`**：八进制。
- **`0x`**：十六进制。

```js
console.log(0b1010); // 10（二进制）
console.log(0o17);   // 15（八进制）
console.log(0xff);   // 255（十六进制）
```

> ES5 的八进制用 `0` 前缀（如 `017`）易混淆且严格模式禁用，ES6 改用明确的 `0o`/`0b` 前缀，语义更清晰。



#### 数值连接符

**数值分隔符 `_`**：在数字中加下划线**分隔**，提升可读性（不影响数值）。

```js
const million = 1_000_000;
const binary = 0b1010_0001;
console.log(million); // 1000000
console.log(binary);  // 161
```

> 数值分隔符 `_` 纯粹是**可读性**辅助（如 `1_000_000` 一眼看出是 100 万），不影响实际数值。它让大数字、二进制/十六进制更易读。



#### Number 与 Math 的新增方法

ES6 为 `Number` 和 `Math` 新增了一批方法。

- **`Number.isFinite()`** / **`Number.isNaN()`**：严格判断（不转换）。
- **`Number.isInteger()`**：判断整数。
- **`Math.trunc()`**：去掉小数部分。
- **`Math.sign()`**：判断正负。

```js
console.log(Number.isInteger(3));    // true
console.log(Number.isInteger(3.5));  // false
console.log(Number.isNaN(NaN));      // true
console.log(Number.isNaN("abc"));    // false（不转换）

console.log(Math.trunc(3.9));  // 3
console.log(Math.sign(-5));    // -1
console.log(Math.sign(5));     // 1
```

> 这些方法的共同点是**更严格、更规范**：`Number.isNaN` 不像全局 `isNaN` 那样先转换，`Math.trunc` 提供了"去小数"的明确操作。它们让数值处理更可靠。
