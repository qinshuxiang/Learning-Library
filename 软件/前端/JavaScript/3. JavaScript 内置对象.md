## JavaScript 内置对象

### String

#### 字符串的定义

字符串可用三种引号定义：单引号、双引号、反引号（模板字符串）。

- 单引号和双引号定义的字符串**没有本质区别**，但必须配对使用。
- 单引号内不能出现单引号，可以出现双引号；双引号内不能出现双引号，可以出现单引号。
- 单引号和双引号定义的字符串必须在一行内完成，不能换行。
- 反引号（模板字符串）可以跨行，并利用 `${}` 解析变量或表达式：

```js
let name = "ximingx";
let str = `这是一个可以解析变量的字符串：${name}`;
console.log(str); // 这是一个可以解析变量的字符串：ximingx
```



#### 转义符

有些特殊字符不能直接出现在字符串中（如换行符、引号），需要用反斜杠 `\` 转义。常见的转义符有 `\n`（换行）、`\"`（双引号）、`\'`（单引号）等。

```js
let str1 = '这是一个换行的\n字符串';
let str2 = '这是一个换行的\' 字符串';
```



#### 字符串的特性

- 字符串可以看成由字符组成的**字符数组**，拥有 `length` 属性，可以通过 `for...of` 遍历。
- 字符串具有**不可变性**：字符串的值不能被改变，所有「修改」操作其实都是返回新字符串。



#### String 对象的常用方法

##### charAt 与 charCodeAt

`charAt(index)` 返回指定位置的字符，索引越界时返回空字符串；`charCodeAt(index)` 返回指定位置字符的 Unicode 编码。

```js
let str = "str1";
console.log(str.charAt(1)); // t
console.log(str.charCodeAt(0)); // 115（'s' 的编码）
```



##### String.fromCharCode

`String.fromCharCode(编码)` 把 Unicode 编码还原为字符，是 `charCodeAt` 的逆操作。

```js
console.log(String.fromCharCode(97)); // a
```



##### 字符串比较与 localeCompare

字符串比较时，会按字符的 Unicode 码位**逐位**比较，从第一个字符开始，直到分出大小或到达末尾。因此比较「数字字符串」的大小时，一定要先转为 number 再比较。

`localeCompare(target)` 返回正数、负数或 0，分别表示当前字符串大于、小于、等于目标字符串。

```js
console.log("abc".localeCompare("abd")); // -1
```



##### 截取：slice、substring、substr

三者都用于截取字符串，参数含义不同：

- `slice(start, end)`：截取 `[start, end)` 区间，支持负数（从末尾算起）。
- `substring(start, end)`：截取 `[start, end)` 区间，不支持负数，且会自动交换参数使 start 不大于 end。
- `substr(start, length)`：从 start 开始截取 length 个字符，第二个参数是**长度**。

```js
let str = "123456789";
console.log(str.slice(1, 3)); // 23
console.log(str.slice(-2)); // 89
console.log(str.substring(3, 1)); // 23（参数被自动交换）
console.log(str.substr(1, 2)); // 23
```

> `substr` 已被标准标记为**废弃**（legacy），新代码推荐使用 `slice` 或 `substring`。



##### 查找：indexOf、lastIndexOf、includes、startsWith、endsWith

- `indexOf(search, position)`：从前往后查找，返回第一次出现的索引，找不到返回 -1。
- `lastIndexOf(search, position)`：从后往前查找。
- `includes(search)`：返回布尔值，表示是否包含参数字符串。
- `startsWith(search)`、`endsWith(search)`：判断是否以指定内容开头、结尾。
- 上述三个方法（includes、startsWith、endsWith）都支持第二个参数，表示开始搜索的位置。



##### 替换与分割：replace、split

- `replace(被替换内容, 新内容)`：只替换**第一个**匹配项；要替换全部需用带 `g` 标志的正则。
- `split(分隔符, 次数)`：按分隔符把字符串分割为数组，第二个参数限制分割次数。

```js
let str = "终古，终古人民";
console.log(str.replace("终古", "中国")); // 中国，终古人民
console.log(str.replace(/终古/g, "中国")); // 中国，中国人民
console.log("a-b-c".split("-")); // ['a', 'b', 'c']
```



##### 补全与去空格：padStart、padEnd、trim

- `padStart(len, str)`、`padEnd(len, str)`：在头部或尾部补全到指定长度，常用于给数值补零。
- `trimStart()`、`trimEnd()`、`trim()`：去除头部、尾部或两端的空格，返回新字符串。



##### 大小写转换：toLowerCase、toUpperCase

`toLowerCase()` 转为小写，`toUpperCase()` 转为大写，均返回新字符串。



##### 正则相关：search、match

- `search(正则)`：检索匹配内容，返回第一次出现的索引，找不到返回 -1，且大小写敏感。
- `match(正则)`：提取匹配内容；不带 `g` 只返回第一个，带 `g` 返回所有匹配组成的数组。



### Array

#### 数组简介

数组属于**内置对象**，用数字索引操作元素（从 0 开始），元素可以是任意数据类型。与普通对象相比，数组的存储性能更好，常用于存储列表数据。元素若也是数组，则称为二维数组（可类推多维数组）。



#### 创建数组

**字面量方式**：

```js
let arr1 = [];
let arr2 = [1, 2, 3];
```

**构造函数方式**：

```js
let arr3 = new Array();
let arr4 = new Array(4); // 参数为一个数值时，表示数组长度
let arr5 = new Array(1, 2, 3); // 多个参数表示元素
```

> `new Array(4)` 与 `[4]` 不同：前者创建长度为 4 的空数组，后者创建含一个元素 4 的数组。

**Array.of 与 Array.from**：

- `Array.of(...values)`：总是把传入的所有参数创建为数组元素，不管参数数量与类型。
- `Array.from(arrayLike)`：把可迭代对象或类数组对象（拥有 length 属性的对象）转为真正的数组。

```js
console.log(Array.of(1, 2)); // [1, 2]
console.log(Array.from('foo')); // ['f', 'o', 'o']
```



#### 数组的基本操作

- 通过 `数组[索引]` 访问、设置元素；读取不存在的索引返回 `undefined`。
- 通过 `length` 属性获取或修改长度。
- 修改 `length` 大于原长度时，多出部分成为**空位**（hole，读取为 undefined）；小于原长度时，从末尾删除多余元素。
- 遍历数组可用 for 循环或 `for...of`。



#### 添加与删除元素

- `push(...items)`：向末尾添加一个或多个元素，返回新长度，会改变原数组。
- `pop()`：删除并返回最后一个元素，会改变原数组。
- `unshift(...items)`：向开头添加元素，返回新长度，会改变原数组。
- `shift()`：删除并返回第一个元素，会改变原数组。
- `splice(index, deleteCount, ...items)`：从 index 起删除 deleteCount 个元素，并可在该位置插入新元素，会改变原数组。
- `slice(start, end)`：提取 `[start, end)` 区间元素，返回新数组，不改变原数组。
- `fill(value, start, end)`：用固定值填充 `[start, end)` 区间，会改变原数组。

```js
let arr = [1, 2, 3];
console.log(arr.push(4)); // 4（新长度）
console.log(arr.splice(1, 1)); // [2]（被删除的元素）
console.log(arr); // [1, 3, 4]
console.log(arr.slice(0, 2)); // [1, 3]
```



#### 合并与转换

- `concat(...arrays)`：连接多个数组，返回新数组，不改变原数组。
- `join(分隔符)`：把数组元素拼接为字符串，默认用逗号分隔。
- `toString()`：把数组转为字符串。
- 合并数组也可用扩展运算符 `...`：`[...arr1, ...arr2]`。



#### 排序与反转

- `sort(compareFn)`：对数组排序，默认按 Unicode 编码从小到大排序，会改变原数组。
- `reverse()`：反转数组，会改变原数组。

> `sort()` 默认把元素转为字符串比较，所以对数字排序会出错（如 `[10, 2, 30]` 排成 `[10, 2, 30]`）。对数字排序必须传比较函数：升序 `(a, b) => a - b`，降序 `(a, b) => b - a`。

```js
let arr = [20, 4, 22];
console.log(arr.sort((a, b) => a - b)); // [4, 20, 22]
```



#### 查找元素

- `indexOf(value)`、`lastIndexOf(value)`：查找元素，返回索引，找不到返回 -1。
- `includes(value)`：判断是否包含，返回布尔值。
- `find(fn)`：返回**第一个**满足条件的元素，找不到返回 undefined。
- `findIndex(fn)`：返回第一个满足条件的元素的索引，找不到返回 -1。



#### 遍历与迭代

- `forEach(fn)`：对每个元素执行回调，无返回值，不能用 break 提前终止。
- `map(fn)`：对每个元素加工，返回新数组。
- `filter(fn)`：过滤出满足条件的元素，返回新数组。
- `some(fn)`：只要有一个满足就返回 true。
- `every(fn)`：全部满足才返回 true。
- `reduce(fn, initial)`：把数组归约为单个值，常用于求和、求最大值、统计次数、去重。

```js
let arr = [1, 2, 3, 4];
console.log(arr.map((x) => x * 2)); // [2, 4, 6, 8]
console.log(arr.filter((x) => x > 2)); // [3, 4]
console.log(arr.reduce((pre, cur) => pre + cur, 0)); // 10
```



#### 其他方法

- `Array.isArray(value)`：判断是否为数组，返回布尔值。
- `keys()`、`values()`、`entries()`：分别返回键名、键值、键值对的遍历器对象，可用 `for...of` 遍历。
- `copyWithin(target, start, end)`：把 `[start, end)` 区间的元素复制到 target 位置，会改变原数组。



### Number

#### parseInt 与 parseFloat

`parseInt()`、`parseFloat()` 会把传入的数据先当作**字符串**处理；若传入的不是字符串，会先转为字符串再解析。它们的几个特性：

- 只保留字符串**最开头**的数字部分，后面的内容自动忽略。
- 自动截断小数（取整，不四舍五入）。
- 若字符串不是以数字开头，则返回 `NaN`。
- `parseInt` 的第二个参数表示**进制**，会把该字符串按指定进制解析，最终转换为十进制。

```js
console.log(parseInt('2017在公众号上写了6篇文章')); // 2017
console.log(parseInt('5', 2)); // NaN（二进制中没有 5）
```

> `Number(true)` 与 `parseInt(true)` 的区别：`Number` 会千方百计转成数字，转不了就返回 NaN；`parseInt` 只提取最前面的数字部分，提取不到就返回 NaN。



#### NaN

`NaN`（Not a Number）表示「非数值」，类型仍是 `number`。任何与 `NaN` 的运算结果都是 `NaN`，且 `NaN === NaN` 为 `false`（判断需用 `Number.isNaN()`）。

```js
let a = 'abc';
a++;
console.log(typeof a); // number
console.log(a); // NaN
```



### Boolean

#### 其他类型转布尔

其他数据类型都可以转换为 Boolean，且隐式转换与显式转换的结果一致：

- 数字转布尔：`0` 和 `NaN` 为 `false`，其余为 `true`。
- 字符串转布尔：空串为 `false`，其余（包括 `'0'` 和全是空格的串）为 `true`。
- `null` 和 `undefined` 都转为 `false`。
- **引用数据类型都转为 `true`**，包括空数组 `[]` 和空对象 `{}`。



### Object

#### 对象的基本操作

使用 `new` 关键字调用的函数是**构造函数**，专门用来创建对象。用 `typeof` 检查对象会返回 `object`。

**创建对象与添加属性**：

```js
let obj = new Object();
obj.name = '孙悟空';
obj.age = 18;
```

**获取属性**：使用 `对象.属性名`；若属性不存在，返回 `undefined`（不报错）。

**使用方括号操作属性**：当属性名不符合标识符规范（如 `123`）时，不能用 `.` 操作，需用 `obj['属性名']`；方括号内还可直接传**变量**，更灵活。

**修改与删除属性**：

```js
obj.name = 'tom'; // 修改
delete obj.name; // 删除
```

**in 运算符**：检查对象是否含有某属性，返回布尔值。

```js
console.log('name' in obj); // true
```



#### Object.freeze 冻结对象

`Object.freeze(obj)` 冻结对象，冻结后不能添加、删除、修改属性，也不能修改已有属性的描述符与原型。

```js
const params = { name: 'ximingx' };
Object.freeze(params);
params.name = 'other'; // 修改无效（严格模式下会报错）
```



#### 遍历对象

**for...in 遍历属性名**：

```js
for (let key in obj) {
  console.log(key, obj[key]);
}
```

`for...in` 主要用于遍历对象，不建议遍历数组（会遍历到原型链上的可枚举属性，且不保证顺序）。

**for...of 遍历数组**：获取的是数组的**值**（`for...in` 遍历数组获取的是索引），且避免额外开辟内存，推荐用 `for...of` 遍历数组。



#### 浅拷贝与深拷贝

- **浅拷贝**：只拷贝最外层数据；更深层的对象只拷贝引用（传址）。
- **深拷贝**：每一层数据都拷贝到新的内存空间（传值）。

**用 Object.assign 实现浅拷贝（推荐）**：

```js
let obj2 = Object.assign({}, obj1);
```

`Object.assign(目标对象, 源对象1, 源对象2, ...)` 把源对象的属性拷贝到目标对象，同名属性会被后面的覆盖。注意它是浅拷贝，第二层对象仍是共享引用。

> `B = A` 只是把引用地址赋过去，两者仍是同一个对象；复制对象应使用 `Object.assign({}, A)`。

**深拷贝的实现**：将浅拷贝**递归**即可。一种简单方式是用 JSON 转换：

```js
let obj2 = JSON.parse(JSON.stringify(obj1));
```

> JSON 方式的局限：会丢失函数、`undefined`、`Symbol` 类型的属性；`Date` 会转为字符串，`NaN`、`Infinity` 会变成 `null`，循环引用会报错。有这些需求时应使用递归深拷贝或 `structuredClone()`。



### Function

#### 函数的概念

函数就是把一些语句**封装**起来，在需要时通过**调用**执行。函数也是一个**对象**，用 `typeof` 检查函数会返回 `function`。函数的作用是避免重复劳动，实现高内聚、低耦合的模块化编程。



#### 函数的定义方式

##### 方式一：函数声明（命名函数）

```js
function fun1(a, b) {
  return a + b;
}
```

使用 `function` 关键字定义，会被**声明提前**（可在定义前调用）。



##### 方式二：函数表达式（匿名函数）

```js
let fun2 = function (a, b) {
  return a + b;
};
```

本质是把匿名函数赋值给变量，不会被声明提前。



##### 方式三：new Function 构造函数

```js
let fun3 = new Function('a', 'b', 'return a + b');
```

参数必须都是**字符串**，最后一个字符串是函数体。这种方式很少用：书写啰嗦，且需先把字符串转为代码再执行，效率低。

> 所有的函数本质上都是 `Function` 的实例，函数也属于对象（有 `__proto__`，且 `fun instanceof Object` 为 true）。



#### 函数的调用方式

- **普通函数调用**：`fn()`。
- **对象方法调用**：`obj.fn()`，此时函数是该对象的方法。
- **立即执行函数（IIFE）**：`(function(){ ... })()`，定义后立即调用，只执行一次。
- **构造函数调用**：`new Fn()`。
- **事件绑定函数**：`btn.onclick = function(){ ... }`。
- **定时器函数**：`setInterval(function(){ ... }, 1000)`。



#### 函数的参数

##### 形参与实参

**形参**是定义函数时声明的参数，**实参**是调用时传入的参数。JS 中解析器**不检查**实参的类型与数量：

- 实参多于形参时，多余的实参被忽略（但可用 `arguments` 拿到）。
- 实参少于形参时，缺少的形参为 `undefined`。
- 形参的默认值是 `undefined`。



##### 参数默认值（ES6）

```js
function fn(param = 'hello') {
  console.log(param);
}
```

调用时不给参数就用默认值，给了就用新值。默认值参数之后不能再有**没有默认值**的参数。



##### 剩余参数（rest）

剩余参数用 `...args` 把不确定数量的剩余实参收集到数组中：

```js
function sum(...args) {
  return args.reduce((pre, cur) => pre + cur, 0);
}
console.log(sum(1, 2, 3)); // 6
```

剩余参数必须是最后一个参数，之后不能再有别的参数。



##### arguments 类数组

调用函数时，浏览器会传入两个隐含参数：`this` 和 `arguments`。`arguments` 是**类数组对象**，保存了所有实参，具有 `length` 属性，可用索引访问，但没有 `push`、`pop` 等方法，且**只在函数内可用**。

- `arguments.length` 获取实参个数；`函数名.length` 获取形参个数。
- `arguments.callee` 指向当前正在执行的函数，递归时推荐用它代替函数名。
- arguments 可以修改元素，但不能改变长度。



#### 函数的返回值

`return` 结束函数并把值作为执行结果返回：

- `return` 后的语句不会执行。
- `return` 不跟值时，返回 `undefined`。
- 函数不写 `return`，也返回 `undefined`。
- 返回值可以是任意类型（含对象、函数）。



#### 函数名与函数体

**函数名 == 整个函数**：`fn`（不加括号）表示函数对象本身，`fn()`（加括号）才是调用并得到返回值。



#### break、continue、return

- `break`：结束当前循环体。
- `continue`：跳出本次循环，继续下一次。
- `return`：结束函数并返回值。



#### 原型与原型链

##### 原型对象 prototype

每个函数在创建时，解析器都会给它添加一个 `prototype` 属性，对应一个对象，称为**原型对象**。原型对象是公共区域，同一构造函数创建的所有实例都能访问它，因此可以把实例共有的属性和方法统一放到原型对象上。

```js
function Person(name) {
  this.name = name;
}
Person.prototype.sayName = function () {
  console.log(this.name);
};
```

实例通过 `__proto__`（隐式原型）访问原型对象，`实例.__proto__ === 构造函数.prototype`。



##### 原型链

访问对象的属性或方法时，查找顺序是：先在自己身上找，找不到再去原型对象找，再找不到就去原型的原型找，直到 `Object.prototype`，最后找不到则返回 `null`。

> 用 `in` 检查属性时，原型中的属性也会返回 true；`hasOwnProperty()` 只检查对象自身。



##### 原型三角关系

这是理解原型必须记住的三条等式：

```js
function Person(name) {
  this.name = name;
}
const p = new Person('ximingx');

console.log(p.__proto__ === Person.prototype); // ① 实例隐式原型 === 构造函数显式原型
console.log(Person.prototype.constructor === Person); // ② 原型的 constructor 指回构造函数
console.log(p.constructor === Person); // ③ 实例自身没有 constructor，沿原型链读到
```

> `constructor` 可被改写。若用 `Person.prototype = { ... }` 整体覆盖原型对象，`constructor` 会丢失（变成指向 Object），必须手动补回。



##### 原型链的终点

```js
function Foo() {}
const f = new Foo();
console.log(f.__proto__ === Foo.prototype); // true
console.log(Foo.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__); // null（原型链终点）
```

完整的查找路径是 `f → Foo.prototype → Object.prototype → null`。此外，所有函数都是 `Function` 的实例，`Function` 自己也是自己的实例。



#### 构造函数与面向对象

##### 构造函数

**构造函数**是一种特殊函数，用来创建和初始化对象，必须与 `new` 一起使用才有意义。它和普通函数在创建方式上没有区别，只是习惯上**首字母大写**，且调用方式不同（需用 `new`）。

`new` 一个构造函数的执行流程：

1. 开辟内存空间，创建新的空对象。
2. 让 `this` 指向这个新对象。
3. 执行构造函数体，为新对象添加属性和方法。
4. 返回这个新对象（因此构造函数里不需要写 `return`）。



##### 静态成员与实例成员

- **静态成员**：在构造函数本身上添加的成员，只能由构造函数本身访问。
- **实例成员**：在构造函数内部 `this` 上添加的成员，只能由实例对象访问。



##### instanceof

`对象 instanceof 构造函数` 检查对象是否为某类的实例，返回布尔值。所有对象都是 `Object` 的后代，所以 `任何对象 instanceof Object` 都为 true。



##### 面向过程与面向对象

- **面向过程**：分析步骤，按步骤解决问题；性能较高，适合与硬件联系紧密的场景。
- **面向对象**：以对象功能划分问题，具有封装、继承、多态三大特性；易维护、易复用、易扩展，适合大型软件项目，但性能略低。

JS 的面向对象是基于**原型**的面向对象，ES6 引入的 `class` 和 `extends` 是其语法糖。



#### 继承的演进

JS 没有真正的类继承，`class` 只是语法糖，可用原型模拟继承。由浅入深有六种方案：

##### 方式一：原型链继承

把子类的原型替换成父类的实例。

```js
Child.prototype = new Parent();
Child.prototype.constructor = Child; // 补回 constructor
```

两个致命缺点：引用类型属性被所有实例**共享**；创建子类实例时**无法向父类传参**。



##### 方式二：借用构造函数继承

在子类构造函数内部用 `call`/`apply` 调用父类构造函数。

```js
function Child(name, age) {
  Parent.call(this, name);
  this.age = age;
}
```

解决了共享与传参问题，但**继承不到父类原型上的方法**。



##### 方式三：组合继承

原型链继承（拿方法）+ 借用构造函数继承（拿属性），两者结合。缺点是**父类构造函数被调用了两次**。



##### 方式四：原型式继承与 Object.create

不定义构造函数，直接基于已有对象创建新对象：

```js
const child = Object.create(parent); // child.__proto__ === parent
```

`Object.create(null)` 创建的是无原型对象。这种方式同样存在引用类型共享的问题。



##### 方式五：寄生组合式继承（最优）

用 `Object.create()` 代替 `new Parent()` 建立原型链，避免父类构造函数被调用两次：

```js
Child.prototype = Object.create(Parent.prototype);
Child.prototype.constructor = Child;
```

这是最优方案，也是 ES6 `class` 的底层实现原理。



##### 方式六：ES6 class 与 extends

```js
class Child extends Parent {
  constructor(name, age) {
    super(name); // 必须先调用 super 才能使用 this
    this.age = age;
  }
}
```

class 与普通构造函数的重要区别：

- class 不存在变量提升，有暂时性死区。
- 必须用 `new` 调用，直接调用会报错。
- class 内部默认是严格模式。
- class 的方法不可枚举。
- class 的所有方法都没有 `prototype` 属性。
- 子类必须在 `constructor` 里先调用 `super()` 才能使用 `this`。



#### this 的指向

##### 函数内 this 的指向

根据调用方式的不同，`this` 指向不同对象：

- 以**函数形式**调用（普通函数、定时器、立即执行函数）时，非严格模式下 `this` 是 `window`。
- 以**方法形式**调用时，`this` 是调用方法的那个对象。
- 以**构造函数形式**调用时，`this` 是实例对象。
- 以**事件绑定函数**调用时，`this` 是绑定事件的对象。
- 使用 `call`/`apply`/`bind` 调用时，`this` 是指定的对象。

> 严格模式下的例外：若开启 `"use strict"`，独立函数调用时 `this` 是 `undefined`（不再是 window）。定时器回调在浏览器中恒为 `window`。



##### 箭头函数中 this 的指向

箭头函数**不会**遵循上面的规则，而是**继承外层作用域的 `this`**（在定义时就确定），且 `call`/`apply`/`bind` 无法改变它。



#### 改变 this 指向：call、apply、bind

##### call 方法

`call` 可以**调用**函数，同时改变函数内部的 `this` 指向：

```js
fn.call(thisArg, 实参1, 实参2);
```

第一个参数指定 `this` 指向，不需要改变时传 `null`。`call` 还能实现继承：在子类构造函数中 `Parent.call(this, ...)` 继承父类属性。

> 注意：`Parent.call(this, name)` 里等号左边是 `this.name`（决定属性名），等号右边才是形参名。



##### apply 方法

`apply` 与 `call` 作用相同，唯一区别是 `apply` 的实参必须**以数组（或类数组）形式**传入：

```js
fn.apply(thisArg, [实参1, 实参2]);
```

巧妙应用：借助 `Math.max.apply(null, arr)` 求数组最大值。



##### bind 方法

`bind` **不会调用**函数，但会改变函数内部的 `this` 指向，并返回一个新函数：

```js
const newFn = fn.bind(thisArg, 实参1, 实参2);
```

适合需要改变 `this` 但又不想立即调用的场景，实际开发中使用最频繁。



#### 闭包的引入

变量根据作用域分为全局变量和局部变量：函数外部无法访问函数内部的局部变量。若想在函数外部访问函数内部的局部变量，就需要用到闭包。

**闭包**：指有权访问另一个函数作用域中变量的**函数**。当一个函数可以访问另一个函数内部的局部变量时，就产生了闭包，那个外部函数称为闭包函数。

```js
function fn1() {
  let a = 20;
  return function () {
    console.log(a);
  };
}
const foo = fn1();
foo(); // 20
```

闭包的主要作用是**延伸变量的作用范围**：由于内层函数仍引用外层变量，外层函数的局部变量不会立即销毁，直到不再被引用才会被回收。



### Math

Math 是内置对象，提供数学计算相关的常量与方法。**Math 不是构造函数，不需要实例化**，直接通过 `Math.方法名()` 调用。

**常用常量**：

- `Math.PI`：圆周率 π。
- `Math.E`：自然对数的底数 e。

**取整相关**：

- `Math.ceil(x)`：向上取整。
- `Math.floor(x)`：向下取整。
- `Math.round(x)`：四舍五入。
- `Math.trunc(x)`：直接截断小数部分（ES6 新增）。

**最值**：

- `Math.max(a, b, ...)`：取最大值。
- `Math.min(a, b, ...)`：取最小值。

**幂、开方与绝对值**：

- `Math.pow(x, y)`：x 的 y 次幂。
- `Math.sqrt(x)`：平方根。
- `Math.abs(x)`：绝对值。

**随机数**：

`Math.random()` 返回 `[0, 1)` 之间的随机小数。生成 `[min, max]` 之间的随机整数：

```js
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

> 其他方法：`Math.sin()`、`Math.cos()`、`Math.tan()`（三角函数）、`Math.log()`（自然对数）、`Math.sign(x)`（符号：-1 / 0 / 1）、`Math.hypot()`（平方和的平方根）等。



### Date

Date 用于处理日期和时间。与 Math 不同，Date 是**构造函数**，需先 `new` 实例化才能使用。

#### 创建 Date 对象

- 不传参数时，返回系统当前时间对象。
- 传参时，返回指定时间对象，参数可以是字符串、多个数字或时间戳。

```js
const d1 = new Date();
const d2 = new Date('2020/02/17 21:00:00');
const d3 = new Date(2020, 2, 18); // 注意：月份从 0 开始，2 表示三月
const d4 = new Date(1591950413388); // 时间戳
```

> 用数字传参时，月份从 0 开始（0 表示一月），而日期从 1 开始。



#### 获取日期时间的方法

- `getFullYear()`：获取年份（4 位）。
- `getMonth()`：获取月份（0-11）。
- `getDate()`：获取日（1-31）。
- `getDay()`：获取星期（0-6，0 表示周日）。
- `getHours()`、`getMinutes()`、`getSeconds()`、`getMilliseconds()`：时分秒毫秒。
- `getTime()`：获取时间戳。



#### 设置日期时间的方法

`setFullYear()`、`setMonth()`、`setDate()`、`setHours()`、`setMinutes()`、`setSeconds()`、`setTime()` 等，都会直接修改原 Date 对象。

> `getYear()` / `setYear()` 已废弃，请用 `getFullYear()` / `setFullYear()`。



#### 时间戳

**时间戳**是从格林威治时间 `1970 年 1 月 1 日 0 时 0 分 0 秒` 到当前时刻所经过的**毫秒数**。计算机底层用时间戳统一时间的单位。获取时间戳的常用方式：

- `+new Date()` 或 `new Date().getTime()`（最常用）。
- `new Date().valueOf()`、`new Date() * 1`、`Number(new Date())`。
- `Date.now()` 直接获取当前时间戳。



### Set

Set 是 ES6 提供的数据结构，类似数组，但成员的值都是**唯一**的，可用于去重。Set 是构造函数，通过 `new Set()` 生成实例，可接收一个数组作为参数。

```js
const set = new Set([1, 2, 2, 3]);
console.log([...set]); // [1, 2, 3]
```

常用方法与属性：

- `add(item)`：添加元素。
- `delete(item)`：删除元素。
- `has(item)`：判断是否存在，返回布尔值。
- `clear()`：清空。
- `size`：获取元素个数。



### JSON

JSON 常用于本地存储或前后端数据交换，常用两个方法（ES5 提供）：

- `JSON.stringify(obj)`：把 JS 对象（数组）转为 JSON 字符串。
- `JSON.parse(json)`：把 JSON 字符串解析为 JS 对象（数组）。

我们通常说的「JSON 字符串」只有两种：JSON 对象、JSON 数组。`typeof json字符串` 的结果是 `string`。



### Null 与 Undefined

#### null：空对象

`null` 专门用来定义一个**空对象**。若想定义一个变量保存引用类型，但还没想好内容，可先初始化为 `null`。`null` 虽然是一个单独的数据类型，但相当于「地址为空的对象」。Null 类型的值只有一个，用 `typeof` 检查 `null` 会返回 `object`。



#### undefined：未定义类型

Undefined 类型的值只有一个，用 `typeof` 检查会返回 `undefined`。以下情况会得到 `undefined`：

- 变量已声明但未赋值。
- 变量未声明（未定义）时，`typeof` 检查返回 `undefined`（直接使用则报 ReferenceError）。
- 函数没有返回值时。
- 调用函数时未传参，对应形参为 `undefined`。



#### null 与 undefined 的区别

`null == undefined` 为 `true`，但 `null === undefined` 为 `false`。与数字运算时：

- `10 + null` 结果为 `10`（null 被看作 0）。
- `10 + undefined` 结果为 `NaN`（只要有 undefined 参与就是 NaN）。

> 上述规律只适用于**数值运算**；若是字符串拼接（`+` 且一方是字符串），则不适用，如 `'a' + null` 得到 `'anull'`。
