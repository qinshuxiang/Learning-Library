## 包装类型与常用内置对象

### 包装类型

#### 原始类型的属性和方法

**包装类型（Wrapper）**：是 JavaScript 为让**原始类型也能调用方法**而设计的机制。当访问 `number`、`string`、`boolean` 原始值的方法或属性时，引擎会**临时**创建一个对应的包装对象，调用完成后再销毁。

- `string` 对应 `String` 包装对象。
- `number` 对应 `Number` 包装对象。
- `boolean` 对应 `Boolean` 包装对象。

```js
const str = "hello";
console.log(str.length);        // 5（原始值能访问属性）
console.log(str.toUpperCase()); // "HELLO"（原始值能调用方法）

// 等价于引擎临时做了：
// const temp = new String("hello");
// console.log(temp.length);
// temp 立即被销毁
```

> 为什么原始值能调用方法？因为引擎在背后**临时装箱（boxing）**：访问属性时，把原始值包装成对象，用完即弃。这也是为什么原始值看起来"有方法"，但严格来说它们本身不是对象。



### Number

#### Number 的常见属性和方法

`Number` 既是**包装类型**，也提供了一批**静态属性**与**实例方法**用于数值处理。

常用静态属性与方法：

- **`Number.MAX_VALUE`** / **`Number.MIN_VALUE`**：最大/最小正数。
- **`Number.MAX_SAFE_INTEGER`** / **`Number.MIN_SAFE_INTEGER`**：安全整数边界。
- **`Number.isNaN(value)`**：判断是否为 `NaN`（比全局 `isNaN` 更严格）。
- **`Number.isInteger(value)`**：判断是否为整数。
- **`Number.parseInt()` / `Number.parseFloat()`**：与全局版本相同，但挂在 `Number` 上更规范。

实例方法：

- **`num.toFixed(digits)`**：保留指定位数小数，返回字符串。
- **`num.toString(radix)`**：转字符串，可指定进制。

```js
console.log(Number.isNaN(NaN));        // true
console.log(Number.isNaN("abc"));      // false（不转换，严格判断）
console.log(Number.isInteger(3));      // true
console.log(Number.isInteger(3.5));    // false
console.log(Number.parseInt("10px"));  // 10
console.log((3.14159).toFixed(2));     // "3.14"
console.log((255).toString(16));       // "ff"
```

> `Number.isNaN` 与全局 `isNaN` 的区别是考点：全局 `isNaN("abc")` 会先把 `"abc"` 转成 `NaN` 再判断（返回 `true`），而 `Number.isNaN("abc")` 不做转换、直接判断（返回 `false`）。同理 `Number.isInteger` 也不做类型转换。



### String

#### String 类型的基本补充

`String` 类型的几个基础但重要的特性与属性。

- **`str.length`**：字符串长度（字符个数）。
- **索引访问**：`str[index]` 或 `str.charAt(index)` 取单个字符。
- **不可变性**：字符串一旦创建不能修改，所有方法都返回**新字符串**。

```js
const str = "hello";
console.log(str.length);      // 5
console.log(str[0]);          // "h"
console.log(str.charAt(1));   // "e"

const upper = str.toUpperCase();
console.log(upper);           // "HELLO"
console.log(str);             // "hello"（原字符串不变）
```

> 字符串的**不可变性**是重要特性：`str[0] = "H"` 不会报错但也不生效（严格模式下会报错）。所有"看似修改"的操作（`toUpperCase`、`replace`、`slice`）都返回新字符串，原字符串保持不变。



#### 修改字符串的方法

修改字符串的方法都返回**新字符串**，不改变原字符串，常见的包括大小写转换与去空格。

- **`toUpperCase()`** / **`toLowerCase()`**：转大写/小写。
- **`trim()`** / **`trimStart()`** / **`trimEnd()`**：去除首尾/开头/结尾空格。
- **`repeat(count)`**：重复字符串指定次数。
- **`padStart(len, str)`** / **`padEnd(len, str)`**：在开头/结尾填充至指定长度。

```js
const str = "  Hello World  ";
console.log(str.trim());        // "Hello World"
console.log(str.toUpperCase()); // "  HELLO WORLD  "
console.log("ab".repeat(3));    // "ababab"
console.log("5".padStart(3, "0")); // "005"
console.log("5".padEnd(3, "0"));   // "500"
```

> `padStart` 是处理"补零"（如生成编号 `001`、`002`）的利器，`repeat` 常用于生成占位符或分隔线。这些方法均返回新字符串，需接收返回值才生效。



#### 搜索字符串的方法

搜索字符串的方法用于**查找子串或匹配模式**，返回位置或布尔值。

- **`indexOf(sub, from)`** / **`lastIndexOf(sub)`**：查找子串位置，找不到返回 `-1`。
- **`includes(sub, from)`**：判断是否包含，返回布尔值。
- **`startsWith(sub)`** / **`endsWith(sub)`**：判断开头/结尾。
- **`search(regexp)`**：用正则查找，返回首次匹配位置。

```js
const str = "Hello World";
console.log(str.indexOf("o"));        // 4
console.log(str.lastIndexOf("o"));    // 7
console.log(str.includes("World"));   // true
console.log(str.startsWith("Hello")); // true
console.log(str.endsWith("World"));   // true
console.log(str.search(/o/));         // 4
```

> 判断"是否存在"优先用 `includes`（语义清晰）；需要位置用 `indexOf`（找不到为 `-1`）；判断前后缀用 `startsWith`/`endsWith`。`search` 与 `indexOf` 的区别在于前者接受**正则**。



#### 获取子字符串的方法

获取子字符串的三个方法 `slice`、`substring`、`substr` 易混淆，核心区别在参数语义。

- **`slice(start, end)`**：返回 `[start, end)` 区间，**支持负数**（从末尾数），是推荐用法。
- **`substring(start, end)`**：类似 `slice`，但**不支持负数**，且自动交换大小参数。
- **`substr(start, length)`**：从 `start` 取 `length` 个字符（已不推荐，MDN 标注废弃）。

```js
const str = "Hello World";
console.log(str.slice(0, 5));      // "Hello"
console.log(str.slice(-5));        // "World"（负数从末尾数）
console.log(str.substring(0, 5));  // "Hello"
console.log(str.substring(5, 0));  // "Hello"（自动交换为 (0, 5)）
console.log(str.substr(6, 5));     // "World"（从 6 取 5 个）
```

> 记忆要点：**`slice` 支持负索引、`substring` 不支持负索引但会交换参数、`substr` 第二个参数是长度**。日常推荐只用 `slice`，它行为最一致、最直观。



#### 其他方法补充

String 还有几个常用的补充方法。

- **`split(separator)`**：按分隔符拆成数组，与 `join` 互逆。
- **`replace(search, replacement)`** / **`replaceAll(search, replacement)`**：替换匹配内容。
- **`concat(...str)`**：拼接字符串（模板字符串更常用）。
- **`charCodeAt(index)`**：返回字符的 Unicode 编码。

```js
const str = "apple,banana,orange";
console.log(str.split(","));        // ["apple", "banana", "orange"]

console.log("a-b-c".replace("-", "|"));    // "a|b-c"（只替换第一个）
console.log("a-b-c".replaceAll("-", "|")); // "a|b|c"（替换全部）

console.log("A".charCodeAt(0));     // 65
```

> `split` 与 `join` 是字符串与数组互转的桥梁，处理 CSV、路径等分隔数据时高频使用。`replace` 只替换首个匹配，`replaceAll`（ES2021）才替换全部，若需全局替换旧写法是配合正则的 `g` 标志。



### Math

#### Math 对象的常见属性

**`Math`**：是内置的**数学工具对象**（不是构造函数，不能 `new`），提供一组数学常量，全部为**静态属性**。

- **`Math.PI`**：圆周率 π。
- **`Math.E`**：自然对数的底 e。
- **`Math.LN2`** / **`Math.LN10`**：2 和 10 的自然对数。
- **`Math.SQRT2`**：2 的平方根。

```js
console.log(Math.PI);      // 3.141592653589793
console.log(Math.E);       // 2.718281828459045
console.log(Math.SQRT2);   // 1.4142135623730951
```

> `Math` 的常量都是**只读**的，修改无效。它是典型的"工具类"设计——无需实例化，直接通过 `Math.xxx` 调用，这与 `Number`、`JSON` 等内置对象的设计理念一致。



#### Math 对象的常见方法

`Math` 提供丰富的数学方法，最常用的是取整与随机。

- **取整**：`Math.floor()`（向下）、`Math.ceil()`（向上）、`Math.round()`（四舍五入）、`Math.trunc()`（去掉小数）。
- **极值**：`Math.max(...)`、`Math.min(...)`。
- **幂与根**：`Math.pow(a, b)`、`Math.sqrt()`、`Math.cbrt()`。
- **随机**：`Math.random()` 返回 `[0, 1)` 随机数。
- **绝对值**：`Math.abs()`。

```js
console.log(Math.floor(3.9));  // 3（向下取整）
console.log(Math.ceil(3.1));   // 4（向上取整）
console.log(Math.round(3.5));  // 4（四舍五入）
console.log(Math.trunc(3.9));  // 3（去掉小数部分）

console.log(Math.max(1, 5, 3)); // 5
console.log(Math.min(1, 5, 3)); // 1
console.log(Math.sqrt(16));     // 4
console.log(Math.abs(-5));      // 5
console.log(Math.random());     // [0, 1) 的随机数
```

> 四个取整方法的差异是高频考点：`floor` 向负无穷、`ceil` 向正无穷、`round` 四舍五入（注意 `-3.5` 会得 `-3`）、`trunc` 直接截断。取随机整数常用 `Math.floor(Math.random() * n)`。



### JSON

#### JSON.stringify 的规则与 replacer

**`JSON.stringify(value, replacer?, space?)`**：把 JavaScript 值**序列化**为 JSON 字符串，是数据交换与存储的核心方法。

序列化规则（关键点）：

- 基本类型直接转换；`undefined`、函数、`Symbol` 会被**忽略**（对象中）或转成 `null`（数组中）。
- 对象只序列化**可枚举**的自身属性。
- 日期对象转为 ISO 字符串，`NaN`、`Infinity` 转为 `null`。
- **`replacer`** 参数：可传入函数或数组，用于**过滤/转换**序列化的属性。
- **`space`** 参数：指定缩进，生成**可读的格式化** JSON。

```js
const obj = {
  name: "why",
  age: 18,
  secret: "隐藏",
  fn: function () {}
};

// 基本用法
console.log(JSON.stringify(obj));
// {"name":"why","age":18,"secret":"隐藏"}

// replacer 数组：只保留指定属性
console.log(JSON.stringify(obj, ["name", "age"]));
// {"name":"why","age":18}

// space 参数：格式化缩进
console.log(JSON.stringify(obj, null, 2));
```

> `replacer` 为函数时，可对每个键值做**动态处理**（如过滤敏感字段、替换值）。`JSON.stringify` 无法序列化 `undefined`、函数、`Symbol`、循环引用（会抛错），这些局限是后续"深拷贝"话题的关键。



#### JSON.parse 与 reviver

**`JSON.parse(text, reviver?)`**：把 JSON 字符串**反序列化**为 JavaScript 值，是 `stringify` 的逆操作。

- 严格解析：字符串必须是**合法的 JSON**，否则抛 `SyntaxError`。
- **`reviver`** 参数：可传入函数，在解析过程中**逐项转换**每个值。

```js
const jsonStr = '{"name":"why","age":18}';
const obj = JSON.parse(jsonStr);
console.log(obj.name); // "why"

// reviver：解析时转换值
const data = JSON.parse('{"date":"2024-01-01","price":"100"}', (key, value) => {
  if (key === "price") return Number(value);
  return value;
});
console.log(data.price); // 100（已转成数字）
```

> `reviver` 从**最内层到最外层**逐项调用，适合在反序列化时统一做类型修正（如把字符串日期转回 Date 对象）。`parse` 与 `stringify` 互为逆过程，但往返**不一定完全等价**（如丢失函数、`undefined`）。



#### JSON 的局限与深拷贝

JSON 虽强大，但作为深拷贝手段存在**明显局限**，理解这些局限才能正确选型。

`JSON.parse(JSON.stringify(obj))` 深拷贝的局限：

- **丢失** `undefined`、函数、`Symbol` 值。
- **无法处理** `Date`（变字符串）、`RegExp`（变空对象）、`Map`/`Set`（变空对象）。
- **无法处理循环引用**（抛错）。
- **丢失原型**：拷贝结果变成纯对象。

```js
const original = {
  a: 1,
  fn: () => {},
  date: new Date(),
  undef: undefined
};

const copied = JSON.parse(JSON.stringify(original));
console.log(copied.fn);    // undefined（函数丢失）
console.log(copied.date);  // "2024-..."（Date 变字符串）
console.log(copied.undef); // undefined（属性丢失）
```

> JSON 深拷贝只适用于**纯数据**（基本类型 + 普通对象/数组）。面对函数、Date、Map、循环引用等场景，应使用 `structuredClone()`（原生深拷贝）或手写递归深拷贝（见"常用工具函数"章节）。



### Intl 国际化

#### Intl.DateTimeFormat

**`Intl`**：是 ECMAScript 国际化 API 的命名空间，`Intl.DateTimeFormat` 用于**按地区格式化日期时间**。

```js
const date = new Date();

// 默认格式化
console.log(new Intl.DateTimeFormat("zh-CN").format(date)); // 2024/1/15

// 指定格式选项
const formatter = new Intl.DateTimeFormat("zh-CN", {
  year: "numeric",
  month: "long",
  day: "numeric",
  weekday: "long"
});
console.log(formatter.format(date)); // 2024年1月15日星期一
```

- 第一个参数是 **locale（地区）**，如 `"zh-CN"`、`"en-US"`。
- 第二个参数是**选项对象**，可指定年/月/日/星期等显示粒度与风格。

> `Intl.DateTimeFormat` 相比手写 `getFullYear() + "-" + getMonth()` 的优势是**自动适配地区格式**（中文"2024年1月15日"、英文"January 15, 2024"），且正确处理时区与本地化，是国际化应用的标准做法。



#### Intl.NumberFormat

**`Intl.NumberFormat`**：用于**按地区格式化数字**，包括千分位、货币、百分比等。

```js
// 千分位
console.log(new Intl.NumberFormat("zh-CN").format(1234567.89)); // "1,234,567.89"

// 货币
const money = new Intl.NumberFormat("zh-CN", {
  style: "currency",
  currency: "CNY"
});
console.log(money.format(1234.5)); // "¥1,234.50"

// 百分比
const percent = new Intl.NumberFormat("zh-CN", {
  style: "percent",
  maximumFractionDigits: 1
});
console.log(percent.format(0.123)); // "12.3%"
```

> `style: "currency"` 配合 `currency` 可自动加上货币符号并保留两位小数；`style: "percent"` 会自动乘 100。相比手写 `toFixed`，`Intl.NumberFormat` 能正确处理千分位、货币符号与地区差异。



#### Intl.Collator

**`Intl.Collator`**：用于**按地区规则比较和排序字符串**，处理不同语言的排序规则（如中文拼音、重音符号）。

```js
const collator = new Intl.Collator("zh-CN");
const names = ["张三", "李四", "王五", "阿明"];

names.sort(collator.compare);
console.log(names);
```

- `collator.compare(a, b)` 返回负数/0/正数，可直接作为 `sort` 的比较函数。
- 通过选项可指定是否区分大小写、数字排序等。

> 默认的 `sort()` 按 Unicode 码点排序，对中文等语言**排序结果不符合直觉**（按拼音、笔画才对）。`Intl.Collator` 提供了符合语言习惯的排序规则，是国际化排序的正确选择。



### Date

#### Date 的创建方式

**`Date`**：是表示日期时间的内置对象，有多种创建方式。

- **`new Date()`**：当前时间。
- **`new Date(timestamp)`**：传入 Unix 时间戳（毫秒）。
- **`new Date(year, month, day, ...)`**：传入年月日等，注意**月份从 0 开始**。
- **`new Date(dateString)`**：传入日期字符串（易有解析差异，慎用）。

```js
const now = new Date();
console.log(now); // 当前时间

const fromTimestamp = new Date(0); // 1970-01-01 08:00:00（UTC+8）
console.log(fromTimestamp);

const specific = new Date(2024, 0, 15); // 2024年1月15日（月份从 0 开始）
console.log(specific);
```

> 两个关键陷阱：一是**月份从 0 开始**（`0` 表示 1 月），这是历史设计、极易写错；二是 `new Date(dateString)` 的解析**因浏览器而异**，推荐统一使用时间戳或 `year, month, day` 形式，避免歧义。



#### 时间的两种表示标准

时间有两种标准表示，理解它们的差异是处理时区问题的前提。

- **UTC（Coordinated Universal Time，协调世界时）**：全球统一的基准时间，不含时区偏移。
- **本地时间（Local Time）**：UTC 加上本地时区偏移后的时间，如中国是 **UTC+8**。

Date 对象提供 `get` 与 `getUTC` 两组方法，分别获取本地与 UTC 时间。

```js
const date = new Date();

console.log(date.getHours());     // 本地小时（如 14）
console.log(date.getUTCHours());  // UTC 小时（如 6，UTC+8 时差 8 小时）
console.log(date.getTimezoneOffset()); // 本地与 UTC 的分钟差（如 -480）
```

> 中国在东八区，`getTimezoneOffset()` 返回 `-480`（本地时间 - UTC = 480 分钟）。理解 UTC 与本地时间的关系，是正确处理跨时区应用、避免"时间差 8 小时"问题的关键。



#### 时间格式化方法

Date 提供了若干格式化输出的方法，但都有**局限性**。

- **`toString()`** / **`toDateString()`** / **`toTimeString()`**：完整/日期/时间的字符串。
- **`toLocaleString()`** / **`toLocaleDateString()`** / **`toLocaleTimeString()`**：本地化的字符串，可传 locale。

```js
const date = new Date(2024, 0, 15, 14, 30, 0);

console.log(date.toString());        // 完整字符串
console.log(date.toDateString());    // Mon Jan 15 2024
console.log(date.toLocaleString("zh-CN"));     // 2024/1/15 14:30:00
console.log(date.toLocaleDateString("zh-CN")); // 2024/1/15
```

> 这些方法的输出**格式固定、可定制性差**，且 `toLocaleString` 的结果因环境而异。现代项目更推荐用 `Intl.DateTimeFormat` 做格式化，它格式可控、地区自适应，是官方推荐的方案。



#### Unix 时间戳与 parse 方法

**Unix 时间戳（Timestamp）**：是从 **1970-01-01 00:00:00 UTC** 起经过的**毫秒数**，是表示时间最通用、最无歧义的方式。

- **`date.getTime()`**：获取时间戳。
- **`Date.now()`**：获取当前时间戳（等价 `new Date().getTime()`）。
- **`Date.parse(str)`**：把日期字符串解析为时间戳。
- **`+date`**：一元加号可快速把 Date 转为时间戳。

```js
const now = Date.now();
console.log(now); // 当前时间戳（毫秒）

const date = new Date("2024-01-15");
console.log(date.getTime());   // 该时间的时间戳
console.log(Date.parse("2024-01-15")); // 等价
console.log(+date);            // 一元加号转时间戳
```

> 时间戳的三大优势：**无时区歧义**、**易比较排序**、**易计算差值**。存储时间时用时间戳（或 ISO 字符串），展示时再转成本地格式，是业界通用实践。
