## DOM 节点与 Web 存储

### Node 节点

**节点（Node）**是构成 HTML 网页的最基本单元，网页中的每个部分都是节点。常见节点分为四类：

- **文档节点**：整个 HTML 文档。
- **元素节点**：HTML 标签。
- **属性节点**：元素的属性。
- **文本节点**：标签中的文本内容（含标签间的空格、换行）。

节点的类型不同，属性方法也不同。可通过 `nodeType` 判断节点类型：

- `nodeType === 1`：元素节点（标签）。
- `nodeType === 2`：属性节点。
- `nodeType === 3`：文本节点。

> **元素**指页面中所有标签；**节点**指页面中所有内容（标签、属性、文本），元素也是节点。



### 什么是 DOM

**DOM**（Document Object Model，文档对象模型）为文档提供结构化表示，定义如何通过脚本访问文档结构，目的就是让 JS 能操作 HTML 元素。DOM 由节点组成：HTML 加载完毕后，渲染引擎在内存中把文档生成一棵 DOM 树。



### 获取节点

节点之间的访问关系以**属性**的方式存在。

#### 获取父节点

```js
node.parentNode;
```



#### 获取兄弟节点

- `nextElementSibling`：下一个元素节点。
- `previousElementSibling`：上一个元素节点。



#### 获取子节点

- `firstElementChild`：第一个子元素节点。
- `lastElementChild`：最后一个子元素节点。
- `childNodes`：所有子节点（含元素、文本、注释节点，不含属性节点）。
- `children`：所有子**元素**节点（只返回 HTML 节点，不含文本节点）。



### 节点的操作

#### 创建节点

```js
let el = document.createElement('标签名');
```



#### 插入节点

```js
父节点.appendChild(新子节点); // 末尾插入
父节点.insertBefore(新子节点, 参考节点); // 参考节点前插入
```

> 把一个已存在的节点插入到另一个已存在的节点时，原节点会从原位置消失。



#### 删除节点

```js
父节点.removeChild(子节点);
```



#### 克隆节点

```js
节点.cloneNode(); // 只复制节点本身，不复制子节点
节点.cloneNode(true); // 复制节点本身及其所有子节点
```



#### 设置与删除属性

```js
元素节点.setAttribute('属性名', '属性值');
元素节点.removeAttribute('属性名');
```



### 获取 html 文档

- `document.title`：文档标题。
- `document.head`：head 标签。
- `document.body`：body 标签。
- `document.documentElement`：html 标签（注意不是 `document.html`）。



### Web 存储

HTML5 提供了两种存储方式：

#### sessionStorage 会话存储

- 保存在内存中。
- 生命周期为关闭浏览器窗口，窗口关闭时数据销毁。
- 同一窗口下数据可共享。



#### localStorage 本地存储

- 可能保存在内存或硬盘中。
- 永久生效，除非手动删除。
- 可多窗口共享。



### Web 存储的常用 API

```js
setItem(key, value); // 设置存储内容
getItem(key); // 读取存储内容
removeItem(key); // 按键删除存储内容
clear(); // 清空所有存储内容
```
