## 变量与数据类型

### 变量

#### 变量与数据的存储

**变量**：是程序中用于**存储数据的一个有名字的"盒子"**，其本质是一块被命名的内存空间。程序运行过程中，数据被写入变量、从变量中读取，变量名就是对这段内存的**符号化引用**。

理解变量与数据的存储关系，需要区分两个概念：

- **数据**：真正被处理的内容，如数字 `20`、字符串 `"coderwhy"`、对象 `{ name: "why" }`。
- **变量**：指向数据的**标识符**，通过变量名即可访问其背后的数据，而无需关心数据具体存在内存的哪个地址。

```js
// 把数据 20 存入变量 age
const age = 20;
// 通过变量名 age 读取数据
console.log(age); // 20
```

> 变量名与内存地址的映射关系由引擎自动维护，开发者只需"命名—赋值—使用"。这一层抽象屏蔽了内存管理的复杂性，是高级语言与汇编语言的核心区别之一。



#### 变量的定义过程

在 JavaScript 中，定义一个变量经历**声明**与**赋值**两个步骤，二者可以合并，也可以分离。早期使用 `var`，现代（ES6 起）使用 `let` 与 `const`。

- **声明（Declaration）**：用关键字告诉引擎"我要一个变量"，如 `let age`。此时变量已被创建。
- **赋值（Assignment）**：用 `=` 把数据放进变量，如 `age = 20`。`=` 读作"把右侧的值赋给左侧"。
- **初始化（Initialization）**：声明与赋值合并书写，如 `let age = 20`。

```js
// 声明与赋值分离
let age;      // 声明，未赋值时为 undefined
age = 20;     // 赋值

// 声明与赋值合并（初始化）
const name = "why";
```

`let`、`const`、`var` 三者的核心差异：

- **`let`**：声明**可变**变量，有块级作用域，是默认选择。
- **`const`**：声明**不可重新赋值**的常量，声明时必须初始化，有块级作用域。
- **`var`**：旧式声明，只有函数作用域、存在变量提升，存在诸多历史缺陷，现代代码中应避免使用。

> `const` 的"不可变"仅指**不能重新赋值**，而非值本身不可变：`const` 声明的对象，其属性仍可修改，只是不能把变量重新指向别的值。



#### 变量的命名规范

变量名是代码可读性的第一道关口，JavaScript 对标识符有硬性语法规则，也有约定俗成的风格规范。

硬性语法规则（违反即报错）：

- 只能由**字母、数字、下划线（`_`）、美元符号（`$`）**组成，且**不能以数字开头**。
- **不能使用保留字与关键字**，如 `if`、`for`、`class`、`let` 等。
- **区分大小写**：`age` 与 `Age` 是两个不同变量。

约定俗成的风格规范：

- 变量与函数用**小驼峰**命名：`userName`、`getUserById`。
- 类与构造函数用**大驼峰**命名：`Person`、`HttpClient`。
- 命名应**见名知义**，用完整英文单词，不用拼音、缩写或无意义的 `a`、`b`、`x`。

```js
// 推荐：见名知义的小驼峰
const userName = "coderwhy";
const maxCount = 100;

// 错误示范：无意义命名
const a = 20;
const data1 = "why";
```

> 一条经验法则：**代码是给人读的，只是顺便给机器执行**。当变量名需要写注释解释含义时，往往说明命名本身已经失败，应当重命名而非补注释。



#### 变量的练习题目

通过几道练习巩固变量的声明、赋值与交换，尤其要理解"赋值是值的拷贝，而非绑定"。

```js
// 1. 声明两个变量并交换它们的值
let a = 10;
let b = 20;

// 借助第三个变量暂存
const temp = a;
a = b;
b = temp;
console.log(a, b); // 20 10

// 2. 使用解构赋值一步完成交换（ES6）
let x = 1;
let y = 2;
[x, y] = [y, x];
console.log(x, y); // 2 1
```

- 交换两个变量是经典入门题，关键点是**中间必须有个"暂存"**，否则赋值会互相覆盖。
- 解构赋值 `[x, y] = [y, x]` 是 ES6 的语法糖，本质等价于借助临时数组完成交换。

> 交换变量的核心陷阱：若直接 `a = b; b = a;`，第二句里的 `a` 已经是 `b` 的旧值，两个变量最终会变成同一个值，原来的数据就丢失了。



#### 变量使用的注意事项

使用变量时有几个容易被忽略、却又极其关键的细节。

- **先声明后使用**：`let` / `const` 声明的变量存在**暂时性死区（TDZ）**，在声明之前访问会抛出 `ReferenceError`。
- **未声明的变量不能直接赋值**：在严格模式下，给未声明的变量赋值会报错；非严格模式下则会**隐式创建全局变量**，这是危险的坏味道。
- **`const` 必须初始化**：`const x;` 会直接抛出语法错误。
- **避免隐式全局变量**：忘记写 `let`/`const` 直接 `foo = 1`，会污染全局作用域，引发难以追踪的 bug。

```js
// 暂时性死区：声明前访问会报错
console.log(bar); // ReferenceError: Cannot access 'bar' before initialization
const bar = 10;

// 未声明直接赋值（非严格模式）会创建隐式全局变量
// myVar = 100; // 应避免这种写法
```

> 所有这些注意事项都可归结为一句原则：**显式优于隐式**。声明、初始化、作用域都写清楚，能规避绝大多数变量相关的运行时错误。



### 数据类型

#### 动态类型

JavaScript 是一门**动态类型**语言，即**变量的类型在运行时才能确定，且同一变量在不同时刻可以持有不同类型的值**。

- 声明变量时**无需指定类型**，引擎根据赋值的内容自动推断。
- 一个变量可以**先存数字、再存字符串**，类型随之改变，这是与 Java 等静态类型语言的根本区别。

```js
let value = 20;          // value 现在是 number
value = "hello";         // value 变成 string
value = true;            // value 变成 boolean
console.log(typeof value); // "boolean"
```

> 动态类型带来了**灵活**，也带来了**隐患**：类型错误要到运行时才暴露，无法靠编译器提前发现。TypeScript 正是为补上"静态类型检查"这一环而诞生的。



#### 类型判断的多种方式

判断一个值的类型是高频需求，JavaScript 提供了多种手段，各有适用场景与局限。

- **`typeof`**：最常用的运算符，返回类型的字符串，但对 `null`、数组等有历史遗留的误判。
- **`instanceof`**：判断对象是否为某构造函数的实例，用于**引用类型**（对象、数组等），无法判断基本类型。
- **`Object.prototype.toString.call()`**：最精确的通用判断手段，能准确区分所有内置类型。
- **`Array.isArray()`**：专门判断是否为数组，是判断数组的**首选**（弥补 `typeof` 的缺陷）。

```js
const arr = [1, 2, 3];

typeof arr;                              // "object"（误判，无法区分数组）
Array.isArray(arr);                      // true（正确）
Object.prototype.toString.call(arr);     // "[object Array]"
arr instanceof Array;                    // true
```

> 这四种方式的定位清晰：**`typeof` 判断基本类型，`instanceof` 判断继承关系，`Array.isArray` 专判数组，`toString` 万能兜底**。日常最常用 `typeof` 与 `Array.isArray`，遇到疑难再请出 `toString`。



#### typeof 操作符

**`typeof`**：是一个**一元操作符**，用于返回操作数类型对应的字符串。它的写法有两种：`typeof x`（运算符形式）或 `typeof(x)`（函数调用形式），二者等价。

`typeof` 的返回值对照：

- **`"undefined"`**：未定义的变量、未赋值的变量、`undefined` 本身。
- **`"number"`**：所有数字，包括 `NaN`、`Infinity`。
- **`"string"`**：字符串。
- **`"boolean"`**：布尔值。
- **`"object"`**：对象、数组、`null`。
- **`"function"`**：函数（函数本质是对象，但 `typeof` 单独识别为 `"function"`）。
- **`"symbol"`**：ES6 的 Symbol 类型。
- **`"bigint"`**：ES2020 的大整数类型。

```js
typeof 20;              // "number"
typeof "hello";         // "string"
typeof undefined;       // "undefined"
typeof null;            // "object"（历史遗留 bug）
typeof [1, 2, 3];       // "object"
typeof function () {};  // "function"
typeof Symbol();        // "symbol"
```

> `typeof null` 返回 `"object"` 是 JavaScript 著名的历史 bug：早期实现中，对象的类型标签是 `0`，而 `null` 被实现为空指针、标签也是 `0`，于是被误判。该 bug 已无法修复（牵动海量存量代码），只能靠 `value === null` 来单独判断 `null`。



### 基本数据类型

#### Number 类型

**Number 类型**：是 JavaScript 表示数字的唯一数值类型，采用 IEEE 754 标准的**双精度 64 位浮点数**格式。JavaScript 不区分整数与浮点数，`1` 和 `1.0` 是同一个值。

- **范围**：最大安全整数为 `Number.MAX_SAFE_INTEGER`（`9007199254740991`），超过此值的整数运算可能失真。
- **特殊值**：`NaN`（非数值）、`Infinity`（正无穷）、`-Infinity`（负无穷）。
- **进制表示**：支持二进制 `0b`、八进制 `0o`、十六进制 `0x` 前缀，输出时统一转为十进制。

```js
const int = 42;             // 整数
const float = 3.14;         // 浮点数
const hex = 0xff;           // 十六进制，255
const binary = 0b1010;      // 二进制，10
console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
```

> 由于只用一个类型表示所有数字，JavaScript 没有"整数溢出"的经典问题，但带来了**浮点精度**问题（见下一节）。处理超大整数（如金融、大数 ID）时应改用 ES2020 引入的 `BigInt`。



##### 数值范围与特殊值

Number 类型有几个**特殊值**和边界常量，是必须牢记的知识点。

- **`Number.MAX_VALUE`**：能表示的最大正数，约 `1.7976931348623157e+308`。
- **`Number.MIN_VALUE`**：能表示的最小正数，约 `5e-324`（无限接近 0 但不为 0）。
- **`Number.MAX_SAFE_INTEGER`**：安全整数上限 `9007199254740991`（即 `2^53 - 1`）。
- **`Number.MIN_SAFE_INTEGER`**：安全整数下限 `-9007199254740991`。
- **`Infinity`**：正无穷，由 `1 / 0` 或 `Number.MAX_VALUE * 2` 得到。
- **`-Infinity`**：负无穷，由 `-1 / 0` 得到。
- **`NaN`（Not a Number）**：非数值，表示"本应是数字但结果不是数字"。

```js
console.log(1 / 0);                       // Infinity
console.log(-1 / 0);                      // -Infinity
console.log(Number.MAX_VALUE * 2);        // Infinity
console.log(Number("abc"));               // NaN
console.log(NaN === NaN);                 // false
```

> `NaN` 有两个反直觉特性：一是 `NaN === NaN` 返回 `false`（它不与任何值相等，包括自己），判断须用 `Number.isNaN()`；二是任何与 `NaN` 的算术运算结果都是 `NaN`，具有"传染性"。



##### 浮点数精度与 0.1 + 0.2

浮点数精度是 JavaScript 最著名的"坑"之一，根源在于 **IEEE 754 双精度浮点数用二进制无法精确表示某些十进制小数**。

```js
console.log(0.1 + 0.2);        // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3); // false
```

- **根因**：十进制小数 `0.1`、`0.2` 转换为二进制后是**无限循环小数**，只能截断存储，累加时产生舍入误差。
- **常见后果**：涉及小数的比较、金额计算、循环累加时出现"差一点"的诡异结果。
- **应对方案**：
  - 判断相等用**误差容限**：`Math.abs(a - b) < Number.EPSILON`。
  - 金额等场景**改用整数运算**（如以"分"为单位），或使用专门的库（如 `decimal.js`）。

```js
// 用误差容限判断"相等"
const sum = 0.1 + 0.2;
const isEqual = Math.abs(sum - 0.3) < Number.EPSILON;
console.log(isEqual); // true

// 金额用整数（分）避免精度问题
const totalCents = 10 + 20; // 0.1 元 + 0.2 元 = 30 分
console.log(totalCents / 100); // 0.3
```

> 这不是 JavaScript 独有的问题，所有采用 IEEE 754 浮点数的语言（Java、C、Python 等）都有同样的表现。JavaScript 只是因为没有独立的整数/小数类型，让这一问题更常被初学者撞见。



#### String 类型

**String 类型**：用于表示**文本**，由零个或多个 16 位 Unicode 字符组成，是不可变的字符序列。字符串可以包含任何字符，包括中文、表情符号等。

字符串的三种书写方式：

- **单引号**：`'hello'`。
- **双引号**：`"hello"`。
- **反引号（模板字符串）**：`` `hello` ``，ES6 引入，支持**插值**与**多行**。

```js
const name = "coderwhy";
const age = 18;

// 模板字符串：用 ${} 插入变量，可换行
const intro = `我叫 ${name}，今年 ${age} 岁`;
console.log(intro); // 我叫 coderwhy，今年 18 岁
```

字符串常用的几个操作：

- **拼接**：用 `+` 或模板字符串。
- **获取长度**：`str.length`。
- **转义字符**：`\n` 换行、`\t` 制表符、`\\` 反斜杠、`\'` 单引号。
- **不可变性**：字符串一旦创建就不能修改，所有"修改"操作都返回新字符串。

```js
const str = "hello";
console.log(str.length);      // 5
console.log(str.toUpperCase()); // "HELLO"（返回新字符串，原字符串不变）
console.log(str);             // "hello"（仍为原值）
```

> 模板字符串是 ES6 最重要的语法糖之一：`${}` 里可以放任意表达式，且天然支持多行，让拼接字符串从"满屏加号"变得清晰可读。现代代码中应优先使用模板字符串。



#### Boolean 类型

**Boolean 类型**：只有两个取值 **`true`（真）** 和 **`false`（假）**，用于表达逻辑判断的结果，是流程控制（`if`、循环、三元运算）的基石。

- 布尔值由**比较运算**、**逻辑运算**产生，如 `1 > 0` 得到 `true`。
- 其他类型的值可以通过 `Boolean()` 转换为布尔值，规则即"**真值（truthy）与假值（falsy）**"。

六个**假值（falsy）**，转换为布尔后为 `false`，其余皆为真值：

- `false`
- `0` 和 `-0`
- `""`（空字符串）
- `null`
- `undefined`
- `NaN`

```js
console.log(Boolean(0));       // false
console.log(Boolean(""));      // false
console.log(Boolean(null));    // false
console.log(Boolean("0"));     // true（非空字符串是真值）
console.log(Boolean([]));      // true（空数组是真值）
console.log(Boolean({}));      // true（空对象是真值）
```

> 两个高频陷阱：一是 `"0"` 和 `[]` 都是**真值**（只有空字符串 `""` 是假值）；二是在 `if` 条件里，引擎会自动做布尔转换，等价于调用 `Boolean()`，理解假值列表就能预判所有分支行为。



#### Undefined 类型

**Undefined 类型**：只有一个值 **`undefined`**，表示"**变量已声明但尚未赋值**"或"**缺失的值**"。它是 JavaScript 中"空"的一种表现。

`undefined` 出现的典型场景：

- 声明了变量但未赋值。
- 访问对象上**不存在的属性**。
- 函数**没有返回值**时，默认返回 `undefined`。
- 调用函数时**未传入的形参**。

```js
let foo;
console.log(foo);            // undefined（声明未赋值）

const obj = { name: "why" };
console.log(obj.age);        // undefined（不存在的属性）

function noReturn() {}
console.log(noReturn());     // undefined（无返回值）

function greet(name) {
  console.log(name);         // 未传参时为 undefined
}
greet();
```

> `undefined` 与"未声明"是两个概念：访问一个**已声明但未赋值**的变量得到 `undefined`；访问一个**从未声明**的变量则抛出 `ReferenceError`。前者是"有这个盒子但空着"，后者是"根本没有这个盒子"。



#### Null 类型

**Null 类型**：也只有一个值 **`null`**，表示"**空值**"或"**有意为之的不存在**"。与 `undefined` 的"未定义"不同，`null` 是**主动赋值的空**，代表"这里应该有一个值，但现在故意设为空"。

- `null` 通常用于**初始化一个将来要赋值为对象的变量**，表示"暂时没有对象"。
- `null` 是一个**字面量**，也是 `object` 类型在历史上的误判对象（`typeof null` 返回 `"object"`）。
- 判断 `null` 只能用**严格相等**：`value === null`。

```js
let user = null;          // 主动设为空，表示"暂无用户对象"
user = { name: "why" };   // 之后赋值为真正的对象

console.log(typeof null); // "object"（历史 bug）
console.log(null === undefined); // false
console.log(null == undefined);  // true（宽松相等下二者视为相等）
```

> `null` 与 `undefined` 的区分是经典面试题：`undefined` 是**系统默认**的"未定义"（被动），`null` 是**开发者主动**的"空"（主动）。语义上，**需要"空对象"用 `null`，需要"未定义"让系统给 `undefined`**。



#### Object 类型

**Object 类型**：是 JavaScript 中唯一的一种**复杂（引用）类型**，用于存储**键值对**的集合，也是几乎所有复杂结构的根基——数组、函数、正则、日期等，本质上都是对象。

- **键值对结构**：由若干 `属性名: 属性值` 组成，属性值可以是任意类型，包括另一个对象。
- **引用语义**：对象通过**引用**存储，赋值、传参都是复制引用，多个变量可指向同一对象。
- **创建方式**：对象字面量 `{}`、`new Object()`、`Object.create()` 等。

```js
const person = {
  name: "coderwhy",
  age: 18,
  sayHi() {
    console.log("你好，我是 " + this.name);
  }
};

console.log(person.name);  // "coderwhy"
person.sayHi();            // 你好，我是 coderwhy

// 引用语义：两个变量指向同一对象
const p2 = person;
p2.age = 20;
console.log(person.age);   // 20（修改 p2 影响 person）
```

> 对象与基本类型的本质区别在于**存储方式**：基本类型存"值本身"，对象存"值的地址（引用）"。理解这一点，才能解释"为什么改 `p2` 会连 `person` 一起变"这类现象，这也是后续"深浅拷贝"等话题的前提。
