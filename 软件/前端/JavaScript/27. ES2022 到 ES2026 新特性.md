## ES2022 到 ES2026 新特性

### ES2022

#### 类的实例字段与静态字段

**实例字段**与**静态字段**（ES2022）：直接在类体里声明字段，无需在 `constructor` 中赋值。

- **实例字段**：每个实例独立。
- **静态字段**：用 `static` 声明，属于类本身。

```js
class Person {
  name = "未命名";        // 实例字段
  static species = "人类"; // 静态字段

  constructor(name) {
    this.name = name;
  }
}

const p = new Person("why");
console.log(p.name);           // "why"
console.log(Person.species);   // "人类"（通过类访问）
```

> 类字段让字段声明**更直观**：不用在 `constructor` 里逐个 `this.x = x`，直接在类体声明（可带默认值）。静态字段属于**类本身**（而非实例），通过 `类名.字段` 访问。



#### 私有字段与 # 前缀

**私有字段 `#`**（ES2022）：真正私有的字段，**类外无法访问**。

```js
class Counter {
  #count = 0; // 私有字段

  increment() {
    this.#count++;
  }
  getCount() {
    return this.#count; // 类内部可访问
  }
}

const c = new Counter();
c.increment();
console.log(c.getCount()); // 1
// console.log(c.#count);  // 语法错误：外部无法访问
```

> `#` 私有字段提供**语言级封装**：只能在类内部访问，外部（甚至子类、反射）都无法直接读取。它比 `_` 约定和 `Symbol` 都更安全，是"私有"的标准方案。



#### 类的静态初始化块

**静态初始化块 `static {}`**（ES2022）：在类**定义时执行一次**的代码块，用于复杂的静态字段初始化。

```js
class Config {
  static settings;

  static {
    // 类定义时执行，做复杂初始化
    this.settings = { env: "production", timeout: 1000 };
  }
}

console.log(Config.settings); // { env: "production", timeout: 1000 }
```

> 静态块在**类定义时立即执行一次**，适合需要**多步计算**的静态字段初始化（单条 `static x = ...` 表达不了的逻辑）。它让静态初始化逻辑更清晰。



#### 顶层 await

**顶层 await**（ES2022）：在**模块顶层**直接使用 `await`，无需包在 `async` 函数里。

```js
// 在 ES Module 顶层直接 await
const data = await fetch("/api/data").then((r) => r.json());
console.log(data);
```

> 之前 `await` 只能在 `async` 函数内，模块顶层要用 `await` 得包一层；顶层 await 让模块可以直接**等待异步结果**再继续。它**只能在 ES Module** 中使用，常用于等待配置、数据加载后再导出。



#### at() 方法

**`Array.prototype.at(index)` / `String.prototype.at(index)`**（ES2022）：支持**负数索引**的元素访问。

```js
const arr = [1, 2, 3, 4];
console.log(arr.at(0));   // 1
console.log(arr.at(-1));  // 4（最后一个元素）

const str = "hello";
console.log(str.at(-1));  // "o"
```

> `at(-1)` 直接取**最后一个元素**，替代了 `arr[arr.length - 1]` 的繁琐写法。负数索引从末尾倒数，是 `at` 的核心价值。



#### Object.hasOwn() 与 Error.cause

- **`Object.hasOwn(obj, key)`**（ES2022）：判断**自身属性**，替代 `hasOwnProperty`。
- **`Error` 的 `cause`**：给错误附加**原始原因**。

```js
// Object.hasOwn
const obj = { a: 1 };
console.log(Object.hasOwn(obj, "a"));        // true
console.log(Object.hasOwn(obj, "toString")); // false（继承的，不算自身）

// Error.cause
try {
  throw new Error("操作失败", { cause: "数据库连接超时" });
} catch (err) {
  console.log(err.cause); // "数据库连接超时"
}
```

> `Object.hasOwn` 比 `obj.hasOwnProperty()` 更安全（不依赖原型链、可用在 `Object.create(null)` 的对象上）。`Error.cause` 让错误链可追溯，方便排查根因。



### ES2023

#### findLast() 与 findLastIndex()

**`findLast()` / `findLastIndex()`**（ES2023）：从**末尾向前**查找元素。

```js
const arr = [1, 2, 3, 4, 5, 4];

console.log(arr.findLast((x) => x === 4));      // 4（最后一个 4）
console.log(arr.findLastIndex((x) => x === 4)); // 5（最后一个 4 的索引）
```

> 之前从末尾查找要 `reverse` 或用循环，ES2023 提供 `findLast`/`findLastIndex` 直接实现，与 `find`/`findIndex` 对称。



#### Change Array by Copy

**"Array by Copy"**（ES2023）：一组**返回新数组、不修改原数组**的方法。

##### toReversed()、toSorted() 与 toSpliced()

- **`toReversed()`**：返回反转后的新数组。
- **`toSorted()`**：返回排序后的新数组。
- **`toSpliced()`**：返回增删改后的新数组。

```js
const arr = [3, 1, 2];

console.log(arr.toReversed());       // [2, 1, 3]（原数组不变）
console.log(arr.toSorted());         // [1, 2, 3]（原数组不变）
console.log(arr.toSpliced(1, 1, 9)); // [3, 9, 2]（原数组不变）
console.log(arr);                    // [3, 1, 2]（原数组始终不变）
```

> 传统 `reverse`/`sort`/`splice` 会**原地修改**数组；`toReversed`/`toSorted`/`toSpliced` 返回**新数组**，符合**不可变数据**思想，在 React 等强调不可变的场景尤其有用。



##### with()

**`with(index, value)`**（ES2023）：返回"**替换指定索引元素**"的新数组。

```js
const arr = [1, 2, 3];
const newArr = arr.with(1, 99);
console.log(newArr); // [1, 99, 3]
console.log(arr);    // [1, 2, 3]（原数组不变）
```

> `with(index, value)` 是"**不可变地替换单个元素**"：`arr.with(1, 99)` 等价于"复制数组并改 `[1]` 为 99"，原数组不变。



#### Hashbang 语法

**Hashbang**（ES2023）：允许 JS 文件**首行**写 `#!` 声明解释器（用于 CLI 脚本）。

```js
#!/usr/bin/env node
// 上面这行是 hashbang，用于指定解释器

console.log("这是可执行的 Node 脚本");
```

> Hashbang 让 JS 文件可以像 Shell 脚本一样**直接执行**（`./script.js` 而不必 `node script.js`）。它只允许出现在**文件第一行**，是构建 CLI 工具的标配。



#### Symbol 作为 WeakMap 的键

**Symbol 作为 WeakMap 键**（ES2023）：`WeakMap` 的键现在也可以是 `Symbol`。

```js
const weakMap = new WeakMap();
const symKey = Symbol("key");

weakMap.set(symKey, "value");
console.log(weakMap.get(symKey)); // "value"
```

> 之前 `WeakMap` 键只能是**对象**，ES2023 扩展到也可用 **`Symbol`**（`Symbol` 也是唯一、可被 GC 的类型）。这让 `WeakMap` 的键类型更丰富。



### ES2024

#### Object.groupBy() 与 Map.groupBy()

**`Object.groupBy()` / `Map.groupBy()`**（ES2024）：按**回调的返回值**对数组元素**分组**。

```js
const people = [
  { name: "张三", age: 18 },
  { name: "李四", age: 25 },
  { name: "王五", age: 18 }
];

const grouped = Object.groupBy(people, (p) => p.age);
console.log(grouped);
// { 18: [...张三, 王五], 25: [...李四] }
```

> 分组是高频需求，之前要用 `reduce` 手写。`Object.groupBy`（返回对象）/`Map.groupBy`（返回 Map）提供了**原生分组**，让代码更简洁。



#### Promise.withResolvers()

**`Promise.withResolvers()`**（ES2024）：一次性获取 `Promise` 及其 `resolve`/`reject` 函数。

```js
const { promise, resolve, reject } = Promise.withResolvers();

// 稍后在别处 resolve/reject
setTimeout(() => resolve("完成"), 1000);
promise.then((v) => console.log(v)); // "完成"
```

> 之前要"**外部控制 Promise 何时 resolve**"得手写：`let resolve; new Promise((r) => resolve = r)`。`withResolvers` 一次性返回 `promise`、`resolve`、`reject`，更简洁。



#### ArrayBuffer 的 transfer 与可调整大小

- **`ArrayBuffer.prototype.transfer()`**：**转移**缓冲区（零拷贝移动所有权）。
- **可调整大小的 ArrayBuffer**：`maxByteLength` 支持动态调整大小。

```js
const buffer = new ArrayBuffer(16);
const transferred = buffer.transfer(32); // 转移到更大的新缓冲区
console.log(transferred.byteLength); // 32
```

> `transfer` 实现**零拷贝**的缓冲区转移（所有权移交，旧缓冲区失效）。可调整大小的 `ArrayBuffer` 允许**动态扩容**，是 WebAssembly、高性能场景的基础能力。



#### 良构的 Unicode 字符串

**`String.prototype.toWellFormed()` / `isWellFormed()`**（ES2024）：处理**孤立代理项**（残缺的 Unicode 字符）。

```js
const bad = "ab\uD800"; // 末尾是孤立的代理项
console.log(bad.isWellFormed()); // false

const fixed = bad.toWellFormed(); // 替换孤立代理项
console.log(fixed.isWellFormed()); // true
```

> 处理含 emoji、生僻字的字符串时，可能出现**孤立代理项**（半个字符），导致编码出错。`isWellFormed` 检测、`toWellFormed` 修复，保证字符串是**良构的 Unicode**。



#### Atomics.waitAsync()

**`Atomics.waitAsync()`**（ES2024）：**异步**等待共享内存的值变化（`Atomics.wait` 的异步版）。

```js
const sab = new SharedArrayBuffer(4);
const view = new Int32Array(sab);

// 异步等待，返回 Promise
Atomics.waitAsync(view, 0, 0).then(() => {
  console.log("值已变化");
});
```

> `Atomics.wait` 是**同步阻塞**的（会卡住主线程），`waitAsync` 提供**异步**版本，适合在主线程安全地等待共享内存状态。



### ES2025

#### Set 的集合方法

**Set 的集合方法**（ES2025）：为 `Set` 增加**集合运算**。

- **`union(other)`**：并集。
- **`intersection(other)`**：交集。
- **`difference(other)`**：差集。
- **`symmetricDifference(other)`**：对称差。

```js
const a = new Set([1, 2, 3]);
const b = new Set([3, 4, 5]);

console.log([...a.union(b)]);             // [1, 2, 3, 4, 5]
console.log([...a.intersection(b)]);      // [3]
console.log([...a.difference(b)]);        // [1, 2]
```

> 集合运算（并、交、差）是**数学集合**的经典操作，之前要手写实现。ES2025 原生提供，让 `Set` 的集合运算更便捷。



#### Iterator helpers

**Iterator helpers**（ES2025）：给迭代器增加 `map`、`filter` 等**链式方法**。

```js
const result = [1, 2, 3, 4, 5]
  .values()
  .filter((x) => x % 2 === 1)
  .map((x) => x * 10)
  .toArray();

console.log(result); // [10, 30, 50]
```

> 迭代器方法让"**迭代过程中**"就能 map/filter，且**惰性求值**（不立即产生中间数组），对大数据更省内存。`toArray()` 把结果收集为数组。



#### Promise.try()

**`Promise.try(fn)`**（ES2025）：把函数**统一包装成 Promise**，同步/异步都安全。

```js
function maybeSync() {
  return 42; // 同步返回
}
function maybeAsync() {
  return Promise.resolve(42); // 异步返回
}

Promise.try(maybeSync).then((v) => console.log(v));  // 42
Promise.try(maybeAsync).then((v) => console.log(v)); // 42
```

> `Promise.try` 解决"**函数可能同步抛错、也可能返回 Promise**"的不确定性：无论哪种情况，都能安全地用 `then`/`catch` 处理，避免同步异常逃逸。



#### RegExp.escape()

**`RegExp.escape(str)`**（ES2025）：转义字符串中的**正则特殊字符**，用于动态构造正则。

```js
const keyword = "a.b"; // 含特殊字符的点
const escaped = RegExp.escape(keyword); // "a\.b"
const reg = new RegExp(escaped);
console.log(reg.test("a.b")); // true（点被当作字面量）
```

> 之前动态构造正则时，用户输入里的 `.`、`*` 等会**被当作正则符号**；`RegExp.escape` 自动转义，让字符串**按字面量**匹配，避免意外与注入风险。



#### JSON 模块与导入属性

**导入属性（Import Attributes）**（ES2025）：用 `with` 语法指定模块**导入类型**，如 JSON 模块。

```js
// 以 JSON 模块方式导入
import data from "./data.json" with { type: "json" };
console.log(data);
```

> 导入属性 `with { type: "json" }` 让 JSON 能被**作为模块导入**（而不是字符串），并明确了模块类型，避免歧义。这是模块系统的重要增强。



#### Float16Array 与 Math.f16round()

**`Float16Array`** 与 **`Math.f16round()`**（ES2025）：支持 **16 位浮点数**，适合 GPU、机器学习等场景。

```js
const arr = new Float16Array([1.5, 2.5]);
console.log(arr[0]); // 1.5

console.log(Math.f16round(1.337)); // 转成 float16 精度
```

> `Float16`（半精度浮点）**精度低但省一半内存**，在 GPU 计算、神经网络推理等"精度可牺牲、性能要优先"的场景很有价值。



#### RegExp 修饰符与重复具名捕获组

**正则修饰符增强**（ES2025）：允许在**重复的具名捕获组**中使用修饰符。

```js
// 重复的具名分组 + 修饰符
const reg = /(?:(?<year>\d{4})-){2}/;
const match = "2024-2025-".match(reg);
console.log(match.groups.year); // "2025"（重复分组保留最后一个）
```

> 之前**重复的具名捕获组**会导致匹配失败，ES2025 允许这种用法（保留最后一个匹配）。这让"重复模式 + 具名分组"成为可能。



### ES2026

#### Array.fromAsync()

**`Array.fromAsync()`**（ES2026）：从**异步可迭代对象**创建数组。

```js
async function* asyncGen() {
  yield 1;
  yield 2;
  yield 3;
}

const arr = await Array.fromAsync(asyncGen());
console.log(arr); // [1, 2, 3]
```

> `Array.from` 只能处理同步可迭代对象，`Array.fromAsync` 扩展支持**异步可迭代对象**（异步生成器、异步流），是异步数据收集的利器。



#### Math.sumPrecise()

**`Math.sumPrecise()`**（ES2026）：**精确求和**，避免浮点累加误差。

```js
const nums = [0.1, 0.2, 0.3];
console.log(nums.reduce((a, b) => a + b, 0)); // 0.6000000000000001（有误差）
console.log(Math.sumPrecise(nums));            // 0.6（精确）
```

> 浮点累加会产生**累积误差**（`0.1 + 0.2 !== 0.3`），`Math.sumPrecise` 用**补偿求和算法**（Kahan 求和）减少误差，适合金融、科学计算等精度敏感场景。



#### Error.isError()

**`Error.isError(value)`**（ES2026）：判断值是否为 `Error` 对象（跨 iframe/领域安全）。

```js
console.log(Error.isError(new Error())); // true
console.log(Error.isError("error"));     // false
console.log(Error.isError({}));          // false
```

> 之前判断 Error 用 `instanceof Error`，但**跨 iframe/领域**会失效（不同领域的 Error 构造器不同）。`Error.isError` 用内部机制判断，跨领域也可靠。



#### Uint8Array 与 Base64 转换

**`Uint8Array.prototype.toBase64()` / `fromBase64()`**（ES2026）：二进制与 Base64 的**原生转换**。

```js
const bytes = new Uint8Array([104, 101, 108, 108, 111]); // "hello"
const base64 = bytes.toBase64();
console.log(base64); // "aGVsbG8="

const decoded = Uint8Array.fromBase64(base64);
console.log(decoded); // Uint8Array(5)
```

> 之前二进制 ↔ Base64 要借助 `btoa`/`atob`（只支持 ASCII）或手写实现，ES2026 提供 `Uint8Array` 的原生方法，高效且支持任意二进制数据。



#### 迭代器的拼接

**迭代器拼接**（ES2026）：`Iterator.concat()` 拼接多个迭代器。

```js
const a = [1, 2].values();
const b = [3, 4].values();

const combined = Iterator.concat(a, b);
console.log([...combined]); // [1, 2, 3, 4]
```

> `Iterator.concat` 把多个**迭代器拼接**成一个，类似数组的 `concat`，但作用于迭代器、惰性求值。



#### JSON.parse() 的源文本访问

**JSON.parse 的源文本访问**（ES2026）：通过 `reviver` 的 `context.source` 获取**原始 JSON 文本**。

```js
const json = '{"num": 123}';
JSON.parse(json, (key, value, context) => {
  console.log(context.source); // 原始文本片段
  return value;
});
```

> 新版 `JSON.parse` 的 `reviver` 第三个参数 `context` 提供了 `source`（原始 JSON 文本），可用于**保留数字的原始表示**（如区分 `1` 和 `1.0`）、做更精细的解析。



#### Map 的 getOrInsert

**`Map.prototype.getOrInsert()`**（ES2026）：获取键对应的值，**不存在则插入默认值**并返回。

```js
const map = new Map();
const value = map.getOrInsert("key", () => "默认值");
console.log(value); // "默认值"（已插入）

console.log(map.getOrInsert("key", () => "其他")); // "默认值"（已存在，返回原值）
```

> `getOrInsert` 合并了"**获取 + 不存在则插入**"两个操作，常用于**缓存**（键不存在时计算并缓存，存在时直接返回）。第二个参数是**工厂函数**（惰性求值默认值）。
