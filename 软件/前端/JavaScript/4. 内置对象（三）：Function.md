## 内置对象（三）：Function

### 函数的概念

函数就是把一些语句**封装**起来，在需要时通过**调用**执行。函数也是一个**对象**，用 `typeof` 检查函数会返回 `function`。函数的作用是避免重复劳动，实现高内聚、低耦合的模块化编程。

### 函数的定义方式

#### 方式一：函数声明（命名函数）

```js
function fun1(a, b) {
  return a + b;
}
```

使用 `function` 关键字定义，会被**声明提前**（可在定义前调用）。

#### 方式二：函数表达式（匿名函数）

```js
let fun2 = function (a, b) {
  return a + b;
};
```

本质是把匿名函数赋值给变量，不会被声明提前。

#### 方式三：new Function 构造函数

```js
let fun3 = new Function('a', 'b', 'return a + b');
```

参数必须都是**字符串**，最后一个字符串是函数体。这种方式很少用：书写啰嗦，且需先把字符串转为代码再执行，效率低。

> 所有的函数本质上都是 `Function` 的实例，函数也属于对象（有 `__proto__`，且 `fun instanceof Object` 为 true）。

### 函数的调用方式

- **普通函数调用**：`fn()`。
- **对象方法调用**：`obj.fn()`，此时函数是该对象的方法。
- **立即执行函数（IIFE）**：`(function(){ ... })()`，定义后立即调用，只执行一次。
- **构造函数调用**：`new Fn()`。
- **事件绑定函数**：`btn.onclick = function(){ ... }`。
- **定时器函数**：`setInterval(function(){ ... }, 1000)`。

### 函数的参数

#### 形参与实参

**形参**是定义函数时声明的参数，**实参**是调用时传入的参数。JS 中解析器**不检查**实参的类型与数量：

- 实参多于形参时，多余的实参被忽略（但可用 `arguments` 拿到）。
- 实参少于形参时，缺少的形参为 `undefined`。
- 形参的默认值是 `undefined`。

#### 参数默认值（ES6）

```js
function fn(param = 'hello') {
  console.log(param);
}
```

调用时不给参数就用默认值，给了就用新值。默认值参数之后不能再有**没有默认值**的参数。

#### 剩余参数（rest）

剩余参数用 `...args` 把不确定数量的剩余实参收集到数组中：

```js
function sum(...args) {
  return args.reduce((pre, cur) => pre + cur, 0);
}
console.log(sum(1, 2, 3)); // 6
```

剩余参数必须是最后一个参数，之后不能再有别的参数。

#### arguments 类数组

调用函数时，浏览器会传入两个隐含参数：`this` 和 `arguments`。`arguments` 是**类数组对象**，保存了所有实参，具有 `length` 属性，可用索引访问，但没有 `push`、`pop` 等方法，且**只在函数内可用**。

- `arguments.length` 获取实参个数；`函数名.length` 获取形参个数。
- `arguments.callee` 指向当前正在执行的函数，递归时推荐用它代替函数名。
- arguments 可以修改元素，但不能改变长度。

### 函数的返回值

`return` 结束函数并把值作为执行结果返回：

- `return` 后的语句不会执行。
- `return` 不跟值时，返回 `undefined`。
- 函数不写 `return`，也返回 `undefined`。
- 返回值可以是任意类型（含对象、函数）。

### 函数名与函数体

**函数名 == 整个函数**：`fn`（不加括号）表示函数对象本身，`fn()`（加括号）才是调用并得到返回值。

### break、continue、return

- `break`：结束当前循环体。
- `continue`：跳出本次循环，继续下一次。
- `return`：结束函数并返回值。

### 原型与原型链

#### 原型对象 prototype

每个函数在创建时，解析器都会给它添加一个 `prototype` 属性，对应一个对象，称为**原型对象**。原型对象是公共区域，同一构造函数创建的所有实例都能访问它，因此可以把实例共有的属性和方法统一放到原型对象上。

```js
function Person(name) {
  this.name = name;
}
Person.prototype.sayName = function () {
  console.log(this.name);
};
```

实例通过 `__proto__`（隐式原型）访问原型对象，`实例.__proto__ === 构造函数.prototype`。

#### 原型链

访问对象的属性或方法时，查找顺序是：先在自己身上找，找不到再去原型对象找，再找不到就去原型的原型找，直到 `Object.prototype`，最后找不到则返回 `null`。

> 用 `in` 检查属性时，原型中的属性也会返回 true；`hasOwnProperty()` 只检查对象自身。

#### 原型三角关系

这是理解原型必须记住的三条等式：

```js
function Person(name) {
  this.name = name;
}
const p = new Person('ximingx');

console.log(p.__proto__ === Person.prototype); // ① 实例隐式原型 === 构造函数显式原型
console.log(Person.prototype.constructor === Person); // ② 原型的 constructor 指回构造函数
console.log(p.constructor === Person); // ③ 实例自身没有 constructor，沿原型链读到
```

> `constructor` 可被改写。若用 `Person.prototype = { ... }` 整体覆盖原型对象，`constructor` 会丢失（变成指向 Object），必须手动补回。

#### 原型链的终点

```js
function Foo() {}
const f = new Foo();
console.log(f.__proto__ === Foo.prototype); // true
console.log(Foo.prototype.__proto__ === Object.prototype); // true
console.log(Object.prototype.__proto__); // null（原型链终点）
```

完整的查找路径是 `f → Foo.prototype → Object.prototype → null`。此外，所有函数都是 `Function` 的实例，`Function` 自己也是自己的实例。

### 构造函数与面向对象

#### 构造函数

**构造函数**是一种特殊函数，用来创建和初始化对象，必须与 `new` 一起使用才有意义。它和普通函数在创建方式上没有区别，只是习惯上**首字母大写**，且调用方式不同（需用 `new`）。

`new` 一个构造函数的执行流程：

1. 开辟内存空间，创建新的空对象。
2. 让 `this` 指向这个新对象。
3. 执行构造函数体，为新对象添加属性和方法。
4. 返回这个新对象（因此构造函数里不需要写 `return`）。

#### 静态成员与实例成员

- **静态成员**：在构造函数本身上添加的成员，只能由构造函数本身访问。
- **实例成员**：在构造函数内部 `this` 上添加的成员，只能由实例对象访问。

#### instanceof

`对象 instanceof 构造函数` 检查对象是否为某类的实例，返回布尔值。所有对象都是 `Object` 的后代，所以 `任何对象 instanceof Object` 都为 true。

#### 面向过程与面向对象

- **面向过程**：分析步骤，按步骤解决问题；性能较高，适合与硬件联系紧密的场景。
- **面向对象**：以对象功能划分问题，具有封装、继承、多态三大特性；易维护、易复用、易扩展，适合大型软件项目，但性能略低。

JS 的面向对象是基于**原型**的面向对象，ES6 引入的 `class` 和 `extends` 是其语法糖。

### 继承的演进

JS 没有真正的类继承，`class` 只是语法糖，可用原型模拟继承。由浅入深有六种方案：

#### 方式一：原型链继承

把子类的原型替换成父类的实例。

```js
Child.prototype = new Parent();
Child.prototype.constructor = Child; // 补回 constructor
```

两个致命缺点：引用类型属性被所有实例**共享**；创建子类实例时**无法向父类传参**。

#### 方式二：借用构造函数继承

在子类构造函数内部用 `call`/`apply` 调用父类构造函数。

```js
function Child(name, age) {
  Parent.call(this, name);
  this.age = age;
}
```

解决了共享与传参问题，但**继承不到父类原型上的方法**。

#### 方式三：组合继承

原型链继承（拿方法）+ 借用构造函数继承（拿属性），两者结合。缺点是**父类构造函数被调用了两次**。

#### 方式四：原型式继承与 Object.create

不定义构造函数，直接基于已有对象创建新对象：

```js
const child = Object.create(parent); // child.__proto__ === parent
```

`Object.create(null)` 创建的是无原型对象。这种方式同样存在引用类型共享的问题。

#### 方式五：寄生组合式继承（最优）

用 `Object.create()` 代替 `new Parent()` 建立原型链，避免父类构造函数被调用两次：

```js
Child.prototype = Object.create(Parent.prototype);
Child.prototype.constructor = Child;
```

这是最优方案，也是 ES6 `class` 的底层实现原理。

#### 方式六：ES6 class 与 extends

```js
class Child extends Parent {
  constructor(name, age) {
    super(name); // 必须先调用 super 才能使用 this
    this.age = age;
  }
}
```

class 与普通构造函数的重要区别：

- class 不存在变量提升，有暂时性死区。
- 必须用 `new` 调用，直接调用会报错。
- class 内部默认是严格模式。
- class 的方法不可枚举。
- class 的所有方法都没有 `prototype` 属性。
- 子类必须在 `constructor` 里先调用 `super()` 才能使用 `this`。

### this 的指向

#### 函数内 this 的指向

根据调用方式的不同，`this` 指向不同对象：

- 以**函数形式**调用（普通函数、定时器、立即执行函数）时，非严格模式下 `this` 是 `window`。
- 以**方法形式**调用时，`this` 是调用方法的那个对象。
- 以**构造函数形式**调用时，`this` 是实例对象。
- 以**事件绑定函数**调用时，`this` 是绑定事件的对象。
- 使用 `call`/`apply`/`bind` 调用时，`this` 是指定的对象。

> 严格模式下的例外：若开启 `"use strict"`，独立函数调用时 `this` 是 `undefined`（不再是 window）。定时器回调在浏览器中恒为 `window`。

#### 箭头函数中 this 的指向

箭头函数**不会**遵循上面的规则，而是**继承外层作用域的 `this`**（在定义时就确定），且 `call`/`apply`/`bind` 无法改变它。

### 改变 this 指向：call、apply、bind

#### call 方法

`call` 可以**调用**函数，同时改变函数内部的 `this` 指向：

```js
fn.call(thisArg, 实参1, 实参2);
```

第一个参数指定 `this` 指向，不需要改变时传 `null`。`call` 还能实现继承：在子类构造函数中 `Parent.call(this, ...)` 继承父类属性。

> 注意：`Parent.call(this, name)` 里等号左边是 `this.name`（决定属性名），等号右边才是形参名。

#### apply 方法

`apply` 与 `call` 作用相同，唯一区别是 `apply` 的实参必须**以数组（或类数组）形式**传入：

```js
fn.apply(thisArg, [实参1, 实参2]);
```

巧妙应用：借助 `Math.max.apply(null, arr)` 求数组最大值。

#### bind 方法

`bind` **不会调用**函数，但会改变函数内部的 `this` 指向，并返回一个新函数：

```js
const newFn = fn.bind(thisArg, 实参1, 实参2);
```

适合需要改变 `this` 但又不想立即调用的场景，实际开发中使用最频繁。

### 闭包的引入

变量根据作用域分为全局变量和局部变量：函数外部无法访问函数内部的局部变量。若想在函数外部访问函数内部的局部变量，就需要用到闭包。

**闭包**：指有权访问另一个函数作用域中变量的**函数**。当一个函数可以访问另一个函数内部的局部变量时，就产生了闭包，那个外部函数称为闭包函数。

```js
function fn1() {
  let a = 20;
  return function () {
    console.log(a);
  };
}
const foo = fn1();
foo(); // 20
```

闭包的主要作用是**延伸变量的作用范围**：由于内层函数仍引用外层变量，外层函数的局部变量不会立即销毁，直到不再被引用才会被回收。
