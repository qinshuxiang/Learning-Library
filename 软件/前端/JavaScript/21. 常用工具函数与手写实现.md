## 常用工具函数与手写实现

### 类型判断

#### 手写 instanceof

**`instanceof`**：判断对象是否是某构造函数的实例，其原理是**沿原型链查找**构造函数的 `prototype`。

```js
function myInstanceof(instance, constructor) {
  // 获取实例的原型
  let proto = Object.getPrototypeOf(instance);
  const prototype = constructor.prototype;

  while (proto) {
    if (proto === prototype) return true; // 找到
    proto = Object.getPrototypeOf(proto); // 继续向上
  }
  return false;
}

console.log(myInstanceof([], Array));  // true
console.log(myInstanceof({}, Array));  // false
```

> `instanceof` 的本质：**沿着 `__proto__`（原型链）一直向上找，看能否找到构造函数的 `prototype`**。手写它需要理解原型链——这也解释了为什么 `[] instanceof Object` 也是 `true`（数组原型链顶端是 `Object.prototype`）。



#### 完整的类型判断函数

结合 `typeof` 与 `Object.prototype.toString`，写一个能准确判断所有类型的函数。

```js
function getType(value) {
  // Object.prototype.toString 返回 "[object Xxx]"
  const raw = Object.prototype.toString.call(value);
  return raw.slice(8, -1).toLowerCase();
}

console.log(getType([]));        // "array"
console.log(getType({}));        // "object"
console.log(getType(null));      // "null"
console.log(getType(new Date())); // "date"
console.log(getType(() => {}));  // "function"
```

> `Object.prototype.toString.call(value)` 是**最精确**的类型判断手段，能区分 `typeof` 搞不定的 `null`、数组、`Date` 等。手写 `getType` 时，通过 `slice(8, -1)` 截取 `[object Xxx]` 中间的类型名即可。



### 深浅拷贝

#### 浅拷贝的方式

**浅拷贝（Shallow Copy）**：只复制**第一层**，嵌套的对象仍**共享引用**。常见实现方式有多种。

```js
const original = { a: 1, b: { c: 2 } };

// 方式一：展开语法
const copy1 = { ...original };

// 方式二：Object.assign
const copy2 = Object.assign({}, original);

// 方式三：数组用 slice
const arr = [1, { x: 2 }];
const arrCopy = arr.slice();
```

> 浅拷贝的关键特征：**第一层是独立的，但嵌套对象仍指向原对象**。`copy1.b === original.b` 为 `true`，改 `copy1.b.c` 会影响 `original`。浅拷贝只够处理"单层对象"，有嵌套时需深拷贝。



#### 深拷贝：JSON 与递归实现

**深拷贝（Deep Copy）**：递归复制**所有层级**，拷贝结果与原对象**完全独立**。

```js
// 方式一：JSON（有局限，见第 7 章）
function deepCloneByJSON(obj) {
  return JSON.parse(JSON.stringify(obj));
}

// 方式二：递归实现
function deepClone(obj) {
  if (obj === null || typeof obj !== "object") {
    return obj; // 基本类型直接返回
  }
  const result = Array.isArray(obj) ? [] : {};
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      result[key] = deepClone(obj[key]); // 递归拷贝
    }
  }
  return result;
}

const original = { a: 1, b: { c: 2 } };
const copy = deepClone(original);
copy.b.c = 99;
console.log(original.b.c); // 2（原对象不受影响）
```

> 递归深拷贝的核心是"**基本类型直接返回，对象则递归处理每个属性**"。它解决了 JSON 方案"丢函数、丢 Date、不处理循环引用"的问题，但纯递归版仍需注意循环引用（见下一节）。



#### 循环引用与 structuredClone()

递归深拷贝会遇到**循环引用**导致栈溢出，现代方案用 `structuredClone` 解决。

```js
// 循环引用对象
const obj = { name: "why" };
obj.self = obj; // 自己引用自己

// structuredClone 原生深拷贝，能处理循环引用
const copy = structuredClone(obj);
console.log(copy.self === copy); // true（正确处理循环引用）

// 也支持 Date、Map、Set 等
const complex = { date: new Date(), map: new Map([["a", 1]]) };
const complexCopy = structuredClone(complex);
console.log(complexCopy.map.get("a")); // 1
```

> **`structuredClone()`** 是 ES2021 引入的**原生深拷贝**，能正确处理循环引用、`Date`、`Map`、`Set`、`ArrayBuffer` 等 JSON 搞不定的类型。它不能拷贝**函数**（会抛错），是普通深拷贝的首选；需拷贝函数时再退回手写递归。



### 防抖与节流

#### 防抖 debounce

**防抖（Debounce）**：在事件**连续触发**时，只在**最后一次触发后等待一段时间**才执行，用于"等用户停下再执行"。

```js
function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);            // 清除上一次的定时器
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 应用：输入框搜索
const handleInput = debounce(() => {
  console.log("执行搜索");
}, 500);

// 连续输入时，只在停止输入 500ms 后执行一次
```

> 防抖的核心是"**每次触发都重置定时器**"：只要还在触发，就不执行；停止触发 `delay` 后才执行。它适合**搜索框输入、窗口 resize、表单校验**等"等操作结束再响应"的场景。



#### 节流 throttle

**节流（Throttle）**：在**固定时间间隔**内只执行**一次**，用于"控制执行频率"。

```js
function throttle(fn, interval) {
  let lastTime = 0;
  return function (...args) {
    const now = Date.now();
    if (now - lastTime >= interval) {
      fn.apply(this, args);
      lastTime = now;
    }
  };
}

// 应用：滚动监听
const handleScroll = throttle(() => {
  console.log("执行（每 200ms 最多一次）");
}, 200);
```

> 节流的核心是"**时间戳判断**"：距离上次执行超过 `interval` 才允许再执行。它适合**滚动、拖拽、鼠标移动**等高频触发、需控制频率的场景。



#### 防抖与节流的应用场景

防抖与节流的**区别**在于执行策略，选型取决于需求。

- **防抖**：**停止触发后才执行一次**——适合"**等用户操作结束**"（搜索输入、resize 后重绘）。
- **节流**：**固定频率持续执行**——适合"**过程中持续响应**"（滚动加载、拖拽跟随）。

```js
// 防抖：搜索框（等输入停止）
const search = debounce((kw) => console.log("搜：" + kw), 300);

// 节流：滚动加载更多（滚动中持续判断）
const loadMore = throttle(() => console.log("加载更多"), 200);
```

> 记忆口诀：**"防抖是等停下，节流是控频率"**。一个判断方法——如果需求是"**最后做一次**"就用防抖，是"**过程中隔段时间做一次**"就用节流。二者本质都是**用闭包保存定时器/时间戳状态**来限制执行。



### 数组常用操作

#### 数组去重

数组去重有多种实现，从传统到现代层层递进。

```js
const arr = [1, 2, 2, 3, 3, 3, 4];

// 方式一：Set（最简洁）
const unique1 = [...new Set(arr)];
console.log(unique1); // [1, 2, 3, 4]

// 方式二：filter + indexOf
const unique2 = arr.filter((item, index) => arr.indexOf(item) === index);

// 方式三：reduce
const unique3 = arr.reduce((acc, cur) => {
  if (!acc.includes(cur)) acc.push(cur);
  return acc;
}, []);
```

> `Set` 是去重**首选**（简洁、高效），但它用 `===` 比较、**无法区分对象**（两个相同内容的对象视为不同）。去重"对象数组"时需按某个字段（如 id）去重，需配合 `Map` 或 `filter` + 字段判断。



#### 数组扁平化

**扁平化**：把嵌套数组展开为一维数组。

```js
const nested = [1, [2, [3, [4]]]];

// 方式一：flat（指定深度，Infinity 全展开）
console.log(nested.flat(Infinity)); // [1, 2, 3, 4]

// 方式二：递归实现
function flatten(arr) {
  let result = [];
  for (const item of arr) {
    if (Array.isArray(item)) {
      result = result.concat(flatten(item)); // 递归展开
    } else {
      result.push(item);
    }
  }
  return result;
}
console.log(flatten(nested)); // [1, 2, 3, 4]
```

> 扁平化的核心是"**遇到数组就递归展开，否则收集元素**"。原生 `flat(depth)` 是最简方案（`flat(Infinity)` 全展开），手写递归则帮助理解"分治"思想。



#### 最大值、最小值与乱序

数组的极值、乱序等常见操作。

```js
const nums = [3, 1, 4, 1, 5, 9, 2];

// 最大值、最小值
const max = Math.max(...nums);
const min = Math.min(...nums);
console.log(max, min); // 9 1

// 用 reduce 求最大
const maxByReduce = nums.reduce((a, b) => (a > b ? a : b));

// 乱序（Fisher-Yates 洗牌）
function shuffle(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  return arr;
}
console.log(shuffle([...nums]));
```

> 求极值用 `Math.max(...arr)` 最简洁；**乱序推荐 Fisher-Yates 洗牌**（从后往前随机交换），它保证**均匀分布**。用 `sort(() => Math.random() - 0.5)` 洗牌**不均匀**，应避免。



### 其他工具函数

#### 惰性函数

**惰性函数（Lazy Function）**：在**首次调用时**做一次判断，之后**重写自身**，后续调用直接走正确分支，避免重复判断。

```js
function getEvent() {
  if (window.addEventListener) {
    // 首次调用后重写自己
    getEvent = function (el, type, fn) {
      el.addEventListener(type, fn);
    };
  } else {
    getEvent = function (el, type, fn) {
      el.attachEvent("on" + type, fn);
    };
  }
  return getEvent.apply(this, arguments);
}
```

> 惰性函数的核心是"**判断一次、缓存结果**"：首次调用时做兼容性判断并**重写函数本身**，之后调用不再判断，直接执行正确分支。适合**只需判断一次**的环境检测、兼容性处理场景。



#### 函数记忆 memoize

**记忆化（Memoize）**：缓存函数的**计算结果**，相同输入直接返回缓存，避免重复计算（尤其适合纯函数）。

```js
function memoize(fn) {
  const cache = new Map();
  return function (...args) {
    const key = JSON.stringify(args); // 用参数做缓存键
    if (cache.has(key)) {
      return cache.get(key); // 命中缓存
    }
    const result = fn.apply(this, args);
    cache.set(key, result);  // 存入缓存
    return result;
  };
}

// 应用：缓存斐波那契，避免重复计算
const fib = memoize((n) => (n <= 1 ? n : fib(n - 1) + fib(n - 2)));
console.log(fib(40)); // 快速得出结果
```

> 记忆化适合**纯函数 + 重复计算**的场景（如斐波那契、递归、昂贵计算）。用 `Map` + 参数序列化作键，命中缓存直接返回。它把 O(2^n) 的斐波那契优化到近似 O(n)，是"以空间换时间"的典范。



#### 偏函数 partial

**偏函数（Partial）**：**固定部分参数**，生成一个**参数更少**的新函数，是柯里化的"简化版"。

```js
function partial(fn, ...presetArgs) {
  return function (...args) {
    return fn.apply(this, [...presetArgs, ...args]);
  };
}

function add(a, b, c) {
  return a + b + c;
}

const addFive = partial(add, 5); // 固定第一个参数为 5
console.log(addFive(1, 2));      // 8（5 + 1 + 2）
```

> 偏函数与柯里化的区别：柯里化是**逐个参数**生成函数链，偏函数是**一次固定多个参数**。偏函数更"宽松"，适合"**先绑定前面几个参数**、后面参数稍后传入"的场景。



#### 判断两个对象相等

判断两个对象是否"**内容相等**"（而非引用相等），需递归比较。

```js
function isEqual(objA, objB) {
  // 引用相同或基本类型严格相等
  if (objA === objB) return true;
  // 类型不同或非对象
  if (typeof objA !== "object" || typeof objB !== "object") return false;
  if (objA === null || objB === null) return false;

  const keysA = Object.keys(objA);
  const keysB = Object.keys(objB);
  if (keysA.length !== keysB.length) return false; // 键数量不同

  // 递归比较每个键
  for (const key of keysA) {
    if (!keysB.includes(key)) return false;
    if (!isEqual(objA[key], objB[key])) return false;
  }
  return true;
}

console.log(isEqual({ a: 1, b: { c: 2 } }, { a: 1, b: { c: 2 } })); // true
console.log(isEqual({ a: 1 }, { a: 2 })); // false
```

> 判断对象相等要注意：`===` 只判断**引用**（两个独立对象即使内容相同也不相等），内容比较需**递归**。手写 `isEqual` 的思路是"**先比引用、再比类型、最后递归比键值**"，与深拷贝的思路一脉相承。
