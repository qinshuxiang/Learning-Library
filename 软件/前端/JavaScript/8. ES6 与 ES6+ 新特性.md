## ES6 与 ES6+ 新特性

### Symbol

#### 概述

ES5 中对象的属性名都是字符串，容易重名。ES6 引入了新的原始数据类型 **Symbol**，表示独一无二的值，用于解决命名冲突。它是 JavaScript 的第七种数据类型，前六种是 undefined、null、布尔值、字符串、数值、对象。

特点：

- Symbol 属性的值是唯一的。
- Symbol 值不能与其他数据进行运算，包括与字符串拼接。
- `for...in`、`for...of` 遍历时不会遍历 Symbol 属性。

#### 创建 Symbol

`Symbol` 是函数，但**不是构造函数**（不能用 `new`）。

```js
let mySymbol = Symbol();
console.log(typeof mySymbol); // symbol
```

可在括号里传参作为**标识**（仅用于区分，不影响唯一性）：

```js
let s1 = Symbol('one');
let s2 = Symbol('two');
console.log(s1 === s2); // false
```

#### 将 Symbol 作为对象属性

添加 Symbol 属性时不能用 `.`，要用方括号：

```js
let obj = {};
let mySymbol = Symbol();
obj[mySymbol] = 'hello';
```

Symbol 也常用于定义常量：`const MY_NAME = Symbol('my_name')`。

#### 内置 Symbol 值

ES6 提供了多个内置 Symbol 值，指向语言内部使用的方法，常见的有：

- `Symbol.iterator`：对象的默认遍历器方法（被 `for...of`、扩展运算符触发）。
- `Symbol.asyncIterator`：`for await...of`（ES2018）。
- `Symbol.hasInstance`：`instanceof` 运算符。
- `Symbol.toPrimitive`：对象转原始值。
- `Symbol.toStringTag`：`Object.prototype.toString.call()` 的标签。
- `Symbol.species`：派生对象的构造函数。

### 解构赋值

#### 数组解构

```js
const [a, b, ...rest] = [1, 2, 3, 4];
console.log(a, b, rest); // 1 2 [3, 4]

// 交换变量
let x = 1, y = 2;
[x, y] = [y, x];

// 默认值（仅当对应位置 === undefined 时生效）
const [p = 10] = [null];
console.log(p); // null（不是 10）
```

#### 对象解构

```js
const user = { name: 'ximingx', age: 18 };
const { name, age } = user; // 基本解构
const { name: userName } = user; // 重命名
const { gender = 'unknown' } = user; // 默认值
const { name: n, ...others } = user; // 剩余属性
```

> 嵌套解构的坑：若中间层是 `undefined`，会直接报错，稳妥写法是给中间层加默认值。

#### 函数参数解构

```js
function connect({ host = 'localhost', port = 3306 } = {}) {
  console.log(host, port);
}
connect(); // localhost 3306
```

> 末尾的 `= {}` 不能省，否则不传参时会因对 `undefined` 解构而报错。

### 模板字符串与标签模板

模板字符串用反引号定义，支持多行和 `${}` 插值（`${}` 里可以是任意表达式）。

**标签模板**：在模板字符串前写函数名，函数会以「字符串数组 + 各插值」的形式被调用，可用于实现防 XSS 的 HTML 转义。

### 箭头函数

#### 语法简写

```js
const fn1 = (a, b) => a + b; // 单表达式省略 {} 和 return
const fn2 = a => a * 2; // 单参数省略括号
const fn3 = () => ({ name: 'x' }); // 返回对象需用小括号包住
```

#### 与普通函数的区别

- `this` 指向：普通函数在**调用时**决定，箭头函数在**定义时**继承外层作用域，且 `call`/`apply`/`bind` 改不了。
- 箭头函数不能 `new`，没有 `prototype`，没有 `arguments`（用 `...rest` 代替），不能作 Generator。
- 箭头函数不适合作为对象方法（`this` 会指向外层）。

箭头函数的主要用途是**避免 this 陷阱**：在定时器等回调里，箭头函数的 `this` 自动继承外层。

### 对象字面量的增强

```js
const name = 'ximingx';
const obj = {
  name, // ① 属性简写
  sayHi() {}, // ② 方法简写
  ['user_' + name]: true, // ③ 计算属性名
  get info() { return name; }, // ④ getter/setter 简写
};
```

### 可选链与空值合并（ES2020）

**可选链 `?.`**：链上任一环为 `null` 或 `undefined` 时短路返回 `undefined`，不报错。

```js
const city = user?.address?.city;
```

**空值合并 `??`**：仅当值为 `null` 或 `undefined` 时才取默认值。

> `??` 与 `||` 的区别：`||` 对所有假值（`0`、`''`、`false`、`NaN`）都生效，`??` 只对 `null` 和 `undefined` 生效。如 `0 ?? 5` 得到 `0`，而 `0 || 5` 得到 `5`。

### Module 模块化

#### 导出（export）

- 命名导出：`export const name = 'x';` 或 `export { name }`。
- 导出重命名：`export { age as userAge }`。
- 默认导出：`export default { ... }`（一个模块只能有一个）。
- 转发导出：`export * from './other.js'`。

#### 导入（import）

- 导入命名导出：`import { name } from './user.js'`（名字必须一致）。
- 导入默认导出：`import user from './user.js'`（名字随便起）。
- 整体导入：`import * as M from './user.js'`。
- 只执行模块：`import './polyfill.js'`。

#### 动态 import()

静态 `import` 必须在顶层；动态 `import()` 返回 Promise，可**按需加载**（路由懒加载的底层原理）：

```js
const { default: Chart } = await import('./chart.js');
```

#### 模块化的特点

1. 自动严格模式。
2. 模块作用域，顶层变量不挂到 `window`。
3. 单例：多次 import 只执行一次。
4. 静态分析，便于 Tree Shaking。
5. 输出的是**值的引用**（live binding），不是拷贝。

### Iterator 与 for...of

实现了 `Symbol.iterator` 方法的对象就是**可迭代对象**，该方法返回的迭代器必须有 `next()` 方法，返回 `{ value, done }`。原生可迭代对象有 Array、String、Map、Set、arguments、NodeList 等；**普通对象不可迭代**。

`for...of` 遍历的是**值**，`for...in` 遍历的是**键名**：

```js
const arr = ['a', 'b'];
for (const v of arr) console.log(v); // 'a' 'b'
for (const k in arr) console.log(k); // '0' '1'
```

> 不要对数组用 `for...in`：它会遍历原型链上的可枚举属性，不保证顺序。

### Set 与 Map

#### Set（集合）

值唯一的集合，使用 SameValueZero 判等（`NaN` 等于 `NaN`）。常用方法：`add`、`delete`、`has`、`clear`、`size`。最经典用途是数组去重与集合运算。

#### Map（字典）

与 Object 相比，**Map 的键可以是任意类型**（对象、函数、NaN 都行）。常用方法：`set`、`get`、`has`、`delete`、`clear`、`size`。

#### WeakSet 与 WeakMap

- 键（成员）只能是对象。
- 采用**弱引用**，不影响垃圾回收。
- 不能遍历，没有 `size` 和 `clear`。
- 典型用途：私有属性、缓存、DOM 关联数据。

### Proxy 与 Reflect

**Proxy** 在目标对象前架设拦截层，对读写等操作进行自定义：

```js
const proxy = new Proxy(target, handler);
```

常用拦截方法：`get`（读属性）、`set`（设属性）、`has`（`in` 运算符）、`deleteProperty`（`delete`）、`ownKeys`（`Object.keys`）、`apply`（函数调用）、`construct`（`new`）。

**Reflect** 提供了与 Proxy 拦截方法一一对应的方法，把 `Object` 上的命令式操作函数化，并让返回值更合理（如 `Reflect.defineProperty` 失败返回 `false` 而不是抛错）。

### ES2016 ~ ES2025 新特性速览

- **ES2016**：`Array.prototype.includes()`、指数运算符 `**`。
- **ES2017**：`async/await`、`Object.values()`、`Object.entries()`、`String.padStart()`/`padEnd()`。
- **ES2018**：对象扩展运算符 `{ ...obj }`、`Promise.prototype.finally()`、正则命名捕获组。
- **ES2019**：`Array.flat()`/`flatMap()`、`Object.fromEntries()`、`String.trimStart()`/`trimEnd()`。
- **ES2020**：可选链 `?.`、空值合并 `??`、`Promise.allSettled()`、`BigInt`、`globalThis`、动态 `import()`。
- **ES2021**：`String.replaceAll()`、`Promise.any()`、逻辑赋值运算符 `&&=`/`||=`/`??=`、数值分隔符。
- **ES2022**：class 私有字段 `#field`、`Array.prototype.at()`、`Object.hasOwn()`、顶层 `await`。
- **ES2023**：`findLast()`/`findLastIndex()`、不可变数组方法 `toSorted()` 等。
- **ES2024**：`Object.groupBy()`、`Promise.withResolvers()`。
- **ES2025**：Set 集合方法（`union`/`intersection`/`difference`）、`Promise.try()`、`RegExp.escape()`。

> ES2015（即 ES6）之后，标准改为每年发布一次，并以年份命名。

### 将 ES6 转为 ES5（Babel）

若需兼容低版本浏览器，可用 **Babel** 把 ES6 代码转为 ES5：

1. `npm init -y` 初始化项目。
2. `npm install --save-dev babel-cli` 安装。
3. 新建 `.babelrc`，配置预设。
4. 执行 `babel src/index.js -o dist/index.js` 完成转换。
