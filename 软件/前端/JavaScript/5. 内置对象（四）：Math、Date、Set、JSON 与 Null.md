## 内置对象（四）：Math、Date、Set、JSON 与 Null

### Math

Math 是内置对象，提供数学计算相关的常量与方法。**Math 不是构造函数，不需要实例化**，直接通过 `Math.方法名()` 调用。

**常用常量**：

- `Math.PI`：圆周率 π。
- `Math.E`：自然对数的底数 e。

**取整相关**：

- `Math.ceil(x)`：向上取整。
- `Math.floor(x)`：向下取整。
- `Math.round(x)`：四舍五入。
- `Math.trunc(x)`：直接截断小数部分（ES6 新增）。

**最值**：

- `Math.max(a, b, ...)`：取最大值。
- `Math.min(a, b, ...)`：取最小值。

**幂、开方与绝对值**：

- `Math.pow(x, y)`：x 的 y 次幂。
- `Math.sqrt(x)`：平方根。
- `Math.abs(x)`：绝对值。

**随机数**：

`Math.random()` 返回 `[0, 1)` 之间的随机小数。生成 `[min, max]` 之间的随机整数：

```js
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
```

> 其他方法：`Math.sin()`、`Math.cos()`、`Math.tan()`（三角函数）、`Math.log()`（自然对数）、`Math.sign(x)`（符号：-1 / 0 / 1）、`Math.hypot()`（平方和的平方根）等。

### Date

Date 用于处理日期和时间。与 Math 不同，Date 是**构造函数**，需先 `new` 实例化才能使用。

#### 创建 Date 对象

- 不传参数时，返回系统当前时间对象。
- 传参时，返回指定时间对象，参数可以是字符串、多个数字或时间戳。

```js
const d1 = new Date();
const d2 = new Date('2020/02/17 21:00:00');
const d3 = new Date(2020, 2, 18); // 注意：月份从 0 开始，2 表示三月
const d4 = new Date(1591950413388); // 时间戳
```

> 用数字传参时，月份从 0 开始（0 表示一月），而日期从 1 开始。

#### 获取日期时间的方法

- `getFullYear()`：获取年份（4 位）。
- `getMonth()`：获取月份（0-11）。
- `getDate()`：获取日（1-31）。
- `getDay()`：获取星期（0-6，0 表示周日）。
- `getHours()`、`getMinutes()`、`getSeconds()`、`getMilliseconds()`：时分秒毫秒。
- `getTime()`：获取时间戳。

#### 设置日期时间的方法

`setFullYear()`、`setMonth()`、`setDate()`、`setHours()`、`setMinutes()`、`setSeconds()`、`setTime()` 等，都会直接修改原 Date 对象。

> `getYear()` / `setYear()` 已废弃，请用 `getFullYear()` / `setFullYear()`。

#### 时间戳

**时间戳**是从格林威治时间 `1970 年 1 月 1 日 0 时 0 分 0 秒` 到当前时刻所经过的**毫秒数**。计算机底层用时间戳统一时间的单位。获取时间戳的常用方式：

- `+new Date()` 或 `new Date().getTime()`（最常用）。
- `new Date().valueOf()`、`new Date() * 1`、`Number(new Date())`。
- `Date.now()` 直接获取当前时间戳。

### Set

Set 是 ES6 提供的数据结构，类似数组，但成员的值都是**唯一**的，可用于去重。Set 是构造函数，通过 `new Set()` 生成实例，可接收一个数组作为参数。

```js
const set = new Set([1, 2, 2, 3]);
console.log([...set]); // [1, 2, 3]
```

常用方法与属性：

- `add(item)`：添加元素。
- `delete(item)`：删除元素。
- `has(item)`：判断是否存在，返回布尔值。
- `clear()`：清空。
- `size`：获取元素个数。

### JSON

JSON 常用于本地存储或前后端数据交换，常用两个方法（ES5 提供）：

- `JSON.stringify(obj)`：把 JS 对象（数组）转为 JSON 字符串。
- `JSON.parse(json)`：把 JSON 字符串解析为 JS 对象（数组）。

我们通常说的「JSON 字符串」只有两种：JSON 对象、JSON 数组。`typeof json字符串` 的结果是 `string`。

### Null 与 Undefined

#### null：空对象

`null` 专门用来定义一个**空对象**。若想定义一个变量保存引用类型，但还没想好内容，可先初始化为 `null`。`null` 虽然是一个单独的数据类型，但相当于「地址为空的对象」。Null 类型的值只有一个，用 `typeof` 检查 `null` 会返回 `object`。

#### undefined：未定义类型

Undefined 类型的值只有一个，用 `typeof` 检查会返回 `undefined`。以下情况会得到 `undefined`：

- 变量已声明但未赋值。
- 变量未声明（未定义）时，`typeof` 检查返回 `undefined`（直接使用则报 ReferenceError）。
- 函数没有返回值时。
- 调用函数时未传参，对应形参为 `undefined`。

#### null 与 undefined 的区别

`null == undefined` 为 `true`，但 `null === undefined` 为 `false`。与数字运算时：

- `10 + null` 结果为 `10`（null 被看作 0）。
- `10 + undefined` 结果为 `NaN`（只要有 undefined 参与就是 NaN）。

> 上述规律只适用于**数值运算**；若是字符串拼接（`+` 且一方是字符串），则不适用，如 `'a' + null` 得到 `'anull'`。
