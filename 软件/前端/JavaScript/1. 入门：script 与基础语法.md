## 入门：script 与基础语法

### script 标签

`<script>` 标签用于在 HTML 中引入或内嵌 JavaScript 代码。它的几个重要特性如下：

- 脚本默认会**阻塞文档渲染**，浏览器会立即下载并执行该脚本（不带 defer 或 async 属性时）。
- `document.currentScript` 可以获取当前正在运行的脚本元素。
- 脚本默认按 `<script>` 标签出现的**顺序**执行。
- `<script>` 没有跨域限制，可以加载任何网站的脚本，与 `<img>` 类似，因此常被用来解决跨域问题（即 JSONP）。
- 当设置 `type="module"` 时，代码被识别为 ES6 模块，才能使用 `import` 和 `export`。
- 同时存在行内代码和 `src` 属性时，会**忽略行内代码**。

`<script>` 通常放在 `<head>` 中，但这样必须等全部脚本下载解析执行完毕才开始渲染页面；如果脚本较大，建议将其放在 `<body>` 的末尾，让页面先呈现，减少用户等待时间。

### async 属性

async 是 HTML5 的新特性，表示该脚本**不阻塞**文档解析，也不保证按顺序执行。浏览器只需在脚本下载完毕后再执行即可，不必阻塞渲染去等待它的下载与执行。

> 通过 `document.createElement('script')` 动态插入的脚本，默认就是异步的；若要改为同步，可设置 `script.async = false`，但这种方式会影响资源队列的优先级。

### defer 属性

带有 defer 的脚本同样会推迟执行、不阻塞文档解析，但会**保证在文档解析完毕后**、`DOMContentLoaded` 之前执行。即使脚本在解析过程中就已下载完成，浏览器也会推迟到解析结束后再执行。同时，多个带 defer 的脚本之间能保证执行顺序。

> async 与 defer 的区别：async 是「下载完就执行，不保证顺序」；defer 是「等文档解析完再执行，保证顺序」。

### 基础语法

- JavaScript 严格区分字母大小写。
- **标识符**由数字、字母、下划线、美元符组成，第一位不能是数字；严格来说还可包含 Unicode 字符（如中文变量名），但不推荐。
- 注释有两种形式：`// 单行注释` 与 `/* 多行注释 */`。
- 语句以分号结束；可以省略分号，但省略分号在部分情况下会出错。

### 严格模式

在脚本或函数体的**所有语句之前**放置 `"use strict"` 即可开启严格模式：

```js
"use strict";
var name = "Reeoo";
```

严格模式下的一些重要限制：

- 不允许使用未声明的变量。
- 不允许修改只读属性的值。
- 不允许修改不可扩展的对象。
- 不允许在一个对象字面量中多次定义同一属性。
- 不允许使用未来的保留字作标识符。
- 不允许使用八进制数字参数和转义字符。

### 变量声明

#### var 声明变量

- 声明但不赋值时，值为 `undefined`。
- 作用域是**函数作用域**。
- 在函数内声明的变量会成为该函数的局部变量。
- 在全局声明时会挂载到 `window` 对象上。
- 在函数内省略 var 直接赋值，会将其视为**全局变量**。
- 会**变量提升**：声明会被提升到函数作用域顶部。
- 允许重复声明。

#### let 声明变量

- 作用域是**块级作用域**。
- 不允许重复声明。
- 声明的变量不会提升，存在**暂时性死区**。
- 在全局声明时不会成为 `window` 对象的属性。

#### const 声明变量

- 声明时**必须初始化**。
- 不能修改基本数据类型的值，但可以修改引用数据类型（对象、数组）的属性或元素。
