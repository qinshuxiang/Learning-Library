## ES7 到 ES12 新特性

### ES7

#### includes 方法

**`Array.prototype.includes(value)`**（ES7）：判断数组是否**包含**某元素，返回布尔值，弥补了 `indexOf` 的语义缺陷。

```js
const arr = [1, 2, 3, NaN];

console.log(arr.includes(2));   // true
console.log(arr.includes(NaN)); // true（indexOf 找不到 NaN）
console.log(arr.includes(99));  // false
```

> `includes` 相比 `indexOf` 的两大优势：一是**语义清晰**（返回布尔而非索引）；二是**能正确识别 `NaN`**（`indexOf` 因 `NaN !== NaN` 而找不到）。判断"是否存在"优先用 `includes`。



#### 指数运算符

**指数运算符 `**`**（ES7）：计算幂，等价于 `Math.pow()`。

```js
console.log(2 ** 3);        // 8
console.log(2 ** 10);       // 1024
console.log(2 ** 3 ** 2);   // 512（右结合：2 ** (3 ** 2)）

console.log(Math.pow(2, 3)); // 8（等价）
```

> `**` 运算符是**右结合**的：`2 ** 3 ** 2` 等于 `2 ** (3 ** 2)` = 512，而非 `(2 ** 3) ** 2`。它比 `Math.pow` 更简洁、可读性更好。



### ES8

#### values 与 entries

**`Object.values()`** 与 **`Object.entries()`**（ES8）：遍历对象的**值**与**键值对**。

```js
const obj = { a: 1, b: 2, c: 3 };

console.log(Object.values(obj));  // [1, 2, 3]
console.log(Object.entries(obj)); // [["a", 1], ["b", 2], ["c", 3]]

// entries 配合 for-of 遍历
for (const [key, value] of Object.entries(obj)) {
  console.log(key, value);
}
```

> `Object.values` 返回值的数组，`Object.entries` 返回键值对数组。它们弥补了 ES5 只有 `Object.keys` 的不足，让对象遍历更方便。



#### padStart 与 padEnd

**`padStart()` / `padEnd()`**（ES8）：在字符串**开头/结尾**填充至指定长度。

```js
console.log("5".padStart(3, "0"));   // "005"
console.log("5".padEnd(3, "0"));     // "500"
console.log("hello".padStart(10));   // "     hello"
```

> 补零是典型场景（生成编号 `001`、`002`、时间补零）。`padStart` 在开头填、`padEnd` 在结尾填，第二个参数是填充字符串（默认空格）。



#### Object.getOwnPropertyDescriptors()

**`Object.getOwnPropertyDescriptors(obj)`**（ES8）：一次性获取对象**所有自身属性的描述符**。

```js
const obj = { a: 1, b: 2 };
const descriptors = Object.getOwnPropertyDescriptors(obj);

console.log(descriptors.a); // { value: 1, writable: true, ... }
```

> 它与 `getOwnPropertyDescriptor`（单个）相对，是**批量获取**所有属性描述符。常用于**完整拷贝属性特性**（配合 `Object.create` 或 `defineProperties`）。



#### 函数参数的尾逗号

**函数参数尾逗号**（ES8）：允许在**最后一个参数后**加逗号。

```js
function foo(
  a,
  b,
  c, // 尾逗号，合法
) {
  return a + b + c;
}

console.log(foo(1, 2, 3)); // 6
```

> 尾逗号让"**增删参数**"更方便（改 Git diff 更干净——加参数只改一行）。数组、对象字面量早已支持尾逗号，ES8 把它扩展到函数参数。



### ES9

#### Promise.prototype.finally

**`Promise.prototype.finally()`**（ES9）：无论 Promise **成功还是失败**，都会执行的回调。

```js
fetch("/api/data")
  .then((res) => res.json())
  .catch((err) => console.error(err))
  .finally(() => {
    console.log("无论成败，都会执行（如关闭 loading）");
  });
```

> `finally` 用于"**无论如何都要执行**"的清理逻辑（关闭加载动画、释放资源），与成功失败无关。它返回的 Promise 会**透传**上一个 Promise 的结果。



#### 对象的 Rest 与 Spread 属性

**对象的 Rest/Spread**（ES9）：把数组已有的 `...` 语法扩展到对象。

```js
const obj = { a: 1, b: 2, c: 3 };

// Spread：展开/合并
const copy = { ...obj };            // 浅拷贝
const merged = { ...obj, d: 4 };    // { a:1, b:2, c:3, d:4 }

// Rest：收集剩余属性
const { a, ...rest } = obj;
console.log(rest); // { b: 2, c: 3 }
```

> 对象的 Rest/Spread 是**最常用的 ES9 特性**：`...obj` 用于浅拷贝、合并对象，`{ a, ...rest }` 用于**排除某属性**取剩余，二者在 React/Vue 中无处不在。



### ES10

#### flat 与 flatMap

**`flat(depth)` / `flatMap(fn)`**（ES10）：数组**扁平化**与"**映射 + 扁平化**"。

```js
const nested = [1, [2, [3]]];
console.log(nested.flat());        // [1, 2, [3]]
console.log(nested.flat(2));       // [1, 2, 3]
console.log(nested.flat(Infinity)); // [1, 2, 3]（全展开）

// flatMap：先 map 再 flat 一层
const arr = [1, 2, 3];
console.log(arr.flatMap((x) => [x, x * 2]));
// [1, 2, 2, 4, 3, 6]
```

> `flat` 展开嵌套数组（`depth` 指定深度，`Infinity` 全展开）；`flatMap` 等价于 `map` + `flat(1)`，适合"每个元素映射成数组再拍平"的场景。



#### fromEntries

**`Object.fromEntries()`**（ES10）：把**键值对数组**转为对象，是 `Object.entries` 的逆操作。

```js
const entries = [["a", 1], ["b", 2]];
const obj = Object.fromEntries(entries);
console.log(obj); // { a: 1, b: 2 }

// 常用：Map 转对象
const map = new Map([["x", 10], ["y", 20]]);
console.log(Object.fromEntries(map)); // { x: 10, y: 20 }
```

> `fromEntries` 是 `entries` 的**逆操作**。它常用于**Map 转对象**、**处理 URLSearchParams**（`Object.fromEntries(params)`）、以及配合 `entries` + `map` 做"遍历转换后重组对象"。



#### trimStart() 与 trimEnd()

**`trimStart()` / `trimEnd()`**（ES10）：分别去除**开头/结尾**的空白（`trim` 的细分版）。

```js
const str = "  hello  ";
console.log(str.trimStart()); // "hello  "
console.log(str.trimEnd());   // "  hello"
console.log(str.trim());      // "hello"
```

> `trimStart`/`trimEnd` 提供了**单侧去空格**的能力（`trim` 只能双侧）。它们原名为 `trimLeft`/`trimRight`，后被更语义化的 `trimStart`/`trimEnd` 取代（旧名仍可用作别名）。



#### Symbol.prototype.description

**`Symbol.prototype.description`**（ES10）：获取 Symbol 的**描述字符串**。

```js
const sym = Symbol("这是描述");
console.log(sym.description); // "这是描述"
```

> 之前获取 Symbol 描述要用 `String(sym)` 再截取，ES10 直接提供 `description` 属性。它只读，返回创建 Symbol 时传入的描述。



#### 可选的 catch 绑定

**可选的 catch 绑定**（ES10）：`catch` 可以**省略参数**（不需要异常对象时）。

```js
// 传统写法
try {
  throw new Error("出错了");
} catch (error) {
  console.log(error.message);
}

// ES10：省略 catch 参数
try {
  throw new Error("出错了");
} catch {
  console.log("忽略错误详情，只处理");
}
```

> 当 `catch` 里**不需要异常对象**时，可省略括号参数，代码更简洁。需要用到异常信息时，仍应写参数。



### ES11

#### BigInt 大整数类型

**`BigInt`**（ES11）：表示**任意精度**的整数，解决 `Number` 超出安全整数范围的问题。

```js
const big = 123456789012345678901234567890n; // 后缀 n
const big2 = BigInt("9007199254740993");

console.log(big + 1n); // BigInt 运算
console.log(9007199254740993n === BigInt(9007199254740993)); // true
```

> `Number` 的安全整数上限是 `2^53 - 1`，超出会**失真**；`BigInt` 支持**任意精度**。它用 `n` 后缀或 `BigInt()` 创建，**不能与 `Number` 混合运算**（需显式转换），用于大数 ID、精确计算等场景。



#### 空值合并运算符

**空值合并运算符 `??`**（ES11）：当值为 `null` 或 `undefined` 时返回**默认值**，比 `||` 更精确。

```js
const count = 0;
const name = "";

// || 会把 0、"" 等假值也替换
console.log(count || 10);  // 10（错误，0 是合法值）
console.log(name || "匿名"); // "匿名"

// ?? 只在 null/undefined 时兜底
console.log(count ?? 10);  // 0（正确）
console.log(name ?? "匿名"); // ""（正确）
console.log(null ?? "默认");  // "默认"
```

> `??` 与 `||` 的关键区别：`||` 把**所有假值**（`0`、`""`、`false`）都当"空"，`??` 只在 **`null`/`undefined`** 时兜底。需要"**保留 0、空字符串**"的场景，必须用 `??`。



#### 可选链

**可选链 `?.`**（ES11）：安全访问**可能为 `null`/`undefined`** 的属性，避免报错。

```js
const user = { info: { name: "why" } };
const empty = null;

// 传统写法：层层判断
const name1 = user && user.info && user.info.name;

// 可选链：安全访问
const name2 = user?.info?.name;
console.log(name2); // "why"

console.log(empty?.info?.name); // undefined（不报错）

// 也支持方法调用、数组索引
console.log(user?.getName?.());
console.log(arr?.[0]);
```

> 可选链 `?.` 在**访问到 `null`/`undefined` 时短路**、返回 `undefined`，替代了繁琐的 `&&` 链式判断。它极大提升了访问**嵌套属性**的安全性与可读性，是现代代码标配。



#### GlobalThis 与 for-in 标准化

- **`globalThis`**（ES11）：统一获取**全局对象**（浏览器 `window`、Node `global`）。
- **`for-in` 标准化**：规定了 `for-in` 的遍历顺序。

```js
// 浏览器中 globalThis === window
console.log(globalThis); // window（浏览器）或 global（Node）

// 跨环境获取全局对象的统一写法
const globalObj = globalThis;
```

> 之前获取全局对象在不同环境写法不一（浏览器 `window`、Node `global`、Worker `self`），`globalThis` 提供了**统一入口**，让跨环境代码更通用。



### ES12

#### FinalizationRegistry 与 WeakRef

- **`WeakRef`**：持有对象的**弱引用**，不阻止 GC。
- **`FinalizationRegistry`**：在对象被**回收时**执行回调。

```js
// WeakRef：弱引用对象
const ref = new WeakRef({ data: "大对象" });
// ref.deref() 获取对象（可能已被回收）

// FinalizationRegistry：回收时回调
const registry = new FinalizationRegistry((value) => {
  console.log("对象被回收了：", value);
});

let obj = { name: "temp" };
registry.register(obj, "obj 的标识");
obj = null; // 之后 GC 回收 obj 时会触发回调
```

> 这两个 API 用于**高级内存管理**：`WeakRef` 允许"**不阻止回收地引用对象**"，`FinalizationRegistry` 在对象被回收时**通知**。它们是**小众、底层**特性，日常业务很少直接使用。



#### 逻辑赋值运算符

**逻辑赋值运算符**（ES12）：把逻辑运算与赋值合并的简写。

- **`||=`**：值为假值时赋值。
- **`&&=`**：值为真值时赋值。
- **`??=`**：值为 `null`/`undefined` 时赋值。

```js
let a = 0;
a ||= 10;   // a 为假值(0)，赋值为 10 → a = 10
console.log(a); // 10

let b = 5;
b &&= 10;   // b 为真值(5)，赋值为 10 → b = 10
console.log(b); // 10

let c = null;
c ??= "默认"; // c 为 null，赋值为 "默认" → c = "默认"
console.log(c); // "默认"
```

> 三者是 `a = a || b` 等写法的简写：`||=` 对应 `||`、`&&=` 对应 `&&`、`??=` 对应 `??`。它们让"**条件赋值**"更简洁。



#### String.prototype.replaceAll

**`String.prototype.replaceAll()`**（ES12）：替换**所有**匹配，替代 `replace` 配全局正则。

```js
const str = "a-b-c";

console.log(str.replace("-", "|"));     // "a|b-c"（只替换第一个）
console.log(str.replaceAll("-", "|"));  // "a|b|c"（替换所有）
```

> `replace` 只替换**首个**匹配（除非配 `/g` 正则），`replaceAll` 直接替换**所有**。它让"全局替换"无需再写正则，语义更清晰。
