## 迭代器与生成器

### 迭代器

#### 迭代器协议

**迭代器（Iterator）**：是一个对象，实现**迭代器协议**——提供 `next()` 方法，返回 `{ value, done }`。

- **`next()`**：返回 `{ value: 当前值, done: 是否结束 }`。
- `done` 为 `true` 时表示迭代结束，此时 `value` 可选地携带迭代器的**返回值**（`for-of` 不消费它）。
- **`next()` 必须返回对象**：返回非对象值（如 `false`、`undefined`）会抛出 `TypeError: iterator.next() returned a non-object value`。

```js
const iterator = {
  current: 0,
  next() {
    this.current++;
    if (this.current <= 3) {
      return { value: this.current, done: false };
    }
    return { value: undefined, done: true };
  }
};

console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: 3, done: false }
console.log(iterator.next()); // { value: undefined, done: true }
```

> 迭代器协议的核心是"**`next()` 返回 `{ value, done }`**"。它把"遍历"抽象成一个**统一接口**，让各种数据结构（数组、Map、Set、字符串）都能用同一种方式遍历。



#### 生成迭代器的函数

可以写一个函数来**生成迭代器**，让遍历逻辑可复用。

```js
function createArrayIterator(arr) {
  let index = 0;
  return {
    next() {
      if (index < arr.length) {
        return { value: arr[index++], done: false };
      }
      return { value: undefined, done: true };
    }
  };
}

const it = createArrayIterator([1, 2, 3]);
console.log(it.next()); // { value: 1, done: false }
console.log(it.next()); // { value: 2, done: false }
```

> 用函数生成迭代器，把"**遍历逻辑**"封装起来，通过**闭包**保存遍历状态（`index`）。这是迭代器设计模式的典型实现。



#### 可迭代对象的理解与封装

**可迭代对象（Iterable）**：实现了 **`Symbol.iterator`** 方法、返回迭代器的对象，可被 `for-of`、展开语法遍历。

```js
const iterableObj = {
  data: [1, 2, 3],
  [Symbol.iterator]() {
    let index = 0;
    const data = this.data;
    return {
      next() {
        if (index < data.length) {
          return { value: data[index++], done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
};

for (const item of iterableObj) {
  console.log(item); // 1 2 3
}
```

> 可迭代对象的关键是 **`Symbol.iterator`** 方法。实现了它，对象就能被 `for-of`、`[...obj]`、解构等遍历。数组、字符串、Map、Set 都内置了它。



#### 可迭代对象的应用场景

可迭代对象让自定义数据结构**无缝接入** JavaScript 的遍历体系。

- **`for-of` 遍历**：直接遍历对象。
- **展开语法**：`[...obj]` 转数组。
- **解构赋值**：`const [a, b] = obj`。
- **传给接受可迭代对象的 API**：`Array.from`、`Promise.all` 等。

```js
const set = new Set([1, 2, 3]);

for (const item of set) console.log(item); // 1 2 3
console.log([...set]);                     // [1, 2, 3]
const [a, b] = set;                        // a=1, b=2
console.log(Array.from(set));              // [1, 2, 3]
```

> 可迭代协议让"**一切皆可遍历**"成为可能：只要实现 `Symbol.iterator`，自定义对象就能享受数组般的遍历便利。这是 JavaScript 迭代体系的统一基石。



#### 自定义类对象的可迭代性

给自定义的**类**实现可迭代性，让其实例可用 `for-of`。

```js
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        if (current <= end) {
          return { value: current++, done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
}

const range = new Range(1, 5);
for (const num of range) {
  console.log(num); // 1 2 3 4 5
}
```

> 自定义类实现 `[Symbol.iterator]` 后，其实例就能被遍历。这展示了可迭代协议的**扩展性**：任何"集合"语义的类，都能融入 JS 的遍历生态。



### 生成器

#### 生成器与生成器函数

**生成器函数（Generator Function）**：用 `function*` 声明的函数，返回**生成器对象**，可**暂停/恢复**执行。

```js
function* gen() {
  yield 1;
  yield 2;
  yield 3;
}

const generator = gen();
console.log(generator.next()); // { value: 1, done: false }
console.log(generator.next()); // { value: 2, done: false }
console.log(generator.next()); // { value: 3, done: false }
console.log(generator.next()); // { value: undefined, done: true }
```

> 生成器函数用 `function*` 声明，`yield` 关键字**暂停**执行并产出值。每次调用 `next()` 从上次暂停处**恢复**，直到遇到下一个 `yield` 或函数结束。它是**可控的暂停执行**。



#### 生成器函数的执行流程

生成器函数的执行是**断续**的：`next()` 驱动一段段执行。

```js
function* gen() {
  console.log("开始");
  const a = yield 1;   // 第一次 next 停在这
  console.log("a =", a);
  const b = yield 2;   // 第二次 next 停在这
  console.log("b =", b);
  return "结束";
}

const g = gen();
g.next();        // 开始（执行到 yield 1 停）
g.next("传给a"); // a = 传给a（yield 1 的返回值是传入的参数）
g.next("传给b"); // b = 传给b
```

> 关键理解：`yield` 的**返回值**是下一次 `next()` 传入的参数。`const a = yield 1` 中，`yield 1` 先产出 `1` 并暂停，下次 `next(value)` 时 `value` 作为 `yield` 的返回值赋给 `a`。这实现了**双向数据流**。



#### 生成器的其他方法调用

生成器对象除了 `next()`，还有 `return()` 和 `throw()`。

##### return() 方法

**`generator.return(value)`**：**提前终止**生成器，返回 `{ value, done: true }`。

```js
function* gen() {
  yield 1;
  yield 2;
  yield 3;
}

const g = gen();
console.log(g.next());       // { value: 1, done: false }
console.log(g.return("终止")); // { value: "终止", done: true }（提前结束）
console.log(g.next());       // { value: undefined, done: true }
```

> `return(value)` 让生成器**立即结束**，后续 `next()` 都返回 `done: true`。它用于"**提前终止迭代**"（如满足某条件后不再继续）。



##### throw() 方法

**`generator.throw(error)`**：在生成器**内部抛出错误**，可在生成器内用 `try/catch` 捕获。

```js
function* gen() {
  try {
    yield 1;
  } catch (err) {
    console.log("捕获到：", err);
  }
  yield 2;
}

const g = gen();
g.next();            // yield 1
g.throw("出错了");   // 捕获到：出错了（在 yield 1 处抛错）
console.log(g.next()); // { value: 2, done: false }
```

> `throw(error)` 在**上次暂停的位置**抛出错误，可被生成器内的 `try/catch` 捕获。它实现了"**从外部向生成器内部注入错误**"的能力。



#### 生成器迭代迭代器的写法

生成器可以用来**包装/简化**迭代器的写法。

```js
// 用生成器实现迭代器，更简洁
function* createIterator(arr) {
  for (const item of arr) {
    yield item;
  }
}

const it = createIterator([1, 2, 3]);
console.log(it.next()); // { value: 1, done: false }
```

> 生成器函数**自动实现迭代器协议**（返回的对象有 `next()`），因此用 `function*` + `yield` 写迭代器，比手写 `next()` 简洁得多。



### 异步迭代器

#### 异步迭代协议

**异步迭代器**：是 `next()` 返回 **Promise** 的迭代器，用于遍历**异步**数据源。

```js
const asyncIterator = {
  data: [1, 2, 3],
  index: 0,
  async next() {
    if (this.index < this.data.length) {
      return { value: this.data[this.index++], done: false };
    }
    return { value: undefined, done: true };
  }
};
```

> 异步迭代器的 `next()` 返回 Promise，`{ value, done }` 在异步完成后才可用。它用于**异步数据源**（如流式数据、分页接口）的遍历。



#### for await...of

**`for await...of`**：用于遍历**异步可迭代对象**，自动等待每个 `next()` 的 Promise。

```js
const asyncIterable = {
  async *[Symbol.asyncIterator]() {
    yield 1;
    yield 2;
    yield 3;
  }
};

(async () => {
  for await (const value of asyncIterable) {
    console.log(value); // 1 2 3（逐个异步取出）
  }
})();
```

> `for await...of` 是 `for-of` 的**异步版**：每次迭代等待 Promise 完成，再取 `value`。它只能在 `async` 函数内使用，是遍历异步数据流的标准方式。



#### 异步生成器

**异步生成器**：用 `async function*` 声明，可 `yield` 异步值（配合 `await`）。

```js
async function* asyncGen() {
  yield await Promise.resolve(1);
  yield await Promise.resolve(2);
  yield await Promise.resolve(3);
}

(async () => {
  for await (const value of asyncGen()) {
    console.log(value); // 1 2 3
  }
})();
```

> 异步生成器 `async function*` 结合了 `async`（可 `await`）和生成器（可 `yield`），适合**逐步产出异步结果**（如分页拉取、流式处理）。配合 `for await...of` 使用，是处理异步序列的利器。
