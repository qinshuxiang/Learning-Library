## 正则表达式

### 正则表达式的定义与作用

**正则表达式**用于定义字符串的规则。计算机可以根据它检查字符串是否符合规则，或提取字符串中符合规则的内容。

### 创建正则表达式对象

#### 方式一：构造函数

```js
let reg = new RegExp('正则表达式', '匹配模式');
```

参数都是字符串。使用 `typeof` 检查正则对象返回 `object`。`RegExp` 的意思是 Regular expression。

#### 方式二：字面量

```js
let reg = /正则表达式/匹配模式;
```

注意字面量写法中没有引号。字面量更简单，构造函数更灵活（参数可以是变量）。

### 匹配模式

创建正则时可传**匹配模式**作为标志：

- `i`：忽略大小写（ignore）。
- `g`：全局匹配（global）。

### test 方法

`reg.test(str)` 检查字符串是否符合规则，符合返回 `true`，否则返回 `false`。

```js
let reg = /X/i;
console.log(reg.test('ximingx')); // true
```

> 避坑：全局匹配 `g` 慎用 `test()`。带 `g` 的正则每次匹配成功后会把 `lastIndex` 设为上次匹配位置，下次从该位置继续，导致交替返回 true/false。`g` 一般用于 `exec()`、`match()`、`replace()` 等方法。

### 正则表达式的简单语法

- `a|b`：表示「或」，等价于 `[ab]`。
- `[a-z]`：任意小写字母；`[A-Z]`：任意大写字母；`[0-9]`：任意数字。
- `[A-Za-z]`：任意字母（`[A-z]` 范围是 ASCII 65~122，中间夹有非字母字符，不严谨）。
- `a[bde]c`：匹配 abc、adc、aec。
- `[^ab]`：表示「除了」，匹配除了 a、b 之外的字符。

```js
let reg = /[^0-9]/; // 除了数字之外的字符
console.log(reg.test('1991')); // false（纯数字）
console.log(reg.test('199a1')); // true
```

### 支持正则的 String 方法

#### split

`split(正则)` 按正则规则把字符串拆分为数组。

#### search

`search(正则)` 返回第一次匹配的索引，找不到返回 -1，大小写敏感，且只找第一个。

#### match

`match(正则)` 提取匹配内容；不带 `g` 只返回第一个，带 `g` 返回所有匹配组成的数组。

#### replace

`replace(正则, 新内容)` 替换匹配内容；不带 `g` 只替换第一个，带 `g` 替换全部，不修改原字符串。

```js
let str = 'Today is fine day,today is fine day';
console.log(str.replace(/today/gi, 'tomorrow')); // 替换所有 today
```

### 常见正则举例

#### 手机号

```js
let phoneReg = /^1[3-9][0-9]{9}$/;
```

规则：以 1 开头，第二位是 3~9，后面 9 位数字。同时使用 `^` 和 `$` 表示字符串必须完全匹配。

#### 去掉首尾空格

```js
str = str.replace(/^\s*|\s*$/g, '');
```

#### 邮箱

```js
let emailReg = /^\w{3,}(\.\w+)*@[A-Za-z0-9]+(\.[A-Za-z]{2,5}){1,2}$/;
```
