## 分支与循环

### 代码块与分支结构

#### 代码执行方式与代码块

JavaScript 代码默认按照**从上到下、从左到右**的顺序逐行执行，这是**顺序执行**。但真实程序需要"按条件走不同路径"，于是引入了**代码块**与**分支结构**。

**代码块（Block）**：是用一对花括号 `{}` 包裹的一组语句，作为一个整体执行，可用于聚合多条语句。它本身**不创建作用域**（`var` 声明的变量会泄漏出去，`let`/`const` 则会形成块级作用域）。

```js
// 顺序执行
console.log("第一行");
console.log("第二行");

// 代码块
{
  const message = "块内的变量";
  console.log(message);
}
// console.log(message); // 报错：let/const 是块级作用域
```

> 代码块最常见的用途是与 `if`、`for`、`while` 等搭配，作为"受控语句体"。单条语句可省略花括号，但**始终写花括号**是更安全、更规范的实践。



#### 分支结构

**分支结构**：是指程序根据**条件的真假**，选择执行不同代码路径的结构。它是程序从"一条道走到黑"走向"智能决策"的关键。

JavaScript 提供了三类分支语句：

- **`if` / `if-else` / `if-else if-else`**：最基础、最通用的条件判断。
- **三元运算符 `?:`**：`if-else` 的表达式级简写。
- **`switch`**：多分支的等值判断，结构更清晰。

```js
// if-else if-else 多分支
const score = 85;
if (score >= 90) {
  console.log("优秀");
} else if (score >= 60) {
  console.log("及格");
} else {
  console.log("不及格");
}
```

> 选择哪种分支结构要看场景：**两个分支**用 `if-else` 或三元；**多个互斥条件**用 `if-else if` 或 `switch`；**范围判断**只能用 `if-else if`（`switch` 只擅长等值匹配）。



### if 分支语句

#### if 语句

**`if` 语句**：是最基础的条件语句，**当条件为真时执行代码块**，条件为假则跳过。它是所有分支逻辑的起点。

- 条件表达式会先被隐式转换为布尔值（假值规则）。
- 条件为真才执行花括号内的语句。

```js
const age = 20;
if (age >= 18) {
  console.log("已成年，可以进入");
}
// 输出：已成年，可以进入

// 条件里可以是任意表达式，会自动转布尔
if (userName) {
  console.log("用户名存在");
}
```

> `if` 的条件里写"空字符串、0、null"等假值会被视为 `false`，这一隐式转换让"存在性判断"变得简洁，但也需注意 `0` 等合法假值被误判的边界情况。



#### if-else 语句

**`if-else` 语句**：在 `if` 基础上增加**否则分支**，条件为真走 `if` 块，为假走 `else` 块，二者**必走其一**。

```js
const isLogin = false;
if (isLogin) {
  console.log("欢迎回来");
} else {
  console.log("请先登录");
}
// 输出：请先登录
```

> `if-else` 表达的是"非此即彼"的**互斥关系**，两个分支恰好覆盖所有情况，不会有"无路可走"的空窗。这是它与单个 `if` 的本质区别。



#### if-else if-else 语句

**`if-else if-else` 语句**：用于**多个互斥条件**的判断，从上到下依次检查，命中第一个为真的分支后**立即停止**，不再判断后续分支。

```js
const hour = 14;
if (hour < 12) {
  console.log("上午好");
} else if (hour < 18) {
  console.log("下午好");
} else {
  console.log("晚上好");
}
// 输出：下午好
```

> 关键点在于"**命中即停**"：一旦某个分支条件为真，后面的 `else if` 都不会再被判断。因此**条件的书写顺序**很重要——范围应从小到大（或从大到小）排列，避免"前面的条件把后面的覆盖掉"。



### 三元运算符

**三元运算符（条件运算符）`?:`**：是 `if-else` 的**表达式形式**，语法为 `条件 ? 表达式1 : 表达式2`，条件为真返回 `表达式1`，否则返回 `表达式2`。它是 JavaScript 唯一的**三元**运算符。

```js
const age = 20;
const status = age >= 18 ? "成年" : "未成年";
console.log(status); // "成年"

// 等价于 if-else
let result;
if (age >= 18) {
  result = "成年";
} else {
  result = "未成年";
}
```

- 三元是**表达式**，有返回值，可以直接用于赋值、`return`、参数等位置；`if-else` 是**语句**，没有返回值。
- 三元运算符支持**嵌套**，但过度嵌套会严重损害可读性。

```js
// 嵌套三元（可读性差，慎用）
const level = score >= 90 ? "A" : score >= 60 ? "B" : "C";
```

> 使用原则：三元适合**简单、单一**的二选一赋值；一旦需要嵌套或多个动作，就应改用 `if-else`。可读性永远优先于"看起来高级"。



### switch 语句

**`switch` 语句**：用于**多个等值分支**的判断，把某个表达式的值与多个 `case` 依次进行**严格相等（`===`）**比较，命中后执行对应代码。

- 每个 `case` 末尾通常要写 **`break`**，否则会发生**穿透（fall-through）**，继续执行后续分支。
- 所有 `case` 都不匹配时，执行 **`default`** 分支（可选）。

```js
const day = 3;
switch (day) {
  case 1:
    console.log("星期一");
    break;
  case 2:
    console.log("星期二");
    break;
  case 3:
    console.log("星期三");
    break;
  default:
    console.log("未知星期");
}
// 输出：星期三
```

> `switch` 的比较是**严格相等**（`===`），不会做类型转换；`if-else if` 则可以用任意比较（`>`、`<` 等）。因此**等值判断**用 `switch` 更清晰，**范围判断**只能用 `if-else if`。漏写 `break` 导致的"穿透"是 `switch` 最常见也最隐蔽的 bug。



### 循环语句

#### 循环的认识

**循环（Loop）**：是指**重复执行同一段代码**的结构。循环让程序能够以几行代码处理成千上万条数据，是"自动化"的核心手段。

JavaScript 的循环语句主要有四种：

- **`while`**：先判断条件，再执行循环体。
- **`do-while`**：先执行一次循环体，再判断条件。
- **`for`**：初始化、条件、迭代三者集中书写，最常用。
- **`for-in`** / **`for-of`**：分别用于遍历对象的键、可迭代对象的值。

一个循环通常包含三要素：**初始化变量**、**循环条件**、**迭代更新**，缺一容易造成死循环或逻辑错误。

```js
// 打印 0 到 4
let i = 0;          // 初始化
while (i < 5) {     // 条件
  console.log(i);
  i++;              // 更新
}
```

> 所有循环本质上都是这三要素的组合。写循环时首要警惕**死循环**：确保"迭代更新"能让"条件"最终变为假，否则程序将卡死。



#### while 循环

**`while` 循环**：**先判断条件，再执行循环体**。条件为真则执行，为假则退出。当循环次数**事先未知**时尤其适用。

```js
let i = 0;
while (i < 5) {
  console.log(i);
  i++;
}
// 输出：0 1 2 3 4
```

> `while` 是"入口判断"循环：若条件一开始就为假，循环体**一次都不会执行**。它适合"不知道要循环几次、只知道何时该停"的场景，如读取数据直到结束。



#### while 循环的练习

通过几个练习巩固 `while` 循环的写法与边界。

```js
// 1. 计算 1 到 100 的和
let sum = 0;
let n = 1;
while (n <= 100) {
  sum += n;
  n++;
}
console.log(sum); // 5050

// 2. 打印 1 到 100 中能被 7 整除的数
let num = 1;
while (num <= 100) {
  if (num % 7 === 0) {
    console.log(num);
  }
  num++;
}
```

> 累加与筛选是 `while` 的两类经典题。共同要点：**变量在循环外初始化**、**循环内必须更新**、**条件要能走到假**。任何一条疏忽都可能导致结果错误或死循环。



#### do-while 循环

**`do-while` 循环**：**先执行一次循环体，再判断条件**。与 `while` 的区别在于：无论条件真假，循环体**至少执行一次**。

```js
let i = 10;
do {
  console.log("至少执行一次");
  i++;
} while (i < 5);
// 输出：至少执行一次（尽管条件 i<5 一开始就为假）
```

> `do-while` 是"出口判断"循环，适合"无论如何都要先做一次、再决定是否继续"的场景，如"至少尝试读取一次输入"。日常使用频率低于 `while` 和 `for`，但理解其"至少一次"的语义很重要。



#### for 循环

**`for` 循环**：把**初始化、条件、迭代**三要素集中写在一行，是**最常用**的循环形式，尤其适合**次数已知**的循环。

```js
// 语法：for (初始化; 条件; 迭代) { 循环体 }
for (let i = 0; i < 5; i++) {
  console.log(i);
}
// 输出：0 1 2 3 4
```

- **初始化** `let i = 0`：只在循环开始前执行一次。
- **条件** `i < 5`：每次循环前判断，为假则退出。
- **迭代** `i++`：每次循环体执行完后执行。

> 三个表达式都可省略（如 `for (;;)` 是死循环），但省略条件须格外小心。用 `let` 声明循环变量能形成块级作用域，避免 `var` 带来的变量提升与污染。



#### for 循环的练习

`for` 循环是最常用的循环，通过练习掌握典型模式。

```js
// 1. 累加：计算 1 到 100 的和
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;
}
console.log(sum); // 5050

// 2. 遍历数组
const fruits = ["苹果", "香蕉", "橙子"];
for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}

// 3. 打印偶数
for (let i = 0; i <= 10; i += 2) {
  console.log(i); // 0 2 4 6 8 10
}
```

> 遍历数组是 `for` 最高频的用途，核心是**用 `i < arr.length` 控制边界、用 `arr[i]` 取元素**。现代 JavaScript 中，遍历数组更推荐用 `for-of` 或 `forEach`，但经典的索引式 `for` 仍是最底层、最灵活的方式。



#### 循环的嵌套

**循环嵌套**：是在一个循环体内**再写一个循环**，外层每循环一次，内层完整循环一遍。常用于处理**二维结构**（如矩阵、表格）。

```js
// 外层控制行，内层控制列
for (let i = 1; i <= 3; i++) {
  for (let j = 1; j <= 3; j++) {
    console.log(`i=${i}, j=${j}`);
  }
}
// 输出 9 行：i 每变一次，j 从 1 到 3 走一遍
```

##### 嵌套的理解与案例练习

理解嵌套的关键是**分清内外层各自的职责**，用具体案例体会。

```js
// 打印一个 3 行 4 列的星号矩阵
for (let row = 0; row < 3; row++) {
  let line = "";
  for (let col = 0; col < 4; col++) {
    line += "* ";
  }
  console.log(line);
}
// 输出：
// * * * *
// * * * *
// * * * *
```

> 内层循环的**循环变量名**应区别于外层（如 `row`/`col`、`i`/`j`），避免混淆。嵌套的总执行次数是**内外层次数的乘积**（3×4 = 12 次），理解这一点有助于估算复杂度。



##### 嵌套案例练习二

继续用嵌套解决更有层次的图形问题，体会内外层变量的关系。

```js
// 打印三角形：第 i 行有 i 个星号
for (let i = 1; i <= 5; i++) {
  let line = "";
  for (let j = 1; j <= i; j++) {
    line += "*";
  }
  console.log(line);
}
// 输出：
// *
// **
// ***
// ****
// *****
```

> 这个案例的精髓在于**内层循环的次数依赖于外层变量 `i`**（`j <= i`），从而打印出逐行递增的三角形。这种"内层依赖外层"的模式是嵌套循环处理复杂图形的基础。



##### 九九乘法表练习

九九乘法表是嵌套循环的经典综合题，同时涉及**格式化输出**与**内层依赖外层**两个要点。

```js
for (let i = 1; i <= 9; i++) {
  let line = "";
  for (let j = 1; j <= i; j++) {
    line += `${j} × ${i} = ${i * j}\t`;
  }
  console.log(line);
}
// 输出：
// 1 × 1 = 1
// 1 × 2 = 2	2 × 2 = 4
// ...（共 9 行，第 i 行有 i 个算式）
```

> 乘法表用**外层 `i` 控制行（乘数）、内层 `j` 控制列（被乘数）**，内层上界 `j <= i` 形成下三角。模板字符串 `` `${j} × ${i} = ${i * j}` `` 与制表符 `\t` 让输出对齐，是格式化输出的常用技巧。



#### break 与 continue

**`break`** 与 **`continue`** 是两个改变循环流程的关键字。

- **`break`**：**立即终止整个循环**，跳出循环体，执行循环后的代码。
- **`continue`**：**跳过本次循环的剩余代码**，直接进入下一次迭代。

```js
// break：找到目标就退出
for (let i = 1; i <= 10; i++) {
  if (i === 5) {
    break;          // i 到 5 就终止
  }
  console.log(i);
}
// 输出：1 2 3 4

// continue：跳过偶数
for (let i = 1; i <= 5; i++) {
  if (i % 2 === 0) {
    continue;       // 跳过本次，不打印偶数
  }
  console.log(i);
}
// 输出：1 3 5
```

> `break` 只跳出**最近的一层**循环，不跳出外层；`continue` 只跳过**本次迭代**，不影响后续。在嵌套循环中，`break`/`continue` 默认作用于最内层，若需影响外层则要配合**标签（label）**。



### 综合练习

#### 随机生成数字

随机数生成是游戏与抽奖等场景的基础，JavaScript 通过 `Math.random()` 实现。

- **`Math.random()`**：返回 `[0, 1)` 之间的伪随机浮点数（含 0，不含 1）。
- 通过乘法和取整，可以映射到任意区间。

```js
// 生成 [0, n) 的随机整数
function getRandomInt(max) {
  return Math.floor(Math.random() * max);
}

// 生成 [min, max] 的随机整数（闭区间）
function getRandomIntInRange(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

console.log(getRandomInt(10));          // 0 ~ 9
console.log(getRandomIntInRange(1, 6)); // 1 ~ 6（模拟骰子）
```

> 区间映射的通用公式：`Math.floor(Math.random() * (max - min + 1)) + min` 得到 `[min, max]` 的随机整数。用 `Math.floor`（向下取整）而非 `Math.round`，能保证每个整数被抽中的概率**均匀**。



#### 猜数字游戏

猜数字游戏是循环、分支、随机数、交互函数的**综合应用**，也是入门阶段最有代表性的完整案例。

```js
// 生成 1~100 的随机数，让用户猜
const target = getRandomIntInRange(1, 100);
let guess = -1;
let count = 0;

while (guess !== target) {
  guess = Number(prompt("请输入你猜的数字（1~100）："));
  count++;
  if (guess > target) {
    alert("猜大了");
  } else if (guess < target) {
    alert("猜小了");
  }
}
alert(`恭喜猜中！你一共猜了 ${count} 次`);
```

- 用 `while` 循环直到猜中才退出（循环次数未知）。
- 用 `if-else if` 给出"大了/小了"的提示，逐步缩小范围。
- 用 `count` 统计次数，体验"状态累积"。

> 这个游戏完整串联了**变量、随机数、循环、分支、交互函数**五大知识点。思考一个改进方向：如何限制最大猜测次数？——只需把 `while` 的条件改为 `guess !== target && count < 上限` 即可，这正是"多条件退出"的典型写法。
