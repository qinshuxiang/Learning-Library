## CSS 动画：transition、transform 与 animation

### transition 过渡

transition 用于实现元素属性变化的平滑过渡。它的不足是只关心元素的**初始状态和结束状态**，无法获取过渡中每一帧的状态。

#### 四个属性

- `transition-property`：指定应用过渡的属性名称，可指定多个（逗号分隔），默认值为 `all`。只有具有中间值的属性才能过渡。
- `transition-duration`：过渡持续时间，单位秒 `s` 或毫秒 `ms`，默认值为 0（瞬时，无过渡效果）。时长列表个数不足会重复，过长会裁剪。
- `transition-timing-function`：过渡的时间函数（速度曲线），取值有 `linear`、`ease-in`、`ease-out`、`ease-in-out`、`cubic-bezier` 等。
- `transition-delay`：过渡开始前的延迟时间，单位秒或毫秒。取正值延迟响应，取负值立即开始。

#### 简写

```css
transition: 过渡属性 过渡时间 过渡函数 延迟时间;
```

一条 transition 规则可通过逗号同时定义多个属性的变化。

#### transition 的局限

- 需要事件触发，无法在网页加载时自动发生。
- 是一次性的，不能重复发生，除非一再触发。
- 只能定义开始和结束两个状态，无法描述中间过程。

CSS Animation 正是为解决这些问题而提出的。

### transform 转换

**转换**是 CSS3 的颠覆性特性，可实现元素的位移、旋转、变形、缩放，配合过渡和动画可取代大量早期只能靠 Flash 实现的效果。

#### 2D 转换

- **缩放 `scale`**：`transform: scale(x, y)`，只写一个值为等比例缩放；大于 1 放大，小于 1 缩小，不能为百分比。
- **位移 `translate`**：`transform: translate(x, y)`，参数为百分比时相对于自身移动；正值向右向下，负值向左向上，只写一个值表示水平移动。
- **旋转 `rotate`**：`transform: rotate(角度)`，正值顺时针，负值逆时针。默认以盒子正中心为原点，可用 `transform-origin` 改变旋转原点。

#### 3D 转换

3D 坐标系是左手坐标系：浏览器平面是 X 轴、Y 轴，垂直于浏览器的是 Z 轴。

- 旋转：`rotateX(deg)`、`rotateY(deg)`、`rotateZ(deg)`。
- 移动：`translateX(px)`、`translateY(px)`、`translateZ(px)`。
- **透视 `perspective`**：让 2D 平面在转换中呈现 3D 视觉，可设为父元素的属性（作用于所有子元素），或作为 transform 的值作用于元素自身。

### animation 动画

CSS3 的 animation 通过控制关键帧来实现更复杂的动画，制作动画分两步：定义动画 `@keyframes`，然后调用。

#### 定义动画 @keyframes

```css
@keyframes animation01 {
  0% { margin-top: 10px; }
  100% { margin-top: 20px; }
}
```

0% 是动画开始，100% 是完成，中间可插入任意百分比；也可用关键词 `from`（等同 0%）和 `to`（等同 100%）。不连续（无中间值）的属性不可用于动画。

#### 调用动画的属性

- `animation-timing-function`：动画速度曲线，默认 `ease`，还有 `linear`、`ease-in`、`ease-out`、`ease-in-out`、`steps`、`cubic-bezier`。
- `animation-direction`：播放方向，`normal`（正序）、`reverse`（倒序）、`alternate`（交替）、`alternate-reverse`（反向交替）。
- `animation-delay`：动画开始前的延迟，默认 0s。
- `animation-iteration-count`：播放次数，可为数值或 `infinite`（无限循环），默认 1 次。
- `animation-fill-mode`：动画播放前后应用的样式，`none`、`forwards`（保持最后一帧）、`backwards`（保持第一帧）、`both`。
- `animation-play-state`：动画运行或暂停，`running`、`paused`。

#### 简写

```css
animation: 动画名称 持续时间 运动曲线 何时开始 播放次数 是否反方向 动画起始或结束的状态;
```

> 简写属性里不包含 `animation-play-state`。
