## 参考资料与延伸阅读

### 官方文档与规范

#### Pro Git

**《Pro Git》**：是 Git 官方免费电子书的中文版（git-scm.com/book/zh/v2），是本主题最权威的依据与延伸。

- 覆盖从入门基础到分支模型、变基、重写历史直至内部原理的完整知识链。
- 在线阅读免费，内容随 Git 版本持续更新，技术事实以本书第二版为准。
- 既是教程也是权威依据，语言平实、示例充分。

> 本主题各章的技术事实均以《Pro Git》第二版为准；对任何一条结论存疑时，回到本书对应章节核对，尤其是分支、变基与重写历史等章节。



#### Git 参考手册

**Git 参考手册**：是面向命令的中文速查手册（gitref.justjavac.com），按命令逐条给出用法。

- 按命令分类排列，每条列出语义与常用参数。
- 篇幅精炼，以查证用法为目的，不展开原理。

> 适合作为案头速查：写作或练习时忘记某条命令的参数，到手册里按名检索，与第 2 章的基础命令、第 13 章的高级操作对照使用。



#### Git 官方文档

**Git 官方文档**：是 Git 官网（git-scm.com/doc）的文档总入口，汇集手册、书籍与视频。

- 汇集参考手册、Pro Git 电子书与官方教学视频。
- 命令行执行 git help 得到的本地手册与网站文档同源。

> 适合作为一站式入口：不确定该查手册还是查书时，从这里出发按需跳转；视频资料适合偏好听讲的初学者。



### 中文教程与书籍

#### 廖雪峰的 Git 教程

**《廖雪峰的 Git 教程》**：是最流行的中文入门教程（liaoxuefeng.com），既讲原理也讲实战。

- 从安装配置讲起，覆盖版本回退、分支管理、远程仓库、标签等主线内容。
- 每个知识点配动手演示，穿插原理说明与常见疑问。
- 全程在线免费阅读。

> 入门首选：初学者按顺序走完一遍即可建立完整认知。本主题第 2 章与第 5 章的讲解顺序即参考了它的组织思路。



#### Learn Git 中文版

**《Learn Git 中文版》**：是 Tower 团队出品的图文电子书（www.git-tower.com/learn/git/ebook/cn/command-line/），面向命令行用户。

- 以图文并茂的方式逐条讲解常用命令。
- 篇幅适中，概念解释清楚，附提示与进阶用法。

> 适合学完基础命令后系统梳理：图示把分支与提交的演变过程画得直观，可与第 4 章、第 5 章的分支操作对照阅读。



#### Git 权威指南

**《Git 权威指南》**：是蒋鑫所著的深度著作（www.worldhello.net/gotgit/），在线全文免费。

- 深入 Git 内部原理：对象模型、引用、索引机制、协议与钩子均有专章。
- 覆盖大量实战场景与团队协作话题。

> 进阶研读之选：想弄清提交到底存了什么、分支只是指针这类问题时读它，与第 6 章的底层存储、第 13 章的钩子与子模块内容呼应。



#### Git Magic 中文版

**《Git Magic 中文版》**：是视角独特的入门小册（www-cs-students.stanford.edu/~blynn/gitmagic/intl/zh_cn/），篇幅短小。

- 从数据快照与魔法的比喻切入，讲解视角与其他教程不同。
- 章节短、节奏快，适合快速通读。

> 适合已被命令淹死的初学者换换脑子：它把 Git 的心智模型讲得生动，帮助理解第 3 章的对象模型；不适合作查证手册使用。



#### 猴子都能懂的 GIT入门

**《猴子都能懂的 GIT入门》**：是零基础图文入门教程（backlogtool.com/git-guide/cn/），以配图出色著称。

- 用大量插图演示分支、合并、远端的每一步操作。
- 分入门篇与进阶篇，难度平缓。

> 纯零基础或对分支图示有困难时的首选：插图把抽象的提交树变成直观画面，与第 4 章的分支概念互补。



#### Git Community Book 中文版

**《Git Community Book 中文版》**：是社区协作翻译的早期经典（gitbook.liuhui998.com/index.html）。

- 由社区维基式编写，覆盖命令与原理两条线。
- 章节短小，可作碎片化阅读。

> 历史较早、部分内容基于旧版 Git，但原理性章节仍然有效；适合作为补充读物，不建议作为唯一的入门材料。



#### git - 简易指南

**《git - 简易指南》**：是一页纸速查页（rogerdudler.github.io/git-guide/index.zh.html），把最常用的操作浓缩在一页。

- 只列典型工作流中的高频命令，配一行说明。
- 页面单屏可览，扫一眼即可上手操作。

> 适合第一次装机后的快速上手，或给偶尔用 Git 的同事当指引；与第 2 章的基础命令清单互为补充。



### 速查表与工具

#### Git Cheat Sheet

**《Git Cheat Sheet》**：是 Tower 官方的中文速查表（www.git-tower.com/blog/git-cheat-sheet-cn），按场景分组的命令卡片。

- 按创建仓库、日常改动、分支合并、撤销等场景分组。
- 每条命令配一句中文说明，可打印张贴。

> 适合贴在工位边随手查阅：按场景查找比按命令名查找更贴近实际工作，覆盖第 2 章到第 5 章的大部分命令。



#### Git-Cheat-Sheet 中文版

**《Git-Cheat-Sheet 中文版》**：是社区维护的命令速查表（github.com/flyhigher139/Git-Cheat-Sheet），一页覆盖常用命令。

- 收录配置、暂存、分支、远端、标签等常用命令。
- 源文件托管在 GitHub，便于下载与本地打印。

> 与 Tower 版速查表二选一即可；它的组织更贴近命令名首字母，习惯按字母查找者更顺手。



#### git-flow 备忘清单

**《git-flow 备忘清单》**：是 GitFlow 分支模型的图形化速查页（danielkummer.github.io/git-flow-cheatsheet/index.zh_CN.html）。

- 用图示完整呈现 main、develop 与 feature、release、hotfix 的流转。
- 对照列出 git-flow 工具的对应命令。

> 学 GitFlow 时的最佳图示材料：与第 14 章的 GitFlow 工作流对照阅读，图中每条箭头都能在那一章找到文字对应。



### GitHub 相关资源

#### GotGitHub

**《GotGitHub》**：是蒋鑫所著的 GitHub 全面指南（www.worldhello.net/gotgithub/index.html），在线全文免费。

- 系统讲解账号、仓库、分支、拉取请求、Wiki、Pages 等平台功能。
- 兼顾个人使用与开源项目运营的视角。

> 用好 GitHub 平台的深度读物：第 14 章讲的 fork 与拉取请求流程，本书给出了更完整的功能细节与实例。



#### GitHub秘籍

**《GitHub秘籍》**：是围绕 GitHub 平台的技巧合集（snowdream86.gitbooks.io/github-cheat-sheet/content/zh/index.html）。

- 收录忽略文件模板、快捷键、隐藏功能等零散技巧。
- 以条目式短文组织，随手翻阅。

> 适合已经会用的用户进阶挖宝：内容零散但含金量高，不承担系统教学职责，与各章正文互不替代。



#### GitHub帮助文档

**《GitHub帮助文档》**：是 GitHub 官方帮助文档的中文译本（github.com/waylau/github-help）。

- 覆盖账号设置、仓库管理、协作流程等官方操作说明。
- 译文忠实原文，条目按官方文档结构排列。

> 查平台功能细节的备选来源；与官方英文帮助相比更新稍滞后，准确表述以官方原文为准。



#### GitHub漫游指南

**《GitHub漫游指南》**：是面向个人成长的实践指南（github.com/phodal/github-roam），讲述从入门到打造个人影响力。

- 从提交规范、开源参与到个人品牌建设的渐进路线。
- 混合方法论与作者自身实践案例。

> 适合想把 GitHub 用作长期履历的读者：第 14 章的协作礼节讲的是单次贡献怎么做，这本书回答的是多年参与怎么规划。



### 其他版本控制工具

#### Mercurial 使用教程

**《Mercurial 使用教程》**：是 Mercurial 官方 Wiki 的中文教程（www.mercurial-scm.org/wiki/ChineseTutorial），介绍分布式版本控制的另一代表工具。

- 覆盖初始化、提交、合并、分支等与 Git 对应的基本操作。
- 以官方教程形式组织，篇幅紧凑。

> 开阔视野之用：对照 Mercurial 与 Git 的命令差异，能反过来加深对 Git 设计取舍的理解，与第 1 章的版本控制系统分类呼应。



#### svn 手册

**《svn 手册》**：是 Subversion 官方手册的中文版（svnbook.red-bean.com/nightly/zh/index.html），集中式版本控制代表工具的权威文档。

- 完整讲解检出、提交、更新、冲突解决与分支合并的集中式模型。
- 译文随原书版本更新，术语规范。

> 对比阅读的最佳样本：集中式与分布式的核心差别在本书与《Pro Git》的对照中一目了然，可与第 1 章的版本控制系统对比呼应。
