## 代码优化与目标代码生成

> **本块定位**：本块对应官方考纲的代码优化与目标代码生成，回答三个问题——优化按什么层次展开、基本块与流图如何为优化提供分析单位、目标代码如何选择指令并分配寄存器。基本块划分、局部优化与循环优化的前后代码对照是本篇的计算点，寄存器分配的基本思路与指令调度是概念辨析的常考点。中间代码形式见本主题第 8 篇 语义分析与语法制导翻译，运行时的存储布局见本主题第 10 篇 运行时环境与存储组织。

### 优化的层次与原则

优化在不改变程序外部行为的前提下改进代码的时间和空间效率，它按作用范围分层实施，并受若干可判定原则约束。

#### 优化的目标与前提

**代码优化（Code Optimization）**是在保证程序外部行为等价的前提下，对中间代码或目标代码进行变换以提高运行效率或减少存储开销的过程。

- 目标一：减少目标代码的运行时间，如减少访存次数与循环体内指令数。
- 目标二：减少目标代码占用的存储空间，如删除无用代码与合并常量。
- 前提一：等价性，优化前后对同一输入必须产生相同输出与相同副作用。
- 前提二：可判定性，优化变换必须能在有限步骤内完成，不能依赖不可判定的性质。
- 现实约束：优化需与编译速度折中，过度优化会显著延长编译时间。

**考察形式**：综合知识选择题，考查代码优化的目标与它必须满足的两个前提。



#### 优化的层次

按作用范围由小到大，优化分为局部优化、循环优化与全局优化三类，另有与机器无关和机器相关之别。

- 局部优化：作用范围限于单个基本块内部，如常量折叠、公共子表达式删除。
- 循环优化：以循环为对象，如代码外提、强度削弱、归纳变量删除，收益通常最大。
- 全局优化：跨基本块进行，如全局公共子表达式删除、全局常量传播、死代码删除。
- 机器无关优化：在中间代码上做，如常量折叠与循环不变量外提，与具体指令集无关。
- 机器相关优化：在目标代码上做，如寄存器分配、指令选择与指令调度，依赖具体机器。

**考察形式**：综合知识选择题，考查优化三个层次的划分依据与机器无关优化、机器相关优化的分界。



#### 优化的原则

优化必须同时满足等价、有效与经济三条原则，三者缺一即不可取。

- 等价原则：变换不得改变程序的可见行为，包括输出、副作用与异常行为。
- 有效原则：变换后确实在时间或空间上有改进，不能只是形式变化。
- 经济原则：变换带来的收益应大于分析与变换本身的编译开销。
- 副作用警惕：含函数调用或指针引用的表达式不能随意删除或移动。
- 保守处理：无法确定是否安全时放弃该优化，宁可少优化也不改变语义。

> [!CAUTION]
> **注意内容**：把公共子表达式或循环不变量外提时，若该表达式含函数调用、指针解引用或可能异常的运算，移动或删除都可能改变程序行为。优化的等价性以可观察行为为准，不能只看数值结果是否相同。

**考察形式**：综合知识选择题，考查优化三原则的含义以及不安全变换导致的语义改变。



#### 常用优化技术概览

- 常量类：常量折叠、常量传播、常量条件分支消除。
- 表达式类：公共子表达式删除、复写传播、代数化简。
- 循环类：代码外提、强度削弱、归纳变量删除、循环展开与循环合并。
- 代码类：死代码删除、无用赋值删除、窥孔优化。
- 分配类：寄存器分配、活跃变量分析、指令调度。

**考察形式**：综合知识选择题，考查常用优化技术的名称与所属类别。



### 基本块与流图

为做局部与全局优化，需要把线性中间代码切成粒度合适、控制流单一的片段，这就是基本块与流图的作用。

#### 基本块的定义与入口语句

**基本块（Basic Block）**是满足下列条件的最大连续三地址码序列：控制流只能从序列的第一条语句进入，只能从最后一条语句离开。

- 唯一入口：除第一条语句外，块内任何语句都不是转移目标。
- 唯一出口：除最后一条语句外，块内任何语句都不是转移或停语句。
- 最大性：满足条件的两块不能合并为更大的一块，否则应合并。
- 用途：块内控制流线性，可安全地做常量折叠与公共子表达式删除。

**考察形式**：综合知识选择题，考查基本块的唯一入口、唯一出口与最大性三条条件。



#### 基本块的划分算法

划分基本块的关键是先确定各块的入口语句，再按入口界限切分三地址码序列。

- 入口一：程序的第一条三地址码是入口语句。
- 入口二：任何条件转移或无条件转移语句的目标标号所指语句是入口语句。
- 入口三：紧跟在条件转移或无条件转移语句之后的下一条语句是入口语句。
- 切分规则：两个相邻入口语句之间的全部语句构成一个基本块，含第一个入口、不含第二个入口。

```text
三地址码程序与基本块划分示例
(1) i = 1
(2) L1: if i > 100 goto L4        标号 L1 是转移目标，为入口语句
(3) t1 = i * 4
(4) t2 = a[t1]
(5) if t2 < 0 goto L3             是条件转移，其后一句 (6) 是入口语句
(6) sum = sum + t2
(7) goto L2                       是无条件转移，其后一句 (8) 是入口语句
(8) L3: sum = sum - t2            标号 L3 是转移目标，为入口语句
(9) L2: i = i + 1                 标号 L2 是转移目标，为入口语句
(10) goto L1
(11) L4: 结束                     标号 L4 是转移目标，为入口语句

入口语句集合：(1)、(2)、(6)、(8)、(9)、(11)
基本块 B1：(1)(2)     B2：(3)(4)(5)     B3：(6)(7)
基本块 B4：(8)        B5：(9)(10)       B6：(11)
```

**考察形式**：综合知识选择题与案例分析，考查基本块入口语句的三条判定规则与划分结果。



#### 流图与控制流图

**流图（Flow Graph）**是以基本块为结点、以控制转移可能为有向边的有向图，用于描述程序的控制流。

- 结点：每个基本块对应一个结点，入口块是含第一条语句的块。
- 有向边：块 B1 的最后一条语句可能转向块 B2 时，画一条 B1 到 B2 的边。
- 条件转移：条件转移语句产生两条边，分别指向目标块与顺序后继块。
- 无条件转移：产生一条边，指向目标块。
- 用途：循环识别、到达定值分析、活跃变量分析都以流图为对象。

```text
上例流图的主要边（块名即基本块）
B1 -> B2        条件 i > 100 不成立，进入循环体
B1 -> B6        条件 i > 100 成立，跳出循环
B2 -> B3        条件 t2 < 0 不成立
B2 -> B4        条件 t2 < 0 成立
B3 -> B5        顺序执行到 i = i + 1
B4 -> B5        两条分支汇合到 B5
B5 -> B2        回边，构成循环
B6              程序出口，无后继
```

**考察形式**：综合知识选择题，考查流图的结点与边如何由基本块和转移语句确定。



#### 循环的识别

**循环（Loop）**是流图中满足强连通性且只有唯一入口结点的结点集合，识别循环是循环优化的前提。

- 回边定义：若结点 n 到结点 d 的边满足 d 是 n 的必经结点，则该边称为**回边（Back Edge）**。
- 必经结点：从入口块到 n 的每条路径都经过结点 d，则 d 是 n 的必经结点。
- 自然循环：由回边 n 到 d 构成的自然循环是 d 加上所有能不经过 d 而到达 n 的结点。
- 唯一入口：自然循环的入口 d 是支配结点，保证优化时不会从多处跳入。

> **说明**：回边不是按结点编号大小判断的，而按必经关系判断。只要目标结点是源结点的必经结点，这条边就是回边，即使它的目标编号大于源编号也成立。

**考察形式**：综合知识选择题，考查回边的判定条件与自然循环的构成。



### 局部优化（常量折叠、公共子表达式删除、复写传播）

局部优化以单个基本块为范围，利用块内控制流线性这一性质实施安全变换，是构造优化器的基础环节。

#### 常量折叠与常量传播

**常量折叠（Constant Folding）**是在编译期把常量表达式的值直接算出的变换；**常量传播（Constant Propagation）**是把变量已被赋为常量的值代入其后的引用。

- 常量折叠示例：把 2 * 3 + 4 直接替换为 10，编译期完成运算。
- 常量传播示例：先有 x = 5，其后引用 x 处替换为 5，再触发折叠。
- 触发条件：变量的定值在块内唯一且其后未被重新赋值。
- 连带收益：折叠往往暴露更多常量，为条件分支消除与死代码删除创造条件。

```text
局部优化前后的三地址码对照
优化前                         优化后
t1 = 2 * 3                     t1 = 6
t2 = 4 * t1                    t2 = 24
x  = t2 + 1                    x  = 25
说明：先折叠 2 * 3 得 6，再传播得 t2 = 4 * 6 并折叠为 24，最后折叠为 25
```

**考察形式**：综合知识选择题，考查常量折叠与常量传播的适用条件及优化前后的代码对照。



#### 公共子表达式删除

**公共子表达式（Common Subexpression）**是多次出现且各次出现的运算对象取值均未改变的表达式；**公共子表达式删除**是把重复计算的表达式合并为一次计算并复用结果的变换。

- 识别条件：同一表达式在两次出现之间，其涉及的变量都没有被重新赋值。
- 实现结构：用带值编号的**有向无环图**或在块内维护可用表达式表。
- 删除动作：第二次出现时不再重复计算，直接引用第一次的结果。
- 安全性前提：表达式不含函数调用与可能改变值的指针引用。

```text
公共子表达式删除示例
优化前                         优化后
t1 = b * c                     t1 = b * c
t2 = b * c                     t2 = t1        复用 t1 的结果
t3 = a + t2                    t3 = a + t1
说明：b 与 c 在两次 b * c 之间未被赋值，第二次计算可以删除
```

> **辨析提示**：常量传播替换的是变量的引用，公共子表达式删除替换的是整个表达式的重复计算。前者要求变量取值恒定，后者要求运算对象在两次出现之间未被重新赋值，两者的安全条件不同。

**考察形式**：综合知识选择题，考查公共子表达式的识别条件与删除后的代码变化。



#### 复写传播与死代码删除

**复写传播（Copy Propagation）**是在形如 u = v 的复写语句之后，把对 u 的引用尽可能替换为对 v 的引用；**死代码删除（Dead Code Elimination）**是删除计算结果永远不会被使用的语句。

- 复写传播目的：减少复写语句建立起的中间变量，为后续删除铺路。
- 传播前提：u 在复写之后、引用之前没有被重新赋值。
- 死代码判定：某赋值的结果变量在块内及其后继均无引用，则该赋值可删。
- 连带效应：删除死代码后可再触发复写传播与公共子表达式删除，形成迭代。
- 常见死代码：不可达分支、被常量条件判定为永不执行的分支、无用赋值。

```text
复写传播与死代码删除示例
优化前                         优化后
u  = v                         t = v + 1      把 u 的引用替换为 v
t  = u + 1                     说明：u 在后续不再被使用
后续不再使用 u                  故删除复写语句 u = v（u 成为死变量）
```

**考察形式**：综合知识选择题，考查复写传播的前提条件与死代码删除的判定依据。



#### 基本块内的 DAG 表示

- **DAG 表示**：以叶结点表示变量初值或常量，以内部结点表示运算，边表示操作数依赖。
- 构成方式：从左到右处理每条三地址码，为每个新运算查找或建立结点，并给结果变量挂上标记。
- 复用规则：若已有结点表示相同运算且操作数结点相同，则直接复用该结点。
- 读出的三类信息：公共子表达式、块内可复制的赋值、块内可删除的无用赋值。
- 与优化的对应：DAG 化简过程本身即完成了常量折叠与公共子表达式删除。

**考察形式**：综合知识选择题，考查基本块内 DAG 的构成方式以及从 DAG 读出的优化信息。



### 循环优化（代码外提、强度削弱、归纳变量）

循环体被执行次数最多，因此循环上的优化收益最大。本模块给出代码外提、强度削弱与归纳变量三类主要手段。

#### 代码外提

**代码外提（Loop-Invariant Code Motion）**是把循环不变量计算移到循环入口之前、使其只计算一次的变换。

- **循环不变量（Loop-Invariant）**：在循环内每次迭代其值都不改变的运算或变量。
- 判别条件：运算的各操作数在循环内均为常量或循环不变量，且循环内对其操作数无重新定值。
- 外提位置：通常提到循环的入口块之前，设立前置首结点以放置外提代码。
- 安全条件：外提后不得改变异常行为，循环可能一次不执行时须谨慎。

**考察形式**：综合知识选择题，考查循环不变量的判别条件与代码外提的位置和安全约束。



#### 强度削弱

**强度削弱（Strength Reduction）**是把执行代价高的运算替换为代价低的等价运算的变换，最常见的是把乘法替换为加法。

- 典型替换：循环内形如 i * c 的乘法，可改用每次加 c 的递归赋值完成。
- 前提条件：循环变量 i 每次按固定步长变化，乘法因子 c 为循环不变量。
- 实现方式：在循环前初始化临时变量为初值乘积，循环内改为加上步长与 c 的乘积。
- 其它形式：乘 2 的幂替换为移位，幂运算替换为连乘，除法替换为乘倒数。

**考察形式**：综合知识选择题，考查强度削弱的典型替换形式与适用前提。



#### 归纳变量与归纳变量删除

**归纳变量（Induction Variable）**是在循环中每次迭代按固定步长增减的变量，它常与另一个归纳变量成线性关系。

- 识别依据：变量在循环中的每次定值都是自增或自减一个不变量，或可表达为另一归纳变量的线性函数。
- 成组现象：循环变量 i 与由它计算出的地址、乘积往往构成一组归纳变量。
- 删除条件：组内某变量可由其它归纳变量线性表示，且不再有其它用途。
- 删除收益：减少循环体内赋值与寄存器占用，配合强度削弱效果显著。
- 注意边界：删除后必须保证循环出口处被删除变量的值在需要时仍可用。

**考察形式**：综合知识选择题，考查归纳变量的识别依据与归纳变量删除的条件。



#### 循环优化前后对照

下面给出一个数组求和循环的综合优化示例，强度削弱与归纳变量删除依次作用。

```text
优化前的循环（三地址码）
L1: t1 = i * 4          每次迭代做一次乘法，属强度可削弱对象
    t2 = a[t1]          以乘法结果作下标
    sum = sum + t2
    i = i + 1
    if i <= n goto L1
循环不变量分析：4 是常量，n 在循环内不动
强度削弱：把 i * 4 改为每次加 4 的累积变量 t1
归纳变量：i 与 t1 成线性关系 t1 = 4 * i，i 可删除
最终优化后
    t1 = 0              循环前初始化，对应 i = 0 时的 4 * i
L1: t2 = a[t1]
    sum = sum + t2
    t1 = t1 + 4         乘法改为加法
    if t1 <= 4 * n goto L1
说明：循环体内只剩一次加法与一次访存，乘法被削弱
```

**考察形式**：综合知识选择题与案例分析，考查循环优化前后的代码对照与各步变换的依据。



#### 循环展开与循环合并

- **循环展开（Loop Unrolling）**：把循环体复制多份、相应减少迭代次数，以降低循环控制开销并增加指令调度空间。
- 展开收益：减少循环控制语句的比例，便于跨迭代做公共子表达式删除与指令调度。
- 展开代价：代码规模增大，指令高速缓存命中率可能下降，需权衡展开因子。
- **循环合并（Loop Fusion）**：把两个迭代次数相同的相邻循环合为一个，减少循环控制开销并改善访存局部性。
- 合并前提：两循环迭代空间一致、无循环携带依赖冲突。

> [!TIP]
> **建议内容**：做循环优化时按由内到外的顺序处理嵌套循环，先在内层做强度削弱与归纳变量删除，再对外层做代码外提。内层迭代次数通常远大于外层，先优化内层的累计收益更高。

**考察形式**：综合知识选择题，考查循环展开与循环合并的收益、代价与适用前提。



### 目标代码生成与寄存器分配

目标代码生成把优化后的中间代码翻译为具体机器的指令序列，寄存器分配在这一步决定哪些值驻留寄存器。

#### 目标代码生成的输入与任务

**目标代码生成（Target Code Generation）**是把优化后的中间代码映射为目标机器的指令序列、并确定各数据存放位置的过程。

- 输入：优化后的中间代码、符号表中的存储信息、目标机器的指令系统描述。
- 任务一：指令选择，为每段中间代码选出合适的机器指令。
- 任务二：寄存器分配与指派，决定哪些值放入寄存器及放入哪个寄存器。
- 任务三：指令排序，确定指令的先后顺序与目标代码的最终布局。
- 输出质量：受指令系统特点、寄存器数量与访存代价共同影响。

**考察形式**：综合知识选择题，考查目标代码生成的输入与三项基本任务。



#### 寄存器分配与指派

**寄存器分配（Register Allocation）**是确定哪些变量与中间结果驻留寄存器、哪些放入内存的决策；**寄存器指派（Register Assignment）**是在分配确定后指定具体寄存器编号的决策。

- 分配对象：使用频繁的变量优先分配寄存器，以减少访存次数。
- 指派约束：同一时刻活跃的两个值不能占用同一个寄存器。
- 溢出处理：寄存器不够时把某些值暂存到内存，需要时再取回，称为溢出。
- 层次关系：先按活跃变量分析确定冲突关系，再做分配，最后做指派。
- 目标：在寄存器数量约束下使访存次数与溢出开销最小。

**考察形式**：综合知识选择题，考查寄存器分配与寄存器指派的区别以及溢出发生的原因。



#### 活跃变量分析与图着色分配

**活跃变量分析（Live Variable Analysis）**是判断某程序点上变量的值在后续是否还会被使用的数据流分析，它给出寄存器分配的冲突依据。

- 活跃定义：若变量 v 在程序点 p 之后的某条路径上被引用且其间未被重新定值，则 v 在 p 点活跃。
- 定值与引用：分析围绕变量的定值集合与引用集合向前或向后传播。
- 冲突图构造：两个变量同时活跃则它们相互冲突，在冲突图中连一条边。
- **图着色（Graph Coloring）**：用 K 种颜色给冲突图结点着色，K 即可用寄存器数，相邻结点颜色不同。
- 分配失败：冲突图无法用 K 色着色时，选择溢出代价最小的变量放入内存，重建冲突图后重试。

**考察形式**：综合知识选择题，考查活跃变量的定义、冲突图的构造与图着色分配的基本思路。



#### 目标代码生成示例

```text
为表达式 a = b + c * d 生成目标代码（两寄存器模型 R1、R2）
优化前的四元式序列
t1 = c * d
t2 = b + t1
a  = t2

活跃变量分析：b、c、d 在计算前活跃，t1 在第二句前活跃
寄存器分配：c 与 d 各占一个寄存器完成乘法，t1 留在 R1
生成的目标代码（LOAD 装入、MUL 乘、ADD 加、STORE 存）
LOAD  R1, c
MUL   R1, d         R1 得到 c * d，即 t1
LOAD  R2, b
ADD   R2, R1        R2 得到 b + t1，即 t2
STORE a, R2
说明：t1 全程留在寄存器，省去一次写回与一次装入
```

**考察形式**：综合知识选择题与案例分析，考查给定表达式生成目标代码时寄存器重用与访存次数的计算。



### 指令选择与指令调度

指令选择解决选哪条指令，指令调度解决指令按什么次序执行，两者共同决定目标代码的最终质量。

#### 指令选择

**指令选择（Instruction Selection）**是为中间代码的每个运算从目标机器指令系统中选出实现方案的过程，其目标是使指令条数与执行代价最小。

- 依据：目标机器的指令格式与寻址方式，详见 架构/计算机组成原理 主题第 10 篇 指令系统：指令格式与寻址方式。
- 等价方案：同一运算常有多种指令组合，如先计算地址再访存，或直接用变址寻址一条指令完成。
- 优化方向：优先选用能一次完成访存与运算的指令，减少临时寄存器占用。
- 实现方法：常用树形覆盖法，把中间代码树用指令模板自底向上覆盖。

**考察形式**：综合知识选择题，考查指令选择的目标、依据与树形覆盖的实现思路。



#### 指令调度

**指令调度（Instruction Scheduling）**是在不改变程序语义的前提下重排指令顺序、以减少流水线停顿的过程。

- 调度原因：目标机器多为流水线结构，相邻指令存在数据相关时会插入等待周期。
- 相关类型：数据相关、反相关与输出相关，决定了指令能否交换次序。
- 调度方法：在基本块内做局部调度，或在循环与全局范围做调度。
- 调度收益：把无相关的指令填入等待槽，提高流水线吞吐率。
- 约束条件：调度不得改变数据依赖关系与异常顺序，也不得破坏内存别名约束。

**考察形式**：综合知识选择题，考查指令调度的原因、相关类型与约束条件。



#### 窥孔优化

**窥孔优化（Peephole Optimization）**是在目标代码上用一个滑动的小窗口逐段检查、把窗口内的低效指令序列替换为等价高效序列的局部改进技术。

- 窗口大小：通常只覆盖相邻的少数几条指令。
- 常见形式：删除冗余装入与存回、消除跳转到下一条语句的转移、合并相邻常数运算。
- 强度削弱：把乘 2 的幂替换为左移等更廉价指令。
- 迭代执行：替换后可能暴露新的可优化窗口，需反复扫描直到不再变化。
- 定位：属机器相关优化，实现简单、见效快，是目标代码生成后的常规收尾。

```text
窥孔优化示例
优化前                         优化后
LOAD  R1, x                    LOAD  R1, x
STORE R1, x                    说明：冗余地存回自身，删除该存回
LOAD  R2, y                    LOAD  R2, y
MUL   R2, 2                    SHL   R2, 1        乘 2 替换为左移
```

> [!NOTE]
> **提醒内容**：优化与目标代码生成并非互不相干的串行步骤。寄存器数量、指令集特点与流水线结构都会反过来影响中间代码阶段可选的优化方案，工程实现中常在两者之间反复权衡，而不是一次做完就固定下来。

**考察形式**：综合知识选择题，考查窥孔优化的窗口范围、常见形式与它在编译流程中的位置。
