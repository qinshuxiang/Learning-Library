## 文法与语言的形式定义

> **本块定位**：本块对应官方考纲的文法与语言的形式定义，回答三个问题——语言如何由字母表与符号串逐层构造、文法如何用四元组刻画、乔姆斯基谱系如何按产生式的形式给文法分级。四类文法的判别与包含关系是本主题题量最稳定的概念考点，推导与语法树的构造、二义性的判定常出小计算题。记号构成规则的自动机识别已在前一篇讲完，本块只补它所属的文法类型，正规式与 3 型文法的对应关系见本主题第 4 篇 词法分析与有限自动机。本块建立的形式定义是后两篇语法分析方法的共同基础，自上而下与自下而上分别见本主题第 6 篇 语法分析：自上而下与第 7 篇 语法分析：自下而上。

### 字母表、符号串与语言

形式语言理论用字母表、符号串与串的集合三层概念刻画语言，本模块先把这三层定义清楚，再给出语言的运算。它对应大纲中语言的形式化描述部分，是后面所有定义的语言学底座。

#### 字母表的定义与记法

**字母表（Alphabet）**是元素的非空有穷集合，其元素称为符号，通常记作 Σ。字母表只规定允许出现哪些符号，不规定符号如何组合。

```text
Σ = {a, b}                                    字母表：两个符号组成的有穷集合
Σ = {0, 1}                                    二进制字母表
Σ = {字母, 数字, 下划线}                        程序设计语言标识符用的字母表
```

- 有穷性：字母表必须是有穷集合，不允许无限多符号。
- 非空性：字母表至少含一个符号。
- 与字符集的区别：字符集指实现层面的编码集合，字母表是理论层面的抽象集合。
- 常见误用：把字符串当作字母表的元素，字母表的元素只能是单个符号。

**考察形式**：综合知识选择题，考查字母表的有穷非空性质与常见字母表的举例。



#### 符号串与空串

**符号串（String）**是字母表中符号的有穷序列，序列的长度即串的长度；长度为 0 的符号串称为**空串（Empty String）**，记作 ε。

- 表示法：串一般直接写出符号序列，abba 表示由 a、b、b、a 依次连接而成的串。
- 长度计算：长度为 n 的串含 n 个符号，空串长度为 0。
- 空串的唯一性：任意字母表上只有一个空串。
- 空集与空串之别：空集不含任何串，含有空串的集合不是空集。
- 空前缀与空后缀：任何串都以空串为前缀，也以空串为后缀。

> **辨析提示**：题目把 ε 与空集并列出选项时，看集合是否含元素即可判定。{ε} 是含一个元素的集合，空集是含零个元素的集合，两者不等价。

**考察形式**：综合知识选择题，考查符号串长度与空串的性质、空集与空串的区分。



#### 符号串的连接、逆与幂

**连接（Concatenation）**是把两个符号串首尾相接得到新串的运算，记作 xy；**逆（Reversal）**是把串中符号次序颠倒的运算，记作 x 的逆。

- 连接不满足交换律：xy 与 yx 一般是不同的串。
- 连接满足结合律：xyz 无论先接前两个还是先接后两个，结果相同。
- 空串是连接的单位元：ε 与任何串连接仍得该串。
- 长度相加：连接后串的长度等于两个串长度之和。
- 幂的记号：串 x 的 n 次幂记作 x 的 n 次方，表示 n 个 x 连接，x 的 0 次幂等于 ε。
- 逆的性质：逆运算两次还原原串，且 x 与 y 连接后的逆等于 y 的逆与 x 的逆连接。

```text
x = ab    y = ba                              两个待运算的串
xy = abba                                     连接：长度 4 = 2 + 2
yx = baab                                     连接不可交换：结果与 xy 不同
x的逆 = ba                                    逆运算：符号次序颠倒
x的2次幂 = abab                               幂：两个 x 连接
x的0次幂 = ε                                  0 次幂为单位元，即空串
```

**考察形式**：综合知识选择题，考查连接运算的结合律与不可交换性、串的逆与幂的计算。



#### 符号串集合的运算与闭包

**符号串集合的运算**包含并、交、差、连接与闭包，其中**闭包（Closure）**是把集合中的串反复连接所能得到的一切串汇成的集合。设 L 为符号串集合，则 L 的星闭包记作 L 的星，正闭包记作 L 的正号。

- 并、交、差：按集合论定义逐元素判定，与串的内部结构无关。
- 连接：L 与 M 的连接是所有形如 xy 的串的集合，其中 x 取自 L、y 取自 M。
- 星闭包：含空串，等于 L 的 0 次幂、1 次幂、2 次幂依次并起来的结果。
- 正闭包：不含空串，等于 L 的 1 次幂、2 次幂依次并起来的结果。
- 两者的关系：星闭包等于正闭包与集合 {ε} 的并。
- 闭包的表示差别：两者只在空串上不同，其余元素完全一致。

```text
L = {a}                                       单元素集合
L的0次幂 = {ε}                                 0 次幂固定为含空串的集合
L的1次幂 = {a}    L的2次幂 = {aa}              幂次递增即重复连接
L的星闭包 = {ε, a, aa, aaa, ...}               含空串，长度任意
L的正闭包 = {a, aa, aaa, ...}                  不含空串
```

> **辨析提示**：判断某串是否属于星闭包时，先看它能否拆成若干个 L 中串的连接；空串一定属于星闭包，一定不属于正闭包。

**考察形式**：综合知识选择题，考查星闭包与正闭包的定义差别、闭包中空串的归属。



#### 语言的定义与语言运算

**语言（Language）**是某个字母表上符号串的集合，即字母表上串集合的一个子集。文法的作用正是用有穷的规则描述一个可能无穷的语言。

- 语言的给定方式：有穷语言可枚举全部串，无穷语言只能用文法或自动机等有穷描述手段给出。
- 字母表上的全部串：字母表 Σ 上一切符号串的集合记作 Σ 的星闭包，任何语言都是它的子集。
- 语言的运算：并、交、差、连接、闭包都按符号串集合的运算定义。
- 语言与记号的联系：记号的构成规则对应一个有穷或无穷的语言，软件通行的做法是给出描述而不是枚举。
- 语言的规模：有穷语言与无穷语言都可能由有穷文法描述，规模不是判定语言类别的依据。

**考察形式**：综合知识选择题或案例分析的背景判断，考查语言的集合本质与有穷描述的意义。



### 文法的形式定义

文法用一组有穷的产生式刻画无穷的语言。本模块给出文法的四元组定义，并说明推导如何从开始符号生成句子，对应大纲中文法的组成与推导部分。

#### 文法的四元组定义

**文法（Grammar）**是刻画语言结构的数学系统，通常定义为四元组 G = (V N, V T, P, S)，其中 V N 为非终结符集合、V T 为终结符集合、P 为产生式集合、S 为开始符号。

```text
G = (V N, V T, P, S)                          四元组的四个分量
   V N：非终结符集，{E, T, F}                   占位符，不出现在最终句子里
   V T：终结符集，{+, *, (, ), i}               基本符号，构成最终句子
   P：产生式集，形如 左部 → 右部                   规则集合
   S：开始符号，E，且必须属于 V N                推导的出发点
约束：V N 与 V T 不相交，两者并集称为文法符号集
```

- 有穷性：四个分量都是有穷集合，这是文法能作为有穷描述手段的前提。
- 开始符号的归属：开始符号必须是某个非终结符，不能是终结符。
- 产生式的记法：同左部的多条产生式可合并写，用竖线分隔各右部。
- 文法符号集：V N 与 V T 的并集记作 V，推导与语法树都在这套符号上进行。
- 与语言的对应：四元组一经确定，该文法所生成的语言随之确定。

**考察形式**：综合知识选择题，考查文法四元组各分量的含义与开始符号的归属。



#### 终结符与非终结符

**终结符（Terminal）**是构成句子的基本符号，推导到它就不再展开；**非终结符（Nonterminal）**是表示语法成分的占位符号，必须继续推导直到全部替换为终结符。

- 命名习惯：非终结符常用大写字母或尖括号包裹的名字，终结符常用小写字母或具体符号。
- 出现位置：非终结符可出现在产生式左部，终结符只能出现在右部。
- 语言中的地位：终结符是句子的组成材料，非终结符是句子结构的中间记号。
- 判断依据：某符号能否出现在左部，是区分两类符号最直接的依据。
- 与词法输出的关系：词法分析输出的记号类别在文法中对应终结符，词法规则的描述不进入本层。

**考察形式**：综合知识选择题，考查给定文法中终结符与非终结符的划分。



#### 产生式与直接推导

**产生式（Production）**是形如 A → α 的重写规则，规定把左部的非终结符替换为右部的符号串；**直接推导（Direct Derivation）**是把符号串中的某个非终结符按其产生式一步替换的过程，记作箭头加下标 G 的形式。

- 规则形式：左部为单个非终结符，右部为任意文法符号串，可为空串。
- 推导的记号：α 经一步替换得到 β 记作 α 直接推出 β，连续多步记作加上双箭头。
- 替换位置：一步只替换一个非终结符，位置可在串中任意处。
- 推导的方向：从左部到右部展开，反向使用即归约。
- 错误用法：一次替换多个非终结符不构成一步推导。

**考察形式**：综合知识选择题，考查产生式的形式约束与一步推导的定义。



#### 推导与归约

**推导（Derivation）**是从开始符号出发、反复使用产生式展开非终结符的序列；**归约（Reduction）**是推导的逆过程，从符号串出发逐步替换回非终结符。

- 多步推导：若存在串序列使每一步都是直接推导，则首串可推导出末串。
- 长度：推导的步数为串序列中直接推导的次数。
- 推导的多样性：同一句子常有多条不同推导，区别只在展开非终结符的先后次序。
- 归约的用途：自下而上分析按归约方向工作，细节见本主题第 7 篇 语法分析：自下而上。
- 推导的用途：自上而下分析按推导方向工作，细节见本主题第 6 篇 语法分析：自上而下。

> **辨析提示**：题目问某串能否由文法推出时，只认可达性，不要求推导唯一；问共有几种推导时，需区分是否把非终结符展开次序一并计入。

**考察形式**：综合知识选择题，考查推导的步数计算与推导方向与两类分析方法的对应。



#### 句型、句子与语言

**句型（Sentential Form）**是从开始符号推导出的任意符号串，其中可以含非终结符；**句子（Sentence）**是仅由终结符构成的句型；**语言**是该文法全部句子的集合，记作由文法生成的语言。

- 包含关系：句子是句型的特例，全部句型包含全部句子。
- 语言的定义：从开始符号推导出的终结符串全体构成该文法生成的语言。
- 语言与文法的关系：一个文法唯一确定一个语言，一个语言可由多个不同文法生成。
- 等价文法：生成同一语言的文法互称等价文法，它们的四元组可以完全不同。
- 边界情形：若开始符号本身是终结符串则重新构造文法，非终结符不得直接充当句子。

**考察形式**：综合知识选择题，考查句型与句子的区分、文法与语言的多对一关系。



### 文法的类型（乔姆斯基谱系）

乔姆斯基按产生式的形式把文法分为四类，四类文法对应的语言族形成严格的包含关系。本模块按 0 型到 3 型依次给出定义与判别口径。

#### 文法分类的依据

**文法的分类**依据产生式左右两部的形式限制，限制越强，描述能力越弱，相应的识别模型也越简单。

- 分类的维度：左部是否受上下文约束、右部长度是否受限制，两项共同决定文法类型。
- 限制与能力：限制越多的文法能生成的语言越少，识别它所需的自动机越简单。
- 分类的用途：确定语言的类别后即可选用对应的识别模型，直接决定分析程序的组织方式。
- 四类的次序：习惯按 0 型、1 型、2 型、3 型编号，编号越大限制越强。
- 名称来源：四类文法对应乔姆斯基谱系，是形式语言理论的分类框架。

**考察形式**：综合知识选择题，考查文法分类所依据的两项形式限制。



#### 0 型与 1 型文法

**0 型文法（Type 0 Grammar）**又称短语文法，其产生式左右两部都是任意符号串且左部非空；**1 型文法（Type 1 Grammar）**又称上下文有关文法，其产生式的形式为 α A β → α γ β。

- 0 型的限制：只要求左部含至少一个非终结符且长度不为零，右部可任意。
- 0 型的识别：可由图灵机识别，能生成递归可枚举语言。
- 1 型的限制：替换非终结符 A 时必须带上左右上下文 α 与 β，右部一般不得短于左部。
- 1 型的例外：允许形如 A → ε 的产生式，前提是 A 不出现在任何产生式右部。
- 上下文有关的含义：只有 A 的左右邻居分别匹配 α 与 β 时才能实施替换，替换的结果依赖上下文。

```text
0 型示意：  α A β → 任意串                     左部含非终结符即可，右部无长度约束
1 型示意：  α A β → α γ β                      替换 A 时必须保留左右上下文
1 型等价写法： A → γ 仅在上下文 α … β 下成立      γ 一般非空
例外条款：  A → ε  允许，但 A 须不出现在任何右部
```

**考察形式**：综合知识选择题，考查 0 型与 1 型文法的形式限制及其语言族名称。



#### 2 型文法（上下文无关文法）

**2 型文法（Type 2 Grammar）**又称上下文无关文法，其产生式的左部是单个非终结符，右部可为任意符号串；无论非终结符出现在什么位置，替换方式都相同。

- 形式：A → γ，左部只有一个非终结符。
- 上下文无关的含义：替换 A 与它左右两侧出现什么符号无关。
- 描述能力：能描述嵌套与配对结构，覆盖程序设计语言的大部分语法。
- 识别模型：由下推自动机识别，对应的语言称为上下文无关语言。
- 表达边界：不能描述需要跨结构比较名称的一类性质，如变量先声明后使用。

> **辨析提示**：判断一个文法是 2 型还是 1 型，只看左部是否恰为单个非终结符。左部带任何附加符号即退为上下文有关。

**考察形式**：综合知识选择题与案例分析题，考查上下文无关文法的形式约束与嵌套结构的描述能力。



#### 3 型文法（正规文法）

**3 型文法（Type 3 Grammar）**又称正规文法，其产生式只允许两种形式——右线性文法为 A → aB 或 A → a，左线性文法为 A → Ba 或 A → a，其中 a 为单个终结符。

- 两种形式：右线性把非终结符放在右端，左线性把它放在左端，同一文法不得混用两种形式的单串。
- 描述能力：只能描述有穷状态可判定的结构，不能描述嵌套配对。
- 识别模型：由有限自动机识别，对应的语言称为正规语言。
- 与正规式的对应：正规文法、正规式与有限自动机三者描述能力等价，词法分析据此工作。
- 边界：正规语言是上下文无关语言的真子集，凡是需要计数配对的记号串都不属于它。

```text
右线性：A → aB | a                             非终结符在最右端
左线性：A → Ba | a                             非终结符在最左端
不可行：A → aBb                                右部出现两个非终结符，超出 3 型
等价对象：正规文法、正规式、有限自动机              三者描述能力等价
```

**考察形式**：综合知识选择题，考查右线性与左线性的形式、3 型文法与有限自动机的对应。



#### 四类文法的包含关系与识别能力

四类文法对应的语言族形成严格的真包含关系，识别它们的自动机也随之逐级增强。

```text
语言族包含关系（由大到小）：0 型 ⊃ 1 型 ⊃ 2 型 ⊃ 3 型
  0 型 递归可枚举语言   ⊃   1 型 上下文有关语言
  2 型 上下文无关语言   ⊃   3 型 正规语言
识别模型对应：0 型 图灵机 / 1 型 线性有界自动机 / 2 型 下推自动机 / 3 型 有限自动机
```

- 严格性：每一层包含都是真包含，都能举出属于上层却不属于下层的语言。
- 典型反例：括号配对属于 2 型而不属于 3 型，先声明后使用越出 2 型的能力上限。
- 识别模型的强弱：从有限自动机到图灵机，可用的存储能力依次增强。
- 选择题的常见变体：给出一个具体文法或语言，要求判断它属于哪一型。
- 实践取舍：程序设计语言的语法定在 2 型，既能表达必要结构又保证分析可行。

**考察形式**：综合知识选择题，考查四类语言族的包含关系与识别模型的配对。



### 上下文无关文法与语法树

上下文无关文法与程序设计语言的语法关系最紧密，本模块给出它的书写约定、两种标准化推导与二义性问题，并交代文法化简的基本手段。

#### 上下文无关文法的书写约定

上下文无关文法在实践中有一套固定的简写约定，它使文法的可读性显著提高而不改变形式定义。

- 大写字母表非终结符，小写字母与具体符号表终结符。
- 第一个产生式左部的非终结符约定为开始符号，不再单列。
- 同一左部的多条产生式合并为一条，右部之间用竖线分隔。
- 空串的产生式写作 A → ε，ε 不得书写在右部的其他位置。
- 非终结符用有意义的名字时可写完整单词，如表达式、项、因子。

```text
约定写法：
  E → E + T | T
  T → T * F | F
  F → ( E ) | i
说明：E 为开始符号，T 为项，F 为因子，i 为标识符终结符
等价展开：E → E + T、E → T 两条产生式
```

**考察形式**：综合知识选择题或案例分析题，考查简写文法还原为完整产生式集合。



#### 最左推导与最右推导

**最左推导（Leftmost Derivation）**是每一步都替换当前串中最左非终结符的推导；**最右推导（Rightmost Derivation）**又称规范推导，是每一步都替换最右非终结符的推导。

- 唯一性相对性：给定句子与文法，最左推导与最右推导各自不唯一的情形取决于文法是否二义。
- 规范推导的地位：最右推导的逆序恰好构成规范归约，是自下而上分析的理论依据。
- 记号：最左推导与最右推导常在推导箭头上加标记区分。
- 与语法树的联系：同一棵语法树可读出唯一的最左推导与唯一的最右推导。
- 计算题的常见要求：给出句子求最左推导与最右推导，或由推导还原语法树。

```text
文法：E → E + T | T，T → T * F | F，F → ( E ) | i
句子：i + i * i

最左推导（每步替换最左非终结符）      最右推导（每步替换最右非终结符）
  E ⇒ E + T                            E ⇒ E + T
  ⇒ T + T                              ⇒ E + T * F
  ⇒ F + T                              ⇒ E + T * i
  ⇒ i + T                              ⇒ E + F * i
  ⇒ i + T * F                          ⇒ E + i * i
  ⇒ i + F * F                          ⇒ T + i * i
  ⇒ i + i * F                          ⇒ F + i * i
  ⇒ i + i * i                          ⇒ i + i * i
```

**考察形式**：综合知识选择题或案例分析题，考查给定句子的最左推导与最右推导书写。



#### 语法树与推导的对应

**语法树（Parse Tree）**又称推导树，是反映推导过程的树形结构，根为开始符号，内部结点为非终结符，叶子按从左到右的顺序组成句型。

- 结点规则：内部结点标非终结符，其子结点从左到右恰为该非终结符某条产生式的右部。
- 叶子与句型：叶子序列即句型的符号序列，叶子全为终结符时该序列是句子。
- 与推导的对应：每一棵语法树对应一条最左推导与一条最右推导，推导次序不再体现在树上。
- 子树对应：语法树的一棵子树对应一个句型中的语法成分。
- 二义性的表现：一个句子存在两棵不同语法树时该句子在此文法下二义。

```text
句子 i + i * i 的语法树（缩进表示层次）：
  E
    E → T → F → i
    +
    T
      T → F → i
      *
      F → i
要点：+ 在树的上一层，* 在下一层，乘法先结合
```

**考察形式**：综合知识选择题或案例分析题，考查由推导画语法树、由语法树读句子与辨析树形差异。



#### 二义性与二义文法

**二义性（Ambiguity）**指同一个句子在该文法下存在两棵不同的语法树；含有二义句子的文法称为**二义文法（Ambiguous Grammar）**。

- 判定对象：二义性是文法或句子的性质，不是语言的性质。
- 语言层面：存在某个语言，其任何文法都是二义的，这类语言称为固有二义语言。
- 常见来源：运算符优先级未分层、悬挂 else 问题、算符结合性未规定。
- 影响：推导不唯一会直接影响语义分析与代码生成的确定性。
- 危害判断：分析程序若按固定次序选择规则，结果可能与语义预期不一致。

> **辨析提示**：题目给出两棵语法树只说明该句子二义，据此不能断言文法固有二义，更不能断言该语言固有二义。

**考察形式**：综合知识选择题，考查二义性的判定对象与二义性对后续阶段的影响。

> [!WARNING]
> **警告内容**：二义文法用在本主题后两篇的分析方法上会直接失效。LL 分析要求文法无二义且无左递归，LR 分析虽能容忍部分二义，但冲突消解规则由工具预设，实际语义可能与设计者预期不符。考试中若题目给出二义文法并要求构造分析表，先判断是否属于此类陷阱。



#### 文法的等价、化简与消除

**文法的等价**指两个文法生成同一语言；**文法的化简**指在不改变生成语言的前提下削减冗余成分，使文法更适合分析程序使用。

- 等价判定：两文法等价当且仅当它们生成的语言相同，四元组本身可以完全不同。
- 化简目标：删除无用符号与多余产生式，使文法更紧凑、更易构造分析表。
- 化简前提：化简必须保持语言不变，改变语言即不是化简。
- 化简的次序：先删无用符号，再删空的产生式，最后删单产生式，次序颠倒会反复返工。
- 实践意义：化简后的文法更容易判定是否满足特定分析方法的适用条件。

**考察形式**：综合知识选择题，考查等价文法的定义与化简的基本原则。



#### 无用符号、空产生式与单产生式的消除

**无用符号（Useless Symbol）**是不能出现在任何句子的推导过程中的文法符号；**单产生式（Unit Production）**是形如 A → B 且右部为单个非终结符的产生式。

- 无用终结符判定：不存在从开始符号出发可达它的推导。
- 无用非终结符判定：它推导不出任何终结符串，或从开始符号不可达，满足其一即无用。
- 删无用符号的次序：先删推导不出终结符串的非终结符，再删从开始符号不可达的符号，两步都要连产生式一并删除。
- 空产生式的消除：把含有可空的非终结符的产生式逐条替换为去掉该非终结符后的各条产生式，开始符号可空的场合单列一条开始符号到空串的产生式。
- 单产生式的消除：把单产生式链上的后继产生式直接并入，删去中间环节。

```text
消除单产生式示例：
  原有：A → B，B → b            单产生式 A → B
  消除：A → b，B → b            把 B 的右部直接并入 A，删去 A → B
消除空产生式示例（设 A 可空）：
  原有：S → A a，A → ε            A 可推出空串
  消除：S → A a，S → a           额外补上去掉 A 后的产生式，再删 A → ε
```

> **说明**：空产生式与单产生式的消除会改变文法的形状但不改变它生成的语言，是 LL(1) 分析前常见的准备工作，细节见本主题第 6 篇 语法分析：自上而下。

**考察形式**：综合知识选择题或案例分析题，考查无用符号的两类判定与空产生式、单产生式的消除步骤。

> [!CAUTION]
> **注意内容**：化简三步的次序不可颠倒。若先删单产生式再删空产生式，新并入的右部可能又产生出可空的非终结符，导致前一步的成果作废、需要返工；删除无用非终结符时若先删不可达符号，会把本来可推导的符号误判为无用。每完成一步都应重新检查产生式集合。



### 形式语言与自动机的对应

文法与自动机是同一件事的两种描述，本模块给出四类文法对应的识别模型，并交代这套理论在编译实践中的落点。

#### 正规文法与有限自动机的对应

正规文法、正规式与有限自动机三者描述能力完全等价，都只能刻画有穷状态可判定的语言，词法分析器即建立在这一等价关系之上。

- 三种描述可互相转换：正规式可转 NFA，NFA 可确定化并最小化，正规文法可与自动机互推。
- 状态与符号的对应：正规文法的非终结符对应自动机的状态，终结符对应输入符号。
- 转换的用途：把词法规则写成正规式后自动生成扫描器代码，减少手工编码。
- 能力边界：不能描述需要无限计数或嵌套配对的结构，这类语言交给 2 型文法处理。
- 与前一主题的衔接：NFA 确定化与 DFA 最小化的具体算法见本主题第 4 篇 词法分析与有限自动机。

**考察形式**：综合知识选择题，考查正规文法、正规式与有限自动机三者的等价关系。



#### 上下文无关语言与下推自动机

**下推自动机（Pushdown Automaton）**是在有限状态机基础上增设一个栈作为辅助存储的识别装置，它与上下文无关文法等价，是语法分析的理论模型。

- 存储差别：相对有限自动机多了栈，因此能记录任意深度的嵌套信息。
- 两种接受方式：终态接受与空栈接受，两种方式可相互转换。
- 与文法的对应：上下文无关文法与下推自动机描述能力等价，可互相转换。
- 分析中的体现：自下而上分析的移进栈与自上而下分析的推导栈，都是这一模型的具体实现。
- 定性与确定性：存在非确定的下推自动机，其对应的文法不一定能用确定性方法分析，这正是 LL 与 LR 分析适用条件差异的根源。

**考察形式**：综合知识选择题，考查下推自动机的构成、与上下文无关文法的等价关系。



#### 四类文法与识别模型对照

四类文法、四类语言与四类自动机的对应关系是选择题的固定来源，须作为一张对照表达成记忆。

```text
文法类型        语言族              识别模型
0 型 短语      递归可枚举语言      图灵机
1 型 上下文有关  上下文有关语言      线性有界自动机
2 型 上下文无关  上下文无关语言      下推自动机
3 型 正规      正规语言            有限自动机

记忆线索：文法的限制越强，语言越小，识别模型越简单
  短语 → 图灵机 → 上下文有关 → 线性有界 → 上下文无关 → 下推 → 正规 → 有限
```

- 配对关系：每一型文法与唯一一类自动机对应，不交叉。
- 能力方向：从上往下限制递增，从下往上能力递增。
- 考点密度：该对照关系几乎每次考试都会以选择或填空的形式出现。
- 与编译的衔接：词法分析用 3 型，语法分析用 2 型，是本主题两篇分析文章的选型依据。

**考察形式**：综合知识选择题，考查文法、语言、自动机三者的配对关系。



#### 文法理论在编译中的落点

文法与语言的形式定义在编译实践中并不停留于理论，它直接决定了各阶段采用的方法与工具。

- 词法分析：用 3 型文法与有限自动机描述记号构成，常由正规式自动生成扫描器。
- 语法分析：用 2 型文法描述程序结构，按 LL 或 LR 方法构造分析程序或分析表。
- 语法分析生成器：以产生式为输入自动生成分析程序，输入形式的说明见本主题第 3 篇 编译过程与阶段划分。
- 语义分析：在语法树基础上附加属性与翻译规则，属性文法的做法见本主题第 8 篇 语义分析与语法制导翻译。
- 能力边界意识：超出 2 型文法的性质不能靠语法规则表达，须移到语义阶段处理。

**考察形式**：综合知识选择题或论文写作的理论铺垫，考查形式语言理论在编译各阶段的具体落点。
