## 条件与循环

### 条件分支

#### 条件块

**条件块让工作流长出判断力**：按条件真假走不同连线。

- 条件块支持多种比较：值相等、包含、大于小于、正则匹配
- 比较对象可以是表达式：变量、数据表、上一块输出都可参与
- 真假两条出口连线分别接入不同分支
- 多条件用多个条件块串联，或用 JavaScript 代码块自己判断

> 条件的价值判断来自本库 JavaScript 系列第 4 篇分支与循环：真值判定、严格相等这些 JS 语义在条件块里同样适用，表达式返回值最终都会走一遍 JS 的类型判断。

**速记**：**真假两出口，比较对象全可表达式**。



#### 元素级条件

**两类元素条件块服务页面判断**：存在性与可见性。

- 元素存在判断块：页面上有没有匹配选择器的元素
- 元素可见判断块：元素在不在且是否可见（隐藏元素不算）
- 两者的真假出口同样驱动分支
- 典型用途：登录态检查、弹窗处理、内容加载确认

> “存在”与“可见”是两回事：display 为 none 的元素存在但不可见。弹窗判断通常该用可见性而非存在性，页面 DOM 里常年躺着隐藏弹窗模板的站点比比皆是。

**速记**：**存在看 DOM，可见看渲染，弹窗判断选后者**。



### 循环

#### 循环数据块

**循环数据块遍历数据集合**：数组、表格、数字区间都能跑。

- 循环数据源可选：变量中的数组、数据表、指定数字范围
- 每轮迭代当前项通过 loopData 关键字被循环体内的块访问
- 循环体是子图：循环块到结束块之间的连线代表每轮执行的路径
- 迭代索引与当前值都可进表达式（详见 6 篇）

> 循环抓取的标准骨架：循环数据块（数据源为列表）加取文本块（取当前项字段）加数据表写入，循环结束再接导出块。骨架搭对了，其余都是参数。

**速记**：**数据源进去，当前项出来，loopData 随身带**。



#### 循环元素块

**循环元素块直接遍历页面元素**：不用先取数据再循环。

- 输入一组选择器匹配到的元素列表，逐个迭代
- 循环体内对当前元素执行点击、取文本等操作
- 与循环数据块的区别：数据源是页面 DOM 而非数据集合
- 页面元素动态加载时，配合滚动与等待使用

> 遍历列表页的行项是它的主场：每行一个迭代，行内各列分别取值。若列表页有分页，外层套一个翻页循环，内层用循环元素块处理当前页。

**速记**：**DOM 即数据源，行级迭代一气呵成**。



#### While 循环与跳出

**While 循环处理不定次数的迭代**：条件为真就一直转。

- While 块在每轮开始评估条件，为假时走出循环
- 典型场景：下一页按钮存在就翻页
- 循环跳出块可中途退出：满足特定条件提前结束
- 必须设计退出路径：条件永不翻假就是死循环

> 防死循环三板斧：条件里引入会变化的量（页码、结果数）、外层加最大轮次判断、While 体内必有一条能让条件翻假的路径。三管齐下才敢上线跑无人值守。

**速记**：**条件翻假才出圈，最大轮次是保险丝**。



### 控制辅助

#### 延迟与重复

**延迟块与重复块是节奏控制的两件工具**：等待与次数。

- 延迟块：固定毫秒等待，垫动画、防频控
- 重复任务块：把一段子图重复执行 N 次，无需数据源
- 两者常配合使用：每次重复后垫延迟，模拟人的操作节奏
- 频控敏感站点（登录、下单）务必加延迟，节奏太快触发风控

> 重复块与循环数据块的选择标准是有没有数据要遍历：纯次数重复用重复块，带数据迭代用循环数据块，混用反而绕。

**速记**：**延迟垫节奏，重复管次数，有数据才用循环**。
