## 表达式与模板语法

### 表达式基础

#### mustache 模板

**表达式用双花括号包裹**：块输入框里静态文本与动态值混写。

- 格式：{{keyword}}，花括号内是动态部分，花括号外是静态文本
- 例子：{{variables.baseUrl}}/search?q={{variables.keyword}} 拼出完整 URL
- Automa 用 mustache 模板并扩展了自己的数据源与函数
- 任何块的几乎任何输入框都支持表达式

> 表达式的本质是字符串插值加数据求值：求值引擎在背后跑的是 JavaScript。所以表达式的行为可以用 JS 的类型转换规则解释（本库 JavaScript 系列第 3 篇），拼接出的最终值永远是字符串。

**速记**：**双花括号是插值，静态动态随手混**。



#### 八大数据源

**花括号内的关键字指向八类数据**：记全这张清单。

- variables：工作流变量
- table：数据表
- loopData：循环数据块的当前迭代项
- prevBlockData：上一个块的输出
- globalData：本次执行注入的全局数据
- googleSheets：Google 表格数据
- activeTabUrl：当前活动标签页的 URL
- workflow：被 Execute Workflow 块调用的子工作流数据

> 关键字就是数据面的地图：写表达式前先问数据在哪张面上，选对关键字，路径就顺着结构点下去。

**速记**：**变量表格循环项，上块输出全局参**。



### 路径语法

#### 点号路径

**v1.22 起推荐点号路径**：顺着数据结构逐层取值。

- {{variables.socials}} 取整个数组
- {{variables.socials.0.url}} 取数组第一元素的 url 属性，0 即下标
- {{table.0.title}} 取表格第一行的 title 列
- 旧版 @ 语法（{{variables@key}}）在 v1.22 及以后仍兼容，新工作流建议统一用点号

> 点号路径与 JS 的属性访问同构：数组下标、对象键、多级嵌套一路点下去。路径写不通时，回 JS 系列 2 篇的“对象与内存”想清楚数据的真实形状，路径自然就通了。

**速记**：**点号一层层下钻，数组下标也是一层**。



#### 特殊路径与方括号

**两条进阶规则处理复杂取值**：$last 与表达式嵌套。

- $last 特殊路径：{{table.$last.title}} 取最后一行
- 循环中取当前索引行：{{table.[loopData.loopId.$index].columnName}}
- 表达式内再访问数据时，内层表达式必须用方括号包裹
- $getLength([table.1.text]) 这类函数参数同理，数据访问段加方括号

> 方括号规则的根源是解析歧义：花括号内外两层都要求值，方括号是“这里是我要的数据访问”的显式声明。嵌套表达式报错时，第一反应就是检查方括号。

**速记**：**$last 取末行，嵌套取值方括号声明**。



### 表达式与 JavaScript

#### 表达式里的 JS 函数

**$ 前缀函数是表达式的算力来源**：内建在模板里的 JS 工具。

- 表达式可以直接调用 $ 系列函数：{{ $randint(1, 10) }}、{{ $date('YYYY-MM-DD') }}
- 函数返回值嵌入所在字符串，参与块的输入
- 完整函数清单见 7 篇，此处建立“表达式可调用函数”的心智即可
- 超出函数能力的复杂逻辑，交给 JS 代码块（8 篇）

> $ 函数是块输入框里的 JS 标准库：字符串处理、日期、随机、算术都有了。判断逻辑放条件块，取值变换放表达式，重逻辑放代码块，三层各司其职。

**速记**：**$ 函数补算力，表达式即轻量 JS**。



#### 何时用表达式何时用代码块

**表达式管取值，代码块管逻辑**：分界线画在复杂度上。

- 简单取值、拼串、格式化、过滤：表达式一行搞定
- 多步计算、条件嵌套、异常处理、DOM 操作：JS 代码块
- 表达式返回的是字符串，参与数值比较时注意类型（条件块的比较通常帮你处理，但心里要有数）
- 同一段逻辑出现在三个以上块中时，考虑沉淀为变量或子工作流

> 与本库 JavaScript 系列的对照：表达式像模板字符串里的插值，代码块才是函数。凡需要语句（if、循环、try）的地方，表达式到不了，代码块顶上。

**速记**：**取值用表达式，语句进代码块**。
