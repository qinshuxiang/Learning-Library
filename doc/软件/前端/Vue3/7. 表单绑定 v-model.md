## 表单绑定 v-model

### v-model 的定义与本质

#### v-model 是表单双向绑定的语法糖

**v-model**：是 Vue 实现 **数据到视图、视图回数据** 双向同步的指令，本质是 **属性绑定加事件监听** 的语法糖。

- 单向绑定只把数据渲染进表单元素的 value，用户输入不会写回数据。
- v-model 在单向绑定之上，自动监听用户的输入事件，把新值写回响应式数据。
- 双向绑定只作用于 **表单元素与组件**，普通 HTML 元素没有可回写的输入语义，不能使用 v-model。

> 辨析：v-model 的双向指数据与表单元素之间的双通道；在组件上使用时仍遵守 **单向数据流**——父组件传值、子组件发事件，详见本系列 9. 组件事件与组件级 v-model.md。

**速记**：v-model = **value 绑定 + 输入监听** 的合写。



#### 原生 input 上 v-model 的等价展开

**等价展开**：在原生文本输入框上，v-model 展开后是 **:value 绑定加 input 事件监听** 的完整写法。

```html
<input v-model="text">
<!-- 等价于下面的展开形式 -->
<input :value="text" @input="text = $event.target.value">
```

- :value 把响应式数据 text 渲染进输入框，是数据到视图的通道。
- @input 在用户每次键入时触发，事件对象 $event 的 target 即触发事件的元素，读取其 value 写回 text。
- 两条通道合起来，数据与输入框内容保持一致。

> 注意：展开写法里读取的是 event.target.value 而不是事件对象本身；@input 的处理逻辑也可以换成方法名或箭头函数，效果相同。

**速记**：**value 渲染进框，input 写回数据**。



#### 不同表单元素使用不同的属性与事件

**元素差异**：v-model 在不同原生表单元素上绑定的 **属性与监听的事件各不相同**，这是 Vue 的内部约定。

- 文本类元素 input 与 textarea：绑定 **value 属性**，监听 **input 事件**。
- 复选框 checkbox 与单选按钮 radio：绑定 **checked 属性**，监听 **change 事件**。
- 选择器 select：绑定 **value 属性**，监听 **change 事件**。

> 辨析：无需背诵全部展开细节，只需理解绑哪个属性、听哪个事件这一框架；常考的是文本框用 input 事件、复选框与 select 用 change 事件这一组差异。

**速记**：文本走 **input**，复选与选择走 **change**。



#### v-model 忽略表单元素的初始属性

**初始值规则**：v-model 会 **忽略表单元素上书写的 value、checked、selected 初始属性**，一律以响应式数据的初始值为准。

- 表单元素里静态写的 value="abc" 不会成为 v-model 的初值。
- 真正的初值来自被绑定的 ref 或 reactive 属性的初始值。
- 因此初值应写进数据里，而不是写死在模板属性上。

> [!IMPORTANT]
> **重要内容**：把初值同时写在属性与数据两处且互不一致时，页面看似正常，实则数据才是权威、属性会被覆盖。初值只在数据里定义一次，可避免排查这类隐性不一致。

**速记**：初值 **只认数据**，属性被无视。



### 文本与多行文本的绑定

#### 文本输入框 input 的绑定

**文本绑定**：文本输入框用 v-model 绑定一个字符串响应式数据，输入与数据实时同步。

```html
<input v-model="message" placeholder="请输入内容">
```

```js
import { ref } from "vue";
const message = ref("");
```

- 用户每键入一个字符，input 事件触发一次，message 随之更新。
- message 更新后，:value 通道又把新值渲染回输入框，形成闭环。
- placeholder 是原生占位符，与 v-model 不冲突。

> 辨析：type="number" 的输入框从事件里取到的仍是 **字符串**，并不会自动变数字；要拿到数字需加 .number 修饰符，见下文修饰符一节。

**速记**：文本框 **键入即同步**。



#### 多行文本 textarea 的绑定

**多行绑定**：textarea 与文本输入框一致，用 v-model 绑定字符串，只是呈现为多行。

```html
<!-- 错误写法：textarea 内部使用插值不会生效 -->
<textarea>{{ article }}</textarea>
<!-- 正确写法：使用 v-model -->
<textarea v-model="article" rows="4"></textarea>
```

```js
import { ref } from "vue";
const article = ref("");
```

- 绑定方式、触发事件与文本输入框完全相同。
- rows 是原生行数属性，不参与 v-model 的同步。
- 换行符以真实字符形式保存在数据里。

> [!WARNING]
> **警告内容**：textarea 内部 **不支持插值表达式**。原因是插值依赖文本节点的更新机制，而 textarea 的内部文本在浏览器里是它自身的表单值而非普通文本节点，Vue 因此要求多行文本一律走 v-model，插值会被忽略。

**速记**：textarea **禁插值，必用 v-model**。



### 复选框的绑定

#### 单个复选框绑定布尔值

**单复选**：单个复选框绑定一个 **布尔值**，勾选为 true，取消为 false。

```html
<input type="checkbox" v-model="checked">
```

```js
import { ref } from "vue";
const checked = ref(true);
```

- checked 为 true 时复选框呈选中态，为 false 时呈未选中态。
- 用户点击切换，change 事件把新的布尔值写回 checked。
- 常用于同意协议、功能开关等二元场景。

> 辨析：初始值写成非布尔值时，Vue 会按真值判断选中态，但写回的仍是布尔值；保持布尔类型是最佳实践。

**速记**：单复选 **勾选 true，取消 false**。



#### 多个复选框绑定同一数组

**多复选**：多个复选框绑定 **同一个数组**，每个复选框的 value 决定它被勾选时存入数组的值。

```html
<input type="checkbox" value="Vue" v-model="frameworks">
<input type="checkbox" value="React" v-model="frameworks">
<input type="checkbox" value="Angular" v-model="frameworks">
```

```js
import { ref } from "vue";
const frameworks = ref([]);
```

- 勾选 Vue 后数组变为只含 Vue 的数组，再勾选 React 则追加进去。
- 取消勾选会把对应值从数组中移除。
- 数组初始值里已存在的值，对应的复选框自动呈选中态。

> 辨析：单复选绑布尔、多复选绑数组，区别只看 **绑定的数据类型**，不看复选框个数——把两个复选框绑到同一个布尔值上，会出现联动错乱。

**速记**：多复选 **勾选进数组，取消即移除**。



#### true-value 与 false-value 自定义选中值

**自定义值**：true-value 与 false-value 是 Vue 专属属性，用来 **指定复选框选中与未选中时写回数据的值**。

```html
<input type="checkbox" v-model="status" true-value="启用" false-value="停用">
```

- 勾选时 status 变为字符串启用，取消时变为停用。
- 不写这两个属性时，默认行为就是布尔 true 与 false。
- 需要动态值时用 v-bind 绑定，写成 :true-value="activeValue" 的形式，值可以是任意类型。

> 注意：true-value 与 false-value 只决定 **写回数据的值**，不改变复选框的视觉勾选逻辑；选中态由数据是否等于 true-value 推导。

**速记**：true-value 定 **勾值**，false-value 定 **空值**。



### 单选按钮的绑定

#### radio 绑定选中的值

**单选绑定**：一组单选按钮绑定 **同一个响应式数据**，数据当前的值决定哪一项选中，选中项的 value 又写回数据。

```html
<input type="radio" value="A" v-model="picked">
<input type="radio" value="B" v-model="picked">
```

```js
import { ref } from "vue";
const picked = ref("A");
```

- picked 为 A 时第一项选中；用户选 B 后 picked 变为 B，A 自动取消。
- 一组 radio 的互斥由 v-model 统一管理，无需手写联动逻辑。
- 数据初始值若不匹配任何 value，则初始时一项都不选中。

> 辨析：radio 的 value 属性此时是 **写回数据的来源值**，不是显示文本；用户看到的文字写在标签随后的文本节点里，二者可以不同。

**速记**：同组 radio **共绑一个值**，value 即选中值。



#### name 分组与 v-model 的分工

**分组分工**：name 属性负责 **原生表单层面的分组与提交**，v-model 负责 **Vue 层面的选中联动**，二者职责不同。

- 原生表单直接提交时，浏览器按 name 分组，同组 radio 才互斥。
- 在 Vue 应用里，同组 radio 绑同一个 v-model，即使不写 name 也能互斥。
- 需要 FormData 收集、原生提交或表单语义时，仍应补上相同的 name。

> [!TIP]
> **建议内容**：即便 v-model 已能互斥，也建议保留 name 属性，一是兼容非 Vue 场景与表单语义，二是满足自动化测试与无障碍工具对分组的预期。

**速记**：name 管 **原生分组**，v-model 管 **响应式互斥**。



### 选择器的绑定

#### 单选 select 绑定一个值

**单选选择器**：select 单选时绑定一个字符串，选中项的 value 写入数据，数据又决定选中项。

```html
<select v-model="selected">
  <option disabled value="">请选择</option>
  <option value="A">选项 A</option>
  <option value="B">选项 B</option>
</select>
```

```js
import { ref } from "vue";
const selected = ref("");
```

- option 的 value 是写入数据的值，标签内文本是显示给用户的文案。
- option 不写 value 时，以 **标签内的文本内容** 作为提交值。
- 带 disabled 的占位 option 用于提示用户，不能被选中提交。

> 辨析：v-model 绑定 select 时，Vue 以数据为准设置选中项，无需在 option 上写 selected 属性；写了也会被忽略，理由同前文初始值规则。

**速记**：select 单选 **value 进数据，文本给用户**。



#### 初始值设为空串的 iOS 兼容辨析

**空串初值**：select 的 v-model 初值应设为 **空字符串**，并配一个 value 为空的禁用占位 option，这是官方推荐的兼容写法。

- 初值与任何 option 都不匹配时，select 呈现未选中状态。
- 在 iOS 的 Safari 上，未选中状态会导致用户 **无法选中第一个选项**，因为原生交互不会触发第一项的 change。
- value 为空的禁用 option 充当占位选中项，让 select 始终有一个当前值，避开该兼容问题。

> [!CAUTION]
> **注意内容**：初值写 undefined 或 null 而非空串时，部分移动端浏览器不会渲染任何选中项，用户在 iOS 上点第一项可能毫无反应。请保持初值与占位 option 的空 value 相匹配。

**速记**：初值 **空串配禁用占位项**，防 iOS 点不动第一项。



#### 多选 select 绑定数组

**多选选择器**：select 加上 multiple 属性后变为多选，v-model 应改绑 **数组**，每个选中项的 value 按勾选情况存入。

```html
<select v-model="pickedList" multiple>
  <option value="A">选项 A</option>
  <option value="B">选项 B</option>
  <option value="C">选项 C</option>
</select>
```

```js
import { ref } from "vue";
const pickedList = ref([]);
```

- 点选一项即追加其 value，再次点击取消则移除。
- 数组初值中的值对应的 option 自动呈选中态。
- 多选在桌面端需按住 Ctrl 或 Command 点击，移动端由系统提供多选交互。

> 辨析：多选必须绑数组；若误绑字符串，数据类型与实际写入的数组不一致，模板里按字符串处理的逻辑会出错。

**速记**：multiple 对应 **数组绑定**。



#### 动态选项用 v-for 渲染 option

**动态选项**：选项来自接口或配置时，用 v-for 遍历渲染 option，v-model 的用法不变。

```html
<select v-model="city">
  <option v-for="item in cityList" :key="item.code" :value="item.code">
    {{ item.name }}
  </option>
</select>
```

```js
import { ref } from "vue";
const city = ref("");
const cityList = ref([
  { code: "0571", name: "杭州" },
  { code: "021", name: "上海" }
]);
```

- :key 提供稳定的 diff 标识，建议用唯一编码而非数组下标。
- :value 绑定真正的提交值，插值文本只作显示。
- 列表异步加载后，v-model 的值仍能自动匹配到新渲染的 option。

> 辨析：v-for 渲染的选项与手写 option 可以混用，DOM 顺序即书写顺序；混用时确认 v-model 的值能同时匹配到两类选项。

**速记**：**v-for 出选项，:key 稳标识，:value 存真值**。



### 值绑定 v-bind

#### 值绑定把非字符串值传给表单元素

**值绑定**：指用 v-bind 给复选框或 option 绑定 **非字符串的动态值**，让表单元素携带任意 JavaScript 值。

- 静态属性 value="A" 传入的只能是字符串。
- 用 v-bind 绑定后，值可以是数字、布尔、对象或运行时计算的引用。
- 选中时写回数据的是 **原始值本身**，而不是被转成字符串的副本。

> 辨析：绑定对象时提交到数据里的就是那个对象引用，后续可直接读取其属性；若只用字符串，还要再查表换算，这正是值绑定的价值。

**速记**：v-bind 让表单元素 **携带真值而非字符串**。



#### 复选框与选项绑定对象字面量

**对象绑定**：复选框的 :true-value 与 option 的 :value 都可以直接绑定 **对象字面量**，选中即把对象写入数据。

```html
<input type="checkbox" v-model="pickedUser" :true-value="{ id: 1, name: '张三' }">
```

```html
<select v-model="pickedCity">
  <option :value="{ code: '0571', name: '杭州' }">杭州</option>
  <option :value="{ code: '021', name: '上海' }">上海</option>
</select>
```

- 选中后 pickedUser 即为该对象，pickedCity 同理，可直接在模板里取其属性展示。
- 对象字面量写在模板属性里属于表达式求值，每次渲染都会求值一次。
- 字符串内层用单引号、属性值外层用双引号，避免引号冲突。

> [!NOTE]
> **提醒内容**：模板里的对象字面量每次渲染都会生成新的对象引用，若把 v-model 绑定值与字面量做严格相等比较，可能因引用不同而误判为未选中。涉及选中态匹配时，比较字段值而非引用。

**速记**：:value 绑对象，**选中即得对象**。



### 修饰符 .lazy

#### .lazy 把 input 事件改为 change 事件

**lazy 语义**：.lazy 修饰符把同步时机从 **每次输入的 input 事件** 改为 **失焦或提交时的 change 事件**，数据不再逐字符更新。

```html
<input v-model.lazy="message">
```

- 不加 .lazy 时，每键入一个字符就同步一次。
- 加 .lazy 后，输入期间数据保持旧值，输入框失焦或按回车时才整体同步。
- 适合输入内容较长、实时校验或实时请求代价高的场景。

> 辨析：.lazy 与手写 @change 不同——.lazy 仍由 v-model 统一管理写回，且可与 .number、.trim 叠加；手写 @change 则要自己维护赋值逻辑。

**速记**：lazy **失焦才同步**。



#### IME 组合输入期间默认不更新

**IME 规则**：使用中文、日文等 **输入法组合输入** 期间，v-model 默认 **不触发数据更新**，候选词确认、组合结束后才同步。

- 组合输入时，拼音字母先进入输入框，此时内容还不是最终文本。
- Vue 对组合输入做了内建处理：组合进行中不写回数据，避免数据里混入拼音碎片。
- 组合结束、候选字上屏后，一次性同步最终文本。

> [!NOTE]
> **提醒内容**：这是 v-model 对输入法的内建优化，无须也无法通过修饰符关闭。逐字符实时响应的需求（如搜索联想）在中文输入法下天然推迟到组合结束，设计交互时应知晓此背景。

**速记**：**打拼音不同步，上屏才更新**。



### 修饰符 .number 与 .trim

#### .number 自动把输入转为数字

**number 语义**：.number 修饰符在用户输入同步到数据时，自动调用 parseFloat 把值转为数字。

```html
<input v-model.number="age" type="number">
```

- 同步前先对输入值执行 parseFloat，解析成功则数据里是数字。
- type="number" 只限制键盘与校验，取到的值仍是字符串，.number 才负责类型转换。
- 适合年龄、数量、价格等数值表单项。

> 辨析：parseFloat 的规则是 **从字符串开头尽可能解析数字**：12px 解析为 12，3.14 保持 3.14，前导空白被忽略；这与 Number 要求整串可转的严格规则不同，注意区分。

**速记**：number **同步即 parseFloat**。



#### .number 解析失败保留原始值

**失败回退**：parseFloat 无法从输入解析出数字时，.number **保留原始字符串**，不抛错也不写入 NaN。

- 输入完全没有数字前缀的内容，如字母串，parseFloat 得到 NaN，此时数据保持原字符串。
- 输入 12abc 之类有数字前缀的内容，解析成功，数据为数字 12。
- 空字符串同样解析不出数字，数据保持空串。

> [!WARNING]
> **警告内容**：.number 的回退意味着数据 **时而是数字、时而是字符串**，下游的算术运算与接口校验可能因此出错。提交前应再做一次类型检查，或用计算属性兜底转换。

**速记**：解析失败 **留原值**，类型需自查。



#### .trim 自动去除首尾空白

**trim 语义**：.trim 修饰符在同步时自动调用字符串的 trim 方法，**去除首尾空白字符**，中间空白不受影响。

```html
<input v-model.trim="username">
```

- 输入前后误触的空格不会进入数据。
- 字符串内部的空格按原样保留。
- 用户名、邮箱、搜索词等场景可借此避免脏数据。

> 辨析：.trim 只在 **同步进数据的时刻** 生效一次，并非持续监听；若后续代码又给数据赋了带空格的值，不会被自动修剪。

**速记**：trim **去两头留中间**。



#### 修饰符可以串联使用

**串联规则**：三个修饰符可以在同一个 v-model 上 **串联书写**，按各自规则依次生效。

```html
<input v-model.lazy.trim="message">
<input v-model.number.trim="price">
```

- .lazy.trim 表示失焦时才同步，同步前先修剪首尾空白。
- .number.trim 表示转数字前先去首尾空白，避免空白干扰 parseFloat。
- 常见组合下书写顺序不影响最终结果，按语义排列即可。

> 注意：修饰符紧跟在 v-model 之后以点号连接，中间不能有空格；修饰符只对 v-model 有意义，不能挪到 v-bind 或 v-on 上。

**速记**：修饰符 **可叠加，各管一段**。



### 组件上的 v-model 预告

#### 组件级 v-model 的 modelValue 约定

**组件版 v-model**：v-model 用在组件上时，展开为 **modelValue 属性加 update:modelValue 事件** 的约定组合，由子组件发出更新事件配合完成。

```html
<CustomInput v-model="searchText" />
<!-- 等价于 -->
<CustomInput
  :modelValue="searchText"
  @update:modelValue="newValue => searchText = newValue"
/>
```

- 父组件传入名为 modelValue 的 prop，子组件通过 emit 发出 update:modelValue 事件请求更新。
- Vue 3.4 起子组件可用 defineModel 宏一行声明，自动获得该 prop 与更新事件的双向能力。
- 还支持通过参数指定多个不同名的 v-model，如 v-model:title。

```js
// 子组件 CustomInput 内，Vue 3.4 起可用
const model = defineModel();
```

**速记**：组件 v-model = **modelValue 进，update 事件出**。
