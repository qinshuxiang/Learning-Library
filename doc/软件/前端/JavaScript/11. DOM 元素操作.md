## DOM 元素操作

### 元素的属性操作

#### hidden 全局属性

**hidden**：是一个**全局布尔属性**，设置后元素会隐藏（相当于 display: none），是快速显示/隐藏元素的简洁方式。

- 直接给元素设置 element.hidden = true 即可隐藏。
- 隐藏后元素**不占据布局空间**（类似 display: none）。
- 对应的 HTML 属性是 hidden。

```js
const box = document.querySelector(".box");
box.hidden = true;   // 隐藏
box.hidden = false;  // 显示
```

> hidden 属性比手动操作 style.display 更简洁、语义更清晰。但要注意：若元素在 CSS 里显式设置了 display，hidden 可能不生效（因 display 优先级更高）。日常简单切换用 hidden，复杂场景用 classList 配合 CSS。



#### attribute 操作

**attribute（HTML 属性）**：是写在 HTML 标签上的属性，如 <a href="..."> 中的 href。通过 getAttribute/setAttribute 等操作。

- **getAttribute(name)**：读取属性值。
- **setAttribute(name, value)**：设置属性值。
- **removeAttribute(name)**：移除属性。
- **hasAttribute(name)**：判断是否存在某属性。

```js
const link = document.querySelector("a");

console.log(link.getAttribute("href")); // 属性值
link.setAttribute("target", "_blank");  // 设置 target 属性
console.log(link.hasAttribute("target")); // true
link.removeAttribute("target");          // 移除 target
```

> attribute 是**HTML 层面**的属性，操作的是标签上的**原始字符串**。它与下一节的 property 是两套体系，理解二者的区别（见下下节）是掌握 DOM 属性操作的关键。



#### property 操作

**property（DOM 属性）**：是 DOM 对象上的**JavaScript 属性**，通过点语法直接读写。

```js
const link = document.querySelector("a");

// property 方式：直接用点语法
console.log(link.href);      // 完整的绝对 URL（可能被浏览器规范化）
link.target = "_blank";      // 直接赋值
console.log(link.target);    // "_blank"
```

> property 是 **JavaScript 对象层面**的属性。它与 attribute 常常**同名但不同值**：如 link.href（property）返回**规范化的绝对 URL**，而 link.getAttribute("href") 返回**HTML 里写的原始字符串**。这是二者最典型的差异。



#### class 与 style 的区分

class 与 style 都能控制样式，但**定位不同**，应各司其职。

- **class**：定义**静态、可复用**的样式规则，写在 CSS 里，通过类名应用。
- **style**：直接设置**内联**样式，用于**动态、一次性**的样式。

```js
const el = document.querySelector("div");

// 用 class 切换预定义样式（推荐）
el.classList.add("active");

// 用 style 设置动态样式（适合一次性、需计算的值）
el.style.width = "100px";
el.style.display = "none";
```

> 原则：**能复用、固定的样式放 CSS 用 class 控制；动态计算、临时的样式用 style**。避免把所有样式都写进 style（难以维护），也避免用 style 复刻 CSS 该做的事。



#### class 操作方法

操作类名有两种方式：className 属性和 classList 接口。

##### className 属性

**className**：以**字符串**形式读写元素的整个 class 属性，简单但笨重。

```js
const el = document.querySelector("div");
console.log(el.className);        // "box"（整个类名字符串）
el.className = "box active";      // 直接覆盖整个 class
el.className += " highlight";     // 拼接（需注意空格）
```

> className 的缺点是**字符串操作**：增删某个类需要手动拼接、去重、处理空格，容易出错。因此日常更推荐用 classList（见下一节），className 只在"整体替换"时用。



##### classList 的常用方法

**classList**：是一个**专门管理类名**的接口，提供增删查切等便捷方法，是操作 class 的**首选**。

- **add(...classes)**：添加一个或多个类。
- **remove(...classes)**：移除一个或多个类。
- **toggle(cls)**：有则移除、无则添加（切换）。
- **contains(cls)**：判断是否包含某类。
- **replace(old, new)**：替换类名。

```js
const el = document.querySelector("div");

el.classList.add("active");        // 添加
el.classList.remove("box");        // 移除
el.classList.toggle("active");     // 切换
console.log(el.classList.contains("active")); // 判断
el.classList.replace("active", "highlight");  // 替换
```

> classList 相比 className 的优势：**自动处理空格、去重、无需拼接**，方法语义清晰。toggle 是实现"开关状态"（如深色模式、菜单展开）的利器，contains 用于判断当前状态。



#### style 操作

通过 element.style 操作内联样式，用于**动态设置**样式。

- **element.style.属性名 = 值**：设置单个样式。
- 属性名用**驼峰**（backgroundColor 对应 CSS 的 background-color）。
- **element.style.cssText**：批量设置（覆盖整个内联样式）。

```js
const el = document.querySelector("div");

el.style.color = "red";              // 设置文字颜色
el.style.backgroundColor = "yellow"; // 驼峰命名
el.style.cssText = "width: 100px; height: 50px"; // 批量设置

console.log(el.style.color); // "red"
```

> [!NOTE]
> **提醒内容**：两个注意点：一是 CSS 的连字符属性（background-color）要写成**驼峰**（backgroundColor）；二是 style 只能读取**内联样式**，读不到 CSS 文件里的样式——读取**计算后的样式**要用 getComputedStyle(el)。



#### dataset 的使用

**dataset**：用于读写元素的 **data-* 自定义属性**，是"在标签上存数据"的标准方式。

- HTML 里写 data-xxx="值"。
- JS 里通过 element.dataset.xxx 访问（连字符转驼峰）。

```html
<div id="user" data-id="123" data-user-name="coderwhy"></div>
```

```js
const el = document.querySelector("#user");
console.log(el.dataset.id);       // "123"
console.log(el.dataset.userName); // "coderwhy"（data-user-name 转驼峰）
el.dataset.age = "18";            // 设置，等价于 data-age="18"
```

> dataset 让 HTML 与 JS 之间传递数据更规范：data-user-name 对应 dataset.userName（连字符自动转驼峰）。它常用于**给元素绑定业务数据**（如列表项的 id），供事件处理时读取。



### 元素的创建与修改

#### 创建元素并插入 DOM

动态创建元素并插入页面是 DOM 操作的核心能力，需要"创建 → 设置 → 插入"三步。

- **document.createElement(tag)**：创建元素。
- **parent.appendChild(child)** / **parent.append(...)**：末尾插入。
- **parent.insertBefore(new, ref)** / **ref.before(...)**：指定位置插入。

```js
// 创建新元素
const li = document.createElement("li");
li.textContent = "新项目";
li.classList.add("item");

// 插入到列表末尾
const ul = document.querySelector("ul");
ul.appendChild(li);

// 插入到指定位置（第一个子元素之前）
ul.insertBefore(li, ul.firstChild);
```

> 动态创建元素的典型流程：createElement 创建、设置内容与属性、再 append 插入。appendChild 是传统方法，append 更现代（支持多参数、文本）；insertBefore 需要父元素与参照节点，before() 更直观。



#### 移除元素与克隆元素

移除与克隆是元素操作的补充能力。

- **element.remove()**：移除自身（现代方法）。
- **parent.removeChild(child)**：父节点移除子节点（传统方法）。
- **element.cloneNode(deep)**：克隆节点，deep 为 true 时深克隆（含后代）。

```js
const li = document.querySelector("li");
li.remove();                       // 移除自身

const ul = document.querySelector("ul");
ul.removeChild(ul.firstChild);     // 移除第一个子元素

const clone = li.cloneNode(true);  // 深克隆（含子节点）
```

> remove() 比 removeChild() 简洁（无需找父节点）。cloneNode(true) 深克隆、cloneNode(false) 浅克隆（只克隆标签不含内容）。克隆常用于"复制一个模板元素"的场景。



#### DocumentFragment 节点

**DocumentFragment**：是一个**轻量级的文档片段**，可作为临时的"容器"批量存放节点，插入 DOM 时**只插入其子节点、自身不留痕迹**。

```js
const fragment = document.createDocumentFragment();

for (let i = 0; i < 1000; i++) {
  const li = document.createElement("li");
  li.textContent = `第 ${i} 项`;
  fragment.appendChild(li);      // 先存到片段里
}

document.querySelector("ul").appendChild(fragment); // 一次性插入
```

> DocumentFragment 的核心价值是**性能优化**：批量创建大量节点时，若逐个 appendChild 到真实 DOM，会触发**多次重排**；先存到 Fragment、最后一次性插入，只触发**一次重排**，性能显著提升。



### 全局变量的使用细节

在 DOM 操作中，全局变量与**元素 id/name** 之间存在一个特殊机制，容易造成隐蔽问题。

- 浏览器会把**有 id 的元素**暴露为 window 上的同名全局变量。
- 用 var 声明的全局变量若与元素 id 同名，会**互相影响**。

```html
<div id="app">内容</div>
<script>
  console.log(window.app); // 自动指向 id 为 app 的元素
  console.log(app === document.getElementById("app")); // true
</script>
```

> [!CAUTION]
> **注意内容**：这个"id 变全局变量"是**历史遗留行为**，虽被广泛依赖但也易引发命名冲突。现代代码中应**避免依赖它**：用 document.getElementById 或 querySelector 显式获取，并避免全局变量与元素 id 重名。



### 元素的大小、位置与滚动

#### 获取元素的大小、位置与滚动

获取元素尺寸与位置的属性分几组，分别对应不同口径。

##### clientWidth 与 clientHeight

**clientWidth / clientHeight**：元素的**内容区 + padding** 的尺寸（**不含边框、滚动条**）。

```js
const el = document.querySelector("div");
console.log(el.clientWidth);  // 内容 + padding 的宽度
console.log(el.clientHeight); // 内容 + padding 的高度
```

> clientWidth = 内容宽度 + 左右 padding（**不含** border 和滚动条）。它常用于判断"元素可见内容的实际大小"。



##### offsetWidth 与 offsetHeight

**offsetWidth / offsetHeight**：元素的**内容 + padding + border** 的尺寸（**含边框**）。

```js
const el = document.querySelector("div");
console.log(el.offsetWidth);  // 内容 + padding + border
console.log(el.offsetHeight);
```

> offsetWidth 比 clientWidth 多了**边框（border）**。要精确控制元素占位时（如拖拽、布局计算），需区分"含不含边框"，offset 系列含边框，client 系列不含。



##### scrollTop 与 scrollLeft

**scrollTop / scrollLeft**：元素**已经滚动**的距离（被卷走的内容高度/宽度），可读可写。

```js
const el = document.querySelector(".scroll-box");
console.log(el.scrollTop);  // 已向下滚动的距离
el.scrollTop = 100;         // 设置滚动位置
```

> scrollTop 是处理滚动交互（回到顶部、滚动监听、懒加载）的核心属性：scrollTop 大于某阈值时触发加载，scrollTop = 0 可回到顶部。



##### getBoundingClientRect()

**element.getBoundingClientRect()**：返回元素**相对于视口**的位置与尺寸信息，是一个 DOMRect 对象。

返回的关键字段：

- **top / left**：相对视口上/左边缘的距离。
- **bottom / right**：相对视口下/右边缘的距离。
- **width / height**：元素尺寸（含 border）。

```js
const el = document.querySelector("div");
const rect = el.getBoundingClientRect();
console.log(rect.top, rect.left); // 元素在视口中的位置
console.log(rect.width, rect.height); // 尺寸
```

> getBoundingClientRect 是**获取元素位置**最常用的方法，坐标是**相对视口**的。它广泛用于碰撞检测、判断元素是否进入视口（配合 scrollTop）、定位弹出层等场景。



#### window 的大小与滚动

window 层面也有对应的尺寸与滚动属性。

- **window.innerWidth / innerHeight**：视口（含滚动条）的宽高。
- **window.scrollX / scrollY**：页面已滚动的距离。
- **window.scrollTo(x, y)**：滚动到指定位置。

```js
console.log(window.innerWidth);  // 视口宽度
console.log(window.scrollY);     // 页面滚动距离

// 回到顶部
window.scrollTo(0, 0);
```

> innerWidth 是"**当前窗口能看到的宽度**"（响应式布局、判断设备尺寸的依据）。scrollY 与元素的 scrollTop 对应，是页面级滚动监听的核心。



### DOM 案例练习

#### 动态创建列表

综合练习：根据数据数组动态渲染列表，这是前端最基础也最常见的模式。

```js
const data = ["苹果", "香蕉", "橙子", "葡萄"];

const ul = document.querySelector("ul");
const fragment = document.createDocumentFragment();

data.forEach((item) => {
  const li = document.createElement("li");
  li.textContent = item;
  fragment.appendChild(li);
});

ul.appendChild(fragment);
```

> 这个案例串起了"**遍历数据 + 创建元素 + 批量插入**"的完整流程，是现代框架"数据驱动视图"的雏形。用 DocumentFragment 批量插入是性能优化的关键点。



#### 界面显示时间

综合练习：在页面上实时显示当前时间。

```js
const timeEl = document.querySelector("#time");

function showTime() {
  const now = new Date();
  const text = now.toLocaleTimeString("zh-CN");
  timeEl.textContent = text;
}

showTime();                        // 立即显示
setInterval(showTime, 1000);       // 每秒更新
```

> 这个案例结合了 Date、textContent 与 setInterval：定时器每秒更新时间，textContent 把时间写入页面。它是"**定时更新 UI**"的典型范式。



#### 倒计时的展示

综合练习：实现一个倒计时，展示距离目标时间的剩余时间。

```js
const targetTime = new Date("2026-12-31 23:59:59").getTime();
const displayEl = document.querySelector("#countdown");

function updateCountdown() {
  const now = Date.now();
  let diff = Math.floor((targetTime - now) / 1000); // 剩余秒数

  if (diff <= 0) {
    displayEl.textContent = "已结束";
    clearInterval(timer);
    return;
  }

  const days = Math.floor(diff / 86400);
  const hours = Math.floor((diff % 86400) / 3600);
  const minutes = Math.floor((diff % 3600) / 60);
  const seconds = diff % 60;

  displayEl.textContent = `${days} 天 ${hours} 时 ${minutes} 分 ${seconds} 秒`;
}

updateCountdown();
const timer = setInterval(updateCountdown, 1000);
```

> 倒计时的核心是**时间差换算**：把剩余毫秒数依次除以 86400（天）、3600（时）、60（分）取整，配合取余得到时分秒。到达目标时用 clearInterval 停止定时器，避免无限运行。



### MutationObserver

#### MutationObserver 的基本使用

**MutationObserver**：是一个用于**监听 DOM 变化**的接口，当被观察的节点树发生指定变化时，异步触发回调。

```js
const target = document.querySelector("#app");

const observer = new MutationObserver((mutations) => {
  mutations.forEach((mutation) => {
    console.log("变化类型：", mutation.type);
    console.log("变化的节点：", mutation.target);
  });
});

observer.observe(target, {
  childList: true,   // 监听子节点的增删
  attributes: true,  // 监听属性变化
  subtree: true      // 监听所有后代
});
```

- 创建时传入**回调函数**，收到一组 MutationRecord。
- 通过 observe(target, options) 指定观察目标与选项。

> MutationObserver 相比已废弃的 MutationEvent 性能更好、是异步批量触发。它用于"DOM 被外部修改时做出响应"的场景，如监听第三方脚本对 DOM 的改动。



#### 回调时机与 disconnect

理解回调的**执行时机**与如何**停止观察**。

- **异步批量**：多次 DOM 变化会**合并成一次回调**，回调在微任务阶段执行。
- **disconnect()**：停止观察，释放资源。
- **takeRecords()**：取出尚未处理的记录。

```js
const observer = new MutationObserver((mutations) => {
  console.log(`本次共 ${mutations.length} 条变化`);
});

observer.observe(target, { childList: true });

// 停止观察
observer.disconnect();
```

> [!IMPORTANT]
> **重要内容**：两个关键点：一是回调**不是同步**的——多次连续修改会被合并、一次性通知（所以回调里看到的是"一组"变化）；二是用完务必 disconnect()，否则观察器持续占用资源、可能造成内存泄漏。
