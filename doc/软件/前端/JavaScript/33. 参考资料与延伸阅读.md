## 参考资料与延伸阅读

### 官方文档与规范

#### MDN Web Docs

**MDN（Mozilla Developer Network）**：是由 Mozilla 维护的 **Web 技术权威文档**，是查询 JavaScript 及 Web API 的**首选参考**。

- 覆盖 JavaScript、HTML、CSS 及各类 Web API。
- 每个 API 都提供**语法、参数、返回值、示例、浏览器兼容性**。

> MDN 是查 API 的"**标准答案**"：不确定某个方法的行为、参数、兼容性时，先查 MDN。它内容权威、更新及时、示例丰富，是每个前端开发者的必备工具站。



#### ECMA-262 与 TC39 提案

**ECMA-262** 与 **TC39 提案**：是理解 JavaScript **语言本质**与**未来方向**的权威来源。

- **ECMA-262**：语言的官方规范，定义精确行为。
- **TC39 提案**：跟踪语言的演进（github.com/tc39/proposals）。

> 想深入理解"为什么某行为是这样"、或了解"下一个版本有什么新特性"，就看规范与提案。它们是最权威、最底层的资料，适合进阶时研读。



### 中文教程与博客

#### 阮一峰《JavaScript 教程》

阮一峰的 **《JavaScript 语言入门教程》**（网道 WangDoc.com）：是**最经典的中文 JS 教程**之一。

- 内容系统、全面，覆盖语言核心与浏览器 API。
- 讲解清晰、循序渐进，适合入门与查漏补缺。

> 阮一峰的教程以"**深入浅出、讲解透彻**"著称，是中文 JS 学习的重要参考。本主题多处内容即参考了其讲解思路。



#### 阮一峰《ECMAScript 6 入门》

阮一峰的 **《ECMAScript 6 入门》**：是学习 **ES6 新特性**的**权威中文资料**。

- 逐特性讲解 ES6（及之后版本）的语法。
- 配有大量示例与细节说明。

> 学习 ES6+ 新特性，这本书是**必读**的。本主题第 25~27 章"新特性"部分，即参考了其结构与讲解。



#### 阮一峰《科技爱好者周刊》

阮一峰的 **《科技爱好者周刊》**：是**每周更新的科技资讯周刊**。

- 分享前沿技术、工具、观点。
- 帮助拓宽技术视野。

> 周刊不是"系统教程"，但能让你**保持技术敏感度**、了解行业动态。适合作为日常的碎片化阅读补充。



#### 冴羽的博客：深入系列、专题系列与 ES6 系列

**冴羽**的博客（github.com/mqyqingfeng/Blog）：是**高质量的前端深度系列**文章。

- **深入系列**：深入 this、闭包、原型、作用域等核心概念。
- **专题系列**：防抖节流、深拷贝、柯里化等专题。
- **ES6 系列**：ES6 特性的深入讲解。

> 冴羽的博客以"**深入原理、层层递进**"著称，是进阶必读。本主题中"手写 call/apply/bind""深浅拷贝""防抖节流"等内容，都借鉴了其讲解风格。



#### 后盾人文档

**后盾人（houdunren）**：是一个**系统的 Web 开发学习平台**。

- 提供 JavaScript、Vue、Node 等系统课程。
- 讲解细致、实战导向。

> 后盾人的教程以"**系统、实战**"见长，适合配合视频学习、跟着动手实践。本主题的参考来源之一。



### GitHub 优质仓库

#### 千古壹号 Web 前端图文教程

**千古壹号**的《Web 前端入门到进阶》：是 GitHub 上**高星的中文前端图文教程**。

- 内容详尽、配图丰富。
- 覆盖 HTML、CSS、JavaScript 到框架。

> 这套图文教程以"**细致、接地气**"著称，适合系统入门。其知识点的组织与讲解方式，对本主题的结构设计有启发。



#### You-Dont-Know-JS

**《You Don't Know JS》（你不知道的 JavaScript）**：是 Kyle Simpson 的**经典 JS 深度系列**（github.com/getify/You-Dont-Know-JS）。

- 深入 this、原型、作用域、类型等核心机制。
- 揭示 JS 的**设计细节与坑**。

> 这套书是"**深入理解 JS 本质**"的必读经典，帮你真正"懂" JavaScript 而非只是"会用"。适合有一定基础后的进阶阅读。



#### 33-js-concepts 与 javascript-algorithms

两个经典的 GitHub 算法/概念仓库。

- **33-js-concepts**：33 个 JS 核心概念的**资料合集**。
- **javascript-algorithms**：用 JS 实现的**算法与数据结构**大全。

> 33-js-concepts 帮你梳理"**JS 必须掌握的 33 个概念**"；javascript-algorithms 则提供大量算法的 JS 实现。二者是**查漏补缺**与**算法练习**的优质资源。



### 百科条目

#### 维基百科 JavaScript 条目

**维基百科的 JavaScript 词条**：提供了 JavaScript 的**历史、特性、版本**等综述性信息。

- 涵盖语言起源、标准化历程、各版本特性。
- 提供宏观的、历史性的视角。

> 维基百科条目适合**快速了解 JavaScript 的来龙去脉**（如第 1 章"起源与历史"即参考了它）。它不深入语法细节，但能帮你建立对这门语言的**整体认知**。
