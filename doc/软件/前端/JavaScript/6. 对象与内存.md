## 对象与内存

### 对象的基本使用

#### 对象类型的基本使用

**对象（Object）**：是 JavaScript 中最核心的引用类型，用于**以键值对的形式组织相关数据**，把描述同一事物的多个属性聚合在一起。

对象的创建与访问：

- **创建**：用对象字面量 {} 是最常用方式。
- **访问属性**：点语法 obj.key 或方括号语法 obj["key"]。

```js
const person = {
  name: "coderwhy",
  age: 18,
  height: 1.88
};

console.log(person.name);   // "coderwhy"
console.log(person["age"]); // 18
```

> 对象把"零散的数据"组织成"有意义的整体"：一个 person 对象比三个孤立的 name、age、height 变量更清晰、更易传递。理解对象是理解 JavaScript 一切复杂结构的起点——数组、函数、正则本质上都是对象。



#### 对象类型的常见操作

对象的常见操作包括**增、删、改、查**，分别对应不同语法。

- **增/改**：直接给属性赋值，属性不存在则新增，存在则覆盖。
- **删**：用 delete 运算符删除属性。
- **查**：用点语法或方括号语法读取。

```js
const user = { name: "why" };

user.age = 18;              // 增
user.name = "coderwhy";     // 改
console.log(user);          // { name: "coderwhy", age: 18 }

delete user.age;            // 删
console.log(user);          // { name: "coderwhy" }
console.log(user.name);     // 查
```

> [!NOTE]
> **提醒内容**：delete 删除的是属性，若删除不存在的属性也不会报错（返回 true）。注意 delete 不能删除用 var、let 声明的变量，它只作用于对象属性。



#### 方括号语法

**方括号语法 obj[key]**：是访问对象属性的另一种方式，与点语法的核心区别在于——方括号里的 key 可以是**变量或任意表达式**，实现**动态属性名**。

- 点语法 obj.key 中 key 是**字面量**，不能是变量。
- 方括号 obj[key] 中 key 会被**求值**，可使用变量、拼接结果等。

```js
const user = { name: "why", age: 18 };

const key = "name";
console.log(user[key]);      // "why"（key 是变量，被求值为 "name"）
console.log(user.key);       // undefined（字面量 key，不存在该属性）

// 动态拼接属性名
console.log(user["na" + "me"]); // "why"
```

> [!IMPORTANT]
> **重要内容**：何时必须用方括号？当属性名是**变量**、包含**特殊字符**（空格、连字符）、或是**动态计算**的结果时。例如遍历对象时 for (const k in obj) { obj[k] } 就必须用方括号。



#### for-in 遍历

**for-in 循环**：用于**遍历对象的可枚举属性名**，每次迭代把属性名赋给循环变量。

- 遍历的是**属性名（键）**，通过 obj[key] 再取属性值。
- 会遍历到**继承的**可枚举属性（需配合 hasOwnProperty 过滤）。

```js
const person = { name: "why", age: 18, height: 1.88 };

for (const key in person) {
  console.log(`${key}: ${person[key]}`);
}
// 输出：
// name: why
// age: 18
// height: 1.88
```

> for-in 用于对象，for-of 用于数组/可迭代对象，二者不可混用。for-in 的顺序并非严格保证，且会遍历继承属性，严谨时应配合 Object.prototype.hasOwnProperty.call(obj, key) 过滤自身属性。



### 栈与堆内存

#### 值类型与引用类型

JavaScript 的数据按**存储方式**分为两大类，这是理解一切"赋值/传参/拷贝"行为的地基。

- **值类型（基本类型）**：number、string、boolean、undefined、null、symbol、bigint，存的是**值本身**。
- **引用类型**：对象（含数组、函数），存的是**值的地址（引用）**。

```js
// 值类型：互相独立
let a = 10;
let b = a;      // 拷贝值
b = 20;
console.log(a); // 10（a 不受影响）

// 引用类型：共享同一对象
const obj1 = { x: 1 };
const obj2 = obj1; // 拷贝引用（指向同一对象）
obj2.x = 100;
console.log(obj1.x); // 100（obj1 也被改了）
```

> 核心区别一句话：**值类型复制"值"，引用类型复制"地址"**。所以改基本类型变量不影响原值，改引用类型对象会影响所有指向它的变量。这一区别是"深浅拷贝""函数传参"等话题的总根源。



#### 内存表现

JavaScript 内存主要分**栈（Stack）** 与 **堆（Heap）** 两块，分别存放不同类型的值。

- **栈**：存放**基本类型的值**和**引用类型的地址**，空间小、存取快、自动管理。
- **堆**：存放**引用类型的对象本体**，空间大、存取稍慢。

```js
const num = 10;          // 栈里直接存 10
const obj = { a: 1 };    // 栈里存地址，堆里存 { a: 1 }
```

> 内存表现决定行为：基本类型赋值是**栈内值拷贝**，引用类型赋值是**栈内地址拷贝**。两个变量"共享"对象，是因为它们栈里的地址指向堆里的同一块对象，而非对象被复制了两份。



#### 函数参数的按值传递

**按值传递（Pass by Value）**：是指函数调用时，实参的**值被复制一份**传给形参。JavaScript 中所有参数传递都是**按值**进行的，但对引用类型，"值"是地址，所以表现为"共享对象"。

- 传基本类型：形参拿到值的副本，函数内修改不影响外部变量。
- 传引用类型：形参拿到地址的副本，通过地址修改对象会影响外部，但**重新赋值**不影响外部。

```js
function changeValue(num, obj) {
  num = 100;        // 改的是副本，不影响外部
  obj.name = "新名"; // 通过地址改对象，影响外部
  obj = { name: "新对象" }; // 重新赋值，只改形参的地址，不影响外部
}

const n = 10;
const o = { name: "旧名" };
changeValue(n, o);
console.log(n); // 10（未变）
console.log(o.name); // "新名"（对象被改了）
```

> 这个案例是面试必考：**"对象参数是按引用传递"是通俗说法，严格讲 JavaScript 只有按值传递**。关键要分清"**通过引用改内容**"（会影响外部）与"**给形参重新赋值**"（不影响外部）这两件事。



### this 的初步认识

#### 函数中 this 指向的两种情况

**this**：是函数内部的一个特殊关键字，指向**调用该函数的对象**。初步阶段，理解两种最常见的指向即可。

- **对象方法调用**：obj.method()，this 指向 obj。
- **普通函数调用**：直接 fn()，非严格模式下 this 指向全局对象 window（浏览器），严格模式下为 undefined。

```js
const person = {
  name: "why",
  sayName() {
    console.log(this.name); // this 指向 person
  }
};
person.sayName(); // "why"

function globalFn() {
  console.log(this); // 指向 window（浏览器）
}
globalFn();
```

> 记住核心规则：**this 由调用方式决定，而非定义位置**。person.sayName() 之所以 this 是 person，是因为"通过 person. 调用的"。这一规则是后续深入 this 绑定（默认、隐式、显式、new）的基础。



#### this 在开发中的应用

this 的价值在于**让方法能访问"自己所属的对象"**，从而写出与具体对象解耦的通用逻辑。

```js
// 用 this 访问对象自身属性，方法可复用
const user1 = {
  name: "张三",
  introduce() {
    console.log(`我叫 ${this.name}`);
  }
};
const user2 = {
  name: "李四",
  introduce() {
    console.log(`我叫 ${this.name}`);
  }
};

user1.introduce(); // 我叫 张三
user2.introduce(); // 我叫 李四
```

> this 让方法不必写死具体对象名：同一段 console.log(this.name) 代码，this 指向谁就输出谁的名字。这正是 this 存在的意义——**在方法内部引用"当前这个对象"**，实现代码复用。



### 创建一系列的对象

#### 工厂函数

**工厂函数（Factory Function）**：是**返回新对象的普通函数**，用于批量创建结构相似的对象，避免重复写对象字面量。

```js
function createPerson(name, age) {
  return {
    name,
    age,
    introduce() {
      console.log(`我叫 ${this.name}，今年 ${this.age} 岁`);
    }
  };
}

const p1 = createPerson("张三", 20);
const p2 = createPerson("李四", 25);
p1.introduce(); // 我叫 张三，今年 20 岁
p2.introduce(); // 我叫 李四，今年 25 岁
```

> 工厂函数解决了"重复写字面量"的问题，但有个明显缺点：**无法识别对象的"类型"**——p1 和 p2 没有共同的类型标识，instanceof 无法判断它们是否同类。这个缺陷由**构造函数**弥补。



#### 构造函数

**构造函数（Constructor）**：是用 new 调用的函数，通过 this 给新对象添加属性。按惯例，构造函数名用**大驼峰**（如 Person）以区别于普通函数。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
  this.introduce = function () {
    console.log(`我叫 ${this.name}，今年 ${this.age} 岁`);
  };
}

const p1 = new Person("张三", 20);
const p2 = new Person("李四", 25);

console.log(p1 instanceof Person); // true（能识别类型）
p1.introduce(); // 我叫 张三，今年 20 岁
```

> new 关键字做了四件事：创建空对象、把 this 指向该对象、执行构造函数体、返回该对象。构造函数相比工厂函数的优势是**可识别类型**（instanceof），但它仍有一个隐患：每个实例的方法都单独占一份内存，这引出了**原型**的优化（见原型章节）。



#### 类与对象的关系

**类（Class）** 与 **对象（Object）** 是面向对象的核心概念，二者是"**模板与实例**"的关系。

- **类**：是对一类事物的**抽象描述**，定义这类事物有哪些属性、方法，如"人"有名字、年龄。
- **对象**：是类的一个**具体实例**，如"张三"是"人"这个类的一个实例。

```js
// Person 是类（模板），p1、p2 是对象（实例）
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
}
const p1 = new Person("张三", 20);
const p2 = new Person("李四", 25);
```

> 理解"类与对象"的关键是类比：**类是图纸，对象是按图纸造出来的房子**。一份图纸可以造出无数栋房子，每栋房子是独立的实例。ES6 的 class 本质是原型继承的语法糖，但"模板—实例"的思维方式通用。



#### 构造函数的补充细节

构造函数有几个易被忽略的细节。

- **new 的返回**：若构造函数返回对象，则 new 返回该对象；若返回基本类型，则忽略，仍返回 this。
- **忘记 new**：直接调用构造函数，this 指向全局（严格模式下报错），属性会挂到全局对象上，是严重 bug。
- **构造函数也是函数**：本质上它就是个函数，只是约定用 new 调用、大驼峰命名。

```js
function Person(name) {
  this.name = name;
  // 若显式 return 一个对象，会覆盖默认的 this
  // return { fake: true };
}

// 忘记 new 的后果（非严格模式）
// const p = Person("张三"); // this 指向 window，name 变成全局变量
const p = new Person("张三"); // 正确用法
```

> [!IMPORTANT]
> **重要内容**：防范"忘记 new"的常见手段：一是 ES6 的 class 强制必须用 new（否则报错）；二是构造函数内做 if (!(this instanceof Person)) 检查。理解这些细节，才能避免构造函数使用中的隐性 bug。



### 全局对象与函数对象

#### 全局对象 window

**全局对象 window**：是浏览器环境中 JavaScript 的**顶层对象**，所有全局变量和全局函数都会成为它的属性。

- 用 var 声明的全局变量、全局函数，都会挂到 window 上。
- 浏览器提供的 alert、console、document 等，本质都是 window 的属性。
- 访问 window 的属性时可省略 window. 前缀。

```js
var globalName = "coderwhy";
function sayHello() {}

console.log(window.globalName); // "coderwhy"
console.log(window.sayHello);   // 函数
console.log(window === this);   // true（全局作用域下）
```

> [!NOTE]
> **提醒内容**：注意 let、const 声明的全局变量**不会**挂到 window 上（它们存在于独立的"全局词法环境"），只有 var 和函数声明会。这一差异是 ES6 引入块级作用域后的一个重要变化。



#### 函数也是一个对象

**函数也是对象**：函数是一种特殊的、**可调用的对象**，因此它既有对象的特性（可有属性），又有函数的特性（可被调用）。

- 函数可以有**属性**：fn.customProp = 1。
- 函数有内置属性：name（函数名）、length（形参个数）。
- 函数有自己的**方法**：call、apply、bind。

```js
function foo(a, b) {}

console.log(foo.name);   // "foo"（函数名）
console.log(foo.length); // 2（形参个数）

foo.custom = "自定义属性";
console.log(foo.custom); // "自定义属性"
```

> "函数是对象"这一事实解释了很多现象：为什么函数能作为参数传递、能赋给变量、能拥有属性和方法。它也解释了 typeof fn === "function" 而 fn 又拥有对象特性的"双重身份"。



#### 类方法的编写

在类或对象中编写方法，有多种语法，ES6 提供了更简洁的**方法简写**。

- **传统写法**：方法名: function () { ... }。
- **方法简写（ES6）**：直接 方法名() { ... }，省略冒号和 function。

```js
const obj = {
  // 传统写法
  sayHi: function () {
    console.log("hi");
  },
  // 方法简写
  sayHello() {
    console.log("hello");
  }
};

obj.sayHi();    // hi
obj.sayHello(); // hello
```

> [!WARNING]
> **警告内容**：方法简写不仅更简洁，还有一个重要区别：**简写方法是"方法"而非"函数"**，它不能作为构造函数用 new 调用，且其内部可以正确使用 super（在类继承中）。现代代码中，对象和类里的方法都推荐用简写。
