## 表格

### 表格的结构

#### table 与行列组织

**table 元素**：创建表格。表格由行（tr）构成，每行内再放置单元格，单元格分为表头与数据两类。

- **tr 元素**：表格行。
- **th 元素**：表头单元格，默认加粗居中，表示该列或行的标题。
- **td 元素**：数据单元格，承载表格数据。

```html
<table>
  <tr>
    <th>姓名</th>
    <th>年龄</th>
  </tr>
  <tr>
    <td>张三</td>
    <td>20</td>
  </tr>
  <tr>
    <td>李四</td>
    <td>25</td>
  </tr>
</table>
```

- 表格的基本单位是"行"，先有 tr，再在行内放 th/td。
- th 提供表头语义，利于屏幕阅读器把表头与数据关联起来。

> [!IMPORTANT]
> 重要内容：不要用表格来做页面布局（把整页内容塞进单元格拼版面）——那是 HTML 早期的落后做法。现代 HTML 中表格只用于呈现真正的二维表格数据，布局交给 CSS（flex、grid）。

#### 表头行分区块 thead/tbody/tfoot

为表达长表格的结构语义，可将表格行分入 thead（表头）、tbody（表体）、tfoot（表尾）三个区块。

```html
<table>
  <thead>
    <tr><th>科目</th><th>分数</th></tr>
  </thead>
  <tbody>
    <tr><td>语文</td><td>90</td></tr>
    <tr><td>数学</td><td>95</td></tr>
  </tbody>
  <tfoot>
    <tr><td>总分</td><td>185</td></tr>
  </tfoot>
</table>
```

- thead 放列标题行，tbody 放主要数据，tfoot 放汇总行。
- 三者是可选的语义分块，让浏览器与辅助技术理解表格的组成部分。
- 一个 table 可含多个 tbody，实现数据分组。

> [!NOTE]
> 提醒内容：浏览器渲染顺序上 tfoot 可写在 tbody 之前而仍显示在表格底部，但为源码可读性，惯例仍按 thead、tbody、tfoot 书写。

#### caption 表格标题

**caption 元素**：表格的标题，作为表格的第一个子元素，默认显示在表格上方。

```html
<table>
  <caption>学生成绩表</caption>
  <thead>
    <tr><th>科目</th><th>分数</th></tr>
  </thead>
  ...
</table>
```

- caption 描述整张表格的用途，屏幕阅读器会先读出标题。
- caption 必须是 table 的第一个子元素。

> 一张有数据意义的表格都应配 caption，帮助读者快速理解表格主题。这与图表的 figcaption 作用相当。



### 单元格合并与表头关联

#### 行与列合并

跨行或跨列的单元格可用 rowspan 与 colspan 合并。

- colspan 属性：单元格横向跨越的列数。
- rowspan 属性：单元格纵向跨越的行数。

```html
<table>
  <tr>
    <th colspan="2">个人信息</th>
  </tr>
  <tr>
    <td>姓名</td>
    <td>张三</td>
  </tr>
  <tr>
    <td rowspan="2">联系方式</td>
    <td>13800000000</td>
  </tr>
  <tr>
    <td>hello@example.com</td>
  </tr>
</table>
```

> [!WARNING]
> 警告内容：合并单元格会打乱表格的二维网格，rowspan 尤其易在行列计数上出错，导致后续单元格错位。手写合并后应把表格当作"网格"心算每行列数，或用所见即所得工具，避免多算少算。

#### 用 scope 关联表头与数据

**scope 属性**（写在 th 上）：声明该表头是列标题（col）还是行标题（row），帮助屏幕阅读器正确关联。

```html
<table>
  <tr>
    <th scope="col">科目</th>
    <th scope="col">分数</th>
  </tr>
  <tr>
    <th scope="row">语文</th>
    <td>90</td>
  </tr>
</table>
```

- scope="col"：该 th 是其所在列的标题。
- scope="row"：该 th 是其所在行的标题（如首列表头）。

> [!TIP]
> 建议内容：当表格结构简单（首行即表头）时可不写 scope，浏览器能推断；但含合并或行表头时，显式 scope 能显著提升屏幕阅读器朗读表格的准确度。复杂表也可用 headers 属性建立表头与单元格的显式关联。

#### headers 显式关联

**headers 属性**（写在 td/th 上）：列出与该单元格相关的表头 id，形成精确对应，用于复杂表格。

```html
<table>
  <tr>
    <th id="name">姓名</th>
    <th id="score">分数</th>
  </tr>
  <tr>
    <td headers="name">张三</td>
    <td headers="score">90</td>
  </tr>
</table>
```

- headers 的值是空格分隔的多个表头 id。
- 适合多级表头、合并单元格等浏览器难以自动推断关联的场景。

> headers 是复杂表格可访问性的兜底方案：当自动关联与 scope 都不足以表达时，用 headers 手动指定。简单表格通常用不到。



### 表格的可访问性与实践

#### 数据表格的可访问性原则

表格数据要能被屏幕阅读器有效朗读，需遵循几条结构原则。

- 用 th 标表头，用 scope 或 headers 关联表头与数据。
- 用 caption 给出表格标题。
- 不为布局使用表格。
- 合理使用 thead、tbody、tfoot 分块。

> 一组合规的表格 = table 加 caption，加带 th 的首行，必要时加 scope。屏幕阅读器即可按"列名加数值"的方式朗读每个单元格，实现无障碍读取数据。

#### 表格样式交由 CSS

表格的边框、间距、条纹等一切视觉表现都由 CSS 控制。

- border-collapse：合并单元格边框。
- 斑马纹、悬停高亮等用 nth-child 或 hover 实现。

> 现代做法是把表格结构化语义留给 HTML，把间距、边框、配色全部交给 CSS，二者职责分离，与列表的处理思路一致。
