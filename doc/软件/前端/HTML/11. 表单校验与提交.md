## 表单校验与提交

### HTML5 内置校验

#### 约束验证的基本属性

HTML5 提供一套**约束验证（Constraint Validation）**机制，无需脚本即可在提交时校验输入。核心属性如下。

- required：必填，空值阻止提交。
- minlength / maxlength：文本长度上下限。
- min / max：数值与日期范围。
- step：数值步进。
- pattern：正则匹配（用于 text 类）。
- type="email" / "url"：按类型做格式校验。

```html
<form>
  <input type="text" name="user" required minlength="3" maxlength="12">
  <input type="email" name="mail" required>
  <input type="number" name="age" min="18" max="60" step="1">
  <button type="submit">提交</button>
</form>
```

- 不满足约束时浏览器阻止提交并显示提示。
- 校验在 HTML 层面拦截常见错误，大幅减轻服务端纯前端防御压力。

> [!NOTE]
> 提醒内容：约束验证能拦截大部分误输入，但**不能取代服务端校验**——前端校验只是提升体验，攻击者可绕过。真正的数据安全与合法性判断必须在服务端完成。

#### pattern 与占位示例

**pattern 属性**：用正则约束 text/search/url/tel/email/password 等文本类控件的格式，title 可补充错误说明。

```html
<input type="text" name="code" pattern="[A-Za-z0-9]{6}"
       title="请输入 6 位字母或数字" required>
```

- pattern 是隐式锚定的整串正则（必须匹配整个值）。
- 不匹配时，title 内容作为错误提示的一部分。

> [!WARNING]
> 警告内容：pattern 的正则须整串匹配，不要写成只需部分匹配的宽松正则（如只需出现数字）。校验不过时把 title 写得具体些，比浏览器默认提示更有帮助。错误提示的语言文案可用 setCustomValidity 定制。

#### 用 CSS 反馈校验状态

校验结果会反映为伪类，可用 CSS 视觉反馈。

- :valid——值通过校验。
- :invalid——值未通过校验。
- :required / :optional——必填/选填控件。
- :user-invalid——用户已交互后仍未通过。

```css
input:invalid { border-color: #d00; }
input:valid { border-color: #090; }
```

> 实时校验反馈可用 CSS 伪类（尤其 :user-invalid 在用户提交后高亮），无需脚本即可提示哪些字段填错。



### 约束验证 API

#### validity 对象与校验方法

**约束验证 API**：通过表单控件的属性与方法，让脚本读取或主动触发校验。

- 属性：validity（一个 ValidityState 对象，含多个布尔标志）、validationMessage（错误消息）、willValidate。
- 方法：checkValidity()（返回是否通过）、reportValidity()（校验并展示提示）、setCustomValidity(msg)。

```html
<script>
  const input = document.getElementById("code");
  input.addEventListener("input", () => {
    if (input.validity.patternMismatch) {
      input.setCustomValidity("请输入 6 位字母或数字");
    } else {
      input.setCustomValidity("");
    }
  });
</script>
```

- ValidityState 含 valueMissing、typeMismatch、patternMismatch、rangeUnderflow、rangeOverflow、tooLong、tooShort 等标志，可据此给出针对性提示。

> [!TIP]
> 建议内容：默认错误提示是浏览器语言且较笼统。在 input 事件里读 validity 判断具体哪类错误，用 setCustomValidity 设定中文友好文案，能显著提升表单体验。

#### novalidate 与自定义校验时机

**novalidate 属性**（写在 form 上）：提交时跳过浏览器内置约束验证，交由脚本处理。

```html
<form novalidate>
  <input type="email" name="mail" required>
  <button type="submit">提交</button>
</form>
```

- 需要完全自定义校验、或做跨字段联动的复杂校验（如两次密码一致）时，可关掉内置验证自行实现。
- 也可在 submit 事件里用 event.preventDefault() 拦截后手动校验。

> 跨字段校验（确认密码、起止日期）单靠 HTML 属性难以表达，通常用脚本在提交时统一判断，此时 novalidate 加自写校验更可控。



### 表单提交与数据处理

#### method 与 enctype

提交时数据如何发送由 method 与 enctype 决定。

- method="get"：数据拼进 URL 查询串，适合搜索等无敏感、幂等请求。
- method="post"：数据放请求体，适合会改变数据的提交。
- enctype 决定请求体编码，普通表单默认 application/x-www-form-urlencoded；含文件上传时须用 multipart/form-data。

```html
<form action="/upload" method="post" enctype="multipart/form-data">
  <input type="file" name="avatar">
  <button type="submit">上传</button>
</form>
```

> [!IMPORTANT]
> 重要内容：只要表单含 type 属性为 file 的 input 元素，form 的 enctype 就必须设为 multipart/form-data（并通常用 post），否则文件内容无法正确编码传输。含文件的表单漏设 enctype 是高频错误。

#### FormData 与文件读取

**FormData**：浏览器内置接口，可构建键值对表单数据，配合 fetch 异步上传。

```html
<form id="f">
  <input type="file" name="avatar" id="avatar">
  <button type="submit">上传</button>
</form>
<script>
  document.getElementById("f").addEventListener("submit", async (e) => {
    e.preventDefault();
    const fd = new FormData(e.target);
    const resp = await fetch("/upload", { method: "POST", body: fd });
    // ...
  });
</script>
```

- new FormData(form)：把表单控件自动读入键值集合。
- fetch 直接以 FormData 为 body，浏览器自动加 multipart 边界头（无需手设 enctype）。

> 现代异步上传用 FormData 加 fetch 最简洁；也可用 File 对象、Blob 直接作为 body。文件处理细节参见 JavaScript 目录"二进制数据与文件"章。

#### 文件控件与 multiple、accept

**input type="file"**：选择本地文件，可配属性限制。

- multiple：允许选择多个文件。
- accept：按类型提示可选项（如 image/*、.pdf），仅作过滤器提示、非强制安全限制。
- 文件在 input.files（一个 FileList）中读取。

```html
<input type="file" name="imgs" multiple accept="image/png,image/jpeg">
```

> [!WARNING]
> 警告内容：accept 只是文件选择器的友好过滤，不能作为安全校验依据——用户仍可强制选择其他文件，服务端须自行校验文件类型、大小与内容。多文件用 input.files 遍历读取。

#### autocomplete 与自动填充

**autocomplete 属性**：提示浏览器为字段自动填充已保存的信息，提升长表单填写的便利。

- 常见取值：name、email、tel、organization、street-address、postal-code、username、current-password、new-password、one-time-code。
- 特殊取值：off 关闭、on 允许、new-password 提示新密码生成。

```html
<input type="text" name="username" autocomplete="username">
<input type="password" name="pw" autocomplete="current-password">
```

> [!TIP]
> 建议内容：为常见字段正确设置 autocomplete 名称，能让浏览器智能填充并减少输入错误。给验证码用 autocomplete="one-time-code" 甚至可触发系统短信码填充。autocomplete 与密码管理器协作也依赖它。
