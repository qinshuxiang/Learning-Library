## 表单与输入控件

### 表单基础

#### form 元素与提交

**form 元素**：表单容器，把一组用于收集用户输入的控件组织在一起，并可整体提交。

- action 属性：提交数据的处理地址。
- method 属性：提交方式（get 或 post）。
- name：表单名称。

```html
<form action="/search" method="get">
  <label for="q">搜索：</label>
  <input type="search" id="q" name="q">
  <button type="submit">搜索</button>
</form>
```

- 表单提交时，浏览器把有 name 的控件值按 method 发送到 action。
- 通过脚本也可用 FormData 读取或异步提交（见下一章）。

> [!IMPORTANT]
> 重要内容：能够被提交的控件必须有 name 属性——没有 name 的控件值不会随表单发送。这是新手最常见的遗漏：视觉上填了内容，服务器却收不到。

#### label 与控件关联

**label 元素**：为表单控件提供可点击的文本标签，与控件正确关联后可放大点击区域并提升可访问性。

```html
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 也可用控件嵌套 label 的方式隐式关联 -->
<label>邮箱：<input type="email" name="email"></label>
```

- 显式关联：label 的 for 指向控件的 id。
- 隐式关联：把控件直接嵌进 label 内。
- 点击 label 会聚焦或触发对应控件，屏幕阅读器也能读出控件用途。

> [!IMPORTANT]
> 重要内容：几乎每个表单控件都应有 label（或 aria-label 等可访问名称）。没有 label 的输入框，屏幕阅读器无法告知用户该填什么。用 for 加 id 的显式关联最稳妥。

#### 按钮 button

**button 元素**：可点击按钮，通过 type 区分提交、重置与普通按钮。

- type="submit"：提交表单（默认）。
- type="reset"：重置表单。
- type="button"：普通按钮，不提交不重置，配合脚本用。

```html
<form>
  <button type="submit">提交</button>
  <button type="reset">重置</button>
  <button type="button" onclick="doSomething()">自定义操作</button>
</form>
```

> [!WARNING]
> 警告内容：button 的默认 type 是 submit。在 form 内放一个未写 type 的 button 会触发表单提交，常引发意外刷新。form 内做普通交互的按钮务必写 type="button"。



### 输入控件 input

#### input 的常见类型

**input 元素**：最灵活的表单控件，由 type 属性决定其形态与输入语义。以下是常用类型。

- type="text"：单行文本。
- type="password"：密码框，输入被遮蔽。
- type="email"：邮箱，浏览器可做格式校验（部分设备弹对应键盘）。
- type="number"：数字输入，带增减，可配 min、max、step。
- type="search"：搜索框，样式与清理按钮因平台而异。
- type="tel" / type="url"：电话与网址，提供相应输入体验。
- type="date" / "time" / "datetime-local"：日期与时间选择。
- type="color"：取色器。
- type="range"：滑块。
- type="file"：文件选择（见下一章）。
- type="hidden"：隐藏字段，随表单提交但不显示。

```html
<input type="text" name="name" placeholder="请输入姓名">
<input type="email" name="email" placeholder="name@example.com" required>
<input type="number" name="age" min="1" max="120" step="1">
<input type="date" name="birthday">
```

> [!NOTE]
> 提醒内容：type 的语义价值不仅在于外观——合适的 type（email、number、date）会让移动端弹出对应键盘、让浏览器做基础格式校验，是低成本高收益的做法。

#### input 的通用属性

无论何种 type，input 普遍支持若干通用属性。

- name：提交字段名（必写，见上）。
- value：初始值（文本类）；checkbox/radio 提交的取值。
- placeholder：占位提示（不是 label 替代品）。
- required：必填。
- disabled：禁用，值不提交。
- readonly：只读，值仍提交。
- autocomplete：提示浏览器自动填充。
- maxlength / minlength：长度限制。
- checked：checkbox/radio 默认选中。

```html
<input type="text" name="code" placeholder="验证码" maxlength="6" required>
<input type="checkbox" name="agree" id="agree" checked>
```

> [!WARNING]
> 警告内容：disabled 与 readonly 不同——disabled 控件不参与提交、用户不可交互，readonly 仍参与提交但用户不能改（多用于防编辑的展示值）。placeholder 不应取代 label：它随输入消失，不能作为持久标签。



### 多选与分组控件

#### checkbox 与 radio

复选与单选用于从选项集中选择。

- checkbox：复选框，可多选，勾选时以 value 提交。
- radio：单选框，同 name 的多个 radio 互斥，只能选其一，选中项以 value 提交。

```html
<p>爱好：</p>
<label><input type="checkbox" name="hobby" value="reading"> 阅读</label>
<label><input type="checkbox" name="hobby" value="coding"> 编程</label>

<p>性别：</p>
<label><input type="radio" name="gender" value="male"> 男</label>
<label><input type="radio" name="gender" value="female"> 女</label>
```

- 同组 radio 必须 name 相同才能实现互斥。
- checkbox/radio 的 value 是提交时带的业务值，勾选与否决定是否提交。

> [!WARNING]
> 警告内容：radio 若各自 name 不同则互不排斥，都能选中，这是常见错误。同一组单选必须共享同一个 name。checked 只能设置默认选中项，用户可自行改变。

#### select 下拉框

**select 元素**：下拉选择框，内含 option 选项，适合选项多或节省空间的场景。

**option 元素**：select 或 datalist 的候选选项。

**optgroup 元素**：对 option 分组显示。

```html
<label for="city">城市：</label>
<select id="city" name="city">
  <option value="">请选择</option>
  <optgroup label="东部">
    <option value="sh">上海</option>
    <option value="hz">杭州</option>
  </optgroup>
  <optgroup label="西部">
    <option value="cd">成都</option>
  </optgroup>
</select>
```

- option 的 value 是提交值，option 文本是显示文本。
- select 加 multiple 属性可多选（UI 通常不佳，少用）。
- selected 属性可设默认选中项。

> [!NOTE]
> 提醒内容：option 的显示文本与 value 应区分开——value 是程序要的业务值，显示文本给用户看。不加 value 时提交的是显示文本。给下拉设一个"请选择"的空选项能避免误选第一项。

#### textarea 多行文本

**textarea 元素**：多行文本输入区，区别于单行的 input type="text"。

```html
<label for="bio">个人简介：</label>
<textarea id="bio" name="bio" rows="4" cols="40"
          maxlength="500">默认内容</textarea>
```

- rows 与 cols 给定可见行数与列数（实际大小可由 CSS 控制并缩放）。
- 默认内容写在标签之间而非 value 属性。
- 支持 maxlength、required、placeholder 等。

> 多行自由文本用 textarea；单行用 input type="text"。textarea 没有 value 属性，初始内容放标签内部文本。

#### datalist 与 input 建议值

**datalist 元素**：为 input 提供一组可选建议值，用户既可下拉选择也可自行输入。

```html
<label for="browser">浏览器：</label>
<input list="browsers" id="browser" name="browser">
<datalist id="browsers">
  <option value="Chrome">
  <option value="Firefox">
  <option value="Safari">
</datalist>
```

- input 用 list 属性指向 datalist 的 id。
- datalist 是可编辑输入的下拉提示，区别于不可输入的 select。

> datalist 兼有 input 的自由输入与 select 的候选提示，适合"可从候选中选、也允许自定义"的字段，如城市联想。



### 分组与整体结构

#### fieldset 与 legend 分组

**fieldset 元素**：把一组相关控件分组，视觉上可加边框。

**legend 元素**：fieldset 的分组标题。

```html
<fieldset>
  <legend>收货信息</legend>
  <label>姓名：<input type="text" name="receiver"></label>
  <label>电话：<input type="tel" name="phone"></label>
</fieldset>
```

- fieldset/legend 让长表单按语义分组，屏幕阅读器会把组标题念给组内控件。
- radio/checkbox 成组时也常用 fieldset 包起以表达"这是一组二选一/多选"。

> [!TIP]
> 建议内容：复杂表单用 fieldset 分组能显著提升可读性与可访问性。把一组互斥的 radio 或一组同主题字段放进 fieldset 并给 legend，辅助技术即可向用户描述"这一组在选什么"。

#### 表单的布局与响应

表单布局与响应式主要靠 CSS（flex/grid）完成，HTML 提供结构。

- 用 label 加控件成对组织，或用栅格排布多列。
- 移动端优化输入体验（合适的 type、autocomplete、font-size 不小于 16px 防 iOS 聚焦缩放）。

> 表单的"排布美观"是 CSS 的职责；HTML 只保证语义、标签关联与合理分组。二者配合才能做出可用又好看的表单。
