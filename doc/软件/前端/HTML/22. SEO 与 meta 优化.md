## SEO 与 meta 优化

### SEO 与 HTML 的关系

#### 搜索引擎如何理解网页

**SEO（Search Engine Optimization，搜索引擎优化）**：通过技术与内容优化，让网页在搜索结果中获得更靠前、更准确的排名。

- 爬虫抓取 HTML 并解析其结构与内容，建立索引。
- 语义化结构、标题层级、链接、meta 都是爬虫理解页面的依据。
- 搜索引擎优化同时服务于真实用户——高质量、语义清晰、加载快的页面往往排名更好。

> [!IMPORTANT]
> 重要内容：SEO 的根本是"服务用户"，而非堆砌关键词。语义化 HTML、清晰标题、合理内容结构是 SEO 的基石；meta 与结构化数据是在此基础上的机器可读增强。先内容与结构，再谈技巧。

#### HTML 中影响 SEO 的主要元素

HTML 层面影响 SEO 的要素集中在结构与元信息。

- title 与 meta description：搜索结果标题与摘要。
- 语义化标签与标题层级：主题与大纲。
- 链接（a 与规范 href）：抓取与权威传递。
- 图片 alt、结构化数据：内容识别与富摘要。

> 这些大多已在前面章节涉及，本章从"面向搜索引擎"的视角做系统梳理与补充。



### 核心 meta 与 head 优化

#### title 的优化

title 是搜索结果中最醒目的标题，优化空间大。

- 准确概括页面主题，把核心关键词前置。
- 控制长度，避免被截断（中文约在 30 字内较稳妥）。
- 每页唯一，避免重复与站点名冗长堆叠。

```html
<title>HTML 入门指南 —— 前端学习笔记</title>
```

> title 同时服务用户与搜索引擎：既是标签页名也是搜索结果标题。清晰、前置主题、长度得当是核心。

#### meta description 描述

**meta description**：搜索结果中标题下方的摘要文本，虽非直接排名因素，但影响点击率。

```html
<meta name="description" content="系统学习 HTML 的完整笔记：结构、语义化、表单、多媒体、可访问性与现代特性。">
```

- 一段准确、有吸引力的描述能提升点击。
- 长度建议约 150-160 字符内，避免截断。
- 内容应贴合页面，避免与正文不符。

> description 写不好不会拉低排名，但写得好能显著提升点击率。每页手写贴合内容的描述，胜过自动生成或留空。

#### 关键词与搜索引擎现状

**meta keywords** 关键字已不被主流搜索引擎用作排名依据，可不必再写。

- 早期 keywords 曾被滥用堆砌，搜索引擎已弃用或降权。
- 不靠 keywords 堆砌，靠真实内容与语义表达主题。

> 现代 SEO 的正确姿势是"让语义与内容自己说话"——正确的标题、heading 结构、链接锚文本自然地表征主题，无需依赖已失效的 keywords meta。



### 规范化与索引控制

#### canonical 权威地址

**rel="canonical"**：声明页面的权威（主）URL，解决重复内容问题。

- 同一内容可由多个 URL 访问（如带参、www 与不带）时，用 canonical 指明首选地址。
- 帮助搜索引擎把权重归集到权威页，避免内容重复稀释。

```html
<link rel="canonical" href="https://example.com/article/html-intro">
```

> 何时用：内容有多个可达 URL（跟踪参数、协议变体、分页），或在多处引用同一内容。canonical 让搜索引擎知道"该以哪个为准"。

#### robots 与索引/抓取控制

控制搜索引擎抓取与索引，可用 robots meta 或 robots.txt。

- name 属性为 robots、content 为 noindex 的 meta 元素：不让本页进入索引。
- content="nofollow"：不追踪本页链接。
- robots.txt 控制整站抓取范围（站点级，非本 HTML 元素范畴，此处点到）。

```html
<meta name="robots" content="noindex, nofollow">
```

> noindex 用于不想被收录的页面（登录后内容、草稿、搜索结果页）。对单页控制用 robots meta，整站抓取策略用 robots.txt，二者分工不同。



### 结构化数据与社交分享

#### 结构化数据 schema

**结构化数据（Structured Data）**：用标准词汇（schema.org）标记页面实体，让搜索引擎生成富摘要。

- 通过 JSON-LD（type 属性为 application/ld+json 的 script 元素）在 head 注入。
- 可表达文章、产品、评分、FAQ、面包屑、事件等实体。
- 富摘要呈现评分星、面包屑、FAQ 折叠等，提升展示。

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "HTML 入门指南",
  "author": { "@type": "Person", "name": "作者" }
}
</script>
```

> [!NOTE]
> 提醒内容：JSON-LD 放 head 中表达实体是主流做法。可用 Google 的富结果测试工具验证结构化数据是否正确。别编造虚假的评分/评价等结构化标记（违反政策）。

#### Open Graph 与社交分享

**Open Graph（OG）**：一套 meta，控制链接在社交平台（微信、Facebook、Twitter 等）分享时的预览。

- og:title、og:description：分享标题与描述。
- og:image：分享缩略图。
- og:url：分享权威地址。
- 各平台基于 OG 生成卡片（Twitter 另有 Twitter Card meta）。

```html
<meta property="og:title" content="HTML 入门指南">
<meta property="og:description" content="系统的 HTML 学习笔记">
<meta property="og:image" content="https://example.com/cover.png">
<meta property="og:type" content="article">
```

> 链接被分享时的第一印象由 OG meta 决定。给内容页配好 og:title、og:image、og:description，分享效果会专业很多。



### 面向搜索的 HTML 实践

#### 语义结构与 heading 的 SEO 意义

搜索优化在 HTML 上的落地，很大程度依赖结构与标题层级。

- 每个页面一个 h1，承载主主题，其后层级递进 h2、h3。
- heading 应是内容的真实大纲，而非堆砌关键词的容器。
- 语义元素（article、nav）帮助爬虫识别内容区块。

> heading 是最重要的 on-page 主题信号之一。合理层级 + 真实概括内容的 heading，比堆砌关键词更能帮助搜索引擎正确理解页面。

#### 图片、链接与内容的 SEO

图片与链接的写法也影响搜索。

- 图片给描述性 alt，利于图片搜索与无障碍（语义见图像章）。
- 链接用描述性锚文本，比"点击这里"更利于理解与被链接页的主题。
- 内容质量与独特性是根本——技术与语义是放大器。

> 结论：HTML 侧能做的是"机器可读、语义正确、结构清晰、有恰当 meta 与结构化数据"。真正决定长期排名的仍是内容价值与用户满意度。技术 SEO 是必要条件而非充分条件。
