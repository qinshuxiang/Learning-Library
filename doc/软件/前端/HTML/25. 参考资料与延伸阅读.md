## 参考资料与延伸阅读

### 官方文档与规范

#### MDN Web Docs

**MDN（Mozilla Developer Network）**：是由 Mozilla 维护的 **Web 技术权威文档**，是查询 HTML 及相关 Web 技术的**首选参考**。

- 覆盖 HTML、CSS、JavaScript 及各类 Web API。
- 每个元素与属性都提供**语法、示例、使用说明、浏览器兼容性**。

> MDN 是查 HTML 的"**标准答案**"：不确定某元素放哪、某属性怎么用、兼容性如何时，先查 MDN。它权威、更新及时、示例丰富，是每个前端开发者的必备工具站。

#### WHATWG HTML Living Standard

**WHATWG 的 HTML Living Standard**：是 HTML 规范的**权威事实来源**（html.spec.whatwg.org）。

- 定义每个元素的精确语义、属性与内容模型。
- 采用"活标准"形态，持续更新，是 HTML 语义争议的最终裁决。

> 当遇到"这个 div 能放 button 吗""section 到底要不要标题"等语义细节问题，查 HTML Living Standard 是最权威的依据。适合进阶时精读相关条目。

#### W3C 与 WCAG

**W3C** 与 **WCAG**：负责 Web 可访问性等标准的制定。

- W3C 维护相关 Web 技术建议书，与 WHATWG 协作推进 HTML 生态。
- **WCAG**（Web Content Accessibility Guidelines）是无障碍的国际准则，分 A、AA、AAA 三级。
- 实践层常以 WAI-ARIA 规范为自定义组件无障碍的依据。

> 可访问性内容（对应第 17 章）以 WCAG 与 WAI-ARIA 为准。目标多定在 AA 级，用官方文档核对要求，勿仅凭经验。



### 学习教程与博客

#### MDN 的 HTML 学习区

MDN 的 **HTML 学习区（Learn web development）**：是**面向初学者的系统免费教程**。

- 从"开始学习 Web"到各技术分册，循序渐进。
- 附带大量练习，是 MDN 官方推荐的入门路径。

> 若想按官方路线系统入门，MDN Learn 是零基础起步的可靠选择。它把理论与动手结合，适合配合本主题章节查漏补缺。

#### 阮一峰《HTML 教程》

阮一峰的 **《HTML 教程》**（网道 WangDoc.com）：是**广受好评的中文 HTML/CSS 教程**。

- 讲解清晰、系统，覆盖基础语法到现代特性。
- 适合中文读者快速上手与回顾。

> 阮一峰教程以"**深入浅出**"著称，是中文 HTML 学习的重要参考。本主题若干基础章节的讲解思路与其相近。

#### 前端学习社区与专栏

各类前端社区与专栏提供实战向的 HTML 知识补充。

- 掘金、SegmentFault 等社区有大量实战文章。
- 千古壹号等作者的 Web 前端图文教程覆盖 HTML 到框架，细致接地气。
- 通过优质专栏可了解 HTML 在现代工程中的真实用法。

> 学习 HTML 不止于语法：多看实际项目源码与工程实践，能理解元素与属性在真实场景中的取舍。社区文章宜交叉参考，以官方文档为准绳。



### 实践与调试工具

#### 浏览器开发者工具

**浏览器开发者工具**是学习与调试 HTML 的第一现场。

- Elements 面板查看实时文档树、增删属性、调整样式。
- Accessibility 树（Chrome 的 Accessibility 面板）观察可访问语义。
- Network 面板分析资源加载与阻塞（对应第 23 章）。

> 把"右键查看源码"升级为"用开发者工具观察"：它显示的是浏览器实际解析与渲染的结果，比原始源码更能反映真实结构。

#### 校验与可访问性工具

以下工具用于验证文档合法性与可访问性。

- W3C 的 Markup Validation Service：检查 HTML 语法与嵌套合法性。
- Lighthouse、axe、WAVE：可访问性审计（对应第 17 章）。
- caniuse：查询特性的浏览器支持矩阵。

> 定期用校验器与 Lighthouse 检查，能让结构错误与可访问性问题无处遁形。caniuse 是决定"能否放心用某新特性"的依据。



### 延伸学习方向

#### 与 HTML 紧密相关的技术

学完 HTML 后可自然延伸至相邻技术。

- **CSS**：控制表现与布局（本库有独立主题，盒模型、flex/grid、动画等）。
- **JavaScript / DOM**：操作文档树、处理事件、发起请求（本库 JavaScript 主题详述）。
- **可访问性与性能**：WCAG、核心 Web 指标（LCP、INP、CLS）的落地实践。

> HTML 是入口，CSS 与 JavaScript 让页面"好看且能动"。把三者与 DOM、浏览器 API 贯通，才构成完整的前端能力。

#### 现代组件与工程

从元素到工程，可继续了解其上的抽象。

- 原生 Web Components、shadow DOM（对应第 20 章）。
- 前端框架（Vue、React）如何基于与超越 HTML。
- 构建工具与静态站点生成器对 HTML 产物的加工。

> 理解 HTML 原生能力后，再看框架如何组织与产出 HTML，能更透彻地把握前端工程全貌。本主题为打基础，框架与工程另循专门资料。
