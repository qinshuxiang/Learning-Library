## 块级与行内元素、替换元素

### 显示类别的基础

#### 块级与行内元素的表现特征

"块级"与"行内"最初描述元素默认的排布方式，虽被内容分类取代，但理解其表现仍有助于把握布局。

- **块级元素**：独占一行，宽度默认填满父容器，可设宽高与上下边距，如 div、p、h1-h6、ul、table。
- **行内元素**：在文本流内排列，不换行，宽高与上下边距由内容与行高决定，如 span、a、strong、em。
- 二者可经 CSS display 互相切换（block、inline、inline-block、flex 等）。

> [!NOTE]
> 提醒内容：块级与行内是默认表现，不是元素不可改变的天性。CSS 的 display 决定实际排布，而 HTML 分类决定嵌套合法性——两个维度不要混淆。

#### 行内块 inline-block 与中间形态

**inline-block**：结合行内与块的特点——像行内一样横向排列、又像块一样可设宽高与上下边距。

- 元素默认表现各不同，通过 CSS 控制可得到灵活的布局形态。
- 现代布局（flex/grid）取代了很多昔日对 inline-block 的依赖，但理解其机制仍有价值。

> 布局的最终控制交给 CSS（详见 CSS 目录的盒模型、flex、grid 章节）；本节厘清元素的默认表现类别，是理解为何某些元素"不换行""设不了宽高"的前提。



### 常见块级与行内元素

#### 典型块级元素

以下元素默认块级，各自语义见前文相关章节。

- 结构容器：div、section、article、header、footer、main、aside、nav。
- 文本区块：p、h1-h6、blockquote、pre、ul、ol、table、form。
- 特点：默认占满父宽、独立成行、可设尺寸与内外边距。

> 块级元素的"占满一行"是理解文档流布局的起点：多个块级元素自上而下堆叠。

#### 典型行内元素

以下元素默认行内，随文本流动排列。

- 文本语义：a、span、strong、em、b、i、mark、small、sub、sup、code、time、abbr。
- 特点：不强制换行，紧贴文本排列，上下内边距与行高对排版的影响较特殊。

> 行内元素在文本中自然相连，靠空格或标签换行决定换行位置。给行内元素设 width、height 多数不生效，要生效常需转 inline-block 或 flex 子项。



### 替换元素

#### 替换元素的概念

**替换元素（Replaced Element）**：其内容不由元素本身的子节点决定，而是由外部资源或属性值"替换"而来。

- 典型替换元素：img、video、iframe、input、textarea、select、canvas、embed、object。
- 替换元素的尺寸规则特殊，浏览器按资源固有尺寸或属性值渲染，其内部通常不接受普通子元素。
- 相对地，非替换元素（div、p、span）内容来自自身子节点。

> [!IMPORTANT]
> 重要内容：替换元素的"内部"是外部内容，不是它的子节点——img 内写子节点无意义，video 的子 source 只是候选源而非被渲染内容。这一特性使替换元素在宽高、定位、可访问性上有很多专属规则。

#### 替换元素的尺寸与对齐

替换元素有独特尺寸与对齐行为，影响布局细节。

- 固有尺寸：img 的位图像素、video 的宽高比、iframe 无固有尺寸，各自不同。
- 默认按固有尺寸显示，可被 CSS width/height 覆盖（可能拉伸，除非配合 object-fit 保持比例）。
- 行内替换元素会参与行框，其基线对齐（vertical-align）行为与文本不同。

> 实践中常给 img/video 设 width:100% 并配 aspect-ratio 或 object-fit 控制比例，避免变形。这属于 CSS 范畴，HTML 侧确保给定正确宽高与资源即可（见图像章）。



### 空元素与常见误区

#### 空元素（void 元素）回顾

前面章节提过 void 元素，这里系统梳理其对布局的影响。

- void 元素无内容、无结束标签：br、img、input、hr、meta、link、area、base、col、embed、source、track、wbr。
- void 元素不能包含子元素，其"内容"来自 src/data/type 等属性或外部资源。
- 在源码中它们闭合于开始标签本身。

> 记忆要点：void 元素即使想"放文字进去"也放不了，如想在 img 里写 alt 之外的内容是无效的——替代文本只能通过 alt 属性表达。

#### 常见元素归类误区

把默认表现为块或行内、是否替换，对照清楚可避免踩坑。

- a、span、strong、em、code 等默认行内。
- div、p、h1-h6 默认块级。
- img、input 默认行内但属替换元素，可设宽高（与普通行内元素不同）。
- button 默认行内块（inline-block）形态。

> 判据不必死背：遇到疑惑时，用浏览器检查元素的计算样式看 display，或查规范确认是否为替换元素。理解"默认表现 + 可被 CSS 改变 + 替换与否"三者即够。



### 布局职责的归属

#### HTML 结构与 CSS 布局的分工

最终要牢记：HTML 提供语义结构，布局与视觉归 CSS。

- HTML 不必纠结"要把它变成块还是行内"——那由 CSS 的 display 决定。
- HTML 只需保证嵌套合法、语义正确。
- 现代布局优先 flex/grid，它们天然处理子项排布，弱化了对 inline-block 等技术手段的依赖。

> 结论：掌握块级、行内、替换元素是为了理解"默认渲染为何如此"，但实际排布一律在 CSS 层解决。HTML 保持语义纯净，是长期可维护的关键。
