## Web Components：template、slot 与自定义元素

### Web Components 概览

#### 什么是 Web Components

**Web Components**：一组原生浏览器标准，用于封装可复用的自定义组件，核心由三部分组成。

- **自定义元素（Custom Elements）**：注册并使用自定义 HTML 标签。
- **Shadow DOM**：把组件的内部结构、样式与外部隔离封装。
- **HTML template / slot**：定义模板并在组件内部插槽分发内容。

```html
<!-- 使用自定义元素 -->
<my-badge>新</my-badge>
```

- Web Components 不依赖框架，是浏览器原生能力。
- Vue、React 等可与之配合，也可作为框架无关的共享组件。

> [!NOTE]
> 提醒内容：Web Components 让"用 HTML 标签封装组件"成为可能。它与框架组件不是对立的——Web Components 提供的是平台层封装，框架在其上或与之协作都很常见。

#### 与传统框架组件的差异

理解 Web Components 的定位有助于选型。

- 原生、无运行时依赖，可跨框架复用。
- 样式默认隔离（Shadow DOM），封装强。
- 但生态、模板语法、状态管理不如框架完备，复杂应用仍需框架。

> 何时用：跨项目/跨框架共享的独立小部件、平台组件、对依赖敏感场景；大型应用整体组件体系仍由框架承担更高效。



### 自定义元素

#### 定义与注册自定义元素

自定义元素由类定义并通过 customElements.define 注册到自定义标签名。

- 类继承 HTMLElement（或其子类）。
- 标签名必须含连字符（如 my-card），避免与内置标签冲突。
- 注册名全局唯一。

```js
class MyCard extends HTMLElement {
  constructor() {
    super();
    // 初始化
  }
}
customElements.define("my-card", MyCard);
```

```html
<my-card>卡片内容</my-card>
```

> [!IMPORTANT]
> 重要内容：自定义标签名必须包含连字符（一个及以上），否则无法注册。这是规范硬性要求，用于保证自定义标签不与 HTML 内置标签冲突。

#### 自定义元素的生命周期

自定义元素有一组回调方法，在生命周期关键点被调用。

- connectedCallback：元素被插入文档时。
- disconnectedCallback：元素被移除时。
- adoptedCallback：元素被移入新文档时。
- attributeChangedCallback：监听属性变化时（配合 observedAttributes）。

```js
class MyCounter extends HTMLElement {
  static get observedAttributes() { return ["count"]; }
  connectedCallback() { console.log("已挂载"); }
  attributeChangedCallback(name, oldV, newV) { console.log(name, newV); }
}
```

> connectedCallback 是初始化的常用入口（避免在 constructor 里操作 DOM 的属性），attributeChangedCallback 用于响应属性变化做更新。disconnectedCallback 常用于清理监听器。

#### 自定义元素的属性与状态

自定义元素把数据放属性（声明式）或属性（property，编程式），二者常需同步。

- HTML 属性是字符串；复杂数据通过元素的 property 传入。
- 常见做法是属性变化时用 attributeChangedCallback 触发内部渲染。
- 设计良好的自定义元素应同时支持属性与 property 两种交互。

> 属性（attribute）与 property 不同：attribute 是 HTML 上的字符串，property 是 JS 对象的字段。组件对外接口通常二者都要考虑并做同步。



### Shadow DOM

#### Shadow DOM 的封装思想

**Shadow DOM**：把组件的内部 DOM 挂到一个"影子根"下，与主文档隔离，是组件封装的核心。

- 影子根（shadow root）内的样式与选择器默认不会泄漏到外部。
- 外部文档的样式通常也作用不进影子内部。
- 从而组件的内部实现细节对外是"黑盒"。

```js
class MyCard extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: "open" }); // 建立影子根
    this.shadowRoot.innerHTML = `
      <style>.box{ border:1px solid #ccc; }</style>
      <div class="box"><slot></slot></div>`;
  }
}
```

- attachShadow 的 mode 为 open（可被外部脚本访问 shadowRoot）或 closed（不可访问）。

> [!IMPORTANT]
> 重要内容：Shadow DOM 隔离样式是双刃剑——它防外部样式干扰组件，但也意味着组件需要自带其内部所需样式。全局设计变量若需传入，可用 CSS 自定义属性（变量）穿透进影子内部。

#### 样式隔离与 CSS 变量

影子内样式默认与外部隔离，但可用 CSS 自定义属性共享主题。

- 影子内部定义的 class 选择器不影响外部同名元素。
- 外部声明的 CSS 变量（:root 的 --xx）可穿透进入影子，供组件读取，实现主题定制。
- 组件应优先用 CSS 变量暴露可定制的钩子。

> 实践：组件在影子内写默认样式，同时用 CSS 变量（如 --badge-bg）开放关键视觉参数，调用方即可在外部覆盖实现主题化，又不破坏封装。



### template 与 slot

#### template 惰性模板

**template 元素**：声明一段 HTML 模板，其内容不会被渲染，只有被取用并插入后才显示。

```html
<template id="item-tpl">
  <li class="item">…</li>
</template>
```

- template 内容处于"惰性"状态，不渲染、不加载其资源。
- 用脚本 clone 其内容并插入文档使用。
- 适合渲染列表项、重复结构。

```js
const tpl = document.getElementById("item-tpl");
const clone = tpl.content.cloneNode(true);
document.getElementById("list").appendChild(clone);
```

> template 与 JS 模板字符串的区别：template 是 HTML 片段模板（仍是节点），JS 模板字符串是字符串。渲染大量重复结构时可配合 template 减少 DOM 操作。

#### slot 插槽与内容分发

**slot 元素**：在组件的影子 DOM 中定义插槽，把使用方（light DOM）写的内容分发进组件指定位置。

```html
<!-- 使用方写入的内容 -->
<my-card>
  <h3 slot="title">标题</h3>
  <p>正文</p>
</my-card>
```

```js
this.shadowRoot.innerHTML = `
  <div class="card">
    <header><slot name="title"></slot></header>
    <div><slot></slot></div>   <!-- 无名插槽承接默认内容 -->
  </div>`;
```

- 具名插槽（slot name）接收带对应 slot 属性的内容。
- 无名插槽（默认 slot）承接未指定 slot 的子内容。
- 这是 Web Components 组合内容的机制，类似框架的插槽概念。

> slot 让组件的"外观结构"在影子内固定，"具体内容"由使用方填充，实现复用与定制的平衡。轻量 DOM 与影子内容各自归属清晰。



### 实践与兼容

#### 一个完整自定义元素示例

综合自定义元素、Shadow DOM 与 slot，构成一个可复用组件。

```js
class MyCard extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: "open" });
    this.shadowRoot.innerHTML = `
      <style>
        .card { border: 1px solid #ddd; border-radius: 8px; padding: 12px; }
        .card h3 { margin: 0 0 8px; }
      </style>
      <article class="card">
        <h3><slot name="title">默认标题</slot></h3>
        <div><slot></slot></div>
      </article>`;
  }
}
customElements.define("my-card", MyCard);
```

```html
<my-card>
  <span slot="title">学习笔记</span>
  这是卡片正文内容。
</my-card>
```

> 此例涵盖了组建一个组件所需的全部原生要素：定义类、建影子根、写模板含插槽、注册标签。基于此可扩展为复杂组件。

#### 浏览器支持与工具链

Web Components 各 API 的浏览器支持已趋于完善，现代浏览器默认支持。

- 自定义元素、Shadow DOM、template/slot 在现代浏览器可用。
- 旧浏览器需 polyfill，但需求随时代递减。
- 复杂工程可由框架配合，或用 lit、stencil 等库简化开发。

> [!NOTE]
> 提醒内容：使用前宜确认目标浏览器的支持基线。多数现代项目可直接使用；如需极广兼容或更高效的响应式渲染，可评估 lit 等轻量库。以最新 caniuse 与规范为准。
