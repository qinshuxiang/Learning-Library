## 列表

### 列表的种类

#### 无序列表 ul

**ul 元素**：无序列表，列表项之间没有顺序意义，每项前默认显示圆点（项目符号）。

**li 元素**：列表项，是 ul 与 ol 的直接子元素，承载每一条列表内容。

```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橙子</li>
</ul>
```

- 无序列表适合描述无先后顺序的并列项，如购物清单、功能点罗列。
- 每个 li 是一个独立的列表项，可直接包含文本、链接、图片乃至块级内容。

> [!NOTE]
> 提醒内容：ul 与 li 是唯一合法的父子搭配——ul 的直接子元素只能是 li（可含脚本与模板类元素）。不要把其他元素直接塞进 ul。

#### 有序列表 ol

**ol 元素**：有序列表，列表项有明确的先后或等级顺序，默认以数字 1、2、3 编号。

```html
<ol>
  <li>打开电源</li>
  <li>登录系统</li>
  <li>开始工作</li>
</ol>
```

- 有序列表适合步骤、排名、流程等有顺序的内容。
- ol 与 ul 的直接子元素规则相同，只能是 li。

> 选择 ul 还是 ol，取决于列表项是否存在顺序语义：无顺序用 ul，有顺序用 ol。顺序用 ol 可让屏幕阅读器读出编号，语义更准确。

#### 描述列表 dl

**dl 元素**：描述列表，用于成对的"名称-描述"内容，结构不同于 ul/ol。

**dt 元素**：描述列表中的术语或名称。

**dd 元素**：对应名称的描述内容。

```html
<dl>
  <dt>HTML</dt>
  <dd>负责网页结构的标记语言。</dd>

  <dt>CSS</dt>
  <dd>负责网页样式的层叠样式表。</dd>
</dl>
```

- dl 描述名词术语与释义，也常用于键值对信息展示。
- 一个 dt 可对应多个 dd，一个 dd 也可描述多个 dt。
- 术语与描述天然成组，比用 ul 罗列键值更语义化。

> [!IMPORTANT]
> 重要内容：dl、dt、dd 是专为"名称与描述"设计的列表，不要用它罗列无名称关联的普通项，也不要把 ul/ol 混进 dt/dd 之外的结构里。术语定义、FAQ、配置项说明是其典型场景。



### 列表的组合与属性

#### 嵌套列表

列表项 li 内可再放入列表，形成层级，常见于目录树与多级菜单。

```html
<ul>
  <li>前端
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </li>
  <li>后端</li>
</ul>
```

- 嵌套列表须放在外层 li 内部，保持"子列表属于某列表项"的语义。
- 嵌套的层级会自动换用不同项目符号样式。

> [!TIP]
> 建议内容：嵌套列表可用于生成多级导航或目录。语义层级正确时，屏幕阅读器能读出层级关系，这对复杂菜单的可访问性至关重要。

#### ol 的 start、reversed 与 type

有序列表 ol 提供若干属性控制编号的起始与形态。

- start 属性：指定起始编号，如 start="5" 从 5 开始。
- reversed 属性：倒序编号。
- type 属性：指定编号类型（1 数字、a 小写字母、A 大写字母、i 小写罗马、I 大写罗马）。

```html
<ol start="3">
  <li>第三项开始</li>
  <li>第四项</li>
</ol>

<ol type="a">
  <li>甲</li>
  <li>乙</li>
</ol>
```

> [!NOTE]
> 提醒内容：自定义编号类型与中文排版习惯（一、二、三）往往不符，多数场景保持默认数字即可。如需复杂编号样式，交由 CSS list-style 控制更灵活。

#### 列表的显示控制

列表的项目符号、缩进与布局主要通过 CSS 控制，而非 HTML 属性。

- list-style-type：控制项目符号形态（disc、circle、square、none 等）。
- list-style-position：控制符号位于列表项内还是外。
- 去除符号常用 list-style: none，常配合横向导航使用。

> 列表的"横排导航"（如顶部菜单）不是 HTML 层面的事，而是用 CSS 把 ul 里的 li 排成一行并去符号——HTML 仍是语义列表，视觉交给样式。
