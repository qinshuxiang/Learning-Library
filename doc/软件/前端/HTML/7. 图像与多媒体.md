## 图像与多媒体

### 图像基础

#### img 元素与 src、alt

**img 元素**：在网页中嵌入图像，是空元素（void），靠 src 指定图像地址、alt 提供替代文本。

```html
<img src="photo.jpg" alt="日落时分的海边">
```

- src（必需）：图像资源的 URL。
- alt（推荐）：图像无法显示或被屏幕阅读器朗读时的替代文本。
- width / height：可显式给定，减少布局偏移。

> [!IMPORTANT]
> 重要内容：alt 不是可省的花瓶，它决定图像对屏幕阅读器用户"是否存在"。信息性图像写有意义的描述，纯装饰图像可写空 alt=""（让辅助技术忽略），不可只用装饰图像的图片则 alt 应描述其传达的信息。

#### 图像的尺寸与布局稳定

**宽高属性**：为 img 提供 width 与 height 可防止图片加载时页面跳动（布局偏移）。

```html
<img src="banner.png" alt="活动横幅" width="1200" height="400">
```

- 建议始终为图片设定宽高（常等于其固有尺寸）。
- 若不设定，图片下载完会瞬间改变布局，造成 CLS（累积布局偏移）性能指标劣化。
- CSS 可再通过 max-width: 100% 让图片自适应容器。

> [!TIP]
> 建议内容：给 img 写上与图片固有比例一致的 width、height，再用 CSS 约束 max-width 使其响应式缩放。这样图片加载前后占位稳定，不产生布局跳动，现代浏览器还能据此预留空间。

#### 图像格式与选择

不同图像格式适合不同内容，选对格式能兼顾质量与体积。

- JPEG：适合照片等渐变丰富的写实图像，不支持透明。
- PNG：支持透明，适合图标、含文字的截图，无损但体积偏大。
- GIF：支持动画，色彩有限，体积可能较大。
- WebP：现代格式，压缩率高，支持透明与动图，浏览器广泛支持。
- AVIF：更高压缩率的现代格式，支持 HDR，兼容性仍在普及。
- SVG：矢量格式，适合图标、徽标，可无损缩放（详见"嵌入内容与可编程图形"）。

> [!NOTE]
> 提醒内容：矢量（SVG）与位图（PNG/JPEG 等）的选择看图形性质——徽标、图标用矢量任意缩放不糊，照片必须用位图。WebP 是当前位图的主流均衡选择。



### 响应式图像

#### 用 srcset 提供多尺寸

在多变宽度的网页中，同一图像按设备像素密度与视口宽度提供不同资源，可既清晰又不浪费带宽。

- **srcset 属性**（配 w 描述符或 x 描述符）：让浏览器按条件挑选最合适的图像文件。
- 搭配 sizes 属性（配 w 描述符时必写）：告诉浏览器图像在不同视口下渲染的宽度。

```html
<img srcset="img-320.jpg 320w,
             img-640.jpg 640w,
             img-1024.jpg 1024w"
     sizes="(max-width: 600px) 100vw, 640px"
     src="img-640.jpg"
     alt="示例图">
```

- w 描述符给出图像文件的真实宽度，浏览器结合 sizes 与设备密度计算该选哪张。
- x 描述符用于设备像素比场景，如 1x、2x。

> [!WARNING]
> 警告内容：srcset 里的 w 描述符必须与文件实际宽度一致，否则浏览器计算错误。用了 w 描述符就应提供 sizes，否则默认按 100vw 计算，可能选错尺寸。

#### picture 元素与 art direction

**picture 元素**：在需要按媒体条件切换不同图像（艺术指导 art direction）或为兼容提供不同格式时使用，img 是其最终兜底。

```html
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="风景照">
</picture>
```

- 每个 source 提供一种候选（不同格式或不同裁剪），浏览器取第一个支持的。
- img 必须有且作为 picture 的最后一个子元素，提供最终兜底与 alt。
- 适用于"不同屏宽用不同构图/裁剪"或"不同浏览器用不同格式"。

> [!TIP]
> 建议内容：格式择优（AVIF、WebP、JPEG 逐级兜底）用 picture 加 type；纯响应式调尺寸用 srcset。除非需按媒体条件换不同图像内容，否则单用 img 加 srcset 即可，不必上 picture。

#### loading 与解码优化

图像的加载与解码可用若干属性优化，提升性能与体验。

- loading="lazy"：延迟加载，图片进入视口附近才加载，节省首屏流量。
- loading="eager"：立即加载（默认）。
- decoding="async"：让浏览器异步解码，减少对其他内容渲染的阻塞。
- fetchpriority="high"：提升首屏关键图（如 LCP 图）的加载优先级。

```html
<img src="banner.png" alt="首屏主图" fetchpriority="high">
<img src="lazy-img.png" alt="下方图片" loading="lazy" decoding="async">
```

> [!IMPORTANT]
> 重要内容：首屏之上对 LCP 影响最大的关键图不要设 lazy（会推迟加载），反而应给 fetchpriority="high"；视口以下的长列表图片用 loading="lazy" 可显著省流量。加载优化详见"性能与加载策略"章。



### 图像语义包装

#### figure 与 figcaption

**figure 元素**：把图像、图表、代码等自成一体、可独立移动的内容包装成"图"，figure 内的可选 figcaption 提供图题说明。

```html
<figure>
  <img src="chart.png" alt="近三年营收增长柱状图">
  <figcaption>图 1：公司近三年营收变化</figcaption>
</figure>
```

- figure 表达的内容与正文有引用关系、可被独立理解。
- figcaption 是 figure 的可选标题，应紧随 figure 内部。

> [!NOTE]
> 提醒内容：figure 不仅用于图片，代码块、表格、图表等可独立引用的内容都可用 figure 包裹。它是比普通 div 包裹图片更具语义的"图容器"。

#### map 与 area 图像热区

**map 元素** 与 **area 元素**：把图像划分为多个可点击热区，每个热区指向不同链接。

```html
<img src="map.png" alt="区域导航" usemap="#navmap">
<map name="navmap">
  <area shape="rect" coords="0,0,100,100" href="/east" alt="东区">
  <area shape="circle" coords="150,150,40" href="/west" alt="西区">
</map>
```

- img 用 usemap 属性引用 map 的 name。
- area 支持矩形（rect）、圆形（circle）、多边形（poly）三种 shape。

> 图像热区适合地图、示意图的局部导航，但坐标手工维护脆弱、移动端体验差，现代项目已少用，多以整图链接或 SVG 替代。



### 其他图像相关

#### 内联 SVG 与 favicon

部分图像形态不依赖外部文件，而是内联在文档中。

- 内联 SVG：直接把 svg 写进 HTML，可被 CSS/JS 控制，利于图标系统（详见"嵌入内容与可编程图形"）。
- favicon：网站图标，通过 link rel="icon" 引入，现代多用 SVG 或多尺寸 PNG。

```html
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
```

> 图标与徽标优先考虑 SVG：体积小、可缩放、可着色。网站图标也可提供多尺寸并配 apple-touch-icon 提升体验。

#### 图像加载失败与占位

图像可能因地址错误或网络问题加载失败，应预想兜底体验。

- 提供正确的 alt，失败时用户仍能知道此处本应是什么。
- 可通过 onerror 或 CSS 提供占位样式，但勿依赖 onerror 导致死循环。

> 健壮的做法是 alt 写实 + 合理的容器样式，即便图挂了页面结构与语义仍完整，这也符合"图像是增强而非必需"的渐进增强思想。
