## 全局属性

### 全局属性的概念

#### 什么是全局属性

**全局属性**：几乎所有 HTML 元素都可使用的公共属性，与元素的专有属性（如 a 的 href）相对。它们为元素提供通用能力。

- 全局属性适用于全部（或几乎所有）元素。
- 元素专属属性各有用途，全局属性跨元素通用。
- 常用全局属性包括 id、class、style、title、lang、dir、hidden、tabindex、data-* 等。

> 区分：src 只属于 img 等，href 只属于 a/link——这些是局部属性；而 id、class、title 等几乎处处可用，是全局属性。

#### 认识一套核心全局属性

先用一张清单建立整体认识，其后再逐项展开。

- 标识与归属：id、class。
- 内容与样式：style、title。
- 语言与方向：lang、dir。
- 可见与交互：hidden、tabindex、contenteditable、draggable、spellcheck、translate、accesskey。
- 自定义数据：data-*。

> 全局属性虽多，多数按需使用。掌握 id、class、data-*、hidden、tabindex 就能覆盖绝大多数场景。



### 标识与归属属性

#### id 属性

**id 属性**：为元素设定唯一标识，用于 CSS 选择、脚本获取、锚点定位与表单 label 关联。

```html
<input type="text" id="username">
<label for="username">用户名</label>
```

- id 在同一文档中必须唯一。
- id 的值区分大小写，习惯用连字符命名（如 user-name）。
- id 可被 CSS（#id）、JS（getElementById、querySelector #id）、锚点（#id）、label（for）引用。

> [!IMPORTANT]
> 重要内容：id 的唯一性必须在全页成立，重复 id 会导致 CSS/JS 命中不确定、label 关联与锚点定位错乱。动态渲染列表时尤其要注意不要给每项硬编码相同 id。

#### class 属性

**class 属性**：为元素设置一个或多个样式类名（以空格分隔），供 CSS 与 JS 引用。

```html
<p class="intro highlight">带两个类的段落</p>
```

- 一个元素可有多个 class，空格分隔。
- 多个元素可共享同一 class（与 id 唯一性相反）。
- 类名习惯用连字符分隔词（如 nav-item）。

> [!TIP]
> 建议内容：优先用 class 而非 id 做样式钩子——class 可复用、语义更清晰，CSS 中滥用 id 选择器（高特异性）会让覆盖困难。id 留给脚本取唯一元素与锚点、label 关联。

#### style 与 title 属性

**style 属性**：元素上的内联样式，直接写 CSS 声明。

**title 属性**：元素悬停时的提示文本，也可为某些元素提供补充信息。

```html
<p style="color: red; font-weight: bold;">内联样式文本</p>
<abbr title="World Wide Web">WWW</abbr>
```

> [!WARNING]
> 警告内容：style 内联样式特异性高、难以覆盖，且把样式写死进 HTML 违反结构与表现分离，应尽量少用，交给 class 加 CSS。title 悬停提示在触屏上不可见，不要把重要信息只放 title，且依赖 title 的交互体验对可访问性有限。



### 数据与交互属性

#### data-* 自定义数据属性

**data-* 属性**：以 data- 开头的一类自定义属性，用于在元素上存放与页面关联的数据，供脚本读取。

```html
<button data-action="delete" data-id="42">删除</button>
<script>
  document.querySelector("button").addEventListener("click", (e) => {
    console.log(e.currentTarget.dataset.action); // "delete"
    console.log(e.currentTarget.dataset.id);      // "42"
  });
</script>
```

- data- 后的部分即数据键，读写作驼峰：data-action 对应 dataset.action，data-user-id 对应 dataset.userId。
- 值只能是字符串；复杂数据通常放 JSON 或从接口取。

> [!TIP]
> 建议内容：data-* 适合在 HTML 里声明"这份数据"，供事件委托或组件读取，避免在 JS 里重复维护映射。不要把敏感数据塞进 data-*——它在 DOM 与源码中可见。

#### hidden 与可见性

**hidden 属性**：布尔属性，表示元素当前与页面无关、不应显示，浏览器默认隐藏该元素。

```html
<p hidden>这段内容默认隐藏</p>
```

- 加 hidden 的元素不渲染显示（display 被覆盖为 none，除非 CSS 显式覆盖）。
- 常用于切换显示逻辑的初始隐藏状态；显示/隐藏也可由 CSS 控制。

> [!NOTE]
> 提醒内容：hidden 与 CSS display:none 类似但带语义（"当前无关"）。若只是样式隐藏但语义上仍在，可不用 hidden 而用 CSS。注意 CSS 若对某元素设了 display 显式值，可能覆盖 hidden 的效果。

#### tabindex 与键盘焦点

**tabindex 属性**：控制元素是否可被 Tab 键聚焦及聚焦顺序，是键盘可访问性的关键。

- tabindex="0"：元素可聚焦，按文档顺序进入 Tab 序列。
- tabindex="正值"：元素可聚焦且被排到 Tab 序列的指定优先级（一般不推荐用正数打乱自然顺序）。
- tabindex="-1"：元素可编程聚焦（focus()）但不在 Tab 序列中。

```html
<button>原生可聚焦</button>
<div tabindex="0" role="button" onclick="doIt()">模拟按钮(可Tab)</div>
<p tabindex="-1" id="target">可通过脚本 focus() 聚焦</p>
```

> [!IMPORTANT]
> 重要内容：能用原生控件（button、input、a）就用原生，它们天生可聚焦且有键盘行为。给 div 加 tabindex 模拟可交互元素，必须同时实现 Enter/Space 等键盘操作并配正确 role。避免用正 tabindex 扰乱自然 Tab 顺序。

#### contenteditable 与可编辑内容

**contenteditable 属性**：让元素内容可被用户直接编辑（所见即所得编辑）。

```html
<div contenteditable="true">双击或点击即可编辑这段文字</div>
```

- contenteditable 值可为 true/false/plaintext-only。
- 配合 document.execCommand（已废弃）或更现代的编辑方案可实现富文本编辑。

> 富文本编辑器（contenteditable）细节多且坑深（光标、格式、粘贴清理），生产多借助成熟编辑器库（如 Quill、TipTap、ProseMirror）。此属性是它们的地基。编辑细节见"剪贴板、拖放与编辑"章。



### 语言、方向与其他全局属性

#### lang 与 dir 属性

**lang 属性**：声明元素内容所用语言。

**dir 属性**：声明文本方向（ltr 从左到右、rtl 从右到左、auto）。

```html
<p lang="zh-CN">中文内容</p>
<p lang="en" dir="ltr">English text</p>
<p dir="rtl">从右到左的语言如阿拉伯语</p>
```

- lang 影响拼写检查、屏幕阅读器发音与排版断行规则。
- dir 用于从右到左的语言（阿拉伯语、希伯来语）排版。

> lang 通常在 html 根元素设置一次，个别外语片段再局部覆盖。dir 默认跟随语言，通常不必每处设。详见"国际化与语言属性"章。

#### draggable、spellcheck、translate、accesskey

其余全局属性各司其职。

- draggable：是否可拖拽（true/false/auto），配合拖放 API。
- spellcheck：是否开启拼写检查（true/false）。
- translate：该元素内容是否可被翻译（yes/no，供机器翻译参考）。
- accesskey：设定快捷键组合（如 accesskey="s" 配合平台修饰键聚焦），因与浏览器冲突且体验不一，需慎用。

```html
<p draggable="true">可拖动元素</p>
<input type="text" spellcheck="true">
```

> [!NOTE]
> 提醒内容：accesskey 会与浏览器/系统的快捷键冲突，且不同平台的修饰键不同，可能反而制造混乱。除非精心设计且无冲突，多数情况下不建议依赖 accesskey 作为主要访问手段。

#### 非标准与过时全局属性

个别旧的非标准全局属性（如 HTML4 的 align、bgcolor、border 等）早已废弃，一律交由 CSS 控制。

- 所有外观类旧属性（align、bgcolor、width/height 于部分元素等）都应改用 CSS。
- 看到旧属性出现在代码里应视为需清理的历史遗留。

> 现代原则：表现全部交给 CSS；HTML 属性只管结构与语义。这样能保证样式可控、响应式易实现、代码统一。
