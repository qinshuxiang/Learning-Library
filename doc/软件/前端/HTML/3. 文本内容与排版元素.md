## 文本内容与排版元素

### 文本语义的核心思想

#### 用语义而非样式表达文本

HTML 文本标记的核心原则是**用语义标签表达内容的含义，而非用标签实现视觉效果**。浏览器对同一语义标签有默认样式，但那只是附带的呈现。

- 语义标签告诉浏览器与辅助技术"这段文字是什么"，而不是"这段文字长什么样"。
- 何时用语义标签、何时用带 class 的 span 或 div，取决于内容本身是否有含义。
- 视觉强调与语义强调可分开控制：语义结构决定机器理解，CSS 决定最终视觉。

> [!TIP]
> 建议内容：先问自己"这段内容在语义上是什么"，再选标签。例如强调可用 strong 或 em，而不仅仅是把它加粗或倾斜。语义正确是 SEO 与可访问性的基础。

#### 标题层级

**标题元素 h1 到 h6**：按从大到小表达六个层级的标题，是页面内容大纲的骨架。

- 一个页面通常只有一个 h1（作为页面主标题），其下按层级使用 h2 到 h6。
- 标题层级应连续递进，避免从 h2 直接跳到 h4（跳级会破坏大纲结构）。
- 标题用于组织内容，不应仅为控制字号而选用标题层级。

```html
<h1>前端入门</h1>
<h2>HTML 基础</h2>
<h3>文本元素</h3>
<h4>行内语义元素</h4>
```

> [!WARNING]
> 警告内容：不要让标题层级出现跳跃或反向，如 h1 后直接 h3。清晰的层级是文档大纲、屏幕阅读器跳转与搜索引擎理解内容结构的共同依赖。控制字号应交给 CSS 而非标题层级。



### 段落与结构文本

#### 段落、换行与分隔

**p 元素**：定义段落，是网页正文最基本的块级容器，浏览器会在段落前后自动留出间距。

**br 元素**：强制换行，用于诗歌、地址等确实需要换行的场合。

**hr 元素**：主题性分隔，表示内容从一个主题切换到另一主题，默认渲染为一条横线。

```html
<p>这是第一段，会自动独占一行并留有段落间距。</p>
<p>这是第二段。<br>这里用 br 强制换行，属于同一段落内。</p>

<hr>

<p>横线上方与下方分属不同主题区段。</p>
```

> [!NOTE]
> 提醒内容：br 只用于语义上确实要换行的位置（地址、诗歌、签名），不要用它来制造行距或布局空隙——那是 CSS margin 的职责。hr 同理是主题分隔，不是装饰线。

#### 预格式化文本

**pre 元素**：预格式化文本，浏览器原样保留其中的空格、换行与制表符，常用于展示代码与排版成品。

```html
<pre>
function hello() {
  console.log("你好");
}
</pre>
```

- pre 内的空白不会折叠，以固定宽度字体呈现。
- 展示代码时通常把 code 元素嵌进 pre 里，二者配合表达"这是一段等宽、需保留空白的代码"。

> 需要保留空白的场景才用 pre；普通文本的换行空格会被折叠，若想保留则用 pre 或 CSS 的 white-space 控制。

#### 引用类元素

引用相关内容由 blockquote、q、cite 等元素表达，需区分引用的块级与行内形态。

- **blockquote 元素**：块级长引用，引用一段较长的他人内容，默认缩进展示，可用 cite 属性标注出处 URL。
- **q 元素**：行内短引用，浏览器自动加引号，cite 属性标注出处。
- **cite 元素**：标注作品（书籍、文章、影片）的标题，而非人的名字。

```html
<blockquote cite="https://example.com/source">
  长风破浪会有时，直挂云帆济沧海。
</blockquote>

<p>他写道：<q>学而时习之，不亦说乎。</q></p>
<p>我最喜欢的一本书是 <cite>《活着》</cite>。</p>
```

> [!WARNING]
> 警告内容：cite 元素用于作品标题，不要把作者人名或普通引用框进 cite。blockquote 适合大段引用，若只是正文里一句话，用 q 或直接加引号即可，避免把普通句子塞进 blockquote。

#### 联系信息与版权

**address 元素**：表示文章或页面的作者、组织或联系信息，通常渲染为斜体。

**small 元素**：表示附属细则，如版权声明、法律文本等次要信息，浏览器渲染为较小字号。

```html
<footer>
  <address>
    联系方式：<a href="mailto:hello@example.com">hello@example.com</a>
  </address>
  <small>© 2026 前端学习笔记</small>
</footer>
```

> [!NOTE]
> 提醒内容：address 只用于联系信息，不要用它标注普通地址描述或文档里的邮政地址正文；后者用普通段落即可。



### 行内语义元素

#### 强调与重要

**em 元素**：强调（emphasis），表示语气上的重读，默认斜体。

**strong 元素**：表示内容非常重要（强烈重要），默认加粗。

- em 表达的是语气的轻重变化；strong 表达重要程度。
- 两者都可嵌套提升层级：如 strong 中的 em 或 em 中的 strong。

```html
<p>我真的 <em>非常</em> 喜欢这段笔记。</p>
<p><strong>警告：</strong>此处内容十分重要，务必牢记。</p>
```

> [!TIP]
> 建议内容：机器可读的无障碍与 SEO 层面，strong 与 em 的语义高于视觉。若只是想要斜体或加粗而无语义，用 CSS font-style 或 font-weight，或使用无语义的 b 与 i 更贴切。

#### 无语义的样式元素 b 与 i

**b 元素**：吸引注意但无特别重要性的文本（如关键词、产品名），默认加粗。

**i 元素**：以不同语气或品质呈现的文本（如外来词、分类名、船名、语气），默认斜体。

- b 与 i 在现代 HTML5 中被重新定义为"无语义但需样式区分"的元素，不再建议仅作视觉加粗斜体。
- 若加粗斜体背后有真正的语义（重要、强调），优先用 strong、em。

> 区分要点：strong、em 携带语义（重要、强调），b、i 只是标记"需这样呈现"。能表达语义就选前者。

#### 高亮、删除与插入

**mark 元素**：高亮标记与上下文相关的文本（如搜索结果命中），默认黄底。

**del 元素**：表示被删除的文本，默认删除线。

**ins 元素**：表示插入的文本，默认下划线。

```html
<p>搜索结果：<mark>CSS</mark> 是层叠样式表。</p>
<p>原价 <del>¥199</del>，现价 <ins>¥99</ins>。</p>
```

> 三者语义明确：mark 强调相关性，del 表达删除，ins 表达新增。del 与 ins 常成对出现表示版本修订，可用 cite 与 datetime 属性标注修改来源与时间。

#### 上下标

**sub 元素**：下标文本，如化学式下标，默认下移缩小。

**sup 元素**：上标文本，如指数、脚注序号，默认上移缩小。

```html
<p>水的化学式是 H<sub>2</sub>O，光速约 3×10<sup>8</sup> m/s。</p>
```

> sub 与 sup 用于数学、化学、脚注等真实上下标语义，不要用它做普通文字缩小排版。

#### 代码与预格式

代码相关行内元素用于标记程序文本，与 pre、code 配合展示代码块。

- **code 元素**：行内代码片段，默认等宽字体。
- **kbd 元素**：用户键盘输入，如 Ctrl+C。
- **samp 元素**：程序输出示例。
- **var 元素**：变量名，默认斜体。

```html
<p>在 <code>for</code> 循环里可遍历数组。</p>
<p>按下 <kbd>Ctrl</kbd> + <kbd>S</kbd> 保存。</p>
<p>程序输出 <samp>Hello, World</samp>。</p>
<p>设变量 <var>x</var> 表示半径。</p>
```

> 展示多行代码时，把 code 元素放进 pre 元素：外层为 pre、内层为 code，既保留空白又标记代码。代码块的高亮由脚本或高亮库完成（学习库渲染即如此）。

#### 时间、缩写与术语

- **time 元素**：表示时间或日期，datetime 属性提供机器可读的值，利于日历与搜索。
- **abbr 元素**：缩写或首字母缩略词，title 属性给出全称，title 可在悬停时提示。
- **dfn 元素**：标记术语定义所在位置，通常包裹首次出现的术语。

```html
<p>会议定于 <time datetime="2026-09-05T14:00">明天下午两点</time> 举行。</p>
<p><abbr title="HyperText Markup Language">HTML</abbr> 负责网页结构。</p>
<p><dfn>层叠</dfn> 指多个样式来源按优先级规则决定最终表现。</p>
```

> [!TIP]
> 建议内容：time 给 datetime 机器可读值，abbr 给 title 全称，都是低成本高回报的可访问性与 SEO 增强，应善加利用。

#### 通用行内容器 span

**span 元素**：无语义的通用行内容器，用于需要以样式或脚本单独处理的一段行内文本。

```html
<p>这段文字里 <span class="price">¥199</span> 需要单独着色。</p>
```

- span 本身不带任何语义与默认样式，作用纯粹是提供一个可挂载 class、样式或事件的行内挂点。
- 能用语义标签表达时优先语义标签，span 是语义元素之外的兜底。



### 文本内容的细节

#### 中英文混排与空白折叠

HTML 默认把连续空白折叠为单个空格，这对含中英文混排的页面有具体影响。

- 中文文本一般无需额外的词间空格，浏览器按字渲染。
- 英文单词间以空格分隔；中文与西文相邻时，常需手工或经 CSS 处理留出合适间距。
- 若需要多个连续空格或控制空白，使用 CSS white-space 属性而非堆砌空格。

> [!NOTE]
> 提醒内容：不要用连续空格或 &nbsp; 来"撑"出布局间距——布局间距一律交给 CSS（margin、padding、flex 间隙等）。源代码里多余空格会被折叠或造成混乱。

#### 处理特殊字符

在 HTML 中写正文时，部分字符需用实体（字符引用）表达，以免被误解析为标签。

- 小于号 < 与大于号 >：正文中直接写 < 会被当成标签开始，应写为实体。
- 与号 &：会被当成实体起始，正文孤立的 & 建议写为实体。
- 详细实体表见"字符编码与实体"一章。

> 规则：正文里要显示 <、>、& 等有特殊意义的字符时，用对应实体书写，避免解析歧义。
