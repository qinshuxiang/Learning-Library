## 音频与视频

### 视频元素 video

#### video 元素的基本用法

**video 元素**：在网页中嵌入视频，用 src 或子元素 source 指定视频源，并提供播放控制。

```html
<video src="movie.mp4" controls width="640" height="360">
  您的浏览器不支持视频播放。
</video>
```

- controls 属性：显示浏览器自带的播放控制条（播放、进度、音量、全屏）。
- video 标签内的文本是浏览器不支持时的后备提示。
- 应提供 width、height 以防布局跳动，比例与视频一致。

> [!IMPORTANT]
> 重要内容：video 元素若只给了 src 而无 controls，用户将无法自行播放（除非脚本控制），体验很差。给用户可访问的视频，应提供 controls 或自定义的等效播放控制。

#### 常用播放属性

video 提供若干属性控制自动播放、循环、静音、预加载等行为。

- autoplay：加载后自动播放（多数浏览器要求同时 muted 才允许自动播放有声视频）。
- loop：循环播放。
- muted：默认静音。
- preload：预加载策略（none、metadata、auto），提示浏览器是否预取。
- poster：视频加载完成前显示的封面图。

```html
<video src="intro.mp4" controls muted loop poster="cover.jpg"></video>
```

> [!WARNING]
> 警告内容：多数浏览器的自动播放策略禁止"有声自动播放"。要让 autoplay 生效通常需同时加 muted。此外有声音会自动播放的内容可能打扰用户，商业网站极少用 autoplay 视频。preload 与带宽取舍详见性能章。

#### 多格式源与 source

视频编码格式存在兼容差异，可提供多个 source 供浏览器按支持情况挑选。

```html
<video controls>
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.webm" type="video/webm">
  您的浏览器不支持视频播放。
</video>
```

- source 提供候选，type 给出 MIME 与编码，浏览器选第一个能解码的。
- 若全部不支持，则显示 video 内文本。

> 当前主流为 MP4（H.264）与 WebM（VP9/AV1）。给关键视频同时提供 MP4 与 WebM 可扩大兼容面，但多数站点用 MP4 即可满足。



### 音频元素 audio

#### audio 元素的基本用法

**audio 元素**：嵌入音频，用法与 video 高度相似，但无画面，也可用 controls 显示控制条。

```html
<audio src="music.mp3" controls></audio>
```

- controls 显示播放控制条。
- 不支持 audio 的浏览器显示标签内后备文本。

> [!TIP]
> 建议内容：默认不给音频设置自动播放（同视频，有声自动播放多被限制）。是否需要 controls、preload 都按场景取舍——背景音乐类常需显式播放按钮。

#### 多源与音轨

audio 同样可用多个 source 提供不同编码，用 track 元素可配字幕或说明文本。

```html
<audio controls>
  <source src="voice.ogg" type="audio/ogg">
  <source src="voice.mp3" type="audio/mpeg">
</audio>
```

- MP3、AAC、OGG（Vorbis）、FLAC 等格式在不同浏览器支持不一，用多 source 覆盖。
- 视频与音频都可内嵌 track 元素提供字幕、章节等（详见下）。

> 给多媒体内容配字幕/文本轨能显著提升可访问性与理解度，尤其语言学习类内容。

#### track 字幕元素

**track 元素**：为 video 或 audio 提供文本轨道，常见为字幕（captions）与说明文字。

```html
<video controls src="lecture.mp4">
  <track kind="captions" src="subtitles.vtt" srclang="zh"
         label="中文字幕" default>
</video>
```

- kind：轨道类型（captions 字幕、subtitles 副标题、descriptions 描述、chapters 章节、metadata）。
- src 指向 WebVTT 格式（.vtt）的字幕文件，srclang 标注语言。
- default 指定默认启用轨道。

> [!IMPORTANT]
> 重要内容：为包含语音的视频提供 captions 字幕，是视频无障碍的关键一环——听障用户与嘈杂环境都依赖字幕。字幕文件用标准 WebVTT 格式书写。



### 画中画与播放控制

#### 画中画 Picture-in-Picture

**画中画（Picture-in-Picture）**：让视频脱离页面、以小窗悬浮显示，可一边操作页面一边看视频，是浏览器的原生能力。

- 通过 video 的 requestPictureInPicture() 方法进入，事件与退出由 API 管理。
- 现代浏览器对 video 原生支持画中画。

> 画中画是增强能力，须由用户触发（如在按钮点击事件里调用），不能脚本静默开启。

#### 媒体播放相关 API 概览

控制媒体播放主要依靠 audio/video 元素暴露的属性与方法，它们是 HTMLMediaElement 的实例。

- 控制方法：play()、pause()、load()。
- 关键属性：paused、ended、currentTime、duration、volume、muted、playbackRate。
- 常用事件：play、pause、ended、timeupdate、loadedmetadata。

```html
<video id="mv" src="intro.mp4"></video>
<button id="btn">播放</button>
<script>
  const mv = document.getElementById("mv");
  document.getElementById("btn").addEventListener("click", () => {
    if (mv.paused) { mv.play(); } else { mv.pause(); }
  });
</script>
```

> [!NOTE]
> 提醒内容：play() 返回一个 Promise，若自动播放被策略拒绝会 reject。应在调用处 catch 处理（如 .catch 提示用户手动播放），避免未处理的 Promise 报错。



### 无障碍与资源组织

#### 媒体元素的可访问性

多媒体的无障碍需要结构、字幕与文字替代的多重配合。

- 给无文本轨的纯音乐/环境音场景，考虑是否需对听障用户说明。
- 关键信息若仅在音视频中表达，应有文字形式的等效内容（transcript 文本稿）。
- 提供 controls 让键盘用户能操作播放。

> 无障碍原则：音视频中的重要内容应有文字替代。给较长的讲课/播客配文本稿（transcript），是比仅配字幕更彻底的可访问方案。

#### 视频文件的组织与来源

生产站点播放视频通常不直接放巨大文件，而会借助流媒体或 CDN 优化。

- 大视频建议用渐进式流（HTTP Range）或 HLS/DASH 自适应流。
- 用 poster 提前展示封面，首屏不被视频首帧拖累。

> 本文档聚焦 HTML 元素与属性本身；流媒体切片、自适应码率等属更深的视频工程话题，此处点到即可。
