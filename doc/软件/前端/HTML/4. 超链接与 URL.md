## 超链接与 URL

### 超链接基础

#### a 元素与 href

**a 元素（anchor）**：是 HTML 中创建超链接的元素，通过 href 属性指定跳转目标。互联网的互联互通正是靠不计其数的 a 元素串联而成。

```html
<a href="https://example.com">访问示例站点</a>
```

- href 是 a 元素的核心属性，指定链接指向的 URL。
- 链接文本应是可读的描述性文字，让用户与屏幕阅读器知道点击后会到哪里。
- 除导航外，a 也可下载文件、发邮件、拨打电话、跳转页内锚点。

> [!IMPORTANT]
> 重要内容：链接文本宜自解释，如"查看 HTML 入门指南"，而非笼统的"点击这里"。清晰链接文本对可访问性与 SEO 都更友好。

#### 链接的几种承载形态

a 元素的链接内容不仅可以是文字，也可包裹图片等其他元素，形成多样入口。

- 文本链接：最常见，以文字为可点击区域。
- 图片链接：把 img 等元素包进 a，点击图片跳转。
- 块级内容链接：现代 HTML 允许 a 包裹部分块级内容（如卡片式链接）。

```html
<a href="https://example.com">
  <img src="banner.png" alt="访问示例站点">
</a>
```

> 可点击区域由 a 内内容决定。包裹图片时务必给 img 写 alt，否则屏幕阅读器无从得知链接含义。



### URL 的结构

#### URL 的组成

**URL（Uniform Resource Locator，统一资源定位符）**：指明资源在互联网上的位置与获取方式。理解其结构对编写 href 至关重要。

```
scheme://host:port/path?query#fragment
协议     主机   端口  路径  查询   片段
```

以 https://example.com:443/docs/page.html?id=1#intro 为例：

- scheme（协议）：https，决定如何获取资源。
- host（主机）：example.com，域名或 IP。
- port（端口）：443，可省略（http 默认 80、https 默认 443）。
- path（路径）：/docs/page.html，资源在服务器上的位置。
- query（查询字符串）：?id=1，向服务器传递参数。
- fragment（片段）：#intro，页面内的锚点位置。

> [!NOTE]
> 提醒内容：fragment（# 后部分）不会发送到服务器，只在浏览器本地定位页内元素。它是页内锚点导航的实现基础。

#### 绝对路径与相对路径

链接的 href 可写绝对路径或相对路径，二者的解析基准不同。

- **绝对 URL**：以协议开头（https://…），完整指明资源位置，可跨站点。
- **相对 URL**：相对当前文档位置解析，又分三种。
  - 同目录：直接写文件名，如 page.html。
  - 上级目录：用 .. 表示，如 ../style.css。
  - 根相对：以 / 开头，相对站点根目录，如 /assets/logo.png。

```html
<!-- 绝对 -->
<a href="https://example.com/page.html">外部页</a>

<!-- 相对：假设当前位于 /docs/index.html -->
<a href="intro.html">同目录兄弟页</a>     <!-- /docs/intro.html -->
<a href="../index.html">上一级首页</a>     <!-- /index.html -->
<a href="/about.html">根目录页</a>        <!-- /about.html -->
```

> [!WARNING]
> 警告内容：路径解析极易出错。区分三种相对路径的关键：无前缀是当前目录、.. 是上一级、/ 开头是站点根。斜杠写错或多写一层会 404。可用开发者工具的链接检查或直接访问验证。



### 链接的打开方式与安全

#### target 属性

**target 属性**：决定链接在何处打开，其值决定新窗口或当前窗口行为。

- target="_self"：默认，当前标签页打开。
- target="_blank"：新标签页打开。
- target="_parent" / "_top"：在 iframe 的父级或顶层打开。
- 自定义命名窗口：如 target="win1"，多次点击复用同名窗口。

```html
<a href="https://example.com" target="_blank">在新标签打开</a>
```

> [!WARNING]
> 警告内容：使用 target="_blank" 时，务必同时加 rel="noopener"（现代浏览器默认也隐含 noopener 效果，但显式写出更稳妥）。这能防止新页面通过 window.opener 反向操控原页面（tabnabbing 攻击）。

#### download 与外部协议

除跳转外，a 元素还可触发下载与调用系统能力。

- download 属性：让浏览器下载而非打开目标，可指定保存文件名。
- mailto: 协议：唤起邮件客户端。
- tel: 协议：移动端唤起拨号。
- 避免使用 javascript: 协议的 href。

```html
<a href="report.pdf" download="月报.pdf">下载月报</a>
<a href="mailto:hi@example.com">发邮件</a>
<a href="tel:+8613800000000">拨打电话</a>
```

> [!WARNING]
> 警告内容：不要用 href 值为 javascript:void(0) 的 a 元素来实现"点了没反应"的占位链接，会破坏可访问性与安全。真正的按钮行为应使用 button 元素，链接就应指向真实地址。



### 页内锚点导航

#### 使用 id 与 hash 定位

通过把链接指向 #某元素的 id，可在同一页面内平滑定位，形成目录式导航。

```html
<nav>
  <a href="#section-basics">基础</a>
  <a href="#section-forms">表单</a>
</nav>

<h2 id="section-basics">基础</h2>
<p>…</p>
<h2 id="section-forms">表单</h2>
```

- 链接 href="#intro" 会滚动到 id="intro" 的元素。
- 元素须有唯一 id，且 href 的 hash 与其一致。
- 现代浏览器对元素 id 定位，旧写法用 a name 已废弃。

> [!TIP]
> 建议内容：用 # 加 id 做页内锚点，配合 CSS scroll-behavior: smooth 可实现平滑滚动。为锚点目标设置足够的 scroll-margin-top，避免被固定导航遮住。

#### 跨页锚点与链接状态

- 跨页锚点：先跳转到另一页，再定位其内部锚点，如 page.html#section。
- 浏览器可用 :visited 伪类区分已访问与未访问链接，样式交由 CSS 处理。

> 锚点导航是单页长文档（本文档亦是）常用体验。链接命中与否由 CSS 的 :link 与 :visited 表达，a 本身无需为此加 class。
