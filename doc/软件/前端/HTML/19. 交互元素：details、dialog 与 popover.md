## 交互元素：details、dialog 与 popover

### details 与 summary

#### details 可折叠区块

**details 元素**：创建可展开与收起的折叠区块，无需脚本即可实现手风琴、FAQ 等展开效果。

**summary 元素**：details 的可见标题，点击它以展开或收起内容。

```html
<details>
  <summary>什么是 HTML？</summary>
  <p>HTML 是用于描述网页结构的标记语言。</p>
</details>
```

- details 内除 summary 外的内容默认折叠，点 summary 展开。
- 折叠/展开由浏览器原生处理，天然支持键盘（Enter/Space/方向键）与无障碍。

> [!IMPORTANT]
> 重要内容：details/summary 是"手风琴""FAQ 折叠"的原生实现，自带展开状态与键盘支持，优于用 div 加脚本模拟。尽量用它而非手写 ARIA 手风琴。

#### open 属性与状态控制

**open 属性**：布尔属性，存在时 details 默认展开。

```html
<details open>
  <summary>默认展开的内容</summary>
  <p>打开页面即能看到这段内容。</p>
</details>
```

- 不带 open 时默认收起。
- 展开状态可通过脚本读写 open 属性或 toggle 事件获知。

> 事件联动：监听 details 的 toggle 事件，可在展开收起时执行脚本（如懒加载内容）。初始是否展开用 open 属性决定。



### dialog 对话框

#### dialog 元素与 showModal

**dialog 元素**：创建对话框（模态框）。用脚本调用其方法控制显示。

- dialog.showModal()：以模态框打开，阻断页面其余交互并置顶。
- dialog.show()：以非模态方式打开。
- dialog.close()：关闭。
- 模态框带遮罩层、焦点锁定与 Esc 关闭（现代浏览器默认）。

```html
<dialog id="dlg">
  <p>这是对话框内容</p>
  <form method="dialog">
    <button value="confirm">确定</button>
  </form>
</dialog>
<button onclick="document.getElementById('dlg').showModal()">打开</button>
```

> [!NOTE]
> 提醒内容：dialog 内放 method="dialog" 的 form，点提交按钮会自动关闭对话框并把 button 的 value 作为返回值（dialog.returnValue）。这是原生 dialog 的便捷关闭方式。

#### 模态框的焦点与样式

原生 dialog 解决了传统模态框最难的两个点：焦点管理与 Esc 关闭。

- 打开时焦点自动移入对话框并锁定在内部，关闭后归还触发元素。
- 按 Esc 默认关闭（可监听 cancel 事件处理）。
- 对话框宽度、遮罩背景由 CSS 控制（::backdrop 伪元素设遮罩）。

```html
<style>
  dialog::backdrop { background: rgba(0,0,0,.5); }
</style>
```

> [!TIP]
> 建议内容：原生 dialog 元素已内置焦点锁定与 Esc，省去手写大量可访问逻辑。自绘模态框需自行实现焦点圈闭、Esc、焦点归还，复杂度高，能用原生 dialog 元素就用。

#### 对话框的关闭与返回值

对话框的打开、关闭与返回值的读写由脚本完成。

```js
const dlg = document.getElementById("dlg");
// 打开
dlg.showModal();
// 监听确定按钮关闭
dlg.addEventListener("close", () => {
  console.log("返回值", dlg.returnValue);
});
```

- returnValue 记录关闭时的值（如 method="dialog" 表单按钮的 value）。
- close 事件在关闭时触发，cancel 事件在按 Esc 触发。

> 控制 dialog 主要用 showModal、show、close 三方法与 close/cancel 两事件，理解即可覆盖绝大多数用法。



### popover 弹出层

#### popover 属性与基本用法

**popover 属性**：给元素声明为弹出层，用按钮的 popovertarget 触发，是原生、轻量的气泡/菜单弹出方案。

```html
<button popovertarget="tip" popovertargetaction="toggle">提示</button>
<div popover id="tip">这是弹出内容</div>
```

- 元素加 popover 属性即成为弹出层，默认隐藏，弹出时置顶显示。
- 按钮用 popovertarget 指向目标 id，popovertargetaction 指定动作（toggle/show/hide）。

> [!NOTE]
> 提醒内容：popover 适合工具提示、轻量菜单、弹出卡片。相较自定义浮层，它原生处理了层级（Top Layer）与"点击外部/按 Esc 关闭"，省去不少脚本。详细行为随浏览器演进以最新规范为准。

#### popover 的关闭行为与样式

popover 弹出层有一致的交互关闭行为。

- 点击外部区域默认关闭。
- 按 Esc 关闭。
- 同一时刻可存在多个（行为由具体特性决定）。
- 可用 ::backdrop 等为某些 popover 设置背景（取决于是否 modal 型）。

> 状态控制也可用脚本（showPopover、hidePopover、togglePopover）或监听相关事件。具体 API 以浏览器支持为准。

#### 弹出层方案选型

根据需求选合适的原生方案。

- 纯展开收起文本 → details/summary。
- 模态对话框 → dialog（showModal）。
- 轻量提示/菜单气泡 → popover。
- 复杂、需精细定制的弹层 → 组件库或自定义（注意可访问性）。

> 结论：details、dialog、popover 构成了"原生交互组件三件套"，覆盖多数折叠、弹框、气泡场景。优先原生可少写大量脚本并自带可访问性，是现代 HTML 的进步方向。
