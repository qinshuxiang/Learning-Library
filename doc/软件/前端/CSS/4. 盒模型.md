## 盒模型

### 盒模型的概念

#### 什么是盒模型

**盒模型（Box Model）**：是 CSS 布局的**基础单位模型**——每个元素在渲染时都被视为一个**矩形盒子**，由内到外依次为**内容（content）→ 内边距（padding）→ 边框（border）→ 外边距（margin）**四层。理解盒模型是理解尺寸、定位、布局的起点。

- **内容**：元素实际承载文字/图片的区域，尺寸由 width/height（或内容自身）决定。
- **内边距 padding**：内容与边框之间的留白，属于元素"内部"。
- **边框 border**：包裹内边距与内容的分界线，可设宽窄、样式、颜色。
- **外边距 margin**：本盒子与**相邻元素/父容器**之间的距离，属于元素"外部"。

> 一句话记忆：盒子从里到外是 **内容—内边距—边框—外边距**（像"果肉—果皮—果壳—与邻居的距离"）。四层里，padding 与 border 在盒子的"势力范围"内（会占用布局空间，且可被背景覆盖），margin 在盒子的"势力范围"外。



#### 标准盒模型与怪异盒模型

盒模型的**总宽度如何计算**取决于 box-sizing，它决定 width 到底是"内容宽"还是"含 padding/border 的宽"。

- **标准盒模型（box-sizing: content-box）**：width 只指**内容区**宽，元素实际占宽 = width + padding + border。默认值如此，尺寸需手工加总。
- **怪异盒模型（box-sizing: border-box，又称 IE 盒模型）**：width 指**含 padding 与 border 的宽度**，实际占宽 = width（内容区自动被压缩）。

```css
/* 两者宽度属性的含义不同 */
.a { box-sizing: content-box; width: 200px; padding: 20px; border: 5px solid; }
/* 实际总宽 = 200 + 20*2 + 5*2 = 250px */

.b { box-sizing: border-box;   width: 200px; padding: 20px; border: 5px solid; }
/* 实际总宽 = 200px，其中内容区自动为 200 - 40 - 10 = 150px */
```

> border-box 让"设置一个宽度就得到元素最终占宽"，省去反复加减 padding/border，是现代布局的事实标准。几乎每个项目都会全局加 * { box-sizing: border-box; }。content-box 是默认值，除需严格按内容宽布局的场景外，应尽量避免。



### 盒子的四层与相关属性

#### 内边距 padding

**内边距 padding**：内容区与边框之间的留白。它是元素**背景**（background-color、background-image）能覆盖到的区域，是"把背景撑开"的手段。

```css
.box {
  padding-top: 10px;
  padding-right: 20px;
  padding-bottom: 10px;
  padding-left: 20px;
}
```

- **简写规则**（padding 同 margin、border-width）：1 值四边相同；2 值=上下 / 左右；3 值=上 / 左右 / 下；4 值=上右下左（顺时针）。
- padding 可为**百分比**，其基准是**父容器的宽度**（注意：不是父高）。
- 行内元素（inline）的上下 padding **不改变行高占位**（会"溢出"视觉但不推挤邻近行文本的实际布局尺寸），需小心。

> padding 是"内撑"利器：给按钮/卡片设上下的 padding，配合背景即可得到一个有"留白+底色"的可点击区域。百分比相对**父宽**这一点常被误解——设 padding-bottom: 100% 甚至可用来做"固定比例的占位容器"。



#### 边框 border

**边框 border**：元素最外圈的分界，分 border-width（宽）、border-style（样式）、border-color（颜色）三要素，且可**分方向**设置。

```css
.box {
  border: 2px solid #333;          /* 简写：宽 样式 颜色 */
  border-top: 1px dashed red;      /* 覆盖某一边 */
  border-radius: 8px;              /* 圆角，见下 */
}
```

- **border-style 取值**：solid（实线）、dashed（虚线）、dotted（点线）、double（双线）、groove/ridge（凹/凸立体）、none/hidden。
- **border-radius**：圆角半径，可拆 border-top-left-radius 等四角；斜杠写法 x / y 产生椭圆角。
- **透明占位**：常用 border: 1px solid transparent 预留边框位，避免 hover 时"内容跳动"。

> border 常被"挪用"为画线、三角、分隔符等工具（配合 border-color 上透明可画三角形）。border-radius 配足够大可成圆形/胶囊。需要注意 border 计入盒尺寸，若不统一 box-sizing: border-box，加边框会使布局总宽变化。



#### 外边距 margin

**外边距 margin**：本盒子与外部（兄弟元素、父边界）之间拉开的空间。它**不参与背景渲染**（背景在 border 内侧结束）。

```css
.box {
  margin: 20px auto;   /* 上下 20px，左右 auto */
}
```

- **水平居中**：块级元素设 width 后 margin: 0 auto 可水平居中（auto 平分剩余空间）。
- **margin 可为负值**：把元素向左/上拉、抵消相邻间距，常用于"去嵌套留白"或制造重叠。
- **百分比基准**：同 padding，margin 的百分比也相对**父宽度**。

> margin 的两个"性格"：它是**外部**空间，因此不与背景、点击区域叠加；它还会引发**外边距折叠**（见下一考点），处理相邻间距时应优先用"父子之间 padding、兄弟之间 margin"的朴素法则来规避坑。



#### 外边距折叠

**外边距折叠（Margin Collapsing）**：垂直方向上相邻的两个 margin **不会相加**，而是**取较大者**合并为一个，仿佛"距离被折叠"。这是初学者最容易困惑的"两个盒子间距怎么没加起来"现象。

```css
.a { margin-bottom: 20px; }
.b { margin-top: 30px; }
/* a、b 之间的间距不是 50px，而是取较大值 30px */
```

触发折叠的三种常见情形：

- **相邻兄弟**：上下两个块级兄弟的垂直 margin 折叠为较大值。
- **父子之间**：子元素的外边距可能"溢出"到父元素外（父无 padding/border/overflow 时会与父的外边距折叠）。
- **自身空块**：没有内容、padding、border 的块，其上下 margin 也会相互折叠。

> 规避折叠的常用"阻断"手段：给父元素加 overflow: hidden（或 auto）、加 padding/border、改为 **flex/grid 容器**（flex 容器内不折叠）、或直接给父加 display: flow-root。flex/grid 子元素之间的 margin 不会折叠，是布局里最省心的规避方式。



### 盒子的尺寸

#### width 与 height

**width / height**：定义内容区（或含 padding/border，取决 box-sizing）的尺寸，属性值可为长度、百分比、auto 或关键字。

- **auto**：块级元素默认 auto 宽度 = **填满父容器可用宽**；高度 auto = 由内容撑开。
- **百分比**：宽高百分比相对**父的对应轴**；高度百分比在父无显式高度时常不生效（退化为 auto）。
- **内联元素**：行内元素**设置宽高无效**（除非改为 inline-block 等），其尺寸由内容决定。
- **min/max-width、min/max-height**：限制尺寸上下界，max-width: 100% 是"图片自适应"的经典写法。

```css
img { max-width: 100%; height: auto; }  /* 图片不超父宽，等比缩放 */
.container { width: 100%; max-width: 1200px; margin: 0 auto; }
```

> [!WARNING]
> **警告内容**：一个高频误区：块级元素**默认宽度是"填满父"而不是"撑满内容"**，这就是为什么没设宽度时它占据整行、设了宽度后靠 margin:auto 才能居中。想让它"宽度刚好包住内容"用 width: fit-content（或改为 inline-block）。



#### 溢出的处理 overflow

**overflow**：当内容超出盒子（宽度/高度被固定）时的处理方式。它同时影响水平（overflow-x）与垂直（overflow-y）。

```css
.box { overflow: hidden; }   /* 裁剪溢出内容 */
.box { overflow: auto; }     /* 需要时才出现滚动条 */
.box { overflow: scroll; }   /* 总是显示滚动条 */
.box { overflow: visible; }  /* 默认：溢出内容可见地"溢出" */
```

- **visible**：默认，内容超出仍可见（会"溢出"盒外，不被裁剪）。
- **hidden**：裁剪超出的部分，不可滚动（但可配合 JS 滚动）。
- **scroll / auto**：提供滚动，auto 只在需要时显示滚动条。
- **副作用**：设为非 visible 会**建立新的格式化上下文（BFC）**，从而"阻断"外边距折叠、影响浮动清除与定位包含块。

> overflow 也是常见的"裁剪轮播图、生成滚动区域、触发 BFC"三合一工具。注意 overflow-x: auto 与 overflow-y: hidden 同时显式设置时，visible 会被强制算成 auto，因为"一个轴裁剪另一个轴还可见"不允许。
