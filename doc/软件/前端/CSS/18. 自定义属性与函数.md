## 自定义属性与函数

### 自定义属性

#### CSS 变量的概念

**自定义属性（Custom Property，又称 CSS 变量）**：以 -- 开头的属性，可存任意值并在多处**引用复用**，实现"一处改、全局生效"，是 CSS 实现 DRY 与主题化的关键。

```css
:root {
  --brand: #f60;
  --gap: 16px;
  --radius: 8px;
}
.card {
  color: var(--brand);
  padding: var(--gap);
  border-radius: var(--radius);
}
```

- **声明**：--name: value;，名称大小写敏感，值可为任意 CSS 值（颜色、长度、甚至整段 1px solid #ccc）。
- **取用**：var(--name)。
- **作用域与继承**：自定义属性**会继承**；定义在 :root 则全站可用，定义在某元素则只在该元素子树内生效（可用于做局部主题）。

> CSS 变量让"魔法数字/重复颜色"收敛为**语义化命名**。定义在哪就生效到哪：:root 放全局主题，组件根放组件内主题（换肤即换父级的变量）。自定义属性**参与层叠**，可被覆盖——同一名字在不同作用域定义，就近取用。



#### var() 的默认值与回退

**var(--name, fallback)**：取用变量时可提供**默认值**，当变量未定义/值为空时使用回退值，增强健壮性。

```css
.el {
  color: var(--text-color, #333);   /* --text-color 未定义则用 #333 */
  padding: var(--gap, 16px);
  border: var(--border, 1px solid #eee);
}
```

- 第二个参数是**回退值**，可嵌套 var()。
- 配合 @supports 可做"不支持变量的旧浏览器"降级。

> [!CAUTION]
> **注意内容**：用 var() 默认值可避免"某个变量在某处忘定义导致整条声明失效"（未定义且无回退时该声明被丢弃）。设计变量系统时给关键变量留合理回退，能让样式更稳。这也在语法层面解决了 CSS 本身没有"常量"的问题。



#### 变量做主题与运行时切换

自定义属性是**主题化与动态换肤**的基石——因为 JS 能直接改元素上的变量，从而让 CSS 值实时变化，无需逐条改样式。

```css
:root { --bg: #fff; --fg: #111; }
body { background: var(--bg); color: var(--fg); }

[data-theme="dark"] {
  --bg: #111; --fg: #eee;
}
```

```js
// 切换主题：改 html 的 data-theme，或直接改变量
document.documentElement.dataset.theme = "dark";
// 或运行时常量/自定义
document.documentElement.style.setProperty("--accent", "#0af");
```

> 变量是 JS 与 CSS 的**低耦合接口**：JS 只需改一处变量（setProperty("--x", v)），成百上千处引用自动更新，且可配 transition 平滑过渡。做**深色主题、动态调色、用户自定义颜色**时，一律优先"变量驱动"，而非逐元素改 style。



### 函数式值

#### 数学函数 calc

**calc()**：在声明里做**四则运算**，允许**混合不同单位**（% 与 px 相加等），返回计算结果。

```css
.el {
  width: calc(100% - 40px);          /* 减掉固定留白 */
  height: calc(100vh - 80px);        /* 视口高扣去导航 */
  margin: calc(8px + 1vw);
}
```

- 支持 + - * /；+ - 两侧必须有**空格**（否则被当作正负号报错），* / 不需要但建议留空。
- 可嵌套 calc()，内部可用变量 calc(100% - var(--gap))。
- 计算在**使用处**进行，结果会随变量/百分比实时更新。

> calc() 解决"百分比不能直接加减固定值"的痛点：栅格减间距、扣除固定宽侧边栏、vh 减顶栏高都靠它。注意 +/- 必须写空格是最高频报错点。让布局"自适应容器又留固定余量"，calc 是首选。



#### 尺寸裁剪 clamp、min、max

**clamp(min, val, max)、min()、max()**：在若干候选中取极值，常用于"既要响应式又要保上下界"的尺寸。

```css
h1 { font-size: clamp(1.5rem, 2vw + 1rem, 3rem); }
/*            最小值   推荐(随视口)  最大值       */
.container { width: min(100%, 1200px); }        /* 取较小者 */
.box { padding: max(16px, 4vw); }               /* 至少 16px */
```

- **clamp(min, 首选, max)**：首选值被夹在 [min, max] 之间，适合**随视口弹性又受限**的字号/间距。
- **min()/max()**：多选一取最小/最大，min(100%,1200px) 即"铺满但不超过 1200px"。
- 三者都支持混合单位与变量。

> clamp() 是响应式排版的"圣杯"——标题字号能随视口微调、又不至于过小过大；min(100%, 固定) 替代 max-width 的写法更直观。内部常配 vw 加一个常数做"平滑缩放"。记住写 clamp 时把 **最小、推荐、最大** 想清楚，顺序别反。



#### 其它常用函数

- **选择类**：var()、attr()（读取元素 HTML 属性到 CSS）。
- **图形/背景类**：url()、linear-gradient()、radial-gradient()、conic-gradient()、image-set()、element()。
- **颜色类**：rgb()/hsl()/oklch()、color()（见颜色章）。
- **滤镜/变换类**：blur()、drop-shadow()、rotate()、scale()、translate() 等。
- **网格/文本类**：minmax()、repeat()、fit-content()、cubic-bezier()、steps()。

```css
.btn {
  background-image: image-set(url("a.avif") type("image/avif"),
                               url("a.png") type("image/png"));
}
.icon::before { content: attr(data-icon); }   /* 读取属性作内容 */
```

> CSS 函数是"把复杂值算出来/拼出来"的工具箱：布局算数用 calc/clamp/minmax，表现用渐变/滤镜/变换，取值用 var/attr。理解"函数都产生一个值、能嵌套、能放变量里"，就能把它们灵活组合（例如 width: calc(min(100%,1200px) - 2*var(--gap))）。
