## 文本与字体

### 字体体系

#### font-family 字体族

**font-family**：指定元素使用的**字体族**，值为一个**按优先级排列的字体列表**（逗号分隔），浏览器逐个向后找第一个**已安装或可加载**的字体。

```css
body {
  font-family: "PingFang SC", "Microsoft YaHei",
               "Helvetica Neue", Arial, sans-serif;
}
```

- **字体族分类**：serif（衬线）、sans-serif（无衬线）、monospace（等宽）、cursive、fantasy。列表末尾**必须**放一个通用族作兜底。
- **中文字体名**含空格/特殊字符时加引号；sans-serif 等通用族不加引号。
- **继承与回退**：font-family 可继承，字体找不到时向后回退。

> 字体加载策略：先写**优先的界面字体**（PingFang、Microsoft YaHei、Roboto 等），再写各平台通用字体，最后以通用族兜底。中文需注意字体名区分系统（macOS 为 PingFang SC，Windows 为 Microsoft YaHei）。前端常配 -apple-system、BlinkMacSystemFont 用系统原生字体。



#### @font-face 自定义字体

**@font-face**：把**外部的字体文件**注册为可用字体，供 font-family 引用，是实现图标字体与品牌字体的手段。

```css
@font-face {
  font-family: "MyFont";           /* 自定义字体名 */
  src: url("./fonts/MyFont.woff2") format("woff2"),
       url("./fonts/MyFont.woff") format("woff"); /* 按格式回退 */
  font-weight: normal;
  font-style: normal;
  font-display: swap;              /* 加载期间先用回退字体渲染 */
}
h1 { font-family: "MyFont", sans-serif; }
```

- **src**：可用 url() + format() 声明多个来源；现代优先 woff2（体积小）。
- **font-display**：控制字体加载期间的显示策略：auto/block/swap（先回退后换）/fallback/optional。swap 最常用，避免文字不可见。
- **其它字面**：font-weight、font-style 可让同一字体文件按字重/斜体区分。

> @font-face 配合 unicode-range 可**按需只加载需要的字形子集**（如只加载图标码位），是图标字体性能优化的关键。加载网络字体会阻塞/影响渲染，应配合 font-display: swap 与必要的 preload。自托管字体规避了 Google Fonts 等外链在部分网络的延迟。



#### font 简写与字重

**font**：一次设置字号、行高、字族、字重等，是字体相关属性的简写。同时有单独属性可精确控制。

```css
p {
  font: italic bold 16px/1.6 "PingFang SC", sans-serif;
  /*    斜体  字重  字号/行高 字体族                 */
}
p { font-weight: bold; }   /* normal|bold|100~900|lighter|bolder */
```

- **font-weight**：100~900（400=normal，700=bold），lighter/bolder 相对父级取更细/更粗档。
- **font-style**：normal/italic（斜体，有独立斜体字面）/oblique（机械倾斜）。
- **font-size**：常用绝对/相对单位（px、rem、em、%）。
- **line-height**：行高，可为无单位数值（推荐，相对字号）、长度或百分比。
- **font-variant**、font-stretch 等较少用。

> [!IMPORTANT]
> **重要内容**：font 简写有**强制顺序**：字重/样式/变体在前、字号居中、可选的 /行高 紧跟在字号后、字体族在末尾。**font-size 与 font-family 二者必写**，缺任一项整条声明**失效被忽略**（并非"重置为默认"）；line-height 可选。故仅想改部分属性时多用单属性。无单位 line-height（如 1.6）能随字号等比缩放，是避免行高"失灵"的首选。



### 文本样式

#### color 与文本装饰

- **color**：文字颜色，可继承，是少数几个**会影响大量子元素默认值**的属性（边框、阴影、文本装饰默认取 currentcolor）。
- **text-decoration**：文本装饰线，简写 text-decoration-line（underline/overline/line-through）+ -style + -color + -thickness。

```css
a { color: #06c; }
a { text-decoration: none; }         /* 去掉链接默认下划线 */
.error { text-decoration: line-through; } /* 删除线 */
.u { text-decoration: underline wavy red 2px; }
```

> color 与文本装饰的关系常被忽略：默认 text-decoration-color 跟随文字颜色（currentcolor），若要装饰线独立配色需显式给 text-decoration-color。链接、del 元素与 s 元素的默认装饰都来自这些属性，可用 text-decoration: none 或自定义覆盖。



#### 对齐、缩进与间距

文本排版的核心控制包括水平/垂直对齐与字符间距。

- **text-align**：left/right/center/justify（两端对齐）。
- **text-indent**：首行缩进，常用 2em（缩进两字符）。
- **letter-spacing**：字符间距（正值拉大、负值收紧）。
- **word-spacing**：词间距（作用于空格处，中文意义小）。
- **line-height**：行高（前述），影响行与行的垂直距离。

```css
p { text-indent: 2em; }        /* 段落首行缩进两字 */
.title { letter-spacing: 0.2em; } /* 标题字距拉大更疏朗 */
.center { text-align: center; }
```

> 中文排版常用 text-indent: 2em 做段首缩进；标题、按钮常加 letter-spacing 提升气质；text-align 的 justify 对中英文混排的两端对齐在宽窄不一的行上效果不一，谨慎使用。首行缩进用 em 使其随字号自适应，比固定 px 更稳。



#### 垂直对齐 vertical-align

**vertical-align**：控制**行内级元素**在行内垂直方向的对齐，常见于文字与图片、图标在同一行的排列。

```css
img { vertical-align: middle; }   /* 与父基线/中线对齐 */
sup { vertical-align: super; }    /* 上标 */
span.badge { vertical-align: top; }
```

- 取值：基线相关 baseline（默认）、top/middle/bottom，以及相对行高的 text-top/text-bottom、上标/下标 super/sub、长度值。
- 它**只对行内 / 行内块 / 表格单元格**有效；对块级元素无意义（此时需用 flex/grid 做垂直居中）。
- **经典坑**：图片下方莫名多出一小段空隙，常因图片默认按**基线**对齐，行高基线下方留了空间——解决：vertical-align: bottom/middle 或图片设 display: block。

> [!IMPORTANT]
> **重要内容**：垂直居中务必分清场景：**文字/图标在文本流里**用 vertical-align；**整个盒子相对父元素居中**用 flex 的 align-items: center 或行高法。试图对块级元素用 vertical-align 是无效操作。



### 溢出与换行

#### white-space 空白处理

**white-space**：控制源码中的**空白与换行**如何呈现，是多行文本/不换行控制的关键。

```css
.nowrap { white-space: nowrap; }       /* 不换行 */
.pre { white-space: pre; }             /* 保留换行与空格（等价于 <pre>） */
.wrap { white-space: normal; }         /* 默认：合并空白，自动换行 */
.pre-wrap { white-space: pre-wrap; }   /* 保留换行但允许自动换行 */
.pre-line { white-space: pre-line; }   /* 保留换行，合并空格，允许换行 */
```

- **normal**：连续空格合并为一个，遇容器边界自动换行。
- **nowrap**：不换行，文本溢出容器（配合 overflow/text-overflow 做省略号）。
- **pre 系列**：保留源码里的换行符与空格（常用于代码展示、用户输入的多行文本）。

> 网页里想"用户回车换行就换行"（文本域内容回显）时用 white-space: pre-wrap——它保留 \n 换行又允许长文本自动折行，比 pre（不会自动换行）更贴合现实文本。



#### 文本截断与省略号

当文本在单行/多行内放不下时，需要**截断并加省略号**，这是列表标题、卡片摘要最常用的处理。

```css
/* 单行省略 */
.single-line {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}

/* 多行省略（-webkit-line-clamp） */
.multi-line {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 3;   /* 最多 3 行 */
  overflow: hidden;
}
```

- **单行**：三件套 overflow:hidden + white-space:nowrap + text-overflow:ellipsis。
- **多行**：用 -webkit-line-clamp 限定行数 + -webkit-box 容器；虽带 -webkit- 前缀，但现代浏览器普遍支持。
- 更通用的多行截断可用 line-clamp（标准属性）或结合 height 估算。

> 省略号的前提是**文本被强制不换行（单行）或限定行数（多行）后发生溢出**，所以三件套缺一不可。多行省略时若父容器可伸缩，需固定容器宽度/行高，否则 clamp 判断的行数不准确。



#### 字体图标与 emoji、icon

字体层面还有三个常见的"把符号当字用"的话题：**font-family 里的图标字体**、**系统 emoji**、以及**图标方案选择**。

- **图标字体（Icon Font）**：把图标绘制成字体（如 Font Awesome、iconfont），用字符码位 + font-family 渲染。优点是像文字一样变色、字号缩放、跨平台一致。
- **emoji**：系统级彩色字体，由各平台提供，样式不可控，跨平台外观不同。
- **替代方案**：SVG 图标（可多色、可精细描边）、mask/background 图标，正在逐步取代纯图标字体。

```css
.icon { font-family: "iconfont", sans-serif; }
.icon::before { content: "\e600"; }   /* 用码位引用某个图标 */
```

> 图标字体的取舍：它"一次加载、方便变色/缩放"适合简单线性图标；但**单个字库需载入全部字形、无多色、易受字体回退影响**。需要多色或高保真图形时，SVG 图标更优。选择方案时按"是否要彩色/是否要换色/图标量"权衡。
