## 动画 animation 与 @keyframes

### 动画与过渡的差异

#### transition 与 animation 的区别

**动画（animation）** 与过渡都实现"样式随时间变化"，但定位不同：**transition 是"状态切换的渐变"，animation 是"可自动运行、可循环、多关键帧的完整动画"**。

- **是否需要触发**：transition 需 hover/类切换等**触发**；animation 可**页面加载即自动运行**。
- **能否重复**：transition 一次性；animation 可设播放次数、可 infinite 无限循环。
- **关键帧数量**：transition 只有起止两态；animation 用 @keyframes 定义**任意多个中间帧**。
- **控制能力**：animation 支持方向、填充模式、播放/暂停状态，过渡没有。

> 一句话判断用谁：**只在 hover/focus/类切换时让值平滑变化 → transition**；**要自动播放、循环、多段过程、可暂停 → animation**。两者也常组合——transition 给"交互状态"，animation 给"持续/自动效果"。



#### 制作动画的两步

用 animation 做动画分两步：**① 用 @keyframes 定义关键帧动画；② 用 animation 属性（或各子属性）把动画应用到元素**。

```css
/* 第一步：定义关键帧 */
@keyframes fadeIn {
  from { opacity: 0; }      /* 起始帧 */
  to   { opacity: 1; }      /* 结束帧 */
}

/* 第二步：应用动画 */
.box {
  animation-name: fadeIn;
  animation-duration: 1s;
}
```

> 记住"**先 @keyframes 起名，再 animation 引用**"。@keyframes 描述"过程长什么样"，animation 属性决定"跑多久、跑几次、怎么跑、何时跑"。命名要唯一，animation-name 与其对应。



### @keyframes 关键帧

#### 关键帧语法

**@keyframes**：定义动画在不同**时间点（0%~100% 或 from/to）**上的样式快照，浏览器在帧之间做插值得到动画过程。

```css
@keyframes bounce {
  0%   { transform: translateY(0); }
  40%  { transform: translateY(-30px); }
  60%  { transform: translateY(-15px); }
  100% { transform: translateY(0); }
}
```

- **from = 0%，to = 100%**，可只写 from/to 表示两态。
- 中间可插入**任意百分比**作为关键帧，形成多段运动。
- 未被关键帧覆盖的属性会**保持元素自身样式**（不参与动画）；只有关键帧里出现的属性才被动画。

> 关键帧是把"动作拆成若干姿势快照"：起、扬、落各写一帧，浏览器自动把帧间补成平滑运动。百分比之间均匀插值。做复杂动画的关键是"分解关键节点"，而非逐帧硬写——一个弹跳往往 3~4 个关键帧即可，剩余交给插值。



#### 关键帧的插值规则

- 关键帧**未定义的中间点**，浏览器在其两侧已定义帧之间做**线性插值**（配合 animation-timing-function 可调速）。
- 同一属性在多个关键帧出现即形成该属性的动画轨迹；缺失的时间点继承前一帧值直到被覆盖。
- **不可插值属性**（如 display）出现在关键帧里时是**离散跳变**而非渐变——display: none 常用于"先让它消失，到某帧再显示"，配合其它可插值属性实现"延迟显示"。

```css
@keyframes stepIn {
  0%   { opacity: 0; }
  90%  { opacity: 0; }   /* 前 90% 保持透明（相当于延迟） */
  100% { opacity: 1; display: block; }
}
```

> 想做"延迟若干秒后再动"而不想用 animation-delay 拖慢节奏，可直接在关键帧里"驻留"（如 0% 与 90% 相同，前 90% 无变化）。display 这类离散值在关键帧是**跳到某帧立即切换**，常用来控制元素在某阶段显示/隐藏。



### animation 的属性

#### 各子属性

animation 由多个子属性协同控制，简写一次声明。

- **animation-name**：引用的 @keyframes 名称。
- **animation-duration**：单次播放耗时，默认 0s（不播放）。
- **animation-timing-function**：播放速度曲线，默认 ease（同 transition 的曲线集：linear/ease-*/cubic-bezier/steps）。
- **animation-delay**：播放前的延迟，默认 0s；负值表示"从动画中间开始播放"。
- **animation-iteration-count**：播放次数，默认 1；infinite 无限循环。
- **animation-direction**：normal/reverse/alternate（交替正反）/alternate-reverse。
- **animation-fill-mode**：播放前后的样式保持（下节）。
- **animation-play-state**：running/paused（暂停/继续）。

```css
.box {
  animation-name: bounce;
  animation-duration: 0.6s;
  animation-timing-function: ease-in-out;
  animation-iteration-count: infinite;  /* 无限循环 */
  animation-direction: alternate;       /* 正反来回 */
}
```

> animation 是"最全的定时器+插值器"：iteration-count 控制重复，direction: alternate 做"往返摆动"（如加载条左右来回），delay 控制开始时机，timing-function 控制单段内的加减速。核心参数先掌握：**name / duration / iteration-count / direction**。



#### 简写与多动画

**animation** 简写一次声明多数子属性，顺序为 名称 时长 时间曲线 延迟 次数 方向 填充模式 播放状态。一个元素可同时应用**多个动画**（逗号分隔多组）。

```css
.box {
  animation: fadeIn 1s ease 0.2s infinite alternate both;
}

/* 同时跑多个动画（逗号分隔），不同动画可不同节奏 */
.combo {
  animation:
    move 2s linear infinite,
    pulse 0.8s ease-in-out infinite alternate;
}
```

- 简写**包含** animation-play-state（可写 running/paused）；注意简写里**第一个时间值**是 duration、**第二个**才是 delay。
- 多组用逗号分隔，各组内部用空格分隔多个值；浏览器按位置对应 name/duration/...。

> 建议：动画多、想复用属性时用**各子属性分开写**更清晰；动画简洁或想少写字时用简写。多个不同属性的动画（如一个管位移、一个管透明度）用逗号拆成两组，各自设置时长与曲线，能做"并行但不同步调"的复合效果。



#### fill-mode 与 play-state

- **animation-fill-mode**：控制动画**播放前**与**结束后**是否沿用关键帧样式。
  - none：默认，播放前后元素都用自身样式（结束后回弹到原状）。
  - forwards：**结束后保持最后一帧**样式。
  - backwards：**开始前（含延迟期）就应用第一帧**样式。
  - both：同时具备 forwards 与 backwards。
- **animation-play-state**：running/paused，可用 JS 切换实现"悬停暂停、点暂停"。

```css
.box {
  animation: fadeIn 1s ease both;   /* 结束保持最后状态 */
}
.box.paused { animation-play-state: paused; }  /* 配合 JS 暂停 */
```

> fill-mode 决定"动画跑完/开跑前元素停在哪儿"：入场动画常用 both 让**延迟期先呈现起始透明**、结束后停在中途或终态不跳回。forwards 在"一次性的到达态动画"（如淡入后停住）里几乎必备，否则结束后会闪回原状。



### 动画实践

#### 常用动画技巧

- **用 transform/opacity 驱动**：位移、缩放、旋转、淡入淡出都是 GPU 友好，性能最好；避免动画 width/height/top 触发布局。
- **steps() 做逐帧**：配合雪碧图做"跑动/翻牌"帧动画，每次跳一帧。
- **will-change**：提示浏览器元素将变化（如 will-change: transform），提前建合成层减少抖动（慎用，勿滥用）。
- **入场/出场态**：弹窗、下拉用 opacity + transform + animation-fill-mode: both 做进场，出场再切 display:none。

```css
.popup { animation: popIn 0.3s ease both; }
@keyframes popIn {
  from { opacity: 0; transform: scale(0.9) translateY(10px); }
  to   { opacity: 1; transform: none; }
}
.loading { animation: spin 1s linear infinite; }
@keyframes spin { to { transform: rotate(360deg); } }
```

> 经验：**能交给 transform/opacity 就不碰布局属性**；加载圈用 rotate 转 360°；入场用 opacity+scale/translate 组合；多段复杂动作用多个 @keyframes 或拆多个动画并行。做动画先想"哪些层在动、是否走合成通道"。



#### 无障碍与动效降级

动画需考虑**减少动效偏好**，为 prefers-reduced-motion 提供降级，避免运动诱发眩晕等不适。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

> 无障碍基线：给"大范围/持续运动"加上 prefers-reduced-motion: reduce 分支，把动画几乎瞬时完成或停掉。虽牺牲一点视觉效果，却对前庭敏感用户更友好，也是多数团队的规范项。
