## 定位 position

### 定位概述

#### position 的取值与包含块

**定位（position）**：控制元素相对**包含块**或**视图**的位置，配合 top/right/bottom/left 偏移。取值不同，其"参考系"也不同。

- **static**：默认，标准流定位，top/left 等无效。
- **relative**：相对**自身原位置**偏移，元素仍在流中占位（不脱离），偏移只是"看起来移动了"。
- **absolute**：脱离文档流，相对**最近的已定位祖先**（非 static）偏移；若无，则相对**初始包含块（html）**。
- **fixed**：脱离流，相对**视口**（viewport）固定，滚动时不动；受 transform 等影响时参考系可能改变。
- **sticky**：相对最近滚动容器，在到达阈值前表现为 relative，越过阈值后表现为 fixed（粘住）。

> [!WARNING]
> **警告**：理解 position 一句话：**relative 是"自我偏移"，absolute 是"相对祖先跑位"，fixed 是"钉在视口"，sticky 是"滚到就粘住"**。决定偏移基准的是**包含块**——absolute 的包含块是最近的非 static 祖先，这是定位最核心也最易错的一环。



#### 定位元素的层级与堆叠

定位元素会**脱离标准流**并可能**相互重叠**，重叠次序由 z-index 与书写顺序决定（详见层叠上下文章）。

```css
.overlay { position: absolute; z-index: 10; }
```

- **z-index**：仅在**定位元素（或 flex/grid 子项）**上生效，数值越大越靠上；可为负（垫底）。
- **未设 z-index**：同层定位元素按**DOM 书写顺序**，后写的在上。
- **auto vs 数值**：auto 不创建新层叠上下文；设置数值会创建新的**层叠上下文**，影响内部整体排序。

> [!WARNING]
> **警告**：定位 + z-index 是"悬浮层、遮罩、下拉、角标"的地基。一个高频坑：absolute 元素若其父是 static，会一路飘到最近的定位祖先甚至页面根——所以**给容器设 position: relative**（不偏移，仅作包含块）是给子元素做绝对定位的标准前奏。



### 绝对定位与相对定位

#### position: relative

**relative**：元素仍占据文档流中的原位置，仅相对**自身原来所在位置**做偏移，不会影响兄弟元素的排布。

```css
.box {
  position: relative;
  top: 10px;      /* 相对原位置下移 10px */
  left: 20px;     /* 右移 20px（自身原位置在流中仍占着） */
}
```

- 偏移 top/right/bottom/left 各自给出"从原位置靠哪侧偏移多少"。
- **不脱离流**：兄弟元素位置不变，看起来"元素移动了但没把别人挤走"。
- 最常用场景：作为 absolute 子元素的**定位参考容器**（不偏移或微调）。

> [!NOTE]
> **提醒**：relative 是个"三栖角色"：既做**轻微自我微调**（如图标对正），又常**只做包含块**（设了 relative 但不偏移，好让内部 absolute 有锚点）。要注意它虽不脱离流，但偏移后可**盖住**后面元素，配合 z-index 需留意堆叠。



#### position: absolute

**absolute**：元素**完全脱离文档流**（不再占位、父高度不含它），相对**最近的非 static 祖先**（包含块）定位。

```css
.parent { position: relative; }        /* 做包含块 */
.child {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);   /* 相对自身尺寸回拉 → 居中 */
}
```

- **包含块**：找最近的 position 不为 static 的祖先；都没有则相对**初始包含块**（html）。
- **绝对定位 + 相对自身偏移**：left/top 相对包含块，若想按自身尺寸再居中，配合 transform: translate（负的自身一半）。
- **宽高 auto**：absolute 元素宽度默认收缩（由内容决定），也可用 left:0; right:0 拉满。

> [!WARNING]
> **警告**：绝对定位常做**徽标、遮罩、下拉、工具提示、悬浮层**。最易错的点：忘记给父设 relative 导致元素"飘"到页面根；以及想居中却只写了 top:50% 忘了把自身回拉一半。现代项目里**垂直/水平居中优先 flex**，absolute 居中用于"悬浮在固定位置（如角标）"更合适。



### fixed 与 sticky

#### position: fixed

**fixed**：脱离文档流，相对**视口**固定——页面滚动时元素保持在视口的同一位置，用于"吸顶导航、右下角回到顶部按钮、侧边栏"。

```css
.fixed-top { position: fixed; top: 0; left: 0; right: 0; height: 60px; }
.back-top { position: fixed; right: 20px; bottom: 20px; }
```

- 相对**视口**固定，滚动不移动。
- **例外**：若祖先设置了 transform、perspective、filter、will-change、contain 等，会**改变 fixed 的包含块**——它不再相对视口，而是相对该祖先（表现为"随祖先滚动"）。

> [!NOTE]
> **提醒**：fixed 的两个注意点：一是给它的祖先加 transform（哪怕 transform: translate(0)）会把 fixed 变成"相对祖先 fixed"，这是实现"只在某区域内吸顶"的常用技巧；二是页面有滚动条时 width:100% 可能相对视口不含滚动条宽度，需自行处理。



#### position: sticky

**sticky**：先按**标准流**排布（relative 行为），当滚动使它**越过设定的阈值**后，便在最近滚动容器内**固定（fixed 行为）**，直到离开其父容器边界。

```css
.sticky-header {
  position: sticky;
  top: 0;               /* 滚到距视口顶部 0 时就粘住 */
}
```

- **生效前提**：父容器要有**足够的剩余高度**让 sticky 元素有"可粘"空间；且最近滚动祖先/父容器不能被 overflow: hidden 等裁掉。
- **相对于最近滚动容器**：默认是视口，若元素在某 overflow:auto 容器内，则相对该容器。
- **sticky 不脱离流**：不会造成父塌陷，比 absolute/fixed 更适合做"吸顶表头、吸顶节标题"。

> sticky 是"相对布局 + 视口吸顶"的优雅结合：它**不脱离文档流**（不影响别人）、滚动到阈值就吸附。常见的失败原因：父容器高度不足（sticky 元素顶到父底就停下）、或祖先有 overflow: hidden 让 sticky 相对错误容器。用它做表格吸顶表头或长文节标题最合适。
