## Flex 弹性布局

### Flex 布局模型

#### Flex 的核心概念

**Flexbox（弹性布局）**：是一维布局模型，用于在一行或一列内**分配空间与对齐项目**。给容器设 display: flex 即开启，容器内的**直接子元素**变成"flex 项"，沿**主轴**排布。

```css
.container { display: flex; }   /* 容器 */
.item { /* flex 项 */ }
```

- **主轴与交叉轴**：flex-direction 决定主轴方向（默认 row 水平），交叉轴与之垂直。
- **两个坐标系**：容器属性管**整体排列**（方向、换行、对齐、主轴分配），项目属性管**单项伸缩与对齐**。
- **脱离 float 痛点**：flex 项可自动等高、垂直居中、按比例伸缩，无需清除浮动。

> 心智模型：Flex 把空间切成**主轴/交叉轴**两个方向来管理——主轴方向解决"怎么排、空间怎么分"（justify-content、flex-*），交叉轴解决"怎么对齐"（align-items）。遇到"横排一排、左中右分布、垂直居中"这类需求，先想 flex。



#### 主轴与交叉轴

先弄清轴，才看得懂各项属性名。

- **flex-direction**：row（左→右，默认）、row-reverse（右→左）、column（上→下）、column-reverse（下→上）。
- **主轴** = flex-direction 的方向；**交叉轴** = 垂直于主轴的方向。
- 换到 column 时，**主轴变成了垂直**，"水平居中"要用交叉轴属性（align-items）而非 justify-content。

```css
.row { flex-direction: row; }        /* 主轴水平 */
.col { flex-direction: column; }     /* 主轴垂直：改列 */
```

> [!WARNING]
> **警告**：最常见的轴混乱：把容器设成 column 后，仍用 justify-content: center 想水平居中——错了，此时主轴是垂直，justify-content 管的是**上下**。规则：justify-content 永远沿**主轴**，align-* 永远沿**交叉轴**。先定 flex-direction 再选对齐属性。



### 容器属性

#### flex-direction 与 flex-wrap

- **flex-direction**：主轴方向（上表）。
- **flex-wrap**：nowrap（默认，不换行，强行压缩/溢出）或 wrap（放不下则**换行**，形成多行）。
- 简写 **flex-flow**：<flex-direction> <flex-wrap>。

```css
.container { display: flex; flex-wrap: wrap; }
.container { flex-flow: row wrap; }   /* 等价 */
```

> [!IMPORTANT]
> **重要**：默认 nowrap 会让 flex 项**收缩**而非换行——所以给一排"卡片"时不写 wrap 它们会越缩越窄或被挤出。要做"自动换行的响应式网格"必须开 flex-wrap: wrap。flex-flow 简写便于把方向与换行一并声明。



#### justify-content 主轴对齐

**justify-content**：沿**主轴**分配**剩余空间**，决定 flex 项在主轴上的整体排布。

```css
.container {
  justify-content: flex-start; /* 默认：靠主轴起点 */
  justify-content: flex-end;   /* 靠主轴终点 */
  justify-content: center;     /* 居中 */
  justify-content: space-between; /* 两端贴边，中间等分 */
  justify-content: space-around;  /* 每项两侧留相等空间 */
  justify-content: space-evenly;  /* 项与边、项与项间距全相等 */
}
```

- 仅当主轴有**剩余空间**（项目总宽 < 容器宽）时效果明显。
- space-between：首尾贴边、中间均分；space-around：每个项目两侧各一半空间；space-evenly：所有间隔（含两边）完全相等。

> 记法速记：center 居中一排、space-between 两端对齐、space-evenly 均匀留白。做"导航左、操作右"用 space-between + 首尾两个子项最常用。注意 justify-content 管主轴，别和交叉轴的 align-items 混。



#### align-items 与 align-content 交叉轴对齐

交叉轴上的对齐分为单行项目（align-items）与多行整体（align-content）。

- **align-items**：每行内各**单行项目**在交叉轴的对齐（作用于单个 flex 行）。
- **align-content**：当**多行**（wrap 产生多行）时，这些"行"整体在交叉轴如何分配（类似 justify 但作用于行）。单行时无效。

```css
.container {
  align-items: stretch;   /* 默认：拉伸填满交叉轴（实现等高） */
  align-items: center;    /* 交叉轴居中（垂直居中常用） */
  align-items: flex-start; /* 靠交叉轴起点 */
  /* 多行时的行整体分布 */
  align-content: space-between;
}
```

- **align-items: stretch** 是 flex 项**自动等高**的来源——未显式设高时拉满容器高。
- **垂直水平都居中**：justify-content: center + align-items: center。

> 三个 align-* 属性极易混淆：**align-items 对齐"一行内的项"**（最常用，配合 justify-content 做居中），**align-content 对齐"多行组成的整体"**（只在 wrap 出多行时有用，管的是行与行之间）。垂直居中请写 align-items: center。



### 项目属性

#### flex-basis、flex-grow 与 flex-shrink

Flex 项在主轴上的**大小**由三个属性决定，是 Flex 的"算力"核心。

- **flex-basis**：项目的**基准尺寸**（主轴方向），类似"期望的初始宽/高"，默认 auto（用 width/height 或内容）。
- **flex-grow**：有**剩余空间**时分给该项目的**增长系数**，默认 0（不增长）。
- **flex-shrink**：空间**不足**时该项目允许**收缩**的比例，默认 1（都收缩）。

```css
.item {
  flex-grow: 1;    /* 剩余空间大家均分（都设1时） */
  flex-basis: 200px; /* 先按 200px 基准，再 grow 填满 */
}
```

> 伸缩逻辑：先按 flex-basis 摆出每个项的**基准**，若主轴有富余，按 flex-grow 比例把富余分出去（每项 grow:1 则等分）；若不够放，按 flex-shrink 比例压缩。想"一个撑满、其它自然宽"：把那个项设 flex-grow: 1。



#### flex 简写

**flex** 是 flex-grow flex-shrink flex-basis 的简写，有几种常用的"整数值"便捷写法。

```css
.item { flex: 1; }            /* = flex: 1 1 0% （grow=1, shrink=1, basis=0） */
.item { flex: auto; }         /* = flex: 1 1 auto */
.item { flex: none; }         /* = flex: 0 0 auto （不伸缩，按内容） */
.item { flex: 0 1 auto; }     /* 默认值 */
```

- **flex: 1**：三个等分列最常用——basis: 0% 让它们**从 0 起均分**，避免内容不同导致不均。
- **flex: none**：完全按内容/宽度，不伸缩。
- **只写一个数**表示 flex-grow，并把 shrink 设 1、basis 设 0%。

> 常用速记的记忆：**flex: 1 = 均分占满**（三列各占 1/3）、**flex: none = 固定不伸缩**、flex: auto = 按内容宽但可伸缩。做"中间自适应、两侧固定"的圣杯布局，就是让中间 flex: 1、两侧 flex: none。



#### align-self 与 order

- **align-self**：单独覆盖**某个项目**的交叉轴对齐（覆盖容器的 align-items）。
- **order**：改变 flex 项的**视觉顺序**（不改变 DOM 结构），数值小的排前面，默认 0。

```css
.item { align-self: flex-end; }   /* 单独把这一项沉到底部 */
.first-visible { order: -1; }     /* 让它排到最前 */
.last-visible  { order: 10; }
```

> [!WARNING]
> **警告**：align-self 用于"整体右对齐但某几个元素要单独沉底/顶"；order 用于**不改 HTML 结构的前提下重排**（如移动端把某块提前展示），但其"视觉顺序 ≠ DOM 顺序"会造成**键盘导航与读屏顺序与视觉不一致**，需谨慎使用，仅在有明确意义时用。
