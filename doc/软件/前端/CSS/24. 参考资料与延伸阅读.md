## 参考资料与延伸阅读

### 官方文档与规范

#### MDN Web Docs

**MDN（Mozilla Developer Network）**：是由 Mozilla 维护的 **Web 技术权威文档**，是查询 CSS 属性、值语法与兼容性的**首选参考**。

- 覆盖 CSS 全部属性、选择器、函数、@规则与概念。
- 每个属性都给出**语法、取值、示例、浏览器兼容性（BCD）**，并标注是否可继承、初始值。

> MDN 是查 CSS 的"**标准答案**"：不确定某属性的取值、是否可继承、能否动画、兼容性时，先查 MDN。它比散落的技术博客更权威、更更新及时，是每个前端必备的工具站。



#### CSS 规范与 WHATWG

**CSS 规范**由 W3C 的 **CSS Working Group** 制定，**WHATWG** 维护部分与 HTML 交织的模块；规范的"官方来源"是理解设计意图的底层依据。

- **w3.org / drafts.csswg.org**：各 CSS 模块的规范草案与候选推荐。
- **标准是模块化的**：没有"CSS4 一本规范"，每个模块独立定级（Level 3/4……）。
- **@supports 与特性查询**：可针对规范中较新的特性做能力检测。

> 想搞清"为什么某属性行为如此"、"某个新特性到哪个阶段了"，看 CSS 工作组的草案最有价值。对普通开发者，MDN + Can I Use 已足够日常；深入原理、跟踪新特性时再回到官方草案与浏览器发布说明。



### 查询工具与社区

#### Can I Use

**Can I Use（caniuse.com）**：是查询某 CSS/JS 特性在**各浏览器中支持情况**的工具站，用**兼容性数据表**直观展示支持比例与版本。

- 输入特性名即得各浏览器（Chrome/Firefox/Safari/Edge 等）的支持矩阵。
- 标注**前缀需求、部分支持、polyfill 途径**。
- 数据常被 Autoprefixer、browserslist 等工具直接引用。

> 判断"这个 CSS 新特性能不能用、要不要补前缀、最低兼容到哪"，以 **Can I Use** 为准，而不是靠记忆或博客。结合 browserslist 配置，Can I Use 的数据能直接指导兼容策略与自动补前缀。



#### CSS-Tricks 与社区优质博客

**CSS-Tricks**（css-tricks.com）曾是 CSS 领域的顶级技术博客，其 **Complete Guide to Flexbox / Grid** 是布局学习的经典长文；另有众多高质量的中文与英文社区文章可参考。

- **CSS-Tricks**：Flexbox、Grid、BFC、居中大全等"一本通"式指南。
- **中文社区**：阮一峰的教程、掘金/思否的 CSS 专栏，讲法接地气。
- **Modern CSS 趋势**：Josh Comeau、Ahmad Shadeed 等的文章对现代布局、CSS 现状剖析深入。

> 进阶路径建议：**布局与盒模型看 CSS-Tricks 的 Guide 系列**，理解"为什么"；看 Ahmad Shadeed 等作者了解"现代 CSS 该怎么写"；中文资料用于查漏与快速上手。社区文章质量参差，交叉验证 + 以 MDN/Can I Use 为准。



### 实战与规范

#### 常见 CSS 规范/体系

实际工程常借用社区沉淀的**命名方法论、Reset、设计系统**，加快起步并保证质量。

- **BEM / SMACSS / OOCSS**：命名与组织方法论（见工程化章）。
- **Modern Reset / Normalize**：统一浏览器默认样式。
- **设计系统/样式方案**：Tailwind、Open Props（CSS 变量库）等，提供开箱即用的原子类或变量体系。
- **browserslist**：声明目标浏览器，供 Autoprefixer 等生成兼容前缀。

> 实战起步建议：**Reset/Normalize + box-sizing:border-box + 一套自己的设计变量（颜色/间距/字体）打底**，再引入命名规范或原子方案统一风格。用 Open Props 之类现成变量库可省去从零设计 token 的功夫，但要符合团队约束。



### 延伸方向

#### CSS 演进与性能

CSS 仍在快速演进，且与"渲染性能、可访问性"深度交织，值得持续跟进的方向如下。

- **现代布局**：Subgrid（子网格）、容器查询 @container、@layer 层叠管理。
- **色彩**：oklch()、color-mix()、广色域 Display-P3。
- **交互/动画**：@starting-style、视图过渡 API（View Transitions）、滚动驱动动画。
- **性能**：content-visibility、contain、合成层优化。
- **无障碍**：prefers-* 媒体查询、:focus-visible、语义化与对比度。

> 学 CSS 不止于"会调样式"，更在于**用模型思维（盒、BFC、层叠上下文）推导布局**、**用规范与工具（MDN、Can I Use）支撑决策**、并**关注模块化演进与性能/可达性**。保持跟进新特性，但以"能落地、有兼容依据"为原则引入。
