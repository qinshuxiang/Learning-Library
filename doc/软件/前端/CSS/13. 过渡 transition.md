## 过渡 transition

### 过渡的概念

#### transition 的作用与局限

**过渡（transition）**：让 CSS 属性值变化时**平滑渐变**而非瞬间跳变，多用于 hover、类名切换、JS 改样式等触发下的视觉反馈。

```css
.button {
  background: #ccc;
  transition: background-color 0.3s ease;
}
.button:hover { background: #f60; }  /* 背景在 0.3s 内渐变过去 */
```

- **可过渡的属性**：必须具有**可插值的中间值**（数值、颜色、长度、百分比等）。display、auto 值、不可数值等无法过渡。
- **需要触发**：属性值在某时刻改变时才会过渡（hover、focus、JS 改值、切换类）；无触发则不变。
- **只关心起止**：transition **不暴露过渡中每一帧的状态**，也无法反向"回放"、循环（那是 animation 的职责）。

> transition 是"有起有止的一次性渐变"，**把状态切换变得丝滑**。它只响应"值变了"这一事件，不能自己反复动。若需要"加载即自动跑、多关键帧、可循环、可暂停"的动画，应交给 animation（见动画章）。



#### 哪些属性可过渡

判断"某属性能否过渡"的本质是**该属性是否具有连续的中间值**，即浏览器能否在两个值之间做插值。

- **可过渡**：颜色（color、background-color）、长度/百分比（width、opacity、transform、font-size、margin 等）、box-shadow、filter、flex 等大多数数值/颜色属性。
- **不可过渡**：display、auto 到长度的过渡（如 height:auto）、position、font-family 等无连续中间值的属性。
- **visibility 可过渡（离散插值）**：属 discrete 型，只要起止一端是 visible 就能在过渡中插值——常配合 opacity 做"淡出后再隐藏"，与 display 不同，无需 transition-behavior: allow-discrete。

```css
.box { transition: transform 0.3s, opacity 0.3s; } /* 多属性逗号分隔 */
```

> [!WARNING]
> **警告**：高频误区：想给 display: none 做过渡动画是做不到的（display 没有中间值）。常见替代是配 opacity + visibility，或在元素可见后再切 display。想让 height 从 0 平滑展开到 auto，CSS 原生难实现，可用 grid-template-rows: 0fr→1fr 或 JS 量高度，或用 max-height 近似。



### 过渡的属性

#### 四个子属性

transition 由四个子属性控制，简写一次可声明。

- **transition-property**：指定参与过渡的属性（默认 all，可多值逗号分隔）。只有可插值属性才有效。
- **transition-duration**：过渡耗时，单位 s/ms，默认 0s（即无过渡、瞬时）。列表不足则重复、过长则裁剪。
- **transition-timing-function**：时间曲线（见下节）。
- **transition-delay**：延迟多久后才开始过渡，默认 0s；负值表示"已进行到过渡中间"再开始。

```css
.el {
  transition-property: opacity, transform;
  transition-duration: 0.3s, 0.5s;   /* 属性与时间一一对应 */
  transition-timing-function: ease;
  transition-delay: 0s, 0.1s;
}
```

> duration 与 property 的**列表对应**：多个属性可分别配不同时长（property 列表与 duration 列表按位置对应，不足重复、过长截断）。最常用的写法其实是简写 transition: opacity 0.3s ease，把属性和时长一次声明。



#### 时间函数 timing-function

**transition-timing-function**：定义过渡**进度随时间的变化曲线**，即"中间帧怎么走"。

- **关键字**：ease（默认，慢起慢收）、linear（匀速）、ease-in（慢起快收）、ease-out（快起慢收）、ease-in-out（两头慢）。
- **cubic-bezier(x1,y1,x2,y2)**：自定义贝塞尔曲线，精确控制加速/减速/回弹感。
- **steps(n)**：**阶梯**跳变而非连续渐变（n 步），适合做打字机、雪碧图逐帧动画。

```css
.a { transition: all 0.4s linear; }
.b { transition: all 0.4s cubic-bezier(0.68, -0.55, 0.27, 1.55); } /* 回弹 */
.c { transition: opacity 1s steps(5); }  /* 5 步跳变 */
```

> 选曲线的直觉：**入场（进入/出现）用 ease-out**（快速进入、慢慢落稳），**退场或通用用 ease**；要"带点弹"用超界贝塞尔（y 超出 0~1）实现 cubic-bezier 回弹。steps() 用于离散的逐帧变化，与连续渐变的"平滑"是两回事。



#### 简写与多属性

**transition** 简写一次声明四个子属性，顺序为 属性 时长 时间函数 延迟；**多条不同属性可逗号分隔**写成多个 transition。

```css
.el { transition: opacity 0.3s ease, transform 0.5s ease 0.1s; }
/*            属性      时长  曲线     时长  延迟 */

/* 一条规则同时过渡所有可过渡属性 */
.el { transition: all 0.3s ease; }
```

- **一条规则**：针对 all 或单个属性声明一组（时长/曲线/延迟）。
- **多条（逗号分隔）**：不同属性想要不同的时长/曲线/延迟时，写多组，用逗号隔开。

> [!WARNING]
> **警告**：经验建议：别滥用 transition: all——它会过渡**任何**变化（含你不想动的布局属性），性能与可预期性都差；更精细的做法是**只列要过渡的属性**。涉及 opacity 与 transform 的动画是 GPU 友好的首选（二者可合成，不触发重排），过渡这两者最常见。



### 触发与注意事项

#### 触发方式

transition 的"值变化"来源主要有几类，理解触发源才能判断"为什么不动画"。

- **伪类触发**：:hover、:active、:focus。
- **类名切换**：JS 添加/移除类导致属性变化。
- **直接改样式**：JS 修改元素的内联样式（element.style.transform = ...）。
- **媒体查询**：进入某断点后属性值变化。

```js
box.classList.toggle("is-open");  // 触发 transition: opacity 0.3s
```

```css
.box { opacity: 0; transition: opacity 0.3s; }
.box.is-open { opacity: 1; }
```

> 一个常见"为什么没动画"：元素**初始渲染时**从默认态切到设定态不会触发过渡（浏览器常把首次渲染合并），要触发需先"落一次初值"再改（如先在下一帧加类，或强制 reflow）。另外 display 从 none 到可见瞬间切换过渡不会生效，需先让元素渲染再改属性。



#### 性能与注意事项

- **只用可合成属性**：过渡 transform 与 opacity（由 GPU 合成）性能最好，不触发重排重绘的布局抖动；过渡 width、height、margin、top 等会反复触发重排，应避免大面积使用。
- **避免 transition: all**：范围过宽会带来多余开销与意外动画。
- **注意 auto 值与离散值**：这些无法过渡（前文）。
- **prefers-reduced-motion**：尊重"减少动效"的无障碍偏好，动效场景应做降级。

```css
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
}
```

> [!WARNING]
> **警告**：性能黄金法则：**过渡尽量做在 transform/opacity 上**。前者移动、缩放不触发布局与绘制（仅合成），后者做淡入淡出也不伤性能。要移动一个盒子，优先 transform: translate 而非 left/top。别让 transition 承担大量重排属性的高频动画。
