## 单位与值

### 长度单位

#### 绝对单位与相对单位

CSS 长度分**绝对单位**与**相对单位**。绝对单位与实际物理长度相关（如 px）；相对单位依赖上下文（字号、视口、父元素）。

- **绝对单位**：px（像素，CSS 基准单位）、in（英寸，1in=96px）、cm、mm、pt（磅，1pt=1/72in）、pc。
- **相对单位（字号类）**：em、rem、ex、ch，基于字体度量。
- **相对单位（视口类）**：vw、vh、vmin、vmax，以及新出的 svw/svh、lvh、dvh。
- **相对单位（容器类）**：cqw、cqh、cqi 等（容器查询单位）。

```css
.px { width: 200px; }
.em { font-size: 1.2em; }   /* 相对父元素字号 */
```

> 实践中 px 是最常用、最稳定的绝对单位；**布局尺寸多用相对单位**以获得响应式/可缩放能力。绝对单位中除 px 外（in、pt 等）在屏幕端几乎不用，多用于打印媒体。理解"相对谁"是选择单位的第一问。



#### px、em 与 rem

px、em、rem 是最核心的三种长度单位，区别在于**参考基准**不同。

- **px**：相对**设备像素**（CSS 像素）的绝对单位，1px 即 1 个 CSS 像素，不随父级或根元素变化。
- **em**：相对**当前元素的字号**（font-size）。用于 font-size 时，1em 相对**父元素**字号；用于其它属性（margin、padding、width）时，相对**自身**字号。因此 em 会随嵌套**累积放大**。
- **rem（root em）**：相对**根元素 html 的字号**，不受中间层级影响，无累积效应。

```css
html { font-size: 16px; }
.parent { font-size: 20px; }
.parent .child { font-size: 1.5em; }  /* = 30px，相对父 20px 的 1.5 倍 */
.parent .grand { font-size: 1.5rem; } /* = 24px，相对根 16px 的 1.5 倍，与层级无关 */
```

> 选择经验：**rem 适合做全局比例体系**（设置 html 根字号即可整体缩放，利于无障碍 font-size 适配）；**em 适合做"随自身字号等比"的局部**（如按钮 padding 用 em 会随字号自适应）；px 用于必须固定的细尺寸（边框、阴影）。嵌套时 em 累积放大是常见 bug 来源。



#### 视口单位 vw/vh 与百分比

视口单位与百分比都用于响应式，但基准不同，是高频混淆点。

- **vw**：视口宽度的 1%；**vh**：视口高度的 1%。
- **vmin / vmax**：视口宽高较小 / 较大者的 1%。
- **svh/lvh/dvh**：分别对应**小视口**（移动端地址栏展开可见时）、**大视口**（地址栏收起后）、**动态视口**（实时跟随收展）——解决移动端 100vh 偏大/偏小问题。
- **百分比**：相对**父容器**的对应轴（宽相对父宽，高相对父高，含其具体含义取决于属性）。

```css
.full { width: 100vw; height: 100vh; } /* 铺满视口 */
.half { width: 50%; }                  /* 父宽的一半 */
.safe { height: 100dvh; }              /* 动态视口高，移动端更稳 */
```

> 关键区别：vw/vh 相对**浏览器视口**，百分比相对**父元素**。全屏 section 常用 min-height: 100vh，但移动端 100vh 会包含已隐藏的地址栏区域导致溢出，故现代写法倾向 100dvh（或 svh）。100vw 在有滚动条时可能多出横向一截，可用 width: 100% 规避。



### 百分比与其他值类型

#### 百分比的使用场景

**百分比（%）**：作为长度/尺寸值时，相对**父容器的对应尺寸**，但不同属性对百分比的"基准"约定不同，不能一概而论。

- **width / margin / padding / left**：相对**父宽度**。
- **height / top**：相对**父高度**（父高为 auto 时百分比常失效）。
- **font-size**：相对**父字号**。
- **line-height**：相对**自身字号**。
- **transform: translate()**：相对**自身**尺寸（故可用来做居中）。

```css
.child { width: 50%; }            /* 父宽一半 */
.child { padding: 5%; }           /* 父宽 5%（与高度无关） */
.child { height: 50%; }           /* 需父有确定高度才生效 */
.child { transform: translate(-50%, -50%); } /* 相对自身宽高一半 */
```

> 百分比的两个"反直觉"：一是 **margin/padding 百分比相对父宽**而非父高，水平垂直皆如此；二是 height: % **依赖父级显式高度**（父为 auto 时解析失败退化为 auto）。想按自身尺寸百分比，用 transform: translate 或 width: fit-content 等。



#### 数值、颜色与其他值类型

CSS 值除长度外还有多种类型，写作时需匹配对应语法。

- **无单位数值**：line-height: 1.6、opacity: 0.5、flex: 1、z-index: 10、font-weight: 700。
- **颜色**：见颜色章（关键字、hex、rgb/hsl、oklch 等）。
- **角度**：deg（度）、turn（圈）、rad、grad，用于旋转/渐变。
- **时间**：s、ms，用于过渡/动画。
- **calc() / 数学函数**：动态计算值（见函数章）。

```css
.op { opacity: 0.5; }
.rotate { transform: rotate(45deg); }
.dur { transition-duration: 300ms; }
.w { width: calc(100% - 40px); }
```

> [!WARNING]
> **警告**：值类型的常见笔误：给需要无单位数值的属性（如 line-height、flex-grow、opacity、z-index）误加了 px 或其它单位，会被当作非法值整条丢弃。动画/过渡的时间单位 s/ms 时长不能省略单位。



#### 全局关键字与自定义属性取用

CSS 为"值该从哪来"提供了统一控制，也允许开发者用**自定义属性**把某个值存起来复用。

```css
/* 全局关键字：控制取值来源 */
.box { color: inherit; }   /* 取父值 */
.box { all: unset; }       /* 全部重置 */

/* 自定义属性（变量）：把值存进变量再取用 */
:root { --brand: #f60; --gap: 16px; }
.card { color: var(--brand); padding: var(--gap); }
```

- inherit/initial/unset/revert 详见过往章。
- 自定义属性以 -- 开头声明，用 var(--name) 取用，**可以参与任何值的书写**，是实现主题化、DRY 的关键（详见"自定义属性与函数"章）。

> 值系统的顶层心智：遇到一个值先问"它是绝对、相对、百分比还是关键字？相对谁？"再用**全局关键字**或**变量**统一管理可复用的部分。熟练掌握值类型 = 能准确预测每个属性的结果，避免"试出来的玄学"。
