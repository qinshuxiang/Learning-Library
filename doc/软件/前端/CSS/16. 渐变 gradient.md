## 渐变 gradient

### 线性渐变

#### linear-gradient 语法

**linear-gradient()**：沿一条**直线方向**由一种或多种颜色**平滑过渡**到另一种，属于**背景图**（赋给 background-image）。

```css
.el {
  background-image: linear-gradient(to right, red, blue);
  /*                方向              起点色 终点色  */
}
```

- **方向**：to right/to bottom/to top right，或角度 0deg（向上，同 to top）/90deg（向右，同 to right）/180deg（向下，同 to bottom），角度顺时针递增。
- **色标（color stop）**：可多个颜色，并可给每个颜色一个位置（red 0%、blue 100%）。
- **默认从上到下**（to bottom）。

> 渐变先定**方向**再排**颜色点**。默认 to bottom 即从上到下的垂直渐变；写角度或 to 关键字控制走向。渐变总是"铺满元素"，可叠加、可配合 background-size、可做条纹/光晕等花活。



#### 多色标与硬边

- **多个色标**：把渐变切成多段，如 linear-gradient(red, yellow, green) 三段。
- **色标位置**：red 0%, green 30%, blue 100%，控制每种颜色在路径上何时达到纯色。
- **硬边（清晰分界）**：让两个相邻色标**位置相同**（如 red 50%, blue 50%），中间无渐变、形成锐利分界，可做"双色背景、进度条"。

```css
.bar { background-image: linear-gradient(to right, #f60 50%, #eee 50%); }
/*       用相同位置色标做 50% 分界的"填充条" */

.stripes {
  background-image: repeating-linear-gradient(
    45deg,
    #fff 0 10px,      /* 每段白条 */
    #000 10px 20px    /* 紧接黑条，形成斜条纹 */
  );
}
```

> 硬边的核心是把两色标"贴到同一位"或用 repeating-linear-gradient 加**色标区间**（色 起 止）做条纹。理解"渐变是沿路径排色点，色点重叠就生硬边"，就能做出色块拼接、条纹、刻度尺等非渐变效果。



### 其它渐变

#### radial-gradient 径向渐变

**radial-gradient()**：从**中心点（或某点）向外呈圆形/椭圆形**扩散的渐变。

```css
.el {
  background-image: radial-gradient(circle at center, #fff, #000);
  /*                        形状   位置        起色 止色 */
  background-image: radial-gradient(circle at top left, #f60, transparent);
}
```

- **位置**：at center/at top left/at 20% 30%。
- **形状**：circle（圆形）或 ellipse（椭圆，默认）。
- **大小**：可设 closest-side/farthest-side/closest-corner/farthest-corner 或长度。

> 径向渐变适合做**光晕、聚光、按钮的高光/内阴影晕、圆形质感**。circle at center 最常用来模拟"中心光向外淡出"。想"中间实、四周透明"做遮罩/高光时，末尾色标用 transparent 很常用。



#### conic-gradient 锥形渐变与叠加

- **conic-gradient()**：绕**中心点顺时针**旋转一圈的渐变（色相轮、饼图、加载环）。
- 三种渐变都可作为背景图**叠加**（多层），并用 background-size/background-position 定位。

```css
.conic {
  background-image: conic-gradient(red, yellow, green, blue, red); /* 色轮 */
}
.pie {
  background-image: conic-gradient(#f60 0 25%, #09c 25% 60%, #eee 60% 100%);
  border-radius: 50%;
}
.multi {
  background-image:
    radial-gradient(circle at center, transparent 0 40%, rgba(0,0,0,0.4) 45%),  /* 内阴影晕 */
    linear-gradient(#f60, #c40);   /* 底层渐变，先写的在上 */
}
```

> conic-gradient 是"绕一圈"的渐变，用相同位置色标可精确画**饼图/进度环**。多张渐变用逗号叠成一张 background-image，**先写的在上层**，配合 background-size 可实现"一个元素画多种色块/纹理"。合理叠加渐变可省去大量图片资源。
