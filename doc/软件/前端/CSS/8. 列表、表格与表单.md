## 列表、表格与表单

### 列表样式

#### 列表的项目符号

CSS 控制无序列表 ul 元素、有序列表 ol 元素、自定义列表 dl 元素的项目符号与布局。

- **list-style-type**：符号类型。无序用 disc/circle/square/none，有序用 decimal（数字）/lower-roman/upper-alpha 等。
- **list-style-image**：用图片作为符号。
- **list-style-position**：符号位置，outside（在文本外侧，默认）或 inside（与文本对齐）。
- **简写 list-style**：可一次设置上述三者。

```css
ul { list-style: none; }                 /* 去符号，最常见 */
ul.styled { list-style: square inside; }
ol { list-style: decimal-leading-zero; } /* 编号补零：01、02 */
ul.custom { list-style-image: url("dot.png"); }
```

> [!NOTE]
> **提醒**：现代 UI 几乎总把列表符号去掉（list-style: none），再自定义间距或用 ::marker 做符号样式。注意 padding-left 对符号位置有影响——去符号后常需一并清 padding。自定义的"·/✓"等前缀多用伪元素实现，而非硬改符号。



#### 自定义符号与 li 布局

除内置符号，还可用 ::marker 精确控制符号的外观，或完全自定义。

```css
li::marker { color: #f60; font-weight: bold; }  /* 符号单独上色 */

/* 完全自定义：用伪元素做"对勾"前缀 */
.check-list { list-style: none; padding-left: 0; }
.check-list li::before {
  content: "✓";
  color: green;
  margin-right: 6px;
}
```

- **::marker**：作用于列表项的符号（li 元素、summary 元素），可改颜色、字号等，但能改的属性有限。
- 复杂布局（如符号定宽对齐、多行缩进、图标与文字对齐）建议**去掉原生符号、改用伪元素或 flex**，可控性最强。
- 列表去符号后，多级缩进、间距、换行缩进都需自行用 padding/margin 管理。

> 取舍：**原生符号**省事但定制受限；**去符号 + 伪元素**实现 "✓/图标 前缀、可多行缩进对齐" 最可控。做导航菜单、任务清单、自定义序号（配合 counter）时，几乎都会走向"自定义列表"方案。



### 表格样式

#### 表格的边框与边距

HTML 表格 table 元素默认无边框、单元格间有间隙，CSS 需显式处理 border-collapse 与边框。

- **border-collapse**：collapse（相邻单元格边框**合并**为一条，推荐）或 separate（分开，保留 border-spacing 间隙）。
- **border-spacing**：仅 separate 生效，设单元格间距。

```css
table {
  border-collapse: collapse;   /* 合并边框，避免双线 */
  width: 100%;
}
th, td {
  border: 1px solid #ddd;
  padding: 8px;
}
```

> [!NOTE]
> **提醒**：border-collapse: collapse 让表格边框合成干净的细网格，是绝大多数表格的默认选择。若想保留单元格间隔、做出"卡片式间隔表"，才用 separate 配 border-spacing。注意 collapse 下 border-spacing 与圆角会受限。



#### 表格布局与对齐

表格的尺寸、对齐与留白靠 table-layout、文本对齐和 vertical-align 控制。

- **table-layout**：auto（默认，浏览器根据内容自动分配列宽，可能慢/跳变）或 fixed（列宽由首行/指定宽度决定，加载稳定、性能好）。
- **列宽**：fixed 下给 col 或 th 设 width 即可固定列。
- **对齐**：水平用 text-align，垂直用 vertical-align: middle。
- **语义分区**：thead 元素、tbody 元素、caption 元素、colgroup 元素各有样式落点（表头背景、脚注等）。

```css
table { table-layout: fixed; width: 100%; }
thead th { background: #f5f5f5; text-align: left; }
td { vertical-align: middle; }
col.id { width: 60px; }   /* 配合 <col class="id"> 固定列宽 */
```

> 大表/需要稳定布局时用 table-layout: fixed：它按**第一行与 col 宽度**快速决定整表列宽，避免内容撑裂与首屏跳动；但长内容需配 overflow/text-overflow 截断，否则会被裁切。响应式表格（小屏横向滚动）常外包一层 overflow-x: auto 容器。



### 表单样式

#### 输入框、选择框与按钮

表单控件的默认外观因浏览器而异，通常需要统一定制基础样式（字体、内边距、边框、聚焦态）。

```css
input, select, textarea {
  font: inherit;          /* 摆脱控件默认字体，跟随页面 */
  padding: 8px 12px;
  border: 1px solid #ccc;
  border-radius: 6px;
}
input:focus, select:focus, textarea:focus {
  outline: 2px solid #4a90d9;   /* 聚焦高亮 */
  border-color: #4a90d9;
}
button { cursor: pointer; }
```

- **统一字体**：控件默认不继承 body 字体，需显式 font: inherit。
- **占位符**：::placeholder 定制颜色等。
- **外观统一**：appearance 可关闭/还原平台原生外观（如 appearance: none 去掉原生样式后再完全自定义）。
- **聚焦态**：outline 是给键盘用户的关键可达性反馈，不要粗暴删除。

> 表单定制的核心是**字体继承 + 统一边框/圆角 + 保留聚焦 outline**。appearance: none 是把 checkbox/select 等"脱原生"后完全自定义的前提，但要为它补上自定义外观与 :checked 态，否则控件会不可见/不可点。



#### checkbox 与 radio 的自定义

勾选类控件的原生外观很难精细控制，常见做法是**隐藏原生控件 + 用伪元素画自定义图形**，或用 accent-color 一键换主题色。

- **accent-color**：给表单控件（checkbox、radio、range、progress）设置主题色，原生图形随主题色变化，最简单。
- **完全自定义**：隐藏 input（position:absolute + 透明），用 label + ::before 绘制，靠 :checked 切换状态样式。

```css
/* 方案一：一键主题色（简单但样式有限） */
input[type="checkbox"] { accent-color: #f60; }

/* 方案二：完全自定义 */
.hide-input {
  position: absolute; opacity: 0; /* 隐藏但可聚焦/点击 */
}
label::before { content: ""; display: inline-block; width: 18px; height: 18px;
  border: 2px solid #ccc; border-radius: 4px; vertical-align: middle; }
.hide-input:checked + label::before { background: #f60; border-color: #f60; }
```

> [!IMPORTANT]
> **重要**：两个方案按需取舍：**accent-color** 几行搞定主题色、保留原生可访问性，适合"只要换色"；**隐藏 + 伪元素**能做出完全品牌化的图形（对勾/圆点动画），但要小心保留键盘聚焦与 :checked 语义。隐藏原生控件时务必保留其**可聚焦与可点击区域**，避免损害可达性。



#### select 与 textarea 的特殊处理

下拉框与多行文本域各有专属注意点。

- **select**：定制下拉选项浮层几乎不可能（选项列表由系统渲染），能控制的只有触发框外观；appearance: none 后需自行画箭头。多选可加 size。
- **textarea**：默认可**拖拽调整大小**（右下角），用 resize: none/vertical/horizontal 控制；其内容默认不换行布局取决于 white-space 与 wrap。
- **长度限制提示**：配合 maxlength 在 JS 中计数。

```css
select {
  appearance: none;
  background: url("arrow.svg") no-repeat right 10px center; /* 自绘箭头 */
  padding-right: 30px;
}
textarea {
  resize: vertical;      /* 只允许垂直拖大 */
  min-height: 120px;
  white-space: pre-wrap; /* 保留换行，长文本自动折行 */
}
```

> [!WARNING]
> **警告**：表单的坑多源自"系统控件样式不受控"：select 的浮层、部分平台控件的字体/高度、input[type=date] 的内置图标等难以完全统一。合理预期是**统一能统一的外层，接受系统渲染的内部**，把重点放在布局、间距、聚焦与校验反馈上。
