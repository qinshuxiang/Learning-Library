## 伪类与伪元素深入

### 伪类的进阶应用

#### 结构性 UI 与组件状态

伪类能表达"结构位置与交互状态"，是**纯 CSS 组件**的语法基础。深入掌握状态类可构建无需 JS 的开关、标签、下拉等。

- **交互状态**：:hover、:active、:focus、:focus-visible（仅键盘聚焦时）、:focus-within（自身或其内获得焦点）。
- **表单状态**：:checked、:indeterminate、:disabled、:enabled、:placeholder-shown、:valid/:invalid。
- **focus-within**：父元素内**任一后代聚焦**时命中——实现"点击组内输入框时高亮整个组"。

```css
.search-box:focus-within { border-color: #f60; box-shadow: 0 0 0 3px rgba(255,102,0,.2); }
a:focus-visible { outline: 2px solid #06c; outline-offset: 2px; }
```

> :focus-visible 是现代可达性要点：鼠标点按钮不显示难看的 focus 圈，键盘 Tab 时才显示清晰焦点。:focus-within 让"聚焦组内任意输入"时整组响应，做卡片式表单高亮很顺手。纯 CSS 开关正是靠 :checked + 兄弟选择器实现状态切换。



#### :checked 状态机与纯 CSS 交互

利用 **:checked + 相邻/通用兄弟选择器**，可用一个隐藏的 checkbox/radio 当"开关"，纯 CSS 实现切换类交互。

```css
.tabs input[type="radio"] { display: none; }  /* 隐藏开关 */

/* 默认：隐藏面板 */
.tab-panel { display: none; }
/* 当某单选项被选中，其后所有面板里对应的一块显示 */
#tab1:checked ~ .panels .panel-1 { display: block; }
#tab2:checked ~ .panels .panel-2 { display: block; }
```

```html
<div class="tabs">
  <input type="radio" name="t" id="tab1" checked>
  <input type="radio" name="t" id="tab2">
  <label for="tab1">选项一</label>
  <label for="tab2">选项二</label>
  <div class="panels">
    <div class="panel panel-1">内容一</div>
    <div class="panel panel-2">内容二</div>
  </div>
</div>
```

> 原理：radio 被选中有 :checked，用 input:checked ~ X 命中其后兄弟并切显隐。能做**标签页、手风琴、抽屉、开关**等状态切换。局限：只能"兄弟之间、单向的显示/隐藏"，复杂动画与多状态仍需 JS。用它可写"零 JS 交互组件"，但对可访问性（隐藏 input 的键盘操作）要谨慎。



#### 状态机与动画衔接

伪类状态变化天然适合接续 transition/animation，构成流畅的交互反馈。

```css
.switch input { position: absolute; opacity: 0; }
.switch .track { width: 50px; height: 26px; background: #ccc; border-radius: 13px;
  transition: background 0.3s; }
.switch .thumb { width: 22px; height: 22px; background: #fff; border-radius: 50%;
  transition: transform 0.3s; }
.switch input:checked ~ .track { background: #f60; }
.switch input:checked ~ .track .thumb { transform: translateX(24px); }
```

> 把"状态"与"过渡"结合 = 一个高质量的无 JS 组件：状态类提供"该是什么样"，transition 提供"怎么滑过去"。凡是要做"选中态、激活态、聚焦态"的平滑反馈，都让**状态交给伪类、动画交给 transition**，各司其职。



### 伪元素深入

#### content 与 attr

伪元素 ::before/::after 的核心是 **content**，它不只是文本，还能取属性、加载图片、计序号。

- **文本**：content: "内容"。
- **空串**：content: ""，配合宽高/背景画图形、做装饰层（**必须写**，否则伪元素不生成）。
- **attr(属性)**：读取元素某 HTML 属性值作为内容（如提示文字、tooltip）。
- **url()**：放图片/图标。
- **counter()**：用计数器的值（见下节）。

```css
a[data-tip]:hover::after {
  content: attr(data-tip);      /* 把 data-tip 属性当提示文字显示 */
  position: absolute; ...
}
.close::before { content: "\2715"; }  /* 用转义码位放 × 符号 */
```

> content 让伪元素能"凭空生成内容"。做**tooltip**（读 data- 属性）、**图标**（写码位）、**分隔线/箭头/遮罩层**（空串 + 定位）都靠它。记住：要给伪元素设宽高/背景/定位，务必先写 content: ""，否则不生成、样式全无效。



#### CSS 计数器 counter

**计数器（counter）**：由 CSS 维护的**自动编号**，常用于"自定义有序列表序号"（配合 content: counter()）与章节/图表自动编号。

```css
ol { list-style: none; counter-reset: step; }   /* 初始化计数器 step=0 */
ol li { counter-increment: step; }               /* 每个 li 使 step +1 */
ol li::before {
  content: counter(step) ".";                    /* 显示序号 */
  font-weight: bold; color: #f60;
}
```

- **counter-reset: 名称 [初值]**：重置计数器（默认从 0 开始）。
- **counter-increment: 名称**：每命中一次 +1。
- **counter(name) / counter(name, style)**：读取计数值，可用 decimal/lower-roman 等格式。
- **嵌套列表**：子列表可再开新的计数器实现"1、1.1、1.2"层级。

> 计数器让 CSS 自己维护序号，删除中间项序号自动重排，比手写数字更稳。做"自定义样式的有序列表、图表题注自动编号、分节标题编号"都可用它。注意 reset 放容器、increment 放子项、读取放伪元素，三者配合才能正确计数。



### 组合与边界场景

#### 逻辑伪类的优先级与写法

:not()、:is()、:where()、:has() 的组合是"精确选元素"的利器，但其**优先级规则**是易错点（与选择器章呼应）。

- **:is()**：接受列表（逗号分隔），命中其中任一即选中；**优先级取参数里最高者**。
- **:where()**：同 :is()，但**优先级恒为 0**，便于写"随时可被覆盖"的默认值。
- **:not()**：排除列表中任一命中项；**优先级由参数中最高者整体替换**（伪类本身不再额外计一次类），同 :is()。
- **:has()**：按"是否含某后代/后兄弟"反选祖先，优先级同括号内最高。

```css
:where(header, footer) a { color: inherit; } /* 0 优先级，易被业务覆盖 */
.card:not(.disabled) { cursor: pointer; }
.section:has(> h2) { padding-top: 0; }
article :is(h1, h2, h3) { line-height: 1.3; }
```

> 四个逻辑伪类优先级口诀：**:is / :not / :has 都取参数中最高者（与 :is() 同规则）、:where 恒为 0**。用 :where 写低优先级的"垫底默认"，用 :is 压缩重复前缀，用 :not 做排除，用 :has 做"依赖子内容的父级样式"。用前务必查浏览器支持（:has 支持较新）。



#### 伪类的浏览器支持

伪类家族不断扩展，但**部分较新的选择器存在兼容性门槛**，生产前应核实。

- **广支持（放心用）**：:hover/:active/:focus、:checked、:first-child/:nth-child()、:not()、:is()、:focus-visible、:focus-within。
- **较新（查 Can I Use）**：:has()、:where() 相对更早但支持已广；:nth-child(An+B of S) 语法、:user-invalid 等仍受限。

```css
/* 对 :has 提供渐进增强式写法：不支持的浏览器忽略该规则 */
@supports selector(:has(> img)) {
  .card:has(> img) { padding: 0; }
}
```

> [!IMPORTANT]
> **重要内容**：伪类兼容性铁律：**结构类与状态类可大胆用**；**逻辑增强类（尤其 :has）先查 caniuse**。面向多浏览器时可用 @supports selector(...) 包裹"较新选择器"的规则做渐进增强——不支持就跳过，不影响基础布局。别在必须兼容旧内核的场景依赖 :has 做核心逻辑。
