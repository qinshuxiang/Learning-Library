## 算法设计与复杂度分析

> **全章主脉**：本章是算法设计的方法论（部分超出 408 大纲、属延伸），介绍**分治、贪心、动态规划、回溯**四大算法设计思想，以及**摊还分析与递归复杂度**的分析技巧，最后给**典型问题与数据结构选择**的对照。核心是能识别"某问题该用哪种算法思想"并作复杂度分析。

### 算法设计的基本方法

#### 分治法

**分治法**把一个大问题**分解成若干规模更小、相互独立且与原问题同构的子问题**，分别求解后**合并**子问题的解得到原问题解。典型前提是子问题可独立求解、解可合并。

**分治的步骤**：分解 → 递归求解子问题 → 合并。

**分治典型**：**归并排序**（分两半各自排、再合并）、**快速排序**（划分+递归）、折半查找、大整数乘法、Strassen 矩阵乘等。

**复杂度**：若把规模 n 分成 a 个子问题、每子问题规模 n/b、分解合并代价 O(f(n))，则递推 T(n) = aT(n/b) + O(f(n))，可用主定理解之。

> [!NOTE]
> 提醒内容：分治"**分、治、合**"，子问题相互独立且同构，解需可合并。识别分治：问题可分、子解可合成原解。归并/快排/二分都是分治。若子问题**重叠**而非独立，就应改用**动态规划**而非纯分治。

#### 贪心法

**贪心法**在每一步**都做出当前看起来最优（局部最优）的选择**，期望局部最优能累积成**全局最优**。贪心**不回溯**，一旦选择不再改变，故只有**满足贪心选择性质与最优子结构**的问题才保证得到全局最优。

**贪心典型**：**哈夫曼编码**（每次取最小的两段）、**Prim/Kruskal 最小生成树**（每次选代价最小且安全的边/点）、**Dijkstra 单源最短路**（每次确定距离最小的顶点）、活动选择、找零（特定币值）等。

> [!NOTE]
> 提醒内容：贪心"**每步取当下最优、不回头**"。用贪心前要判断问题是否有**贪心选择性质**（局部最优能推出全局最优）——满足才可用（如 MST、Dijkstra、哈夫曼），否则贪心会出错。识别"贪心 vs 动态规划"：贪心每步定死、不可反悔；DP 会保存子问题最优并在所有选择里取最优。

#### 动态规划

**动态规划（DP）**用于**最优子结构 + 重叠子问题**的问题：把问题分解为子问题，**自底向上（或带记忆化自顶向下）求解**，保存每个子问题的解，**避免重复计算**，由子问题最优解递推得到原问题最优解。

**DP 要素**：**最优子结构**（原问题最优解含子问题最优解）、**重叠子问题**（子问题被反复求解，靠记忆化/表格避免重复）、**状态定义与状态转移方程**。

**DP 典型**：**最长公共子序列、0-1 背包、矩阵连乘、最短路径的 Floyd、编辑距离、爬楼梯/斐波那契（记忆化）**等。

> [!IMPORTANT]
> 重要内容：**分治子问题独立、DP 子问题重叠**是核心区别——DP 用"**保存子解避免重算**"（查表/备忘录）换取效率。写 DP 先**定义状态**，再写**转移方程**，再定**边界**。识别 DP：能拆成重叠子问题且最优子结构成立（如背包、LCS）。Floyd 最短路、斐波那契都可视为 DP。

#### 回溯法

**回溯法**用于**在解空间中搜索可行/最优解**，通过**深度优先地尝试每种选择（构造候选解），发现当前路径不可能得到解（约束不满足）时"回溯"到上一步换其它选择**，直到找到解或穷尽。本质是**带剪枝的深度优先搜索**。

**回溯要点**：搜索树/解空间树、约束条件剪枝（不可能分支及早放弃）、尝试—递归—撤销（恢复现场）。

**回溯典型**：**n 皇后、图的着色、子集/排列/组合生成、数独、0-1 背包的穷举分支、哈密顿回路**等。

> [!WARNING]
> 警告内容：回溯"**试错 + 撤销**"，当候选不满足约束立刻剪枝回溯，避免盲目穷举。与 DFS 关系：回溯是有**约束剪枝**的 DFS。与 DP 区别：回溯是搜索所有（剪枝后的）解，DP 是递推求最值；NP 问题常需回溯/剪枝。写回溯模板：**选择→递归→撤销（restore）**。

### 算法复杂度分析进阶

#### 摊还分析

**摊还分析**用于分析**一系列操作的平均代价**，即使个别操作代价很高，但把高代价"摊还"到一系列低成本操作上，可得**摊还（平摊）复杂度**，比单纯看最坏更贴合实际。

**摊还分析的方法**：聚合分析（总代价除以操作数）、记账/核算法（把势能记到操作上）、势能法（定义势能函数衡量"能量储备"）。

**摊还典型**：

- **动态数组（向量）扩容**：偶尔 O(n) 扩容，摊还到每次插入为 O(1)。
- **二叉堆/并查集操作**、**栈的 multipop**：总代价可控，摊还均摊低。

> [!NOTE]
> 提醒内容：**摊还分析不是平均复杂度，而是"这一系列操作整体的均摊代价"**——它保证任何操作序列的总时间上界。经典例子：动态数组"加倍扩容"时单次插入最坏 O(n)，但连续 n 次插入摊还 O(1)。理解"偶发高代价被均摊"，做题常考动态数组/栈的多重操作摊还。

#### 递归算法的时间分析

**递归算法的时间分析**通过建立并求解**递推关系**（递推方程）得到复杂度。

**主定理（Master Theorem）**：对 T(n) = aT(n/b) + O(f(n))（a 个子问题、规模 n/b、分解合并且 O(f(n))），比较 n 的 (log 以 b 为底 a) 次方 与 f(n)：

- 若 f(n) 小于 n^(log_b a)（多项式意义）：T(n) = O(n^(log_b a))。
- 若二者同阶：T(n) = O(f(n) log n)。
- 若 f(n) 大于且满足正则条件：T(n) = O(f(n))。

**常见递推**：二分归并 T(n)=2T(n/2)+O(n) → O(n log n)；二分查找 T(n)=T(n/2)+O(1) → O(log n)；两个递归各半再线性合并同归并。

> [!NOTE]
> 提醒内容：递归复杂度用**递推方程**求——小规模可直接展开（递归树），大规模用**主定理**。记：**T(n)=2T(n/2)+O(n)→O(n log n)**（归并）、**T(n)=T(n/2)+O(1)→O(log n)**（二分）、**T(n)=2T(n/2)+O(1)→O(n)**（二叉树遍历）。n 每层一分为几、每层代价多少，递归树法最直观。

### 典型问题与数据结构选择

**典型问题与数据结构选择**帮助在解决问题时选对结构——核心思想是"**看问题需要支持哪些核心操作，选能在这些操作上高效的存储结构**"。

- **需要后进先出**（括号、递归转非递归、DFS、撤销）→ **栈**。
- **需要先进先出/按序**（BFS、层序、排队、缓冲）→ **队列**。
- **频繁按键精确查找、插入删除** → **散列表**（哈希）。
- **有序数据需范围/顺序查询、频繁增删** → **平衡树/二叉查找树**（B+ 树做索引）。
- **需要快速取最值 + 动态插入** → **堆（优先队列）**。
- **元素间存在前驱/后继线性关系** → 顺序表/链表（看随机访问 vs 增删）。
- **多对多关系、路径/连通/最短路/拓扑** → **图**（邻接矩阵/邻接表）。
- **一对多层次关系、排序、查找** → 树（二叉树、B 树等）。

> [!TIP]
> 建议内容：选数据结构口诀——"**后进先出找栈、先进先出找队、按键快查找哈希、范围有序找树、动态取最值找堆、线性看存取、关系看树图**"。遇到综合应用题，先列出该问题的**核心操作**（增删改查/取最值/顺序访问），再反向匹配能高效支撑这些操作的结构。
