## 数据结构绪论

> **全章主脉**：数据结构研究"**数据如何组织、如何存储、其上有哪些操作**"。本章是总纲——先给出数据结构的定义与三要素（逻辑结构、存储结构、数据的运算），再讲抽象数据类型与算法概念，最后重点掌握**时间/空间复杂度分析（大 O）**，它是贯穿后续所有章节的度量工具。

### 什么是数据结构

**数据结构**是**相互之间存在一种或多种特定关系的数据元素的集合**，以及**在该集合上的运算及其实现**。它研究的是数据元素之间"是什么关系、怎么存、怎么操作"，是设计高效算法的基石。

**数据结构包含三个层面**：**逻辑结构**（数据元素之间的逻辑关系）、**存储结构**（逻辑结构在计算机中的表示）、**数据的运算**（定义在逻辑结构上的操作）。算法设计的核心，就是在选定逻辑与存储结构后高效实现这些运算。

> [!NOTE]
> 提醒内容：理解数据结构要区分"**逻辑上有什么关系**"与"**物理上怎么存**"两个层面——同一逻辑结构（如线性表）可对应多种存储结构（顺序表/链表），逻辑结构决定能做什么操作，存储结构影响操作效率。

### 数据结构的基本概念与术语

**数据**是信息的载体、描述客观事物的符号集合；**数据元素**是数据的基本单位（一个元素往往就是一个完整对象，如一名学生）；**数据项**是构成数据元素的不可再分的最小单位（如学号、姓名）；**数据对象**是具有相同性质的数据元素的集合。学习数据结构需先厘清这些粒度概念。

- **数据**：可被计算机识别、处理的符号集合。
- **数据元素**：数据的基本单位，一个元素可含多个数据项。
- **数据项**：构成数据元素的、不可再分割的最小单位。
- **数据对象**：性质相同的数据元素的集合，是数据的一个子集。

#### 逻辑结构

**逻辑结构**指**数据元素之间的逻辑关系**，与存储无关，是数据结构的抽象视图。逻辑结构分为**线性结构**与**非线性结构**两大类。

- **线性结构**：数据元素之间是**一对一的线性关系**，除首尾外每个元素有唯一直接前驱与直接后继，如线性表、栈、队列、串。
- **非线性结构**：元素之间存在一对多或多对多关系，如**树**（一对多）、**图**（多对多）。

> [!NOTE]
> 提醒内容：逻辑结构是从"关系"角度分类——**一对一（线性）、一对多（树形）、多对多（图形）**。集合也是一种逻辑结构（元素间无特定关系）。判断某数据对象属于哪种逻辑结构，看元素之间是哪种关系。

#### 存储结构

**存储结构（物理结构）**指**逻辑结构在计算机存储器中的表示（映像）**，即数据元素及其关系如何存放。常用的存储结构有**顺序存储、链式存储、索引存储与散列存储**四种。

- **顺序存储**：把逻辑上相邻的元素**存放在物理地址相邻**的存储单元，元素关系由存储位置的自然相邻体现。随机存取快，但插入删除需移动元素、可能需预留空间。
- **链式存储**：用指针**把逻辑上相邻但物理上可能不相邻**的元素串起来。插入删除灵活、不必连续空间，但不能随机存取、需额外指针空间。
- **索引存储**：建立**索引表**，索引项指向存储元素的位置，可加快查找，但索引表占用额外空间。
- **散列存储**：根据元素的关键字**直接计算出存储地址（散列函数）**，查找快，但要处理冲突。

> [!IMPORTANT]
> 重要内容：**顺序存储"逻辑相邻→物理相邻"（随机存取、移动开销大）；链式存储"逻辑相邻物理可不相邻"（靠指针、不能随机、插入删除快）**。判断用哪种，看操作特点：频繁按位置访问用顺序、频繁插入删除用链式。索引与散列是两种加速查找的存储手段。

#### 数据的运算

**数据的运算**定义在**数据的逻辑结构**之上，指对数据元素执行的操作，是数据结构服务于应用的体现。运算分为**定义在逻辑结构上的抽象操作**与**在存储结构上的具体实现**两层。

常见的数据运算有**插入、删除、查找、修改、排序、遍历**等。对同一逻辑结构，其"能做什么运算"由逻辑结构决定，而"每个运算的效率"由存储结构决定——例如在线性表中"删除中间元素"，顺序表需移动元素、链表只需改指针。

> [!NOTE]
> 提醒内容：运算的定义（抽象、写在逻辑结构上）与实现（具体、依赖存储结构）分离——逻辑结构定了操作的"语义"，存储结构定了操作的"代价"。理解这一点是分析算法复杂度的基础。

### 抽象数据类型

**抽象数据类型（ADT）**指**一个数学模型以及定义在该模型上的一组操作**，它把"数据的逻辑结构 + 数据运算"封装在一起，对外只暴露操作接口、隐藏内部存储与实现细节。如栈的 ADT 只定义入栈、出栈、判空等操作，不关心底层是数组还是链表。

**ADT 的三要素**：**数据对象、数据关系与基本操作**。ADT 的实现可用不同存储结构（顺序/链式），但对外接口不变，这正是"抽象"与"信息隐藏"的意义——使用者只需知道"能做什么"，不必关心"怎么做"。

> [!TIP]
> 建议内容：ADT 的价值是**接口与实现分离**——换一种存储结构实现同一个 ADT，调用方的代码不用改。栈、队列、串、二叉树等都常以 ADT 形式定义。理解"栈是 ADT、顺序栈/链栈是实现"即抓住本质。

### 算法与算法的基本特征

**算法**是**对特定问题求解步骤的一种描述，是指令的有限序列**。程序是算法用某种程序设计语言的具体实现；算法强调的是"解决步骤"。算法必须满足**有穷性、确定性、可行性、输入与输出**五个基本特征。

- **有穷性**：算法必须在**有限步骤**内结束，不能无限循环。
- **确定性**：算法的每一步都**有明确含义、无歧义**，相同输入必得相同输出。
- **可行性**：算法中的每条操作**都能通过已实现的基本运算执行有限次**来完成。
- **输入**：算法有**零个或多个输入**。
- **输出**：算法**至少有一个输出**（结果）。

> [!WARNING]
> 警告内容：**算法 ≠ 程序**——算法必须有穷（有限步结束），而程序可以无限循环（如操作系统、后台服务常驻运行）。判断"是否算法"，先看是否满足有穷性。算法还须**正确、健壮、可读、高效**，其中高效即复杂度低。

### 算法的时间复杂度分析

#### 大 O 记号

**时间复杂度**描述**算法执行时间随问题规模 n 增长而变化的量级**。为避免依赖具体机器与常数，采用**大 O 记号**表示渐进上界：若存在正常数 c 与 n0，使问题规模 n 大于 n0 时算法的执行步数 T(n) 不大于 c 乘 f(n)，则记 T(n) 等于 O(f(n))，表示算法时间不超过 f(n) 这个量级。

**求时间复杂度的要点**：

- 基本操作是算法中**执行次数最多的那条语句**，其执行次数与问题规模 n 的关系即复杂度。
- 大 O 只关心**最高次项与量级**，忽略常数与低次项：如 3n 加 5 记 O(n)，n 方加 n 记 O(n 方)。
- 由循环嵌套与循环次数判断：单循环 O(n)、双重循环 O(n 方)、每次规模减半 O(log n)、二分递归等。
- **最坏、平均、最好**情况：通常分析**最坏**时间复杂度（保证上界），也关注平均。

> [!NOTE]
> 提醒内容：大 O 求法口诀——"**数基本操作执行次数，取最高次项去常数**"。遇到循环看循环变量怎么变：i 每次加 1 则 O(n)、i 每次乘 2 则 O(log n)、双层循环则相乘。递归的时间复杂度常用**递推式**（如主定理）求解，后续算法设计章详述。

#### 常见复杂度的增长比较

**常见时间复杂度**按增长快慢（从慢到快）大致为：**O(1) 小于 O(log n) 小于 O(n) 小于 O(n log n) 小于 O(n 方) 小于 O(n 三次方) 小于 O(2 的 n 次方) 小于 O(n!)**。

- **O(1)**：常数时间，与规模无关（如数组按下标访问）。
- **O(log n)**：对数时间，规模每步减半（折半查找、平衡树查找）。
- **O(n)**：线性时间，单层顺序扫描。
- **O(n log n)**：线性对数，高效排序（快排、归并平均）。
- **O(n 方)/O(n 三次方)**：多项式，双重/三重循环（简单排序、部分图算法）。
- **O(2 的 n 次方)/O(n!)**：指数/阶乘，增长极快，规模稍大即不可行（常对应暴力穷举）。

> [!IMPORTANT]
> 重要内容：**复杂度排序是常考点**——log n 小于 n 小于 n log n 小于 n 方；2 的 n 次方与 n! 增长极快、几乎不可用。给定不同 n 求各算法的实际执行量，或反推某复杂度可承受的 n 上限，是常见题型。**数据规模增大时，低阶算法的优势会远超常数差异**（如 n log n 的排序远快于 n 方的冒泡）。

### 算法的空间复杂度分析

**空间复杂度**描述**算法运行所需的辅助存储空间随问题规模 n 变化的量级**，也用大 O 表示。它通常指算法执行过程中额外开辟的空间（不统计输入数据本身占用的空间）。

**空间复杂度要点**：

- 若算法所需辅助空间为常数（如若干临时变量），则空间复杂度为 **O(1)**（原地工作）。
- 若需随规模增长开辟数组、递归栈等，则空间复杂度随 n 增长，如归并排序 O(n)、递归的深度 O(n)。
- **原地排序**指空间复杂度为 O(1) 的排序（如插入、选择、冒泡、堆排序）。

> [!TIP]
> 建议内容：分析空间复杂度看"**额外开了多大空间**"——常数量 O(1)、随 n 线性 O(n) 最常见。递归算法隐含**递归调用栈**的空间，深度为 n 则空间 O(n)。比较算法时空取舍（如基数排序时间优但空间大、归并稳定但要 O(n) 空间）是综合题的常见角度。
