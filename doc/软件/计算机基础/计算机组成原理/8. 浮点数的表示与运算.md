## 浮点数的表示与运算

> **全章主脉**：定点数范围太小，无法表示科学计算中极大极小的数。浮点数仿照科学记数法，把数写成 尾数 × 基数 的 阶码 次方，用阶码撑开动态范围、尾数保精度。本章先讲浮点的阶码尾数结构与规格化，重点讲 **IEEE 754**（单精度 float 与双精度 double 的标准），再讲浮点加减的对阶、尾数运算、规格化与舍入溢出。
>
> **一句话记 IEEE 754**：单精度 32 位 = 1 位符号 + 8 位阶码（偏置 127）+ 23 位尾数，规格化尾数隐藏最高位 1；阶码用移码（真值加偏置）存储，便于比较大小。

### 浮点数的表示

#### 阶码与尾数

**浮点数**用尾数表示有效数字、用阶码表示小数点的位置，使同一数值可按不同比例伸缩，从而扩大可表示的动态范围。

一个浮点数一般表示为：N = 尾数 × R 的 阶码 次方，其中 R 为基数（常取 2）。

机器中浮点数分为两个字段（连同符号位）：

- **阶码**：定点整数，用移码（或补码）表示，决定小数点的实际位置（数的量级）。
- **尾数**：定点小数，用原码或补码表示，决定数的有效精度（数的数值）。
- **数符**：整个数的正负号，通常放在尾数符号位。

**范围与精度**：阶码位数决定浮点数的范围（能表示多大/多小），尾数位数决定浮点数的精度（能区分多细的差异）。阶码位多则范围大，尾数位多则精度高。

> [!NOTE]
> 提醒内容：浮点数表示范围远大于同字长定点数，但代价是精度有限、并非每个整数都能精确表示。阶码管"量级范围"、尾数管"有效精度"，这是理解浮点"大范围低精度"的钥匙。



#### 规格化

**规格化**指把尾数调整到约定范围，使浮点表示唯一、充分利用尾数位、并便于比较与运算。

对基数为 2 的浮点，规格化尾数满足绝对值介于 2 的负一次方 与 1 之间：

- 尾数最高位（数值部分首位）必须为 1。
- 原码规格化：尾数正数首位为 1、负数（绝对值）首位亦为 1。
- 补码规格化：尾数用补码表示时，数值部分最高位与符号位相反——正数首位为 1、负数首位为 0。

**为什么要规格化**：不规格化会使同一值有多种表示（如 0.5 可写成 0.5×2 的 0 次方，也可 0.25×2 的 1 次方），浪费尾数位；规格化后表示唯一、尾数精度最高。

> [!TIP]
> 建议内容：规格化判断速记——**原码看尾数数值首位是否 1**；**补码看尾数符号位与数值首位是否相反**。运算结果若不在规格化范围，需左规（尾数左移、阶码减 1）或右规（尾数右移、阶码加 1）还原。



#### IEEE 754 标准

**IEEE 754** 是最通用的浮点数标准，规定单精度与双精度的位布局、偏移阶码与规格化规则，现代计算机几乎都遵循它。

**单精度（float）**共 32 位，自高到低为：数符 1 位 + 阶码 8 位 + 尾数 23 位。

**双精度（double）**共 64 位：数符 1 位 + 阶码 11 位 + 尾数 52 位。

**关键约定**：

- **阶码用移码（偏置）表示**：单精度阶码偏置 127，实际阶码 = 存储阶码 − 127；双精度偏置 1023。用移码便于浮点大小比较。
- **规格化尾数隐藏最高位 1**：因为规格化尾数最高位必为 1，故不存储该位，尾数 23 位实际表达 24 位精度，称"隐藏位"或"隐含位"。
- **指数 0 与全 1 特殊**：阶码为 0 表示非规格化数或 0；阶码全 1 表示无穷或 NaN（非数）。

**表示示例**：把十进制 1.5 存成单精度——符号 0，阶码为 0（因 1.5 = 1.1 的 2 进制 × 2 的 0 次方）加偏置 127 得 127，尾数隐藏首位 1 后存 0.1 即二进制小数部分。

> [!WARNING]
> 警告内容：IEEE 754 的几个易错点——(1) 阶码存的是**真值加偏置**的移码，不是补码，也不直接等于实际指数；(2) 尾数**隐藏最高位 1**，读取时要把它补回；(3) 单精度阶码 8 位、偏置 127，双精度阶码 11 位、偏置 1023，勿混淆。换算时把 (符号、阶码、尾数) 三段严格拆开处理。



### 浮点数的加减运算

#### 对阶、尾数运算与规格化

**浮点加减**不能直接对尾数做加减，因为两数阶码（小数点位置）不同，须先对阶使小数点对齐。完整流程分五步：

- **对阶**：把两数阶码对齐为较大的一个。阶码小的数，尾数右移（每右移一位阶码加 1），使两数阶码相等。原则是"小阶向大阶看齐"。
- **尾数求和（差）**：对阶后两尾数同为定点小数，直接做加减（补码或原码）。
- **规格化**：结果若不符合规格化条件，进行左规或右规——尾数左移溢出到符号则右规（阶码加 1），最高位不合则左规（阶码减 1）。
- **舍入**：对阶与右规移出的低位按舍入规则处理（见下节）。
- **判溢出**：检查阶码是否超出范围。

> [!IMPORTANT]
> 重要内容：浮点加减的流程口诀——**对阶（小阶向大阶）→ 尾数求和 → 规格化 → 舍入 → 判溢出**。对阶时阶码小的尾数右移会丢低位（产生舍入），故尾数需保留附加位。阶码溢出（阶码超出表示范围）才是真正的浮点溢出，尾数溢出可由右规解决。



#### 舍入与溢出处理

**舍入**处理对阶或规格化右移时移出的低位，常见的舍入方法有：

- **截断（直接舍去）**：简单丢弃低位，有误差但硬件最简。
- **恒置 1（末位恒置 1）**：把结果最低位恒置为 1，避免全 0 陷阱但引入偏差。
- **0 舍 1 入**：移出的最高位为 1 则末位加 1、为 0 则舍去，最常用，等价"四舍五入"。
- **就近舍入（舍入到偶数）**：IEEE 754 默认，距两个可表示值一样近时选末位为偶数的那个，减少统计偏差。

**浮点溢出的处理**：

- **阶码上溢**：结果阶码超过最大阶，为正/负无穷大，产生溢出，由异常处理。
- **阶码下溢**：结果阶码小于最小阶，结果趋于 0，可按非规格化或置 0 处理（一般不视为致命错误）。
- 尾数溢出可通过对阶后的右规消化，不一定判为溢出。

> [!NOTE]
> 提醒内容：浮点"溢出"看的是**阶码**是否越界，而非尾数。尾数右规产生溢出可通过"尾数右移 + 阶码加 1"消化，真正的致命是阶码上/下溢。IEEE 754 通过无穷、非规格化数、NaN 等特殊编码表达阶码越界情形，命题常考区分"尾数溢出（可救）"与"阶码溢出（真溢出）"。



### 浮点数的乘除运算

**浮点乘除**比加减简单，因为阶码与尾数分别处理、不需要对阶。

**浮点乘法的步骤**：

- 阶码相加（两数阶码之和为新阶码）。
- 尾数相乘（无符号/原码尾数相乘得积尾数）。
- 规格化、舍入，并判断阶码溢出。

**浮点除法的步骤**：

- 阶码相减（被除数阶码减去除数阶码为新阶码）。
- 尾数相除得商尾数。
- 规格化、舍入，判断阶码溢出；除数尾数为 0 则结果非法。

> [!NOTE]
> 提醒内容：浮点乘除的阶码相加/相减要用移码做，需注意移码加减要减去一个偏置或作相应修正；尾数乘除后可能破坏规格化，须再左规/右规一次。把握"乘除时阶码独立做加减、尾数独立做乘除，最后统一规格化舍入判溢出"的主线即可。
