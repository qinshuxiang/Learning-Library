## CPU 的结构与功能

> **全章主脉**：CPU 是计算机的"大脑"，由**运算器 + 控制器**构成。本章先看 CPU 的功能与总体结构、它有哪些寄存器，再看**数据通路**——寄存器、ALU、总线之间如何连接、数据怎么在这些部件间流动来完成一条指令。数据通路是组成原理从"懂部件"走向"懂整机如何取指执行"的桥梁。
>
> **一句话记 CPU**：CPU 的功能 = 取指 + 译码 + 执行 + 中断；结构 = 运算器（ALU + 寄存器）+ 控制器（PC、IR、时序）；数据通路就是"寄存器间靠内部总线传数、经 ALU 运算、由控制器发控制信号调度"。

### CPU 的功能与基本结构

#### 运算器与控制器的功能

**CPU（中央处理器）**由运算器与控制器两大部分组成，是计算机执行指令、完成信息加工的核心。

**运算器的功能**是执行算术与逻辑运算：

- **算术运算**：加、减、乘、除、加 1、求补等。
- **逻辑运算**：与、或、非、异或、移位、比较等。
- **暂存与传送**：寄存器暂存操作数与中间结果，经数据通路在部件间传送。

**控制器的功能**是指挥各部件协调一致地完成指令：

- **取指**：从主存取出指令。
- **译码**：分析指令确定要做的操作与寻址。
- **执行**：发出控制信号指挥运算器、存储器等完成操作。
- **控制时序**：按统一时钟安排各部件动作顺序。
- **处理中断**：响应异常与外部中断请求。

> [!NOTE]
> 提醒内容：运算器"会算"，控制器"会指挥"。控制器的核心任务是产生一系列有序的控制信号，让取指、译码、执行按正确时序推进——这正是后文"指令周期"与"控制单元设计"要展开的内容。



#### CPU 的寄存器组

**CPU 的寄存器**分为对程序员可见（可编程）与内部专用两类，是 CPU 结构中重要的数据栖身之所。

对程序员（或指令）可见的寄存器：

- **通用寄存器**：存放操作数与中间结果，供指令直接访问，是 RISC 大量使用的寄存器。
- **程序计数器（PC）**：存放下一条要执行的指令地址，指令顺序执行靠 PC 自增、转移靠修改 PC。
- **累加器（ACC）**：常用于暂存运算的操作数或结果（在采用累加器的机器中）。
- **程序状态字（PSW）**：保存运算结果的状态标志（零、进位、符号、溢出）与中断等状态。

CPU 内部专用寄存器（一般对程序员不可见，由控制逻辑使用）：

- **指令寄存器（IR）**：暂存刚从主存取出的指令，供译码使用。
- **存储器地址寄存器（MAR）**：存放本次访存的内存地址。
- **存储器数据寄存器（MDR）**：暂存读入或待写出的数据。
- **暂存器**：ALU 运算时暂存操作数与中间结果。

> [!IMPORTANT]
> 重要内容：分清两类寄存器——**程序员可见**的（通用寄存器、PC、PSW）会出现在指令与程序中；**内部控制用**的（IR、MAR、MDR、暂存器）对程序透明，CPU 取指执行时自动使用。PC 存"指令地址"、IR 存"刚取的指令"、MAR 存"访存地址"、MDR 存"读写的数据"，这四者构成取指与访存的最小工作集。



### CPU 的组成

#### 数据通路

**数据通路**指数据在 CPU 内部各功能部件（寄存器、ALU、总线、存储器接口）之间流动与运算所经过的路径及连接关系，是描述 CPU 内部结构的方式。

**数据通路要解决的问题**：

- 部件之间如何连接（专用数据通路或共享总线）。
- 数据如何从源寄存器经 ALU 运算后送到目的寄存器。
- 指令取指、访存时数据如何与主存交换。

**描述数据通路的角度**：

- **结构**：各部件与连接线（总线的位宽、开关）构成的网络。
- **控制**：由控制单元按指令发出"开/关"信号，决定哪条通路在何时有效。

**数据通路中的关键元素**：

- 三态缓冲器/多路选择器：决定某时刻哪个部件占用总线、数据流向。
- 控制信号：每一条"让某寄存器把数据送总线"或"总线数据写入某寄存器"的动作，都由控制信号触发。

> [!NOTE]
> 提醒内容：数据通路回答"数据怎么走"，是 CPU 的"骨架与血管"；控制单元回答"什么时候让数据走、走哪条"，是 CPU 的"调度中枢"。研究数据通路有助于理解单周期、多周期与流水线 CPU 如何组织寄存器传输。



#### 内部总线与片内总线

**内部总线**指 CPU 内部用于连接各寄存器、ALU 等部件的共享传输线，是数据通路的一种常见实现。

内部总线的特点与要点：

- **单总线结构**：CPU 内部只设一组共享总线，所有部件都挂在这条内部总线上，某一时刻只能有一个部件向总线送数。
- **结构简单**：单总线连线少、实现容易，是多数教学型 CPU 采用的结构。
- **性能受限**：所有数据交换都挤在同一条内部总线上，同一时刻只支持一对部件通信，可能形成瓶颈，故高性能 CPU 采用多总线或多端口结构。

**片内总线与外部总线的区分**：片内总线在 CPU 芯片内部、速度极快、线短；CPU 与主存、IO 通信经芯片外的系统总线，速度受引脚与外部连线限制。

> [!WARNING]
> 警告内容：CPU 内部用"内部总线"，CPU 与主存/IO 之间用"系统总线（外部总线）"，两者不同。内部单总线的"分时共享"属性意味着任何时刻只能有一个数据源占用总线，设计数据通路时要保证不会出现两个部件同时驱动同一内部总线（需三态门隔离）。



### 数据通路的功能

#### 寄存器之间的数据传送

**寄存器之间传送**指把某寄存器内容经内部总线送到另一寄存器，是实现指令操作的基础动作。

一次寄存器传送的大致过程：

- 控制单元发出控制信号，使源寄存器把内容放到内部总线上。
- 再发控制信号，使目的寄存器在时钟边沿把总线内容锁存进去。
- 源与目的可以是不同寄存器，也可涉及 PC 与 IR、MAR、MDR 等（如取指时把 PC 内容送 MAR）。

**示例：取指阶段的部分数据流**

- PC 内容送 MAR，把指令地址交到主存。
- 主存读出指令经 MDR，再送 IR 暂存供译码。

> [!NOTE]
> 提醒内容：寄存器传送依赖"三态门放数 + 时钟锁存"，且总线同一时刻只能有一个源。一条指令的完成可分解为若干这样的寄存器传输步骤，每条传输由一条控制信号触发——这是微操作与控制信号分析的入手点。



#### ALU 运算的实现

**ALU 运算的实现**指把寄存器中的操作数送入 ALU、完成算术/逻辑运算并把结果写回目的寄存器。

一次 ALU 运算的数据流：

- 两个操作数分别经内部总线或专用通路送入 ALU 的两个输入端（常需暂存器缓冲，因为单总线上一个时刻只能上一个数）。
- 控制信号选 ALU 做何种运算（加、减、与、或等）。
- ALU 输出结果再送回内部总线，由时钟锁存到目的寄存器，并更新状态标志（进位、零、溢出等）。

**单总线结构的局限**：ALU 两个输入若都来自同一条内部总线，须先分两次把两个操作数分别打入两个暂存器，再做运算，故单总线结构实现"取两操作数相加"需多个时钟节拍。

> [!TIP]
> 建议内容：理解"ALU 运算要几个节拍"是数据通路常考题——单总线 CPU 里把 A 送暂存器、把 B 送另一暂存器、再做加法写回，往往要多步；多端口或多总线结构可并行取操作数、减少节拍。据给定的数据通路结构逐拍写出寄存器传输序列即可推演指令周期。
