## IP 协议与 IP 地址

### IP 地址概述

#### IP 地址的作用

**IP 地址**：是给连接在互联网上的每一台主机（或路由器）的每一个接口分配的、在全世界范围内唯一的 32 位标识符，网络层据此回答“分组该发给哪个网络、哪台主机”。

- **标识作用**：与 MAC 地址标识“网卡在链路内的身份”不同，IP 地址标识“主机接口在全球互联网中的位置”，带有可聚合的层次结构。
- **选路依据**：路由器只按目的 IP 中的**网络号**决定向哪个方向转发，无需逐主机记忆，转发效率由此而来。
- **分配规则**：一个 IP 地址唯一地标识某个接口，不严格标识一台设备——**一台主机若有多个接口（多网卡），就拥有多个 IP 地址**。

> [!WARNING]
> **警告内容**：**IP 是“逻辑、层次、可变”的地址，MAC 是“物理、扁平、基本不变”的地址**。前者随主机搬移网络而改变，后者随网卡出厂固定。两者通过 ARP 协议互相解析（详见《ARP、DHCP、ICMP 与 NAT》章）。

#### IP 地址的表示方法

IPv4 地址是 32 位二进制数，为便于读写，采用**点分十进制**表示：每 8 位（1 字节）一组，共 4 组，组间用点号分隔，每组换算为十进制数 0~255。

```text
11000000.10101000.00000001.00001010  （二进制，共 32 位）
192.168.1.10                         （点分十进制）
```

- 每组取值 0~255，不会出现 256 或负数。
- 除点分十进制外，历史上还有十六进制、八进制等写法，现代实际只用点分十进制。

> 考试换算技巧：只需熟记常见值，如 255（全 1）、128（10000000）、192（11000000）、224（11100000）、240（11110000）等；分类编址恰恰以首字节二进制前缀定类。

#### 网络号与主机号的两级结构

一个 IPv4 地址在逻辑上分为**网络号（网络 ID）**与**主机号（主机 ID）**两部分：**网络号标识主机所在的网络，主机号标识该网络内的具体接口**。

- 网络号相同的接口属于**同一网段**，彼此可直接通信；网络号不同的主机属于不同网络，通信必须经过路由器。
- 路由器转发时只比对目的 IP 的网络号，把数据报送到目的网络，再由目的网络内部交给对应主机号——这是 IP 地址层次化的核心价值。
- 因此互联网上**每个网络都必须有全网唯一的网络号**，否则分组无法被正确路由。

> 两级结构的类比：网络号像“城市 + 街道”，主机号像“门牌号”。邮局（路由器）只需把信件送到街道，最后一公里由街道内的投递员（链路层 + ARP）完成。

### IPv4 分类编址

#### 分类编址的基本思想

**分类编址（classful addressing）**：是最早的 IP 编址方案，把 32 位地址按**最高位（首字节的二进制前缀）**划分为 A、B、C、D、E 五类，每类固定网络号与主机号的位数。

**分类编址把五类地址的“前缀、首字节、网络号位数、主机号位数、默认掩码”固定如下**：

- **A 类**：首位为 0，网络号 8 位、主机号 24 位，默认掩码 255.0.0.0（/8）。
- **B 类**：前两位为 10，网络号 16 位、主机号 16 位，默认掩码 255.255.0.0（/16）。
- **C 类**：前三位为 110，网络号 24 位、主机号 8 位，默认掩码 255.255.255.0（/24）。
- **D 类**：前四位为 1110，用于组播，不作单播分配。
- **E 类**：前四位为 1111，保留给科研实验，不对外分配。

> **速记**：A 类“0 打头一大片”，B 类“10 开头算中段”，C 类“110 收尾小型网”，D 类“1110 组播用”，E 类“1111 留科研”。

**判断类别只看首字节落在哪个区间**：1~126 为 A、128~191 为 B、192~223 为 C、224~239 为 D、240~255 为 E。

> [!NOTE]
> **提醒内容**：127 不在 A 类可用范围内——它是环回地址段（见下文特殊地址）。**分类编址的“类”由最高位决定，与子网掩码无关**。

#### A 类地址

**A 类地址**：首字节以二进制 0 开头、取值 1~126，网络号占 8 位（其中首位固定为 0，实际参与编址 7 位），主机号占 24 位，默认子网掩码 255.0.0.0。

- 首字节 0 与 127 不用于分配：**0.0.0.0 表示本网络、本主机**，**127.x.x.x 为环回地址段**（详见下文特殊地址）。
- 可用网络数 = 2^7 − 2 = 126 个（减去 0 网段与 127 网段）。
- 每网主机数 = 2^24 − 2 = 16777214 个。
- 规模特点：网络个数最少、单个网络容量最大，分配给大型网络。

#### B 类地址

**B 类地址**：首字节以二进制 10 开头、取值 128~191，网络号占 16 位（前 2 位固定为 10），主机号占 16 位，默认子网掩码 255.255.0.0。

- 可用网络数 = 2^14 = 16384 个。
- 每网主机数 = 2^16 − 2 = 65534 个。
- 规模特点：分配给中等规模网络，如大学校园网常申请 B 类或从 B 类划出地址块。

#### C 类地址

**C 类地址**：首字节以二进制 110 开头、取值 192~223，网络号占 24 位（前 3 位固定为 110），主机号占 8 位，默认子网掩码 255.255.255.0。

- 可用网络数 = 2^21 = 2097152 个。
- 每网主机数 = 2^8 − 2 = 254 个。
- 规模特点：网络个数最多、单个网络容量最小，分配给小型局域网。

#### D 类与 E 类地址

**D 类地址**：首字节 224~239、前四位为 1110，是**组播（多播）地址**，标识“一组接收者”而非单台主机。

- 组播地址不分网络号、主机号，也不存在“默认子网掩码”的概念。
- 主机加入某组播组后，发送到该 D 类地址的数据会被组成员接收。

**E 类地址**：首字节 240~255、前四位为 1111，保留地址，用于科研实验，不分配给任何主机或网络。

> [!CAUTION]
> **注意内容**：任何主机都不能把 D 类、E 类地址配置为自己的 IP；D 类只能作为组播组标识出现在目的地址中。遇到“某主机 IP 为 224.x.x.x”的题设，直接判为非法配置。

#### 各类地址可容纳主机数

**一个网络内可分配给主机的地址数 = 2^主机号位数 − 2**：主机号全 0 的地址是**网络地址（本网络）**，主机号全 1 的地址是**广播地址**，两者都不能分配给主机。

- A 类每网：2^24 − 2。
- B 类每网：2^16 − 2 = 65534。
- C 类每网：2^8 − 2 = 254。

> 为什么减 2：以 C 类为例，192.168.1.0 表示“192.168.1 这个网络”，192.168.1.255 表示“发给 192.168.1 网所有主机的广播”，中间 1~254 才能配给主机。**“减 2”规则在子网划分后仍然成立**（《子网划分与 CIDR》章会反复用到）。

### 特殊 IP 地址

#### 主机号全 0 与全 1

**网络地址**：主机号部分全为 0 的 IP 地址，表示“本网络”整体，不能分配给主机，例如 192.168.1.0/24。

**广播地址**：主机号部分全为 1 的 IP 地址，表示“该网络内的所有主机”，作为目的地址时向本网络全体广播，例如 192.168.1.255/24。

- 广播分两种：**受限广播 255.255.255.255**（只能在本网内广播、不出路由器）与**定向广播（直接广播）**如 192.168.1.255（可被路由器转发到目标网络后再广播）。
- 路由器通常不转发广播，因此广播的作用范围被限制在本地链路或单个网络内。

#### 环回地址与零地址

- **127.0.0.1（环回地址）**：整个 127.0.0.0/8 都保留作环回测试，发往环回地址的数据报不离开主机，由协议栈直接送回本机，用于测试本机 TCP/IP 协议栈是否正常。
- **0.0.0.0**：表示“本网络上的本主机”，常见于主机启动但尚未取得 IP 时作为源地址，也用作默认路由的“通配地址”。
- **255.255.255.255**：受限广播地址，作为目的地址时向当前网络内所有主机广播。

> 易混辨析：**127.0.0.1 是“测试自己”，0.0.0.0 是“我自己还没地址”**。前者数据永不出现于网络线路上，后者常出现在 DHCP 的 Discover 报文的源地址中。

### 私有地址与 NAT 的引入

#### 私有地址

**私有地址（private address）**：IANA 在 A、B、C 类中各预留了一段永不向公网分配的地址块，供组织内部局域网自由使用，这些地址**不会出现在互联网上**（规范依据为 RFC 1918）。

- **A 类私有块**：10.0.0.0 ~ 10.255.255.255，相当于 1 个 A 类网络（10.0.0.0/8）。
- **B 类私有块**：172.16.0.0 ~ 172.31.255.255，共 16 个 B 类网络（172.16.0.0/12）。
- **C 类私有块**：192.168.0.0 ~ 192.168.255.255，共 256 个 C 类网络（192.168.0.0/16）。

> **速记**：私网地址只有三种开头——**10. 开头、172.16~172.31 之间、192.168 开头**。家庭路由器给手机、电脑分配的 192.168.x.x 就是私有地址；办公网常见 10.x.x.x 或 172.16~31 段。

#### NAT 的引入

**NAT（Network Address Translation，网络地址转换）**：是让内部网络使用私有地址、由出口设备把私有地址转换为公网 IP 的技术，用于解决 IPv4 地址枯竭问题并隐藏内网结构。

- 每个私有网络内部可自由规划私有地址，只需在连接互联网的边界设备（如家用路由器）上**共享一个或少数几个公网地址**。
- 内网主机访问外网时，NAT 设备改写数据报的源地址（及端口），回程报文再反向改回。
- 私有地址若不经 NAT 转换而直接发往公网，会被中间路由器丢弃，因为互联网上不存在指向这些地址的路由。

> NAT 的完整机制（转换表、NAPT、端口映射、利弊）详见《ARP、DHCP、ICMP 与 NAT》章。这里只记住结论：**私有地址是“内网通行证”，NAT 是“走出内网的桥”**。

### 子网掩码

#### 子网掩码的概念

**子网掩码（subnet mask）**：是一个 32 位的二进制数，**网络号部分全部置 1、主机号部分全部置 0**，用于从 IP 地址中“切”出网络号。

- 把 IP 地址与子网掩码逐位做逻辑“与”运算，结果即该 IP 的**网络地址**，剩余部分即主机号。
- 分类编址下各类有固定的**默认子网掩码**：A 类 255.0.0.0、B 类 255.255.0.0、C 类 255.255.255.0。
- 子网掩码不一定是默认值——管理员可把 1 向左延伸（借用主机位），掩码越长表示网络划分越细，详见《子网划分与 CIDR》章。

```text
IP 地址：   192.168.1.10    11000000.10101000.00000001.00001010
子网掩码：  255.255.255.0   11111111.11111111.11111111.00000000
按位与：    192.168.1.0     11000000.10101000.00000001.00000000  ← 网络地址
```

> 子网掩码的作用对象是“网络边界”，不是“网速”也不是“子网数”本身；考试遇到“某掩码能容纳多少主机”，关键看掩码末尾 0 的个数 n，主机数即 2^n − 2。

#### 用“与”运算判断是否同一网段

**判断两台主机能否直接通信的通用方法：把各自的 IP 与子网掩码做“与”运算得到网络地址，网络地址相同则在同一网段，不同则必须经路由器转发。**

```text
主机 1 IP：     222.21.160.6    11011110.00010101.10100000.00000110
子网掩码：      255.255.255.192 11111111.11111111.11111111.11000000
与运算结果：    222.21.160.0    11011110.00010101.10100000.00000000

主机 2 IP：     222.21.160.73   11011110.00010101.10100000.01001001
子网掩码：      255.255.255.192 11111111.11111111.11111111.11000000
与运算结果：    222.21.160.64   11011110.00010101.10100000.01000000
```

- 主机 1 的网络地址为 222.21.160.0，主机 2 的网络地址为 222.21.160.64，两者不同，**不在同一网段**，通信必须经过路由器。

> 计算技巧：掩码为 1 的位会保留 IP 原值，为 0 的位直接把 IP 对应位置 0，所以只需关注掩码**不是 255 的那个字节**。如上例掩码末字节是 192（11000000），只需看两 IP 末字节与 192 相与：6 与 192 得 0，73 与 192 得 64。

再看一个同网段的对照例：192.168.1.10 与 192.168.1.99 均配掩码 255.255.255.0，相与后同为 192.168.1.0，**处于同一网段，可直接通信**。

> 子网掩码完全可以是“非默认值”（如上例的 255.255.255.192），掩码由管理员规划决定；**“是否同一网络”永远以与运算的结果为准**。掩码中 1 的位数就是网络前缀，这种斜线记法及借位划分子网的细节在《子网划分与 CIDR》章展开。



### IPv4 数据报格式

IPv4 数据报由**首部**和**数据**两部分组成。首部长度 **20~60 字节**（基本首部 20 字节 + 可选变长选项），数据部分承载传输层交付的报文段/数据报。以下是 IPv4 基本首部的各字段（以 32 位为一行排列）：

- **版本**（4 位）：IP 协议版本（IPv4 = 4）。
- **首部长度**（4 位）：单位为 4 字节，基本首部为 5，最大 15（60 字节）。
- **区分服务**（8 位）：早期称服务类型；现多用作 DSCP/QoS 标记，一般不用于路由。
- **总长度**（16 位）：首部 + 数据的总字节数，最大 65535 字节。
- **标识**（16 位）：由计数器产生，同一数据报的所有分片**标识相同**，用于分片重组时归属同一原报。
- **标志**（3 位）：仅低两位有意义——**MF**（More Fragment）= 1 表示后面还有分片；**DF**（Don't Fragment）= 1 表示不允许分片。
- **片偏移**（13 位）：单位为 **8 字节**，表示本片数据部分在原数据报中的相对位置。
- **生存时间 TTL**（8 位）：每经过一个路由器减 1，减到 0 即丢弃（防止数据报在环中无限循环）。
- **协议**（8 位）：指明上层协议，如 ICMP=1、TCP=6、UDP=17、OSPF=89。
- **首部校验和**（16 位）：**只校验首部**（不含数据），因 TTL 逐跳变化，每跳都要重新计算。
- **源地址 / 目的地址**（各 32 位）：发送方与接收方的 IP 地址。
- **选项 + 填充**（可变）：源路由、记录路由、时间戳等，长度不足 4 字节整数倍时填充；选项使首部变长、降低转发效率，实际中基本不用。

> **首部记忆顺序（20 字节）**：版本+首部长+区分服务（4B）｜总长度（2B）｜标识（2B）｜标志+片偏移（2B）｜TTL+协议（2B）｜首部校验和（2B）｜源地址（4B）｜目的地址（4B）。IPv6 已取消首部校验和与分片相关字段（详见《IPv6》章）。



#### IP 分片

**分片**：当数据报长度大于链路的 **MTU（最大传输单元，以太网为 1500 字节）** 时，把数据报拆成多个较小的数据报片的过程。

- **分片时机**：在源端或中间路由器都可分片；但**重组只在目的主机进行**，依据是 标识 + 片偏移 + MF 标志。
- **分片原则**：除最后一片外，每片的数据部分长度必须是 **8 的倍数**（因片偏移以 8 字节为单位）；每片的总长度 = 该片数据长度 + 首部长度（通常各片都保留完整的 20 字节首部）。
- **片偏移计算**：片偏移 = 该片数据在原数据报中的起始字节数 ÷ 8。

> **典型例题**：一个总长 3820 字节（首部 20 + 数据 3800）的数据报，在 MTU = 1420 的链路上分片。
>
> - 每片数据最多 1400 字节（1400 是 8 的倍数，1400 + 20 = 1420 ≤ MTU）。
> - 共需 **⌈3800 / 1400⌉ = 3 片**：片 1 数据 [0, 1400)、片 2 数据 [1400, 2800)、片 3 数据 [2800, 3800)。
> - 片偏移分别为 **0、175、350**（1400 / 8 = 175），片 1、片 2 的 MF = 1，片 3 的 MF = 0。

> **IPv6 的变化**：IPv6 基本首部固定 40 字节，**不允许中间路由器分片**，分片只能由源端进行（配合路径 MTU 发现）；路由器的转发负担因此更轻。
