## 数据的表示：数制与编码

> **全章主脉**：计算机只懂 0 和 1，任何数据都要编码成二进制。本章先把进制讲清（二进制、八进制、十六进制及相互转换），再讲带符号整数在机器里怎么表示——**原码、反码、补码**三种码制，重点落在补码（加减统一、只有一个零），最后补字符编码（ASCII）与十进制压缩编码（BCD）。
>
> **一句话记码制**：正数三码相同；负数原码符号位 1、其余取反得反码、反码末位加 1 得补码；**补码让减变加、0 唯一、能多表示一个最小负数**——所以机器普遍用补码。

### 进位计数制

#### 二进制、八进制与十六进制

**进位计数制**用有限个数字符号按"逢 R 进一"的规则表示数，R 称基数。计算机常用的进制有二进制、八进制、十六进制，还有日常的十进制。

各种进位制的要点：

- **十进制**：基数为 10，数字 0 至 9，逢十进一，人们日常使用。
- **二进制**：基数为 2，数字 0 和 1，逢二进一，是计算机内部唯一能直接处理的进制。
- **八进制**：基数为 8，数字 0 至 7，逢八进一，一位八进制数恰对应 3 位二进制。
- **十六进制**：基数为 16，数字 0 至 9 与 A 至 F（表示 10 至 15），逢十六进一，一位十六进制对应 4 位二进制。

**位权**：任意进制数每一位的值 = 该位数字乘以该位权（基数的幂）。例如二进制 1011 从低位到高位各位的权为 1、2、4、8。

> [!NOTE]
> 提醒内容：二进制位数多、书写不便，故常用八进制/十六进制作为二进制的手写缩写——4 位二进制折 1 位十六进制、3 位二进制折 1 位八进制，二者与二进制之间转换极其方便。



#### 数制转换

**数制转换**是在不同基数间表达同一个数，方法取决于转换方向。

**R 进制转十进制**：按位权展开求和。把每位数字乘以对应权（基数幂）再相加。

- 例：二进制 1011 转十进制 = 1×8 + 0×4 + 1×2 + 1×1 = 11。
- 十六进制 1A 转十进制 = 1×16 + 10×1 = 26。

**十进制转 R 进制**：整数部分与小数部分分开处理。

- **整数部分**：除 R 取余，从后往前排，直至商为 0。
- **小数部分**：乘 R 取整，从前往后排，直至积的小数部分为 0 或达到所需精度。

**二进制与八/十六进制互换**：按位分组拼合。

- 二进制转八进制：从小数点起向左、向右各每 3 位一组，每组换成对应八进制数字。
- 二进制转十六进制：每 4 位一组换成对应十六进制数字。

> [!TIP]
> 建议内容：十进制转二进制整数用"除 2 取余倒排"，转小数用"乘 2 取整顺排"。注意十进制小数转二进制可能无限不循环（如 0.1），只能取有限位近似——这正是浮点数精度问题的来源之一。



### 无符号数与有符号数

#### 原码、反码与补码

机器数中要区分无符号数与有符号数。**无符号数**所有位都表示数值大小；**有符号数**用最高位作符号位（0 正 1 负），其余为数值位。表示有符号数的三种码制如下。

设 n 位机器数，其中最高位为符号位 S：

- **原码**：符号位 + 数值绝对值的二进制。正数符号位 0、负数符号位 1，数值位同绝对值。
  - 例：n=4，+5 的原码为 0101，−5 的原码为 1101。原码的 0 有 +0 与 −0 两种表示（0000 与 1000）。
- **反码**：正数与原码相同；负数是把原码的数值位**逐位取反**（符号位不变）。
  - 例：−5 原码 1101 → 反码 1010。反码的 0 也有 +0（0000）与 −0（1111）。
- **补码**：正数与原码相同；负数 = 反码末位再加 1（即原码取反加 1），也可理解为 2 的 n 次方与该负数绝对值之差。
  - 例：−5：原码 1101 → 反码 1010 → 补码 1011。
  - 补码的 0 只有一种表示（0000），而 1000 用来表示最小负数 −2 的 (n−1) 次方。

> [!WARNING]
> 警告内容：负数求补码必须从**原码**出发"取反加 1"；若误从绝对值直接取反加 1 会出错。同时记住**原码与反码都有正负两个 0，补码只有一个 0**，因此补码能比原码多表示一个最小负数，这是补码的重要优点。



#### 补码的性质

**补码**是为统一加减法而引入的编码，其数值结构使减法规约为加法，是计算机表示有符号整数的主流。

补码的性质可归纳为：

- **0 表示唯一**：补码中只有 0000 一个 0，消除了原码/反码的双零歧义。
- **加减统一**：两个数的加减可统一为补码加法（连同符号位一起按二进制相加），并据符号判断结果，无需单独做减法器。
- **符号位参与运算**：补码做加法时符号位按自然进位处理，结果符号由运算自然得出。
- **模的概念**：n 位补码的模为 2 的 n 次方，负数补码等于 2 的 n 次方减去其绝对值，故加一个负数等价于加它的模补数，即"减变成加"。
- **范围**：n 位补码表示范围是 −2 的 (n−1) 次方 至 2 的 (n−1) 次方 减 1。

> [!IMPORTANT]
> 重要内容：补码通过"模"把减法化为加法——减去一个数等于加上该数补码，且符号位参与运算。这让 CPU 只需加法器就能完成加减（减法转加补码），简化硬件。求负数补码的口诀：**取反加 1**（符号位取反后数值位取反再加 1），或用"模减绝对值"直接得。



### 字符编码

#### ASCII 码

**ASCII（美国信息交换标准码）**是用 7 位二进制表示西文字符的编码，是最基本的字符编码标准。

- **编码范围**：7 位 ASCII 共 128 种编码（0 至 127），通常存成一个字节（最高位为 0）。
- **内容分类**：
  - 控制字符：0 至 31 及 127，如回车、换行、退格等不可打印控制符。
  - 可打印字符：数字 0 至 9（编码 48 至 57）、大写字母 A 至 Z（65 至 90）、小写字母 a 至 z（97 至 122），以及空格与各类标点符号。
- **特点**：大小写字母编码相差 32，便于转换（大写加 32 得小写）。

> [!NOTE]
> 提醒内容：需记忆关键锚点——数字 0 对应编码 48，大写 A 对应 65，小写 a 对应 97。这样可推算出任意字母数字的 ASCII 值。ASCII 只能表达英文字符，无法表示汉字等非西文字符。



#### BCD 码

**BCD 码（二进制编码的十进制）**用若干二进制位来编码十进制数字 0 至 9，使十进制数可直接用二进制逻辑处理。

最常用的 **8421 BCD 码**：每个十进制数字用 4 位二进制表示，位的权分别为 8、4、2、1，恰好是自然二进制的前 10 种编码。

- 例：十进制 35 的 8421 BCD 码为 0011 0101（3 与 5 各用 4 位编码）。
- 8421 BCD 中 1010 至 1111 六个编码（对应十进制 10 至 15）非法，不用于表示单个数字。

**BCD 加法修正**：两个 BCD 数字相加，若结果大于 9 或产生进位，需再加 6（0110）修正，使其回到合法的 BCD 表示。

> [!TIP]
> 建议内容：区分两种编码——**ASCII 是字符编码**（把字符变二进制以便存储），**BCD 是十进制数编码**（把十进制数字直接用 4 位二进制表示以便运算）。BCD 便于十进制输入输出，但比纯二进制浪费位且运算要修正，故内部运算多用二进制、仅在界面转换处用 BCD。



### 码制互换与数值范围的典型计算

数制章的高频计算是"原码/反码/补码互换"与"给定位数求范围"，务必把规则练熟。

**计算示例一（码制互换，以 8 位为例，求 −45）**：

- 原码：45 的二进制为 0010 1101，最高位置 1 得 1010 1101。
- 反码：原码数值位取反（符号位不变）得 1101 0010。
- 补码：反码末位加 1 得 1101 0011。
- 校验：−45 的补码也可用"模 2 的 8 次方（256）减 45 = 211 = 1101 0011"直接得。

**计算示例二（回推真值）**：给定 8 位补码 1110 0100。符号位为 1，是负数；数值 = 补码取反加 1 = 0001 1011 + 1 = 0001 1100 = 28，故真值为 −28。也可用 1110 0100 − 256 得 −28。

**计算示例三（求范围）**：8 位补码范围 −2 的 7 次方 至 2 的 7 次方 − 1，即 −128 至 127；8 位原码/反码范围 −127 至 127（各有两个 0）。补码最小负数编码为 1000 0000 = −128。

> [!WARNING]
> 警告内容：三个易错点——(1) 求负数补码必须从**原码**出发取反加 1，别直接对十进制取反加 1；(2) 回推负数补码的真值时，负数的补码"取反加 1"得到的是其**绝对值**，结果加负号；(3) 原码/反码比补码少一个最小负数（因为有正负两个 0），判断范围别漏这一点。

> **常考角度**：给真值求三种码、给某码求真值、比较不同位长下各码制范围、判断补码加减结果与溢出。数制转换（二进制/八/十六进制互换、十进制小数转二进制）也是基本必考，可一并练习。
