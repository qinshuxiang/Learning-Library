## 排序：归并、基数排序与复杂度比较

> **全章主脉**：本章收尾内部排序——**归并排序**（O(n log n) 稳定、需 O(n) 空间）与**基数排序**（非比较排序，按关键字位分配收集），最后给出**全部内排序的综合比较表**（时间/空间/稳定性）与**选用原则**。综合比较是常考选择题，务必熟记。

### 归并排序

#### 二路归并思想

**归并排序**采用**分治**：把序列**递归地一分为二**，直到每段只含一个元素（天然有序），再**两两归并**成有序段，最终得到整体有序。**二路归并**是每次把两个相邻有序子序列**合并成一个有序序列**。

**二路归并"合并"操作**：用两个指针分别指向两个已有序子段，每次取较小者放入结果，直到一段取完再把另一段剩余接上（类似有序表合并）。

```text
归并排序(low, high)：
  若 low < high：
    mid = (low+high)/2
    归并排序(low, mid)      # 排左半
    归并排序(mid+1, high)   # 排右半
    合并(low, mid, high)    # 把两个有序段归并

合并：用辅助数组，双指针取小，把两有序段合成一段
```

> [!NOTE]
> 提醒内容：归并"**分到底、再两两合**"，合并用辅助数组双指针。**归并排序是稳定排序**。它体现分治法：递归分解 + 合并有序段。会手推归并的趟间序列（每趟把相邻有序段合并扩大）。

#### 归并排序的性能

**归并排序的性能**：递归树高度约 log n，每层归并总代价 O(n)，故总时间 **O(n log n)**（最好、最坏、平均都如此，稳定）。

- **时间**：O(n log n)，**最好最坏平均一致**（不依赖输入是否有序）。
- **空间**：需要**辅助数组**，空间 **O(n)**（另有递归栈 O(log n) 可合并视为 O(n)）。
- **稳定性**：**稳定**（合并时两段相等取左段先，保持稳定）。
- **特点**：时间稳定 O(n log n) 且稳定，是"稳定 + 高效"的选择，代价是 O(n) 空间。

> [!NOTE]
> 提醒内容：归并排序**时间和空间都确定**——O(n log n) 时间（任何输入）、O(n) 辅助空间、稳定。它是**唯一 O(n log n) 且稳定**的常用比较排序（快排不稳定、堆 O(1) 空间但不稳定）。要做"稳定且 O(n log n)"的排序选归并，但要注意它的空间开销。

### 基数排序

#### 多关键字排序

**基数排序**是**非比较排序**，它不比较关键字大小，而是按关键字的**每一位（或每个子关键字）**进行**分配与收集**。有两种策略：**最高位优先（MSD）**与**最低位优先（LSD）**，LSD 更常用且不需递归分组。

**多关键字排序**：若关键字由多个分量组成（如 d 位数或由次要到主要多个关键字），**LSD 最低位优先**做法是**从最低位（最次关键字）到最高位（主关键字）逐趟"分配 + 收集"**——每趟按当前位把元素分配到对应桶（0~9 或 0~r−1），再按桶序收集，经过 d 趟后整体有序。

- **MSD**：先按最高位分组，各组内再按次高位……递归。
- **LSD**：从最低位逐趟分配到收集，无需递归，结果天然有序。

> [!NOTE]
> 提醒内容：基数排序按"**位/子关键字分配收集**"。LSD 从最低位到最高位逐趟做，主关键字（最高位）最后处理保证整体次序。它**不是比较排序**，关键字须能拆成若干"基数"位。基数 r（如十进制 r=10）。

#### 链式基数排序

**链式基数排序**用**链表/队列**实现"分配与收集"：对每个基数位，用**r 个队列（桶）**接收该位为某值的元素，一趟结束后**按队列顺序依次收集**回链表，进行下一趟。

- **实现**：设 r 个队列（如十进制 r=10，即 0~9 十个桶），按位把元素分配到对应桶、收集。
- **时间**：需 d 趟（d 为最大位数/关键字个数），每趟分配+收集 O(n)，总 **O(d(n 加 r))**；d、r 视为常数时近 O(n)。
- **空间**：需要 r 个队列/桶，约 O(r 加 n)。
- **稳定性**：**稳定**（分配收集按序进行）。

> [!IMPORTANT]
> 重要内容：**基数排序 O(d(n+r))，用桶按位分配收集，稳定，非比较排序**——当关键字位数 d 与基数 r 相对 n 很小（如对 0~9999 的整数排序）时接近线性 O(n)，比比较排序快。代价是需桶空间与"能按位分解"的前提。手推：给若干 3 位数，从个位到百位逐趟分配到十/个桶再收集，画每趟结果。

### 各种内部排序算法的比较

#### 时间复杂度

**各内排序的时间复杂度**综合如下（n 为元素个数）。

- **O(n log n)**：快速排序（平均）、归并、堆排序。其中快排平均最优但**最坏 O(n²)**；归并与堆**任何情况 O(n log n)**。
- **O(n 方)**：直接插入、冒泡、简单选择（简单选择无论有序与否都 O(n²)）。
- **O(n 的 1.3 次方) 量级**：希尔排序（介于 O(n log n) 与 O(n²) 之间，随增量序列变化）。
- **O(d(n 加 r))**：基数排序（非比较，d 位数、r 基数）。
- **特殊情况**：插入、冒泡在**已有序**时最好为 O(n)。

> [!NOTE]
> 提醒内容：记时间——**"快 O(nlogn) 平均最好但最坏 O(n²)；归并、堆恒 O(nlogn)；插入冒泡选择 O(n²)（选择恒）；希尔居中；基数看位数"**。会判某算法对特定输入的复杂度（如已序对插入是 O(n)、对快排选端点是 O(n²)）。

#### 空间复杂度与稳定性

**空间复杂度**：

- **O(1)**：插入、冒泡、选择、堆、希尔。
- **O(log n)（递归栈）**：快速排序平均。
- **O(n)**：归并（辅助数组）；基数（桶 O(r+n)）。

**稳定性**：**稳定**——直接插入、冒泡、归并、基数；**不稳定**——希尔、快速、简单选择、堆。

> [!IMPORTANT]
> 重要内容：**空间与稳定性对照必记**——稳定四金刚：插入、冒泡、归并、基数；不稳四件套：希尔、快排、选择、堆。空间：几乎都 O(1)，只有**归并需 O(n)**（辅助数组）、**快排需 O(log n) 递归栈**、**基数需桶空间**。综合题"既稳定又要 O(nlogn)"只有归并。

### 排序算法的选用

**排序算法选用**依数据规模、是否稳定、时空要求而定。

- **数据量小或基本有序**：直接插入（代码简单、基本有序近 O(n)）。
- **一般规模、重速度**：快速排序（平均 O(n log n)、O(1) 空间，平均最快）；要**稳定 + O(n log n)** 则用归并（多 O(n) 空间）。
- **要求原地 + 稳定 O(n log n)**：堆排序（原地但**不稳定**）。
- **关键字可拆位**（整数、可分成多关键字）：基数排序近线性，但要桶空间。
- **只需取前 k 大/小**：用堆（建堆 O(n)、取 k 次 O(k log n)）不用全排。
- **记录是大对象**：减少移动（用选择、或排序索引/指针）。

> [!WARNING]
> 警告内容：**"平均最快用快排、稳定高效用归并、原地高效用堆、近序或小量用插入、可拆位用基数"**。特别提醒：快排**不稳定**且**有序时若选端点基准会退化 O(n²)**；堆**不稳定**但**任何情况 O(n log n) 且原地**；归并**稳定**但**需 O(n) 空间**。选排序先定"稳定否"与"空间预算"，再看规模与数据特征。
