## 排序：插入、交换与选择排序

> **全章主脉**：排序是把一组记录按关键字**有序排列**。本章先讲排序基本概念（**稳定性、内/外排序**），再逐个介绍**直接插入、希尔、冒泡、快速、简单选择、堆排序**六种算法，重点掌握各自的时间/空间复杂度、**稳定性**与**适用场景**。快速排序是最常考的交换排序，务必理解分治与划分。

### 排序的基本概念

#### 稳定性

**排序**是按**关键字**把一组记录排列成递增或递减序列的操作。若待排序的记录中**关键字相同的两个记录，排序后它们的相对次序不变**，则称该排序算法是**稳定的**，否则**不稳定**。

**各排序算法稳定性**（高频记忆）：

- **稳定**：直接插入、冒泡、归并、基数。
- **不稳定**：希尔、快速、简单选择、堆。

> [!NOTE]
> 提醒内容：稳定性指"**同关键字元素排序前后相对次序不变**"。考哪些稳定哪些不稳定是送分项——记"稳：插入冒泡归并基数；不稳：希尔快排选择堆"。稳定的价值：先按次关键字排再按主关键字排，稳定能保留前一次次序。

#### 内排序与外排序

**按排序过程是否全部在内存进行**分**内部排序（内排序）与外部排序（外排序）**。

- **内部排序**：待排序记录**全部在内存**中完成排序，本章讨论的排序（插入、交换、选择、归并、基数）均属内排序。
- **外部排序**：待排序记录**太多、无法一次全放内存**，须借助外存分批调入，如归并式外部排序（见 ch18）。
- 内部排序的时间性能常用**比较次数与移动次数**衡量；记录较多时常用**关键字比较 + 元素移动**来评价。

> [!NOTE]
> 提醒内容：内排序在内存一次完成，外排序因数据量超内存需多趟归并。内排序的评价看比较与移动次数；当记录是"大对象"时，**移动代价**常决定性能（故有的排序为少移动而用索引/指针）。

### 直接插入排序

**直接插入排序**把序列分为"**已排序前缀**"与"**未排序后缀**"，每次**取未排序的第一个元素，在已排序部分中找到正确位置插入**，使已排序部分始终有序，直到全部处理完。类似打牌时理牌。

- **思想**：依次把第 i 个元素插入前 i−1 个有序元素中的合适位置。
- **时间**：最好 O(n)（已有序，每趟几乎不移动）、平均与最坏 **O(n 方)**（逆序时移动最多）。
- **空间**：O(1)（原地）。
- **稳定性**：**稳定**。
- **适用**：数据量小或基本有序时效率高。

> [!NOTE]
> 提醒内容：直接插入是"**把新元素往已有序区里插**"。元素越有序它越快（最好 O(n)）。稳定、原地 O(1)。n 较小时或接近有序时，直接插入比 O(n log n) 算法实际更快。理解它有利于理解折半插入、希尔。

#### 直接插入排序的 JavaScript 实现

**思路**：把数组看成**已排好的前段**与**待处理的后段**两个区域。每趟取后段首个元素存入 temp，在已排段中从后往前**边比较边后移**，空出位置后再把 temp 放入。内层用 while 而非 for，是因为**移动次数事先不确定**。

下面先给出承载各排序算法的 ArrayList 类骨架，后续各节的方法均作为该类的成员接着给出。

```js
class ArrayList {
  constructor() {
    this.array = [];
  }

  insert(item) {
    this.array.push(item);
  }

  // 交换下标 m 与 n 处的元素
  swap(m, n) {
    const temp = this.array[m];
    this.array[m] = this.array[n];
    this.array[n] = temp;
  }

  toString() {
    return this.array.join(",");
  }

  // 直接插入排序
  insertionSort() {
    const arr = this.array;
    const length = arr.length;

    // 外层从下标 1 开始，下标 0 视为长度为 1 的有序段
    for (let i = 1; i < length; i++) {
      let j = i;
      const temp = arr[i];

      // 内层用 while：边比较边后移
      while (j > 0 && arr[j - 1] > temp) {
        arr[j] = arr[j - 1];
        j -= 1;
      }
      arr[j] = temp;
    }
  }
}

const list = new ArrayList();
[3, 6, 4, 2, 11, 10, 5].forEach((n) => list.insert(n));
list.insertionSort();
console.log(list.toString()); // 2,3,4,5,6,10,11
```

> [!TIP]
> 建议内容：**插入排序速记**——"摸牌式整理"。左手已排好的牌是有序段，右手摸一张是 temp，从右往左比、比它大的往右挪，挪不动了就插进去。实现上内层循环用 while，正对应"移动次数不定"这一特点。



### 希尔排序

**希尔排序**是**插入排序的改进**，又称**缩小增量排序**：它按一定**增量（间隔）**把序列分成若干子序列，**对每个子序列做直接插入排序**，然后**逐步缩小增量**再插入，直到增量为 1 时做一次完整的插入排序。目的是让元素能**大跨度跳跃**、提前接近最终位置，减少最后阶段的移动。

- **增量序列**：通常增量 d 从 n/2 起每次减半，直到 1（也可用其他递减序列）。
- **时间**：平均约为 O(n 的 1.3 次方) 量级，优于 O(n²)；最坏依赖增量序列（约 O(n²)）。
- **空间**：O(1)。
- **稳定性**：**不稳定**（间隔插入会打乱同关键字相对次序）。

> [!WARNING]
> 警告内容：希尔排序**不稳定**、是"按增量分组的插入排序"，增量逐步缩到 1。它与直接插入的区别是**先按大间隔远距移动**，因此比直接插入快得多（最坏仍可能 O(n²) 视增量而定）。给定序列按某增量做希尔排序要能写出中间结果。空间 O(1)。

#### 希尔排序的 JavaScript 实现

**思路**：希尔排序是**分组的直接插入排序**。先取一个较大的增量 gap 把数组分成若干子序列分别插入排序，再逐步缩小 gap；最后一轮 gap 为 1 时即退化为直接插入排序，此时数组已基本有序，移动次数大幅减少。

```js
// 接上文 ArrayList 类
shellSort() {
  const arr = this.array;
  const length = arr.length;

  // 初始增量取半，之后逐次折半，直到为 0
  let gap = Math.floor(length / 2);
  while (gap > 0) {
    // 对每个子序列做插入排序
    for (let i = gap; i < length; i++) {
      let j = i;
      const temp = arr[i];
      while (j > gap - 1 && arr[j - gap] > temp) {
        arr[j] = arr[j - gap];
        j -= gap;
      }
      arr[j] = temp;
    }
    gap = Math.floor(gap / 2);
  }
}
```

**增量序列的选择**：

- **折半增量**（length 除以 2 后逐次折半）：本实现所用，写法最简单，但增量之间不互质，效率略逊。
- **Hibbard 增量**（2 的 k 次方减 1）：增量之间互质，最坏时间复杂度优于折半增量。
- **Sedgewick 增量**：工程上常用的更优序列，可把时间复杂度进一步降低。

> [!NOTE]
> 提醒内容：希尔排序的最后一轮一定是 **gap 等于 1** 的直接插入排序，这保证了结果必然有序；前面各轮只是"预处理"，目的是减少最后一轮的元素移动次数。分组跨越式的交换也正是它**不稳定**的根源——相等元素可能被分到不同组而打乱相对次序。



### 冒泡排序

**冒泡排序**反复扫描序列，**相邻元素若逆序则交换**，每一趟把当前未排区**最大的元素"冒"到末尾**，下一趟缩小范围，直到无交换发生。属**交换排序**。

- **思想**：相邻比较交换，一趟把最大（或最小）移到端部。
- **可提前结束**：若一趟无交换，说明已有序、可结束（改进）。
- **时间**：最好 O(n)（已有序一趟即结束）、平均与最坏 O(n 方)。
- **空间**：O(1)。**稳定性**：**稳定**（只有逆序才交换，等值不换）。
- 一趟排序能确定一个元素的最终位置（最大/最小值沉底或浮顶）。

> [!NOTE]
> 提醒内容：冒泡"**相邻逆序就换，一趟定一个极值**"。稳定、O(1) 空间、最好 O(n)。若一趟扫描无交换即有序可提前停。理解"每趟确定一个元素最终位置"有助于判断"第 k 趟后哪些元素已就位"。

#### 冒泡排序的 JavaScript 实现

**思路**：每趟从前往后两两比较、逆序则交换，把当前未排段的最大值"浮"到末尾；外层循环反向从 length 减 1 递减到 0，控制未排段的右边界。可加**提前退出标志**优化：某趟一次交换都没发生，说明数组已整体有序。

```js
// 接上文 ArrayList 类
bubbleSort() {
  const arr = this.array;
  const length = arr.length;

  // 外层反向循环，每趟确定一个最大值，右边界逐趟左移
  for (let i = length - 1; i >= 0; i--) {
    let swapped = false;
    for (let j = 0; j < i; j++) {
      if (arr[j] > arr[j + 1]) {
        this.swap(j, j + 1);
        swapped = true;
      }
    }
    // 本趟未发生交换，说明已整体有序
    if (!swapped) break;
  }
}
```

> [!TIP]
> 建议内容：**冒泡排序速记**——"两两比、逆序换、一趟定一个"。外层倒着走控制右边界，内层正着走做相邻比较；加上 swapped 标志后，对已有序的数组只需一趟比较即可收工，时间复杂度降到 O(n)。



### 快速排序

#### 快速排序思想

**快速排序**是**分治法**的典型：选一个**基准（枢轴）元素**，把序列划分成**左半（小于基准）与右半（大于基准）**，基准就位后**递归对左右两半排序**。平均 O(n log n)，是所有内排序中**平均性能最好**的之一。

**快排的"划分"思想**：选基准 pivot，一趟划分后 pivot 落到**最终正确位置**，其左边都小于它、右边都大于它。之后左右子区间相互独立、各自递归快排。

> [!NOTE]
> 提醒内容：快排核心是"**选基准、分区、递归**"。**每趟划分至少让基准元素落到其最终位置**。选首元素为基准是常见做法。快排是不稳定排序（跨越交换破坏稳定性）。

#### 分区与递归

**快排的划分（partition）**常用 **Lomuto（单指针）或 Hoare（双指针）** 法。Hoare 双指针法：左右两指针从两端向中间靠拢，**左边找大于基准的、右边找小于基准的交换**，直到两指针相遇，把基准放到相遇处。

```text
快排(区间 low..high)：
  若 low < high：
    pivotpos = 划分(low, high)   # 返回基准最终位置
    快排(low, pivotpos-1)        # 排左半
    快排(pivotpos+1, high)       # 排右半

划分(选 a[low] 为基准)：
  用左右指针交换使 小于基准的到左、大于基准的到右
  返回基准最终位置
```

**递归与栈**：快排用递归（隐含栈），递归深度即划分层次，与划分是否均衡有关。

> [!IMPORTANT]
> 重要内容：**快排的划分让基准一次就位，左右递归**。手推题要会：选基准 → 交换使左小右大 → 基准归位，再对左右区间重复。**快排不稳定**。会手推给定序列一趟划分的结果，并判断某趟后哪些元素已在其最终位置（每趟划分确定的基准即最终位置）。

#### 快速排序的性能分析

**快速排序的性能取决于划分是否均衡**（即基准选得好不好）。

- **最好/平均**：划分基本均衡，递归深度 log n，时间 **O(n log n)**。
- **最坏**：序列**已有序/逆序**且选首元素为基准时，划分严重不均衡（每趟只确定一个元素），退化为 O(n 方)，递归深度 O(n)。
- **空间**：递归栈平均 O(log n)、最坏 O(n)。
- **稳定性**：**不稳定**。
- **优化**：随机选基准、三数取中等避免最坏；元素少时改用插入排序。

> [!WARNING]
> 警告内容：**快排最坏 O(n²) 恰恰发生在"原本有序"时（若选端点作基准）**——因每次划分只排掉一个。平均 O(n log n)，是内排序平均最优。空间来自递归栈 O(log n) 平均。**快排不稳定**。题目问"哪种内排序平均最快"答快排（平均意义）；但说最坏时退化为 O(n²)。



#### 快速排序的 JavaScript 实现

**思路**：每趟先用**三数取中法**选出枢纽（pivot）并把它暂存到 right 减 1 处，随后 i 从左、j 从右双向扫描并交换逆序对，直到 i 不小于 j；最后把枢纽换回 i 位置，再对左右两段分别递归。三数取中可避免在有序数组上选到最差枢纽。

- **median（三数取中）**：比较 left、center、right 三个位置的元素并排序，再把中值换到 right 减 1 处返回。
- **双向扫描**：i 从左找第一个不小于枢纽的元素，j 从右找第一个不大于枢纽的元素，i 小于 j 则交换。
- **递归分治**：枢纽归位后，对 left 到 i 减 1 与 i 加 1 到 right 两段各自递归。
- **小区间交给插入排序**：三数取中要求区间至少有 3 个元素，长度不超过 3 的子区间直接改用直接插入排序收尾。
- **三趟比较的次序**：先比 left 与 center 使两者有序，再比 center 与 right 使 center 不大于 right，最后**必须再比一次 left 与 center**——第二趟交换后中值可能被换到 center 之外。三趟走完，center 位置上才是三数的中值。

```js
// 接上文 ArrayList 类

// 对 [left, right] 闭区间做直接插入排序，供小区间收尾使用
insertionSortRange(left, right) {
  const arr = this.array;
  for (let i = left + 1; i <= right; i++) {
    let j = i;
    const temp = arr[i];
    while (j > left && arr[j - 1] > temp) {
      arr[j] = arr[j - 1];
      j -= 1;
    }
    arr[j] = temp;
  }
}

// 三数取中：返回枢纽值，并把它放到 right - 1 位置
median(left, right) {
  const arr = this.array;
  const center = Math.floor((left + right) / 2);

  if (arr[left] > arr[center]) this.swap(left, center);
  if (arr[center] > arr[right]) this.swap(center, right);
  // 第三趟必须再比 left 与 center：第二趟交换后中值可能落到了 center 之外
  if (arr[left] > arr[center]) this.swap(left, center);

  // 把中值移到 right - 1，作为扫描的哨兵
  this.swap(center, right - 1);
  return arr[right - 1];
}

quickSort() {
  if (this.array.length < 2) return;
  this.quickSortRec(0, this.array.length - 1);
}

quickSortRec(left, right) {
  // 0.递归结束条件
  if (left >= right) return;

  // 0.1 小区间（元素个数不超过 3）改用直接插入排序
  // 原因：三数取中要求区间至少有 3 个元素，否则枢纽位置会算错
  if (right - left <= 2) {
    this.insertionSortRange(left, right);
    return;
  }

  // 1.获取枢纽
  const pivot = this.median(left, right);

  // 2.双向扫描并交换逆序对
  let i = left;
  let j = right - 1;
  while (true) {
    while (this.array[++i] < pivot) {}
    while (this.array[--j] > pivot) {}
    if (i < j) {
      this.swap(i, j);
    } else {
      break;
    }
  }

  // 3.枢纽归位
  this.swap(i, right - 1);

  // 4.左右两段分别递归
  this.quickSortRec(left, i - 1);
  this.quickSortRec(i + 1, right);
}
```

**调用示例**：

```js
const list = new ArrayList();
[3, 6, 4, 2, 11, 10, 5].forEach((n) => list.insert(n));
list.quickSort();
console.log(list.toString()); // 2,3,4,5,6,10,11
```

> [!WARNING]
> 警告内容：**双向扫描前必须先把枢纽挪出扫描区间**（本实现挪到 right 减 1），否则 i 或 j 会在枢纽位置卡死甚至越界。三数取中之后，实际扫描区间是 left 加 1 到 right 减 2，两端充当天然哨兵，因而可以省去下标越界判断。

> [!CAUTION]
> 注意内容：**三数取中隐含"区间至少有 3 个元素"的前提**。若不加判断就对只有 2 个元素的区间取中，枢纽会被放到 left 位置、扫描起点 j 越过左边界，排序结果直接出错。正确做法是：递归到元素个数不超过 3 的小区间时，改用直接插入排序收尾——这也正是工程实现中常见的**小区间切换插入排序**优化。

> [!IMPORTANT]
> 重要内容：**枢纽的选择决定快排的效率**。直接取首元素或尾元素作枢纽时，已有序的数组会退化成 O(n²)；三数取中能把这种最坏情况大幅推后。快排**不稳定**，且递归带来的空间开销为 O(log n) 到 O(n)。



### 简单选择排序

**简单选择排序**每趟从**未排序部分**中**选出最小（或最大）元素**，与未排序部分的**第一个元素交换**，使其归位，重复 n−1 趟完成排序。属**选择排序**。

- **时间**：无论序列是否有序，都要比较选出极值，故**最好、平均、最坏都是 O(n 方)**（比较次数固定 n(n−1)/2）。
- **移动次数少**：每趟至多交换一次，移动较少。
- **空间**：O(1)。**稳定性**：**不稳定**（交换可能跨越相等的元素改变相对次序）。

> [!NOTE]
> 提醒内容：选择排序"**每趟挑最小的放前面**"。它的**比较次数固定**（总 O(n²)，与输入顺序无关），但**移动少**（每趟一次交换）。不稳定（如首元素与后面相等元素交换会破坏次序）。特点是"时间恒定 O(n²)"。

#### 简单选择排序的 JavaScript 实现

**思路**：每趟在未排段中扫出最小元素的下标 min，再与未排段首位交换，从而每趟确定一个元素的最终位置。比较次数固定为 n 乘 (n 减 1) 除以 2，但交换次数最多只有 n 减 1 次，远少于冒泡排序。

```js
// 接上文 ArrayList 类
selectionSort() {
  const arr = this.array;
  const length = arr.length;

  // 外层从 0 走到 length - 2，最后一个元素自然归位
  for (let i = 0; i < length - 1; i++) {
    let min = i;
    // 内层在未排段中找最小值下标
    for (let j = min + 1; j < length; j++) {
      if (arr[min] > arr[j]) {
        min = j;
      }
    }
    this.swap(min, i);
  }
}
```

> [!TIP]
> 建议内容：**选择排序速记**——"每趟选最小的换到前面"。与冒泡的区别在于：冒泡靠**相邻交换**把最大值推到末尾，交换次数多；选择排序**先记下标、一趟只换一次**，交换次数少但比较次数不变，故整体仍是 O(n²)。



### 堆排序

#### 建堆

**堆排序**利用**堆**（大顶堆/小顶堆，完全二叉树的数组表示）排序：先**建堆**，再反复取堆顶最值与末尾交换、缩小堆范围并调整。用**大顶堆**可升序排（堆顶最大放末尾）。

**建堆**：从**最后一个非叶结点（下标 ⌊n/2⌋）**开始，向前逐个做**向下调整（筛选）**，使每个子树都满足堆序，最终整棵树为堆。

- **向下调整**：结点若小于其较大的孩子（大顶堆），与最大孩子交换并继续下沉。
- **从 ⌊n/2⌋ 到根逐个调整**，时间复杂度 **O(n)**。

> [!NOTE]
> 提醒内容：**建堆是"从 ⌊n/2⌋ 往前逐个向下调整"，时间 O(n)**。大顶堆根最大、小顶堆根最小。堆用数组存、父子下标 2i/2i+1 关系。会手推给序列建大/小顶堆的过程与结果。

#### 调整与排序过程

**堆排序过程**（升序用大顶堆）：反复把**堆顶（当前最大）与当前堆的最后一个元素交换**，此时最大元素就位到末尾，**把堆范围减 1**，再对缩小的堆做一次向下调整恢复堆序，直到堆只剩一个元素。

```text
堆排序：
  建大顶堆
  for i = n 到 2：
    交换 a[1] 与 a[i]      # 最大放到位
    堆大小减 1，对 a[1] 向下调整恢复堆
```

- **时间**：建堆 O(n)，每次取堆顶调整 O(log n)、共 n−1 次，故总 **O(n log n)**。
- **空间**：O(1)（原地）。**稳定性**：**不稳定**。
- 特点：时间稳定 O(n log n)（不像快排最坏退化）、原地省空间，但常数较大、且不稳定。

> [!IMPORTANT]
> 重要内容：**堆排序 = 建堆 O(n) + n 次"交换顶尾 + 向下调整 O(log n)"，总 O(n log n)，原地 O(1)，不稳定**。它时间稳定 O(n log n)（任何情况），这点优于快排（快排最坏 O(n²)）。每趟把当前最大值沉到末尾并缩小堆。会手推堆排序每趟交换与调整的中间序列是常考大题。
