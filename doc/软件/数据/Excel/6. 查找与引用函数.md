## 查找与引用函数

### VLOOKUP 家族

#### VLOOKUP 的结构与规则

**VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])**：在区域**首列**纵向查找目标值，返回同一行指定列的内容。

- lookup_value：要找的值；table_array：查找区域（目标值必须在区域**第一列**）。
- col_index_num：返回区域中第几列（从区域左端起算，不是工作表的列号）。
- range_lookup：FALSE 或 0 为**精确匹配**（日常默认），TRUE 或省略为近似匹配（区间查找专用）。

```text
=VLOOKUP(B2, 名册!$A$2:$D$200, 3, FALSE)      按姓名查第 3 列：职务
=VLOOKUP($B2, 名册!$A:$D, COLUMN(C1), FALSE)  配合 COLUMN 避免手填列号
```

> [!IMPORTANT]
> **重要内容**：VLOOKUP 三条铁律：**查找值必须在区域第一列**；**查不到返回 #N/A** 而不是空值；**第四参数日常一律写 FALSE**——省略成近似匹配时，查不到会返回“比它小的最大值”，数值台账里是隐蔽的重大差错。第四参数写 FALSE 应形成肌肉记忆。



#### VLOOKUP 的常见故障

- **查无此人**：#N/A 的头号原因是数据不干净——首尾空格、全半角差异、文本型数字与数值型数字互不相认。先 TRIM 清洗，或用分列统一格式。
- **区域未锁定**：填充后查找区域跟着下移，后半部分查不到。查找区域一律加 $ 或转表格用结构化引用。
- **列序错位**：插入新列后 col_index_num 不再指向原列。用 COLUMN 或 MATCH 动态生成列号可免疫插列。

```text
=VLOOKUP(TRIM(B2), 名册!$A$2:$D$200, 3, FALSE)          先清洗再查
=VLOOKUP($B2, 名册!$A$2:$D$200, MATCH(C$1, 名册!$A$1:$D$1, 0), FALSE)
```

> MATCH 行写法用**表头定位列号**：C1 里写什么列名，公式就返回那列的值，插列、调列序都不需要改公式。这是 VLOOKUP 抗变更的标准加固方案。



### INDEX 与 MATCH

#### 各自的职责

- **INDEX(array, row_num, [column_num])**：返回区域中第 row_num 行、第 column_num 列的值，是“按坐标取值”。
- **MATCH(lookup_value, lookup_array, [match_type])**：返回查找值在一维区域中的**位置序号**，match_type 用 0 表示精确匹配，是“按内容找坐标”。

```text
=MATCH("李四", A2:A100, 0)            李四在第几行（相对区域的序号）
=INDEX(B2:B100, 5)                    第 5 行的值
=INDEX(C2:C100, MATCH("李四", A2:A100, 0))   先定位再取值：等价 VLOOKUP 反向自由
```

- INDEX 与 MATCH 组合 = **先找坐标、再按坐标取值**，取代 VLOOKUP 的经典组合。
- match_type 省略是近似匹配（要求升序），日常一律写 0，与 VLOOKUP 的 FALSE 同理。



#### 组合相对 VLOOKUP 的优势

**INDEX 加 MATCH 三个自由度全面胜出**：VLOOKUP 只能从左往右查、列号靠手数、插列即失效，组合拳逐一破解。

- **反向查找**：目标列在查找列左边照样可行——交换两个参数区域即可。
- **行列双向**：外层再套一个 MATCH 定位列，可以做交叉表查询。

```text
=INDEX(A2:A100, MATCH("张三", B2:B100, 0))          反向：按 B 列查 A 列
=INDEX($C$2:$F$50, MATCH($H2, $A$2:$A$50, 0), MATCH(I$1, $C$1:$F$1, 0))
```

> [!IMPORTANT]
> **重要内容**：交叉表查询（行列表头双向定位）是 INDEX 加双重 MATCH 的标准场景，逻辑上等价于 VLOOKUP 做不到的“行列都是变量”。记准分工：**行方向 MATCH 定行号，列方向 MATCH 定列号，INDEX 按坐标取值**。



### XLOOKUP

#### 新一代查找函数

**XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])**：同时取代 VLOOKUP 与 HLOOKUP，Microsoft 365 与 Excel 2021 起可用。

- 前三个参数：找什么、在哪找（一列）、返回哪列——**查找列与返回列分开声明**，不再依赖“首列”规则。
- if_not_found：查不到时的返回值，**内建了 IFNA 的能力**。
- match_mode：0 精确（默认）；-1 返回较小近邻；1 返回较大近邻；2 通配符匹配。
- search_mode：1 从头往后；-1 **从尾往前**（取最后一次记录）。

```text
=XLOOKUP(B2, 名册!A2:A200, 名册!C2:C200, "未找到")          精确查 + 兜底
=XLOOKUP(B2, 流水!D2:D9999, 流水!B2:B9999, , , -1)          取某人最后一次办理记录
=XLOOKUP(B2&F2, 名册!A2:A200&名册!B2:B200, 名册!C2:C200, "未找到")   双条件查找
```

> [!TIP]
> **建议内容**：环境支持时**优先 XLOOKUP**：不用数第几列、自带查不到兜底、能反向能倒序。但它不能跨旧版本使用——发给装 Excel 2016 的同事会直接 #NAME?，收发文场景先确认对方的版本基线。



#### 查找函数选型对照

- **单条件、老版本兼容**：VLOOKUP 加 $ 锁区域。
- **反向查找、交叉表、要抗插列**：INDEX 加 MATCH。
- **Microsoft 365 环境**：XLOOKUP 一把梭，IFNOT_FOUND 参数直接给中文提示。
- **多条件合并查找**：XLOOKUP 用 & 拼两列；老版本可用加辅助列后 VLOOKUP。

> 无论哪个函数，**先清洗再查找**的顺序不变：空格与全半角差异对三者一视同仁地制造 #N/A 与“未找到”。



### 其他引用函数

#### CHOOSE、INDIRECT 与 OFFSET

- **CHOOSE(index_num, value1, [value2], ...)**：按序号取第 n 个值，适合少量固定选项的映射。
- **INDIRECT(ref_text)**：把文本字符串解析成引用，如 INDIRECT(“B”&A2) 拼出动态地址；被解析引用的源区域**变动时不自动跟随**。
- **OFFSET(reference, rows, cols, [height], [width])**：从基准点偏移出一片区域，常配 SUM 做滚动区间统计。

```text
=CHOOSE(WEEKDAY(A2, 2), "一", "二", "三", "四", "五", "六", "日")
=SUM(OFFSET($B$1, COUNTA(B:B)-30, 0, 30, 1))       最近 30 行滚动求和
=INDIRECT("台账!B"&A2)                              按行号动态取台账 B 列
```

> [!CAUTION]
> **注意内容**：INDIRECT 与 OFFSET 都是**易失函数**且不受表格结构化引用保护：大量使用会拖慢整簿重算，引用的表改名后公式静默失准。能用结构化引用、XLOOKUP 解决的需求，不碰这两个函数；确需动态区域时优先考虑表格自动扩展与 FILTER（系列第 7 篇）。
