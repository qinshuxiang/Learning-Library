## 函数基础

### 公式的结构与书写

#### 什么是函数

**函数（Function）**：是 Excel 预置的**现成公式**，接受若干参数、返回一个计算结果，本质是把一段常用计算逻辑封装成一个可复用的名字。

- **函数名**：标识计算逻辑，如 SUM、IF、VLOOKUP，不区分大小写（输入 sum 自动变为 SUM）。
- **参数**：括号内按顺序传入的值，参数之间用**半角逗号**分隔，方括号表示该参数可省略。
- **返回值**：函数计算的结果，可以是数字、文本、日期、逻辑值，也可以是一个区域或数组。

```text
=SUM(B2:B31)
=IF(C2>=60, "及格", "不及格")
=VLOOKUP(F2, A2:D31, 3, FALSE)
```

> 一个单元格里的内容以等号开头时，Excel 才把它当作公式处理：不带等号的 “SUM(B2:B31)” 只是一段普通文本。**先等号、后函数、参数进括号**，是公式的固定三段式。



#### 公式中的运算符

**运算符**按优先级从高到低分为四类，与数学习惯基本一致，但有几处 Excel 特有的规则。

- **算术运算符**：+ 加、- 减、* 乘、/ 除、% 百分比、^ 乘方。
- **比较运算符**：= 等于、> 大于、< 小于、>= 大于等于、<= 小于等于、<> 不等于，结果为 TRUE 或 FALSE。
- **文本连接符**：& 把两段文本拼在一起，如 “姓”&“名”。
- **引用运算符**：冒号（区域）、逗号（联合）、空格（交集）。

```text
=B2*1.1                      算术：涨 10%
=B2>=60                      比较：返回 TRUE 或 FALSE
=A2&"-"&B2                   文本连接：生成"姓-名"样式
=SUM(B2:B10) SUM(C2:C10)     两个区域的联合（逗号）
=A1:B5 B1:C5                 两个区域的交集（空格）
```

> [!IMPORTANT]
> **重要内容**：比较运算符 <> 表示**不等于**，写作一对尖括号——这是 Excel 公式与常见编程语言（如 JavaScript 的 !==）最直观的差异之一。文本连接一律用 **&**，不要依赖 CONCATENATE：& 更短、更直观，且能与区域外文本自由拼接。



#### 嵌套与换行

**嵌套**：把一个函数的返回值直接作为另一个函数的参数，是 Excel 公式组织复杂逻辑的唯一方式；嵌套过深时可配合换行提高可读性。

```text
=IF(B2>=85, "优秀", IF(B2>=60, "合格", "不合格"))
=IF(AND(C2>=60, D2>=60), "双科通过", "有科目未过")
```

> 编辑栏里按 **Alt 加回车** 可以给公式换行而不结束输入，长公式按逻辑段换行、缩进对齐，可读性远高于一行到底。嵌套层级建议控制在三层以内：超过三层时优先考虑拆分成辅助列，或改用 IFS、LET 简化（见系列第 3 篇与第 7 篇）。



### 单元格引用

#### 相对、绝对与混合引用

**引用方式**决定公式在复制、填充时如何自动调整指向，这是 Excel 公式体系的地基概念。

- **相对引用（A1）**：复制公式时**随位置平移**，向右复制变 B1，向下复制变 A2。
- **绝对引用（$A$1）**：行号列标前都加 $，复制时**纹丝不动**。
- **混合引用（$A1 或 A$1）**：只锁一方——$A1 锁列不锁行，A$1 锁行不锁列。
- **切换快捷键**：编辑公式时选中引用按 **F4**，在 A1 → $A$1 → A$1 → $A1 间循环切换。

```text
=B2*C2          相对：每行算自己的乘积，向下填充即可
=B2*$F$1        绝对：每行都乘 F1 里的税率，F1 固定不动
=$A2&B$1        混合：交叉表查值用的经典结构
```

> [!TIP]
> **建议内容**：判断该用哪种引用，只需问一句话——**公式复制到新位置后，这个参数应不应该跟着动**：跟着动的用相对，不动的一律加 $。写九九乘法表、交叉对照表这类“行列交叉”的公式，混合引用是标准答案。



#### 跨表与跨工作簿引用

**引用范围**可以超出当前单元格所在的工作表，语法要点如下：

- **同工作簿跨表**：表名加半角感叹号，如 =台账!B2；表名含空格时用单引号包住，如 ='案件台账'!B2。
- **跨工作簿**：再加方括号写文件名，如 =[汇总.xlsx]Sheet1!B2，两个文件同时打开时可用。
- **整列整行引用**：B:B 表示整列、3:3 表示整行，函数里可用，但建议配合表格结构化引用减少计算量。

```text
=台账!B2                 同簿跨表
='案件台账'!B2           表名含空格或中文标点时加单引号
=[汇总.xlsx]Sheet1!B2    跨工作簿
=SUM(C:C)                整列求和
```

> 跨工作簿引用在源文件移动、改名后会变成 #REF! 错误且难以追溯，**正式交付的台账尽量在同一工作簿内组织数据**，或用 Power Query 做外部数据导入。



#### 结构化引用与表格

**结构化引用（Structured Reference）**：把区域转换为“表格”（快捷键 **Ctrl 加 T**）后，用列名代替单元格地址书写公式。

```text
=SUM(台账[金额])                    金额列合计
=COUNTIF(台账[状态], "办结")        状态列计数
=[@金额]*[@数量]                    当前行的金额乘数量（逐行公式）
```

- 表格会**自动扩展**：在表格末尾新增一行，引用该表的所有公式、图表、数据验证自动覆盖新行。
- 列名代替 A2:A31，**公式含义一目了然**，新增列不会导致引用错位。
- [@列名] 表示当前行该列的值，是“逐行公式”的标准写法。

> [!IMPORTANT]
> **重要内容**：长账表、登记表一律先 **Ctrl 加 T 转成表格再写公式**。普通区域引用（A2:A31）在插入行、删除行后需要人工检查每一处公式，而表格的结构化引用自动跟随数据增减——这是减少“公式悄悄漏行”事故最有效的一招。



### 错误值

#### 七类错误值的含义

**错误值**：公式无法算出结果时返回的标记，以 # 开头。每个错误值对应一类固定病因，认错比改错更重要。

- **#DIV/0!**：除数为零或空单元格。
- **#VALUE!**：参数类型不对，如让 SUM 去加一段文本。
- **#REF!**：引用的单元格被删除，公式成了无源之水。
- **#NAME?**：函数名拼写错误，或引用了不存在的名称。
- **#N/A**：查找类函数找不到目标，是 VLOOKUP 最常见的返回。
- **#NUM!**：数值超出可接受范围，如对负数开平方。
- **#NULL!**：用了空格交集运算符但两个区域不相交。

```text
=B2/C2                 C2 为空或 0 时 → #DIV/0!
=VLOOKUP("王五", A2:D31, 2, FALSE)    名单里没有王五 → #N/A
=SUMM(B2:B10)          函数名打错 → #NAME?
```

> [!NOTE]
> **提醒内容**：#N/A 与其他错误性质不同——它往往不是“公式写错了”，而是**数据本身不存在**：查找值与被查找列存在多余空格、全半角差异是最常见诱因，先检查数据再怀疑公式。



#### 错误值的屏蔽与排查

**屏蔽错误**用 IFERROR 包装整条公式：正常时返回计算结果，出错时返回兜底值。

```text
=IFERROR(B2/C2, "")                    除零时显示空白
=IFERROR(VLOOKUP(F2, A2:D31, 3, FALSE), "未找到")
```

- **屏蔽是双刃剑**：IFERROR 会吞掉一切错误，公式写错（如 #NAME?）也被一起藏起来，排查难度加大。
- **排查顺序**：先看错误值类型 → 检查对应病因 → 用 F9 对公式分段求值定位问题参数。
- **分步求值**：编辑栏里选中公式的一段，按 **F9** 立即算出该段的值，按 Esc 退出不改公式。

> [!CAUTION]
> **注意内容**：交付他人的表格中，**查找类错误建议用 IFERROR 包住并给出“未找到”之类的中文提示**；但调试期不要急着包 IFERROR——错误值本身就是诊断信息，包得太早会把 #NAME?、#REF! 这类“真错误”一并掩埋。
