## 参考资料与延伸阅读

### 官方文档与规范

#### Redis 官方文档

**Redis 官方文档**（redis.io）：是查询 Redis 命令、数据类型、持久化、复制与集群等主题的**权威参考**，也是本主题判定命令行为的最终依据。

- 覆盖五大数据类型、拓展类型、持久化、高可用、安全等全部主题。
- 每条命令都提供**语法、参数、返回值、时间复杂度与版本历史**。

> 查命令行为先看官方文档，这是 Redis 世界的「标准答案」。命令语法与默认值在不同版本间有差异，阅读时注意文档顶部的版本选择器，与第 32 章的版本演进对照理解。



#### Redis 命令参考与中文命令文档

**官方命令索引**（redis.io/commands）与**黄健宏翻译的中文命令参考**（redisdoc.com）：是日常查命令的两大入口。

- 官方索引按功能分组，支持按版本筛选，永远最新。
- 中文版对应 Redis 早期稳定版，讲解细致、流传极广，适合配合《Redis 设计与实现》阅读。

> 中文版对应版本较旧，新命令（如 6.2 的 GETEX、7.0 的 ZRANGE 统一语法）以官方索引为准。本主题第 2 至 9 章的命令详解即逐条对照过这两份资料。



#### Redis 源码仓库

**Redis 源码仓库**（github.com/redis/redis）：是理解内部实现**最可靠的原始资料**，Redis 以 C 语言编写，核心文件划分清晰。

- **sds.c**：SDS 简单动态字符串的实现，对应第 10 章。
- **dict.c**：字典与渐进式 rehash 的实现，对应第 11 章。
- **t_zset.c**：跳表与有序集合的实现，对应第 12 章。
- **redis.conf**：官方配置文件样例，逐项注释含义与默认值，对应第 28、31 章。

> 源码阅读不必求全：带着第 10 至 13 章的问题去读对应文件，比通读高效得多。仓库默认分支为 unstable，读稳定实现可切换到对应版本 tag。



### 中文书籍与教程

#### 黄健宏《Redis 设计与实现》

**《Redis 设计与实现》**（黄健宏 著，机械工业出版社）：是中文世界讲解 Redis **内部实现**的经典书。

- 基于 Redis 3.0 源码，逐个讲解 SDS、字典、跳表、RDB、AOF、复制与哨兵等模块。
- 书稿网络版托管于 GitHub（github.com/huangzworks/redisbook），可免费在线阅读。

> 想知道「为什么这样设计」，这本书是首选。本主题第 10 至 20 章的底层结构、持久化与复制部分，多处参考了它的组织方式，适合配合精读。



#### 钱文品《Redis 深度历险》

**《Redis 深度历险：核心原理与应用实践》**（钱文品 著，电子工业出版社）：是**短平快建立全局认识**的实战向小书。

- 覆盖基础与应用、原理、集群、拓展、源码五大板块。
- 篇幅不大，适合快速通读建立框架，再回到本主题补细节。

> 先读它建立地图，再回本系列逐章深挖，是效率较高的组合。第 27 章分布式锁的「锁超时与续期」讲解思路与它一致。



#### 《Redis 实战》

**《Redis 实战》**（Josiah L. Carlson 著，黄健宏 译，人民邮电出版社）：是**面向工程应用**的经典书。

- 以真实场景为主线：计数器、搜索、社交、消息队列、分布式锁。
- 每个场景都给出完整的数据结构设计与代码实现。

> 做项目时对照翻阅价值最大。第 7 章排行榜、第 24 章消息队列、第 27 章分布式锁的场景设计，都可在书中找到更完整的展开。



#### 小林 coding《图解 Redis》

**《图解 Redis》**（小林 coding，xiaolincoding.com）：是**以手绘图讲解 Redis** 的高质量免费图解系列。

- 用大量图示讲解数据结构、持久化、主从、缓存异常与性能。
- 每篇配面试题视角的总结，图比文字直观。

> 图解系列适合建立直觉：跳表怎么跳、rehash 怎么搬、缓存三兄弟怎么区分，看图一遍胜过文字三遍。本主题第 11、12、25 章可与其对照阅读。



#### JavaGuide 的 Redis 板块

**JavaGuide**（javaguide.cn）：是面试导向的**开源中文知识库**，其中 Redis 部分覆盖主要考点。

- 问答式组织，覆盖缓存穿透、击穿、雪崩、分布式锁、持久化等高频问题。
- 内容持续更新，适合作为自检清单。

> 面试前用它查漏补缺很高效。本主题的考点式写法与它的问答视角互补：本系列讲「为什么」，它列「问什么」。



### GitHub 优质仓库

#### doocs/advanced-java

**doocs/advanced-java**（github.com/doocs/advanced-java）：是 GitHub 上**高星的中文后端进阶知识合集**。

- 把 Redis 放进高并发、分布式、高可用的大图景中讲解。
- 覆盖缓存模式、一致性、消息队列选型等架构级话题。

> 适合在掌握单点知识后向上拉视角：缓存一致性（第 26 章）、消息队列选型（第 24 章）都需放在整个后端架构里理解。



#### antirez 博客与 Redlock 论战原文

**antirez 博客**（antirez.com）：Redis 原作者 Salvatore Sanfilippo 的个人博客，保存着大量**第一手设计思考**。

- 单线程模型、数据结构选型、持久化取舍的原始论述。
- **Is Redlock safe?**（antirez.com/news/101）是对分布式锁安全性质疑的正式回应。

> 与之配套的是 Martin Kleppmann 的批评文章 **How to do distributed locking**（martin.kleppmann.com，2016 年）。先读批评、再读回应，结合第 27 章的实现自行判断安全边界，是分布式锁领域最值得通读的一组原文。



### 综合博客与工具

#### 美团技术团队博客

**美团技术团队博客**（tech.meituan.com）：是国内大厂中**缓存治理经验输出最多**的技术博客之一。

- 缓存穿透、击穿、雪崩的治理文章带真实案例与监控数据。
- 慢查询治理、大 key 清理等运维实践同样成体系。

> 大厂实践文章的价值在于「真实规模下的教训」。本主题第 25、29 章的对策与指标，可在其文章中找到生产级印证。



#### RedisInsight 与图形化客户端

**RedisInsight**（redis.io/insight）与 **Another Redis Desktop Manager**（github.com/qishibo/AnotherRedisDesktopManager）：是两款常用的图形化管理工具。

- **RedisInsight**：官方免费工具，支持数据浏览、慢日志分析与命令工作台。
- **Another Redis Desktop Manager**：开源轻量、跨平台，日常浏览键值顺手。

> 图形工具适合排查与演示，生产排障仍以 redis-cli 为主（详见第 28 章）。两者互补，不必二选一。



#### Redis University

**Redis University**（university.redis.io）：是 Redis 官方运营的**免费课程平台**。

- 提供从入门到数据建模、流处理等多门结构化课程。
- 由官方工程师授课，内容与版本演进同步。

> 适合喜欢跟课学习的方式：本系列读完后，可把它当作官方视角的复习课。Redis 迭代较快，命令行为与配置默认值一律以官方文档当前版本为准。
