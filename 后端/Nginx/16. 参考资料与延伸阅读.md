## 参考资料与延伸阅读

### 官方文档与规范

#### nginx.org 官方文档

**nginx.org 官方文档**：是 Nginx 官方维护的**权威文档站**，由原作者团队持续更新，是查询指令行为的首选来源。

- 指令提供**按模块**与**按字母**两种索引，每个指令页写明语法、默认值与可用上下文（http、server、location 等）。
- 内置变量、模块概览、安装与编译选项均有专页说明。

> 排查任何指令的**作用层级、默认值与继承关系**，先查这里。本主题涉及的 client_max_body_size、proxy_pass、try_files 等指令的准确行为，均以该站为准。

> 官方文档默认展示英文版，页面右上角可切换语言；中文翻译由志愿者维护，存在滞后，涉及新版本特性时以英文版为准。



#### http 各模块文档页

**模块文档页**：是 http 功能按模块拆分的说明书，每个模块一页，收录该模块的全部指令，是理解指令归属与组合关系的基础。

- **ngx_http_core_module**：核心模块，承载 location、root、alias、try_files 等基础指令。
- **ngx_http_proxy_module**：反向代理模块，proxy_pass、proxy_set_header、proxy_read_timeout 等都在这里。
- **ngx_http_gzip_module**：压缩模块，gzip、gzip_types、gzip_min_length 的出处。
- **ngx_http_upstream_module**：负载均衡与连接池模块，keepalive、权重与健康检查参数的定义处。

> 判断一条指令属于哪个模块，在模块页搜索最快；模块归属还决定了指令能与哪些模块组合，排查 if is evil 这类指令交互问题时尤其有用。入口地址：nginx.org/en/docs/http/。



#### nginx.com 官方博客与商业版文档

**nginx.com**：是 Nginx 官方公司的站点，提供**官方博客**与 NGINX Plus **商业版文档**。

- 官方博客持续发布配置实践、性能调优与安全加固的文章， How-to 系列由官方工程师撰写。
- 商业版文档涵盖开源版没有的动态上游、主动健康检查等特性，原理讲解部分对开源用户同样适用。

> 博客质量与时效都有保证，是开源文档之外的重要补充；涉及开源版指令行为时，仍以 nginx.org 为准。地址：nginx.com/blog/。



#### github.com/nginx/nginx 源码仓库

**nginx/nginx 源码仓库**：是 Nginx 的**官方代码仓库**，包含全部模块源码、变更日志与开发分支。

- 阅读源码可确认文档未写清的边界行为。
- Releases 与 changelog 是跟进版本特性与安全修复的第一手材料。

> 源码阅读适合进阶阶段：带着具体问题（如某个指令的解析流程）按模块定位源文件，比通读有效得多。地址：github.com/nginx/nginx。



### 中文书籍与课程

#### 《深入理解 Nginx：模块开发与架构解析》

**《深入理解 Nginx：模块开发与架构解析》**（陶辉著）：是讲解 **Nginx 架构与模块开发**的中文经典。

- 剖析 Nginx 的进程模型、事件驱动框架与内存管理。
- 系统讲解 HTTP 模块的编写方法，从配置解析到请求处理全流程。

> 这本书偏**架构与底层**：想弄清 Nginx 为什么快、master 与 worker 如何协作、模块如何挂接进请求流程，它是中文世界最系统的材料。运维与业务开发可按需选读，模块开发者建议通读。

> 阅读门槛不低：前半部分涉及大量操作系统与网络编程基础，感到吃力时可先跳过实现细节，抓住架构结论，日后再回补。



#### 《Nginx 核心知识 100 讲》

**《Nginx 核心知识 100 讲》**（陶辉在极客时间的专栏）：是体系化的**中文图文与视频课程**。

- 以 100 余讲覆盖核心架构、HTTP 模块、反向代理、缓存、负载均衡与运维实践。
- 每讲配套实验环境与示例代码，可直接动手复现。

> 专栏与上述书籍出自同一作者，课程形态更适合在职工程师按专题补课：时间紧张时按当前业务挑章节学，比啃整本书的门槛低。地址：time.geekbang.org（检索专栏名即可）。

> [!TIP]
> **建议内容**：学这门课时把每讲的实验在自己的测试机上跑一遍，配合本主题第 15 章的踩坑清单做对照实验，理解深度远胜只看文字。



### 社区教程与工具

#### agentzh 的 Nginx 教程系列

**agentzh（章亦春，OpenResty 作者）的 Nginx 教程**：是一组**深入 Nginx 与 Lua 运行原理**的系列文章。

- 从 Nginx 的事件模型、处理阶段讲到 cosocket、子请求等机制。
- 原作以博客连载，网络上另有爱好者整理的汇编版本，便于连续阅读。

> 这套教程的价值在于**讲透为什么**：很多官方文档一笔带过的执行顺序与阶段细节，在这里都有原理级拆解，是把 Nginx 用深之前必读的中文材料。

> 教程成文较早，个别结论对最新版本的适用性需对照官方文档核验，但事件模型与处理阶段等核心内容至今依然成立。



#### awesome-nginx

**awesome-nginx**：是 GitHub 上收录 **Nginx 相关资源**的合集仓库。

- 汇总官方资源、第三方模块、工具、教程与文章清单。
- 按类别组织，适合按需检索而非通读。

> 把它当**导航站**用：想找某个功能的第三方模块或现成配置范例时，先来这里扫一眼，往往比搜索引擎更快命中高质量结果。



#### Let's Encrypt 与 certbot 官网

**Let's Encrypt**（letsencrypt.org）：是提供**免费 TLS 证书**的自动化证书颁发机构；**certbot**（certbot.eff.org）是其官方推荐的**证书申请与续期客户端**。

- 证书有效期 90 天，靠 certbot 的定时任务自动续期。
- 站点提供 Nginx、Apache 等常见服务器的接入指引。

> 全站 HTTPS 已是默认要求，这套组合是个人与中小站点**零成本上线 TLS** 的标准做法；自动续期务必验证到位，避免证书到期导致服务中断。



#### SSL Labs 的 SSL Server Test

**SSL Labs 的 SSL Server Test**（ssllabs.com/ssltest）：是**在线评测 HTTPS 服务器 TLS 配置**的免费工具。

- 输入域名即可对证书链、协议版本、加密套件逐项检查，给出 A 到 F 的总评。
- 报告会标出弱协议、弱套件与常见配置缺陷。

> 配完 TLS 后到这里跑一次评分，按报告修复到 A 级以上，是检验证书与协议配置的**事实标准**。



#### nginxconfig.io

**nginxconfig.io**：是**可视化生成 Nginx 配置**的在线工具站。

- 通过表单选择域名、HTTPS、反向代理、缓存等选项，自动产出一份完整配置。
- 生成的配置附带文件组织建议（conf.d 拆分）与部署说明。

> 适合**起步与对照**：新手可拿它生成规范骨架再按需裁剪；有经验者可借它对照自己配置中遗漏的安全项（如安全响应头、TLS 参数）。



### 阅读路线建议

学习 Nginx 的资料虽多，路径却很清晰：**先官方文档、再架构书、后源码**，每一层解决一类问题。

- **第一步：官方文档打底**。遇到指令先查 nginx.org，把语法、默认值、可用上下文三个要素查清，配合本主题第 15 章的踩坑清单纠正直觉误区。
- **第二步：架构书建体系**。读《深入理解 Nginx：模块开发与架构解析》或《Nginx 核心知识 100 讲》，把零散的指令知识挂到进程模型与请求处理阶段的框架上。
- **第三步：源码验证细节**。带着具体问题进入 github.com/nginx/nginx 源码，确认文档含糊的边界行为；此阶段可结合 agentzh 教程理解设计动机。

> [!TIP]
> **建议内容**：学习与生产实践绑定最有效：每学一类指令（反代、缓存、限流、压缩），就在测试环境复现对应章节的踩坑场景，踩一次坑的记忆远胜十遍阅读。
