# 学习库（Learning Library）

一个**离线、单文件**的 Markdown 学习资料浏览器：把 `doc/` 下的全部笔记内嵌进一个 HTML 文件，双击即可在浏览器里阅读，无需起服务、无需联网。

界面复刻 Typora 的 **Vue 主题**（blinkfox），支持侧栏目录树、全文搜索、GFM 警示框与代码高亮。

## 特性

- **单文件离线**：所有 Markdown 原文、渲染器与高亮器全部内嵌进 `学习库.html`，直接以 `file://` 打开即可使用。
- **侧栏目录树**：按 `doc/` 的目录层级生成，文件夹可折叠；任意层级互斥展开（手风琴），目录在前、文件在后，按编号自然排序。
- **全文搜索**：按文件名与正文模糊匹配，文件名命中优先，结果带路径与高亮片段。
- **GFM 警示框**：完整支持 `NOTE` / `TIP` / `IMPORTANT` / `WARNING` / `CAUTION` 五类彩色提示卡片。
- **代码高亮**：基于 highlight.js，JS / CSS / HTML 等常见语言均可高亮。
- **站内跳转**：索引文件中的 `./N. 章节名.md` 链接可直接跳转到对应文档。

## 快速开始

```bash
# 安装依赖（仅构建需要）
npm install

# 构建单文件浏览器
npm run build

# 双击打开产物即可阅读
open 学习库.html      # macOS
```

> 产物 `学习库.html` 由构建生成、不入库。新增或修改 `doc/` 下的文档后，重新执行 `npm run build` 即可。

### doc 的组织约定

采用**领域 → 主题 → 章节**三层结构：

- **领域层**：2~4 字中文名词，如 `常识`、`法律`、`软件`。
- **主题层**：一门课/一个学科一个目录，目录名即学科名。
- **章节**：`0. 主题名.md` 为**目录索引**（固定编号 0），正文从 `1. 章节名.md` 起连续编号；编号不补零。
- 文件名、文档二级标题、索引条目显示名三者一致。

## 编写规范

`doc/` 下所有学习类文档统一遵循 `doc/编写规范.md`，要点：

- 不使用一级标题；一个文件有且只有一个二级标题，且位于首行，内容与文件名一致。
- 层级不跳级；标题不写编号；同级标题不重名。
- 同级标题之间空 3 行，标题与紧邻内容空 1 行；文件末尾单换行。
- 不使用 Markdown 表格与水平分隔线；二维数据拆成列表表达。
- 正文不使用行内代码反引号；整段可运行代码放进带语言标注的反引号围栏（唯一豁免）。
- 使用五类 GFM 警示框强调信息，正文首句以中文类型词加粗点题。
- 考点采用四段式：定义/结论先行 → 要素拆分 → 辨析与例外 → 速记线索。

## 常见问题

**为什么打开是旧内容？**
产物是构建时的快照。修改 `doc/` 后需重新 `npm run build`。

**为什么 Markdown 里带空格的链接能点？**
CommonMark 的链接不允许含空格，构建时渲染层会预处理把链接内的空格编码后再按文件名查表，因此索引里的 `./1. 章节名.md` 可正常跳转。

**可以直接把 学习库.html 发给别人吗？**
可以。产物自包含，拷贝单个文件即可离线阅读，无需任何环境。
