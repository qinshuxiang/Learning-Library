## 参考资料与延伸阅读

### 官方核心文档

- **Vue 官方文档**：Vue 学习的第一手权威资料，是本系列全部结论的最终依据。
  - 英文站 vuejs.org，中文站 cn.vuejs.org，覆盖指南、API 参考与交互式示例三大块。
  - 随版本持续更新，阅读时先确认页面顶部标注的版本线。
- **Vue 3 迁移指南**：面向从 Vue 2 迁移到 Vue 3 的官方手册（v3-migration.vuejs.org）。
  - 逐条列出破坏性变更、变更原因与对应的新写法。
  - 迁移存量项目时按目录逐节核对，比搜索零散文章可靠。
- **Vue Router 文档**：官方路由方案的完整文档（router.vuejs.org）。
  - 当前稳定线为 Router 4.4+，覆盖动态路由、嵌套路由、导航守卫与组合式 API 用法。
  - 与 Pinia 配合构成官方推荐的完整数据流方案。
- **Pinia 文档**：官方状态管理方案的文档（pinia.vuejs.org）。
  - 当前稳定线为 Pinia 3，覆盖 store 定义、组合式写法、getter 与 action、插件机制。
  - Vue 3 项目不再选用 Vuex 作为新方案，旧项目可参考官方迁移说明。

> 官方文档是学习 Vue 的第一优先级：本系列各篇的结论均以官方文档为准，第三方教程只能作为辅助视角，遇到分歧先查官方。



### 官方仓库

- **vuejs/core**：Vue 本体的源码仓库，运行时与编译器都在其中。
  - 读源码从这里开始，响应式系统在 packages/reactivity 目录。
  - releases 页可核对每个版本的发布记录。
- **vuejs/router**：Vue Router 的源码仓库。
  - issue 区常有核心团队对设计取舍的直接回应。
  - 文档站之外排查路由疑难时，这里是最深入的资料。
- **vuejs/pinia**：Pinia 的源码仓库。
  - 体量较小，适合作为阅读库源码的入门选择。
  - 核心实现集中在 store 相关模块，体量不大，可整读。
- **vuejs/create-vue**：官方脚手架仓库。
  - 基于 Vite 生成项目模板，是创建新项目的推荐入口。
  - 想了解官方推崇的项目结构，直接看它生成的模板即可。
- **vuejs/translations**：官方文档多语言翻译的组织仓库。
  - 中文文档对应其中的 vuejs-translations/docs-zh-cn 仓库。
  - 发现翻译问题可在该仓库提 issue，直接参与官方文档建设。

> 核对版本时间线最可靠的方式是阅读仓库的 releases 页：某一特性到底何时稳定，以发布记录为准，不要凭印象断言。



### 工具链

- **Vite**：官方推荐的构建工具（vitejs.dev）。
  - 开发期以原生 ESM 按需编译，启动与热更新极快。
  - 生产构建基于 Rollup，输出静态资源。
- **create-vue 脚手架**：执行 npm create vue@latest 创建项目。
  - 交互式选择 TypeScript、路由、状态管理、测试等配置。
  - 生成的模板即官方最佳实践的项目结构，新项目不必手工搭骨架。
- **Volar 与 vue-tsc**：Vue 生态的类型与语言支持核心。
  - Volar 为编辑器提供 Vue 文件的语言服务与接管功能。
  - vue-tsc 基于同一套语言服务执行类型检查，TypeScript 项目标配。
- **Vue DevTools**：浏览器调试扩展。
  - 可查看组件树、状态、路由与组合式 API 的运行时数据。
  - 调试状态流转问题时优先打开它，比反复打印直观得多。
- **Vitest**：官方推荐的测试框架。
  - 与 Vite 共享配置与转换管道，单元测试的首选。
  - 写法上兼容 Jest 风格，迁移成本低。



### 生态与延伸

- **VueUse**：社区著名的组合式工具集（github.com/vueuse/vueuse）。
  - 提供大量开箱即用的组合式函数，覆盖事件、存储、传感器等场景。
  - 按需导入，对打包体积友好，几乎零成本引入。
  - 也是学习组合式 API 高质量写法的范例库。
- **Nuxt**：基于 Vue 的元框架（nuxt.com）。
  - 提供服务端渲染、静态站点生成、文件式路由等全栈能力。
  - 需要 SEO 或全栈能力时再引入，纯客户端应用不必上。
- **组件库**：Element Plus、Ant Design Vue、Naive UI、Vuetify 等均提供 Vue 3 版本。
  - 选型时重点看维护活跃度、类型支持与设计风格契合度。
  - 本库点到为止，不逐个展开。

> [!TIP]
> **建议内容**：生态工具优先选择有官方或核心团队背书的项目，如组合式函数用 VueUse、测试用 Vitest，避免引入长期停更、与当前版本线脱节的库。

### 版本演进时间线

- **2020-09**：Vue 3.0.0 发布，组合式 API 正式落地，新响应式系统基于 Proxy 重写。
- **2021-08**：Vue 3.2 发布，script setup 转为稳定，单文件组件的实验性写法转正。
- **2023-12**：Vue 3.4 发布，defineModel 宏转为稳定。
- **2024-09**：Vue 3.5 发布，带来响应式 props 解构、useTemplateRef、useId、延迟 Teleport 等特性。
- **2025**：Pinia 3 与 Vue Router 4.4+ 相继稳定，生态全面对齐 Vue 3.5 线。
- **2026**：Vue 3.6 在研，核心方向为基于 alien signals 的响应式重构与 Vapor 无虚拟 DOM 编译模式。

> 时间线中的月份以官方发布记录为准，拿不准的条目只给年份；阅读旧教程时先核对版本，避免把实验阶段的写法当成稳定 API。
