## 数据导入导出与外部集成

### 数据导出

#### 导出格式与去向

**工作流数据的最终出口是导出块**：文件落地或远端上送。

- 导出数据块：把数据表导出为 CSV 或 JSON 文件
- 文件名支持表达式：{{ $date('YYYYMMDD') }}-result.csv 按日期命名
- 导出内容可选整表或指定列
- JSON 导出保留完整结构，CSV 适合表格软件继续加工

> 导出文件默认进浏览器下载目录：工作流跑在无头或服务器环境时，文件的落点与回收要单独设计。命名带日期是最省心的版本管理。

**速记**：**表格变文件，CSV 给人 JSON 给程序**。



### 外部集成

#### Google Sheets

**Google Sheets 是 Automa 最深度的外部集成**：读写双向。

- Google Sheets 块可读指定范围的数据进工作流
- 也可把数据表内容写回表格（追加或覆盖）
- 首次使用需完成 Google 账号授权
- 表达式关键字 googleSheets 可访问表格数据（6 篇数据源之一）

> 典型组合：Sheets 里维护任务清单（URL 列表、关键词），循环块逐行驱动页面操作，结果再写回表格的另一列。云表格当了数据库与协作面板双重角色。

**速记**：**Sheets 当库当面板，读驱动写回填**。



#### Webhook 与通知

**工作流可以向外发声**：Webhook 推送与桌面通知。

- Webhook 类块：向指定 URL 发 POST，把执行结果推给自己的服务
- 通知块：浏览器桌面通知，适合本地提醒
- 组合用法：抓取完成推企业机器人、异常结束发告警
- 推送体用表达式组装：结果数、时间戳、关键数据

> 无人值守任务的标配是“结束即通知”：成功推结果摘要，失败推错误信息。通知是工作流的回路反馈，缺了它，定时任务跑没跑成功全靠猜。

**速记**：**Webhook 找人，通知找己，结束必发声**。



#### 截图、剪贴板与 Cookie

**三件浏览器侧工具块补齐交互边界**：留证、传递与身份。

- 截图块：整页或指定元素截图保存，留证与巡检常用
- 剪贴板块：读写系统剪贴板，与本地工具交换数据的桥
- Cookie 块：读取或设置站点 Cookie，登录态迁移的抓手
- 三者输出都可进变量供后续块使用

> Cookie 操作与登录态强相关：复制已登录站点的 Cookie 到自动化环境，是最省事的鉴权手段，也要最克制地用——会话凭据属敏感数据，流转与保存都要有边界。

**速记**：**截图留证，剪贴板搭桥，Cookie 搬身份**。



### 组合模式

#### 外部数据驱动的完整链路

**一条完整的集成链路长这样**：外部进、页面跑、结果出。

- 进：Sheets 或 API 提供任务清单（Global Data、变量或表格）
- 跑：循环驱动页面操作，抓取结果累积进数据表
- 出：导出块落文件，Webhook 推摘要，Sheets 写回结果列
- 全程的失败信息单独记录，与成功数据分开通道

> 链路设计的原则是“数据有名字”：清单、结果、错误各自有变量或表格承载，任何一步失败都能从名字定位。链路越长，命名越重要。

**速记**：**进有清单，跑有累积，出有回执**。



#### 集成的安全边界

**外部集成引入了新的风险面**：凭据与数据两头都要管。

- 凭据（API 密钥、Google 授权）只存扩展的凭据管理，不硬编码进工作流
- 工作流分享前检查：JSON 里是否带个人数据与密钥
- Webhook 地址是推送入口，泄露即被灌垃圾，必要时签名校验
- Cookie 与登录态数据不进导出文件

> 分享是双刃剑：市场里的工作流造福他人，也可能无意间带出你的数据。导出 JSON 后用文本搜索过一遍密钥模式（token、key、authorization），三秒钟的检查习惯。

**速记**：**凭据进保险箱，分享前先搜密**。
