## SVG 进阶：文本、渐变、滤镜与动画

### 文本与排版

第 4 篇解决了形状与路径，本节处理图形上的文字。SVG 的文本是真实文本节点，既有坐标定位，也支持分段与沿路径排列。

#### text 元素与定位

**文本元素 text**：在指定坐标处绘制一段文字，x 与 y 决定基线起点，内容作为子文本节点参与选择与复制。

- x、y：文本起始点的坐标，y 是基线位置而非文字顶端。
- dx、dy：相对偏移，可在同一次定位中做微调。
- 真实节点：文字可被选中、复制，也能被搜索引擎与辅助技术读取。
- 沿路径：需要文字走曲线时改用 textPath 引用一条路径。

```html
<svg width="260" height="100" viewBox="0 0 260 100">
  <text x="20" y="40" font-size="18" fill="#333333">季度销售额</text>
  <text x="20" y="70" font-size="14" fill="#4a90d9" dx="4">单位：万元</text>
</svg>
```

**速记**：text 用 x、y 定位基线起点，文字是真实文本节点，可选中可读屏。



#### tspan 与 textPath 分段排版

**tspan 元素**：在 text 内部把文字分段并分别设置样式或位置；**textPath 元素**：让文字沿某条路径排布。

- tspan：可对片段单独设 font-weight、fill、dx、dy，实现同一行内的样式变化。
- textPath：通过 href 引用一条 path，文字沿该路径的走向排列。
- 起点控制：startOffset 指定文字在路径上的起始位置，可写长度或百分比。

```html
<svg width="300" height="140" viewBox="0 0 300 140">
  <text x="20" y="40" font-size="16" fill="#333333">
    <tspan font-weight="bold">总计</tspan><tspan fill="#e07b39"> 1286</tspan>
    <tspan font-size="12" fill="#888888"> 万元</tspan>
  </text>
  <defs><path id="arcPath" d="M20 110 A110 110 0 0 1 280 110" fill="none" /></defs>
  <text font-size="14" fill="#4a90d9">
    <textPath href="#arcPath" startOffset="8%">沿路径排列的刻度文字</textPath>
  </text>
</svg>
```

> [!NOTE]
> **提醒内容**：SVG 不支持按容器宽度自动折行，图表中的多行标签需要手动换行或改用 HTML 覆盖层，不能依赖 CSS 的换行属性。

**速记**：tspan 在同一行内分段改样式或位置，textPath 让文字沿指定路径排列。



#### 文本对齐与度量

**对齐属性**：text-anchor 控制文本相对给定坐标的水平对齐，dominant-baseline 控制垂直对齐基准。

- text-anchor：start 左对齐、middle 居中、end 右对齐，决定 x 坐标对应文字的哪一端。
- dominant-baseline：取值如 middle、central、hanging，用于把文字垂直居中在某个坐标上。
- 度量方法：getComputedTextLength() 返回当前文本渲染后的总长度，可用于排布与溢出判断。

```js
// 根据文本实测宽度决定是否截断并追加省略号
function fitLabel(textNode, maxWidth) {
  while (textNode.getComputedTextLength() > maxWidth && textNode.textContent.length > 1) {
    textNode.textContent = textNode.textContent.slice(0, -1);
  }
  textNode.textContent += "...";
  return textNode.textContent;
}
```

**速记**：text-anchor 定水平对齐、dominant-baseline 定垂直基准，getComputedTextLength 给出实测宽度。



### 渐变与图案

纯色填充无法表达连续变化，本节说明两类渐变与图案填充的定义方式与坐标参考。

#### 线性渐变与渐变单位

**linearGradient 元素**：定义沿一条直线从起点到终点过渡的颜色，用 stop 子元素给出各颜色停靠点。

- 方向：x1、y1 是起点，x2、y2 是终点，默认从 (0%, 0%) 到 (100%, 0%) 即水平向右。
- 停靠点：每个 stop 用 offset 指定位置，stop-color 给颜色，stop-opacity 给不透明度。
- 引用：渐变放在 defs 中并带 id，图形用 fill 加 url 引用该 id。
- 溢出处理：spreadMethod 取 pad、reflect、repeat，决定渐变范围之外如何延续。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <linearGradient id="barFill" x1="0" y1="0" x2="0" y2="1">
      <stop offset="0%" stop-color="#4a90d9" />
      <stop offset="100%" stop-color="#cfe3f7" />
    </linearGradient>
  </defs>
  <rect x="30" y="20" width="60" height="80" fill="url(#barFill)" />
</svg>
```

**速记**：linearGradient 用 x1、y1 与 x2、y2 定方向，stop 定颜色停靠点，spreadMethod 控溢出。



#### 径向渐变与坐标参考

**radialGradient 元素**：定义从一个中心点向外辐射的颜色过渡；**gradientUnits**：决定渐变坐标按元素包围盒还是按用户坐标系解释。

- cx、cy、r：定义渐变中心与半径。
- fx、fy：定义最亮点的位置，与中心错开可产生光照感。
- gradientUnits：objectBoundingBox 为默认值，坐标写 0 到 1 的相对比例；userSpaceOnUse 则使用用户坐标系的绝对数值。
- 选择依据：同一样式套用到不同尺寸的元素用相对比例，需要多元素共享同一渐变位置用绝对坐标。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <radialGradient id="bubbleFill" cx="0.35" cy="0.35" r="0.65">
      <stop offset="0%" stop-color="#ffffff" />
      <stop offset="60%" stop-color="#7a5cff" />
      <stop offset="100%" stop-color="#3f2c99" />
    </radialGradient>
  </defs>
  <circle cx="90" cy="60" r="45" fill="url(#bubbleFill)" />
  <circle cx="190" cy="60" r="30" fill="url(#bubbleFill)" />
</svg>
```

> [!WARNING]
> **警告内容**：渐变坐标默认按元素包围盒计算，把比例值误写成绝对数值时，不同尺寸的元素会呈现完全不同的渐变，跨元素复用前先确认 gradientUnits。

**速记**：radialGradient 用圆心与半径辐射过渡，gradientUnits 决定坐标按包围盒还是用户坐标系。



#### pattern 图案填充

**pattern 元素**：定义一块可重复的图案单元，作为填充时按周期平铺，适合纹理、斜线填充与点阵。

- patternUnits：图案单元自身的坐标单位，默认为 objectBoundingBox。
- patternContentUnits：图案内部内容的坐标单位，默认 userSpaceOnUse。
- 单元内容：图案内部可放形状、路径甚至文本，超出单元的部分会被裁掉。
- 用途：用斜线或点阵区分序列，在黑白打印场景替代颜色差异。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <pattern id="hatch" width="8" height="8" patternUnits="userSpaceOnUse"
             patternTransform="rotate(45)">
      <line x1="0" y1="0" x2="0" y2="8" stroke="#4a90d9" stroke-width="2" />
    </pattern>
  </defs>
  <rect x="30" y="20" width="200" height="80" fill="url(#hatch)" />
</svg>
```

**速记**：pattern 定义可平铺的图案单元，patternUnits 与 patternContentUnits 分别控制单元与内容的坐标。



### 裁剪与遮罩

有些效果需要按另一形状限制可见范围，本节说明裁剪与遮罩两种方式及其差别。

#### clipPath 裁剪路径

**clipPath 元素**：定义一条裁剪路径，引用它的元素只有落在路径内部的部分才显示，边界是硬边。

- clip-path：在元素上引用裁剪路径，取值为 url 加 id。
- 内容：clipPath 内可放形状与路径，它们只贡献几何轮廓，不参与显示。
- 单位：clipPathUnits 取 userSpaceOnUse 或 objectBoundingBox，决定裁剪路径的坐标参考。
- 裁剪依据：只按填充区域的几何裁剪，描边宽度不计入裁剪范围。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <clipPath id="roundClip">
      <rect x="30" y="20" width="200" height="80" rx="16" />
    </clipPath>
  </defs>
  <g clip-path="url(#roundClip)">
    <rect x="30" y="20" width="200" height="80" fill="#4a90d9" />
    <circle cx="60" cy="100" r="60" fill="#e07b39" fill-opacity="0.7" />
  </g>
</svg>
```

**速记**：clipPath 定义硬边可见区域，裁剪只按填充几何计算，描边宽度不参与。



#### mask 遮罩与透明度

**mask 元素**：定义一张亮度或透明度图，引用它的元素按该图逐点决定可见程度，边界可以是渐变的软边。

- mask：在元素上引用遮罩，取值为 url 加 id。
- 亮度模式：默认按遮罩内容的亮度决定可见度，白色全显、黑色全隐、灰色半透。
- 透明度模式：mask-type 设为 alpha 时改用遮罩内容的透明度决定可见度。
- 单位：maskUnits 与 maskContentUnits 控制遮罩区域与内容的坐标参考。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <linearGradient id="fadeGradient" x1="0" y1="0" x2="1" y2="0">
      <stop offset="0%" stop-color="#ffffff" />
      <stop offset="100%" stop-color="#000000" />
    </linearGradient>
    <mask id="fadeMask" maskUnits="userSpaceOnUse" x="0" y="0" width="260" height="120">
      <rect width="260" height="120" fill="url(#fadeGradient)" />
    </mask>
  </defs>
  <rect x="20" y="30" width="220" height="60" fill="#2fa36b" mask="url(#fadeMask)" />
</svg>
```

**速记**：mask 用亮度或透明度逐点决定可见度，可实现裁剪做不到的软边渐隐。



#### 裁剪与遮罩的选择

**选择依据**：裁剪给出非 0 即 1 的硬边可见性，遮罩给出 0 到 1 的连续可见度，两者成本与效果都不同。

- 边界效果：需要清晰边框用裁剪，需要淡出或渐隐用遮罩。
- 成本：裁剪只需几何判断，通常比逐像素计算的遮罩更省。
- 组合：裁剪先限制范围，遮罩再在范围内做渐变，两者可以叠加使用。
- 一点提醒：被裁剪或被遮罩的元素仍参与布局与事件命中，隐藏不等于删除。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <clipPath id="boxClip"><rect x="20" y="20" width="220" height="80" /></clipPath>
    <linearGradient id="softFade" x1="0" y1="1" x2="0" y2="0">
      <stop offset="0%" stop-color="#000000" />
      <stop offset="100%" stop-color="#ffffff" />
    </linearGradient>
    <mask id="softMask" maskUnits="userSpaceOnUse" x="0" y="0" width="260" height="120">
      <rect width="260" height="120" fill="url(#softFade)" />
    </mask>
  </defs>
  <rect x="20" y="20" width="220" height="80" fill="#7a5cff"
        clip-path="url(#boxClip)" mask="url(#softMask)" />
</svg>
```

> [!TIP]
> **建议内容**：做图表边缘渐隐时用遮罩处理一条边即可，不必给整块图形加滤镜；遮罩会触发额外的离屏合成，能省则省。

**速记**：裁剪是硬边布尔可见性，遮罩是连续可见度，淡出类效果优先考虑遮罩。



### 滤镜与视觉效果

SVG 的滤镜在浏览器内部对图形做像素级处理，本节说明滤镜元素的结构、常用基元与性能代价。

#### filter 元素与滤镜区域

**filter 元素**：把一组滤镜基元串成处理链，作用于引用它的元素；滤镜区域决定处理的范围。

- filter：在元素上引用滤镜，取值为 url 加 id。
- 基元链：滤镜内部按基元的书写顺序依次处理，前一个基元的输出作为后一个的输入。
- 区域属性：x、y、width、height 定义处理区域，默认向外扩展 10% 给模糊留出空间。
- 单位：filterUnits 与 primitiveUnits 分别控制滤镜区域与基元参数的坐标单位。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <filter id="softShadow" x="-20%" y="-20%" width="140%" height="140%">
      <feDropShadow dx="0" dy="3" stdDeviation="4" flood-color="#000000"
                    flood-opacity="0.35" />
    </filter>
  </defs>
  <rect x="60" y="30" width="140" height="60" rx="8" fill="#ffffff"
        filter="url(#softShadow)" />
</svg>
```

**速记**：filter 把基元串成处理链，区域属性决定处理范围，默认向外扩出一成。



#### 常用滤镜基元

**滤镜基元**：是滤镜链中的单个处理步骤，名称以 fe 开头，常见有模糊、偏移、合成、合并与阴影等。

- feGaussianBlur：按 stdDeviation 做高斯模糊，是柔化与投影效果的基础。
- feOffset：把输入整体平移 dx 与 dy。
- feMerge 与 feMergeNode：把多路输入叠在一起，常用于叠加阴影与原始图形。
- feDropShadow：一步生成投影，可指定偏移、模糊与颜色。
- feColorMatrix 与 feComposite：分别做颜色变换与合成，用于更精细的控制。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <filter id="blueGlow" x="-50%" y="-50%" width="200%" height="200%">
      <feGaussianBlur in="SourceGraphic" stdDeviation="6" result="glow" />
      <feMerge>
        <feMergeNode in="glow" />
        <feMergeNode in="SourceGraphic" />
      </feMerge>
    </filter>
  </defs>
  <circle cx="130" cy="60" r="30" fill="#4a90d9" filter="url(#blueGlow)" />
</svg>
```

> 基元的输入用 in 指定，默认取 SourceGraphic 即引用该滤镜的元素本身，用 result 可把中间结果命名供后续引用。

**速记**：feGaussianBlur 模糊、feOffset 偏移、feMerge 叠加、feDropShadow 一步投影，均可按 in 与 result 串联。



#### 滤镜的性能代价

**性能代价**：滤镜要求浏览器把图形栅格化到离屏缓冲区再逐像素处理，代价随区域面积与基元数量增长。

- 面积：滤镜区域越大，需要处理的像素越多，应把区域收紧到刚好覆盖效果。
- 链长：多个基元依次执行，每步都可能产生一次离屏绘制。
- 动画联动：滤镜元素发生动画时，每一帧都要重新计算滤镜结果。
- 规避：能用 fill-opacity、渐变或遮罩实现的柔和效果，就不必上滤镜。

```html
<!-- 收紧滤镜区域，避免整幅图重算 -->
<filter id="tightBlur" x="10%" y="10%" width="80%" height="80%">
  <feGaussianBlur stdDeviation="2" />
</filter>
```

> [!CAUTION]
> **注意内容**：对大量元素同时应用滤镜会让帧率明显下降，密集图形上的投影与模糊应改为预渲染或直接省略。

**速记**：滤镜在离屏缓冲里逐像素处理，代价随面积、基元数与动画帧增长，区域应尽量收紧。



### 动画的三种途径

静态图形之外，可视化常需要过渡与循环动画。SVG 上有声明式标记、CSS 与脚本三条途径，本节分别说明。

#### SMIL 声明式动画

**SMIL**：是 SVG 自带的声明式动画标记，通过 animate、animateTransform、animateMotion 等子元素让属性随时间取值。

- animate：改变某个属性，attributeName 指定属性名，from 与 to 给起止值，dur 给时长。
- animateTransform：专门改变 transform，type 指定 translate、rotate、scale 等。
- animateMotion：让元素沿一条路径运动，可用 path 或 mpath 指定轨迹。
- 控制参数：repeatCount 控制重复次数，fill 设为 freeze 可在结束后保持终值。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <circle cx="40" cy="60" r="14" fill="#4a90d9">
    <animate attributeName="cx" from="40" to="220" dur="2s" repeatCount="indefinite" />
  </circle>
  <rect x="100" y="80" width="40" height="24" fill="#e07b39">
    <animateTransform attributeName="transform" type="rotate"
                      from="0 120 92" to="360 120 92" dur="3s" repeatCount="indefinite" />
  </rect>
</svg>
```

**速记**：SMIL 用 animate、animateTransform 与 animateMotion 声明属性随时间变化，可控制重复与终值。



#### CSS 过渡与动画

**CSS 方案**：是把 SVG 的属性当作可过渡的样式，用 transition 与 keyframes 描述状态之间的变化。

- 可过渡属性：fill、stroke、stroke-width、opacity 等呈现属性可直接过渡。
- 变换参考：在 SVG 元素上使用 CSS 变换时，需要配合 transform-box 与 transform-origin 明确参考框与原点。
- 类切换：脚本只负责增删类名，动画节奏交给样式表，职责更清晰。
- 边界衔接：CSS 过渡与动画的一般原理详见 前端/CSS 主题第 13 篇至第 15 篇，此处只讲其在 SVG 上的落地。

```css
.series-bar { fill: #4a90d9; transition: fill 240ms ease; }
.series-bar.is-muted { fill: #c8c8c8; opacity: 0.5; }

.marker-pulse {
  transform-box: fill-box;
  transform-origin: center;
  animation: pulse 1.6s ease-in-out infinite;
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.25); }
}
```

**速记**：CSS 方案用 transition 与 keyframes 过渡呈现属性，SVG 变换需配合 transform-box 与 transform-origin。



#### JavaScript 与 Web Animations API

**脚本方案**：用 requestAnimationFrame 或 Web Animations API 按帧驱动属性，能表达依赖数据的复杂过渡。

- 逐帧驱动：requestAnimationFrame(callback) 在下一帧前调用回调，回调参数为时间戳，适合自定义缓动。
- 动画接口：element.animate(keyframes, options) 返回动画对象，可暂停、取消与查询播放状态。
- 插值对象：数据驱动的动画通常先插值数据，再按新数值重算坐标并写回属性。
- 分工建议：状态动画交给 CSS，依赖数据的形变交给脚本，两者可叠加。

```js
// 用缓动把柱子的高度从当前值过渡到目标值
function animateBarHeight(rectNode, fromHeight, toHeight, duration) {
  const start = performance.now();
  function step(now) {
    const raw = Math.min((now - start) / duration, 1);
    const eased = 1 - Math.pow(1 - raw, 3);
    const height = fromHeight + (toHeight - fromHeight) * eased;
    rectNode.setAttribute("height", height);
    rectNode.setAttribute("y", 100 - height);
    if (raw < 1) requestAnimationFrame(step);
  }
  requestAnimationFrame(step);
}
```

> 与 Canvas 的逐帧绘制相比，SVG 动画改的是元素属性，由浏览器负责重绘，二者性能特征不同，详见本主题第 8 篇 Canvas 动画与交互。

**速记**：requestAnimationFrame 适合自定义缓动，Web Animations API 提供可控的动画对象，数据形变优先脚本。



### 数据驱动 SVG 的常见手法

前面各节讲的是 SVG 的表达能力，本节把它与数据接起来：怎样创建节点、怎样映射坐标、怎样高效更新。

#### 用脚本创建 SVG 元素

**创建方式**：SVG 元素必须按命名空间创建，document.createElementNS(namespaceURI, qualifiedName) 才能得到可渲染的图形节点。

- 命名空间：SVG 的命名空间是 http://www.w3.org/2000/svg。
- 创建流程：createElementNS 传入命名空间与元素名，再用 setAttribute 写坐标与样式。
- 文本内容：文本节点可用 textContent 直接赋值。
- 追加顺序：节点顺序决定遮挡关系，后添加的覆盖先添加的。

```js
// 按数据创建一个矩形的简化示例
const svgNs = "http://www.w3.org/2000/svg";
const chartRoot = document.querySelector("#chart");

function createBar(x, y, width, height, color) {
  const bar = document.createElementNS(svgNs, "rect");
  bar.setAttribute("x", x);
  bar.setAttribute("y", y);
  bar.setAttribute("width", width);
  bar.setAttribute("height", height);
  bar.setAttribute("fill", color);
  return bar;
}

chartRoot.appendChild(createBar(20, 40, 40, 60, "#4a90d9"));
```

> [!IMPORTANT]
> **重要内容**：用 createElement 创建的 rect 属于 HTML 命名空间，浏览器不会把它当作 SVG 图形渲染；创建 SVG 节点必须使用 createElementNS。

**速记**：SVG 节点必须用 createElementNS 按命名空间创建，再用 setAttribute 写入属性。



#### 数据域到坐标域的映射

**比例尺**：是把数据取值范围映射到像素坐标范围的函数，是数据与图形之间的桥梁。

- 定义：给定数据域 domain 与坐标域 range，返回一个把数据值转成坐标值的函数。
- 方向：SVG 的 y 轴向下，数值越大越靠下时，range 通常写成较大值到 0 的反向区间。
- 离散映射：分类数据的取值用序数方式映射到等分位置或带宽区间。
- 复用：同一比例尺同时用于绘制与坐标轴，保证图形与刻度一致。

```js
// 线性映射：把 0 到 100 的数据映射到 0 到 200 的纵向像素
function createLinearScale(domainMin, domainMax, rangeMin, rangeMax) {
  const ratio = (rangeMax - rangeMin) / (domainMax - domainMin);
  return function mapValue(value) {
    return rangeMin + (value - domainMin) * ratio;
  };
}

const mapHeight = createLinearScale(0, 100, 0, 200);
console.log(mapHeight(25)); // 50
```

> 比例尺的完整体系与坐标轴生成详见本主题第 13 篇 D3：比例尺、坐标轴与布局，此处只给出最小可用模型。

**速记**：比例尺把数据域映射到坐标域，绘制与坐标轴共用同一个函数才能保持一致。



#### 更新、复用与分组策略

**更新策略**：是数据变化时决定哪些节点复用、哪些新建、哪些删除的规则，直接影响性能与动画连续性。

- 键绑定：给每个图形标记数据的唯一键，数据顺序变化时按键匹配而不是按下标匹配。
- 复用：数量增加时新建差额节点，数量减少时删除多余节点，其余只改属性。
- 分组：按图层放进不同的 g 元素，更新时按组批量处理，避免整棵树重排。

```js
// 按键复用已有节点，只处理缺失与多余的部分
function syncBars(container, data, keyOf, createNode) {
  const existing = new Map();
  container.querySelectorAll("[data-key]").forEach((node) => {
    existing.set(node.dataset.key, node);
  });
  data.forEach((item) => {
    const key = keyOf(item);
    if (!existing.has(key)) container.appendChild(createNode(item, key));
    existing.delete(key);
  });
  existing.forEach((node) => node.remove());
}
```

> 屏幕外的图形不必进入 DOM：数据量较大时先按可见范围与重叠程度筛选，再创建节点。

**速记**：节点用命名空间创建、坐标靠比例尺映射，更新时按键复用并按图层分组。
