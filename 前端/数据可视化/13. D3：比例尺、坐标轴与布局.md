## D3：比例尺、坐标轴与布局

### 比例尺种类与用法

比例尺负责把数据域的值换算为屏幕上的坐标或颜色。本节按数据类型给出常用比例尺与通用方法。

#### 连续比例尺：scaleLinear 与 scaleTime

**比例尺（scale）**：是数据域与视觉域之间的映射函数，输入数据取值，输出坐标、长度或颜色。

- 线性比例尺：d3.scaleLinear() 用于定量数据，domain 与 range 两个区间按比例对应。
- 时间比例尺：d3.scaleTime() 用于时间数据，domain 接收 Date 对象，内部按时间轴插值。
- 幂与对数：d3.scaleSqrt() 适合面积类视觉通道，d3.scaleLog() 适合跨数量级的数据。
- 取值方向：domain 与 range 的单调方向决定映射方向，range 反向即可让数值向下增长。

```js
const xScale = d3.scaleLinear().domain([0, 100]).range([0, 640]);
xScale(50); // 320

const yScale = d3.scaleLinear().domain([0, 100]).range([360, 0]);
yScale(0); // 360（纵轴向下增长，需反向 range）

const tScale = d3.scaleTime()
  .domain([new Date(2026, 0, 1), new Date(2026, 11, 31)])
  .range([0, 640]);
```

> 纵轴默认从画布底部向上增长，因此 range 常写成 [高度, 0]，这是坐标系差异导致的常见写法。

**速记**：scaleLinear 处理定量数据，scaleTime 处理时间数据，range 反向即可翻转坐标增长方向。



#### 离散比例尺：scaleBand、scalePoint 与 scaleOrdinal

**离散比例尺**：是把类别值映射为位置或非数值视觉属性的一类比例尺，输入为字符串或其他非数值标识。

- 分带比例尺：d3.scaleBand() 把类别映射为等宽区间，用 bandwidth() 取区间宽度，用 step() 取间距加宽度。
- 内边距：padding(ratio) 同时设置区间内与两端留白，paddingInner 与 paddingOuter 可分别设置。
- 点比例尺：d3.scalePoint() 把类别映射为单个位置点，适合散点与折线的类别轴。
- 序号比例尺：d3.scaleOrdinal() 把类别映射为颜色等任意取值，domain 可省略而按出现顺序分配。

```js
const bands = d3.scaleBand()
  .domain(["华东", "华北", "华南", "西南"])
  .range([0, 640])
  .padding(0.2);

bands("华东");        // 约 30.5，两端留白后的起点
bands.bandwidth();    // 约 121.9，区间实际宽度
bands.step();         // 约 152.4，相邻类别起点间距

const colors = d3.scaleOrdinal()
  .domain(["华东", "华北", "华南", "西南"])
  .range(d3.schemeTableau10);
```

> [!CAUTION]
> **注意内容**：把 scaleBand 用来映射连续的数值域会得到未定义的结果，类别轴之外的数值轴必须改用连续比例尺。

**速记**：scaleBand 给类别分配等宽区间并用 bandwidth 取宽，scalePoint 给类别分配点，scaleOrdinal 把类别映射为颜色。



#### 颜色与分段比例尺

**分段比例尺**：是把连续数值切成若干档，再为每档分配一个取值的比例尺，常用于分级设色。

- 顺序色：d3.scaleSequential(interpolator) 接收插值器，把定义域内的数值映射为连续颜色。
- 等分档：d3.scaleQuantize() 把 domain 均分为与 range 等长的若干档位。
- 自定义断点：d3.scaleThreshold() 用阈值数组切分，适合按业务标准分档。
- 色板来源：d3.interpolateBlues 等为连续插值器，d3.schemeBlues[5] 等为定长色板数组。

```js
const maxValue = d3.max(values, (d) => d.value);

const continuousColor = d3.scaleSequential()
  .domain([0, maxValue])
  .interpolator(d3.interpolateBlues);

const binnedColor = d3.scaleQuantize()
  .domain([0, maxValue])
  .range(d3.schemeBlues[5]);
```

> 连续色适合表达趋势，等分档适合表达等级；同一条数据用哪种，取决于读者要比较的是趋势还是档位。

**速记**：scaleSequential 走连续插值，scaleQuantize 均分档位，scaleThreshold 按自定义阈值分档。



### 坐标轴生成

坐标轴生成器把比例尺渲染为一组刻度与标签，省的自己算坐标。本节说明创建、刻度控制、位置摆放与更新。

#### 轴生成器的创建与调用

**轴生成器（axis generator）**：是 d3.axisBottom(scale)、d3.axisLeft(scale) 等函数返回的对象，接收比例尺，产出可绘制刻度线的组件。

- 方向对应：axisBottom 与 axisTop 用于横向比例尺，axisLeft 与 axisRight 用于纵向比例尺。
- 调用方式：轴生成器是函数而非选择集，必须用 selection.call(axis) 把选择集交给它。
- 容器：通常先追加一个 g 元素作为轴容器，再把轴画进去。
- 输出：在容器内生成刻度线、刻度文字与轴线三类子元素。

```js
const xAxis = d3.axisBottom(xScale);

svg.append("g")
  .attr("transform", "translate(0," + height + ")")
  .call(xAxis);
```

> 轴必须在比例尺的定义域确定之后再创建并调用，否则刻度会按旧的定义域生成。

**速记**：轴生成器由方向函数按比例尺创建，必须经 selection.call 调用并放入 g 容器。



#### 刻度与格式化控制

**刻度控制**：是设置刻度数量、位置、长度与文字格式的方法，用于让轴适配画布尺寸与数据特征。

- 数量：ticks(count) 给出建议数量，实际取值由比例尺按整齐端点决定。
- 指定值：tickValues(values) 直接给出刻度取值数组，覆盖自动计算。
- 格式：tickFormat(fn) 指定文字格式，时间轴常配合 d3.timeFormat 使用。
- 尺寸：tickSize(size) 设置刻度线长度，tickSizeOuter(0) 去掉两端多余刻度，tickPadding(px) 调整文字与轴线距离。

```js
const formatMonth = d3.timeFormat("%Y-%m");

d3.axisBottom(tScale)
  .ticks(d3.timeMonth.every(1))
  .tickFormat(formatMonth)
  .tickSize(-height)   // 负值生成贯穿绘图区的网格线
  .tickSizeOuter(0)
  .tickPadding(8);
```

> tickSize 传入负值会生成朝内的刻度线，把刻度文字隐藏后即可当作网格线使用。

**速记**：ticks 与 tickValues 控制刻度位置，tickFormat 控制文字，tickSize 与 tickPadding 控制外观。



#### 轴的重绘与更新

**轴重绘**：是数据或比例尺变化后刷新轴上刻度与标签的操作，做法是把轴生成器再次交给同一个容器。

- 复用容器：保存轴容器的选择集，重绘时对它再次调用 call，避免反复追加新的 g 元素。
- 过渡：轴生成器可在调用前接入过渡，使刻度位置平滑变化。
- 数量变化：刻度数量变化时，D3 会自动为多出的标签创建元素、为多余的标签移除元素。
- 标签宽度：数值范围变化会改变标签宽度，若左边距固定，需要自行按新范围调整。

```js
const yAxisGroup = svg.append("g").attr("class", "axis-y");

function renderAxis(scale) {
  yAxisGroup.transition().duration(400).call(d3.axisLeft(scale));
}

renderAxis(d3.scaleLinear().domain([0, 100]).range([innerHeight, 0]));
```

> [!CAUTION]
> **注意内容**：每次更新都新追加一个 g 容器再画轴，会把多套轴叠在同一位置，表现为文字加粗与刻度重影。

**速记**：轴重绘应复用同一个容器再次 call，追加新容器会叠出多套轴。



### 形状生成器

形状生成器把数据数组换算为路径字符串。本节说明折线与面积、弧与扇形、堆叠，以及曲线与符号。

#### 折线与面积：d3.line 与 d3.area

**形状生成器（shape generator）**：是接收数据数组、返回路径字符串的函数，配合 path 元素的 d 属性即可绘制。

- 折线：d3.line() 用 x 与 y 访问器给出每个点的坐标，返回完整路径字符串。
- 面积：d3.area() 在 x 的基础上用 y0 与 y1 给出上下边界，常用于堆叠面积与置信区间。
- 缺值：defined(predicate) 判定某个点是否参与绘制，返回假值处会断开路径。
- 复用：同一个生成器可用于多条折线，但每条线的数据需单独调用。
- 曲线与符号：生成器调用 curve(d3.curveMonotoneX) 可换成不过冲的平滑连线，d3.symbol().type(d3.symbolCircle).size(64) 把单个数据点画成固定图形。

```js
const lineGen = d3.line()
  .x((d) => xScale(d.date))
  .y((d) => yScale(d.value))
  .defined((d) => d.value != null);

const areaGen = d3.area()
  .x((d) => xScale(d.date))
  .y0(innerHeight)
  .y1((d) => yScale(d.value));

svg.append("path").attr("d", areaGen(series)).attr("fill", "#c9dcf2");
svg.append("path").attr("d", lineGen(series)).attr("fill", "none").attr("stroke", "#2f6fb5");
```

> 面积生成器必须显式给出 y0，省略时默认取 0，容易被误读为贴底。

**速记**：d3.line 用 x 与 y 生成折线路径，d3.area 用 y0 与 y1 生成面积边界，defined 用于断开缺值。



#### 弧与扇形：d3.arc 与 d3.pie

**角度生成器**：是把数值换算为起止角度的函数，d3.pie 负责算角度，d3.arc 负责把角度画成弧。

- 角度计算：d3.pie() 的 value 访问器决定每份占比，sort(null) 保持输入顺序，sortValues(null) 按原顺序保留。
- 半径映射：d3.arc() 用 innerRadius 与 outerRadius 区分饼图与环形图，取 0 即为实心饼图。
- 细节修饰：padAngle 设置扇区间隙，cornerRadius 设置圆角，centroid 返回标签锚点。
- 标签：d3.arc 的 centroid 方法给出扇区中心点，用于定位标签或引导线。

```js
const radius = Math.min(innerWidth, innerHeight) / 2;
const arcGen = d3.arc().innerRadius(radius * 0.6).outerRadius(radius);

const pieGen = d3.pie().value((d) => d.amount).sort(null);

svg.selectAll("path.slice")
  .data(pieGen(rows))
  .join("path")
  .attr("class", "slice")
  .attr("d", arcGen)
  .attr("transform", "translate(" + innerWidth / 2 + "," + innerHeight / 2 + ")")
  .attr("fill", (d) => colors(d.data.name));
```

> [!TIP]
> **建议内容**：饼图与环形图在切片超过五六个后很难比较，需要精确比较份额时改用按数值排序的条形图。

**速记**：d3.pie 算角度，d3.arc 把角度画成弧，innerRadius 决定饼图或环形图，centroid 用于标签定位。



#### 堆叠：d3.stack

**堆叠生成器**：是把多条序列累加成若干层的生成器，输出可直接交给 d3.area 绘制堆叠面积或堆叠条。

- keys：指定参与堆叠的字段名数组，决定层的数量与顺序。
- 取值：每个输出点是一个二元数组，下标 0 是层底、下标 1 是层顶，数据本身挂在 data 属性上。
- 顺序与偏移：order 决定层序，offset 决定累加方式，默认即普通堆叠。
- 绘制：把 y0 取下标 0、y1 取下标 1 交给面积生成器，即得堆叠面积。

```js
const stackGen = d3.stack()
  .keys(["直接访问", "搜索引擎", "推荐", "其他"])
  .order(d3.stackOrderNone)
  .offset(d3.stackOffsetNone);

const layers = stackGen(rows);
// layers[0][0] -> [底值, 顶值]，layers[0][0].data -> 原始记录

const stackedArea = d3.area()
  .x((d) => xScale(d.data.date))
  .y0((d) => yScale(d[0]))
  .y1((d) => yScale(d[1]));

svg.selectAll("path.layer")
  .data(layers)
  .join("path")
  .attr("class", "layer")
  .attr("d", stackedArea);
```

> 堆叠面积适合观察总量与构成变化，但中间层的绝对高度不易读取，需要时配合总量折线。

**速记**：d3.stack 按 keys 把多条序列累加成层，输出点以下标 0 与 1 给出上下边界，交给 d3.area 绘制。



### 布局模块

布局模块把原始数据整理成带坐标的中间结构，供绘制使用。本节说明层次、打包与矩形树、力导向三类布局。

#### 层次结构：d3.hierarchy 与 d3.tree

**层次布局**：是把嵌套数据整理为带父子关系的节点集合，再计算每个节点的位置。

- 构建：d3.hierarchy(data) 包装嵌套数据，sum 累加数值，sort 决定子节点顺序。
- 取值：descendants() 返回全部节点，links() 返回父子连线，leaves() 返回叶子节点。
- 坐标：d3.tree().size([width, height]) 计算节点位置，结果写在每个节点的 x 与 y 属性上。
- 径向：把 size 的横轴设为 2π 弧度、纵轴设为半径，即得径向树图。

```js
const root = d3.hierarchy(treeData)
  .sum((d) => d.value)
  .sort((a, b) => b.value - a.value);

const treeLayout = d3.tree().size([innerHeight, innerWidth]);
treeLayout(root);

root.links().forEach((link) => {
  // link.source 与 link.target 均带 x、y 坐标
  console.log(link.source.x, link.target.y);
});
```

> d3.tree 只计算坐标，不产生元素；绘制仍需自己用连接模式生成连线与节点。

**速记**：d3.hierarchy 把嵌套数据整理为节点集合，d3.tree 把坐标写回节点的 x 与 y，绘制需自行完成。



#### 打包与矩形树：d3.pack 与 d3.treemap

**面积填充布局**：是把数值映射为面积、再把区域划分给各节点的一类布局，d3.pack 用圆，d3.treemap 用矩形。

- 打包圆：d3.pack().size([width, height]).padding(px) 计算每个节点的圆心与半径。
- 绘制：圆的 cx、cy、r 直接取节点的 x、y 与 r。
- 矩形树：d3.treemap().size([width, height]) 计算每个节点的矩形，x0、y0、x1、y1 四个值界定范围。
- 分块算法：tile 设置分块方式，d3.treemapSquarify 倾向生成接近正方形的块，便于比较面积。

```js
const packed = d3.pack().size([innerWidth, innerHeight]).padding(4)(root);
const packedLeaves = packed.leaves();

svg.selectAll("circle.leaf")
  .data(packedLeaves)
  .join("circle")
  .attr("class", "leaf")
  .attr("cx", (d) => d.x)
  .attr("cy", (d) => d.y)
  .attr("r", (d) => d.r)
  .attr("fill", (d) => colorScale(d.value));

const treemapLayout = d3.treemap()
  .size([innerWidth, innerHeight])
  .paddingInner(2)
  .tile(d3.treemapSquarify);
treemapLayout(root);
// 每个节点带 x0、y0、x1、y1
```

> 面积类布局的数值必须按面积而非边长映射，否则大数值会被显著放大，形成视觉误导。

**速记**：d3.pack 把数值映射为圆面积，d3.treemap 映射为矩形面积，两者都只在节点上写坐标供绘制使用。



#### 力导向布局：d3.forceSimulation

**力导向布局**：是把节点视为受多种力作用的粒子、按时间步迭代求解位置的布局，适合关系网络。

- 创建：d3.forceSimulation(nodes) 返回模拟器，节点对象会被写入 x、y 与速度字段。
- 力的组合：forceLink 负责连线张力，forceManyBody 负责节点间斥力，forceCenter 保持整体居中，forceCollide 避免重叠。
- 迭代：on("tick") 在每一帧触发，用于按当前坐标更新元素位置。
- 调参：alpha 控制摆幅，alphaDecay 控制衰减速度，restart 与 stop 控制运行。

```js
const simulation = d3.forceSimulation(nodes)
  .force("link", d3.forceLink(links).id((d) => d.id).distance(60))
  .force("charge", d3.forceManyBody().strength(-120))
  .force("center", d3.forceCenter(innerWidth / 2, innerHeight / 2))
  .force("collide", d3.forceCollide(14));

simulation.on("tick", () => {
  linkSel.attr("x1", (d) => d.source.x).attr("y1", (d) => d.source.y)
    .attr("x2", (d) => d.target.x).attr("y2", (d) => d.target.y);
  nodeSel.attr("cx", (d) => d.x).attr("cy", (d) => d.y);
});
```

> [!WARNING]
> **警告内容**：模拟器会直接向传入的节点与连线对象写入坐标与速度字段，对同一份数据重复建模拟会互相干扰；节点数量很大时每帧开销显著上升，需要按需改用静态布局或聚合。

**速记**：力导向布局由多种力共同迭代求解，tick 时按节点坐标更新元素，模拟器会就地改写传入的数据对象。



### SVG 与 Canvas 两条渲染路径

D3 既生成 SVG 元素，也能把同一套计算交给 Canvas 绘制。本节说明两条路径的接入方式与选择判据。

#### 两条路径的接入方式

**接入方式**：是同一套数据与比例尺分别对接 DOM 元素与绘图上下文的两种写法。

- SVG 路径：选择集生成元素，形状生成器返回的路径字符串写入 d 属性。
- Canvas 路径：把绘图上下文传给生成器的 context 方法，调用生成器即向上下文发出路径指令。
- 上下文获取：由画布的 getContext("2d") 拿到上下文，绘制前需自行清空并开始新路径。
- 共用部分：比例尺、数据整理、布局与颜色换算在两条路径下完全一致。
- 能力差异：Canvas 没有可查询的元素树，选择集、attr、过渡与元素级事件都不适用于图形本身，样式改由上下文属性控制，命中检测需自行按坐标反算。

```js
const canvas = document.getElementById("plot");
const ctx = canvas.getContext("2d");

// 同一个折线生成器改为向 Canvas 上下文输出
const canvasLine = d3.line()
  .x((d) => xScale(d.date))
  .y((d) => yScale(d.value))
  .context(ctx);

function renderCanvas(series) {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.beginPath();
  canvasLine(series);
  ctx.strokeStyle = "#2f6fb5";
  ctx.lineWidth = 2;
  ctx.stroke();
}
```

> 生成器的 context 方法一旦设置，调用生成器不再返回路径字符串，而是直接向上下文画线，取值时需留意这一差别。

**速记**：SVG 路径把路径字符串写入 d 属性，Canvas 路径给生成器设置 context 后直接发指令，计算部分完全共用。



#### 路径选择的判据

**选择判据**：是按图形数量、交互需求与导出要求决定使用哪条路径，必要时同一页面混用。

- 图形数量：数百个以内的元素用 SVG 便于维护，上千个元素用 Canvas 更稳。
- 交互精度：需要逐元素悬停、点击与无障碍语义时用 SVG。
- 动画方式：SVG 可用属性与样式过渡，Canvas 需要自行重绘每一帧。
- 混用方案：底层大批量图形用 Canvas，顶层少量标注与交互热区用 SVG 叠加。

```js
function shouldUseCanvas(pointCount, needPerElementInteraction) {
  if (needPerElementInteraction) return false;
  return pointCount > 1000;
}
```

> 两条路径并不互斥：把静态底图放在 Canvas、把坐标轴与提示层放在 SVG，是常见的高性能组合。

**速记**：按图形数量、交互粒度与导出形式选路径，少量图形要交互用 SVG，大量图形用 Canvas，也可分层混用。



### 常见陷阱

前面的机制在实际使用中会产生若干固定类型的错误。本节按比例尺、坐标轴、过渡与布局三类汇总。

#### 比例尺与数据类型的陷阱

**类型陷阱**：是从数据源读入的取值类型与比例尺期望的类型不一致，导致映射结果异常。

- 字符串数值：从 CSV 读入的数值是字符串，做加法会拼接，需先做数值转换。
- 类别缺失：scaleBand 的定义域必须包含所有出现的类别，漏掉的取值会映射为未定义。
- 面积映射：半径按数值线性映射会让面积按平方增长，面积类视觉通道应使用平方根比例尺。
- 空数组：d3.extent 对空数组返回未定义，需要给出兜底定义域，否则刻度无从计算。

```js
// 从 CSV 读入的数值是字符串
const rows = [{ value: "10" }, { value: "20" }];

// 错误：字符串相加变成拼接，结果是 "01020"
const badTotal = rows.reduce((sum, d) => sum + d.value, 0);

// 正确：先转换为数值再求和，结果是 30
const goodTotal = rows.reduce((sum, d) => sum + Number(d.value), 0);

const radiusScale = d3.scaleSqrt().domain([0, d3.max(rows, (d) => Number(d.value))]).range([0, 40]);
```

> 从文件读入的数据几乎都需要显式转换类型，把转换集中在一处，比散布在绘制代码里更易排查。

**速记**：数值先转换再计算，类别定义域要覆盖全部取值，面积通道用平方根比例尺，空数组要兜底。



#### 坐标轴与选择集的陷阱

**轴与选择集陷阱**：是把轴生成器当作选择集使用，或未按层级正确建立父子选择关系造成的错误。

- 调用方式：轴生成器必须经 call 执行，不能像选择集那样链式调用 attr。
- 容器复用：每次重绘追加新容器会堆叠出多套轴，应保存容器选择集重复使用。
- 选择范围：selectAll 的作用范围限定在已选元素的子孙节点，跨容器查询会得到空选择集。
- 元素顺序：同一层级内后追加的元素覆盖先追加的元素，绘制顺序需按覆盖关系安排。

```js
// 错误：把轴生成器当成选择集用
// d3.axisBottom(xScale).attr("transform", "translate(0,320)");

// 正确：先建容器再调用
svg.append("g")
  .attr("transform", "translate(0," + innerHeight + ")")
  .call(d3.axisBottom(xScale));
```

> [!WARNING]
> **警告内容**：为放大差异而截断纵轴起点、让半径正比于数值、或把两条量纲不同的曲线对齐到同一纵轴，都会造成误读，属于必须避免的错误做法而非技巧。

**速记**：轴生成器必须经 call 调用，容器需复用，选择范围限定在子孙节点，截断纵轴与半径正比数值属误导做法。
