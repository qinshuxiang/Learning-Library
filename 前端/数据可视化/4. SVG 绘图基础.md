## SVG 绘图基础

### SVG 是什么与使用方式

SVG 是浏览器原生支持的矢量绘制底座，图表库在底层通常落到 SVG 或 Canvas 之上。本节先给出定义与特点，再说明引入页面的方式，最后划清与位图及 Canvas 的边界。

#### SVG 的定义与特点

**SVG（Scalable Vector Graphics，可缩放矢量图形）**：是用 XML 描述二维图形的矢量格式，图形由形状、路径与文本等元素构成，可内联进 HTML 并作为 DOM 参与样式与脚本。

- 矢量性：保存的是几何描述而非像素，缩放与打印都不产生锯齿。
- 结构性：每个图形是独立元素节点，可被 CSS 选中、被脚本改写、被事件监听。
- 文本性：文件是纯文本，可压缩、可做版本对比，也便于搜索引擎与辅助技术读取。
- 坐标系：图形绘制在用户坐标系中，坐标是数值，默认按像素等长理解。

```html
<svg width="240" height="120" viewBox="0 0 240 120" role="img" aria-label="柱状图示例">
  <rect x="20" y="40" width="40" height="60" fill="#4a90d9" />
  <rect x="80" y="20" width="40" height="80" fill="#4a90d9" />
  <rect x="140" y="60" width="40" height="40" fill="#4a90d9" />
</svg>
```

**速记**：SVG 用 XML 描述二维矢量，图形即 DOM，可缩放、可样式化、可脚本操作。



#### 在网页中引入 SVG 的几种方式

**引入方式**：是把 SVG 放进页面的途径，常见有内联、图片引用、CSS 背景与外部文档四类，区别在于是否参与 DOM 与脚本。

- 内联：把 svg 元素直接写进 HTML，是唯一能被 CSS 与脚本直接操作的方式，图表场景首选。
- 图片引用：用 img 元素的 src 指向 .svg 文件，浏览器按图片处理，内部元素不可由外部脚本访问。
- CSS 背景：作为背景图使用，适合装饰性图标，同样无法操作内部元素。
- 外部文档：用 object 或 iframe 嵌入，内部有独立文档上下文，交互与脚本被隔离。

```html
<!-- 内联：元素在页面 DOM 中，可直接查询与绑定事件 -->
<svg viewBox="0 0 100 100" width="80" height="80">
  <circle cx="50" cy="50" r="40" fill="#e07b39" />
</svg>

<!-- 图片引用：整体作为一张图片，内部元素对外部脚本不可见 -->
<img src="./chart.svg" width="80" height="80" alt="示例图表" />
```

> 只有内联方式能让脚本访问到内部元素；需要按数据改图时，内联是前提，其余方式只能整体替换文件。

**速记**：内联可脚本化、可样式化，图片与背景方式只能整体替换。



#### 与位图及 Canvas 的边界

**位图**：是以像素矩阵记录图像的方式；**Canvas**：是提供位图画布并由脚本逐帧绘制的元素。SVG 与后两者的差异决定了各自适用的图形规模与交互方式。

- 与位图相比：SVG 记录几何、可无损缩放，但在像素级滤镜与照片处理上不占优。
- 与 Canvas 相比：SVG 的每个图形常驻 DOM，便于事件与无障碍；Canvas 只保留像素，元素再多也不增加 DOM 负担。
- 选择倾向：元素数量不大、需要事件与可访问性时用 SVG；海量元素或逐帧重绘时用 Canvas。
- 组合使用：同一页面可让 SVG 承担坐标轴与标注，让 Canvas 承担密集点集。

```html
<!-- 同一页面里两种底座各司其职 -->
<svg class="axis-layer" viewBox="0 0 400 240"><!-- 坐标轴与文字 --></svg>
<canvas class="point-layer" width="400" height="240"></canvas>
```

> [!NOTE]
> **提醒内容**：Canvas 与 WebGL 的绘制机制在本系列第 6 篇至第 9 篇展开，本篇只建立边界认知，不比较具体 API。

**速记**：SVG 保结构、Canvas 保像素，前者重交互与可访问性，后者重密度与帧率。



### 坐标系与视口

引入方式确定后，下一个问题是图形画在哪里。本节说明用户坐标系的方向、viewBox 视口框的作用，以及缩放时的对齐规则。

#### 用户坐标系的方向与单位

**用户坐标系**：是 svg 元素内部使用的坐标系统，原点在左上角，x 轴向右递增，y 轴向下递增，坐标数值默认按像素等长理解。

- 原点位置：左上角为 (0, 0)，与常见数学坐标系不同，纵向向下为正。
- 坐标数值：写成不带单位的数字，也允许写 px、cm 等长度单位，无单位时按用户单位处理。
- 根元素尺寸：width 与 height 决定元素在页面中的显示尺寸。
- 默认范围：未设置 viewBox 时，可见坐标范围即由 width 与 height 决定。

```html
<!-- 原点在左上角，纵向向下为正 -->
<svg width="200" height="120">
  <circle cx="0" cy="0" r="30" fill="#7a5cff" />
  <circle cx="200" cy="120" r="30" fill="#2fa36b" />
</svg>
```

**速记**：用户坐标系原点在左上角，x 向右、y 向下，数值默认按像素理解。



#### viewBox 视口框与缩放

**viewBox 视口框**：是 svg 元素上声明「用户坐标系中哪一块区域映射到元素显示区域」的属性，取值为四个数字 minX、minY、width、height。

- 含义：前两个是区域左上角坐标，后两个是区域宽高。
- 缩放：显示区域与 viewBox 比例不一致时，浏览器自动做等比例缩放。
- 常用写法：让 viewBox 从 0 0 开始，宽高等于逻辑画布尺寸，图形坐标基于该尺寸设计。
- 不设 viewBox：坐标直接等同于显示像素，缩放时图形不会自行放大。

```html
<!-- 逻辑画布 800x400，缩放到 400 宽显示仍不模糊 -->
<svg width="400" height="200" viewBox="0 0 800 400">
  <rect x="40" y="40" width="320" height="320" fill="#4a90d9" />
</svg>
```

> viewBox 定义的是逻辑尺寸，width 与 height 定义的是显示尺寸，两者分离是 SVG 适配不同容器的基础。

**速记**：viewBox 用四个数字圈定逻辑区域并映射到显示区域，实现等比缩放。



#### preserveAspectRatio 与对齐方式

**preserveAspectRatio**：是控制 viewBox 与显示区域宽高比不一致时如何缩放与对齐的属性，默认值 xMidYMid meet。

- meet：完整显示 viewBox 内容，多余方向留白，不裁切。
- slice：铺满显示区域，超出部分被裁切。
- 对齐：取值形如 xMidYMid，前半控制水平对齐，后半控制垂直对齐，两段都可取 Min、Mid、Max。
- none：不保持宽高比，两个方向各自拉伸，会造成图形变形。

```html
<!-- 保持比例并居中，两侧留白 -->
<svg width="300" height="200" viewBox="0 0 100 100"
     preserveAspectRatio="xMidYMid meet">
  <circle cx="50" cy="50" r="45" fill="#e07b39" />
</svg>
```

> [!WARNING]
> **警告内容**：把 preserveAspectRatio 设为 none 会让图形随容器比例变形，饼图会被拉成椭圆，除非明确要求拉伸，否则不要使用该值。

**速记**：preserveAspectRatio 决定缩放时保持比例还是拉伸，默认居中且完整显示。



### 基本形状元素

有了坐标系，就可以放置图形。SVG 提供若干预设形状元素，覆盖矩形、圆形、直线与多边形等常见需求，本节逐个说明其属性。

#### 矩形 rect 与圆角

**矩形元素 rect**：用于绘制轴对齐矩形，(x, y) 为左上角坐标，width 与 height 为宽高；rx 与 ry 控制圆角半径。

- x、y：矩形左上角坐标，省略时默认为 0。
- width、height：矩形宽高，负值无效，为 0 时不绘制。
- rx、ry：圆角在 x 与 y 方向的半径；只写 rx 时 ry 取同值，形成正圆角。
- 常见用途：柱状图的柱子、背景块与图例色块。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <rect x="10" y="20" width="80" height="80" fill="#4a90d9" />
  <rect x="110" y="20" width="80" height="80" rx="12" fill="#2fa36b" />
  <rect x="110" y="20" width="80" height="80" rx="12" fill="none"
        stroke="#1f6b45" stroke-width="3" />
</svg>
```

**速记**：rect 由 x、y、width、height 定位定尺寸，rx 与 ry 给出圆角。



#### 圆、椭圆与直线

**圆元素 circle**：以 (cx, cy) 为圆心、r 为半径；**椭圆元素 ellipse**：以 (cx, cy) 为中心、rx 与 ry 为两个半轴；**直线元素 line**：从 (x1, y1) 到 (x2, y2)。

- circle：只需圆心与半径三个参数，适合散点与圆点标记。
- ellipse：rx 与 ry 不相等时即为椭圆，适合气泡图的气泡。
- line：只有描边没有填充，必须设置 stroke 才可见。
- 省略坐标：cx、cy、x1、y1 等默认取 0。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <circle cx="50" cy="60" r="30" fill="#7a5cff" />
  <ellipse cx="130" cy="60" rx="40" ry="24" fill="#e07b39" />
  <line x1="190" y1="30" x2="250" y2="90" stroke="#333333" stroke-width="3" />
</svg>
```

> [!CAUTION]
> **注意内容**：line 元素没有面积，只写 fill 不会显示，必须给 stroke；circle 与 ellipse 相反，描边与填充可以同时存在。

**速记**：circle 用圆心与半径，ellipse 用圆心与两半轴，line 只有两端点且依赖描边。



#### 折线与多边形

**折线元素 polyline**：按 points 给出的点序列依次连线，不自动闭合；**多边形元素 polygon**：与折线相同，但会自动把末点连回首点。

- points：形如 x1,y1 x2,y2 的坐标对列表，逗号与空格可以混用。
- 自动闭合：polygon 闭合区域可填充，polyline 通常只用于描边。
- 常见用途：折线图的折线用 polyline，面积图或雷达图的封闭区域用 polygon。
- 点数规模：点数越多路径越复杂，超过千级坐标点时应考虑改用 path。

```html
<svg width="300" height="140" viewBox="0 0 300 140">
  <polyline points="20,120 80,60 140,90 200,30 260,70"
            fill="none" stroke="#4a90d9" stroke-width="3" />
  <polygon points="20,120 80,60 140,90 200,30 260,70 260,130 20,130"
           fill="#4a90d9" fill-opacity="0.25" />
</svg>
```

**速记**：polyline 连点不闭合适合折线，polygon 自动闭合可填充，两者都靠 points 描述。



### 路径 path 的指令集

形状元素只能表达规则图形，任意轮廓需要 path。本节说明 d 属性的组织方式，以及直线、曲线、圆弧三类指令的写法。

#### path 与 d 属性

**路径元素 path**：用一条或多条子路径描述任意二维轮廓，所有几何信息写在 d 属性里，d 是一串指令字母与坐标参数的组合。

- 指令字母：大写表示绝对坐标，小写表示相对上一点的坐标。
- 参数：跟在字母之后，多个参数用空格或逗号分隔，参数个数由指令决定。
- 子路径：每个 M 开启一条子路径，多条子路径可以不相连，用于挖空与多个轮廓。
- 填充规则：fill-rule 取 nonzero 或 evenodd，决定重叠区域算不算内部。

```html
<!-- 一个带内孔的矩形，借助填充规则挖空 -->
<svg width="200" height="120" viewBox="0 0 200 120">
  <path d="M20 20 H180 V100 H20 Z M60 45 H140 V75 H60 Z"
        fill="#4a90d9" fill-rule="evenodd" />
</svg>
```

**速记**：path 用 d 属性表达任意轮廓，字母定指令、大小写定绝对与相对，M 开启子路径。



#### 直线与闭合指令 M、L、H、V、Z

**直线类指令**：M 移动到起点、L 连线到指定点、H 水平连线、V 垂直连线、Z 闭合当前子路径。

- M x y：把画笔移到新位置，不产生线段，通常是路径的第一个指令。
- L x y：从当前点画直线到 (x, y)。
- H x 与 V y：只给一个坐标的水平与垂直线，适合画直角轮廓。
- Z：从当前点连回本子路径起点，用于闭合多边形。

```html
<!-- 阶梯线：M 起步，H 与 V 交替走直角，Z 收口 -->
<svg width="260" height="120" viewBox="0 0 260 120">
  <path d="M20 100 H70 V60 H120 V80 H170 V40 H220 V100 Z"
        fill="none" stroke="#2fa36b" stroke-width="3" />
</svg>
```

**速记**：M 定位、L 连线、H 与 V 走直角、Z 闭合，是构成折线与轮廓的基础指令。



#### 曲线指令 C、S、Q、T

**贝塞尔曲线指令**：C 用两个控制点与一个终点画三次曲线、S 顺接三次曲线、Q 用一个控制点与终点画二次曲线、T 顺接二次曲线。

- C x1 y1 x2 y2 x y：前两组是控制点，最后一组是终点，控制点越远弯曲越强。
- S x2 y2 x y：省略的第一个控制点由上一段三次曲线自动镜像得到，用于连续平滑。
- Q x1 y1 x y：一个控制点加终点，次数低，画弧顶更直观。
- T x y：顺接二次曲线，控制点自动镜像，适合连续的平滑起伏。

```html
<!-- 三次曲线与二次曲线各画一条 -->
<svg width="280" height="120" viewBox="0 0 280 120">
  <path d="M20 100 C60 20 120 20 160 100"
        fill="none" stroke="#4a90d9" stroke-width="3" />
  <path d="M170 100 Q210 20 250 100"
        fill="none" stroke="#e07b39" stroke-width="3" />
</svg>
```

> [!TIP]
> **建议内容**：折线图改用平滑曲线时，用 S 或 T 顺接比手工计算每个控制点更省事，但曲线会改变数据点的视觉读数，需在图表中说明。

**速记**：C 与 Q 各用两个与一个控制点画曲线，S 与 T 复用上一段的控制点实现平滑衔接。



#### 圆弧指令 A 与相对坐标

**圆弧指令 A**：以椭圆弧连接当前点与终点，参数依次为 rx、ry、x 轴旋转角、大弧标志、扫描标志与终点坐标。

- rx、ry：椭圆的两个半轴，半径过小时会被浏览器自动放大到能连接两点。
- 旋转角：椭圆相对 x 轴旋转的角度，单位为度。
- 大弧标志：0 取小弧，1 取大弧。
- 扫描标志：0 逆时针、1 顺时针，决定走哪一侧。
- 相对坐标：把小写字母用于所有指令，可让路径基于上一点增量描述，便于程序生成。

```html
<!-- 用两段圆弧拼出饼图扇区的简化示意 -->
<svg width="200" height="140" viewBox="0 0 200 140">
  <path d="M100 70 L100 10 A60 60 0 1 1 40 70 Z" fill="#7a5cff" />
</svg>
```

> [!IMPORTANT]
> **重要内容**：A 指令的参数顺序固定为 rx ry 旋转角 大弧标志 扫描标志 x y，参数错位会画出完全不同的弧，程序生成时应逐项核对。

**速记**：A 用两个半轴、旋转角、两个标志位与终点定义弧，小写指令可改用相对坐标。



### 分组、变换与复用

路径与形状可以直接摆放，但成组管理、统一变换与重复使用需要额外机制。本节说明分组、变换与复用元素。

#### g 元素与分组

**分组元素 g**：把若干子元素组织为一个整体，样式、变换与事件可作用于整组。

- 继承：组上的 fill、stroke、opacity 等属性会被未自行设置的子元素继承。
- 变换：组上的 transform 一次性作用于全部子元素。
- 组织：按图层或语义分层，脚本按组查询与更新，减少逐个节点操作。
- 事件：组上绑定的事件可捕获子元素冒泡上来的交互。

```html
<svg width="240" height="120" viewBox="0 0 240 120">
  <g fill="#4a90d9" stroke="#1f5c93" stroke-width="2">
    <rect x="20" y="30" width="50" height="60" />
    <rect x="90" y="30" width="50" height="60" />
    <rect x="160" y="30" width="50" height="60" />
  </g>
</svg>
```

**速记**：g 把子元素合成整体，统一继承样式、共享变换、集中绑定事件。



#### 变换函数与叠加顺序

**transform 属性**：接受一串变换函数，常用 translate、scale、rotate、skewX、skewY 与 matrix 六种，按书写顺序作用于坐标系。

- translate(tx, ty)：整体平移，是复制元素或调整布局最常用的手段。
- scale(sx, sy)：按倍数缩放，只写一个值时两个方向同倍。
- rotate(angle, cx, cy)：绕指定点旋转，省略圆心则绕原点旋转。
- skewX 与 skewY：沿一个方向倾斜。
- matrix(a, b, c, d, e, f)：把上述变换合并成一个矩阵，适合程序计算后直接写入。

```html
<!-- 书写顺序决定结果：先平移坐标系，再在其中旋转 -->
<svg width="260" height="140" viewBox="0 0 260 140">
  <rect x="0" y="0" width="60" height="40" fill="#e07b39" />
  <rect x="0" y="0" width="60" height="40" fill="#2fa36b"
        transform="translate(100,50) rotate(30)" />
</svg>
```

> 多个变换等价于按书写顺序嵌套的分组，最左侧的变换位于最外层；图形上的点先受最右侧变换影响，再逐层向外。

**速记**：transform 是一串变换函数，左侧在外层、右侧在内层，顺序不同结果不同。



#### defs、use 与 symbol 复用

**defs 元素**：用于存放不直接渲染的可复用定义；**use 元素**：按引用实例化定义内容；**symbol 元素**：带自身 viewBox 的可复用模板，经 use 实例化时可独立缩放。

- defs：定义渐变、裁剪与图形模板等，只有被引用才出现在画面上。
- use：通过 href 指向定义，x 与 y 指定实例位置，可再用 CSS 覆盖样式。
- symbol：可带 viewBox 与 preserveAspectRatio，适合图标库式的复用。
- 拆分原则：把固定的形状放进 defs，把随数据变化的坐标留给实例。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <defs>
    <path id="markerShape" d="M0 -8 L8 8 L-8 8 Z" fill="#7a5cff" />
  </defs>
  <use href="#markerShape" x="60" y="60" />
  <use href="#markerShape" x="130" y="40" />
  <use href="#markerShape" x="200" y="80" />
</svg>
```

> use 的引用属性在新版浏览器中写作 href，早期写法为 xlink:href 并需声明命名空间，兼容旧环境时两者可同时书写。

**速记**：defs 存模板、use 实例化、symbol 带独立视口，是减少重复节点的主要手段。



### 样式与呈现属性

图形摆好之后还需要控制外观。本节说明呈现属性与 CSS 的关系、填充与描边的控制项，以及线型细节。

#### 呈现属性与 CSS 的优先级

**呈现属性**：是直接写在元素上的外观属性，如 fill、stroke、stroke-width；它们本质上是低优先级声明，会被 CSS 规则覆盖。

- 直接属性：写在元素起始标签上，就近可读，适合固定外观。
- CSS 规则：通过类选择器统一控制，适合主题切换与状态变化。
- 优先级：CSS 声明高于呈现属性，因此用类可以整体换肤而不必改元素。
- 内联样式：style 属性优先级最高，调试时短期使用，长期维护应回到类。

```css
/* 统一主题色，覆盖元素上的呈现属性 */
.chart-series {
  fill: #4a90d9;
  stroke: #1f5c93;
  stroke-width: 2;
}

.chart-series.is-active {
  fill: #e07b39;
}
```

```html
<svg viewBox="0 0 200 100">
  <rect class="chart-series" x="20" y="20" width="60" height="60" fill="#999999" />
  <rect class="chart-series is-active" x="110" y="20" width="60" height="60" />
</svg>
```

**速记**：呈现属性是低优先级声明，CSS 类可整体覆盖，主题与状态统一交给样式表。



#### 填充与描边

**填充**：用 paint 值填充图形内部，取色值、渐变或图案；**描边**：绘制轮廓，除了颜色还有宽度与不透明度等参数。

- fill：填充颜色，设 none 表示不填充。
- fill-opacity：填充的不透明度，取 0 到 1。
- stroke：描边颜色，设 none 表示不描边。
- stroke-width：描边宽度，以用户单位计，默认 1。
- stroke-opacity：描边不透明度；元素级 opacity 则同时影响填充与描边。

```html
<svg width="260" height="120" viewBox="0 0 260 120">
  <rect x="20" y="20" width="80" height="80" fill="#4a90d9" fill-opacity="0.4" />
  <rect x="140" y="20" width="80" height="80" fill="none"
        stroke="#e07b39" stroke-width="6" stroke-opacity="0.6" />
</svg>
```

> opacity 作用于整个元素包括描边，fill-opacity 与 stroke-opacity 只作用于对应部分，叠加时按乘法生效。

**速记**：fill 与 stroke 各自控制内部与轮廓，透明分为元素级与填充描边级两套。



#### 虚线、线帽与线接

**线型属性**：描述描边在端点与转折处的处理方式，包括 stroke-linecap、stroke-linejoin、stroke-miterlimit 与 stroke-dasharray。

- stroke-linecap：端点样式，取 butt 平头、round 圆头、square 方头。
- stroke-linejoin：转折样式，取 miter 尖角、round 圆角、bevel 斜切。
- stroke-miterlimit：限制尖角长度，超过阈值自动转为斜切，避免长刺。
- stroke-dasharray：一组数值交替表示实线与空白长度，用于虚线。
- stroke-dashoffset：整体偏移虚线起点，可用于描边生长一类的效果。

```html
<svg width="280" height="120" viewBox="0 0 280 120">
  <line x1="20" y1="30" x2="260" y2="30" stroke="#4a90d9"
        stroke-width="4" stroke-linecap="round" />
  <line x1="20" y1="60" x2="260" y2="60" stroke="#2fa36b"
        stroke-width="4" stroke-dasharray="12 6" />
  <polyline points="20,100 80,70 140,100 200,70 260,100" fill="none"
            stroke="#e07b39" stroke-width="4" stroke-linejoin="round" />
</svg>
```

> 折线图区分多条序列时，虚线配合颜色比只换颜色更易区分，但线型种类不宜超过三种，过多会让图例难以对应。

**速记**：linecap 定端点、linejoin 定转折、dasharray 出虚线，虚线是区分序列的低成本手段。
