## D3：数据驱动与选择集

### D3 是什么与设计取向

D3（Data-Driven Documents，数据驱动文档）把数据映射为文档中的图形元素。本节先确定它在工具链中的位置，再说明数据驱动的含义与引入方式。

#### D3 的定位：低层构件而非成品图表

**D3**：是一个以 HTML、SVG 与 CSS 等 Web 标准为基础的数据可视化函数库，提供选择集、数据绑定、比例尺、形状生成器、布局算法与过渡等构件，由开发者组合成图表，自身不提供现成的图表类型。

- 构件层：选择集与数据绑定、比例尺、坐标轴、形状生成器、布局算法、过渡与交互。
- 不提供层：柱状图、折线图等成品图表，以及主题、图例、提示框等成套组件。
- 输出层：生成 SVG 元素，或向 Canvas 上下文发出绘制指令，产物是标准 DOM 或位图。
- 对照对象：ECharts 以配置项声明图表，D3 以代码构造图形，两者的可控粒度处在不同层级。

```js
// D3 的构造式写法：元素与数据的映射由代码显式给出
const bars = svg.selectAll("rect")
  .data(values)
  .join("rect")
  .attr("x", (d, i) => xScale(i))
  .attr("y", (d) => yScale(d))
  .attr("width", xScale.bandwidth())
  .attr("height", (d) => height - yScale(d));
```

> 需要现成图表与配置项时用 ECharts，需要精确控制图形构造与交互细节时用 D3，两者可在同一页面分工，详见本主题第 14 篇 ECharts 快速上手与配置体系。

**速记**：D3 提供选择集、比例尺、形状生成器等构件，不提供成品图表类型。



#### 数据驱动的核心思想

**数据驱动**：是把数据数组与文档元素建立对应关系，再由绑定结果决定元素的创建、更新与删除，而不是手工编写逐条增删元素的流程。

- 声明映射：写出每个数据点对应什么元素、每个属性由哪个字段决定。
- 自动同步：数据变化后重新绑定，由对比结果决定新增、保留与移除。
- 属性即函数：属性值可写成接收数据与索引的函数，由数据算出坐标、颜色与文本。
- 对照命令式：命令式逐条下达绘制指令，数据驱动只描述对应关系与映射规则。

```js
// 属性值为函数时，每个元素按自身的数据计算取值
selection.attr("cx", (d) => xScale(d.time))
  .attr("cy", (d) => yScale(d.value))
  .attr("r", (d) => Math.sqrt(d.count));
```

> 数据驱动不等于自动绘制：映射关系仍由开发者写出，D3 负责按映射批量维护元素。

**速记**：数据驱动的核心是把数据与元素建立对应关系，由绑定结果决定元素的增删改。



#### 引入方式与最小示例

**引入方式**：是把 D3 装入页面的途径，常见为通过包管理器安装后以 ES 模块引入，或直接引入 CDN 上的打包版本。

- 包管理器：安装 d3 后按模块引入，也可只取其一部分以减小体积。
- CDN：引入打包文件后以全局变量 d3 访问，适合演示与快速验证。
- 模块化：D3 由选择集、比例尺、地理等多个子模块组成，可分模块引入。
- 版本差异：v6 起事件对象改由回调参数传入，v7 已移除全局 d3.event，示例按 v7 写法。

```bash
# 通过包管理器安装
npm install d3
```

```js
import * as d3 from "d3";

const data = [12, 30, 18, 42];

d3.select("#chart")
  .selectAll("div")
  .data(data)
  .join("div")
  .style("width", (d) => d * 4 + "px")
  .text((d) => d);
```

> D3 按子模块发布，只做几何计算或比例尺换算时可以只引入对应模块，不必引入整个包。

**速记**：D3 可整包或按子模块引入，v7 的事件对象由回调参数传入。



### 选择集与 DOM 操作

选择集是 D3 操作 DOM 的统一入口，把单个或多个元素包装成可链式调用的对象。本节说明选择集的创建、方法与遍历方式。

#### 选择集的创建

**选择集（selection）**：是 D3 对一组 DOM 节点的包装对象，提供统一的读写接口，单个节点与多个节点共用同一套方法。

- 创建入口：d3.select(selector) 返回首个匹配元素的选择集，d3.selectAll(selector) 返回全部匹配元素的选择集。
- 传入节点：两个方法也可直接接收 DOM 节点或节点数组，跳过选择器查询。
- 子级查询：selection.select(selector) 与 selection.selectAll(selector) 在已选元素的后代中查询。
- 空选择集：未匹配到元素时返回空选择集，对其调用方法不报错，也不产生元素。

```js
const svg = d3.select("#chart").append("svg")
  .attr("width", 640)
  .attr("height", 360);

// 此时为空选择集，尚无元素可供绑定
const circles = svg.selectAll("circle");
```

> 空选择集是数据绑定中「进入」状态的来源：先由空选择集承载待创建的元素。

**速记**：d3.select 返回首个匹配元素，d3.selectAll 返回全部匹配元素，未匹配时得到空选择集。



#### 增删与属性读写

**增删与属性读写**：是选择集维护元素结构、设置属性与样式的方法集合，写入值可以为常量，也可以为接收数据与索引的函数。

- 结构：append(name) 追加子元素，insert(name, before) 在指定元素前插入，remove() 移除元素。
- 属性：attr(name, value) 读写 HTML 属性，property(name, value) 读写 DOM 属性，classed(names, value) 增删类名。
- 样式：style(name, value, priority) 写内联样式，text(value) 与 html(value) 写文本与内部标记。
- 写入规则：值为函数时每个元素各自调用一次，值为常量时统一赋值。

```js
svg.selectAll("rect")
  .attr("x", (d, i) => i * 40)
  .attr("width", 32)
  .classed("highlight", (d) => d > 30)
  .style("fill", (d) => (d > 30 ? "#c0392b" : "#4a90d9"));
```

> [!CAUTION]
> **注意内容**：向元素写入对象型数据时，attr 会把对象转换成字符串导致信息丢失，需要保留复杂数据时应改用 datum 或 DOM 属性接口。

**速记**：append、attr、style、classed 等方法完成结构增删与属性样式写入，写入值可为常量或函数。



#### 遍历、过滤与调用

**遍历与调用**：是对选择集中的元素逐个处理，或把整个选择集交给外部函数的方法，用于执行命令式逻辑与复用绘制函数。

- each：selection.each(function) 对每个元素执行一次回调，回调内 this 指向当前 DOM 节点，参数为数据、索引与全部节点。
- filter：selection.filter(test) 按条件返回子选择集，test 接收数据与索引。
- call：selection.call(fn, ...args) 把当前选择集传给函数并返回原选择集，便于封装一段链式操作。
- 取值：nodes() 返回节点数组，node() 返回首个节点，size() 返回元素个数。

```js
function drawAxis(g, scale, height) {
  return g.attr("transform", "translate(0," + height + ")")
    .call(d3.axisBottom(scale).ticks(5));
}

svg.append("g").call(drawAxis, xScale, 320);

svg.selectAll("circle").each(function (d, i) {
  d3.select(this).attr("data-index", i);
});
```

> call 的价值在于让绘制逻辑脱离链式调用的位置，被多个图表复用时不必复制整条调用链。

**速记**：each 逐元素执行回调，filter 按条件筛选，call 把选择集交给外部函数以复用绘制逻辑。



### 数据绑定与键函数

数据绑定把数组与元素关联起来，是 D3 区别于普通 DOM 操作库的核心。本节说明绑定接口、键函数与三种状态。

#### data 与 datum

**数据绑定**：是把数组元素分配给选择集中的元素，使每个元素可通过回调取到自身的数据。

- data(data, key)：把数组绑定到选择集，返回更新选择集；多出的数据进入进入选择集，多余的旧元素进入退出选择集。
- datum(value)：给选择集中的元素设置同一个数据值，不做对比，也不产生进入与退出选择集。
- 取值来源：回调的第一个参数是绑定数据，第二个是索引，第三个是当前分组的节点数组。
- 解绑：data(null) 或 data([]) 可使原有元素全部进入退出状态。

```js
const values = [8, 15, 4, 23];

// 一个 datum 供整组元素共享
svg.selectAll("line")
  .datum({ color: "#333333" })
  .attr("stroke", (d) => d.color);
```

> 只想给已有元素挂一份上下文数据而不做增删时用 datum；需要按数组增删元素时用 data。

**速记**：data 把数据与元素按键对比并产生进入、更新、退出三种状态，datum 只给已有元素挂数据。



#### 键函数的作用

**键函数（key function）**：是 data 的第二个参数，接收数据、索引与分组，返回该数据的唯一标识字符串，用于在多次绑定时把数据与元素对应起来。

- 默认行为：省略键函数时按索引对应，数据顺序或长度变化会造成元素被复用或重建。
- 稳定对应：键函数返回稳定且唯一的值（如记录的 id），同一数据在不同次绑定中映射到同一元素。
- 过渡前提：元素被正确复用，正在进行的过渡与元素内部状态才能延续。
- 常见错误：键函数返回索引或不稳定的对象字符串，等价于未使用键函数。

```js
const rows = [
  { id: "a", value: 3 },
  { id: "b", value: 9 },
  { id: "c", value: 5 }
];

svg.selectAll("rect")
  .data(rows, (d) => d.id)
  .join("rect");
```

> [!CAUTION]
> **注意内容**：键函数返回的值不稳定或存在重复时，D3 会把同一元素判给不同数据，导致过渡被打断、元素内部状态错乱。

**速记**：键函数返回数据的唯一标识，保证多次绑定时数据与元素稳定对应，是过渡连续的前提。



#### 进入、更新与退出

**三种状态**：是 data 对比后对数据与元素关系给出的分类，多出的数据为进入，仍然保留的为更新，没有数据可配的旧元素为退出。

- 进入：enter 选择集中的占位符对应新增数据，需再用 append 补齐元素。
- 更新：data 返回的选择集对应已有元素，属性在此更新。
- 退出：exit 选择集对应没有数据可配的旧元素，通常用 remove 删除。
- 合并：更新选择集与进入后新建的元素可用 merge 合并，统一设置属性，避免重复书写。

```js
const update = svg.selectAll("rect").data(rows, (d) => d.id);

update.enter().append("rect").attr("height", 0);
update.merge(update.enter())
  .attr("x", (d, i) => i * 44)
  .attr("width", 36);
update.exit().remove();
```

> 三种状态的出现顺序不固定，但都必须处理：只写进入不写退出会留下多余元素。

**速记**：进入对应新增数据，更新对应已有元素，退出对应多余旧元素，三者需分别处理。



### 连接模式的写法

连接模式是数据绑定的落地写法，决定元素如何随数据增删。本节给出传统写法与 join 简写两种落地方式。

#### 传统 enter 与 exit 写法

**传统写法**：是分别取得进入选择集并补齐元素、合并更新选择集并设置属性、再移除退出选择集的多段式结构。

- 第一步：绑定数据得到更新选择集。
- 第二步：enter 选择集调用 append 创建元素，并设置只在创建时生效的初始属性。
- 第三步：更新与进入合并后写入随数据变化的属性。
- 第四步：exit 选择集调用 remove 删除多余元素。

```js
const update = chart.selectAll("path.line").data(series);

const entering = update.enter().append("path")
  .attr("class", "line")
  .attr("fill", "none");

update.merge(entering)
  .attr("d", (d) => lineGen(d.points));

update.exit().remove();
```

> 多段式的优点是每一步都可见，便于在创建、更新、删除三处分别插入逻辑，例如进入时从零高度起步。

**速记**：传统写法按绑定、进入、合并更新、退出四步处理，每一步可插入独立逻辑。



#### join 简写

**join 方法**：是 selection.join(enter, update, exit) 提供的连接简写，一次完成进入元素的创建、更新元素的写入与退出元素的移除，并返回合并后的选择集。

- 默认行为：join("rect") 等价于进入时 append 该元素、更新时直接沿用、退出时 remove。
- 传入函数：三个参数可分别为函数，按需自定义创建、更新与删除的行为。
- 返回值：合并后的选择集，可继续链式设置属性。
- 适用边界：需要精确控制元素的插入位置或删除动画时，用传统写法更清晰。

```js
chart.selectAll("circle.point")
  .data(points, (d) => d.id)
  .join(
    (enter) => enter.append("circle").attr("r", 4),
    (update) => update.attr("fill", "#4a90d9"),
    (exit) => exit.attr("fill", "#bbbbbb").remove()
  )
  .attr("cx", (d) => xScale(d.x))
  .attr("cy", (d) => yScale(d.y));
```

> [!WARNING]
> **警告内容**：调用 data 之后忘记处理 exit 选择集，旧元素会一直留在页面上，反复更新后会形成重影并造成误命中。

**速记**：join 一次完成创建、更新与移除并返回合并选择集，需要细粒度控制时用传统写法。



### 过渡与动画

过渡让属性变化按时间插值呈现。本节说明过渡的创建、缓动与时间控制，以及事件与中断处理。

#### 创建过渡与插值

**过渡（transition）**：是 D3 按时间对属性值做插值的机制，作用于选择集，使属性从当前值平滑变化到目标值。

- 创建：selection.transition(name) 返回过渡对象，可指定名称以便多个过渡并存互不覆盖。
- 可过渡属性：attr、style、text 等，写法与选择集一致，值可以为函数。
- 插值依据：数值与颜色按各自的插值器过渡，字符串中的数字片段也会被替换。
- 派生过渡：transition.transition() 在前一个过渡结束后开始，形成时间上的序列。

```js
svg.selectAll("rect")
  .data(values)
  .join("rect")
  .attr("y", height)
  .transition()
  .duration(600)
  .attr("y", (d) => yScale(d));
```

> 过渡按属性分别插值，同一元素的不同属性可落在不同时间段，形成错落的动效。

**速记**：过渡在选择集属性上做时间插值，attr 与 style 均可过渡，可链式派生多个阶段。



#### 缓动与时间控制

**缓动（easing）**：是控制插值进度随时间变化的函数，把线性时间映射为非线性进度，实现加速、减速与回弹等效果。

- 时长与延迟：duration(ms) 设置过渡总时长，delay(ms) 设置开始前的等待，二者均可传入函数按元素错开。
- 缓动函数：ease(fn) 指定缓动函数，d3.easeLinear 为匀速，d3.easeCubic 与 d3.easeCubicInOut 为平滑加减速，d3.easeBounce 与 d3.easeElastic 带反弹。
- 错开进场：delay 传入以索引为参数的函数，可实现依次入场。
- 默认值：未指定时使用默认时长与默认缓动函数。

```js
svg.selectAll("circle")
  .transition()
  .duration(800)
  .delay((d, i) => i * 40)
  .ease(d3.easeCubicInOut)
  .attr("r", (d) => radiusScale(d.value));
```

> [!TIP]
> **建议内容**：多个元素依次入场时用 delay 按索引错开，比逐元素设置定时器更简单，中断时也更容易统一回收。

**速记**：duration 与 delay 控制时间，ease 指定缓动函数，delay 传函数可实现逐元素错开。



#### 过渡事件与中断

**过渡事件**：是过渡过程中触发回调的钩子；**中断**：是提前结束过渡并让元素停在当前状态的操作。

- 事件钩子：transition.on("start", listener) 在开始时触发，on("end") 在正常结束时触发，on("interrupt") 在被打断时触发。
- 自定义插值：attrTween(name, fn) 与 styleTween(name, fn) 接收返回插值函数的回调，用于非标准属性与自定义路径。
- 中断：selection.interrupt() 停止该选择集上的过渡。
- 清理时机：数据更新时先中断旧过渡再开始新过渡，避免同一属性被两个过渡同时驱动。

```js
function animateRadius(selection, radiusOf) {
  selection.interrupt()
    .transition()
    .duration(500)
    .attrTween("r", function (d) {
      const start = Number(this.getAttribute("r"));
      return (t) => start + (radiusOf(d) - start) * t;
    })
    .on("end", function () {
      d3.select(this).attr("data-animated", "true");
    });
}
```

> 过渡被打断时不会触发 end，依赖 end 的收尾逻辑需要同时在 interrupt 中补一份。

**速记**：on 监听 start、end、interrupt 三类事件，attrTween 提供自定义插值，interrupt 提前结束过渡。



### 事件与交互模块

交互建立在 DOM 事件之上，D3 提供统一的监听写法与坐标换算工具，并对缩放、拖拽等通用交互做了封装。

#### 监听写法与事件对象

**事件监听**：是选择集上的 on(typenames, listener, options) 方法，为每个元素绑定回调，v6 起回调首参为事件对象。

- 绑定与解除：selection.on("click", listener) 绑定，selection.on("click", null) 解除。
- 命名空间：类型可写为 "click.panel"，同一命名空间后绑定的监听会覆盖前一个。
- 回调参数：listener 接收 (event, d)，event 为原生事件，d 为该元素绑定的数据。
- this 指向：回调内的 this 是当前 DOM 节点，箭头函数会改变这一点，需要节点时必须用普通函数或闭包取节点。

```js
svg.selectAll("circle")
  .data(points)
  .join("circle")
  .on("click.point", function (event, d) {
    d3.select(this).attr("stroke-width", 3);
    console.log(d.id, event.clientX);
  })
  .on("mouseover.point", function (event, d) {
    d3.select(this).attr("fill", "#c0392b");
  });
```

> [!IMPORTANT]
> **重要内容**：D3 v6 起事件对象由回调第一个参数传入，全局 d3.event 已被移除；迁移旧代码时须逐处改写，混用写法在 v7 中会直接失效。

**速记**：on 绑定与解除监听，类型可带命名空间，v6 起回调首参为事件对象，this 指向当前节点。



#### 指针坐标的获取

**指针坐标**：是把事件坐标换算为指定元素局部坐标系中的位置，D3 由 d3.pointer(event, target) 提供。

- 用途：命中检测、拖拽定位与提示框跟随，都需要元素内的相对坐标。
- 参数：event 为事件对象，target 为参照元素，省略时取事件的当前元素。
- 返回值：长度为 2 的数组，分别是以参照元素左上角为原点的横纵坐标。
- 近似方法：也可用 getBoundingClientRect() 与事件坐标自行相减，但需处理页面滚动与视图缩放。

```js
const canvas = document.getElementById("plot");
```

#### 缩放与拖拽交互

**缩放与拖拽**：是 D3 对平移缩放与拖动两类交互的封装，绑定到元素后自动处理手势与指针事件。

- 缩放：d3.zoom() 创建缩放行为，用 scaleExtent 限定倍率、用 on("zoom") 接收变化，再经 selection.call 绑定。
- 变换使用：缩放回调的事件对象携带 transform，含 k、x、y 三个分量，用于更新比例尺或视图。
- 拖拽：d3.drag() 创建拖拽行为，监听 start、drag、end 三个事件，回调中读取事件的 x、y。
- 适用范围：缩放常用于地图与散点图视图，拖拽常用于节点位置调整与图例排序。

```js
function enableZoom(svg, viewport) {
  const zoomBehavior = d3.zoom()
    .scaleExtent([1, 12])
    .on("zoom", (event) => {
      viewport.attr("transform", event.transform);
    });

  svg.call(zoomBehavior);
  return zoomBehavior;
}
```

```js
function enableDrag(nodes) {
  const dragBehavior = d3.drag()
    .on("start", (event, d) => { d.dragging = true; })
    .on("drag", (event, d) => { d.x = event.x; d.y = event.y; })
    .on("end", (event, d) => { d.dragging = false; });

  nodes.call(dragBehavior);
  return dragBehavior;
}
```

> 缩放与拖拽都由 selection.call 绑定，返回的行为对象可用于程序化触发，例如重置视图。

**速记**：d3.zoom 与 d3.drag 封装两类通用交互，经 call 绑定，回调读取事件对象中的变换与坐标。
