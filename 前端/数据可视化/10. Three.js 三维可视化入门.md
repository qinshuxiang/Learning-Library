## Three.js 三维可视化入门

Three.js 在 WebGL 之上提供场景图、相机与材质等高层抽象，把缓冲区与着色器的细节收进对象模型里。本篇讲 Three.js 是什么与基本结构，再依次展开几何体与材质、光照与阴影、相机控制与点选、动画与时间，最后落到与数据结合的常见形态。WebGL 管线与 GLSL 语法详见本主题第 9 篇 WebGL 与 GPU 渲染基础。

### Three.js 是什么与基本结构

Three.js 面向的是「用三维方式组织数据与场景」的绘制任务。本节给出定义与定位，拆解场景、相机、渲染器三件套，并说明渲染循环与尺寸适配。

#### Three.js 的定义与定位

**Three.js**：是一套基于 WebGL 的 JavaScript 三维图形库，用场景图组织对象、用相机描述视角、用渲染器把场景输出到画布，把缓冲区、着色器与矩阵运算封装在对象之后。

- 抽象层次：提供 Scene、Camera、Geometry、Material、Light 等对象，不再直接操作缓冲区。
- 使用方式：通过 npm 安装后以模块方式引入，也可用打包器按需引入子模块以减小体积。
- 适用场景：三维散点、曲面、体数据、地理场景、需要透视与光照的数据表达。
- 边界：仍需理解坐标变换与绘制顺序，排错时常常要回到矩阵与深度这两层。

```js
import * as THREE from "three";

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(45, 800 / 600, 0.1, 1000);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(800, 600);
document.getElementById("stage").appendChild(renderer.domElement);
```

> 自定义着色器可以挂在材质上，语法与管线的分工详见本主题第 9 篇，本节只讲对象模型。

**速记**：Three.js 是基于 WebGL 的三维库，用场景图、相机与渲染器封装了缓冲区与着色器细节。



#### 场景、相机与渲染器三件套

**场景图（scene graph）**：是以 Scene 为根、以父子关系组织对象的树形结构，父对象的变换会传递给子对象，渲染时遍历整棵树。

- Scene：场景根节点，容纳网格、光源、辅助对象与相机。
- PerspectiveCamera：透视相机，参数含义与透视/正交的取舍见下文「相机的类型与投影」一节。
- WebGLRenderer：渲染器，持有 WebGL 上下文，负责把场景按相机视角绘制出来。
- 变换：对象的位置、旋转与缩放分别由 position、rotation、scale 描述，父级变换自动叠加。
- 遍历顺序：树的层级越深，逐帧遍历与矩阵更新的成本越高。

```js
const group = new THREE.Group();
const point = new THREE.Mesh(geometry, material);
point.position.set(2, 1, 0);
group.add(point);
scene.add(group);
// 移动父级 group 会带动全部子对象一起位移
```

> 相机与光源本身也是场景图里的对象，只不过只有相机决定观察视角，光源影响的是材质的着色结果。

**速记**：Scene 是场景图根节点，相机决定视角，渲染器负责输出，父级变换会传递给子对象。



#### 渲染循环与尺寸适配

**渲染循环**：是每帧调用一次渲染器绘制、并按时间更新对象状态的循环，通常用浏览器提供的逐帧回调驱动。

- 渲染调用：每次循环内调用 renderer.render(scene, camera) 完成一帧绘制。
- 尺寸适配：窗口尺寸变化时更新相机宽高比并调用 renderer.setSize 同步画布尺寸。
- 像素比：调用 renderer.setPixelRatio 把设备像素比交给渲染器，避免高分屏发虚。
- 停止条件：场景静止时不必逐帧重绘，可改为按需渲染以节省电量。

```js
function renderScene() {
  requestAnimationFrame(renderScene);
  renderer.render(scene, camera);
}
renderScene();

window.addEventListener("resize", () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});
```

> [!NOTE]
> **提醒内容**：改变相机的视野角、宽高比或近远裁剪面后，必须调用 updateProjectionMatrix 才生效，否则画面比例不会更新。

**速记**：渲染循环逐帧调用 renderer.render 输出画面，窗口变化时同步相机宽高比与画布尺寸。



### 几何体与材质

几何体描述形状，材质描述表面外观，两者组合成网格对象。本节说明内置几何体、缓冲区几何体与材质选择。

#### 内置几何体

**内置几何体**：是库中预置的参数化形状，用少量参数生成顶点数据，适合快速搭建场景与占位。

- BoxGeometry：长方体，参数为宽、高、深与分段数。
- SphereGeometry：球体，参数为半径与经纬分段数。
- PlaneGeometry：平面，常用作底面或承载纹理的画布。
- CylinderGeometry：圆柱体，参数为顶底半径、高与分段数。
- 圆柱与柱状图：柱状数据常用圆柱或长方体堆叠表示，分段数决定圆柱的圆滑度。

```js
const boxGeometry = new THREE.BoxGeometry(1, 2, 1);
const sphereGeometry = new THREE.SphereGeometry(0.6, 32, 16);
const planeGeometry = new THREE.PlaneGeometry(20, 20);

const boxMesh = new THREE.Mesh(boxGeometry, material);
boxMesh.position.y = 1;
scene.add(boxMesh);
```

> 分段数越高，顶点数越多：球体与圆柱的平滑度靠分段数换来，对大批量对象要控制分段数。

**速记**：内置几何体用少量参数生成顶点，长方体、球体、平面与圆柱覆盖常见形状，分段数换平滑度。



#### 缓冲区几何体与自定义顶点

**BufferGeometry**：是用类型化数组直接描述顶点数据的几何体，属性写入位置、法线、颜色与纹理坐标等具名属性，是内置几何体的底层形式。

- 属性设置：用 setAttribute(name, attribute) 把顶点数据挂到几何体上。
- 位置属性：position 属性为每三个数值表示一个顶点的 x、y、z。
- 索引复用：可用索引属性复用顶点，减少顶点总数与显存占用。
- 计算法线：顶点位置变化后需重新计算法线，光照才会正确。

```js
const geometry = new THREE.BufferGeometry();
const positions = new Float32Array([
  0, 0, 0,
  1, 0, 0,
  0, 1, 0,
]);

geometry.setAttribute("position", new THREE.BufferAttribute(positions, 3));
geometry.computeVertexNormals();

const triangle = new THREE.Mesh(geometry, material);
scene.add(triangle);
```

> 从数据生成图形时，先算好顶点数组再交给位置属性，比逐个创建网格对象更省内存也更快。

**速记**：BufferGeometry 用类型化数组描述顶点，经 setAttribute 写入位置等属性，索引可复用顶点。



#### 材质的种类与选择

**材质（material）**：是描述网格表面如何着色的对象，决定颜色、透明度、贴图与是否受光照影响。

- MeshBasicMaterial：不受光照影响，始终按给定颜色显示，开销最低。
- MeshStandardMaterial：基于物理的着色模型，配合光源才能体现明暗，适合真实感场景。
- 线材质与点材质：线条用线材质，散点用点材质，可分别控制线宽与点的大小。
- 复用：同一种材质可被多个网格共享，减少程序与状态切换。

> [!CAUTION]
> **注意内容**：切换材质类型时着色器程序会重新编译，场景中材质种类过多会导致首帧卡顿，能用同一种材质就不要拆成多种。

**速记**：基础材质不受光、标准材质走物理着色，同种材质尽量复用，透明与材质种类都会增加开销。



### 光照与阴影

光照让三维物体的体积感得以显现，阴影进一步强化位置关系。本节说明光源类型、光照与材质的关系以及阴影的代价。

#### 光源类型与作用

**光源（light）**：是场景中影响材质着色的对象，决定物体表面的明暗与方向感，不同类型的光源在空间中的行为不同。

- AmbientLight：环境光，均匀照亮所有方向，没有方向与位置，只提亮暗部。
- DirectionalLight：平行光，光线方向一致，常用于模拟日光，有方向无位置衰减。
- PointLight：点光源，从一点向四周发光，随距离衰减。
- SpotLight：聚光灯，有方向与张角，可控制照射范围与边缘柔和度。
- 组合使用：环境光打底加一盏平行光做主光，是既省事又出效果的基础组合。

```js
const ambientLight = new THREE.AmbientLight(0xffffff, 0.6);

const directionalLight = new THREE.DirectionalLight(0xffffff, 1.2);
directionalLight.position.set(5, 8, 6);
scene.add(ambientLight);
scene.add(directionalLight);
```

> 环境光过强会压平明暗对比、削弱体积感，通常只用来把暗部提到能被看清的程度。

**速记**：环境光均匀提亮，平行光给方向，点光与聚光有衰减，环境光加一盏主光是基础组合。



#### 光照与材质的关系

**着色结果**：是材质属性与光源共同作用后的表面颜色，同一盏灯照在不同材质上会得到不同亮度与质感。

- 受光条件：只有标准材质这类受光材质才会响应光源，基础材质忽略光照。
- 表面粗糙度：粗糙度越低反射越集中，高光越锐利。
- 法线方向：法线决定表面朝向，法线错误时会出现整片死黑或明暗反向。
- 调试手段：给几何体加上法线辅助显示，可直接看出法线朝向是否正确。

```js
const material = new THREE.MeshStandardMaterial({
  color: 0x4f83cc,
  roughness: 0.4,
  metalness: 0.0,
  flatShading: false,
});

const mesh = new THREE.Mesh(geometry, material);
```

> 换了材质却看不到明暗变化，多半是场景里根本没有光源，或所用材质不响应光照。

**速记**：着色由材质与光源共同决定，粗糙度与金属度改变质感，法线方向错误会造成死黑。



#### 阴影的开启与代价

**阴影（shadow）**：是光源对被照射物体在接收面上投下的暗影，需要同时开启渲染器、光源与物体三处开关才会出现。

- 渲染器开关：把渲染器的阴影能力打开。
- 光源开关：设置光源产生阴影，并配置阴影相机与贴图尺寸。
- 物体开关：物体分别设置是否投射阴影与是否接收阴影。
- 贴图尺寸：阴影贴图越大越清晰，显存与绘制开销也越高。
- 性能代价：阴影相当于额外一次场景绘制，物体多时应关闭或只让少量关键对象投射。

```js
renderer.shadowMap.enabled = true;

directionalLight.castShadow = true;
directionalLight.shadow.mapSize.set(1024, 1024);

boxMesh.castShadow = true;
planeMesh.receiveShadow = true;
```

> [!IMPORTANT]
> **重要内容**：阴影是逐帧额外绘制的产物，物体数量大时是主要瓶颈之一，交互场景应优先考虑用假阴影或接触阴影替代。

**速记**：阴影需在渲染器、光源与物体三处分别开启，贴图越大越清晰也越费，物体多时应改用假阴影。



### 相机控制与点选

相机决定观察方式，控制组件提供交互式视角操作，射线用于把平面点击转成三维对象选择。本节说明相机类型、轨道控制与点选。

#### 相机的类型与投影

**投影方式**：是三维坐标映射到二维画面的规则，透视投影近大远小，正交投影保持平行线平行。

- PerspectiveCamera：透视相机，参数为视野角、宽高比、近裁剪面与远裁剪面。
- OrthographicCamera：正交相机，参数为左右上下与近远范围，适合等距视角与精确比例。
- 视野角：视野角越大取景越广，透视变形也越强。
- 裁剪面：超出近远裁剪面的物体不会被绘制，距离范围设错会导致物体消失。
- 选择依据：需要空间纵深用透视，需要可比较的长度比例用正交。

```js
const perspectiveCamera = new THREE.PerspectiveCamera(
  45,
  window.innerWidth / window.innerHeight,
  0.1,
  2000
);
perspectiveCamera.position.set(6, 6, 10);
perspectiveCamera.lookAt(0, 0, 0);

const halfWidth = 10;
const orthographicCamera = new THREE.OrthographicCamera(
  -halfWidth, halfWidth, halfWidth, -halfWidth, 0.1, 2000
);
```

> 正交相机没有近大远小，柱状图的高度比较在正交视角下不会被透视放大或缩小，更适合比较。

**速记**：透视相机近大远小适合纵深，正交相机保持比例适合比较，裁剪面设错会让物体消失。



#### 轨道控制与视图操作

**OrbitControls**：是围绕目标点旋转、缩放与平移相机的交互组件，把鼠标与触摸操作翻译成相机位姿变化。

- 构造：传入相机与渲染器所在画布元素即可创建。
- 交互：拖拽旋转视角，滚轮缩放，右键或双指平移目标点。
- 阻尼：开启阻尼后相机缓动跟随，手感更顺滑，但需要逐帧更新。
- 约束：可限制俯仰角范围与缩放距离，避免视角翻转到难以理解的位置。
- 更新时机：启用阻尼时必须每帧调用其更新方法，否则相机不会移动。

```js
import { OrbitControls } from "three/addons/controls/OrbitControls.js";

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.minDistance = 4;
controls.maxDistance = 60;

function animateScene() {
  requestAnimationFrame(animateScene);
  controls.update();
  renderer.render(scene, camera);
}
animateScene();
```

> 控件改变的是相机位姿，不改变场景数据，因此切换视角不需要重建任何几何体。

**速记**：OrbitControls 把拖拽、滚轮与平移翻译成相机位姿变化，开启阻尼后必须每帧调用更新方法。



#### 用射线做点选

**Raycaster**：是把屏幕坐标转换为一条射线、再与场景中的对象求交的选择工具，用于在三维场景里命中某个网格。

- 坐标转换：把鼠标位置换算到以画布中心为原点的标准化设备坐标。
- 设置射线：用相机与鼠标坐标调用 setFromCamera 生成射线。
- 求交：用 intersectObjects 传入候选对象数组，返回按距离排序的交点列表。
- 结果读取：交点对象包含被命中的网格、交点坐标与距离等信息。

```js
const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

canvas.addEventListener("pointerdown", (event) => {
  const rect = canvas.getBoundingClientRect();
  pointer.x = ((event.clientX - rect.left) / rect.width) * 2 - 1;
  pointer.y = -((event.clientY - rect.top) / rect.height) * 2 + 1;

  raycaster.setFromCamera(pointer, camera);
  const hits = raycaster.intersectObjects(pickableMeshes);
  if (hits.length > 0) {
    selectPoint(hits[0].object);
  }
});
```

> 点选的性能取决于候选对象数量与几何体复杂度，数据点很多时应先用包围盒粗筛或改用其他命中策略。

**速记**：Raycaster 把鼠标坐标转成射线并与候选对象求交，交点列表按距离排序，候选范围越小越快。



### 动画与时间

三维场景的动态效果依赖逐帧按时间更新对象状态。本节说明时间驱动、逐帧更新与资源释放。

#### 用 Clock 驱动时间

**Clock**：是提供经过时间与帧间隔的计时对象，用两次取时间的差值驱动动画，使速度快慢与帧率无关。

- 取时间：调用 getElapsedTime 取得自启动以来经过的秒数。
- 取间隔：调用 getDelta 取得距上一帧的秒数，用于与速度相乘。
- 帧率无关：用时间而非帧序号推进动画，高低帧率下运动速度保持一致。
- 暂停与重置：页面隐藏时暂停计时，回到前台再继续，避免出现跳变。

```js
const clock = new THREE.Clock();

function updateScene() {
  const delta = clock.getDelta();
  const elapsed = clock.getElapsedTime();

  point.rotation.y += delta * 0.8;
  point.position.y = Math.sin(elapsed * 1.5) * 0.5;
}
```

> 动画速度一律乘以帧间隔，直接按帧累加会在不同刷新率的设备上表现不一致。

**速记**：Clock 提供经过时间与帧间隔，用时间驱动动画可让速度与帧率无关。



#### 逐帧更新与插值

**逐帧更新**：是每帧按时间改变对象属性并重绘的过程，属性变化的连续性决定动画是否平滑。

- 直接赋值：逐帧改写位置、旋转或缩放，适用于简单运动。
- 缓动插值：用插值函数在当前值与目标值之间按比例靠近，形成缓动效果。
- 目标切换：交互触发后只改目标值，让更新逻辑自然收敛，避免写多套动画分支。
- 数据过渡：数据更新时对柱高、点位置做插值，避免值突变带来的跳变感。
- 成本控制：只更新发生变化的属性，不对整棵树做无谓的矩阵重算。

```js
const targetValue = { y: 2 };
const currentValue = { y: 0 };

function updateHeight(delta) {
  const factor = 1 - Math.pow(0.001, delta);
  currentValue.y += (targetValue.y - currentValue.y) * factor;
  barMesh.scale.y = currentValue.y;
}
```

> 缓动系数必须与帧间隔挂钩，帧率无关的原因见上文「用 Clock 驱动时间」一节。

**速记**：逐帧更新直接改属性或用插值逼近目标值，系数与时间挂钩才能避免帧率影响。



#### 资源释放与性能

**资源释放**：是显式销毁几何体、材质、纹理与渲染器，回收 GPU 侧的显存与程序，避免重复创建时内存持续增长。

- 几何体释放：调用几何体的 dispose 方法释放顶点缓冲区。
- 材质与纹理释放：分别调用材质与纹理的 dispose 方法。
- 渲染器释放：不再使用时调用渲染器的 dispose 方法并移除画布。
- 绘制调用数：对象数越多绘制调用越多，合并几何体或使用实例化可显著减少。

```js
function removeMesh(mesh) {
  scene.remove(mesh);
  mesh.geometry.dispose();
  if (Array.isArray(mesh.material)) {
    mesh.material.forEach((material) => material.dispose());
  } else {
    mesh.material.dispose();
  }
}
```

> [!WARNING]
> **警告内容**：只从场景移除对象不会释放显存，反复增删数据点而不调用 dispose，会造成显存持续增长直到上下文丢失。

**速记**：移除对象后必须调用几何体、材质与纹理的 dispose，否则显存只增不减。



### 与数据结合的形态

三维可视化的价值在于把数据映射成空间中的对象。本节说明数据到几何属性的映射、实例化渲染的批量方案，以及标注与联动。

#### 把数据映射到几何属性

**数据映射**：是把数据字段换算成顶点坐标、颜色或尺寸的过程，映射规则决定图形能否被正确解读。

- 位置映射：两个字段映射到水平面的两个轴，第三个字段映射到高度。
- 颜色映射：数值字段映射到颜色渐变，需按数值范围做归一化。
- 尺寸映射：字段映射到柱体的高度或散点的半径，注意面积感知的非线性。
- 归一化：先把数值缩放到统一区间，再乘上场景尺寸，避免量纲差异导致图形失真。
- 坐标轴：三维场景同样需要轴与刻度，否则空间位置无法被读数。

```js
function mapRowsToPoints(rows, maxValue) {
  const positions = new Float32Array(rows.length * 3);
  rows.forEach((row, index) => {
    positions[index * 3] = row.x;
    positions[index * 3 + 1] = (row.value / maxValue) * 5;
    positions[index * 3 + 2] = row.z;
  });
  return positions;
}
```

> 三维比二维多一个维度，可读性反而更依赖视角与坐标轴，映射规则要在图例中明确交代。

**速记**：数据经归一化后映射到位置、颜色或尺寸，三维同样需要坐标轴与明确图例才可读。



#### 实例化渲染与大批量数据点

**实例化渲染**：是让 GPU 用同一份几何体与材质、按每个实例各自的变换与属性绘制多次的方式，InstancedMesh 是其在 Three.js 中的载体，一次绘制即可呈现成千上万个对象。

- 使用方式：用 InstancedMesh 指定几何体、材质与实例数量，再逐个写入实例矩阵。
- 矩阵设置：用 setMatrixAt 把每个实例的位置、旋转与缩放写入。
- 属性写入：为实例额外挂上一份自定义属性，可让每个实例有不同颜色或尺寸。
- 更新标记：批量改写后把实例矩阵标记为需要重新上传。
- 交互适配：实例本身不是独立对象，点选需从交点中取出实例编号再回查数据。

```js
const mesh = new THREE.InstancedMesh(sphereGeometry, material, rows.length);
const matrix = new THREE.Matrix4();

rows.forEach((row, index) => {
  matrix.setPosition(row.x, row.value, row.z);
  mesh.setMatrixAt(index, matrix);
});
mesh.instanceMatrix.needsUpdate = true;
scene.add(mesh);
```

> [!NOTE]
> **提醒内容**：用普通 Mesh 逐个绘制上万个数据点会先耗尽绘制调用预算，数据点规模大时应改用 InstancedMesh 或点云。

**速记**：InstancedMesh 用一份几何体与材质按实例矩阵绘制多次，是一次绘制呈现大批量数据点的关键手段。



#### 标注、辅助元素与联动

**辅助元素**：是不承载数据、但帮助理解空间关系的对象，包括坐标轴、网格、文字标注与选中高亮。

- 坐标轴：AxesHelper 用三条彩色线表示三个轴的方向。
- 网格：GridHelper 提供参考平面，帮助判断高度与尺度。
- 文字标注：把文本绘制到画布再作为纹理贴上，实现始终朝向相机的标签。
- 选中高亮：给选中对象换材质或叠加描边，配合点选结果反馈给用户。
- 联动：点选结果作为事件抛出，由外部更新对应的图表或明细面板。

```js
const axesHelper = new THREE.AxesHelper(10);
const gridHelper = new THREE.GridHelper(20, 20, 0x94a3b8, 0x334155);
scene.add(axesHelper);
scene.add(gridHelper);

function selectPoint(mesh) {
  highlightMesh(mesh);
  emitSelection({ id: mesh.userData.id });
}
```

> 标注与辅助元素本身也占绘制调用，数量多时应合并或按需显示，避免成为新的性能来源。

**速记**：坐标轴、网格与文字标注帮助理解空间，点选结果作为事件对外抛出以驱动联动。
