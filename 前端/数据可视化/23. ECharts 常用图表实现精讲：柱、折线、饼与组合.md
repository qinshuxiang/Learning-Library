## ECharts 常用图表实现精讲：柱、折线、饼与组合

第 14 篇给过常用图表的最小可运行配置，本篇把每种类型补成可以直接落地的完整实现：每类图表先说清它在什么场景下是对的选型，再给覆盖常见细节的完整配置，最后指出容易做错的点。地图系列属于地理坐标系，整体内容归本主题第 17 篇 地理与空间数据可视化，本篇只在类型清单中提及。

### 柱状图家族

柱状图适合表达类别之间的数量对比，是默认的对比类图表。本节覆盖基础柱状图与条形图、堆叠柱状图与百分比堆叠，以及标签在柱上的布局处理。



#### 基础柱状图与条形图

**柱状图（bar）**：是以矩形长度表达数值的系列类型，类目轴在 x 轴时为竖向柱状图，类目轴在 y 轴时为横向条形图。

- 类目数量多、类目名长时改用条形图，横向空间充裕，标签不会被挤到旋转变形。
- 类目按数值排序后展示，比较关系比按原始顺序更易读。
- 单系列柱状图用统一色，用颜色区分类别只在颜色本身承载含义时才有必要。
- barWidth 固定柱宽，barCategoryGap 控制类目内整组柱与相邻类目的间距，二者不宜同时收紧。
- 数值差距悬殊时柱状图会牺牲小值类目的可读性，此时考虑条形图或对数轴（对数轴见本主题第 24 篇）。

```js
chart.setOption({
  tooltip: { trigger: 'axis', axisPointer: { type: 'shadow' } },
  grid: { left: 48, right: 24, top: 48, bottom: 48, containLabel: true },
  xAxis: { type: 'value' },
  yAxis: {
    type: 'category',
    data: ['华东', '华南', '华北', '西南', '东北'],
    axisLabel: { width: 64, overflow: 'truncate' }
  },
  series: [{
    name: '销售额',
    type: 'bar',
    barWidth: 18,
    data: [1860, 1420, 1350, 780, 420],
    label: { show: true, position: 'right' }
  }]
});
```

> 条形图的数值轴在下方、类目轴在左侧，标签 position 相应改为 right，坐标轴类型互换是条形图与柱状图唯一的结构差别。

**速记**：柱状图比对比、类目长就转条形图，排序后展示，坐标轴互换即得条形图。



#### 堆叠与百分比堆叠

**堆叠柱状图**：是把同类别多个系列的柱段首尾相接为一根柱的画法，用于同时表达总量与构成；**百分比堆叠**：是把每根柱归一化为百分之百后堆叠的画法，用于只比较构成比例。

- 堆叠由各系列的 stack 字段实现，同名 stack 的系列堆为一根柱，不同名各自成柱。
- 堆叠后单段数值不易直接比较，需要精确比较单段时应拆为分组柱状图。
- 百分比堆叠可配合内置 transform 把原始数据转为占比，做法见本主题第 15 篇 数据集与数据转换。
- 堆叠顺序由系列在数组中的顺序决定，靠近轴的系列先声明。
- 总量波动大时百分比堆叠会掩盖总量信息，页面上应同时给出总量数字或并列一张总量趋势图。

```js
chart.setOption({
  tooltip: { trigger: 'axis', axisPointer: { type: 'shadow' } },
  legend: { data: ['线上', '线下'] },
  xAxis: { type: 'category', data: ['一季度', '二季度', '三季度', '四季度'] },
  yAxis: { type: 'value', name: '万元' },
  series: [
    { name: '线上', type: 'bar', stack: 'total', data: [320, 380, 350, 420] },
    { name: '线下', type: 'bar', stack: 'total', data: [280, 260, 300, 310] }
  ]
});
```

> [!WARNING]
> **警告内容**：堆叠柱状图的各段基准线不同，相邻两段的长度差不能直接读作数值差；把堆叠图当分组对比图解读是常见的误读，需要比较单段时必须拆开画。

**速记**：stack 同名即堆叠，堆叠看总量与构成，单段精确比较要拆分组柱，占比比较用百分比堆叠。



#### 柱上的标签与视觉细节

**柱标签（bar label）**：是绘制在柱段上或旁边的数值文字，配合圆角、渐变等细节可以让柱状图在交付页面中更完整。

- label.show 打开标签，position 取 top、right、inside 等方位，条形图常用 right。
- 标签数量多时会互相推挤或溢出绘图区，series 的 labelLayout 提供 hideOverlap 与 moveOverlap 两种疏解策略。
- itemStyle.borderRadius 给柱端加圆角，只影响视觉，不改变数据表达。
- 渐变填充用 echarts.graphic.LinearGradient 构造，写法见本主题第 14 篇 调色盘与逐项样式。
- 正负值共存的柱状图可按数值正负给不同颜色，让增长与下降一眼可分。

```js
chart.setOption({
  xAxis: { type: 'category', data: ['一月', '二月', '三月', '四月'] },
  yAxis: { type: 'value' },
  series: [{
    type: 'bar',
    data: [120, -40, 200, 150],
    itemStyle: { borderRadius: [4, 4, 0, 0] },
    label: { show: true, position: 'top' },
    labelLayout: { hideOverlap: true }
  }]
});
```

> 正负值混合时 borderRadius 的数组写法按上右下左取值，负向柱的圆角会出现在柱底，需要按方向分别设置。

**速记**：标签靠 label 与 labelLayout 疏解，圆角渐变只做视觉修饰，正负值配色按正负区分。



### 折线图家族

折线图适合表达连续时间或有序类目上的数值变化趋势。本节覆盖趋势折线与面积图、多系列对比，以及分段样式与预测线这类工程中常见的进阶画法。



#### 趋势折线与面积图

**趋势折线**：是以点线连接表达数值随时间变化的画法；**面积图（area chart）**：是在折线下方填充半透明面积的画法，强调量的累积感。

- 时间数据用 type 为 time 的横轴更合适，间隔不均的时间点不会被均匀拉开，时间轴细节见本主题第 24 篇。
- showSymbol 为 false 可去掉数据点圆标，数据点密集时线条更干净。
- areaStyle 的填充色用渐变并控制透明度，实色大面积填充会压住其它图层。
- 单调趋势图不开启 smooth，平滑曲线在极值附近会画出偏离数据点的弧线，造成误读。
- x 轴类目过多时开启 dataZoom 或抽稀数据，而不是缩小字号硬塞。

```js
chart.setOption({
  tooltip: { trigger: 'axis' },
  grid: { left: 48, right: 24, top: 40, bottom: 48 },
  xAxis: { type: 'time' },
  yAxis: { type: 'value' },
  series: [{
    name: '活跃用户',
    type: 'line',
    showSymbol: false,
    smooth: false,
    areaStyle: {
      color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
        { offset: 0, color: 'rgba(91, 143, 249, 0.35)' },
        { offset: 1, color: 'rgba(91, 143, 249, 0.02)' }
      ])
    },
    data: [
      ['2026-09-01', 820], ['2026-09-05', 932], ['2026-09-12', 1010],
      ['2026-09-19', 1290], ['2026-09-25', 1130]
    ]
  }]
});
```

**速记**：趋势用折线、强调累积感加渐变面积，时间数据配时间轴，不随手开 smooth。



#### 多系列折线与对比表达

**多系列折线**：是在同一坐标系内画多条折线做趋势对比的画法，系列之间共享横轴与时间窗口。

- 系列数量控制在四条以内，超过后线条交叉严重，对比价值下降。
- 多系列配色从顶层 color 调色盘取，保证同一页面内同一含义的颜色一致。
- 数值量级差异大的两条线放同一坐标轴会把小量级线压成直线，改用双轴或拆分为小倍数图。
- 图例点击隐藏系列后坐标轴范围会自动重算，这是默认行为，不需求时由 legend 的相关配置关闭。
- 对比两个时间段的同指标时，可用两组类目轴并列展示，而不是把不同时期的点画进同一条线。

```js
chart.setOption({
  color: ['#5b8ff9', '#5ad8a6', '#f6bd16', '#e8684a'],
  legend: { data: ['2025', '2026'] },
  tooltip: { trigger: 'axis' },
  xAxis: { type: 'category', data: ['一月', '二月', '三月', '四月', '五月', '六月'] },
  yAxis: { type: 'value' },
  series: [
    { name: '2025', type: 'line', data: [560, 620, 700, 680, 760, 820] },
    { name: '2026', type: 'line', data: [610, 660, 760, 790, 810, 900] }
  ]
});
```

**速记**：多系列控制在四条内，量级悬殊不共轴，同页同义同色。



#### 分段样式与预测线

**分段样式（visualMap 分段）**：是按数值区间给折线的不同区段着不同样式的画法；**预测线**：是把已有实绩与后续预测值接在同一条线或相邻线上表达的画法。

- piecewise 类型的 visualMap 按区间给 lineStyle 分色，可用于标出超阈值区段，视觉映射基础见本主题第 14 篇。
- 预测段的常用做法是实绩一条系列、预测一条系列，预测系列起点重复实绩终点值，两段视觉上无缝衔接。
- 预测段的 lineStyle 用虚线并在图例与提示框中注明口径，避免读图者把预测当实绩。
- 阈值线用 series 中的 markLine 表达，不再用额外系列模拟。
- 标记点 markPoint 用于强调最大值、最小值与特定点位，使用频率应克制。

```js
chart.setOption({
  tooltip: { trigger: 'axis' },
  xAxis: { type: 'category', data: ['七月', '八月', '九月', '十月', '十一月'] },
  yAxis: { type: 'value' },
  series: [
    { name: '实绩', type: 'line', data: [620, 660, 710], markLine: { data: [{ yAxis: 700, name: '目标线' }] } },
    {
      name: '预测',
      type: 'line',
      lineStyle: { type: 'dashed' },
      data: [null, null, 710, 760, 800]
    }
  ]
});
```

> [!TIP]
> **建议内容**：预测段与实绩段必须用线型或颜色区分，并在提示框与图例中写明口径；没有任何视觉区分的预测线是数据图表里最常见的误导来源之一。

**速记**：区间着色用分段 visualMap，预测段虚线另起系列并接在实绩末端，阈值与极值用 markLine 与 markPoint。



### 饼图与占比表达

饼图用扇形角度表达占比，是最容易被滥用的一类图。本节给出饼图与环形图的规范画法、玫瑰图的适用边界，以及占比场景下的替代选型。



#### 饼图与环形图

**饼图（pie）**：是以扇形角度表达各部分占整体的份额的系列类型；**环形图（donut chart）**：是把饼图中心挖空的形态，radius 写成数组即得。

- 扇形数量控制在六块以内，小份额过多时合并为「其他」并注明口径。
- 扇形按占比从大到小、从十二点方向顺时针排布，读图顺序稳定。
- 占比接近的扇形肉眼难分大小，标签上直接给出百分比数值而不是只靠角度。
- label 的 alignTo 与 edgeDistance 控制引导线标签贴边对齐，避免标签重叠。
- 环形图中心区域可放总量数字，用 graphic 或标题组件叠放。

```js
chart.setOption({
  tooltip: { trigger: 'item', formatter: '{b}: {c} ({d}%)' },
  legend: { orient: 'vertical', left: 'left' },
  series: [{
    name: '渠道占比',
    type: 'pie',
    radius: ['42%', '68%'],
    center: ['55%', '50%'],
    avoidLabelOverlap: true,
    itemStyle: { borderRadius: 4, borderColor: '#fff', borderWidth: 2 },
    label: { show: true, formatter: '{b} {d}%' },
    data: [
      { value: 1048, name: '直接访问' },
      { value: 735, name: '搜索引擎' },
      { value: 580, name: '外部链接' },
      { value: 484, name: '社交媒体' },
      { value: 300, name: '其他' }
    ]
  }]
});
```

**速记**：饼图扇形不超过六块、按占比顺时针排布，环形图挖空放总量，标签带百分比。



#### 玫瑰图与变形的适用边界

**玫瑰图（roseType）**：是把扇形半径也纳入数值表达的饼图变形，角度与半径同时编码数值。

- 玫瑰图的双重编码让占比与数值难以各自读准，面积随半径平方增长，视觉差异被放大。
- 适合场合是对数值差异做强调性展示的汇报场景，不适合需要精确读数的分析页面。
- 扇形数量多时玫瑰图可读性迅速劣化，比普通饼图更依赖控制数量。
- 3D 饼图与各类立体变形会引入透视失真，角度不再与数值成比例，分析场景一律不用。
- 需要强调单个份额时，可高亮该扇形（emphasis）而不是改用变形图型。

```js
series: [{
  type: 'pie',
  roseType: 'radius',
  radius: ['15%', '70%'],
  data: [
    { value: 40, name: 'A 类' },
    { value: 32, name: 'B 类' },
    { value: 24, name: 'C 类' },
    { value: 18, name: 'D 类' }
  ]
}]
```

> [!WARNING]
> **警告内容**：玫瑰图与 3D 饼图的图形面积、角度与数值不再保持线性对应，读图者无法从图形准确还原占比，正式分析报告中不应使用这两类变形。

**速记**：玫瑰图是强调型展示不是精确读数工具，3D 饼图在分析场景一律不用。



#### 占比场景的替代选型

**替代选型**：是在占比表达中用其它图型替换饼图的做法，依据是比较目标选择替代品。

- 类目较多或需要精确比较份额时用排序后的条形图，长度差比角度差易读得多。
- 需要表达占比随时间变化时用百分比堆叠面积图或百分比堆叠柱状图。
- 单个指标达成率用环形进度或仪表盘，不必画整张饼图。
- 两期占比对比用双条形图或斜率图，两张并排饼图很难对出变化。
- 保留饼图的场合是：类目少、强调构成关系、不需要精确比较份额。

```js
// 占比对比：两期并列条形图，比并排两张饼图可读
chart.setOption({
  legend: { data: ['上期', '本期'] },
  grid: { left: 96, right: 32, containLabel: true },
  xAxis: { type: 'value', axisLabel: { formatter: '{value}%' } },
  yAxis: { type: 'category', data: ['直接访问', '搜索引擎', '外部链接', '社交媒体'] },
  series: [
    { name: '上期', type: 'bar', data: [32, 28, 22, 18] },
    { name: '本期', type: 'bar', data: [27, 31, 25, 17] }
  ]
});
```

**速记**：精确比较份额用排序条形图，占比随时间用百分比堆叠，两期对比用并列条形图，饼图只留给类目少且重构成的场合。



### 组合图表与综合实战

真实页面常见的是一张图里同时回答两个问题：数量对比与趋势变化、总量与比率。本节覆盖柱线组合、散点气泡与雷达图三类组合与多维表达，配置思路可以迁移到其它组合。



#### 柱线组合与双轴

**柱线组合**：是把柱状系列与折线系列放进同一坐标系的画法，柱表达每期数值、线表达趋势或比率；**双轴**：是新增第二根 y 轴承载量纲不同的系列。

- 第 14 篇给过双轴的最小配置，本节关注实战细节：两轴刻度要对齐网格、图例与提示框要把两类系列合并呈现。
- 第二根轴不带 splitLine，两组分割线重叠会造成读数混乱。
- yAxisIndex 指明系列归属，漏写时系列默认挂第一轴，量纲错位表现为折线被压平。
- 双轴的零线尽量对齐（min、max 成比例设置），交叉的零线会让正负读数失真。
- 双轴仅在量纲一致或有明确换算关系时使用，误导风险见第 14 篇的警告。

```js
chart.setOption({
  tooltip: { trigger: 'axis', axisPointer: { type: 'cross' } },
  legend: { data: ['销售额', '毛利率'] },
  grid: { left: 56, right: 56, bottom: 48, containLabel: false },
  xAxis: { type: 'category', data: ['一月', '二月', '三月', '四月', '五月', '六月'] },
  yAxis: [
    { type: 'value', name: '万元', splitLine: { show: true } },
    { type: 'value', name: '%', min: 0, max: 100, splitLine: { show: false }, axisLabel: { formatter: '{value}%' } }
  ],
  series: [
    { name: '销售额', type: 'bar', data: [420, 480, 510, 460, 530, 580] },
    { name: '毛利率', type: 'line', yAxisIndex: 1, data: [31, 33, 34, 32, 35, 36], smooth: false }
  ]
});
```

**速记**：柱管数量、线管趋势，第二轴关分割线、写清 yAxisIndex，零线尽量对齐。



#### 散点图与气泡图

**散点图（scatter）**：是以点位置表达两个定量维度关系的系列类型；**气泡图（bubble chart）**：是在散点基础上用点的面积编码第三个维度的画法。

- 点数在数千以内散点图可直接绘制，更大规模先看本主题第 15 篇的大数据量配置。
- symbolSize 用回调按数值换算面积，感知上人眼读的是面积而不是半径，换算应以面积为准。
- 第三维的数值范围跨度大时，symbolSize 做开方或对数换算，避免最大点遮住全部其它点。
- 多组散点用多个系列区分，悬停 emphasis 放大点并配合 tooltip 读出完整数值。
- 需要标出相关趋势时叠加 markLine 或用 series 单独画参考线，不手工目测。

```js
chart.setOption({
  tooltip: {
    trigger: 'item',
    formatter: (p) => `${p.data[3]}：研发 ${p.data[0]}、市场 ${p.data[1]}、营收 ${p.data[2]}`
  },
  xAxis: { name: '研发投入', type: 'value' },
  yAxis: { name: '市场投入', type: 'value' },
  series: [{
    type: 'scatter',
    symbolSize: (val) => Math.sqrt(val[2]) / 2,
    data: [
      [120, 80, 3200, '甲产品'],
      [90, 130, 2600, '乙产品'],
      [200, 60, 5400, '丙产品'],
      [60, 40, 900, '丁产品']
    ]
  }]
});
```

**速记**：散点看两维关系、气泡面积编码第三维，尺寸换算以面积为准并做开方压缩。



#### 雷达图与多维对比

**雷达图（radar）**：是在多个放射状指标轴上同时表达一组或多组数值的图型，用于多维综合对比。

- 指标轴数量以三到八为宜，过多时相邻轴挤在一起，多边形失去辨识度。
- 各轴的 max 与 min 要按指标口径分别设置，统一 max 会把低量程指标压成贴心的三角形。
- 多组数据同图时系列线宽与填充透明度要克制，两层以上填充叠加后互相遮挡。
- 指标含义不同时雷达图读数只是相对比较，轴间连线长度没有跨轴可比性。
- 场景不合适时的替代：指标可分组时拆成小倍数柱状图，时序指标改折线。

```js
chart.setOption({
  legend: { data: ['本季度', '上季度'] },
  radar: {
    indicator: [
      { name: '接警响应', max: 100 },
      { name: '办结率', max: 100 },
      { name: '群众满意', max: 100 },
      { name: '巡查覆盖', max: 100 },
      { name: '宣传触达', max: 100 }
    ],
    radius: '65%'
  },
  series: [{
    type: 'radar',
    data: [
      { value: [88, 92, 95, 76, 70], name: '本季度' },
      { value: [80, 85, 90, 82, 60], name: '上季度', areaStyle: { opacity: 0.1 } }
    ]
  }]
});
```

> [!TIP]
> **建议内容**：雷达图各轴必须独立设定量程并在轴名上写清口径，跨轴比较长度没有意义；评估类场景先问一句「这些指标同质吗」，不同质的指标拆开各自表达。

**速记**：雷达图管多维相对对比，各轴独立定标，三到八条轴，异质指标拆开画。
