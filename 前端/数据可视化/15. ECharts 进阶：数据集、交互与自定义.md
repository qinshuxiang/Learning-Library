## ECharts 进阶：数据集、交互与自定义

### 数据集与数据转换

第 14 篇把数据直接写在 series.data 里，数据列一多就会出现重复与散乱。本节说明集中声明数据的 dataset、把列绑定到视觉通道的 encode，以及两类数据转换。

#### dataset 与 encode 的关系

**dataset**：是集中声明数据源的顶层配置，数据以二维表形式给出；**encode**：是写在系列里、声明各视觉通道对应哪一列的字段。

- source 写二维数组时首行默认作为维度名，也可用 dimensions 显式声明。
- source 写对象数组时键名即维度名，encode 用维度名引用。
- 系列通过 encode.x、encode.y、encode.itemName 等字段绑定列。
- 多个系列可共用同一份 dataset，不必重复书写数据数组。
- 不写 encode 时按默认约定取列，显式声明才能避免列序变化带来的错位。

```js
chart.setOption({
  dataset: {
    source: [
      ['产品', '2024', '2025'],
      ['甲', 120, 150],
      ['乙', 200, 180],
      ['丙', 150, 210]
    ]
  },
  xAxis: { type: 'category' },
  yAxis: { type: 'value' },
  series: [
    { type: 'bar', encode: { x: '产品', y: '2024' } },
    { type: 'bar', encode: { x: '产品', y: '2025' } }
  ]
});
```

**速记**：dataset 集中写数据，encode 把列绑定到视觉通道，多系列共用一个数据源。



#### 内置数据转换 transform

**数据转换（transform）**：是在 dataset 上按声明执行的加工步骤，以 dataset 数组的后续项表达。

- 转换项写成 transform: { type, config }，type 为转换名，config 传给该转换。
- 内置转换常用 filter 与 sort，前者按维度条件筛选行，后者按维度排序。
- 数组形式的 dataset 中，后一项默认以前一项为输入，可用 fromDatasetIndex 显式指定来源。
- 转换在绘制前执行，坐标轴范围与图例会随转换结果重新计算。

```js
chart.setOption({
  dataset: [
    {
      source: [
        ['产品', '销量'],
        ['甲', 120],
        ['乙', 200],
        ['丙', 60]
      ]
    },
    { transform: { type: 'filter', config: { dimension: '销量', gt: 100 } } }
  ],
  xAxis: { type: 'category' },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', encode: { x: '产品', y: '销量' } }]
});
```

**速记**：转换写在 dataset 数组里，后项默认接前项，filter 与 sort 是常用内置转换。



#### 自定义转换 registerTransform

**registerTransform(transformOption)**：是注册自定义转换的静态方法，注册后可在 dataset 的 transform 中按 type 引用。

- transformOption 由 type 与 transform 两部分组成，前者是调用名，后者是处理函数。
- 处理函数接收上游数据与 config 配置，返回处理后的二维数据。
- 注册必须早于 setOption，否则数据集初始化时找不到该转换。
- 可复用的清洗与派生计算适合放进转换，避免把计算散落在 formatter 里。

```js
echarts.registerTransform({
  type: 'scaleToPercent',
  // data 为上游数据集，config 为 transform.config 传入的配置
  transform: (data, config) => {
    const [header, ...rows] = data;
    return [header, ...rows.map((row) => [row[0], row[1] / 100])];
  }
});
```

> 自定义转换的入参形态与返回结构在跨版本时可能调整，落地前以所用版本的文档为准。

**速记**：registerTransform 注册自定义转换，处理函数接上游数据与配置，注册要早于 setOption。



### 异步数据与加载状态

真实项目中数据来自网络。本节说明请求与 setOption 的先后关系、加载提示的使用，以及向已有系列追加数据的做法。

#### 数据获取与 setOption 时机

**异步加载**：是先以空配置初始化图表实例、待数据返回后再调用 setOption 填充的流程。

- 首次 setOption 可先给出坐标轴与系列骨架，数据返回后按字段合并新值。
- 需要丢弃旧序列时用 replaceMerge 指定按数组整体替换的键，而非整体清空配置。
- 请求失败时应给出失败态，避免图表长时间停留在空白或加载提示上。
- 过期响应必须丢弃，防止先发出的慢请求覆盖后发出的新数据。

```js
async function loadChartData(chart, url) {
  const response = await fetch(url);
  const rows = await response.json();
  chart.setOption(
    { series: [{ data: rows.map((item) => item.value) }] },
    { replaceMerge: ['series'] }
  );
}
```

**速记**：先建骨架后填数据，第二次 setOption 按字段合并，并处理失败与过期响应。



#### showLoading 与 hideLoading

**showLoading(type, opts)**：是在容器上覆盖加载提示的方法，opts 可写 text、color、textColor 与 maskColor；**hideLoading()**：移除该提示。

- 请求开始前调用 showLoading，成功或失败后都必须调用 hideLoading。
- 加载提示覆盖整个容器，与图表当前内容无关。
- 并发请求应按计数收尾，最后一个完成后才移除提示。
- 极快返回的请求会让提示一闪而过，可按耗时阈值延迟显示。

```js
function requestChartData(chart, url) {
  chart.showLoading('default', {
    text: '加载中',
    maskColor: 'rgba(255, 255, 255, 0.6)'
  });
  return fetch(url)
    .then((response) => response.json())
    .finally(() => chart.hideLoading());
}
```

**速记**：showLoading 与 hideLoading 成对出现，并发请求按计数收尾，避免提示残留。



#### appendData 与增量追加

**appendData({seriesIndex, data})**：是向已有系列尾部追加数据的实例方法，用于流式或滚动更新的场景。

- 仅部分系列类型支持追加，使用前需确认所用系列类型的支持情况。
- 追加数据的格式必须与该系列初始 data 一致。
- 追加不清空既有数据，适合逐点到达的实时数据。
- 需要限制历史长度时应在追加后裁掉过旧的数据，控制累计内存。

```js
chart.appendData({
  seriesIndex: 0,
  data: [[Date.now(), 128]]
});
```

**速记**：appendData 向系列尾部追加数据，格式须与初始数据一致，历史长度自行裁剪。



### 交互、事件与联动

图表交付后面对的是一系列交互行为。本节说明事件的绑定与解绑、主动触发动作，以及多图联动的配置方式。

#### 事件绑定与解绑 on／off

**on(eventName, handler, context)**：是绑定实例事件的方法；**off(eventName, handler)**：是解绑对应处理函数的方法。

- 回调参数含 seriesIndex、dataIndex、name 与 value 等字段。
- 常用事件有 click、mouseover、legendselectchanged、datazoom 与 rendered。
- 绑定时可先传 query 对象，把事件限定到某个系列或组件。
- 组件卸载时应解绑处理函数，避免重复绑定与内存泄漏。

```js
function handleSeriesClick(params) {
  console.log(params.seriesIndex, params.dataIndex, params.value);
}

chart.on('click', { seriesIndex: 0 }, handleSeriesClick);

// 卸载时
chart.off('click', handleSeriesClick);
```

> [!CAUTION]
> **注意内容**：同一事件反复绑定同一处理函数，会在一次触发中按绑定次数执行多次，绑定与解绑必须成对管理。

**速记**：on 绑定、off 解绑，回调参数带系列与数据下标，可用 query 限定触发范围。



#### dispatchAction 主动触发

**dispatchAction(payload)**：是主动触发图表行为的方法，payload 以 type 区分动作，如 highlight、downplay、showTip、legendSelect 与 dataZoom。

- 主动高亮数据项用于在外部控件操作时引导注意力。
- legendSelect 与 legendUnSelect 可按系列名切换图例状态。
- dataZoom 动作可让外部滑块与图表的数据窗口保持同步。
- 动作执行后会派发对应事件，注意避免与事件回调互相触发形成循环。

```js
chart.dispatchAction({
  type: 'highlight',
  seriesIndex: 0,
  dataIndex: 2
});
```

**速记**：dispatchAction 按 type 主动触发交互行为，常与外部的列表与控件配合。



#### connect 联动与 dataZoom、brush

**connect(target)**：是把若干图表实例连成一组、组内交互互相广播的静态方法；**brush**：是框选组件的配置项。

- 分组由 init 的 opts.group 指定，也可直接把实例数组传给 connect。
- 默认联动提示框与数据区域缩放，同组图表随之更新视图。
- brush 配合 brushLink 可把一幅图中的框选范围映射到其他图。
- 不再需要联动时用 disconnect 解除，避免无关图表互相干扰。

```js
const group = 'report';
const chartA = echarts.init(document.getElementById('chart-a'), null, { group });
const chartB = echarts.init(document.getElementById('chart-b'), null, { group });
echarts.connect(group);

chartA.setOption({
  tooltip: { trigger: 'axis' },
  brush: { toolbox: ['rect', 'clear'], brushLink: 'all' },
  xAxis: { type: 'category', data: ['一月', '二月', '三月'] },
  yAxis: { type: 'value' },
  series: [{ type: 'bar', data: [120, 200, 150] }]
});
```

**速记**：同 group 的图表用 connect 联动，brush 配 brushLink 把框选范围传到其他图。



### 自定义系列与自定义渲染

内置图表类型覆盖不了所有图形。本节说明自定义系列的适用边界、renderItem 的写法，以及不参与数据映射的图形组件。

#### 什么时候用自定义系列

**自定义系列（custom series）**：是 series[i].type 取 custom 的系列类型，由调用方在 renderItem 中自行返回图形元素。

- 适用：需要在坐标系内绘制连线、图标或规则图形时。
- 不适用：图形只是内置类型的样式变体，改 itemStyle 即可解决。
- 代价：尺寸换算、裁剪与层级顺序都需要自行处理。
- 与图形组件的分工：随数据变化与缩放选自定义系列，固定装饰选 graphic。

```js
chart.setOption({
  xAxis: { type: 'value' },
  yAxis: { type: 'value' },
  series: [{
    type: 'custom',
    encode: { x: 0, y: 1 },
    data: [[10, 20], [30, 45], [50, 12]],
    renderItem: renderMarkItem
  }]
});
```

**速记**：custom 系列由 renderItem 返回图形，适合内置类型无法表达的坐标系内图形。



#### renderItem(params, api) 的写法

**renderItem(params, api)**：是自定义系列的绘制函数，params 提供当前数据项与坐标系信息，api 提供取值与坐标换算能力，返回一个图形描述对象或对象数组。

- api.value(dimIndex) 取当前项指定维度的原始值。
- api.coord([x, y]) 把数据坐标换算为容器内的像素坐标。
- api.size([w, h]) 把数据跨度换算为像素尺寸。
- params.dataIndex 定位当前项，params.coordSys 提供坐标系边界信息。
- 返回对象的 type 取 rect、circle、line 等，style 可用 api.style() 继承系列样式。

```js
function renderMarkItem(params, api) {
  const center = api.coord([api.value(0), api.value(1)]);
  const size = api.size([0, 10]);
  return {
    type: 'rect',
    shape: {
      x: center[0] - 5,
      y: center[1],
      width: 10,
      height: size[1]
    },
    style: api.style()
  };
}
```

**速记**：renderItem 用 api.value 取值、api.coord 换算坐标、api.size 换算尺寸，返回图形描述对象。



#### 图形组件 graphic 的用途

**graphic**：是 option 顶层用于直接挂载图形元素的组件，元素不参与数据映射，位置以像素或百分比给出。

- 适合水印、标题装饰、说明线与自定义标记。
- 元素可指定 id，后续通过 setOption 按 id 更新或删除。
- 多个元素可用 group 类型归组，统一设置位置与变换。
- 元素不随坐标系缩放，需要跟随数据的场景应改用自定义系列。

```js
chart.setOption({
  graphic: [{
    id: 'watermark',
    type: 'text',
    right: 16,
    bottom: 12,
    style: { text: '内部资料', fill: 'rgba(0, 0, 0, 0.15)', fontSize: 20 }
  }]
});

// 只移除该元素，其余配置保持不变
chart.setOption({ graphic: [{ id: 'watermark', $action: 'remove' }] });
```

**速记**：graphic 挂载不参与数据映射的图形，按 id 更新与删除，随数据缩放的需求归自定义系列。



### 扩展与二次开发

库留出的扩展位置决定了二次开发的边界。本节说明按需注册机制、地图数据注册，以及数据、组件与渲染三层扩展点。

#### 组件与系列的注册机制

**注册机制**：是按需引入时用 echarts.use 把图表类型、组件与渲染器注册进核心对象的过程，未注册的能力不会出现在配置中。

- 按需引入的每个图表类型、坐标系组件与特性模块都需要注册。
- 注册是全局的，注册一次后所有实例都可使用。
- 漏注册时 setOption 不会报错，但对应图形或组件不会渲染，排查时优先检查注册清单。
- 新增能力应在统一的入口模块注册，避免散落在业务代码各处。

```js
import * as echarts from 'echarts/core';
import { CustomChart, ScatterChart } from 'echarts/charts';
import { DatasetComponent, TransformComponent, TooltipComponent } from 'echarts/components';
import { CanvasRenderer } from 'echarts/renderers';

echarts.use([
  CustomChart,
  ScatterChart,
  DatasetComponent,
  TransformComponent,
  TooltipComponent,
  CanvasRenderer
]);
```

**速记**：use 是按需引入的注册开关，图表、组件与渲染器都要注册，漏注册时静默不渲染。



#### 地图数据注册 registerMap

**registerMap(mapName, geoJson, specialAreas)**：是把地理数据注册进指定地图名的方法，注册后 map 系列与 geo 组件可按名引用。

- mapName 为自定义地图名，series.map 与 geo.map 引用它。
- geoJson 为地理数据对象，通常由 GeoJSON 文件或简化后的版本提供。
- 地图数据体积较大，应按需引入并对边界做简化处理。
- 需要为中国地图做特殊区域处理时，用 specialAreas 把数据合并到指定区域。

```js
import chinaGeoJson from './geo/china.json';

echarts.registerMap('china', chinaGeoJson);

chart.setOption({
  geo: { map: 'china', roam: true },
  series: [{
    type: 'scatter',
    coordinateSystem: 'geo',
    data: [[116.4, 39.9, 120]]
  }]
});
```

> [!IMPORTANT]
> **重要内容**：绘制中国地图必须使用自然资源部发布的标准地图或经审核的地图数据，不得自行绘制国界线；中国全图必须完整表示台湾、藏南、南海诸岛及钓鱼岛、赤尾屿等，涉及香港、澳门、台湾时表述为中国香港、中国澳门、中国台湾。

**速记**：registerMap 注册后按地图名引用，中国地图必须使用经审核的标准地图数据。



#### 第三方扩展与底层协作

**扩展点**：是库在数据、组件与渲染三层留出的接入位置，第三方能力与自研逻辑都从这三层进入。

- 数据层：自定义数据集与自定义转换，适合派生指标与清洗逻辑。
- 组件层：自定义系列与 graphic 元素，适合新图形与装饰。
- 渲染层：在容器内叠加其他绘制结果，或替换渲染器实现。
- 协作原则：容器尺寸与生命周期由外层统一管理，叠加内容与图表共享同一套尺寸与销毁时机。

> 跨渲染层的通用性能手法不属本篇范围，详见本主题第 18 篇 大数据量与渲染性能优化。

**速记**：扩展点分数据、组件与渲染三层，自研能力从对应层接入并共享容器的尺寸与生命周期。



### 大数据量性能配置

本节只覆盖 ECharts 自身的性能字段：批量绘制模式、渐进渲染与降采样。跨渲染层的通用优化手法归第 18 篇。

#### large 模式与 largeThreshold

**large 模式**：是图形密集型系列开启的批量绘制模式；**largeThreshold**：是进入该模式的数据量阈值。

- 开启后单个图形不再保留独立的交互状态，逐点提示与高亮会失效。
- 阈值的意义是避免小数据量下支付批量绘制的固定开销。
- 批量绘制与逐点动画互斥，开启后应同时关闭逐点动画效果。
- 图形数量达到万级时应先评估是否改用聚合或分箱表达。

```js
chart.setOption({
  xAxis: { type: 'value' },
  yAxis: { type: 'value' },
  series: [{
    type: 'scatter',
    large: true,
    largeThreshold: 2000,
    symbolSize: 3,
    data: generatePoints(50000)
  }]
});
```

**速记**：large 模式按 largeThreshold 阈值开启批量绘制，代价是丧失逐点交互与动画。



#### 渐进渲染与 progressiveThreshold

**progressive**：是每帧参与绘制的图形数量；**progressiveThreshold**：是启用渐进渲染的数据量阈值。

- 数据量超过阈值后图形被拆成多批在连续帧中绘制，避免单帧长时间阻塞。
- progressive 数值越小，单帧工作量越少，但绘制完成所需的帧数越多。
- 两个字段可在实例级设置，也可下放到单个系列。
- 渐进绘制未完成时部分交互需要等待，应配合加载提示告知进度。

```js
chart.setOption({
  progressive: 400,
  progressiveThreshold: 3000,
  animation: false,
  series: [{
    type: 'line',
    showSymbol: false,
    data: loadSeriesData()
  }]
});
```

**速记**：progressive 定每帧工作量，progressiveThreshold 定启用门槛，用分帧换流畅。



#### 降采样 sampling

**降采样（sampling）**：是在绘制前按规则从原始数据中挑出代表点的做法，用于在不改变整体趋势的前提下减少绘制量。

- 常用取值有 lttb、average、max、min 与 sum，lttb 在保留峰谷形状上表现较好。
- samplingThreshold 指定启用降采样的数据量阈值。
- 降采样只影响绘制取点，提示框与坐标轴读数仍来自原始数据。
- 需要精确读出每个点的场景不应降采样，应改用分段缩放或按需加载。

```js
chart.setOption({
  xAxis: { type: 'time' },
  yAxis: { type: 'value' },
  series: [{
    type: 'line',
    showSymbol: false,
    sampling: 'lttb',
    samplingThreshold: 5000,
    data: loadSeriesData()
  }]
});
```

> [!TIP]
> **建议内容**：large 模式与降采样都会改变图形的呈现精度，开启后应对比开关前后的视觉效果，再决定是否保留。

**速记**：sampling 用 lttb 等规则挑代表点，只改绘制不改读数，精确读数场景不用降采样。
