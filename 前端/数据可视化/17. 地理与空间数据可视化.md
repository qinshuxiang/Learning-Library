## 地理与空间数据可视化

### 地理数据格式

地理可视化的输入是带坐标的空间数据，格式决定了能表达哪些对象。本节说明 GeoJSON 的结构、几何类型与压缩格式。

#### GeoJSON 的结构

**GeoJSON**：是基于 JSON 的地理空间数据交换格式，用若干带类型的几何对象与属性字段描述点、线、面及其业务信息。

- 顶层类型：Feature、FeatureCollection 与各类几何对象；FeatureCollection 的 features 字段存放要素数组。
- 要素：Feature 由 geometry 与 properties 两个字段组成，前者是几何，后者是业务属性。
- 规范依据：RFC 7946 规定字段名、坐标顺序与坐标参考系，是各软件互操作的基础。
- 坐标参考系：默认使用 WGS84 经纬度（EPSG:4326），文件本身不携带投影信息。

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": { "name": "示例区", "value": 128 },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [[116.0, 39.0], [116.6, 39.0], [116.6, 39.6], [116.0, 39.6], [116.0, 39.0]]
        ]
      }
    }
  ]
}
```

> 属性字段名没有统一约定，接入前先确认数据源用的是什么键名，再写取值访问器。

**速记**：GeoJSON 以 Feature 与 FeatureCollection 组织数据，几何与属性分离，坐标默认是 WGS84 经纬度。



#### 几何类型与坐标顺序

**几何类型**：是 GeoJSON 允许的对象种类，覆盖零维到二维的空间对象。

- 点与多点：Point 与 MultiPoint 的 coordinates 是单个坐标或坐标数组。
- 线与多线：LineString 与 MultiLineString 由若干坐标点顺序连接。
- 面与多面：Polygon 与 MultiPolygon 由若干闭合环组成，第一个环是外环，其余是内环即孔洞。
- 集合：GeometryCollection 把不同几何类型放在同一对象内。
- 坐标顺序：每个坐标是「经度在前、纬度在后」的数组，可再带一位高程。

```js
function toScreen(projection, feature) {
  const [longitude, latitude] = feature.geometry.coordinates;
  return projection([longitude, latitude]); // [x, y]
}
```

> [!CAUTION]
> **注意内容**：GeoJSON 的坐标顺序是经度在前、纬度在后，与日常「纬度在前」的读法相反；顺序写反会把位置落到错误的大洲。

**速记**：几何类型覆盖点、线、面及各自的集合，坐标一律经度在前、纬度在后。



#### TopoJSON 与体积优化

**TopoJSON**：是 GeoJSON 的拓扑扩展格式，把相邻要素共享的边界只存一次，因此体积更小。

- 拓扑编码：文件以 arcs 存放弧段，几何对象通过引用弧段下标表达位置。
- 转换：使用 topojson-client 的 topojson.feature(topology, object) 还原为 GeoJSON 要素。
- 取边界：topojson.mesh(topology, object, filter) 返回由弧段组成的网格，常用于只画边界。
- 取值入口：几何对象挂在 topology.objects 下，按名称取用。
- 常用手段：坐标量化与顶点简化可进一步减小体积，代价是形状精度下降。

```js
import * as topojson from "topojson-client";

const regions = topojson.feature(topology, topology.objects.regions);
// 只取相邻区域的公共边界
const interiorBorders = topojson.mesh(topology, topology.objects.regions, (a, b) => a !== b);
```

> 体积与精度需要权衡：底图缩放级别较低时，适度简化顶点几乎不影响观感，文件却能小一个量级。

**速记**：TopoJSON 共享边界、以弧段引用表达几何，用 topojson.feature 还原要素，用 topojson.mesh 取边界。



### 地图投影与变形

投影决定球面坐标如何落到平面上，也决定了地图看起来是否「正常」。本节说明投影的本质、常用类型与适配方式。

#### 投影的本质

**投影（projection）**：是把球面上的经纬度换算为平面坐标的函数，D3 中即一个接收经纬度、返回平面坐标的函数对象。

- 正向与反向：projection([longitude, latitude]) 返回平面坐标，projection.invert([x, y]) 返回经纬度。
- 不可兼得：面积、形状、角度与距离无法同时保真，任何投影都要放弃其中若干项。
- 变形类型：等角投影保持局部角度与形状，等积投影保持面积比例，等距投影保持特定方向的距离，折中投影在各指标间取平衡。
- 参数：center、rotate、scale、translate 共同决定观察中心、朝向与缩放。

```js
const projection = d3.geoMercator();

projection([116.4, 39.9]);       // [x, y] 平面坐标
projection.invert([480, 250]);   // [经度, 纬度]
```

> 投影是纯函数式的换算，不改变数据本身；同一份数据换一个投影函数即可得到另一种布局。

**速记**：投影是经纬度到平面坐标的函数，可正反换算，等角、等积、等距与折中四类各有取舍。



#### 常见投影与适用场景

**投影选择**：是按表达的区域范围与要强调的指标挑选投影类型，避免用面积失真严重的投影比较面积。

- 墨卡托：d3.geoMercator() 为等角投影，局部形状与方位保真，面积随纬度迅速放大，是网络瓦片底图的标准投影。
- 经纬等距：d3.geoEquirectangular() 直接把经纬度线性映射，最易理解，适合教学与全球概览。
- 折中投影：d3.geoNaturalEarth1() 在面积与形状之间取平衡，全球地图观感较均匀。
- 等积与球面：d3.geoAzimuthalEqualArea() 保持面积比例，d3.geoOrthographic() 呈现地球视角。
- 圆锥类：d3.geoConicConformal() 与 d3.geoAlbers() 适合中纬度、东西跨度较大的国家或区域。

```js
const globalView = d3.geoNaturalEarth1().fitSize([width, height], world);

const areaView = d3.geoAzimuthalEqualArea()
  .rotate([-105, 0])
  .fitSize([width, height], region);
```

> [!WARNING]
> **警告内容**：用墨卡托投影比较不同纬度的区域面积会严重夸大高纬度地区，例如看起来比实际大得多；涉及面积比较必须换用等积投影。

**速记**：全球概览用自然地球或经纬等距，形状与方位优先用墨卡托，面积比较必须用等积投影，中纬度区域可用圆锥类投影。



#### 缩放、平移与自动适配

**适配与调参**：是通过参数或自动计算把感兴趣的区域放进画布，避免手工试错比例与位移。

- 手动参数：scale(k) 设比例，translate([x, y]) 设平移，center([longitude, latitude]) 设观察中心，rotate 设球面朝向。
- 自动适配：fitSize([width, height], object) 按对象包围盒计算 scale 与 translate，使其恰好填满给定尺寸。
- 带边距适配：fitExtent([[x0, y0], [x1, y1]], object) 适配到内缩后的矩形，留出轴标与图例空间。
- 重算时机：数据范围变化后需重新调用适配，否则新几何可能超出画布。

```js
const projection = d3.geoEquirectangular();

projection.fitExtent(
  [[24, 16], [width - 24, height - 16]],
  regions
);
```

> 自动适配只保证包围盒贴合，形状特殊的对象仍可能在角落留白，必要时用 rotate 调整观察中心后再适配。

**速记**：scale、translate、center、rotate 手工调参，fitSize 与 fitExtent 按包围盒自动适配，数据变化后须重算。



### 静态地图绘制

静态地图的绘制路径是：先投影，再把投影结果渲染为元素。本节说明路径生成、区域填充与标注定位。

#### geoPath 生成路径

**路径生成器（path generator）**：是 d3.geoPath(projection) 返回的函数，接收 GeoJSON 几何对象并输出 SVG 路径字符串。

- 基本用法：把几何对象作为参数调用，返回的字符串直接写入 path 元素的 d 属性。
- 输入范围：可接收单个几何、Feature 或 FeatureCollection。
- 点半径：pointRadius(r) 控制点与多点的半径，配合投影使用。
- 转 Canvas：context(ctx) 让生成器改为向二维上下文输出，与 SVG 路径共用同一套几何计算。

```js
const pathGen = d3.geoPath().projection(projection);

svg.append("path")
  .attr("d", pathGen(regions))
  .attr("fill", "#dfe8f3")
  .attr("stroke", "#ffffff")
  .attr("stroke-width", 0.5);
```

> 路径生成器与投影解耦：换投影只需重建生成器或调用其 projection 方法，几何与属性数据不动。

**速记**：d3.geoPath 把几何对象换算为路径字符串，支持点半径与 Canvas 上下文，换投影不必改数据。



#### 区域填充与边界

**区域填充**：是把面要素逐个绑定到路径元素，并按属性换算填充色，即分级设色地图的基本形态。

- 绑定方式：把 FeatureCollection 的 features 数组与路径元素做数据连接。
- 配色：颜色比例尺的输入取自属性的数值字段，先确认字段类型再设定义域。
- 边界叠加：单独绘制公共边界可让区域轮廓更清晰，边界数据由拓扑的 mesh 结果提供。
- 交互钩子：每个面元素自带事件，可直接挂悬停与点击。
- 绘制顺序：填充在下、边界与标注在上，避免被遮挡。

```js
svg.selectAll("path.region")
  .data(regions.features)
  .join("path")
  .attr("class", "region")
  .attr("d", pathGen)
  .attr("fill", (d) => colorScale(d.properties.value));
```

> [!WARNING]
> **警告内容**：绘制中国地图必须使用自然资源部发布的标准地图或经审核的地图数据，不得自行绘制或拼接国界线；未经审核的地图不得公开使用。

**速记**：把面要素绑定到路径元素并按属性换算填充色，边界与标注单独叠加，中国地图必须使用标准地图或经审核数据。



#### 按经纬度定位标注

**坐标定位**：是先把经纬度经投影换算为平面坐标，再把点、文字等元素放到该位置。

- 换算：projection([longitude, latitude]) 返回平面坐标，取两个分量分别作为横纵坐标。
- 与路径生成器分工：面数据交给 geoPath，点与标注自行定位更易控制大小与排版。
- 经纬网：d3.geoGraticule() 生成经纬线对象，交给 geoPath 即得网格背景。
- 引出与避让：密集点位需配合引导线、聚合或错位标注，避免相互压盖。

```js
const graticule = d3.geoGraticule().step([10, 10]);

svg.append("path")
  .datum(graticule())
  .attr("d", pathGen)
  .attr("fill", "none")
  .attr("stroke", "#e3e8ef");

const cities = [{ name: "示例城", coord: [116.4, 39.9], value: 42 }];

svg.selectAll("circle.city")
  .data(cities)
  .join("circle")
  .attr("class", "city")
  .attr("cx", (d) => projection(d.coord)[0])
  .attr("cy", (d) => projection(d.coord)[1])
  .attr("r", (d) => Math.sqrt(d.value));
```

> 经纬网的疏密随缩放级别调整才有可读性，固定步长在地图放大后会变成一团密线。

**速记**：标注先经投影换算再定位元素，经纬网由 d3.geoGraticule 生成，密集点位需要引导与避让。



### 瓦片与在线底图

在线地图由切好的瓦片图片拼成，矢量图层叠加其上。本节说明瓦片编号、与视图对齐的方式，以及底图的合规要求。

#### 瓦片金字塔与编号

**瓦片（tile）**：是把地图按层级切成固定尺寸的小图片，按层级、列号与行号组织成金字塔结构。

- 层级：第 0 层是世界地图的一张图，每增加一层，行列数各翻一倍。
- 编号：常见写法为 z 表示层级、x 表示列、y 表示行，地址模板中以占位符填入。
- 坐标系：网页瓦片普遍使用 Web 墨卡托（EPSG:3857），与 d3.geoMercator 的算法一致。
- 方案差异：XYZ 方案的行号自上而下递增，TMS 方案自下而上，两者换算关系为 y 取补。

```bash
# 常见的瓦片地址模板
https://tile.example.com/{z}/{x}/{y}.png
```

> 使用任何瓦片服务前都要确认其服务条款允许的请求量、是否要求署名、是否允许离线缓存。

**速记**：瓦片按 z、x、y 编号组成金字塔，使用 Web 墨卡托与 XYZ 或 TMS 行号方案，边长通常为 256 像素。



#### 与地图视图对齐

**视图对齐**：是让瓦片图片的位置与矢量图层的投影一致，使两类图层落在同一处。

- 比例关系：瓦片世界在缩放层级 z 下的像素宽度为 256 乘 2 的 z 次方，而墨卡托投影的比例与像素宽度除以 2π 成正比。
- 计算方式：D3 核心不含瓦片模块，需要自行计算瓦片编号与像素偏移，或借助社区提供的瓦片工具。
- 反算编号：由经纬度与层级算出行列号，公式为行列各按归一化后的经纬度取整。
- 叠加：把矢量路径与瓦片放在同一容器，共用同一投影参数，缩放时同步更新。

```js
function mercatorScale(tileSize, zoom) {
  // 瓦片世界宽度除以经度方向的总弧度
  return (tileSize * Math.pow(2, zoom)) / (2 * Math.PI);
}

function lngLatToTile(longitude, latitude, zoom) {
  const n = Math.pow(2, zoom);
  const x = Math.floor(((longitude + 180) / 360) * n);
  const latRad = (latitude * Math.PI) / 180;
  const y = Math.floor(
    ((1 - Math.log(Math.tan(latRad) + 1 / Math.cos(latRad)) / Math.PI) / 2) * n
  );
  return { x, y };
}
```

> 图层叠加时最容易出现的是「矢量与底图错位半格」，多半来自瓦片行列取整方式或 TMS 行号方向不一致。

**速记**：瓦片比例等于 256 乘 2 的 z 次方除以 2π，矢量与底图必须共用投影并同步更新，行号方案不同会导致错位。



#### 底图来源与合规

**底图合规**：是地图可视化中最容易被忽略的约束，涉及数据来源、使用授权与国界表达三方面。

- 来源与授权：使用公开底图服务须遵守其服务条款，标注来源与版权信息，控制请求量并缓存。
- 数据阶段：公开使用的地图应基于经审核的地图数据或标准地图，并按规定标注审图号。
- 表达完整：国界线、岛屿与附属要素的表达必须完整，不得漏绘或错绘，区域表述使用规范用语。

> [!IMPORTANT]
> **重要内容**：中国全图必须完整表示台湾、藏南、南海诸岛及钓鱼岛、赤尾屿等，不得漏绘、错绘；涉及香港、澳门、台湾时表述为中国香港、中国澳门、中国台湾。

**速记**：底图须来源合规、标注版权与审图号，国界与岛屿表达完整且不得错绘，区域表述使用规范用语。



### 空间数据表达

同一份空间数据可用多种视觉形式表达，选择取决于要回答的问题。本节说明分级设色、点与气泡、流向与轨迹、密度与聚合。

#### 分级设色图

**分级设色图（choropleth）**：是按区域属性值给面要素填充不同颜色的地图，用于表达区域的相对水平。

- 比例尺：用连续色比例尺或分段比例尺把数值映射为填充色。
- 分级方法：等分、分位数、自然断点各有倾向，分级方式变化会改变读图结论，需要明示。
- 适用指标：适合表达比率、密度这类已归一化的指标，直接填绝对量会让大区域吃掉视觉权重。
- 图例：必须给出完整的色阶与取值范围，否则颜色无法解读。

```js
const valueOf = (d) => d.properties.value;

const colorScale = d3.scaleQuantize()
  .domain([0, d3.max(regions.features, valueOf)])
  .range(d3.schemeBlues[5]);
```

> [!TIP]
> **建议内容**：默认选用感知均匀的顺序色板并按数值大小排序，避免用分类色表达有序数据，否则读者无法判断高低。

**速记**：分级设色按属性值为区域填色，适合比率类指标并须给出图例，分级方法与色板选择都会影响解读。



#### 点与气泡

**点与气泡**：是用点标记位置，再用点的大小或颜色承载第二个变量的表达方式。

- 位置即坐标：投影后的平面坐标作为点的圆心位置。
- 大小映射：面积需与数值成正比，因此半径应按数值的平方根比例映射。
- 重叠处理：透明度、轻微抖动与聚合都是常用手段，重叠严重时应改用网格聚合。

```js
const radiusScale = d3.scaleSqrt()
  .domain([0, d3.max(cities, (d) => d.value)])
  .range([2, 28]);
```

> 半径直接按数值线性映射会让面积按平方增长，小数值之间的差异被压缩，是必须避免的错误做法。

**速记**：点标记位置、大小承载第二变量，半径须按平方根映射保证面积成比例，重叠严重时改用聚合。



#### 流向与轨迹

**流向表达**：是用线要素连接起点与终点，表达移动方向与强度的一类图形。

- 数据组织：用 LineString 或由两点临时构造的线，坐标序列由起点与终点组成。
- 大圆航线：d3.geoInterpolate(a, b) 返回球面插值函数，加密后可得到贴合地球的弧线。
- 落位：把插值得到的经纬度交给投影与路径生成器，即得弯曲的连线。
- 方向与强度：箭头标记方向，线宽映射流量，颜色区分类型，动画用于表现流动过程。

```js
function greatCircle(start, end, steps = 64) {
  const interpolate = d3.geoInterpolate(start, end);
  return {
    type: "LineString",
    coordinates: d3.range(steps + 1).map((i) => interpolate(i / steps))
  };
}

svg.append("path")
  .attr("d", pathGen(greatCircle([116.4, 39.9], [121.5, 31.2])))
  .attr("fill", "none")
  .attr("stroke", "#e07a5f");
```

> 平面直线在地图上会显得不自然，跨区域连线应使用球面插值后的折线，而不是两点直连。

**速记**：流向用线要素连接起止点，跨区域连线经 d3.geoInterpolate 球面插值加密后更自然，线宽与箭头承载强度与方向。



#### 密度与聚合

**密度表达**：是在点数据过密时改用聚合结果呈现分布趋势的一类做法。

- 网格聚合：把空间切成网格，统计落入每格的点数，再用设色或柱高表达。
- 等值密度：d3.contourDensity() 由散点估算密度并输出等值多边形，可直接交给路径生成器绘制。
- 热力渲染：在 Canvas 上叠加模糊的半透明圆点，再按阈值染色，适合交互式实时更新。
- 渲染选择：聚合后的图形数量远少于原始点，但底图与聚合层仍需分层管理。

```js
const density = d3.contourDensity()
  .x((d) => projection(d.coord)[0])
  .y((d) => projection(d.coord)[1])
  .size([width, height])
  .bandwidth(24);

const contours = density(points); // 平面坐标下的等值多边形

svg.selectAll("path.contour")
  .data(contours)
  .join("path")
  .attr("d", d3.geoPath()) // 无投影时按原坐标直接输出
  .attr("fill", "none")
  .attr("stroke", "#b45309");
```

> 等值密度的带宽参数直接决定平滑程度：过小会碎成许多孤立斑块，过大会抹掉真实的局部结构。

**速记**：密度表达用网格聚合、等值密度或热力渲染代替逐个画点，d3.contourDensity 输出等值多边形，带宽决定平滑程度。



### 空间交互

地图的可读性依赖缩放、拾取与联动。本节说明视图控制、区域拾取与多视图联动的常用做法。

#### 缩放与平移

**视图控制**：是把用户的手势换算为地图的缩放与位移，D3 由 d3.zoom() 统一处理。

- 绑定：d3.zoom() 创建行为，经 selection.call 绑到画布或容器元素上。
- 两种做法：对容器施加整体变换实现快速缩放，或改写投影的 scale 与 translate 后重绘路径。
- 差别：整体变换会让线宽与文字一起放大，重设投影能保持线宽与标签字号不变。
- 限制：scaleExtent([min, max]) 限定缩放范围，防止缩放到无意义的级别。

```js
const zoomBehavior = d3.zoom()
  .scaleExtent([1, 8])
  .on("zoom", (event) => {
    const { k, x, y } = event.transform;
    projection.scale(baseScale * k).translate([baseX + x, baseY + y]);
    svg.selectAll("path.region").attr("d", pathGen);
  });

svg.call(zoomBehavior);
```

> 重设投影的代价是每次缩放都要重算路径，矢量要素很多时应改用整体变换或降级到 Canvas。

**速记**：d3.zoom 统一处理缩放平移，可选整体变换或重设投影两种做法，后者保持线宽与字号不变但重算量更大。



#### 区域拾取与提示

**区域拾取**：是判断指针落在地图的哪个区域上，并给出对应提示的过程。

- SVG 路径：路径元素自带事件，绑定后即可按要素属性取值，实现简单。
- Canvas 路径：没有元素树，需按指针坐标反算，或借助空间索引判断命中。
- 球面判断：d3.geoContains(object, [longitude, latitude]) 判断经纬度点是否落在给定几何内。
- 提示定位：把事件坐标换算为画布内坐标后定位提示框，注意容器滚动与缩放的影响。

```js
svg.selectAll("path.region")
  .on("pointermove.region", function (event, d) {
    const [px, py] = d3.pointer(event, svg.node());
    showTooltip(d.properties.name, px, py);
  })
  .on("pointerleave.region", hideTooltip);

// 需要精确判断时，把平面坐标反算为经纬度再做球面包含判断
const [longitude, latitude] = projection.invert([px, py]);
d3.geoContains(feature, [longitude, latitude]);
```

> 在投影后的平面上做点面判断，与在球面上做判断结果可能不同，跨投影或极区数据应使用球面判断。

**速记**：SVG 可直接按元素拾取，Canvas 需坐标反算，球面包含用 d3.geoContains，提示框定位需换算为画布内坐标。



#### 联动与筛选

**联动**：是让地图与其他视图共享同一份选择状态，一处操作带动多处更新。

- 地图作为筛选器：点击区域筛选出该区域的明细数据，再驱动表格与统计图重绘。
- 作为被筛选方：由外部条件控制区域的高亮、填充或可见性。
- 状态保持：记录当前选中的区域标识，重绘时按标识恢复高亮，避免刷新后丢失。
- 联动键：以区域编码等稳定标识作为跨视图的连接键，不要用显示名称或数组下标。

```js
let selectedRegion = null;

function selectRegion(code) {
  selectedRegion = code;
  svg.selectAll("path.region")
    .classed("is-selected", (d) => d.properties.code === selectedRegion);
  renderDetail(rows.filter((row) => row.regionCode === code));
}

svg.selectAll("path.region")
  .on("click", (event, d) => selectRegion(d.properties.code));
```

> 联动键必须稳定：用显示名称做键时，名称微调或重复会让高亮与筛选同时失效。

**速记**：联动以稳定标识为键共享选择状态，地图既可作筛选器也可被外部条件控制，重绘时按标识恢复高亮。
