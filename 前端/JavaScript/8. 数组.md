## 数组

### 数组的创建

#### 字面量创建方式

**数组（Array）**：是用于存储**有序集合**的引用类型，元素按索引排列，索引从 0 开始。数组是 JavaScript 最常用的数据结构。

**字面量创建**：用方括号 [] 直接创建，是最简洁、最推荐的方式。

```js
const fruits = ["苹果", "香蕉", "橙子"];
const empty = [];               // 空数组
const mixed = [1, "two", true]; // 元素类型可混合（但实践中不推荐）

console.log(fruits[0]); // "苹果"（索引从 0 开始）
console.log(fruits.length); // 3
```

> 字面量 [] 与 new Array() 相比，**更简洁、无歧义、性能更好**，是唯一推荐方式。数组元素可混合类型，但为了可维护性，实践中应让同一数组的元素类型保持一致。



#### new 创建方式

用 new Array() 构造函数创建数组，存在**歧义陷阱**，需谨慎使用。

- new Array(n)：传入**单个数字** n 时，创建**长度为 n 的空数组**（而非包含 n 一个元素）。
- new Array(a, b, ...)：传入多个参数时，创建包含这些元素的数组。

```js
const arr1 = new Array(3);           // 长度为 3 的空数组 [empty × 3]
console.log(arr1.length);            // 3
console.log(arr1[0]);                // undefined

const arr2 = new Array(1, 2, 3);     // [1, 2, 3]
console.log(arr2);                   // [1, 2, 3]
```

> [!CAUTION]
> **注意内容**：new Array(3) 与 new Array("3") 结果完全不同——前者是长度为 3 的空数组，后者是含一个字符串 "3" 的数组。这种“单数字参数”的歧义是 new Array 最大的坑，也是推荐用字面量 [] 的根本原因。



### 数组的基本操作

#### 数组的添加、删除与替换

数组的增删改通过索引赋值和几个核心方法完成。

- **添加/替换**：arr[index] = value 直接赋值，索引不存在则新增、存在则替换。
- **push(...items)**：末尾添加，返回新长度。
- **pop()**：删除末尾元素，返回被删元素。
- **unshift(...items)** / **shift()**：头部添加/删除。
- **splice(start, deleteCount, ...items)**：万能方法，可增可删可替换。

```js
const arr = [1, 2, 3];
arr.push(4);          // [1, 2, 3, 4]
arr.pop();            // 返回 4，数组变 [1, 2, 3]
arr.unshift(0);       // [0, 1, 2, 3]
arr.shift();          // 返回 0，数组变 [1, 2, 3]
arr.splice(1, 1, 99); // 从索引 1 删 1 个，插入 99 → [1, 99, 3]
```

> splice 是数组最强大也最易混的方法：splice(start, deleteCount, ...items) 表示"从 start 开始删 deleteCount 个，再插入 items"。它**原地修改**数组，注意与不修改原数组的 slice 区分。



#### length 属性与数组遍历

数组的 **length 属性**既可读又可写，是数组最特殊的属性。

- **读**：返回数组元素个数。
- **写**：设置 length 可**截断**或**扩展**数组。
- 最大索引为 length - 1。

```js
const arr = [1, 2, 3, 4, 5];
console.log(arr.length); // 5

arr.length = 3;          // 截断为前 3 个
console.log(arr);        // [1, 2, 3]

// 遍历方式一：索引式 for
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
// 遍历方式二：for-of（推荐）
for (const item of arr) {
  console.log(item);
}
```

> arr.length = 0 是**清空数组**的简洁写法。遍历数组现代推荐 for-of（直接取元素）或 forEach（函数式），索引式 for 在需要**索引或步长**时仍不可替代。



#### slice、concat 与 join

这三个方法都**不修改原数组**，是数组处理的基础工具。

- **slice(start, end)**：截取 [start, end) 区间的**浅拷贝**，支持负数。
- **concat(...items)**：拼接数组或元素，返回**新数组**。
- **join(separator)**：把元素用分隔符连接成字符串。

```js
const arr = [1, 2, 3, 4, 5];

console.log(arr.slice(1, 3));   // [2, 3]
console.log(arr.slice(-2));     // [4, 5]（负数从末尾数）
console.log(arr.concat([6, 7])); // [1, 2, 3, 4, 5, 6, 7]
console.log(arr.join("-"));     // "1-2-3-4-5"
console.log(arr);               // [1, 2, 3, 4, 5]（原数组不变）
```

> 三者的共同点是**返回新值、不改原数组**，这使它们适合在函数式、不可变风格中使用。slice 常用于"复制数组"（arr.slice() 即浅拷贝），join 与 split 是字符串/数组互转的桥梁。



#### 查找元素：indexOf 与 find

查找元素是高频需求，indexOf 找**位置**，find 找**元素**。

##### indexOf() 方法

**arr.indexOf(item, from)**：从 from 起查找 item 的**第一个索引**，找不到返回 -1。配套还有 lastIndexOf（从后往前）和 includes（返回布尔）。

```js
const arr = [1, 2, 3, 2, 1];

console.log(arr.indexOf(2));      // 1（第一个 2 的位置）
console.log(arr.lastIndexOf(2));  // 3（最后一个 2 的位置）
console.log(arr.indexOf(99));     // -1（不存在）
console.log(arr.includes(3));     // true
```

> [!WARNING]
> **警告内容**：indexOf 用**严格相等（===）**比较，无法查找对象，NaN 也找不到（因 NaN !== NaN）。判断“是否存在”用 includes 更语义化（且 includes 能正确识别 NaN）。



##### find() 方法

**arr.find(callback)**：返回**第一个满足条件的元素**；配套的 findIndex 返回索引；都找不到时 find 返回 undefined、findIndex 返回 -1。

```js
const users = [
  { name: "张三", age: 20 },
  { name: "李四", age: 25 },
  { name: "王五", age: 30 }
];

const result = users.find((item) => item.age > 24);
console.log(result); // { name: "李四", age: 25 }

const index = users.findIndex((item) => item.age > 24);
console.log(index); // 1
```

> find 相比 indexOf 的优势是能按**自定义条件**查找（尤其查找对象），弥补了 indexOf 只能用 === 的局限。它接收回调函数，返回第一个使回调为 true 的元素。



#### sort 与 reverse

**sort()** 用于排序，**reverse()** 用于反转，二者都**原地修改**数组。

- **reverse()**：反转数组顺序，无参数。
- **sort([compareFn])**：默认按**字符串**排序（有陷阱），传入比较函数可自定义。

```js
const arr = [3, 1, 4, 1, 5, 9];
arr.sort();
console.log(arr); // [1, 1, 3, 4, 5, 9]（默认也恰好正确）

// 陷阱：默认按字符串排序
const arr2 = [1, 10, 2, 20];
arr2.sort();
console.log(arr2); // [1, 10, 2, 20]（"10" < "2" 按字符串）

// 正确：传入比较函数
arr2.sort((a, b) => a - b);
console.log(arr2); // [1, 2, 10, 20]（数字升序）
```

> [!WARNING]
> **警告内容**：sort 最大的坑是**默认按字符串比较**，导致 [1, 10, 2, 20] 排成 [1, 10, 2, 20]。比较函数 (a, b) => a - b 升序、(a, b) => b - a 降序，是必须掌握的写法。



#### 其他高阶函数

高阶函数（接收或返回函数的函数）是数组的精华，现代开发几乎离不开。

##### forEach() 方法

**arr.forEach(callback)**：遍历每个元素执行回调，**没有返回值**（返回 undefined），用于**副作用**操作。

```js
const arr = [1, 2, 3];
arr.forEach((item, index) => {
  console.log(`第 ${index} 个元素是 ${item}`);
});
// 第 0 个元素是 1
// 第 1 个元素是 2
// 第 2 个元素是 3
```

> forEach 只做"遍历 + 副作用"，**不能中断**（break/return 无效），也不能链式调用。需要"得到新数组"用 map，需要"筛选"用 filter，需要"提前中断"用 for-of 或 some/every。



##### map() 方法

**arr.map(callback)**：对每个元素执行回调，**返回一个由回调返回值组成的新数组**，用于**映射/转换**。

```js
const nums = [1, 2, 3];
const doubled = nums.map((item) => item * 2);
console.log(doubled); // [2, 4, 6]

const users = [{ name: "张三" }, { name: "李四" }];
const names = users.map((item) => item.name);
console.log(names); // ["张三", "李四"]
```

> map 与 forEach 的核心区别：map **返回新数组**（可链式、用于数据转换），forEach 无返回值（只做副作用）。"把一组数据变成另一组数据"就用 map。



##### filter() 方法

**arr.filter(callback)**：返回**所有满足条件的元素组成的新数组**，用于**筛选**。

```js
const nums = [1, 2, 3, 4, 5, 6];
const evens = nums.filter((item) => item % 2 === 0);
console.log(evens); // [2, 4, 6]

const users = [
  { name: "张三", age: 18 },
  { name: "李四", age: 25 }
];
const adults = users.filter((item) => item.age >= 18);
console.log(adults.length); // 2
```

> filter 返回所有满足条件的元素（find 只返回第一个），且返回的**始终是新数组**。它与 map 常组合使用：先 filter 筛出目标，再 map 取出需要的字段。



##### reduce() 方法

**arr.reduce(callback, initialValue)**：把数组**归约**成单个值，是数组方法中功能最强、也最灵活的一个。

- 回调 (accumulator, currentValue) => newAcc：accumulator 是累积结果。
- initialValue 是初始累积值。

```js
// 求和
const nums = [1, 2, 3, 4, 5];
const sum = nums.reduce((acc, cur) => acc + cur, 0);
console.log(sum); // 15

// 统计元素出现次数
const items = ["a", "b", "a", "c", "b", "a"];
const count = items.reduce((acc, cur) => {
  acc[cur] = (acc[cur] || 0) + 1;
  return acc;
}, {});
console.log(count); // { a: 3, b: 2, c: 1 }
```

> [!IMPORTANT]
> **重要内容**：reduce 的精髓是**累积器（accumulator）**：每次迭代把结果累积到 acc 上。求和、求积、去重、扁平化、分组统计……几乎所有“把数组变单值”的操作都能用 reduce 表达，建议**始终传初始值**以规避空数组报错。



#### some 与 every

**arr.some(callback)** 与 **arr.every(callback)**：是返回**布尔值**的判定型方法——some 判断"**是否存在**至少一个满足条件"，every 判断"**是否全部**满足条件"。二者都**在结果确定时提前短路**，是高效替代 forEach + 标志位的做法。

```js
const nums = [1, 2, 3, 4, 5];

const hasEven = nums.some((item) => item % 2 === 0); // true（存在偶数）
const allPositive = nums.every((item) => item > 0);  // true（全部正数）
const allEven = nums.every((item) => item % 2 === 0);// false（并非全是偶数）

// 空数组语义：some → false（"一个都没有"为假），every → true（"全都不违背"为真）
console.log([].some((x) => x > 0));  // false
console.log([].every((x) => x > 0)); // true
```

> [!WARNING]
> **警告内容**：some/every 与 includes/indexOf 的关系：后两者只能判断“值是否存在”，而前两者能按**任意条件**判断。空数组是经典陷阱：every 对空数组恒返回 true（数学上“vacuous truth”），some 恒返回 false，逻辑上完全自洽但常出乎直觉。



#### Array.from 与类数组转换

**Array.from(arrayLike, mapFn?)**：把**类数组或可迭代对象**转换为真正的数组；第二个可选参数 mapFn 可同时做映射，等价于 Array.from(x).map(mapFn) 但更省一趟遍历。

```js
// 类数组：arguments、NodeList、字符串
const str = "hello";
console.log(Array.from(str));        // ["h", "e", "l", "l", "o"]

// 可迭代对象：Set、Map、生成器
const set = new Set([1, 2, 3]);
console.log(Array.from(set));        // [1, 2, 3]

// 带 mapFn：配合 length 快速造数组
const squares = Array.from({ length: 5 }, (_, i) => i * i);
console.log(squares);                // [0, 1, 4, 9, 16]
```

> Array.from 是"把不是数组的东西变数组"的通用入口：既处理有 length 的类数组（arguments、NodeList），也处理可迭代对象（Set、Map、字符串）。它与展开语法 [...iterable] 的区别是——展开语法**只认可迭代对象**（类数组不可迭代时无效），而 Array.from 两者皆可。Array(5).fill(0) 与 Array.from({length: 5}, ...) 的区别在于后者能通过 mapFn 逐项生成值而非同一份填充。



### 数组高阶函数的实现

#### hyForEach 的实现

通过**手写实现**高阶函数，能深入理解其内部原理。先实现 forEach 的简化版。

```js
function hyForEach(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    callback(arr[i], i, arr);
  }
}

// 使用
hyForEach([1, 2, 3], (item, index) => {
  console.log(item, index);
});
// 1 0
// 2 1
// 3 2
```

> 手写 forEach 揭示其本质：**就是一个 for 循环 + 回调**。把"遍历逻辑"（for）与"具体操作"（回调）解耦，正是高阶函数"传入函数以定制行为"思想的体现。



#### hyFind 的实现

同理实现 find，体会"满足条件即返回"的语义。

```js
function hyFind(arr, callback) {
  for (let i = 0; i < arr.length; i++) {
    if (callback(arr[i], i, arr)) {
      return arr[i]; // 满足条件立即返回该元素
    }
  }
  return undefined; // 都不满足返回 undefined
}

const users = [{ name: "张三", age: 20 }, { name: "李四", age: 30 }];
const result = hyFind(users, (item) => item.age > 25);
console.log(result); // { name: "李四", age: 30 }
```

> find 与 forEach 的关键区别：find 在回调返回 true 时**提前终止**并返回元素，forEach 则无论如何都遍历到底。理解"条件满足即 return"是手写 find 的核心，也是它与 filter（返回全部）的区别。
