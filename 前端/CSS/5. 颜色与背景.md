## 颜色与背景

### 颜色系统

#### 颜色的表示方式

CSS 中颜色有多种写法，理解其语法是精确控制配色的前提。按出现时间与能力大致分两类。

- **CSS 颜色关键字**：如 red、transparent、currentcolor（取当前元素 color 值）。
- **函数式表示**：rgb() / rgba()、hsl() / hsla()（老式）；现代统一命名 rgb()、hsl()、hwb()，以及新色彩空间的 lab()、lch()、oklab()、oklch()、color()。
- **十六进制 #RRGGBB / #RGB / #RRGGBBAA**：最常用的简写形式，可带透明度。

```css
.color-1 { color: #ff6600; }
.color-2 { color: #f60; }            /* 每两位压缩为一位 */
.color-3 { color: rgb(255 102 0); }  /* 现代：空格分隔，无需逗号 */
.color-4 { color: rgba(255,102,0,0.5); } /* 老式写法，仍可用 */
.color-5 { color: hsl(24 100% 50%); }    /* 色相 24°，饱和 100%，明度 50% */
```

> 现代浏览器把 rgb() 与 rgba()、hsl() 与 hsla() **合并为同一函数**——是否带 alpha 由第四个参数决定，空格语法下可省略逗号。transparent 是 rgba(0,0,0,0)；currentcolor 能让 border-color、box-shadow 等跟随文字颜色自动变化。



#### rgb 与 hex

- **rgb(red, green, blue)**：三通道取值范围 **0~255**（或百分比 0%~100%），现代语法可第四个参数给透明度。
- **十六进制**：#RRGGBB，每个通道用两位十六进制（00~ff）；每两位相同时可压缩为 #RGB。

```css
p { color: rgb(255, 0, 0); }   /* 红 */
p { color: rgb(255 0 0 / 0.5); } /* 现代：红 + 50% 透明 */
p { color: #ff0000; }          /* 同上红 */
p { color: #f00; }             /* 压缩写法 */
p { color: #ff000080; }        /* 8 位 hex：后两位 80 是透明度 */
```

> hex 与 rgb 只是同一颜色的不同记法，可互相换算：把每两位十六进制换算成 0~255 即得 rgb。8 位 hex（#RRGGBBAA）把透明度直接揉进颜色串里，适合"不想拆两行"的场景。压缩规则是"每两个相同字符可合成一个"，故 #ff6600 → #f60。



#### hsl 与 hwb

- **hsl(色相, 饱和度, 明度)**：基于**色轮**的描述。色相 0°(红)/120°(绿)/240°(蓝)，0~360；饱和度 0%（灰）~100%（最艳）；明度 0%（黑）~100%（白），50% 为正常。
- **hwb(色相, 白度, 黑度)**：色相同 hsl，另用"掺白量、掺黑量"描述，直觉上是"从纯色往白/黑方向走"。

```css
div { background: hsl(120, 100%, 50%); } /* 纯绿：色相120，饱和满，明度半 */
div { background: hsl(120 100% 50% / 0.6); } /* 现代语法 + 透明 */
div { background: hwb(120 0% 0%); }       /* 纯绿（不掺白不掺黑） */
```

> hsl 对**调色**更直观：想变浅就抬明度，想柔和就降饱和，不用像 rgb 那样凭经验推算。取"同一色相、不同明度"的一组色做渐变深浅最省心。hwb 更贴合"调色盘上选色"的直觉，适合做取色器。二者色相定义与 hsl 一致。



#### 现代色彩空间 oklch 等

传统 sRGB 色彩空间**色域有限且明度感知不均**，为更广色域与更"人眼线性"的调整，规范引入 lab()、lch()、oklab()、oklch()。

- **oklch(明度, 彩度, 色相)**：L（明度 0~1，感知均匀）、C（彩度）、H（色相角）。因其**明度感知线性**，同一 L 下做深浅微调视觉更一致。
- **color(显示设备 通道值)**：指定色彩空间（如 display-p3、srgb）取色，可访问广色域屏幕的更多颜色。
- **优势**：比 hsl 的"明度"更贴近人眼感知，配色/取反色/做色阶更可预测；可表达 P3 等超 sRGB 颜色。

```css
div { background: oklch(70% 0.15 30); }   /* 明度70%、彩度0.15、色相30° */
div { background: color(display-p3 1 0 0); } /* 用 Display-P3 空间取纯红 */
```

> 面向未来的建议：高保真设计与广色域显示器（如 Mac 的 Display-P3）下，oklch() 是"调色更可控 + 可下探 P3"的首选；但**兼容性仍不如 rgb/hex**。生产上常先在 @supports 里对支持 oklch 的浏览器启用新语法，其余回退到 sRGB 十六进制。



### 背景属性

#### background 简写

**background**：是背景相关多个属性的**简写**，可一次设置颜色、图片、位置、尺寸、重复方式、附着方式等。

```css
.box {
  background: #f5f5f5
              url("bg.png")      /* 颜色 + 图片 */
              no-repeat          /* 不重复 */
              center / cover     /* 位置 / 尺寸 */
              fixed;             /* 随视口固定（不随滚动） */
}
```

background 可简写的子属性包括：

- background-color：底色。
- background-image：背景图（url()）。
- background-repeat：重复方式（repeat/no-repeat/repeat-x/repeat-y）。
- background-position：位置（left top、center、百分比、长度）。
- background-size：尺寸（auto/cover/contain/长度百分比）。
- background-attachment：scroll（随元素滚动）/fixed（随视口固定）。
- background-clip、background-origin。

> [!WARNING]
> **警告内容**：简写里**未写的子项会重置为初始值**，这是最常见的坑——例如想只改颜色却把 background-image 重置掉了。多层背景用逗号分隔多组；background 简写最常用于"铺一张 cover 尺寸、不重复、居中"的 banner 背景。



#### background-image 与渐变背景

- **background-image: url(...)**：可多张图片用逗号分隔，**先写的在上层**。
- **背景图与颜色可共存**：图片在上、颜色在下（无图或透明处透出底色）。
- **渐变也是背景图**：linear-gradient()、radial-gradient()、conic-gradient() 等函数可直接赋给 background-image。

```css
.banner {
  background-image:
    url("overlay.png"),            /* 上层 */
    linear-gradient(#e66465, #9198e5); /* 下层渐变兜底 */
  background-size: cover, cover;
}
.card {
  background-image: linear-gradient(45deg, #f60, #e66465);
}
```

> 理解"渐变属于背景图"能解开很多困惑：渐变无法用 background-color 直接"填"，且遵循 background-clip、可叠加多张、可通过调整方向与色标做出立体/条纹/光晕等效果。纯渐变背景由 GPU 光栅化，性能良好。



#### background-clip 与裁剪

**background-clip**：决定背景（颜色与图片）**渲染到盒子的哪一层为止**，默认裁到 border-box（边框之下），可裁到 padding、内容甚至文本。

```css
.box { background-clip: border-box; }   /* 默认：铺到边框内沿（边框下层） */
.box { background-clip: padding-box; }  /* 背景到 padding 内沿，不含边框区 */
.box { background-clip: content-box; }  /* 背景只在内容区内 */
.text-gradient {
  background-image: linear-gradient(...);
  background-clip: text;                /* 背景裁到文字笔画 */
  color: transparent;                   /* 文字透明以露出背景 → 渐变文字 */
}
```

- background-origin 决定**背景图的定位起点**（padding-box 默认 / border-box / content-box），与 clip 的裁切边界是两个不同概念。
- clip: text + color: transparent 是制作**渐变文字、图片文字**的经典技巧，需注意对非支持浏览器兜底。

> 区分 clip 与 origin：**origin 管"图片从哪开始铺"**（定位参考），**clip 管"铺到哪为止被裁掉"**。设圆角盒子背景时，若发现背景"溢出圆角外"的直角，多半是忘了 clip——border-radius 本身不裁背景，需 background-clip 配合或容器设 overflow: hidden。



### 阴影与滤镜

#### box-shadow 阴影

**box-shadow**：给盒子绘制**投影**，可多层叠加（逗号分隔）。语法为：水平偏移 垂直偏移 模糊半径 扩散半径 颜色（可有 inset 改为内阴影）。

```css
.box { box-shadow: 2px 4px 8px rgba(0,0,0,0.3); }
/*     offset-x offset-y blur spread color       */
.box { box-shadow: 0 0 0 3px #f60; }          /* 0模糊0扩散=纯描边效果 */
.box { box-shadow: 0 0 10px #f60, inset 0 0 5px #999; } /* 多重阴影 */
```

- **offset-x / offset-y**：阴影在水平/垂直方向偏移，可为负值（向左/上）。
- **blur（模糊半径）**：越大越柔和；为 0 则阴影边缘清晰。
- **spread（扩散半径）**：正值扩大阴影、负值收缩，0 模糊 + 指定 spread 可得到"描边/外发光"。
- **inset**：把阴影放进盒子**内部**，用于内凹陷、按钮按下效果。

> box-shadow 是营造**层次感（卡片浮起）、焦点高亮（focus ring）、外描边、发光**的主力。0 模糊 + 正扩散再配主题色，能做出比 border 更不影响盒尺寸的"伪边框"。多重阴影用逗号分隔，最前面那层在最上层。



#### text-shadow 文本阴影

**text-shadow**：给文本文字绘制阴影，语法较简单：水平偏移 垂直偏移 模糊半径 颜色（无 spread），可多层。

```css
h1 { text-shadow: 2px 2px 4px rgba(0,0,0,0.3); }
h1 { text-shadow: 0 0 8px #f60; }   /* 文字发光 */
```

> text-shadow 常用于给浅色文字在浅背景上加"可读性阴影"、做立体字（多层偏移）、或发光标题。与 box-shadow 的区别是它**跟随文字笔画**而非矩形盒。文字长投影可用多层叠加，但过多层会偏性能负担，慎用。



#### filter 滤镜

**filter**：对元素渲染结果做**图像级滤镜**，作用于"整块含背景/子内容的合成结果"，语法为若干滤镜函数。

```css
.img:hover { filter: grayscale(100%); }        /* 灰度 */
.img { filter: brightness(1.2); }               /* 亮度 */
.img { filter: blur(4px); }                     /* 高斯模糊 */
.img { filter: drop-shadow(0 0 8px #f60); }     /* 按形状投影（跟随透明度轮廓） */
```

- 常用函数：blur()、brightness()、contrast()、grayscale()、sepia()、saturate()、hue-rotate()、invert()、opacity()、drop-shadow()。
- 可**用空格叠加**多个：filter: blur(2px) grayscale(50%);。
- **drop-shadow()** 与 box-shadow 关键不同：它按元素的**实际不透明轮廓**（含裁剪/透明 PNG 形状）投影，而不是方盒子。
- **副作用**：filter 不为 none 时会**新建层叠上下文**并触发**独立合成层**（性能与渲染分组会改变）。

> 滤镜是把"运行时调图/调色"变成 CSS 声明的好工具——hover 加 grayscale(0) 让灰图变彩、drop-shadow 给不规则图标加投影。但它会让元素**自成合成层**，过多使用增加内存与合成开销，动画时应谨慎。对**文字像素**的模糊也可用 backdrop-filter（作用于其后方的背景）。
