## 选择器

### 选择器的作用与分类

#### 选择器的概念

**选择器（Selector）**：是 CSS 规则中**指明该规则作用于哪些元素**的部分，是"给谁上样式"的入口。选择器的能力直接决定样式书写的效率与可维护性。

- **命中（匹配）**：某元素满足选择器条件，即被该规则命中。
- **选择器列表**：用逗号合并多个选择器，任一命中即生效。
- **伪类与伪元素**：选择器还能命中"状态"（:hover）与"虚拟部件"（::before），是选择器体系的高级扩展。

> 选择器的组合观：单个**基础选择器**（类型、类、ID）经**组合器**（后代、子、兄弟）与**选择器列表**拼装，可精确到"某状态下、某结构关系中的特定元素"。越精确的选择器往往越难复用——追求**足够而非过度**是选择器设计的关键。



#### 分类总览

CSS 选择器按命中方式分为几大类，理解分类能快速判断用哪种。

- **基础选择器**：元素/类型、类、ID、通用 *、属性。
- **组合选择器**：后代（空格）、子代 >、相邻兄弟 +、通用兄弟 ~。
- **伪类**：结构类（:nth-child()）、状态类（:hover）、表单类（:checked）、逻辑类（:not()）等。
- **伪元素**：::before、::after、::first-line、::selection 等。
- **分组与特殊**：选择器列表（,）、命名空间、列组合（||，用于表格/网格）。

> 一个实用的分层心智：**普通页面样式多用类与伪类**；**语义化结构页可用类型与结构伪类**；**ID 与 * 慎用**（ID 难以复用、* 性能与粒度都差）。掌握"选择器 = 基础 × 组合 × 状态"即可覆盖绝大多数需求。



### 基础选择器

#### 类型选择器与类选择器

- **类型选择器（Type）**：匹配指定**元素名**（p、div、h1）。粒度最粗，命中该类型的所有元素。
- **类选择器（Class）**：以 . 开头，匹配带**该 class** 的元素。可复用、可叠加，是日常最常用的选择器。

```css
p { color: gray; }            /* 类型：所有 <p> */
.note { color: green; }       /* 类：所有 class 含 note 的元素 */
.error.note { color: orange; } /* 同时含 error 与 note 两个类的元素 */
```

- 一个元素可同时有多个 class：例如 class 属性值为 note error 的 p 元素，其中任意一个类都使其被对应类选择器命中。
- **链式类**（.a.b）要求元素**同时具备**这些类；**空格**则是后代组合，含义完全不同。

> 类型选择器适合"通篇统一"的规则（如默认段落样式）；类选择器适合"可复用组件"。链式类用于"交集"场景（同时满足两个条件的才命中），但要小心与"后代"写法的混淆——.a.b 无空格是交集，.a .b 有空格是后代。



#### ID 选择器与通用选择器

- **ID 选择器**：以 # 开头，匹配**该 id** 的元素。id 在文档中应**唯一**。
- **通用选择器 ***：匹配**所有元素**（含未来的后代）。

```css
#app { max-width: 1200px; }   /* id 唯一 */
* { box-sizing: border-box; } /* 全部元素，常用作 reset */
```

- **ID 与类的取舍**：ID 在 CSS 中优先级极高（远超类）且不可复用，容易造成"难覆盖"；**布局钩子常用类而非 ID**，ID 更多保留给 JS 锚点或表单 label 关联。
- *** 的性能**：单独用影响不大，但配合后代如 div * p 会使浏览器对每个元素都做遍历，层级越深越慢。

> 经验法则：**能用类就不用 ID**（除了明确唯一的页面级钩子）；* 主要用于 reset（且最好直接用在元素上而非深层后代里）。优先级极低的 * 让它很适合做"兜底默认值"。



#### 属性选择器

**属性选择器**：按元素的**属性及其值**来命中元素，用方括号 [...] 书写，且支持多种匹配方式。

```css
[href] { color: blue; }            /* 存在 href 属性 */
[type="text"] { border: 1px solid; }  /* 属性值精确等于 text */
[class~="btn"] { ... }             /* 值列表中含 btn（空格分隔） */
[lang|="en"] { ... }               /* 值以 en 开头且后接 -（en、en-US） */
[href^="https"] { ... }            /* 值以 https 开头 */
[href$=".pdf"] { ... }             /* 值以 .pdf 结尾 */
[title*="图"] { ... }              /* 值中包含"图"子串 */
```

- **存在与精确**：[attr] 只看有无；[attr=val] 要求完全相等。
- **子串三件套**：^=（开头）、$=（结尾）、*=（包含），是最常用的三类。
- **加标识符**：可用 i 忽略大小写、s 区分大小写（默认对部分属性不区分）。

> 属性选择器常用于"不用加 class 也能挑出特定元素"，例如按 href 前缀给外链加图标、按 type 给表单控件分组。它属于**类优先级**这一档（特异性为类级别），可与类选择器灵活互换。



### 组合选择器

#### 后代与子代选择器

组合选择器用**组合器**描述元素之间的**结构关系**。

- **后代组合器（空格）**：A B，命中 A 的**任意后代** B（父子、孙辈都算）。
- **子代组合器 >**：A > B，只命中 **A 的直接子元素** B，不穿透更深层级。

```css
div p { color: red; }    /* div 内任意层级的 p */
div > p { color: blue; } /* 仅 div 的直接子 p，孙子 p 不受影响 */
```

```html
<div>
  <p>直接子，命中 div>p</p>
  <section><p>孙子，只命中 div p，不命中 div>p</p></section>
</div>
```

> 后代组合器穿透力强、写起来省事，但也容易**误伤深层元素**；子代组合器 > 更精确、语义更清楚。当只想管"紧挨着的一层"时用 >，可显著降低样式串扰。



#### 兄弟选择器

兄弟组合器命中**同一父元素下、位置相邻**的元素。

- **相邻兄弟 +**：A + B，命中**紧跟在 A 后面**的第一个兄弟 B。
- **通用兄弟 ~**：A ~ B，命中 **A 之后**的所有兄弟 B（不必紧邻）。

```css
h2 + p { margin-top: 0; }   /* 紧跟 h2 的那个 p */
h2 ~ p { color: gray; }     /* h2 后面的所有 p */
```

```html
<h2>标题</h2>
<p>紧邻，命中 h2+p 且 h2~p</p>
<p>次一位，只命中 h2~p</p>
```

> 兄弟选择器最大的价值是"**不用改 HTML 也能表达相邻关系**"。典型如"第一个段落去间距""选中项高亮其后的指示条""checkbox 状态的切换"——配合 :checked 和 + 可做出纯 CSS 的开关效果。



### 伪类选择器

#### 结构伪类

**结构伪类**：根据元素在**文档树中的位置**命中元素，无需依赖 class。

```css
li:first-child {}   /* 是父元素第一个子元素的 li */
li:last-child {}    /* 最后一个子元素 */
li:only-child {}    /* 唯一子元素 */
li:first-of-type {} /* 同类元素中的第一个 */
p:nth-child(2n) {}  /* 第 2、4、6...个（偶数位）子元素 */
p:nth-of-type(odd) {}
```

- **nth-child(n)**：参数可为**整数**（第 n 个）、**关键字**（odd/even）、**表达式**（2n+1）。
- **of-type 系列**：先按**类型**分组再数位置，与"父下所有子元素"的 child 系列区别在于会忽略其它类型的兄弟。

> [!WARNING]
> **警告内容**：关键易混点：:nth-child 数的是父元素下**所有类型**的子元素；:nth-of-type 只在该**元素类型**内部数。例：父元素下的四个子元素依次是 h1、p、span、p，那么第二个 p 是 :nth-child(4)（第四个子），却只是 :nth-of-type(2)（p 类型里第二个）。



#### 状态伪类

**状态伪类**：命中元素的**动态状态**（交互、表单、链接等），使 CSS 能响应状态而无须 JS。

```css
a:hover {}        /* 鼠标悬停 */
a:active {}       /* 按下未松开 */
a:visited {}      /* 已访问链接（受限） */
input:focus {}    /* 获得焦点 */
input:checked {}  /* 勾选（checkbox/radio） */
input:disabled {} /* 禁用 */
input:required {} /* 必填 */
```

- 链接伪类有约定书写顺序：LVHA——:link → :visited → :hover → :active（后写者优先级更高，若不按此序，:hover/:active 可能被覆盖）。
- :visited 出于隐私安全，**只允许修改颜色类属性**（color、background-color、border-color 等），其余被浏览器忽略。

> :checked + label 或 :checked ~ 元素 是"纯 CSS 状态切换"的经典玩法——用一个隐形的 checkbox 当开关，靠状态伪类改变其后兄弟的外观，可做出标签页、抽屉、开关等组件，无需 JS。



#### 表单与 UI 伪类、逻辑伪类

除结构、状态外，还有一批面向表单校验结果与逻辑运算的伪类。

- **校验相关**：:valid（合法）、:invalid（非法）、:in-range / :out-of-range、:placeholder-shown（占位符显示中）。
- **可编辑性**：:read-only、:read-write。
- **逻辑与否定**：:not(选择器)（排除）、:is(列表)、:where(列表)、:has(选择器)（父级/前后匹配）。

```css
input:invalid { border-color: red; }
/* :is 简化重复前缀，:where 优先级恒为 0 */
header :is(h1, h2) { margin: 0; }
/* :not 排除某些项 */
li:not(:last-child) { border-bottom: 1px solid #ddd; }
/* :has 命中"含某后代"的父元素（父选择器） */
.card:has(img) { padding: 0; }
```

> [!WARNING]
> **警告内容**：:not()、:is()、:where() 三个**优先级规则**是高频坑：:not() 与 :is() 的优先级取**参数里最高**那个（而非整体）；:where() 优先级**恒为 0**，最适合写"可被覆盖的默认样式"；:has() 提供了"根据子/兄弟反选父"的能力，是现代选择器的重要增强。



### 伪元素

#### ::before 与 ::after

**伪元素**：命中元素上**实际不存在的虚拟部件**，常见为 ::before（作为该元素第一个子内容）与 ::after（作为最后一个子内容）。它们必须配合 content 属性使用。

```css
.note::before {
  content: "⚠ ";      /* 必须有 content，否则伪元素不生成 */
  color: orange;
}
.button::after {
  content: " →";
}
a::after {
  content: "";
  display: inline-block;
  width: 8px; height: 8px;
}
```

- content 可以是文本、""（空，常用于画图形）、url()（图片）、attr()（读取元素属性）、counter()（序号）等。
- 默认 ::before/::after 是**行内元素**，要设宽高需先改 display 或用绝对定位。
- 伪元素只能命中一个元素的"内部首尾"，不能命中任意位置。

> 经典用途：图标、分割线、角标、对话框小箭头、序号、清除浮动（.clearfix::after 加空块清浮动）。注意写法上**新旧统一为双冒号 ::**；单冒号 : 是给伪类用的，但 ::before/::after/::first-line/::first-letter 等老伪元素曾用单冒号，现在规范建议双冒号以区分。



#### 其它常用伪元素

- **::first-line**：元素**首行**文本（随视口宽度变化的"首行"），只能改文本与排版类属性。
- **::first-letter**：元素**首字符**（或首个标点+字符）。
- **::selection**：用户**选中的文本**的样式（背景、颜色）。
- **::placeholder**：输入框**占位文本**的样式。
- **::marker**：list-item 元素（li、summary）的**列表标记**符号样式。
- **::backdrop**：全屏元素（dialog、video 全屏）背后的**背景层**。

```css
p::first-line { font-weight: bold; }
p::first-letter { font-size: 2em; float: left; }
::selection { background: #ffe08a; }
input::placeholder { color: #999; }
li::marker { color: #f60; }
```

> 伪元素与伪类的本质区别：伪类表示元素的**状态/结构**，用一个冒号 :；伪元素表示一个**子部件或部分内容**，规范用双冒号 ::。个别老伪元素在旧浏览器仍支持单冒号写法，新代码一律写双冒号。
