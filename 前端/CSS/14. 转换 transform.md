## 转换 transform

### transform 基础

#### transform 的概念与特性

**转换（transform）**：对元素进行**位移、旋转、缩放、倾斜**等几何变换，且**不改变文档流布局**——变换只是"看起来动了"，原占位仍在。它是 CSS 动画性能的关键，因为多数变换由 GPU 合成。

```css
.el { transform: translate(20px, 10px) rotate(45deg) scale(1.2); }
```

- **多重变换**：transform 可叠加多个函数（空格分隔），从右到左依次应用。
- **不脱离流**：变换不触发重排（除非影响相邻布局，实际只影响自身渲染层），性能优于改 top/left。
- **创建合成层**：使用 transform（非 none）时元素常被提升到独立合成层，利于 GPU 加速。
- **影响层叠上下文**：transform 非 none 会创建新的层叠上下文与包含块（可改变 fixed/absolute 的参考系）。

> transform 是实现**"丝滑移动/放大"**的首选：把"从 A 移到 B"写成 transform: translate，把"悬停放大"写成 scale，交给 GPU 合成，得到 60fps 动画。它不挪走流中位置，因此常与 transition/animation 配合做浮层、弹窗的进出场。



#### transform-origin 变换原点

**transform-origin**：变换的**基准点**，默认元素**中心**（50% 50%）。旋转、缩放都相对该点进行。

```css
.el {
  transform-origin: left top;      /* 以左上角为原点 */
  transform-origin: 20px 30px;     /* 以偏移量 */
  transform: scale(2);             /* 相对左上角放大，元素向右下扩展 */
}
.card { transform-origin: top center; transform: rotate(-3deg); }
```

- 默认居中，改到某个角/边可实现"从某侧展开、围绕某点旋转"。
- 属性顺序：transform-origin: x y（可带 z）。

> 决定"绕哪儿转/从哪儿放大"看 transform-origin：默认绕中心；想让卡片从**左上角**放大（像展开）就设 left top；想让标签围绕**底边**倾倒就设 bottom center。旋转进场动画绕中心，翻牌动画则常绕一侧边。



### 2D 变换函数

#### translate 位移

**translate**：沿 X、Y（及 Z）轴移动元素，**不触发重排**，是"移动而不伤布局"的标准做法。

```css
.el { transform: translate(20px, 10px); } /* 右移20、下移10 */
.el { transform: translateX(50px); }      /* 只水平 */
.el { transform: translateY(-30px); }     /* 只垂直，负值向上 */
.el { transform: translate(50%, 50%); }   /* 相对自身尺寸 */
```

- **百分比**：相对**元素自身**宽高的百分比——正因如此，translate(-50%,-50%) 配合定位可把元素精确居中。
- 正值向右/向下，负值向左/向上。

> translate 的两大价值：一是**不触发布局**的平滑移动（配合 transition 动画）；二是其百分比**相对自身**，top:50%;left:50%;transform:translate(-50%,-50%) 即"不管元素多大都居中"的经典居中方案。需要"移动一个块而不挤动别人"，用 translate 而非 left/top。



#### scale 缩放

**scale**：按比例**缩放**元素。大于 1 放大，0~1 缩小，可为负值（翻转）。只能填**数值**，不能写百分比。

```css
.el { transform: scale(2); }          /* 等比例放大2倍 */
.el { transform: scale(2, 0.5); }     /* 宽2倍、高0.5倍 */
.el { transform: scaleX(-1); }        /* 水平翻转（镜像） */
.card:hover { transform: scale(1.05); } /* 悬停轻微放大 */
```

> scale 是"hover 放大、入场放大"的首选：配合 transform-origin 控制向哪放大，配合 transition 平滑。缩放的**视觉大小改变但不影响流中占位**，所以放大可能盖住相邻元素，可通过容器留白规避。负值缩放可做镜像/翻转动画。



#### rotate 旋转

**rotate**：按角度**旋转**元素。正值为**顺时针**，负值为逆时针，默认绕中心（可用 transform-origin 改）。

```css
.el { transform: rotate(45deg); }   /* 顺时针 45° */
.el { transform: rotate(-90deg); }  /* 逆时针 90° */
.badge { transform: rotate(90deg) translateY(-8px); } /* 旋转后再位移 */
```

- 单位常用 deg（度），也可 turn（圈）、rad。
- 旋转会改变元素的实际视觉朝向，多用于图标方向、装饰角标、入场动画。

> 旋转让内容"换个朝向"，如竖排文字、打标签的斜向 banner、hover 时图标转 180° 的箭头。注意 rotate 会连同坐标系一起转，rotate 之后再 translate 的方向会被旋转影响——多变换按**从右到左**执行，需按此设计顺序。



#### skew 倾斜

**skew**：沿轴**倾斜**元素，使矩形变平行四边形，多用于立体/斜切风格。

```css
.el { transform: skewX(20deg); }  /* 沿 X 倾斜 */
.el { transform: skewY(-10deg); } /* 沿 Y 倾斜 */
.btn-cut { transform: skewX(-12deg); }
.btn-cut > span { transform: skewX(12deg); } /* 内部反向倾斜，让文字保持正 */
```

- skewX：上下边相对水平方向倾斜；skewY：左右边相对垂直方向倾斜。
- 文字会跟着变形，若只要背景斜而文字正，需对内部容器反向倾斜校正。

> skew 常见于"斜切按钮、斜向标签、强调背景条"：外层 skewX(-12deg) 得到斜切背景，内层再 skewX(12deg) 反向校正让文字端正。理解"变换会连带影响子元素坐标系"，才能用好这类"反向补偿"技巧。



### 3D 变换

#### 3D 变换与透视

3D 变换让元素沿 Z 轴产生深度感，需**透视（perspective）**才能看到立体效果。CSS 3D 使用**左手坐标系**：屏幕平面为 X（右）、Y（下），垂直屏幕向外为 Z。

```css
/* 方式一：透视设在父容器，作用于所有子元素 */
.scene { perspective: 800px; }
.card  { transform: rotateY(45deg); }

/* 方式二：透视写在元素自身 transform 里，只作用于它自己 */
.card { transform: perspective(800px) rotateY(45deg); }
```

- **perspective**：视点距离，值越小透视越强（变形越夸张）。
- **perspective-origin**：视点位置，默认居中。
- **transform-style: preserve-3d**：让子元素保留自身的 3D 位置（默认 flat 会被压平），做多层 3D（如翻牌）必需。
- **backface-visibility**：控制元素背面是否可见，用于翻牌时隐藏背面。

> 3D 的核心是**先有透视、后有沿 Z 的变换**。父容器设 perspective 是最常见做法。真正做"卡片 3D 翻转、立方体"时还要 transform-style: preserve-3d 让子元素不被压平、用 backface-visibility: hidden 隐藏背面。多数日常交互用 2D 变换即可，3D 用于轮播、翻牌、视差等场景。



#### 常用 3D 函数

- **位移**：translateZ(z) 沿 Z 前后移动；translate3d(x,y,z)。
- **旋转**：rotateX(deg)（绕 X 轴，上下翻转）、rotateY(deg)（绕 Y 轴，左右翻转）、rotateZ(deg)（等同 2D rotate）、rotate3d(x,y,z,deg)。
- **缩放**：scaleZ、scale3d。

```css
.flip-card { transform: perspective(800px) rotateY(180deg); }
.card { transform: translateZ(50px); }   /* 向观察者拉近 */
```

> 选哪个轴：rotateY 做"左右翻牌"，rotateX 做"上下翻转/扑克翻开"，rotateZ 就是普通平面旋转。给元素整体加 perspective 后，translateZ 正数朝你拉近（变大）、负数推远（变小），可做景深层次。3D 函数基本都提供带 3D 的复合版（translate3d/scale3d）以便一次声明。
