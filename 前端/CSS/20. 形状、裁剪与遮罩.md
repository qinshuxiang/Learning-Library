## 形状、裁剪与遮罩

### 形状与裁剪

#### clip-path 裁剪

**clip-path**：按指定**路径**裁剪元素的可见区域，被裁掉部分不显示、不响应交互，是制造"多边形/圆角/异形"视觉的利器。

```css
.circle { clip-path: circle(50% at center); }
.poly { clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); } /* 菱形 */
.blob { clip-path: path("M10 10 L90 10 ..."); }  /* SVG 路径 */

/* hover 裁切过渡 */
.card { transition: clip-path 0.4s ease; }
```

- 常用函数：circle(r at x y)、ellipse()、inset(top right bottom left round r)（圆角内切）、polygon(x% y%, ...)（多边形）、path()（任意 SVG 路径）。
- **可动画**：几何结构相同的 clip-path（如同为 polygon、顶点数一致）可被 transition/animation 平滑过渡（如"展开/擦除"）。
- **不影响布局**：裁剪只改变可视，盒子占位仍在。

> clip-path 能造圆形头像、菱形卡片、多边形标签、以及"窗口展开"的入场动画。它**不可命中被裁掉区域**（点击穿透到不可见区域不算），这点与 mask 不同。给同一多边形改不同坐标可做酷炫的路径形变动画。



#### 圆形、圆角与 border-radius

**border-radius** 制造**圆角与圆形**，是盒子的"倒角"能力，虽非裁剪，却是形状视觉最常用手段。

```css
.avatar { border-radius: 50%; }                 /* 圆形头像 */
.btn { border-radius: 999px; }                  /* 胶囊/半圆两端 */
.card { border-radius: 12px 12px 0 0; }         /* 上圆下直 */
.egg { border-radius: 50% / 60% 60% 40% 40%; }  /* 椭圆角（斜杠） */
```

- 简写顺序 border-radius: 左上 右上 右下 左下（顺时针）。
- **50%** 得到圆形（对正方形）；999px（或很大的值）得到**胶囊**。
- 斜杠写法 x/y：水平/垂直半径分开，用于椭圆角。

> border-radius 与 clip-path 的选择：**只需圆角/圆形用 border-radius**（简单、不影响裁剪与圆角内背景）；**需任意多边形/异形裁切用 clip-path**。注意 border-radius 只圆角，配合背景时若不裁背景（background-clip/overflow）圆角外的背景直角可能露馅。



#### shape-outside 环绕形状

**shape-outside**：让浮动元素旁的**文字按指定形状环绕**（而不只是贴着方盒子），常用于图文杂志风排版。

```css
.circle {
  float: left;
  width: 200px; height: 200px;
  border-radius: 50%;
  shape-outside: circle(50%);   /* 文字绕圆形边缘环绕 */
  margin-right: 20px;
}
.poly {
  float: left;
  shape-outside: polygon(0 0, 100% 30%, 100% 100%, 0 70%);
}
```

- 需配合 float 使用（作用于浮动元素）。
- 值可用 circle()、ellipse()、polygon()、inset()、url()（图片 alpha 形状）。
- 与 clip-path 的区别：clip-path 裁**元素自身**，shape-outside 改**周边文字的绕行路径**。

> shape-outside 是"文字绕形"的正解：圆形头像/多边形插图旁让文字优雅绕行而非顶出方角。它**只作用于浮动元素**，且文字要足够多才看得出效果。想裁元素本身用 clip-path，想让文字绕不规则的边用 shape-outside。



### 遮罩与混合

#### mask 遮罩

**mask**：用一张**遮罩层（黑白/透明度）**控制元素各处的可见程度——白色处显示、黑色处隐藏、中间为半透明，可裁成任意形状或做渐变淡出。

```css
.img {
  -webkit-mask-image: linear-gradient(to bottom, #000, transparent);
  /* 顶部实显、向下渐隐 → 底部淡出融合 */
  mask-image: radial-gradient(circle, #000 60%, transparent);
  /* 中间实、四周淡出 */
}
.mask-icon {
  -webkit-mask-image: url("star.svg");
  mask-image: url("star.svg");     /* 用图标形状当遮罩 */
  background-color: #f60;          /* 透过镂空显示的颜色 */
}
```

- **mask-image**：遮罩图（渐变或 url() 图片/SVG），也遵循 mask-size/mask-position/mask-repeat。
- **语义**：遮罩的**白色=不透明**、黑色=完全隐藏、灰度=半透明。
- **常见手法**：-webkit-mask + SVG 图形做"变色图标"（比切多色图片灵活）。
- 兼容性：多为 -webkit- 前缀 + 无前缀并用。

> mask 与 clip-path 的区别：**mask 用灰度控制逐像素透明度（可渐变、可柔边），clip-path 用矢量路径硬裁（边缘锐利）**。要"边缘柔和淡出"或"按图标形状镂空变色"用 mask；要"多边形硬切"用 clip-path。做可变色图标（改 background-color 即可）是 mask 的招牌用途。



#### 混合模式与 isolation

**混合模式**让元素与**下层内容**（背景、底下图片）进行色彩运算，产生叠加、变暗、滤色等效果。

```css
.overlay {
  mix-blend-mode: multiply;   /* 正片叠底：变暗，适合纹理叠加 */
  mix-blend-mode: screen;     /* 滤色：变亮，适合光效 */
  mix-blend-mode: difference; /* 差异：反色，常用于图片标题 */
}
.blend-group { isolation: isolate; } /* 把混合限制在组内，不穿透影响更外层 */
```

- **mix-blend-mode**：元素与其**后面的内容**混合。
- **background-blend-mode**：同一元素**多层背景**之间混合。
- 常用模式：multiply、screen、overlay、darken/lighten、difference 等。
- **isolation: isolate**：建立新的层叠上下文，防止某组混合“污染”到更外层内容。

> 混合模式做"图片上叠加带纹理的色块、文字上做反色标题、光影特效"很出效果，但它是**逐像素合成**、开销较大，且在不同浏览器/ GPU 上可能略有差异。用 isolation: isolate 控制混合的作用范围能避免"隔了几层还受影响"的诡异现象。
