## Grid 网格布局

### Grid 布局模型

#### Grid 与 Flex 的分工

**Grid（网格布局）**：是**二维**布局模型，同时管理**行与列**两条轴，适合"整体网格划分"的页面骨架。它和 Flex（一维）互补而非替代。

- **Flex**：沿一条轴（行或列）排列，适合**组件内部**的横向/纵向排布与对齐。
- **Grid**：同时定义行与列，适合**整页/大区块**的二维骨架，或"既要横又要竖"的网格内容。
- 现实习惯：**大结构用 Grid 定网格，单元格内部用 Flex 排内容**，两者嵌套使用。

```css
.grid { display: grid; grid-template-columns: 200px 1fr 1fr; }
```

> 一句话分工：**Flex 管"一行/一列怎么排"，Grid 管"几行几列的版面"**。遇"九宫格、卡片墙、整页布局"优先 Grid；遇"一行里左中右、图标与文字对齐"用 Flex。二者在各自维度最强，嵌套协同才是正确姿势。



#### 网格轨道与区域

Grid 用**行与列切分**出"轨道"，相交形成**单元格（cell）**，多个单元格可合并成**网格区域（area）**。

```css
.container {
  display: grid;
  grid-template-columns: 200px 1fr 1fr; /* 三列 */
  grid-template-rows: auto 300px;        /* 两行 */
  gap: 16px;                              /* 行列间隙 */
}
```

- **grid-template-columns/rows**：定义每条轨道的尺寸（可混合长度、fr、auto、minmax()）。
- **gap**：轨道间距，row-gap / column-gap 可分开设置。
- **fr 单位**：Grid 特有的"份数"，按比例瓜分剩余空间（类似 flex-grow）。

> Grid 世界里的轨道如同"表格的行列线"，gap 就是轨间留白。fr 是 Grid 空间分配的灵魂——grid-template-columns: 1fr 2fr 让右列宽度是左列两倍。相比 flex，Grid 把"几列、每列多宽"一次性用轨道定义说清楚，尤其适合"对称的卡片网格"。



### 轨道定义

#### fr 单位与重复轨道

- **fr（fraction，份）**：等分剩余可用空间的比例单位，1fr 1fr 1fr 即三列等宽。
- **repeat()**：批量定义重复轨道，repeat(3, 1fr) = 1fr 1fr 1fr；也可 repeat(auto-fill, minmax(200px,1fr)) 做自动响应网格。
- **auto**：轨道按内容所需宽度。

```css
.grid { grid-template-columns: repeat(3, 1fr); }        /* 三等分 */
.responsive {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  /* 每列至少 200px，容器够宽就多排几列 → 自动响应 */
}
```

> fr + repeat 是建网格的主语法：**repeat(3,1fr) 稳的三列**、**repeat(auto-fill, minmax(200px,1fr)) 自适应卡片墙**（容器越宽自动挤出的列越多）。auto-fill 与 auto-fit 的区别在于多余空轨道的填满与否，排满卡片常用 auto-fit。



#### minmax 与自动轨道

- **minmax(min, max)**：轨道尺寸在 min 与 max 之间弹性伸缩，做"有下限的响应轨道"。
- **auto-fit / auto-fill**：让浏览器自动决定轨道数量。
- **隐式轨道**：当项目超过显式声明的轨道时，Grid 会**自动创建额外轨道**，其尺寸由 grid-auto-rows/grid-auto-columns 控制。

```css
.grid {
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  grid-auto-rows: minmax(120px, auto); /* 自动行至少 120px */
}
```

> minmax 让轨道"最小保底、最多占满"，是响应网格的基础。当不设 grid-template-rows 时，自动生成的行的默认高度是 auto（由内容决定），如需统一行高可设 grid-auto-rows。理解"隐式轨道"能解释为什么多出的项目会自动排到新行。



### 项目放置

#### 线编号放置

Grid 的轨道边界有**编号线**，项目可用 grid-row/grid-column 按线号**跨越放置**，或按网格区域命名放置。

```css
.item {
  grid-column: 1 / 3;   /* 从第1列线到第3列线 → 占第1~2列 */
  grid-row: 1 / 2;      /* 只占第1行 */
}
```

- **grid-column: 1 / 3**：跨越两条列线之间，占两列。
- **简写 span**：grid-column: 1 / span 2 表示"从第1列开始横跨 2 列"，语义更直观。
- **线号可负**：-1 指最后一条线，grid-column: 1 / -1 表示横贯整行。

> 线编号是 Grid 放置的基础，也是最灵活的方式：一个项目可精确"坐"在任意行列、跨任意格数。想让某个"横幅"横贯所有列，写 grid-column: 1 / -1 最省心（从第一条到最后一条线）。配合 span 让"占几格"的表达更清晰。



#### 命名区域与 auto 放置

- **grid-template-areas**：用字符画给网格区域命名，项目用 grid-area 引用名称，语义一目了然。
- **默认 auto 放置**：不给项目指定位置时，Grid 按文档顺序**自动填满**行列（row-first 先填满行再换下一行）。

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto auto auto;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  gap: 12px;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
```

> 两种放置方式：**线编号精确但抽象**，**命名区域直观但定义麻烦**。做"header/sidebar/main/footer"整页骨架，grid-template-areas 一眼看清布局，是首选；做"图片网格/数据网格"（大量同构单元自动排布）用 auto 放置即可，无需逐个指定。
