## 内置模块 meta 与 selector

### meta 的定位

sass:meta 模块暴露编译器内部信息：值的类型、模块的成员清单、函数与混合宏的引用，以及加载其他模块的手段。它主要服务于库作者与工具代码，业务样式很少需要。

```scss
@use "sass:meta";
```



### 类型与调试辅助

```scss
@use "sass:meta";

@debug meta.type-of(10px);        // number
@debug meta.type-of(1px 2px);     // list
@debug meta.type-of((a: 1));      // map
@debug meta.inspect((width: 200px));  // (width: 200px)
@debug meta.inspect(null);        // null
@debug meta.inspect("Helvetica"); // "Helvetica"
```

meta.type-of($value) 返回类型名字符串，可用于编写按类型分派的通用函数。meta.inspect($value) 返回值的字符串表示，能表示任意 Sass 值（包括无法输出为 CSS 的映射与 null），因此它是调试时的首选打印手段；其输出格式仅供调试，不跨版本保证。



### 变量与成员的存在性判断

```scss
@use "sass:math";
@use "sass:meta";

$spacing: 8px;

@debug meta.variable-exists("spacing");          // true
@debug meta.global-variable-exists("spacing");   // true
@debug meta.function-exists("div", "math");      // true
@debug meta.mixin-exists("reset-list");          // false
```

- meta.variable-exists($name) 判断当前作用域内是否存在该变量，$name 是不含美元符号的字符串。
- meta.global-variable-exists($name, $module: null) 只判断全局变量，传入模块名时判断该模块的变量。
- meta.function-exists 与 meta.mixin-exists 的 $module 参数必须是本文件中某个 @use 规则的命名空间字符串。



### 模块成员清单

```scss
@use "sass:meta";
@use "src" as lib;

@debug meta.module-variables("lib");
// ("radius": 3px, "text": black, "bg": white)
```

三个函数分别列出模块的变量、函数与混合宏：meta.module-variables($module)、meta.module-functions($module)、meta.module-mixins($module)。它们只列出公开成员，以连字符或下划线开头的私有成员不会出现。用途包括：写自动化检查确认库的公开 API 面、在报错信息中列出可用的名字、按名字批量调用。



### 函数值与混合宏值

```scss
@use "sass:math";
@use "sass:meta";

$fn: meta.get-function("sqrt", $module: "math");

@debug meta.type-of($fn);    // function
@debug meta.call($fn, 16);   // 4
@debug meta.call($fn, 25);   // 5
```

- meta.get-function($name, $css: false, $module: null) 取得函数值。$css 置为真时允许取纯 CSS 函数名，否则找不到 Sass 函数会报错。
- meta.call($function, $args...) 调用函数值。
- meta.get-mixin($name, $module: null) 取得混合宏值，配合 meta.apply($mixin, $args...) 使用。
- meta.accepts-content($mixin) 判断该混合宏是否可能接受内容块。

```scss
@use "sass:math";
@use "sass:meta";

@function applyTwice($fn, $value) {
  @return meta.call($fn, meta.call($fn, $value));
}

@debug applyTwice(meta.get-function("sqrt", $module: "math"), 256);
// 4
```

这一组能力让 Sass 支持高阶函数：函数可以作为参数与返回值传递，算法与具体运算解耦。



### 内容块与计算表达式

```scss
@use "sass:meta";

@mixin optional-content {
  @if meta.content-exists() {
    @content;
  } @else {
    color: #000;
  }
}
```

meta.content-exists() 判断当前混合宏是否被传入内容块，只能写在混合宏内部，写在顶层会报 content-exists() may only be called within a mixin。

处理 calc() 一类表达式时用两个函数：

```scss
@use "sass:meta";

@debug meta.calc-name(calc(1px + 2%));                    // calc
@debug meta.calc-args(clamp(50px, var(--w), 1000px));      // 50px, var(--w), 1000px
```

meta.calc-name($calc) 返回表达式名（calc、clamp、min、max），meta.calc-args($calc) 返回参数列表，其中非数值参数以不带引号字符串返回。需要改写或校验计算表达式时用它们拆解。



### 按模块加载样式

meta.load-css($url, $with: null) 加载指定模块并把它的 CSS 作为内容插入当前位置，与 @use 的差别有四点：

- 不引入任何成员，只带入样式。
- 可以出现在样式表的任意位置，包括嵌套在样式规则内部。
- URL 可以是变量且支持插值。
- 与 @use 一样，同一模块只求值一次，且已加载过的模块不能再配置。

```scss
@use "sass:meta";

.theme-dark {
  @include meta.load-css("themes/dark", $with: ("accent": #06f));
}
```

需要把某个模块的样式限制在某个选择器范围内时，这个 mixin 是唯一手段。$with 参数接收的是从变量名（不含美元符号）到值的映射，而非 with 子句的写法。

> [!NOTE]
> **提醒内容**：meta.feature-exists($feature) 自 Dart Sass 1.78.0 起弃用，原因是不同实现的特性集已收敛，逐特性探测失去意义。需要判断版本差异时应改由构建配置区分，不要继续依赖该函数。



### selector 与选择器值

sass:selector 模块用于在选择器层面做运算。选择器值的数据结构是固定三层：外层是逗号分隔的列表（选择器列表），每一项是空格分隔的列表（复杂选择器），再往里是不带引号的字符串（复合选择器）。

```scss
@use "sass:selector";

@debug selector.parse(".main aside:hover, .sidebar p");
// .main aside:hover, .sidebar p
```

打印时会还原为选择器文本，其内部结构仍是三层嵌套列表，需要观察结构时用 meta.inspect 包裹。

函数参数既可以是这种嵌套结构，也可以直接传普通字符串，两者等价。

```scss
@use "sass:selector";

@debug selector.append("a", ".disabled");          // (a.disabled,)
@debug selector.append(".accordion", "__copy");    // (.accordion__copy,)
@debug selector.nest("ul", "li");                  // (ul li,)
@debug selector.nest(".alert, .warning", "p");     // .alert p, .warning p
@debug selector.nest(".alert", "&:hover");         // (.alert:hover,)
@debug selector.simple-selectors("a.disabled");    // a, .disabled
```

结果按选择器列表打印，含单个选择器时会带一个尾逗号，如 (a.disabled,)；含多个选择器时不带，如 a, .disabled。两种都属正常的列表表示。

- selector.append($selectors...) 无空格拼接，用于 BEM 后缀这类组合。
- selector.nest($selectors...) 按嵌套语义拼接，第二个及以后的参数可以含父选择器引用 &。
- selector.simple-selectors($selector) 拆出单个简单选择器，参数不能含组合器或逗号。



### selector 的关系运算

```scss
@use "sass:selector";

@debug selector.is-superselector("a", "a.disabled");  // true
@debug selector.is-superselector("a.disabled", "a");  // false
@debug selector.unify("a", ".disabled");              // (a.disabled,)
@debug selector.unify("a", "h1");                     // null
@debug selector.replace("a.disabled", "a", ".link");  // (.disabled.link,)
@debug selector.extend("a.disabled", "a", ".link");   // a.disabled, .disabled.link
```

- is-superselector($super, $sub) 判断前者是否覆盖后者的全部匹配对象。
- unify($selector1, $selector2) 求交集，无交集时返回 null。
- replace($selector, $original, $replacement) 用后者替换前者中出现的部分。
- extend($selector, $extendee, $extender) 等价于对单个选择器执行一次 @extend。

> [!TIP]
> **建议内容**：这些函数在业务样式中很少需要，它们的实际用途是构建工具与库：检查选择器是否越界、批量改写类名前缀、为设计系统生成选择器变体。需要的是「按选择器结构做判断」而不是「拼字符串」时再用它们，比正则改文本可靠。
