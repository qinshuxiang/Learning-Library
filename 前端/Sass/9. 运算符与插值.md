## 运算符与插值

### 数值运算与单位

Sass 支持加、减、乘、除、取余五种算术运算，数值可带单位，单位参与运算并按 CSS 单位换算规则归约。

```scss
@use "sass:math";

@debug 1 + 2;            // 3
@debug 1px + 2px;        // 3px
@debug 3 * 2;            // 6
@debug (1 + 2) * 3;      // 9
@debug 10 % 3;           // 1
@debug 1in + 6px;        // 1.0625in
@debug math.div(100px, 5px);  // 20
@debug math.div(100px, 5);    // 20px
@debug math.div(100px, 5s);   // calc(20px / 1s)
@debug 10px * 2;         // 20px
```

单位规则有三条需要记住：

- 相加相减要求单位可换算。1in 与 6px 可换算，结果为左操作数的单位；px 与 em 之间不可换算，相加会直接报错。
- 相乘时单位也参与相乘，10px 乘 2 得到 20px，而 5px 乘 10px 的单位会变成 px*px，通常不是想要的结果。
- 相除时相同单位相消，结果成为无单位的比值；不同单位相除会形成复合单位，如 100px 除以 5s 得到带 px/s 单位的值，该值在输出时表示为未求值的 calc 表达式。



### 除法的三种形态

斜杠在 Sass 中有三重含义：既可能是除法，也可能是 CSS 里本就合法的斜杠语法（如 font 简写的 font-size/line-height、grid-area 的行列写法、aspect-ratio 的比值），还可能是斜杠分隔的列表。因此直接写 100px / 3 不再被当作除法。

```scss
@use "sass:math";

@debug 100px / 3;          // 100px/3，斜杠分隔的列表
@debug (100px / 3);        // 33.333333333333336px，附加弃用警告
@debug math.div(100px, 3); // 33.333333333333336px
```

```shell
DEPRECATION WARNING [slash-div]: Using / for division outside of calc()
is deprecated and will be removed in Dart Sass 2.0.0.

Recommendation: math.div(100px, 3) or calc(100px / 3)
```

需要真正的除法时用 math.div($number1, $number2)；需要输出 CSS 原生除法时用 calc。带括号的斜杠仍按除法处理，但会输出弃用警告，新代码不应再写。



### 比较与逻辑运算

比较运算返回布尔值；相等比较不忽略单位差异。

```scss
@use "sass:math";

@debug 10 == 10px;         // false，带单位与不带单位不相等
@debug 10 != 5;            // true
@debug 5 > 3;              // true
@debug true and false;     // false
@debug not true;           // false
@debug math.div(10, 4) == 2.5;   // true
@debug (1 2 3) == (1, 2, 3);     // false，分隔符不同即不相等
```

- 数值比较用于判断区间，如 @if $width > 768px。
- and、or、not 用于组合条件，短路求值。
- 相等比较对列表与映射逐个元素递归比较，但分隔符（空格、逗号、斜杠）参与判定。



### 字符串运算

加号在字符串语境下表示拼接。结果是否带引号由左操作数决定。

```scss
@debug "1" + "2";   // 12
@debug "abc" + 1;   // abc1
@debug "a" + b;     // ab
@debug a + "b";     // ab
```

减号可用作字符串连接并插入连字符，等号与斜杠在部分语境下也有字符串语义，但写法隐晦，容易与算术混淆。需要拼接字符串时统一使用插值或加号，不要依赖减号。

> 引号传播规则与 CSS 产物直接相关：属性值若需要保留引号（例如 content 的文本、font-family 中含空格的字体名），左操作数必须带引号；反之需要裸标识符（例如 animation-name、grid-template-areas 的自定义名）时左侧不要带引号。



### 插值

插值语法把变量或表达式的结果嵌入到文本位置，写法是井号加大括号，括号内写表达式。

```scss
$name: "card";
$count: 3;

.icon-#{$name} { width: #{$count * 10}px; }
.content::after { content: "共 #{$count} 项"; }
:root { --gap: #{$count}px; }
```

```css
@charset "UTF-8";
.icon-card {
  width: 30px;
}

.content::after {
  content: "共 3 项";
}

:root {
  --gap: 3px;
}
```

插值可用的位置有四类：

- 选择器：类名、元素名、伪类后缀，如 .icon-#{$name}。
- 属性名：如 #{$prop}-color，用于批量生成同族属性。
- 属性值：把计算结果嵌入文本，如 #{$count}px。
- 字符串内部：在引号内直接插值，如 "共 #{$count} 项"。

插值与变量的直接引用的差别在于求值方式：插值把值转成不带引号的文本再拼入上下文，因此 $name 取值为 "card" 时，.icon-#{$name} 得到 .icon-card 而不是 .icon-"card"。

> 插值在自定义属性中的作用不可替代。CSS 自定义属性的声明值除插值外不接受 Sass 表达式，写成 --gap: $count * 2px 会原样输出这段文本；必须写成 --gap: #{$count * 2px} 才会在编译期求值。



### 列表与映射的文本形态

列表与映射无法直接写进 CSS 声明，需借助 meta.inspect($value) 或遍历后逐项输出。

```scss
@use "sass:meta";

$spacing: (1px, 2px);
@debug meta.inspect($spacing);      // 1px, 2px
@debug meta.inspect([1px 2px]);     // [1px 2px]
@debug meta.inspect(());            // ()
@debug meta.type-of(());            // list
```

方括号是列表值的一部分，meta.inspect 会原样呈现；空括号在类型上属于 list，在映射函数语境下也可当作空映射使用。

> [!NOTE]
> **提醒内容**：产物含非 ASCII 字符时，Dart Sass 默认在文件头插入 @charset "UTF-8"。这是规范行为而非多余输出，移除它会导致中文内容在部分环境下乱码；如需压缩体积，可用 --no-charset 关闭，但要确保服务端已正确声明编码。
