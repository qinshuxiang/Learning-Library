## 变量、数据类型与作用域

### 变量声明与命名

Sass 变量以美元符号开头，用冒号赋值，赋值表达式右侧可以是任意 SassScript 表达式。

```scss
$brand: #ff6600;
$font-stack: "Helvetica Neue", sans-serif;
$spacing: 8px;
$double-spacing: $spacing * 2;
```

变量名中的连字符与下划线完全等价，$font-size 与 $font_size 指向同一个变量，混用不会报错。

```scss
$font-size: 14px;

.a { size: $font_size; }
```

```css
.a {
  size: 14px;
}
```

命名上仍应统一使用连字符，下划线写法是历史兼容而非另一种风格。

变量可以重新赋值，后续引用取最新值。Sass 变量与 CSS 自定义属性的关键差别在于求值时机：Sass 变量在编译期解析并替换为字面值，产物中不会留下变量本身。



### 数据类型

Sass 共有十一种值类型，用 meta.type-of($value) 可返回类型名。实测各类型的返回值如下：

```scss
@use "sass:meta";

@debug meta.type-of(10px);           // number
@debug meta.type-of("a");            // string
@debug meta.type-of(#fff);           // color
@debug meta.type-of(1px 2px);        // list
@debug meta.type-of((a: 1));         // map
@debug meta.type-of(null);           // null
@debug meta.type-of(true);           // bool
@debug meta.type-of(calc(1px + 2%)); // calculation
@debug meta.type-of(1) + " " + meta.type-of(null);
// number null
```

- number：数字，可带单位，如 10px、1.5、50%。
- string：字符串，分带引号与不带引号两种。
- color：颜色，可以是十六进制、颜色名或颜色函数的结果。
- list：列表，如 1px 2px 3px 或 (a, b, c)。
- map：映射，键值对的集合，如 (small: 4px, large: 16px)。
- bool：布尔值，只有 true 与 false。
- null：空值，表示「没有值」。
- calculation：计算表达式，如 calc(1px + 2%)、clamp(...)，在未求值前保持为计算类型。
- function 与 mixin：函数值与混合宏值，由 meta.get-function($name, $css: false, $module: null) 与 meta.get-mixin($name, $module: null) 返回。
- arglist：参数列表，即可变参数在函数或混合宏内部的实际类型。



### 字符串的两种形式

字符串带不带引号属于值的一部分：带引号字符串会原样输出引号，不带引号字符串输出裸文本。

```scss
@use "sass:meta";

$quoted: "Helvetica";
$unquoted: Helvetica;

.b { a: $quoted; b: $unquoted; }
@debug meta.type-of($quoted);    // string
@debug meta.type-of($unquoted);  // string
@debug $quoted == $unquoted;     // true，引号不参与相等比较
```

```css
.b {
  a: "Helvetica";
  b: Helvetica;
}
```

字符串相加时，结果是否带引号由加号左侧决定：

```scss
@debug "a" + b;  // ab，左侧带引号则结果带引号
@debug a + "b";  // ab，左侧不带引号则结果不带引号
```



### 真假值与 null

除 false 与 null 之外的所有值都是真值，这一点与 JavaScript 不同：数字 0 与空字符串都算真。

```scss
$flag: null;

.c { @if $flag { color: red; } @else { color: blue; } }   // blue
.d { @if 0 { color: red; } @else { color: blue; } }       // red
.e { @if "" { color: red; } @else { color: blue; } }      // red
```

> null 的典型用途是「可选值」：变量默认为 null 时，条件分支可判断调用方是否传入；同时含 null 的列表在输出时会被自动剔除，便于条件拼接声明。



### 作用域与遮蔽

变量有作用域。在样式规则或混合宏内部声明的变量只在块内有效，同名时会遮蔽外层的变量，块结束后外层变量恢复。

```scss
$brand: #336699;

.scope {
  $brand: #ff6600;   // 局部变量，遮蔽外层
  color: $brand;
}

.after {
  color: $brand;
}
```

```css
.scope {
  color: #ff6600;
}

.after {
  color: #336699;
}
```



### !global 与跨块修改

在局部作用域内给变量加上 !global 标志，赋值会作用于全局变量本身，块结束后仍然生效。

```scss
$brand: #336699;

.g {
  $brand: #000 !global;
}

.g2 {
  color: $brand;
}
```

```css
.g2 {
  color: #000;
}
```

> [!CAUTION]
> **注意内容**：!global 会破坏变量的可追踪性，块的执行顺序变成隐式依赖。仅在需要跨越块写入状态时使用，绝大多数场景应改为把值作为参数传入混合宏或函数，靠返回值传递结果。



### !default 与可配置模块

在变量声明末尾加 !default，表示该变量只在尚未赋值或值为 null 时才取此值。它用于定义库的默认配置，允许调用方覆盖。

```scss
// _theme.scss
$text-color: black !default;
$background-color: white !default;

.button {
  color: $text-color;
  background: $background-color;
}
```

调用方通过 @use 的 with 子句覆盖默认值，覆盖发生在模块首次加载时。!default 与 with 的完整配合方式见模块系统相关篇章。



### 与 CSS 自定义属性的分工

Sass 变量与 CSS 自定义属性解决不同层面的问题，同一项目中常并存：

- Sass 变量：编译期常量，可用于颜色运算、循环次数、单位换算等需要参与计算的位置。
- CSS 自定义属性：运行期变量，可被 JavaScript 读取与修改，支持级联与媒体查询覆盖，但无法在编译期参与运算。

```scss
@use "sass:color";

$brand: #ff6600;
$steps: 3;

:root {
  --brand: #{$brand};
  --brand-dark: #{color.scale($brand, $lightness: -20%)};
}

@for $i from 1 through $steps {
  .theme-#{$i} {
    --brand: #{color.adjust($brand, $hue: $i * 40deg)};
  }
}
```

> 上例中颜色运算由 Sass 在编译期完成，结果通过插值写入自定义属性，运行期切换主题只需改变元素上的类名。需要跨路由、跨组件动态换肤时用自定义属性承接，需要预生成色阶时用 Sass 变量与循环。
