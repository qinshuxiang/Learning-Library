## 内置模块 string

### 加载与引号处理

字符串函数集中在 sass:string 模块。

```scss
@use "sass:string";
```

quote 与 unquote 用于切换字符串的引号形式。这两个操作只改变值的引号属性，不改内容。

```scss
@use "sass:meta";
@use "sass:string";

@debug meta.inspect(string.quote(Helvetica));         // "Helvetica"
@debug meta.inspect(string.quote("Helvetica"));       // "Helvetica"
@debug meta.inspect(string.unquote("Helvetica"));     // Helvetica
@debug meta.inspect(string.unquote(".widget:hover")); // .widget:hover
```

> [!NOTE]
> **提醒内容**：@debug 打印单个字符串时会省略引号，打印列表中的字符串时保留引号，两种情况下日志看起来都可能与实际值不符。要确认某个值的引号属性，统一用 meta.inspect($value) 包裹后再打印，它会带上引号。

> string.unquote 可以产出不符合 CSS 语法的字符串，例如把含空格的内容还原为裸标识符。它是拼接类名、选择器、动画名时的常用手段，但需自行保证结果合法。



### 查找与计数

```scss
@use "sass:string";

@debug string.index("Helvetica Neue", "Helvetica"); // 1
@debug string.index("Helvetica Neue", "Neue");      // 11
@debug string.length("Helvetica Neue");             // 14
@debug string.length(bold);                         // 4
@debug string.length("");                           // 0
```

索引从 1 开始计数，与 CSS 中多数从 0 开始的位置概念不同。string.index 找不到子串时返回 null，因此可用它做包含判断：

```scss
@use "sass:string";

@function startsWith($string, $prefix) {
  @return string.index($string, $prefix) == 1;
}

@debug startsWith("data-theme-dark", "data-");   // true
```



### 切片与插入

string.slice($string, $start-at, $end-at: -1) 的两端都是闭区间，负索引从末尾倒着数，-1 表示最后一个字符。

```scss
@use "sass:string";

@debug string.slice("Helvetica Neue", 11);    // Neue
@debug string.slice("Helvetica Neue", 1, 3);  // Hel
@debug string.slice("Helvetica Neue", 1, -6); // Helvetica
```

string.insert($string, $insert, $index) 在指定位置插入内容，插入点位于该索引字符之前。

```scss
@use "sass:string";

@debug string.insert("Roboto Bold", " Mono", 7);  // Roboto Mono Bold
@debug string.insert("Roboto Bold", " Mono", -6); // Roboto Mono Bold
@debug string.insert("Roboto", " Bold", 100);     // Roboto Bold
```

索引越界不会报错：超过长度时追加到末尾，小于负长度时插到开头。这让插入操作在长度不确定的字符串上也能安全使用。



### 大小写与拆分

```scss
@use "sass:string";

@debug string.to-upper-case(bold);       // BOLD
@debug string.to-lower-case(SANS-SERIF); // sans-serif
@debug string.split("Segoe UI Emoji", " ");             // ["Segoe", "UI", "Emoji"]
@debug string.split("Segoe UI Emoji", " ", $limit: 1);  // ["Segoe", "UI Emoji"]
```

大小写转换只处理 ASCII 字母，中文与其他字符不受影响。string.split($string, $separator, $limit: null) 返回带方括号的逗号分隔列表，$limit 限制最多拆分次数，上例限一次后剩下的部分整体留在最后一项。

拆分常与列表函数配合，把一串文本还原成结构化数据：

```scss
@use "sass:list";
@use "sass:meta";
@use "sass:string";

$token: "primary:#ff6600";

@function splitToken($token) {
  @return string.split($token, ":");
}

$parts: splitToken($token);
@debug meta.inspect(list.nth($parts, 1));   // "primary"
@debug meta.inspect(list.nth($parts, 2));   // "#ff6600"
```



### 唯一标识符

string.unique-id() 返回一个随机的、保证是合法 CSS 标识符的字符串，同一次编译内不重复。

```scss
@use "sass:string";

@debug string.unique-id();   // 例如 uabtrnzug
@debug string.unique-id();   // 例如 u6w1b1def
```

它用于需要保证唯一性的场景：动画名、层叠层名、临时类名。与 math.random() 不同，它返回的是合法标识符而非数值，适合直接作为名字使用。

> [!NOTE]
> **提醒内容**：string.unique-id() 的结果同样不可复现，两次编译产出的名字不同。若该名字需要被 JavaScript 或其他样式表引用，应当改用确定性的命名规则，例如由组件名与用途拼接而成。



### 与插值的分工

字符串函数与插值解决两类不同问题：

- 需要在编译期对文本做检索、切分、改写：用 string 模块的函数。
- 只需把值嵌入文本，不做加工：用插值 #{$var}。

```scss
@use "sass:string";

$modifier: "hover";

// 加工：先把首字母转大写，再拼成状态类名
$state: string.to-upper-case(string.slice($modifier, 1, 1))
       + string.slice($modifier, 2);
.is-#{$state} { color: red; }
```

```css
.is-Hover {
  color: red;
}
```

上例的组合方式体现了函数式加工与插值输出的分工：string 模块负责变换，插值负责落到选择器位置。
