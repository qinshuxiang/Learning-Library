## 参考资料与延伸阅读

### 官方文档

Sass 的唯一权威来源是官方站点，内容按下列结构组织：

- 语法篇：https://sass-lang.com/documentation/syntax/ 说明 SCSS 与缩进语法的差异、注释、特殊函数。
- 样式规则篇：https://sass-lang.com/documentation/style-rules/ 覆盖属性声明、父选择器、占位符选择器、嵌套规则。
- 变量篇：https://sass-lang.com/documentation/variables/ 说明作用域、!default 与 !global 的完整规则。
- 值类型篇：https://sass-lang.com/documentation/values/ 逐类说明数字、字符串、颜色、列表、映射、布尔、null、计算表达式。
- 规则篇：https://sass-lang.com/documentation/at-rules/ 收录 @use、@forward、@mixin、@function、@extend、@media、控制指令。
- 内置模块篇：https://sass-lang.com/documentation/modules/ 是函数签名与示例的查询入口，每个函数都标注了引入版本。
- 破坏性变更篇：https://sass-lang.com/documentation/breaking-changes/ 是升级项目的必读清单，每项写明了引入版本与替代方案。

命令行与 JavaScript API 的说明分别在 https://sass-lang.com/documentation/cli/dart-sass/ 与 https://sass-lang.com/documentation/js-api/。



### 线上试验与迁移工具

- Sass Playground：https://sass-lang.com/playground 提供在线编译，左右分栏对照源码与产物。官方文档中的每个示例都带进入 Playground 的链接，验证行为时最直接。
- sass-migrator：https://sass-lang.com/documentation/cli/migrator/ 是官方迁移工具，支持模块化、除法、颜色函数、命名空间等迁移子命令，均提供 --dry-run 预演。
- Sass 样式指南：https://sass-guidelin.es/ 是社区中被引用最多的组织约定来源，7-1 目录模式即出自此处，同时给出了命名与书写顺序的建议。



### 相关规范

以下 CSS 规范与 Sass 的行为直接相关，遇到边界问题时需要回到规范确认：

- CSS 颜色规范第四版：定义 lab、lch、oklab、oklch、color 函数、color-mix 与广色域行为，是 Sass 颜色模块语义的来源。
- CSS 颜色规范第五版：补充 color-mix 的插值空间与相对颜色语法。
- CSS 嵌套规范：定义原生嵌套的解析规则。Sass 在嵌套与声明混排上的行为变更正是为了向它对齐。
- CSS 值与单位规范：定义单位换算关系，Sass 的长单位换算规则与之保持一致。



### 构建链集成

Sass 本身只负责编译，前缀补全、压缩、拆分由下游工具承担。具体接入方式参见本库前端构建工具领域的对应篇章：

- Vite 的 CSS 与预处理器一篇：说明只安装 sass 依赖即可解析 SCSS 的原因与配置方式。
- webpack 的 loader 与 plugin 一篇：给出 sass-loader 与 postcss-loader、css-loader 的链式顺序。
- Gulp 的 CSS 与样式流水线一篇：给出 dart-sass 与 gulp-sass 的搭配写法及增量编译配置。
- Babel 与 PostCSS 一篇：说明预处理器与后处理器的分工边界，Sass 负责语法扩展，PostCSS 负责前缀与降级。
- Rollup 处理样式与资源一篇：说明库里打包样式时的 sideEffects 声明与产物形态。

样式工程化的通用约定（命名方法论、作用域隔离、层叠管理）见前端 CSS 领域的工程化与最佳实践一篇，本篇的令牌与分层建立在那一篇的约定之上。



### 生态中的相邻方案

选型时可将 Sass 与下列方案对照：

- Less：语法与 Sass 相近，功能集更小，模块系统与函数能力弱于 Sass，多见于较早的项目。
- Stylus：语法自由度最高，允许省略括号与冒号，代价是团队一致性难以维持。
- 原生 CSS：自定义属性、原生嵌套、@layer、color-mix 已覆盖 Sass 的一部分能力，选型分界线见简介篇。
- PostCSS 插件组合：以 postcss-preset-env 为核心，用未来语法加降级插件替代预处理器，适合不愿引入独立编译链的项目。
- 原子化框架：Tailwind 一类以预生成工具类替代手写样式，与 Sass 是不同层面的方案，可并存，此时 Sass 主要用于令牌与少量组件样式。



### 版本查询入口

Dart Sass 的发布记录在 https://github.com/sass/dart-sass/blob/main/CHANGELOG.md，每项变更标注了版本号与影响范围。判断某个函数是否可用、某个行为何时变更时，以该文件为准，比第三方博客可靠。

> [!NOTE]
> **提醒内容**：本文所有示例与输出均在 Dart Sass 1.104.1 上实测，函数签名与弃用状态以此版本为准。Sass 的小版本迭代频率较高，函数可用性以官方文档标注的引入版本为下限判断，弃用项以破坏性变更页面的当前状态为准。
