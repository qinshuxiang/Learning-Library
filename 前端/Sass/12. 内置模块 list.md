## 内置模块 list

### 字面量与分隔符

列表是一串有序值，分隔符有空格、逗号、斜杠三种，方括号是可选的包裹形式。

```scss
$space-list: 1px 2px 3px;
$comma-list: (1px, 2px, 3px);
$slash-list: 1px / 2px / 3px;
$bracketed: [1px 2px 3px];
```

三条性质需要在开始使用列表函数前明确：

- 单值也是列表。变量 $size 取值 10px 时，list.length($size) 返回 1。
- 映射也是列表。映射的每个元素是「键 值」构成的二元列表，因此所有列表函数对映射同样可用。
- 分隔符属于值本身。1px 2px 与 (1px, 2px) 不相等，比较与拼接时都参与判定。

```scss
@use "sass:list";
@use "sass:meta";

@debug list.length(10px);            // 1
@debug list.length(10px 20px 30px);  // 3
@debug list.length((a: 1, b: 2));    // 2
@debug list.separator(1px 2px 3px);  // space
@debug list.separator((1px, 2px));   // comma
@debug list.is-bracketed([1px, 2px]); // true
@debug list.is-bracketed(1px 2px);    // false
@debug meta.type-of(());              // list
```



### 读取元素

```scss
@use "sass:list";

@debug list.nth(1px solid red, 2);        // solid
@debug list.nth(10px 20px 30px, -1);      // 30px
@debug list.index(1px solid red, 1px);    // 1
@debug list.index(1px solid red, solid);  // 2
@debug list.index(1px solid red, dashed); // null
```

list.nth($list, $n) 的索引从 1 开始，负索引从末尾计数，-1 表示最后一项；索引越界会报错。list.index($list, $value) 找不到时返回 null，因此可直接作为成员判断使用：

```scss
@use "sass:list";

@function hasSize($sizes, $target) {
  @return list.index($sizes, $target) != null;
}

@debug hasSize(small medium large, medium);  // true
```



### 替换、追加与合并

```scss
@use "sass:list";

@debug list.set-nth(10px 20px 30px, 2, 2em);   // 10px 2em 30px
@debug list.append(10px 20px, 30px);           // 10px 20px 30px
@debug list.append(10px 20px, 30px 40px);      // 10px 20px (30px 40px)
@debug list.join(10px 20px, 30px 40px);        // 10px 20px 30px 40px
@debug list.join((blue, red), (#abc, #def));   // blue, red, #abc, #def
@debug list.join((blue, red), (#abc, #def), $separator: space);
// blue red #abc #def
```

append 与 join 的差别容易用错：append 把第二个参数整体作为一个元素追加，所以传入列表时会嵌套；join 把两个列表的元素逐个拼接。往列表尾部加单个值用 append，合并两个列表用 join，这一点在传参为列表时尤其关键。

list.set-nth($list, $n, $value) 与 list.nth 使用同一套索引规则，负索引同样从末尾计数，越界时报错。



### 结构转换

```scss
@use "sass:list";

@debug list.slash(1px, 50px, 100px);                 // 1px / 50px / 100px
@debug list.zip(10px 50px 100px, short mid long);    // 10px short, 50px mid, 100px long
@debug list.zip(10px 50px 100px, short mid);         // 10px short, 50px mid
```

list.slash($elements...) 生成斜杠分隔列表，用于需要输出斜杠语法的属性值（字体简写、aspect-ratio、grid-area）。它是过渡期方案，因为斜杠在 Sass 中仍保留除法语义。

list.zip($lists...) 把多个等长列表转置：取每个列表同一位置的元素组成一项。长度不等时以最短者为准，多余元素丢弃。它是「两份列表配对」的标准做法：

```scss
@use "sass:list";

$names: small medium large;
$sizes: 4px 8px 16px;

@each $pair in list.zip($names, $sizes) {
  .gap-#{list.nth($pair, 1)} { gap: list.nth($pair, 2); }
}
```

```css
.gap-small {
  gap: 4px;
}

.gap-medium {
  gap: 8px;
}

.gap-large {
  gap: 16px;
}
```



### 遍历与解构

@each 直接遍历列表，也可对元素解构。上例的配对写法可用解构简化：

```scss
@use "sass:list";

@each $name, $size in list.zip(small medium large, 4px 8px 16px) {
  .gap-#{$name} { gap: $size; }
}
```

> 列表与映射都能被 @each 直接遍历，因此「一份数据派生多条规则」不一定要先把数据整理成映射。列表更适合有顺序含义的场景（刻度、索引、序列），映射更适合按名查询的场景（令牌表、配置项）。

> [!TIP]
> **建议内容**：列表的分隔符不一致是排查 Sass 问题的常见来源。收到「拼接结果不符合预期」或「比较结果恒为 false」时，先用 list.separator($list) 打印分隔符，再用 meta.inspect($list) 看值的确切形态，通常一眼可见问题。
