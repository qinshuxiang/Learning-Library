## 内置模块 map

### 字面量写法

映射是键到值的对应关系，字面量用圆括号包裹，键值对之间用逗号分隔。

```scss
$font-weights: ("regular": 400, "medium": 500, "bold": 700);
$breakpoints: (small: 576px, medium: 768px, large: 992px);
```

键可以是任意 Sass 值：带引号字符串、不带引号字符串、数字、颜色、布尔值。同一个映射中混用不同类型键是允许的，但会降低可读性，实际使用时统一键的写法。

映射与列表的关系有两条：映射本身是列表，元素为「键 值」二元列表；空括号 () 在类型上是列表，在映射函数语境下可当作空映射传入。

```scss
@use "sass:list";
@use "sass:map";
@use "sass:meta";

@debug list.length((a: 1, b: 2));   // 2
@debug meta.type-of((a: 1));        // map
@debug meta.type-of(());            // list
@debug map.get((), "anything");     // null
```



### 读取与存在判断

```scss
@use "sass:map";

$font-weights: ("regular": 400, "medium": 500, "bold": 700);

@debug map.get($font-weights, "medium");       // 500
@debug map.get($font-weights, "extra-bold");   // null
@debug map.has-key($font-weights, "regular");  // true
@debug map.has-key($font-weights, "bolder");   // false
@debug map.keys($font-weights);                // "regular", "medium", "bold"
@debug map.values($font-weights);              // 400, 500, 700
```

map.get($map, $key, $keys...) 的键不存在时返回 null，不会报错；这与 list.nth 的越界报错形成对比。需要区分「键不存在」与「键存在但值为 null」时用 map.has-key 先行判断。

多层映射可以把剩余键一次性传入，逐层下钻：

```scss
@use "sass:map";

$config: (a: (b: (c: d)));

@debug map.get($config, a, b, c);   // d
@debug map.get($config, a, x);      // null
```

任一层缺键或该层的值不是映射，map.get 都返回 null 而不报错，因此它能安全地用于探测配置树。



### 增删改

三个函数都返回新的映射，原映射不被修改。

```scss
@use "sass:map";

$font-weights: ("regular": 400, "medium": 500, "bold": 700);

@debug map.set($font-weights, "regular", 300);
// ("regular": 300, "medium": 500, "bold": 700)
@debug map.remove($font-weights, "regular");
// ("medium": 500, "bold": 700)
@debug map.remove($font-weights, "regular", "bold");
// ("medium": 500)
@debug map.remove($font-weights, "bolder");
// ("regular": 400, "medium": 500, "bold": 700)，不存在的键被忽略

$light-weights: ("lightest": 100, "light": 300);
$heavy-weights: ("medium": 500, "bold": 700);
@debug map.merge($light-weights, $heavy-weights);
// ("lightest": 100, "light": 300, "medium": 500, "bold": 700)
```

map.merge($map1, $map2) 的键冲突规则是后者覆盖前者；键的顺序保持 $map1 的顺序，$map2 中的新键追加在末尾。map.set 也支持多层键，写法是把中间层键依次传入、最后的键与值收尾。



### 深度操作

普通 merge 对嵌套映射做整体替换，deep-merge 做递归合并。

```scss
@use "sass:map";

$base: (
  "sizes": ("sm": 4px, "md": 8px),
  "colors": ("primary": #f60)
);
$patch: (
  "sizes": ("lg": 16px),
  "colors": ("primary": #06f)
);

@debug map.deep-merge($base, $patch);
// ("sizes": ("sm": 4px, "md": 8px, "lg": 16px), "colors": ("primary": #06f))
@debug map.merge($base, $patch);
// ("sizes": ("lg": 16px), "colors": ("primary": #06f))
```

同一组数据在两种合并下的结果完全不同：deep-merge 保留了 sizes 下的 sm 与 md，merge 把整个 sizes 换成了补丁中的内容。做主题覆盖、配置叠加时必须明确要哪一种。

map.deep-remove($map, $key, $keys...) 对应深度删除，末尾键之前的键用于定位目标层：

```scss
@use "sass:map";

$fonts: ("Helvetica": ("weights": ("regular": 400, "bold": 700)));

@debug map.deep-remove($fonts, "Helvetica", "weights", "regular");
// ("Helvetica": ("weights": ("bold": 700)))
```



### 映射作为配置载体

映射是承载设计令牌与组件配置的默认结构，原因是它能按名查询且可以逐层下钻。

```scss
@use "sass:map";

$breakpoints: (
  "sm": 576px,
  "md": 768px,
  "lg": 992px
);

@mixin respond($name) {
  $value: map.get($breakpoints, $name);

  @if $value == null {
    @error "未知断点名 #{$name}，可用的断点有 #{map.keys($breakpoints)}";
  }

  @media (min-width: $value) {
    @content;
  }
}

.card {
  @include respond("md") {
    display: flex;
  }
}
```

```css
@media (min-width: 768px) {
  .card {
    display: flex;
  }
}
```

上例体现了映射做配置的三个配套要点：查询失败时返回 null，正好在 @error 中给出可用键列表；map.keys($map) 输出逗号分隔的键列表，报错信息可以直接内嵌；调用侧只传字符串名，取值的细节封装在混合宏内。

> [!IMPORTANT]
> **重要内容**：当需要「已知键必存在」的查询时，直接 map.get 会返回 null 并把问题推迟到使用处（例如某个属性值变成空）。在库代码中应加一层校验函数，缺键时 @error 报出键名，把失败点收敛到调用处。



### 遍历与顺序

@each 遍历映射时，映射的插入顺序会被保留，键去重且后写入者覆盖。

```scss
@use "sass:map";

$palette: ("primary": #ff6600, "secondary": #336699);

@each $name, $color in $palette {
  .text-#{$name} { color: $color; }
}
```

```css
.text-primary {
  color: #ff6600;
}

.text-secondary {
  color: #336699;
}
```

顺序稳定的价值在于产物可预期：映射的书写顺序就是规则输出顺序，需要调整优先级时改映射顺序，不必改循环体。

> 映射的键在 Sass 中无序存储但遍历有序，所以 map.keys($map) 的返回顺序与书写顺序一致。需要排序时应显式处理，Sass 不提供内置的排序函数，常见做法是把键取出后用 @for 按索引访问完成插入排序。
