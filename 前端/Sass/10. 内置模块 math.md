## 内置模块 math

### 加载与模块常量

数学函数集中在 sass:math 模块，加载后所有调用都带 math 命名空间。

```scss
@use "sass:math";
```

模块提供七个常量，用于数值边界判断与浮点比较：

```scss
@use "sass:math";

@debug math.$pi;                // 3.141592653589793
@debug math.$e;                 // 2.718281828459045
@debug math.$epsilon;           // 0，受 10 位精度限制
@debug math.$max-safe-integer;  // 9007199254740991
@debug math.$min-safe-integer;  // -9007199254740991
```

math.$epsilon 是 1 与大于 1 的最小双精度浮点数之差，在 Sass 的 10 位有效精度下显示为 0。比较两个浮点数是否相等时不要用等号，而应判断差值是否小于某个容差。

math.$max-safe-integer 与 math.$min-safe-integer 是能保证加 1 或减 1 不丢精度的整数边界，对应 JavaScript 的 Number.MAX_SAFE_INTEGER。



### 取整与边界

四个取整函数把小数转为整数，一个夹取函数把数值限制在区间内。

```scss
@use "sass:math";

@debug math.ceil(4.2);      // 5
@debug math.floor(-2.1);    // -3
@debug math.round(2.5);     // 3
@debug math.abs(-10px);     // 10px
@debug math.clamp(-1, 0, 1);        // 0
@debug math.clamp(1px, -1px, 10px); // 1px
@debug math.max(1px, 4px);  // 4px
@debug math.min(1px, 4px);  // 1px
```

三个取整函数的边界行为值得记住：floor 向负无穷方向取整，因此 floor(-2.1) 得 -3 而不是 -2；round 对 .5 向上取整；ceil 向正无穷方向取整。

math.clamp($min, $number, $max) 三个参数都必须单位兼容，或全部无单位。math.max 与 math.min 接受任意个数参数，也可以传入展开的列表。



### 除法与百分比

math.div($number1, $number2) 是唯一的除法写法，单位按相除规则处理。

```scss
@use "sass:math";

@debug math.div(100px, 3);     // 33.333333333333336px
@debug math.div(100px, 5px);   // 20
@debug math.div(100px, 5);     // 20px
@debug math.div(100px, 5s);    // calc(20px / 1s)
@debug math.unit(math.div(100px, 5s));  // px/s
@debug math.div(10, 3) * 1px;  // 3.3333333333333335px
@debug math.percentage(0.2);   // 20%
```

第三个与第四个调用展示了单位运算的两种表现：相同单位相消后得到无单位的比值 20；不同单位相除形成复合单位 px/s，该值在 @debug 与 CSS 输出中表示为未求值的 calc 表达式，需要观察单位字符串时用 math.unit 查看。

math.percentage($number) 把无单位小数转为百分比，等价于乘以 100%。反过来把百分比转为小数用 math.div($number, 100%)。

> 半像素与三列均分场景下会出现长小数，Sass 在输出 CSS 时按 10 位有效数字截断，避免产物中出现超长浮点串。



### 距离、指数与对数

```scss
@use "sass:math";

@debug math.hypot(3, 4);            // 5
@debug math.hypot(1in, 10cm, 50px); // 4.095277568269715in
@debug math.pow(10, 2);   // 100
@debug math.pow(5, -2);   // 0.04
@debug math.log(10);      // 2.302585092994046
@debug math.log(10, 10);  // 1
@debug math.sqrt(100);    // 10
```

math.hypot($number...) 返回各参数构成向量的长度，参数单位需互相兼容，结果的单位取第一个参数。math.log($number, $base: null) 省略底数时取自然对数；$number 与 $base 必须无单位，否则报错。

math.sqrt($number) 的参数必须无单位。传入负数时结果是未定义值，输出为 calc(NaN)，但不会中断编译，因此参数需自行校验：

```scss
@use "sass:math";

@function safeSqrt($number) {
  @if $number < 0 {
    @error "开方参数不能为负，收到 #{$number}";
  }
  @return math.sqrt($number);
}
```



### 三角函数

三角函数的参数单位规则分两类：正弦、余弦、正切接受角度或弧度，无单位时按弧度解释；反三角函数返回带 deg 单位的角度，参数必须无单位。

```scss
@use "sass:math";

@debug math.cos(100deg);  // -0.1736481776669303
@debug math.sin(1rad);    // 0.8414709848078965
@debug math.tan(100deg);  // -5.671281819617711
@debug math.acos(0.5);    // 60deg
@debug math.asin(0.5);    // 30deg
@debug math.atan(10);     // 84.28940686250037deg
@debug math.atan2(-1, 1); // -45deg
```

math.atan2($y, $x) 与先算 math.div($y, $x) 再取反正切的结果不同：它保留了点的象限信息，因此上例返回 -45deg 而非 135deg。需要由两轴分量求方向角时使用 atan2。



### 单位判断与换算

```scss
@use "sass:math";

@debug math.is-unitless(100);          // true
@debug math.is-unitless(100px);        // false
@debug math.unit(math.div(5px, 1s));   // px/s
@debug math.compatible(2px, 1px);      // true
@debug math.compatible(100px, 3em);    // false
```

math.compatible($number1, $number2) 判断两数单位能否安全相加减或比较。它是符号计算前的前置检查：来自外部参数的两个数值在相加前先做判断，可在编译期给出明确报错，而不是让产物静默出错。

math.unit($number) 返回单位的字符串表示，仅用于调试，其输出格式不跨版本保证。



### 随机数与使用边界

math.random($limit: null) 省略参数时返回 0 到 1 之间的小数，传入大于等于 1 的整数时返回 1 到该整数之间的整数。

```scss
@use "sass:math";

@debug math.random();       // 例如 0.2821251858
@debug math.random(10);     // 例如 6，1 到 10 之间的整数
```

> [!CAUTION]
> **注意内容**：math.random() 的结果在每次编译时都会变化，用它生成的颜色、间距或动画参数会导致产物不可复现，构建缓存与产物比对全部失效。它只适合玩具项目或一次性素材生成；生产样式中的随机效果应改由 JavaScript 在运行期产生。

模块内其余函数的参数类型约束都以「无单位」为前提，混入带单位的值会直接报错，这是编译期校验而非运行期警告，写库时可直接依赖。
