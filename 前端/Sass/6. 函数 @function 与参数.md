## 函数 @function 与参数

### 定义与返回值

函数用 @function 定义，用 @return 返回一个值，值参与后续的表达式运算或声明输出。

```scss
@use "sass:math";

@function px2rem($px, $base: 16px) {
  @return math.div($px, $base) * 1rem;
}

.title {
  font-size: px2rem(24px);
}
```

```css
.title {
  font-size: 1.5rem;
}
```

函数体内只允许变量声明与控制指令，混入样式声明会直接报错：

```shell
Error: @function rules may not contain declarations.
  ╷
5 │   color: red;
  │   ^^^^^^^^^^
  ╵
  u.scss 5:3  root stylesheet
```

这条限制保证了函数是纯计算：不产出 CSS，只返回值。



### 参数规则

函数的参数规则与混合宏一致，包含三种形式：

- 必需参数：无默认值，调用时必须传入。
- 默认参数：形如 $base: 16px，可省略，可在调用时用关键字乱序传入。
- 可变参数：形如 $nums...，收集多余的位置参数为 arglist。

```scss
@function sum($nums...) {
  $total: 0;
  @each $n in $nums {
    $total: $total + $n;
  }
  @return $total;
}

@debug sum(1, 2, 3);   // 6
```

需要按名取值时，可变参数配合 meta.keywords($args) 取回关键字参数映射：

```scss
@use "sass:meta";

@function describe($args...) {
  $kw: meta.keywords($args);
  @return meta.inspect($kw);
}
```



### 参数校验与 @error

@error 在条件不满足时中断编译并输出指定信息，是给库函数做参数护栏的标准手段。

```scss
@use "sass:math";

@function divide($a, $b) {
  @if $b == 0 {
    @error "除数不能为 0，收到 #{$b}";
  }
  @return math.div($a, $b);
}

@debug divide(10, 2);   // 5
```

```shell
Error: "除数不能为 0，收到 0"
  ╷
5 │ .a { width: divide(10, 0); }
  │      ^^^^^^^^^^^^^^^^^^^^
  ╵
  input.scss 5:6  root stylesheet
```

> [!TIP]
> **建议内容**：@error 的信息里带上实际收到的值，用插值 #{$var} 写入。报错发生在构建期，错误信息就是唯一的排查入口；只写「参数错误」而不写收到的值，会让每次排查都退回源码逐层加日志。



### 函数值：meta.get-function 与 meta.call

函数本身可以作为一个值传递，由 meta.get-function($name, $css: false, $module: null) 取得，再由 meta.call($function, $args...) 调用。

```scss
@use "sass:math";
@use "sass:meta";

$fn: meta.get-function("sqrt", $module: "math");

@debug meta.call($fn, 16);        // 4
@debug meta.call($fn, 25);        // 5
@debug meta.type-of($fn);         // function
```

函数值也能作为参数传给别的函数，实现高阶函数：

```scss
@use "sass:math";
@use "sass:meta";

@function applyTwice($fn, $value) {
  @return meta.call($fn, meta.call($fn, $value));
}

@debug applyTwice(meta.get-function("sqrt", $module: "math"), 256);
// 4
```

上例先对 256 开方得 16，再开方得 4。传纯 CSS 函数名时需把 $css 参数置为真，否则会因找不到 Sass 函数而报错。



### 三种调试输出

Sass 提供三条调试指令，用途严格区分：

- @debug：输出到日志，用于开发期观察中间值，不中断编译。
- @warn：输出警告，用于提示调用方写法即将失效或参数可疑，不中断编译。
- @error：输出错误并中断编译，用于参数非法等硬性失败。

```scss
@debug "调试信息";
@warn "构建警告：变量即将废弃";
```

```shell
input.scss:1 DEBUG: 调试信息
WARNING: 构建警告：变量即将废弃
    input.scss 2:1  root stylesheet
```

> [!NOTE]
> **提醒内容**：@debug 在命令行下输出到标准错误流，因此重定向标准输出为文件时仍能在终端看到；@warn 除位置信息外还会打印调用栈所在的文件与行号，定位来源直接可用。



### 覆盖内置函数与全局函数的取舍

自定义函数可以与非内置函数重名，Sass 会在调用点解析为自定义版本；但这属于隐式覆盖，会破坏可读性，并不推荐。

需要留意的是全局内置函数已进入弃用期。绝大多数旧全局函数都有对应的模块版本，应以模块调用替代：

```scss
@use "sass:math";
@use "sass:list";

// 旧写法（已弃用）
// width: percentage(math.div(1, 3));

// 现写法
@debug math.percentage(math.div(1, 3));   // 33.33333333333333%
@debug list.length(1px 2px 3px);          // 3
```

全局函数自 Dart Sass 1.80.0 起输出 global-builtin 弃用警告，计划在 3.0.0 中移除，具体的迁移对照见迁移与弃用清单篇。
