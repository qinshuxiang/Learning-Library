## 控制指令与循环

### @if 与分支

@if 按条件决定是否展开块内内容，可跟 @else if 与 @else 组成分支链。

```scss
$dark: true;

.box {
  @if $dark {
    color: white;
  } @else if not $dark {
    color: black;
  } @else {
    color: grey;
  }
}
```

```css
.box {
  color: white;
}
```

条件表达式遵循真假值规则：只有 false 与 null 为假，数字 0 与非空判定无关的字符串均为真。比较与逻辑运算符为 ==、!=、<、>、<=、>=、and、or、not。

@if 是编译期分支，不是运行期条件。未命中的分支完全不会进入产物，因此可以用它来包住只在特定配置下需要的整块样式。



### @each 遍历列表与映射

@each 逐个取出列表元素或映射的键值对，是最常用的生成式指令。

```scss
$sizes: (small: 4px, medium: 8px, large: 16px);

@each $name, $size in $sizes {
  .gap-#{$name} { gap: $size; }
}
```

```css
.gap-small {
  gap: 4px;
}

.gap-medium {
  gap: 8px;
}

.gap-large {
  gap: 16px;
}
```

遍历映射时写两个变量接收，前一个是键、后一个是值；遍历列表时写一个变量即可。

```scss
@each $i in 1, 2, 3 {
  .col-#{$i} { width: $i * 10%; }
}
```

映射本身也是列表，其元素是「键 值」构成的二元列表，因此遍历单个变量时会拿到成对的值，用解构赋值更清晰。



### @for 计数循环

@for 按整数区间重复，两种写法差一个端点：through 包含终点，to 不包含终点。

```scss
@for $i from 1 through 3 {
  .through-#{$i} { z-index: $i; }
}

@for $i from 1 to 3 {
  .to-#{$i} { z-index: $i; }
}
```

```css
.through-1 {
  z-index: 1;
}

.through-2 {
  z-index: 2;
}

.through-3 {
  z-index: 3;
}

.to-1 {
  z-index: 1;
}

.to-2 {
  z-index: 2;
}
```

区间递减时写法为 @for $i from 3 through 1，方向由起止值的相对大小决定，不需要额外参数。

> 生成等比或等差数列色阶、间距刻度、栅格列宽时，@for 是首选：它保证产物确定、可预测，且所有取值都在编译期展开，运行期零成本。



### @while

@while 在条件为真时反复执行，需要手动维护计数变量，否则会陷入无限循环。

```scss
$i: 1;

@while $i < 3 {
  .while-#{$i} { order: $i; }
  $i: $i + 1;
}
```

```css
.while-1 {
  order: 1;
}

.while-2 {
  order: 2;
}
```

> [!CAUTION]
> **注意内容**：@while 的终止条件依赖循环体内对变量的修改，一旦遗漏自增或修改方向写反，编译会挂死并持续输出，磁盘被产物写满的情况确有发生。能用 @for 或 @each 表达时不要用 @while，只在迭代次数无法预先计算时才使用。



### 与函数、混合宏配合

控制指令写在函数或混合宏内部即可构成小型算法。下面的函数把数值向下取整到指定步长的整数倍：

```scss
@use "sass:math";

@function floorTo($n, $unit) {
  @return math.floor(math.div($n, $unit)) * $unit;
}

@debug floorTo(37px, 8px);   // 32px
```

下面的混合宏把一组关键字参数直接展开成声明，跳过值为 null 的项：

```scss
@use "sass:meta";

@mixin declarations($args...) {
  @each $name, $value in meta.keywords($args) {
    @if $value != null {
      #{$name}: $value;
    }
  }
}

.card {
  @include declarations($padding: 8px, $margin: null, $border: 1px solid #ddd);
}
```

```css
.card {
  padding: 8px;
  border: 1px solid #ddd;
}
```



### 从数据源生成工具类

把设计刻度集中成一张映射，用一条 @each 派生整套工具类，是控制指令最有价值的用法：刻度只维护一份，类名与取值永远同步。

```scss
@use "sass:math";

$space-scale: 4px;
$space-steps: (0: 0, 1: 1, 2: 2, 3: 4, 4: 6, 5: 8);
$directions: (t: top, r: right, b: bottom, l: left);

@each $step, $factor in $space-steps {
  $value: $space-scale * $factor;

  @each $abbr, $side in $directions {
    .m#{$abbr}-#{$step} { margin-#{$side}: $value; }
    .p#{$abbr}-#{$step} { padding-#{$side}: $value; }
  }
}
```

产物共 48 条规则，覆盖四方向的 margin 与 padding 六个刻度。手工维护这 48 条规则需要上百行，且任何一次刻度调整都要全量修改；用循环后只改 $space-steps 一处。

> [!TIP]
> **建议内容**：生成的数量级需要控制。两层循环相乘容易在不经意间产出上千条规则，让 CSS 体积失控。设定一条上限（例如单个循环产出的规则数不超过 100 条），超出的部分改用 CSS 自定义属性在运行期组合，或交由原子化框架承担。
