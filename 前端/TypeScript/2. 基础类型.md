## 基础类型

### 原始类型

#### 原始类型总览

**原始类型**（primitive type）：是 JavaScript 中非对象、按值传递的基础类型，TypeScript 为它们各提供一个同名类型，共七种：string、number、boolean、null、undefined、symbol、bigint。

TypeScript 的类型名一律小写，下面为每种类型各标注一个变量。

```ts
let userName: string = "Ada";
let userAge: number = 36;
let isActive: boolean = true;
let emptyValue: null = null;
let unsetValue: undefined = undefined;
let idKey: symbol = Symbol("id");
let largeCount: bigint = 10n;
```

> 说明：大写开头的 String、Number、Boolean 是包装对象类型，与对应的原始类型不是一回事，标注时统一用小写形式。

**速记**：七种原始类型用小写类型名标注，null 与 undefined 各只有一个值。



#### string

**string**：是 UTF-16 编码的文本序列，内容由单引号、双引号或反引号包裹。

- 单引号与双引号等价，项目内保持统一。
- 反引号包裹的是模板字符串，支持美元符号加大括号的插值语法。

```ts
const firstName: string = 'Ada';
const greeting: string = `Hi, ${firstName}`;

console.log(greeting);        // "Hi, Ada"
console.log(greeting.length); // 7
```

> 说明：length 统计的是 UTF-16 码元个数，emoji 等代理对字符会被计为 2，按字符计数需用 Array.from 或展开运算符。

**速记**：string 表示文本，三种引号写法中只有模板字符串支持插值。



#### number

**number**：是 IEEE 754 双精度浮点数，整数与小数共用同一类型，绝对值上限约为 1.7976931348623157e308。

- 安全整数范围是 Number.MIN_SAFE_INTEGER 到 Number.MAX_SAFE_INTEGER，即正负 2 的 53 次方减 1。
- 字面量支持十进制、十六进制 0x、八进制 0o、二进制 0b、指数形式与下划线分隔符；特殊值有 NaN、Infinity、-Infinity。

```ts
const price: number = 19.99;
const hexValue: number = 0xff;     // 255
const readable: number = 1_000_000;

console.log(Number.MAX_SAFE_INTEGER); // 9007199254740991
console.log(0.1 + 0.2);               // 0.30000000000000004
```

> 说明：number 无法精确表示所有小数，0.1 加 0.2 不等于 0.3；金额等场景用整数分表示或改用十进制运算库，超出安全整数范围的整数用 bigint。

**速记**：number 同时表示整数与小数，安全整数上限为 Number.MAX_SAFE_INTEGER。



#### boolean

**boolean**：是只有 true 与 false 两个字面量值的真值类型。

- 比较表达式与逻辑表达式的推断结果通常是 boolean。
- 0、空字符串、null 等在条件中会被当作 false，但它们的类型不是 boolean。

```ts
const isEnabled: boolean = false;
const isEmpty = (text: string): boolean => text.length === 0;

console.log(isEmpty("")); // true
// const wrongFlag: boolean = 0; // 报错：number 不能赋给 boolean
```

> 说明：把 number 或 string 传给 boolean 参数会报错，转布尔要显式写 Boolean(value) 或写成比较表达式。

**速记**：boolean 只有 true 与 false，条件中的假值转换不改变其类型。



#### null 与 undefined

**null**：表示有意设置的"空"值。**undefined**：表示变量已声明但尚未赋值。

- 默认配置下两者可赋给任意类型，容易掩盖空值错误。
- 开启 strictNullChecks 后，二者只能赋给自身类型，以及 any、unknown、void。

```ts
let middleName: null = null;

// strictNullChecks 关闭时以下不报错，开启后报错
// let fullName: string = null; // 报错：null 不能赋给 string

// 需要"有值或为空"时显式声明，联合类型详见本主题第 5 篇
let backupName: string | null = null;

console.log(backupName); // null
```

> [!IMPORTANT]
> **重要内容**：strictNullChecks 是 tsconfig 中 strict 家族的核心开关，关闭时 null 与 undefined 会静默赋给任意类型，把空值问题推迟到运行时；新项目应始终开启。

**速记**：null 是有意置空、undefined 是尚未赋值，strictNullChecks 开启后两者必须显式声明。



#### symbol 与 bigint

**symbol**：是每次创建都独一无二、不可变的原始值，常用作对象属性键以避免命名冲突。**bigint**：是任意精度的整数类型，数值范围只受内存限制。

- Symbol 加描述字符串创建，相同描述也互不相等；作为属性键时不会被 Object.keys、Object.entries、for...in 枚举。
- bigint 字面量以 n 结尾，也可用 BigInt 函数转换；不能与 number 混合运算，除法结果向零截断。

```ts
console.log(Symbol("userId") === Symbol("userId")); // false

const session = { [Symbol("userId")]: "user-1" };
console.log(Object.keys(session)); // []

console.log(9007199254740991n + 2n); // 9007199254740993n
// console.log(1n + 1);              // 报错：bigint 与 number 不能混合运算
```

> 说明：bigint 与 number 之间需要显式转换，大整数转 number 会丢精度，小数转 bigint 会抛错。

**速记**：symbol 每次创建都唯一且不被常规枚举读取，bigint 以 n 结尾且不与 number 混合运算。



### 特殊类型

#### any 的代价

**any**：是关闭类型检查的逃逸类型，任何值都能赋给它，它也能赋给任何类型，在其上访问任意属性、调用任意方法都不会报错。

- 编译期检查被跳过，错误推迟到运行时才暴露。
- 编辑器补全与重构失效，且 any 会沿赋值与传参扩散。
- 未标注参数类型时默认推断为 any，开启 noImplicitAny 后直接报错。

```ts
const payload: any = JSON.parse('{"id": 1}');

console.log(payload.profile.name); // 编译通过，运行时抛错
const wrongId: number = payload;   // 编译通过，实际可能不是数字
```

> [!CAUTION]
> **注意内容**：any 的代价不在写下它的那一刻，而在它传播出去之后——调用方以为拿到了确定的类型，错误却全部推迟到运行时。

**速记**：any 关闭该位置的类型检查并会向外扩散，只在迁移旧代码等不得已场景使用。



#### unknown 与 any 的区别

**unknown**：是 any 的类型安全版本，任何值都能赋给它，但在确认类型之前不能把它赋给具体类型，也不能访问其属性或调用其方法。

- 赋值方向：两者都能接收任意值；any 可赋给任何类型，unknown 只能赋给 unknown 或 any。
- 使用方式：any 上任意操作一律放行，unknown 必须先做类型检查。

```ts
function parseJson(text: string): unknown {
  return JSON.parse(text);
}
const data = parseJson('{"id": 1}');
// console.log(data.id); // 报错：unknown 上不能直接访问属性
function readName(value: unknown): string {
  if (typeof value === "string") return value; // 收窄详见本主题第 8 篇
  return String(value);
}
```

> 说明：any 表示"放弃检查"，unknown 表示"暂时未知、等待确认"；网络响应、JSON、第三方回调参数等外部数据先用 unknown 接住，验证后再使用。

**速记**：unknown 与 any 都能接收任意值，区别在于 unknown 使用前必须确认类型。



#### never 的语义与出现场景

**never**：是"永不存在的值"的类型，没有任何值属于它，处在类型层级的底部。

- never 可以赋给任何类型；除 any 外，任何类型都不能赋给 never。
- 它描述"这里不会正常产生值"，而不是"值恰好为空"。

出现场景有三类：函数必定抛错、函数体是永无止境的循环、所有分支穷尽后剩下的兜底分支。

```ts
function fail(message: string): never {
  throw new Error(message);
}
function repeatForever(): never {
  while (true) {} // 永不返回，需要外部中断
}
```

> 说明：never 在实际项目中最常见的用途是穷尽检查，当某处类型被收窄为 never，说明所有分支都已覆盖，细节详见本主题第 8 篇。

**速记**：never 表示永不存在的值，常见于抛错函数、死循环与穷尽检查兜底。



#### void 与 undefined

**void**：表示函数没有可用的返回值。**undefined**：是一个具体的值，表示尚未赋值。

- 返回 void 的函数可以不写 return，也可以写不带值的 return。
- 严格模式下类型为 void 的变量只能赋 undefined。
- void 与返回类型为 undefined 不同：前者是"不关心"，后者是"确实返回 undefined"。

```ts
function logMessage(message: string): void {
  console.log(message);
}
function runTask(callback: () => void): void {
  callback();
}
runTask(() => 42);  // 允许：返回值被忽略
logMessage("done"); // "done"
```

> 说明：返回类型为 void 的函数用作回调参数时，实现方可以返回任意值；写成 undefined 则实现方必须明确返回 undefined，约束更强。

**速记**：void 表示不关心返回值，undefined 是具体值，回调形参的返回类型通常用 void。



#### object 与 Object 与 {} 的辨析

**object**：任何非原始类型值，包括对象、数组、函数、日期。**Object**：包装对象类型，除 null 与 undefined 外几乎任何值都能赋给它。**{}**：空对象字面量类型，表示"没有已知属性"，原始类型也满足它。

- 三者约束力由强到弱依次是 object、{}、Object。
- 需要"任意对象"时用 object，需要具体结构时直接写对象字面量类型。

```ts
let config: object = { timeout: 3000 };
config = [1, 2, 3]; // 允许：数组也属于 object

// let badConfig: object = "text"; // 报错：string 是原始类型

let looseValue: {} = "text"; // 允许：{} 不拒绝原始类型
let boxedValue: Object = 42; // 允许：Object 不拒绝原始类型
```

> 说明：Object 与 {} 几乎不表达有效约束，除兼容旧代码外应避免，日常用 object 或直接写出具体结构。

**速记**：object 只接受非原始类型，Object 与 {} 几乎不设限，日常用 object 或具体结构。



### 对象、数组与函数的初步写法

#### 对象字面量类型

**对象字面量类型**：是直接在大括号内逐条写出属性名与属性类型来描述对象结构的写法，属性之间用分号或逗号分隔。

- 每条属性写成"属性名 冒号 类型"，属性顺序不影响类型兼容性。
- 适合内联使用；需要命名或复用时改用 interface 或 type，详见本主题第 4 篇。

```ts
const userProfile: { name: string; age: number } = { name: "Ada", age: 36 };
function describeProfile(profile: { name: string; age: number }): string {
  return `${profile.name} is ${profile.age}`;
}
console.log(describeProfile(userProfile)); // "Ada is 36"
```

> 说明：同一结构在多处重复时不要反复内联书写，抽成 interface 或类型别名可保证各处完全一致。

**速记**：对象字面量类型在大括号内逐条声明属性名与类型，适合一次性描述结构。



#### 数组的两种写法

数组类型有两种等价写法：元素类型后加一对方括号，或使用 Array 加尖括号的写法。

```ts
const names: string[] = ["Ada", "Grace"];
const scores: Array<number> = [90, 85];

const flags: boolean[] = [true, false];
const flagList: Array<boolean> = [true, false]; // 与上一行类型相同

console.log(names[0]);      // "Ada"
console.log(scores.length); // 2
```

> 说明：元素类型简单时用方括号写法更短；元素类型本身含联合、函数签名等内容时，Array 写法嵌套更少、更易读。尖括号是泛型语法的应用，详见本主题第 9 篇；数组与元组的完整内容归第 6 篇。

**速记**：数组类型有元素类型加方括号、Array 加尖括号两种等价写法，简单元素优先前者。



#### 函数参数与返回值标注

函数的标注分两处：参数写在参数名后加冒号与类型，返回值写在参数列表的右括号之后、函数体之前。

- 漏标且无默认值的参数退化为 any，开启 noImplicitAny 会报错。
- 不标注返回类型时由编译器推断，推断规则详见本主题第 3 篇。
- 箭头函数直接返回对象字面量时要用圆括号包裹，否则大括号被当作函数体。

```ts
function sumValues(left: number, right: number): number {
  return left + right;
}
const isEven = (value: number): boolean => value % 2 === 0;
const makePoint = (x: number, y: number): { x: number; y: number } => ({ x, y });

console.log(sumValues(2, 3)); // 5
```

> 说明：对外导出的函数建议显式写返回类型，函数体改动时不会无声改变调用方看到的类型。

**速记**：参数在参数名后标注，返回值在参数列表后标注，箭头函数返回对象需加圆括号。



### 类型注解的书写形式

#### 注解的基本语法

**类型注解**（type annotation）：是在标识符后用冒号加类型名、明确声明该位置允许哪些值的写法，冒号后留一个空格。

- 变量与常量：变量名后加冒号与类型。
- 参数与返回值：参数名后、参数列表右括号后各加冒号与类型。
- 属性：属性名后加冒号与类型，用于描述对象结构。

```ts
let visitCount: number = 0;
const siteName: string = "TypeScript";
function formatTag(name: string): string {
  return "#" + name;
}
const tagList: string[] = [formatTag(siteName)];

console.log(tagList); // ["#TypeScript"]
```

> 说明：注解写在被约束的标识符之后，中间只隔一个冒号，不写等号也不写箭头。

**速记**：类型注解统一写成标识符加冒号加类型，出现在变量、参数、返回值与属性四个位置。



#### 类型出现的位置

除变量与函数，类型标注还出现在多个位置，位置不同写法略有差异。

- 对象字面量与数组元素的形状。
- 类成员：属性、方法参数与方法返回值，详见本主题第 14 篇。
- 类型别名与接口声明（第 4 篇）、泛型参数（第 9 篇）、类型断言（第 3 篇）。

```ts
function getLabel(labels: string[], index: number): string {
  return labels[index];
}
const labelRow: { text: string; index: number } = { text: "ts", index: 0 };

console.log(getLabel(["js", "ts"], 1)); // "ts"
```

> 说明：位置决定括号与分隔符的写法，核心规则不变——在需要约束的标识符后加冒号与类型。

**速记**：类型可标注在变量、参数、返回值、对象元素与类成员等位置，跨篇细节按对应篇目查阅。



#### 何时可以省略注解

多数位置可以省略注解、交给类型推断，前提是该位置有初始值或实现体提供信息。

- 变量有初始值时通常省略，函数返回值有明确的 return 时通常省略。
- 参数有默认值时通常省略；无默认值的参数必须标注，否则是隐式 any。
- 对外契约、公共 API 与复杂表达式的中间结果建议显式标注，避免推断结果与预期不符。

```ts
const timeout = 3000;                             // 推断为 number
const labels = ["js", "ts"];                      // 推断为 string[]
const doubleValue = (value: number) => value * 2; // 返回值推断为 number

console.log(doubleValue(3)); // 6
```

> 说明：省略注解的前提是初始值或实现体能提供足够信息，推断规则与上下文类型详见本主题第 3 篇。

**速记**：有初始值或实现体时可省略注解，对外契约与无默认值的参数应显式标注。



#### 常见书写错误

- 用大写 String、Number、Boolean 标注，得到包装对象类型而非原始类型。
- 参数漏标注且无默认值，在 noImplicitAny 下报错。
- 注解与初始化值冲突，例如标注 string 却赋数字。

```ts
const userName: string = "Ada";
// const badName: String = "Ada"; // 不推荐：String 是包装对象类型
// const badCount: number = "3";  // 报错：string 不能赋给 number

console.log(userName.length); // 3
```

> [!TIP]
> **建议内容**：开启 noImplicitAny 与 strictNullChecks，或直接开启 strict，让漏标注与空值错误在编译期就暴露出来。

**速记**：统一用小写原始类型名，避免漏标注与初始值冲突，开启 strict 让错误提前暴露。
