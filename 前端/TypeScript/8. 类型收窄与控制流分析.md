## 类型收窄与控制流分析

### 基本收窄形式

**类型收窄（narrowing）**：是编译器依据运行期的判断语句，把变量在其后代码路径上的类型由宽变窄的过程；**控制流分析（control flow analysis）**：是沿每条分支追踪变量可能类型的算法，收窄是它的输出。

#### typeof 判断与 instanceof 判断

typeof 运算符返回类型字符串，与字面量比较后收窄原始类型；instanceof 运算符沿原型链检测实例关系，右侧为构造函数时收窄为该构造函数的实例类型。

```ts
function format(value: string | number): string {
  if (typeof value === "string") return value.toUpperCase(); // value: string
  return value.toFixed(2); // value: number
}
class HttpError extends Error {}
function describeError(error: Error): string {
  if (error instanceof HttpError) return "HTTP 错误"; // error: HttpError
  return "其他错误"; // error: Error
}
console.log(format("ts"), describeError(new HttpError("404"))); // "TS" "HTTP 错误"
```

- typeof 可返回 "string"、"number"、"boolean"、"bigint"、"symbol"、"undefined"、"object"、"function"；typeof null 是 "object"，判 null 须用相等判断。
- instanceof 只认原型链，跨 iframe 或跨模块的实例会误判。

**速记**：typeof 判原始类型，instanceof 判构造函数实例。



#### in 运算符与真值判断

in 运算符判断属性是否可能存在于对象上，用于区分属性集合不同的对象联合；真值判断把变量直接放进条件位置，编译器剔除所有可能为假的成员。

```ts
type Cat = { meow: () => void };
type Dog = { bark: () => void };
function speak(pet: Cat | Dog): void {
  if ("meow" in pet) pet.meow(); // pet: Cat
  else pet.bark(); // pet: Dog
}
function printLength(input: string | null | undefined): number {
  if (input) return input.length; // input: string
  return 0;
}
console.log(printLength("ts"), printLength(null)); // 2 0
```

- in 的判定依据是属性名是否被任一成员声明；可选属性用 in 判断只得到存在性，取值前还需判空。
- 真值判断剔除的假值有 false、0、""、NaN、null、undefined，0 或 "" 属于合法输入时会被误伤。

**速记**：in 按属性存在性切开联合，真值判断剔除全部假值。



#### 相等判断与字面量比较

相等判断在比较 null、undefined 时触发收窄，比较双方类型相同时两边一起收窄；字面量比较用于字面量类型联合。

```ts
function greet(name?: string): void {
  if (name !== undefined) console.log(name.toUpperCase()); // "ANN"，name: string
}

type TrafficLight = "red" | "yellow" | "green";
function nextLight(light: TrafficLight): TrafficLight {
  if (light === "red") return "green";
  if (light === "yellow") return "red";
  return "yellow"; // light: "green"
}
```

- != null 同时匹配 null 与 undefined，是排除空值的简写；不用 == 比较不同类型的值，宽松相等引入隐式转换，收窄结果难以预期。

**速记**：!== undefined 与 != null 是最常用的空值收窄。



### 可辨识联合的收窄

可辨识联合（discriminated union）的定义见本主题第 5 篇，本节只讨论收窄手法：每个成员都带同一个字面量类型的判别属性，对它的判断能让编译器精确定位当前成员。

#### 判别属性的用法

判别属性：是各联合成员共有、名字相同、类型为互不重叠字面量的属性，对它的比较会收窄整个对象。

```ts
type Circle = { kind: "circle"; radius: number };
type Square = { kind: "square"; side: number };
type Shape = Circle | Square;
function area(shape: Shape): number {
  if (shape.kind === "circle") return Math.PI * shape.radius ** 2; // shape: Circle
  return shape.side ** 2; // shape: Square
}
console.log(area({ kind: "square", side: 3 })); // 9
```

- 判别属性的值必须是字面量类型，写成 string 会失去区分能力；索引访问 shape["kind"] 与点访问等价，收窄同样作用于整个对象。

**速记**：判别属性是互不重叠的字面量类型属性，比较它即收窄整个对象。



#### switch 分支收窄

switch 以判别属性为条件时，每个 case 分支内部自动收窄到对应成员。

```ts
function toText(shape: Shape): string {
  switch (shape.kind) {
    case "circle":
      return `圆 r=${shape.radius}`; // shape: Circle
    case "square":
      return `方 a=${shape.side}`; // shape: Square
  }
}
console.log(toText({ kind: "circle", radius: 2 })); // "圆 r=2"
```

- 全部成员都有对应 case 时 switch 被视为穷尽，末尾无需兜底 return；case 可用逗号合并多个字面量。
- 少写 break 会贯穿，贯穿后的类型通常是 never。

**速记**：switch 按 case 字面量逐支收窄，成员全覆盖时即为穷尽。



#### if 链与嵌套结构的收窄

if 链把多个判断按顺序串联，每个后续判断都建立在前面的收窄结果之上；判别属性位于嵌套层级时，收窄沿属性访问路径逐层进行。

```ts
type LoadEvent = { type: "load"; payload: { url: string } };
type FailureEvent = { type: "failure"; payload: { code: number } };
type AppEvent = LoadEvent | FailureEvent;

function label(shape: Shape): string {
  const isBigCircle = shape.kind === "circle" && shape.radius > 10; // 别名条件
  if (isBigCircle) return "大圆";
  if (shape.kind === "square" && shape.side > 10) return "大方";
  return "小图形";
}

function handle(event: AppEvent): string {
  if (event.type === "failure" && event.payload.code === 404) return "未找到";
  return event.type === "load" ? event.payload.url : "其他错误";
}
console.log(label({ kind: "square", side: 3 })); // "小图形"
```

- && 右侧的属性访问已被左侧收窄，两侧须写在同一分支内；别名条件存入 const 变量后仍能收窄。
- 属性位置上再出现联合时要连判两层，例如 status === "ok" && data.kind === "text" 之后才能读 data.text；多层判断须在同一表达式中串接。
- 用 || 连接时收窄为两侧结果之并，不能访问任一侧的独有属性。

**速记**：if 链逐层收窄，嵌套判别沿路径逐层收窄，条件须在同一表达式中串接。



### 类型谓词与断言函数

把复用性强的判断写进自定义函数会丢失收窄，类型谓词与断言函数用来把收窄能力随判断一起封装。

#### 自定义类型谓词的写法

**类型谓词（type predicate）**：是写在函数返回类型位置的 参数名 is 类型 标注，声明当该函数返回 true 时实参属于该类型。

```ts
function isString(value: unknown): value is string {
  return typeof value === "string";
}
function joinText(input: unknown): string {
  if (isString(input)) return input.toUpperCase(); // input: string
  return "";
}
console.log(joinText("ts")); // "TS"
```

- 谓词中的参数必须是该函数自己的参数名，返回类型必须是 boolean 的兼容形式；普通返回 boolean 的函数不具备收窄能力。

> [!IMPORTANT]
> **重要内容**：谓词的判定逻辑完全由作者负责，编译器不会核对。谓词体写错时收窄结果与运行期事实不符，且没有任何编译期提示。

**速记**：x is T 声明返回 true 时实参为 T，编译器据此收窄调用处。



#### 断言函数

**断言函数（assertion function）**：是返回类型标注为 asserts 参数名 is 类型 的函数；调用后若未抛出异常，编译器即在后续代码中收窄该实参。

```ts
function assertDefined<T>(value: T | undefined): asserts value is T {
  if (value === undefined) throw new Error("值未定义");
}
function firstChar(value: string | undefined): string {
  assertDefined(value);
  return value.charAt(0); // value: string
}
console.log(firstChar("ts")); // "t"
```

- 必须带显式返回类型标注：函数声明可直接写，箭头函数须先给变量标注函数类型再赋值。
- 断言的实参必须是标识符或属性访问这类可引用表达式，传入函数调用结果会报错；写成 asserts value（不带 is）表示断言该值为真值。

**速记**：asserts x is T 通过检查后收窄，失败路径靠 throw 终止。



#### 与 as 断言的本质差别

as 断言是纯编译期声明，类型谓词与断言函数带运行期判断，两者的收窄范围与安全性都不同。

```ts
function getLength(value: unknown): number {
  if (isString(value)) return value.length; // 运行期真的检查过，收窄可信
  const forced = value as string;
  return forced.length; // 编译期放行，运行期非字符串时得到 undefined
}
console.log(getLength({})); // undefined
```

- as 不做任何运行期检查且只作用于该表达式；谓词与断言函数会真正执行判断并收窄整条后续路径。
- 把断言类型放宽会主动丢弃已有收窄：已在 string 分支内写 as string | number，该表达式退回联合。

> [!WARNING]
> **警告内容**：as 断言跳过全部检查，与实际运行期值不符时错误会推迟到运行期暴露。能用类型谓词表达的判断，不要用 as 代替。

**速记**：as 是编译期声明且范围仅限当次表达式，谓词与断言函数带运行期判断。



#### 把收窄逻辑封装成可复用函数

把可复用的判断写成谓词函数，既保留收窄，又能直接传给 filter、find 等方法。

```ts
type User = { id: number; name: string };
type Guest = { sessionId: string };
function isUser(actor: User | Guest | null): actor is User {
  return actor !== null && "id" in actor;
}
const actors: (User | Guest | null)[] = [{ id: 1, name: "ann" }, null];
console.log(actors.filter(isUser).map((user) => user.name)); // ["ann"]
```

- 谓词命名以 is、has、can 开头，读起来就是一句判断；filter 与 find 传入谓词后返回值元素类型被收窄。
- 泛型谓词 isDefined 可复用于任意可空类型，是判空逻辑的标准封装形式。

**速记**：判断写成 is 开头的谓词即可复用，还能让 filter、find 的返回值收窄。



### 控制流分析与穷尽检查

控制流分析不只依赖条件语句，还会追踪赋值、终止语句与属性存在性，在此之上可以做穷尽检查。

#### 赋值后的收窄

变量声明处的类型是声明类型，赋值后编译器把该路径上的当前类型收窄为所赋值的类型。

```ts
function pick(flag: boolean): string | number {
  let result: string | number = "default";
  if (flag) {
    result = 0; // 赋值后 result: number
    return result.toFixed(1);
  }
  return result; // 未赋值分支 result: string
}
console.log(pick(true), pick(false)); // "0.0" "default"
```

- 收窄以当前代码路径为单位，同一函数的不同分支可以有不同收窄结果。
- 声明时不写注解直接赋值，变量被推断为初始化值的类型；在循环体或回调中重新赋值会把收窄重置回声明类型。

**速记**：赋值把当前路径的类型收窄为所赋值的类型，各分支相互独立。



#### never 与 switch 的 default 兜底

**never** 是不含任何值的底类型；把已排除全部成员后的变量交给 never 参数，可以让遗漏成员变成编译错误。

```ts
function assertNever(value: never): never {
  throw new Error("未处理的分支");
}
function toIcon(shape: Shape): string {
  switch (shape.kind) {
    case "circle":
      return "circle";
    case "square":
      return "square";
    default: {
      const exhaustive: never = shape; // 漏 case 时此处报错
      return assertNever(exhaustive);
    }
  }
}
console.log(toIcon({ kind: "square", side: 1 })); // "square"
```

- 全部成员被 case 覆盖时 default 里的 shape 类型为 never；新增成员而未补分支时不再是 never，立即报错。
- 不写「其他情况都当作某值」的笼统兜底，它把遗漏成员吞掉，穷尽检查形同虚设；default 内声明变量用花括号包成块，避免与其它 case 的变量名冲突。

**速记**：default 里用 assertNever 或 never 赋值兜底，遗漏成员即编译报错。



#### return 与 throw 对后续分支的影响

return 与 throw 会终止当前分支，控制流分析据此让后续代码只在剩余类型上分析。

```ts
function describeShape(shape: Shape): string {
  if (shape.kind === "circle") return `圆：${shape.radius}`; // 分支在此终止
  return `方：${shape.side}`; // 到这里 shape: Square
}
function ensurePositive(value: number): number {
  if (value <= 0) throw new RangeError("必须为正数");
  return value;
}
console.log(describeShape({ kind: "square", side: 3 }), ensurePositive(2)); // "方：3" 2
```

- 分支内的 return、throw、continue、break 都会终止该分支，终止后不再参与后续收窄。
- 提前 return 的卫语句能把收窄条件写在前面；普通数值判断不会改变变量的类型。

**速记**：return 与 throw 终止分支，后续代码只在剩余类型上分析，卫语句可替代嵌套。



#### 可选属性的收窄

可选属性在类型上等价于该属性类型并上 undefined，判空后即可收窄为确定类型。

```ts
type Config = { host: string; port?: number };
function endpoint(config: Config): string {
  if (config.port !== undefined) return `${config.host}:${config.port}`; // port: number
  return `${config.host}:80`;
}
console.log(endpoint({ host: "localhost", port: 8080 })); // "localhost:8080"
```

- 可选属性判定用 !== undefined；属性类型显式含 null 时还要再判一次 null。
- 可选链与空值合并可做表达式级收窄：config.port ?? 80 直接得到 number。

**速记**：可选属性等价于并上 undefined，判 undefined 或用 ?? 兜底即可收窄。



### 收窄失效的常见情形

收窄结果依赖编译器对代码路径的判断，一旦路径超出可分析范围，收窄就退回声明类型。

#### 回调与闭包中的收窄丢失

变量在收窄之后仍有赋值时，编译器无法保证回调或闭包执行时变量仍是该类型，函数边界内的收窄因此被取消。

```ts
function loadUser(): void {
  let userId: string | undefined = "u1";
  if (userId !== undefined) {
    // [1].forEach(() => console.log(userId.length)); // 报错：userId 可能为 undefined
    const safeId = userId; // const 快照固定已收窄的类型
    const read = () => safeId.length; // 闭包捕获常量，收窄保持
    userId = undefined; // 这次赋值让回调与闭包内的收窄失效
    console.log(read()); // 2
  }
}
```

- 根因是编译器不跟踪回调与闭包的实际调用时机，无法跨函数边界保证类型不变。
- 规避做法是在收窄分支内把值赋给 const 局部变量；函数参数若从未被重新赋值，收窄不会跨边界丢失。

**速记**：收窄后仍被赋值的变量，其回调与闭包内收窄失效，用 const 快照解决。



#### 对象属性反复读取的收窄失效

属性收窄绑定在具体访问路径上，路径被赋值即失效；赋值之外编译器对属性收窄偏宽松，可能与运行期不符。

```ts
function resetBox(): void {
  const box: { value: string | null } = { value: "ts" };
  if (box.value !== null) {
    const snapshot: string = box.value; // 先取出快照
    box.value = null; // 给该属性赋值，收窄失效
    console.log(snapshot.length); // 2
    // console.log(box.value.length); // 报错：box.value 可能为 null
  }
}
```

- 一旦在可见范围内给属性或对象绑定赋值，该属性的收窄立即重置为声明类型。
- 调用外部函数不会重置属性收窄，编译器假定被调函数不改动该属性；若它真的改了，错误会推迟到运行期。

**速记**：属性被赋值时收窄失效，函数调用却不会失效，跨调用请自行快照。



#### 解构后的收窄

解构会创建新绑定，收窄不会在源对象与新变量之间互相传递。

```ts
function printName(user: { name: string | null }): string {
  const { name } = user;
  if (user.name !== null) {
    // return name.toUpperCase(); // 报错：name 可能为 null
    return user.name.toUpperCase(); // 收窄只作用于被检查的那条路径
  }
  return "";
}
console.log(printName({ name: "ann" })); // "ANN"
```

- 检查源属性不会收窄解构出的变量，检查解构变量也不会收窄源属性，二者是两条独立路径。
- 正确顺序是先判断、后解构：在 user.name !== null 的分支内再 const { name } = user，此时 name 为 string；解构出的判别属性仍能收窄源对象。

**速记**：解构副本与源属性互不共享收窄，正确顺序是先判断、后解构。



#### as 断言打断收窄

as 断言会覆盖编译器已推断的类型，断言为更宽的类型时已有收窄被主动丢弃。

```ts
function pickLength(value: string | number): number {
  if (typeof value === "string") {
    const loose = value as string | number;
    // console.log(loose.toUpperCase()); // 报错：number 上不存在 toUpperCase
    const anyValue = value as any;
    return anyValue.toFixed(2); // 骗过检查，运行期 value 为字符串时会抛错
  }
  return value;
}
console.log(pickLength(2)); // 2
```

- as 的断言结果只在该表达式内生效，赋给变量后变量即为断言出的类型；as any 让后续所有访问跳过检查。
- 双重断言 as unknown as T 可跨越不相关类型，风险更高；需要按运行期事实收窄时应改用类型谓词或断言函数。

**速记**：as 覆盖已推断类型即丢弃收窄，as any 与双重断言风险最高。
