# AGENTS.md

## 使用原则

**动手前先出方案**：任何会写入文件或执行命令的操作，先给出方案（改哪些文件、怎么改），等我明确确认后再动手，未确认前只读不写。

**更新维护**：除非用户明确要求更新规则，否则你不得修改 AGENTS.md 等文件。每次任务结束时，仅当规则满足“可复用、跨任务、非显而易见、已验证、未被现有规则覆盖”时，才在回复末尾输出“规则候选”，最多 3 条，按价值排序。每条格式为：目标文件/章节、操作（新增/修改/删除）、建议文本、理由/证据、适用范围、不适用场景、与现有规则关系（无/重复/冲突/扩展）。若只是临时偏好、一次性需求、已有规则或无法验证，不要建议。无候选则省略。

**知乎 MCP**：用户要求或问题可能涉及中文社区经验/观点/热榜/问答时，优先调用知乎数据开放平台 MCP；调用前确认工具可用，精准查询、限制条数。回答标注来源（标题、作者、链接/时间），区分观点与事实，不得编造或大段复制。不可用/无结果时说明并回退普通搜索。纯稳定知识不用。



## 加载顺序

1. **身份背景.md（必读）**
2. **协作偏好.md（必读）**
3. **按任务选读，可多选**：
   - 写代码／搭工程 → **编程规范.md**
   - 写文档／写长文 → **文档规范.md**
