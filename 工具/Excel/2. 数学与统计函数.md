## 数学与统计函数

### 基础统计

#### SUM 与求和家族

**SUM(number1, [number2], ...)**：对参数中的数字求和，参数可以是单元格、区域或多个区域的联合。

- 参数数量上限 255 个；文本与空单元格**自动忽略**，逻辑值忽略。
- 加号与 SUM 的分工：零散几个单元格相加用 +，成片区域求和一律 SUM。
- 自动求和：选中区域下方或右侧空单元格，按 **Alt 加 =** 自动生成 SUM。

```text
=SUM(B2:B31)                  单区域求和
=SUM(B2:B10, D2:D10)          两个区域联合求和
=SUM(台账[金额])              结构化引用：整列金额
```

> [!NOTE]
> **提醒内容**：SUM 会**忽略文本型数字**：从系统导出的金额若是文本格式（单元格左上角带绿色小三角），SUM 结果恒为 0。先用“分列”功能或 VALUE 函数把文本转成数值再求和。



#### AVERAGE 与 MAX、MIN

- **AVERAGE(number1, [number2], ...)**：算术平均，同样忽略文本与空单元格。
- **MAX(number1, [number2], ...)**：最大值；**MIN**：最小值。
- 三者对**空单元格与零值的处理不同**：空单元格不参与平均，但 0 参与——这是平均值失真的头号原因。

```text
=AVERAGE(B2:B31)              平均值（0 计入，空白不计入）
=MAX(C2:C100)                 最高值
=MIN(C2:C100)                 最低值
=AVERAGEIF(B2:B31, "已办结", C2:C31)   按条件求平均
```

> 统计案件办理天数、值班加班时长这类数据时，**未填写留空与实际为 0 语义不同**：留空的记录会拉低不了也不抬高平均值，而填 0 会把平均值往下拽。做表时先统一空值口径再统计。



#### COUNT 计数家族

- **COUNT(value1, [value2], ...)**：数**数值**个数。
- **COUNTA(value1, [value2], ...)**：数**非空**单元格个数（文本也算）。
- **COUNTBLANK(range)**：数空白单元格个数。
- **COUNTIF(range, criteria)**：按单一条件计数；**COUNTIFS(criteria_range1, criteria1, ...)**：多条件计数。

```text
=COUNT(B2:B31)                        有数值的行数
=COUNTA(A2:A31)                       已登记的总行数
=COUNTBLANK(C2:C31)                   还有多少没填
=COUNTIF(D2:D31, "在办")              在办件数
=COUNTIFS(D2:D31, "在办", E2:E31, ">2026-1-1")   双条件：在办且日期以后
```

> [!IMPORTANT]
> **重要内容**：COUNTIF 的条件参数是**文本表达式**：大于比较要写成 “&gt;60” 整体加引号，日期写成 “&gt;”&DATE(2026,1,1) 这类拼接形式。条件里写单元格引用时必须用 & 拼接——“&gt;”&F2，直接写 “&gt;F2” 会被当成文本而恒为 0。



### 条件求和

#### SUMIF 与 SUMIFS

- **SUMIF(range, criteria, [sum_range])**：对满足条件的对应单元格求和；range 是条件区域，sum_range 是求和区域，两者**行数必须对齐**。
- **SUMIFS(sum_range, criteria_range1, criteria1, ...)**：多条件求和；注意**求和区域在第一个参数**，与 SUMIF 相反。

```text
=SUMIF(D2:D31, "办结", C2:C31)              办结案件的金额合计
=SUMIFS(C2:C31, D2:D31, "办结", B2:B31, "治安")   类型为治安且办结的金额
```

- 条件支持**通配符**：* 代表任意多个字符，? 代表单个字符，如 “张*” 匹配所有姓张的。
- 多条件之间是**与关系**：SUMIFS 的各条件必须同时满足；需要“或”逻辑时用多个 SUMIF 相加。
- 通配符只对**文本条件**有效，数值条件不生效。

```text
=COUNTIF(A2:A31, "张*")              姓张的人数
=SUMIF(A2:A31, "*酒驾*", C2:C31)     事由含"酒驾"的金额
```

> [!WARNING]
> **警告内容**：SUMIF 与 SUMIFS 的**参数顺序不同**：SUMIF 求和区域在第三位，SUMIFS 求和区域在第一位。混用是最常见的报错来源——SUMIFS 报“参数太多”或结果恒 0 时，先检查是不是把求和列写在了条件区之前。



#### RANK 排名与 SUBTOTAL 小计

- **RANK(number, ref, [order])**：返回某值在一组数值中的名次；order 为 0 或省略是降序（最大值第 1 名），1 是升序。
- **SUBTOTAL(function_num, ref1, ...)**：对可见单元格做统计，配合筛选使用；function_num 用 101 至 111 时**忽略手工隐藏的行**。

```text
=RANK(C2, $C$2:$C$31)                  降序排名（第一名是最大值）
=SUBTOTAL(9, C2:C31)                   筛选后求和：只算筛出来的行
=SUBTOTAL(109, C2:C31)                 筛选与手工隐藏行都不算
```

- SUBTOTAL 常用编号：9 求和、1 平均、2 计数、3 计非空、4 最大、5 最小；再加 100 即忽略隐藏行版本（109、101、102、103）。
- RANK 的 ref 必须**加 $ 固定**：排名公式向下填充时排名区域不能跟着动，否则每行的“全体”都不一样。

> [!TIP]
> **建议内容**：给台账做“汇总行”时一律用 **SUBTOTAL(9, ...)** 而不是 SUM：它天然跟随筛选结果变化，筛选到某个辖区时小计自动只算当前辖区；配合表格的“汇总行”功能（表格工具里勾选）会自动生成 SUBTOTAL。



### 数值处理

#### 四舍五入与取整

- **ROUND(number, num_digits)**：四舍五入；num_digits 为小数位位数，负数表示向左数（-2 即保留到百位）。
- **ROUNDUP / ROUNDDOWN**：向上、向下舍入，不受四舍五入规则约束。
- **INT(number)**：向下取整到整数；**TRUNC(number, [num_digits])**：直接截断。
- **MOD(number, divisor)**：求余数；**QUOTIENT(numerator, denominator)**：取商的整数部分。

```text
=ROUND(B2, 2)            保留两位小数（金额标准格式）
=ROUND(B2, -2)           保留到百位（1205 → 1200）
=ROUNDUP(A2/6, 0)        向上取整：不足一组的也算一组
=INT(A2)                 向下取整（负数 -3.2 → -4，与截断不同）
=MOD(A2, 2)              余数：0 即偶数
```

> [!WARNING]
> **警告内容**：**单元格显示位数不等于实际数值**：把列宽格式设为两位小数只是“看着”四舍五入，底层仍是长小数，合计时会出现 0.01 级别的对不上账。涉及金额的中间计算一律用 ROUND 显式舍入，而不是调格式。



#### 随机与按需生成

- **RAND()**：0 到 1 之间的随机小数，无参数；**RANDBETWEEN(bottom, top)**：指定区间随机整数。
- **SEQUENCE(rows, [columns], [start], [step])**：生成连续序列，配合动态数组使用（详见系列第 7 篇）。
- 随机值在每次重算时变化，**要固定结果需复制后选择性粘贴为值**。

```text
=RANDBETWEEN(1, 100)           抽签用的随机整数
=INDEX($A$2:$A$20, RANDBETWEEN(1, 19))   随机抽取一名人员
```

> [!NOTE]
> **提醒内容**：随机函数会随任何编辑操作重算，**抽签、分组这类“抽完不能变”的场景，抽完立即粘贴为值**；需要可复查的公平抽取时，用 RAND 排序法（辅助列生成随机数后按该列排序）并保留原始随机数列备查。
