## 逻辑函数

### IF 与条件判断

#### IF 的结构与嵌套

**IF(logical_test, value_if_true, [value_if_false])**：条件为真返回第二个参数，为假返回第三个参数；第三个参数省略时返回 FALSE。

- logical_test 是返回 TRUE 或 FALSE 的**比较表达式**。
- 三个参数依次是：条件、条件成立时的值、条件不成立时的值，缺一不可（末参数省略有歧义，建议写全）。
- IF 内可再嵌 IF，实现多档判断。

```text
=IF(C2>=60, "及格", "不及格")
=IF(C2="办结", "√", "")
=IF(B2>=85, "优秀", IF(B2>=70, "良好", IF(B2>=60, "合格", "不合格")))
```

> [!IMPORTANT]
> **重要内容**：多档 IF 的条件**必须从高到低排列**：先判 ≥85 再判 ≥70，嵌套才有意义；顺序颠倒会出现“先命中低档、高档永远轮不上”的逻辑错误——这与正则里“或分支从左到右先命中即停”是同一种陷阱。



#### 多档判断的更优写法

**IFS(logical_test1, value1, [logical_test2, value2], ...)**：把多档 IF 拍平成“条件、结果”成对罗列，无需层层嵌套，Excel 2019 起可用。

```text
=IFS(B2>=85, "优秀", B2>=70, "良好", B2>=60, "合格", TRUE, "不合格")
```

- 条件仍须**从高到低**；末尾用 TRUE 兜底，等价于 IF 的“其余情况”。
- IFS 没有默认值参数：所有条件都不满足且没写 TRUE 时返回 #N/A。
- 嵌套 IF 与 IFS 的选择：两三档用 IF 更直观，四档以上 IFS 可读性明显占优。

> 判断某行是否需要 IFS 的经验值：**括号里的 IF 超过两层就该换**。嵌套越深，后期维护越容易漏配对括号——IFS 每档独立成对，出错时一眼能定位到具体档位。



### AND、OR 与 NOT

#### 三兄弟与 IF 的配合

- **AND(logical1, [logical2], ...)**：全部为真才返回 TRUE。
- **OR(logical1, [logical2], ...)**：任一为真即返回 TRUE。
- **NOT(logical)**：取反。

```text
=IF(AND(C2>=60, D2>=60), "双科通过", "有科目未过")
=IF(OR(B2="治安", B2="交通"), "重点类型", "一般类型")
=IF(NOT(C2="办结"), "在办流程", "已归档")
```

- AND、OR、NOT 自身只返回逻辑值，**几乎总是包在 IF 外层**当条件用。
- 参数上限 255 个，但不建议堆太多：超过五个条件时考虑拆辅助列或用 COUNTIF 家族统计代替。

> [!TIP]
> **建议内容**：条件组合的读写口诀是**“全部满足用 AND，满足其一用 OR，反面否定用 NOT”**。遇到“既不 A 也不 B”这类条件，写成 NOT(OR(A, B)) 比硬想嵌套直观得多。



#### 用乘法与加法代替 AND、OR

**逻辑值参与算术时 TRUE 算 1、FALSE 算 0**，因此多条件统计可以把 AND、OR 翻译成乘法与加法，直接配合 SUM 使用。

```text
=SUM((D2:D31="办结")*(B2:B31="治安")*C2:C31)     与关系：乘法（需按 Ctrl+Shift+Enter 或 365 版本）
=SUM((D2:D31="办结")+(D2:D31="中止"))            或关系：加法
```

> 加法做“或”时要小心**条件重叠**：某行同时满足两个条件会计 2 次，需要去重时改用加法后判大于零：((条件一)+(条件二))>0。这一写法在旧版 Excel 需数组公式确认，Microsoft 365 直接回车即可。



### 错误处理与条件返回

#### IFERROR 与 IFNA

- **IFERROR(value, value_if_error)**：公式出错时返回兜底值，否则返回公式结果。
- **IFNA(value, value_if_na)**：只拦 #N/A，其他错误照常抛出。

```text
=IFERROR(B2/C2, "")                                 除零显示空白
=IFNA(VLOOKUP(F2, A2:D31, 3, FALSE), "未找到")      只提示查无此人
```

> 两者的分工：**查找不到用 IFNA**——它只处理“数据不存在”，公式写错（#NAME?、#REF!）仍会暴露；除法、日期计算等“多种错法”的场景才用 IFERROR 一网打尽。能用 IFNA 时优先 IFNA，把其他错误留在水面之上。



#### 布尔值的直接使用

**逻辑函数的返回值本身就是 TRUE 或 FALSE**，很多场景可以不包 IF 直接用。

```text
=D2="办结"                     单元格里直接显示 TRUE 或 FALSE
=(C2>=60)*(D2>=60)             两项均达标为 1，否则为 0，可直接求和
=IF(C2>=60, 1, 0)              与上一行等价，但更啰嗦
```

> [!NOTE]
> **提醒内容**：辅助列里存 TRUE、FALSE 或 1、0 比存“是、否”文本更好用——逻辑值与数值可直接参与 SUM、AVERAGE 与筛选统计，而“是否”文本每次都要套一层条件判断再换算。



### 实战范式

#### 条件判断的组合套路

台账判断的三类高频需求与标准写法：

- **多档评级**：IFS 从高到低，TRUE 兜底。
- **多条件放行**：IF(AND(...), ...) 全满足才通过。
- **查无此人**：IFNA 包住查找函数，给中文提示。

```text
=IFS(C2>=90, "甲", C2>=80, "乙", C2>=70, "丙", TRUE, "丁")
=IF(AND(LEN(B2)=18, COUNTIF($B$2:$B$31, B2)=1), "格式与查重通过", "需人工复核")
=IFNA(VLOOKUP(B2, 名册!A:C, 2, FALSE), "名册中无此人")
```

> [!IMPORTANT]
> **重要内容**：判断**文本相等时 Excel 不区分全半角与大小写**的差异很有限——半角 a 与 A 相等，但全角字母与半角字母不相等、前后空格也不相等。台账中出现“看着一样却判不等”的输入，先检查全半角与首尾空格，必要时用 TRIM 与 SUBSTITUTE 清洗后再比较。
