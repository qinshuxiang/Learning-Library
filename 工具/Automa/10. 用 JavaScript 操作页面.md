## 用 JavaScript 操作页面

### 网页上下文里的 DOM

#### document 就是你的主场

**website 上下文的代码块与页面脚本同权**：document、window 随便用。

- 代码直接跑在页面环境：querySelector、addEventListener、createElement 全部可用
- 与本库 JavaScript 系列第 10、11 篇（DOM 基础与元素操作）的语法完全一致，那里是底座
- 页面上已有的全局变量与框架实例（如挂到 window 的应用对象）也能访问
- 代码与页面自身脚本共享同一个 DOM 树

> 这就是“深度对齐 JavaScript”的落点之一：学过 JS 系列的 DOM 篇，Automa 代码块零门槛。差异只在交付方式——页面脚本住在源码里，代码块住在工作流里。

**速记**：**页面即环境，DOM 篇语法原样搬**。

```js
// 网页上下文里直接操作 DOM
const rows = document.querySelectorAll('table tr');
const data = [];
rows.forEach((row) => {
  const cells = row.querySelectorAll('td');
  data.push({
    name: cells[0]?.textContent.trim(),
    price: cells[1]?.textContent.trim(),
  });
});
automaNextBlock(data);
```



### 典型场景

#### 批量抽取复杂结构

**表格化数据抓取是代码块的招牌场景**：块拼不出的结构化抽取。

- 复杂嵌套（表内表、跨行合并）用块逐个取文本会碎成几十个块
- 一段 JS 用 querySelectorAll 加 map 一次抽完整结构
- 结果组装成对象数组，列名对齐表格定义后 automaNextBlock 写入
- 依赖数组方法（map、filter、reduce）的变换一气呵成（本库 JavaScript 系列第 8 篇数组）

> 判断用块还是用代码的经验值：取两三个字段用块，超过五个字段或结构嵌套超两层就用代码。块数超过十个的工作流，通常该有一段 JS 收拢。

**速记**：**五字段两嵌套是分水岭，代码一次抽全**。



#### 事件派发与状态注入

**代码块能触发页面自身的事件**：绕开模拟点击的局限。

- 直接调用元素方法或派发自定义事件：element.click()、dispatchEvent
- 框架页面（Vue、React 渲染的表单）对模拟输入响应不佳时，操作其内部状态或派发 InputEvent
- 修改页面全局状态：写 localStorage、挂 window 变量
- 与本库 JavaScript 系列第 12 篇事件处理的知识直接对接

> 框架页面的自动化是代码块的高价值区：受控组件需要真实输入事件而不是直接赋值。先试块的模拟输入，不行再上 dispatchEvent，最后才是读框架内部状态。

**速记**：**模拟输入失灵就派事件，框架页面分三档试**。



#### 滚动加载与无限列表

**无限滚动的收尾靠代码**：滚动到没有新内容为止。

- 逻辑：循环滚动加高度对比，页高不再增长即到底
- 纯块方案需要循环块加延迟块加条件块的组合，逻辑分散
- 代码块把整套收敛成一个 async 函数，内含循环与等待
- 收集到的数据一次性交给表格或变量

```js
let lastHeight = 0;
while (document.body.scrollHeight !== lastHeight) {
  lastHeight = document.body.scrollHeight;
  window.scrollTo(0, lastHeight);
  await new Promise((r) => setTimeout(r, 1000));
}
automaNextBlock({ done: true, height: lastHeight });
```

> 代码内的 while 有内建的退出条件（高度不变），比块级 While 更紧凑；但注意超时预算，列表过长时设上限轮数。滚动间隔 1000 毫秒是礼貌值，太快会被前端风控盯上。

**速记**：**高度不变即到底，轮数上限防失控**。



### 边界与风控

#### 代码块的操作边界

**在页面里跑代码要守住三条边界**：权限、频率与合规。

- 扩展权限决定可达范围：跨域 iframe 内的 DOM 不一定摸得到
- 操作频率贴近人的节奏：批量点击与提交之间垫等待
- 站点条款优先：抓取与自动化多数平台有明确限制条款，遵守 robots 与服务协议
- 登录态操作（下单、发言）慎入自动化，出错代价不对称

> Automa 是能力工具，边界靠使用者划：技术上能做的与被允许做的是两回事。写代码块前先过一遍“这个操作是否被站点允许”。

**速记**：**权限定可达，频率像真人，条款划红线**。
