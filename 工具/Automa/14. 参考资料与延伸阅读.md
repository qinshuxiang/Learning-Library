## 参考资料与延伸阅读

### 官方资料

#### 文档与源码

**官方文档与开源仓库是两大权威**：语法争议以此为准。

- 官方文档：goautoma.com 的 extension/docs 板块，含中文版（zh 路径）
- 块参考：每个块的参数、默认值与示例逐块成页
- 表达式参考：数据源关键字与 $ 函数清单的官方定义
- 开源仓库：GitHub 的 AutomaApp/automa（AGPL 协议），源码可查实现细节
- 官方文档仓库 AutomaApp/documentation 可直接读 Markdown 源文件

> 本系列的事实性陈述以官方文档为准；版本行为差异（如 v1.22 前后的表达式语法）以 Release Notes 与文档标注为准。第三方教程与文档冲突时，自己起一个最小工作流实测裁决。

**速记**：**文档定语法，仓库定实现，实测定争议**。



### 延伸指引

#### 按系列篇目深挖

**前十三篇各有所归**：回查与进阶的对照索引。

- 块操作与页面交互（2 至 4 篇）：官方 blocks 参考逐块精读
- 数据与表达式（5 至 7 篇）：官方 expressions 页对照练习
- JavaScript 核心（8 至 11 篇）：配本库 JavaScript 系列第 10 至 14 篇（DOM、事件、网络）、第 30 与 32 篇（异步）
- 集成与实战（12 至 13 篇）：官方教程区与市场里的高星工作流拆解

> 深度对齐 JavaScript 的意义在此收束：Automa 的代码能力上限就是 JavaScript 的能力上限，JS 系列学得越扎实，代码块的天花板越高。两系列交叉阅读，互为练习场。

**速记**：**块查官方参考，码回 JS 系列**。



#### 社区与市场

**市场与社区是活教材**：别人的工作流是最好的课。

- 官方 Marketplace：按分类浏览高下载量工作流，导入拆解
- 社区讨论与issue 区：常见故障（元素找不到、选择器失效）的实战解法
- 教程视频：官方推荐的视频教程区适合入门期跟练
- 学习方法：先跑通、再拆解、后改写，三步把别人的流变成自己的能力

> 拆解工作流时带着本系列的地图读：触发在哪、数据走哪条通道、JS 用在哪。看懂十个高星工作流，比零散看十篇教程收益更大。

**速记**：**市场当教材，拆解加改写**。



### 学习路径建议

#### 四段式进阶

**与系列编排同构的进阶路线**：按需推进不必线性。

- 第一段 无代码上手：1 至 4 篇，跑通抓取与填表流
- 第二段 数据与表达式：5 至 7 篇，让流程有状态
- 第三段 JavaScript 内功：8 至 11 篇，配 JS 系列同步学
- 第四段 工程化运行：12 至 13 篇，定时、容错与告警

> 建议每段收尾用对应篇目的速记清单自测；第三段务必与 JavaScript 系列同修——表达式是 JS 的函数化，代码块是 JS 的宿主环境，分离学事倍功半。

**速记**：**无代码起步，数据搭桥，JS 内功，工程收尾**。
