## 内置函数：$ 系列

### $ 函数总览

#### 命名约定与调用位置

**内置函数一律以 $ 开头**：只能在表达式内调用。

- 调用形态：{{ $funcName(param) }}，写在任何块支持表达式的输入框里
- 函数可以与数据源组合：{{ $getLength([variables.items]) }}
- 返回值直接嵌入所在字符串或作为块的输入值
- 与 JS 代码块的内置函数（automa 前缀，见 9 篇）是两套体系，作用域不同

> $ 函数服务于“块输入框里的轻量计算”：表达式一层内完成取值与变换。需要多语句的场合，$ 函数表达不了，那是代码块的领地。

**速记**：**$ 开头即内置，表达式内随处调**。



### 数值与随机

#### 算术四则与取模

**算术函数覆盖加减乘除取模**：不用绕道代码块。

- $increment(value, n) 加法、$subtract(value, n) 减法
- $multiply(value, n) 乘法、$divide(value, n) 除法
- $modulo(num, divisor) 取余数
- 参数可以是字面量，也可以是方括号包裹的数据访问：{{ $multiply([variables.price], 0.8) }}

> 这些函数就是 JS 算术运算符的函数化封装（对照本库 JavaScript 系列第 12 篇运算符）：表达式引擎不直接算术，函数是它的算术入口。除零、浮点精度等 JS 特性原样继承。

**速记**：**加减乘除模，五函数包办算术**。



#### 随机数与随机数据

**两类随机函数服务不同需求**：随机数字与随机字符串。

- $randint(min?, max?)：区间内随机整数，参数省略时默认 0 到 100
- $randData(expression)：按模板生成随机字符串，模板为数组时随机取一项
- 模板记号：?l 小写、?u 大写、?d 数字、?s 符号、?a 任意等，可组合；?f、?n、?m、?i 是两到三类的组合记号
- 例子：$randData("?u?l?l?l?l?d?d@gmail.com") 生成形如 Apond89@gmail.com 的随机邮箱

> 随机数据的典型用途是测试数据填充与占位账号生成；真要用于注册等严肃场景，注意合规与站点条款，自动化注册多数平台明令禁止。源码补充两点：randint 默认区间为 0 到 100；randData 支持传数组随机取元素，比文档列出的记号更灵活。

**速记**：**$randint 出数，$randData 按模出串**。



### 字符串与日期

#### 字符串处理

**字符串函数是大小写与替换三件套**：与 JS 原生方法对应。

- $toLowerCase(value) 与 $toUpperCase(value)：大小写转换
- $replace(value, search, replace)：替换第一个匹配
- $replaceAll(value, search, replace)：替换全部匹配
- $getLength(str)：取字符串长度，也能取数组长度
- $slice(value, start, end)：按下标截取字符串或数组（源码可见，文档少提）

> 一一对应关系：toLowerCase、toUpperCase、replace、replaceAll、length、slice 都是 JS 字符串与数组的原生方法（本库 JavaScript 系列第 7 篇），$ 函数只是把它们搬进表达式。数值类函数有统一守卫：参数任一不是数字时原样返回输入，而非报错。

**速记**：**大小写替换加长度截取，六个函数对六个方法**。



#### 日期函数 $date

**$date 管日期取值与格式化**：底层是 day.js 的格式体系。

- {{ $date('YYYY-MM-DD') }}：按模板格式化当前时间
- {{ $date('timestamp') }}：取毫秒级时间戳
- {{ $date('relative') }}：相对时间描述，如 A few seconds ago
- {{ $date('2026-09-07', 'DD MMMM YYYY') }}：把指定日期转格式
- 格式记号遵循 day.js：YYYY 年、MM 月、DD 日、HH 时、mm 分、ss 秒

> 报表命名、日志时间戳、定时任务参数都靠它：文件名里嵌日期是最常见的用法（导出文件名写 data-{{ $date('YYYYMMDD') }}.csv）。day.js 格式记号与 MySQL 的 DATE_FORMAT 思路同源，格式串即输出。

**速记**：**$date 一把梭，day.js 记号即格式**。



### 查询与序列化

#### $filter 与 JSONPath

**$filter 用 JSONPath 语法查询 JS 对象**：表达式里的查询语言。

- 语法：$filter(data, syntax)，data 是对象，syntax 是 JSONPath 表达式
- $..color 从数组所有元素中取 color 字段，返回值数组
- 典型用法：{{ $filter([variables.items], "$..price") }} 抽出全部价格
- JSONPath 的通配符与过滤表达式是一套独立语法，按需查阅

> $filter 解决的是“从对象树里批量抽值”：等价于 JS 里的一串 map 加 filter 组合（本库 JavaScript 系列第 20 篇函数式编程的思想），只是被压缩成了一条表达式。

**速记**：**JSONPath 当查询串，一条表达式抽全树**。



#### $stringify 与选型收束

**$stringify 把 JS 值转 JSON 字符串**：序列化进请求体的必需品。

- {{ $stringify([variables.obj]) }} 输出 JSON 文本
- 向 HTTP 请求体传对象时，先序列化再发送
- 至此 $ 函数全家福：算术五件、随机两件、字符串五件、日期一件、查询与序列化两件
- 选型收束：能一个表达式解决的都在这里，解决不了的去代码块

> $ 函数的边界意识最重要：它只有一层表达式的表达力，没有语句、没有循环、没有 try。本篇清单当作速查表用，写工作流时翻着选。

**速记**：**序列化进请求体，全家福十几个够用**。
