### 执行结束

每个任务完成且验证通过后，将本次修改提交并推送到 GitHub main：

1. 先 git status，只添加本次任务相关文件。
2. 排除 .env、密钥、凭据、构建产物、缓存和无关改动。
3. 若已有测试/lint，必须通过；否则不要提交。
4. 若当前不在 main，先切到 main 并执行 git pull --rebase origin main。
   有冲突则停止并报告，不要自动解决。
5. 提交信息用：type(scope): 摘要，如 fix(auth): 修复登录过期问题。
6. 执行 git push origin main。
7. 禁止 force push、禁止跳过 hooks。
8. 若认证失败、分支保护、推送失败、无变更：停止并报告，等待人工处理。
9. 输出：提交 SHA、提交信息、推送结果。
